# 软件交互原型

## 打开与预览

解压后打开index.html。若本地浏览器的文件协议有限制，在解压目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

然后在浏览器打开 http://127.0.0.1:8000/ 。运行服务仅供本机访问；窗口关闭或Ctrl+C即可停止。

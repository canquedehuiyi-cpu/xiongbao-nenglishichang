# 方法来源与范围

核对日期：2026-11-05。本包采用针对软件原型任务重新编写的方法，不分发以下第三方Skill全文、模板代码或数据集，也不依赖它们在使用者电脑上安装。

- WorkBuddy「快速原型工程师」：参考小范围、核心用户流程和快速迭代的定位，去掉全栈基础设施、详细工程架构和固定工期要求。
- grill-me／grilling：参考先解决上游问题、给建议、复用已知信息的提问方法；收敛为每轮1–3问、通常1–2轮，够画主要页面即停止。
- [taste-skill](https://github.com/Leonxlnx/taste-skill)：采用一致的视觉约束、实际控件与浏览器检查；不强制营销网站结构、随机配色或特殊动效。
- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)：参考样式参数、响应式、焦点、对比度和点击反馈等检查维度；当前图片基线优先，不用风格推荐覆盖确认稿。
- [Figma Community模板](https://www.figma.com/community/design-templates?resource_type=files&editor_type=figma)：研究手机、桌面界面及模板预览中的视觉组织方式，归纳简洁工具、温暖消费、编辑式品牌、深色沉浸、数据工作台五类可选方向。仅做方法归纳；包内不含第三方模板、截图或其资产，也不声称访问了所有可编辑源文件。
- [Figma原型连接](https://help.figma.com/hc/en-us/articles/360040315773-Connect-your-prototype)：把交互简化为触发、动作、目标和状态，落实为页面跳转表与浏览器点击检查。

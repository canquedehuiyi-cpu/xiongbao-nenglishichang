# 产品与交互设计 (Product & Interaction Design)

本技能为团队产品与体验侧提供工程方法，与 `agents/` 中的蓝图画(产品)/涂悦目(UI)角色卡联动：角色卡定目标与验收，本技能给可交付的产出物。

## 适用边界
- 需求拆解、PRD、用户故事、验收标准（AC）、优先级与范围。
- 信息架构、交互流程、原型、设计规范与可用性（含可访问性）。

## 工作流
1. **需求对齐**：先澄清用户是谁、要解决什么、成功长什么样；区分 MUST/SHOULD/MAY。
2. **验收口径**：把验收写成可测勾选项（如「P95 < 200ms」而非「响应快」），与测试查无漏共定。
3. **交互与信息架构**：画信息层级与关键流程（mermaid/线框），与 UI 涂悦目对齐体验目标。
4. **设计规范**：输出间距/色彩/状态/异常态的还原度要求，可落地到前端组件（Vue/React）。
5. **范围控制**：范围蔓延或冲突时回抛技术总监钟帷幄裁决。

## 产出约定
- PRD 模板：背景、目标、用户故事、AC、非功能需求、范围边界、里程碑。
- 交互/原型：关键路径流程图 + 主要页面状态（正常/空/错误/加载）。
- 设计规范：组件级还原度清单，便于前端（韦悠然/李响应）落地。

## 与内置技能协同
- 验收口径驱动测试 → `qa-quality`。
- 设计规范落地到前端 → `team-p8-full-stack`（Vue/React 章节）。
- 多端体验一致性 → 跨端唐端阳。

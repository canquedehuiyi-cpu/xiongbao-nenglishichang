# 测试用例 (Test Cases)

本技能为团队产出**具体可执行的测试用例集**，与 `agents/` 中的查无漏(测试)角色卡及 `qa-quality` 技能联动：`qa-quality` 定策略与门禁，`test-case` 产出用例实体。

## 适用边界
- 用例模板、表驱动/参数化用例、边界值分析、等价类划分、状态迁移用例、异常与并发用例。
- 每条用例可追溯验收标准（AC），并标注优先级与类型。

## 工作流
1. **取 AC**：先读产品蓝图画定的验收标准（来自 `product-design`/`qa-quality`），作为用例来源。
2. **拆维度**：正常 / 边界 / 异常 / 并发 / 幂等 / 性能，覆盖等价类与边界值。
3. **生成用例**：用统一模板（编号 / 场景 / 前置 / 步骤 / 输入 / 预期 / 优先级 / 关联 AC）。
4. **可追溯**：每条用例标注关联 AC 编号；状态迁移场景画状态表或状态图（见 `design-diagrams`）。
5. **可自动化**：参数化用例给出数据驱动结构，便于接入 `qa-quality` 的自动化与门禁。

## 产出约定
- 用例集表格：含唯一编号、优先级（P0/P1/P2）、类型、关联 AC、步骤与预期。
- 边界矩阵：输入维度 × 边界点，确保边界全覆盖。
- 状态迁移表：状态 × 事件 × 下一状态 × 断言。

## 与内置技能协同
- 策略与门禁 → `qa-quality`。
- 验收口径 → `product-design`。
- 状态/流程可视化 → `design-diagrams`。

# 教学智能体场景清单

教师从此清单中选择要设计的智能体场景。每个场景包含：名称、说明、典型用途。

---

## 一、备课类

| 场景名称 | 说明 | 典型用途 |
|---------|------|---------|
| 单元备课 | 从课标到课时规划的完整单元设计 | 新学期开始前规划一个单元的整体教学 |
| 课时设计 | 单课时的详细教学设计（五轮迭代） | 为明天的课做详细的教学流程设计 |
| 教学目标拆解 | 将课标要求转化为可操作的课时目标 | 把笼统的课标要求拆成具体可测的目标 |
| 教材分析 | 教材编排意图解读和知识点梳理 | 理解编者为什么这样安排教材内容 |
| 学情预判 | 基于前序数据预判学生学习起点和困难 | 开学前了解学生可能的基础和薄弱点 |

---

## 二、课堂类

| 场景名称 | 说明 | 典型用途 |
|---------|------|---------|
| 苏格拉底提问 | 生成引导性提问链，启发学生思考 | 课堂上用追问引导学生自己发现答案 |
| 课堂追问 | 基于学生回答即时生成深入追问 | 学生给了一个不完整的答案，怎么追问 |
| 分层任务生成 | 同一知识点生成不同难度层次的任务 | 课堂上给不同水平的学生布置不同任务 |
| 情境创设 | 生成贴近学生生活的教学情境 | 用真实情境引入新概念，提高学习兴趣 |
| 课堂小结 | 生成结构化的课堂总结和知识梳理 | 下课前5分钟，帮学生整理这节课的要点 |

---

## 三、作业类

| 场景名称 | 说明 | 典型用途 |
|---------|------|---------|
| 分层作业设计 | 基于教学目标生成基础/提升/拓展三层作业 | 给不同水平的学生布置差异化作业 |
| 错题归因分析 | 分析学生错题模式，定位知识薄弱点 | 从错题中看出学生到底是"不会"还是"粗心" |
| 个性化练习 | 根据薄弱点生成针对性练习 | 给错题多的学生推荐同类变式练习 |
| 作业批改建议 | 为教师提供批改要点和反馈模板 | 快速批阅并给出有针对性的评语 |
| 探究性作业 | 设计开放性的探究任务或项目作业 | 布置需要学生调研、动手、合作的长周期作业 |

---

## 四、评价类

| 场景名称 | 说明 | 典型用途 |
|---------|------|---------|
| 课堂表现评价 | 设计课堂即时评价工具和观察量表 | 课堂上快速记录学生的参与度和表现 |
| 作文/写作评价 | 多维度作文评价（内容、结构、语言、立意） | 批改作文时提供结构化的评价框架 |
| 口语/表达评价 | 口语表达或课堂展示的评价量规 | 评价学生的口语表达、演讲或小组汇报 |
| 解题过程评价 | 不仅看结果，还评价解题思路和方法 | 数学解题中评价思维过程而不仅是答案 |
| 表现性任务设计 | 设计真实情境下的表现性评价任务 | 设计"给校长写一封信"类的真实任务 |
| 评分量规生成 | 为核心评价任务生成简明的评分量规 | 给学生和教师提供清晰的评分标准 |

---

## 五、教研类

| 场景名称 | 说明 | 典型用途 |
|---------|------|---------|
| 听评课 | 基于课堂观察生成结构化评课报告 | 听完一节课后写出有依据的评课意见 |
| 课例分析 | 深度分析一个教学案例，提炼方法论 | 分析名师课例，提取可借鉴的教学策略 |
| 教学反思 | 引导教师做结构化教学反思 | 上完一节课后系统地回顾和改进 |
| 教研议题生成 | 从教学问题中提炼值得研究的教研议题 | 发现教学中的共性问题，转化为教研课题 |
| 教学论文辅助 | 辅助教学论文的选题、框架和论证 | 把教学经验整理成论文的基本结构 |

---

## 六、特色教学类

| 场景名称 | 说明 | 典型用途 |
|---------|------|---------|
| 跨学科项目学习 | 整合多学科视角的项目式学习方案 | 设计融合语文+数学+英语的综合项目 |
| 阅读拓展 | 课外阅读推荐和阅读指导方案 | 为学生推荐适合的课外书并设计阅读任务 |
| 探究式学习 | 引导学生自主探究的学习活动设计 | 设计"提出问题→实验→结论"的探究活动 |
| 作文专项辅导 | 从审题到修改的全流程写作辅导 | 帮学生系统提升写作能力 |
| 数学思维训练 | 逻辑推理和数学建模的专项训练 | 培养学生的数学高阶思维 |
| 英语听说专项 | 语音、口语和听力的专项训练 | 英语课堂上增加听说练习的机会 |
| 个性化学习计划 | 为学生定制学习路径和任务 | 为学困生或优等生制定个人提升计划 |
| 社团/拓展课程 | 社团活动的方案设计和过程指导 | 设计辩论社、戏剧社、STEM社团的活动 |

---

## 使用说明

- 教师从以上清单中选择与自己教学最相关的场景
- 如果教师的需求不在清单中，可以自定义场景（记录名称+简要描述）
- 建议优先级：备课类 > 作业类 > 课堂类 > 评价类 > 教研类 > 特色教学类（按教师日常使用频率排序）
- 每个场景都需要区分学科版本（语文/数学/英语）和学段版本（小学/初中）

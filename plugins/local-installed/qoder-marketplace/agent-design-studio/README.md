# 智能体设计工坊（agent-design-studio）

Qoder 插件版 v1.1.0 —— 引导一线教师完成教学智能体设计的完整工作流。

## 插件功能

主技能 **agent-design-studio** 带领教师走完四步流程：

```
Step 1 选题 ──→ Step 2 设计 ──→ Step 3 制作 ──→ Step 4 测试
（从清单中选）  （建模+对话采集）  （生成智能体配置）  （价值验证+三关质检）
```

- **选题**：从教学场景清单中推荐匹配场景，判断教师类型（专家/成熟/新手）调整引导深度
- **设计**：模块0建模（扩句-缩句-做真题）+ 四模块需求采集（场景/提示词/约束/质量标准）
- **制作**：按标准模板生成智能体配置文件（SKILL.md）
- **测试**：第零关价值验证（A/B 盲评）+ 课标合规性、课堂可行性、教师友好度三关质检

触发词：设计智能体、创建教学助手、制作 Agent、智能体工坊、做一个 skill/技能等。

## 包含的技能

| 技能 | 说明 |
|------|------|
| `skills/agent-design-studio/` | 主技能：智能体设计工坊四步工作流 |
| `skills/grade2-math-worksheet/` | 示例成品：北师大版二年级数学随堂学案生成助手（五星网状模型） |
| `skills/weekly-journal-feedback/` | 示例成品：中学生周记个性化评语生成 |

两个示例技能是工坊流程产出的真实成品，既可直接使用，也可作为 Step 3 生成结果的参照样例。

## 主技能支撑文件

均位于 `skills/agent-design-studio/`，由 SKILL.md 相对链接引用：

- `quick-start-guide.md` —— 教师上手指南（首次启动时可选阅读）
- `scenario-checklist.md` —— 教学场景清单（Step 1 选题参考）
- `constraint-library.md` —— 通用教学约束库（Step 2 模块C 参考）
- `skill-template.md` —— 智能体配置模板（Step 3 生成依据）
- `test-checklist.md` —— 三关评测检查清单（Step 2 模块D / Step 4 参考）

## 外部依赖说明

主技能的"知识库调用能力"章节假定环境中已接入 **ima 知识库技能**，可检索三份教学理论文档（《五星网状教学模型的核心理论结构》《五星网状教学模型的理论策略库体系》《百倍速学习教学设计理论完整知识库》）。若目标环境未接入 ima 知识库，该章节的检索能力不可用，其余流程不受影响。

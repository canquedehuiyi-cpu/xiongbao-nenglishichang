# 纹身图案设计公开能力说明

服务提供方：神火 AI。固定设计师：纹身图案设计，`des_60c0082400b0` / `tattoo_design_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

以图案、身体部位与观看尺度共同决定视觉方案，提供用于讨论的平面稿、身体预览与线条参考。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 主题、个人含义、目标部位和大致尺寸
- 宠物身份、个人上身或旧图改造所需的对应照片
- 已定图稿、准确姓名日期及明确保留或修改的范围

## 交付

- 完整的白底纹身概念图稿
- 基于部位照片的上身概念预览
- 沿用已定图案结构的简化线稿参考

默认 **2K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 不承诺可直接施作的模板或长期愈合效果
- 不提供进针、色料、麻醉、消毒或去除等操作指导
- 不从照片保证精确厘米、完整环绕展开或真实遮盖效果

## 领域注意

- 线稿和上身图都是沟通材料；实际尺寸、线宽、曲面衔接与遮盖可行性须由纹身师复核。
- 只有概念图时不强迫上传身体照片；用户要求本人上身预览时再补对应部位素材。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

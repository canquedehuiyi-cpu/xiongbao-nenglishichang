# 神火招聘海报公开能力说明

服务提供方：神火 AI。固定设计师：招聘海报，`des_372f48ddc810` / `office_recruitment_poster_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

面向店主、行政与招聘人员，制作真实单岗位或多岗位的数字招聘图片。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 雇主、真实岗位、人数、职责与要求、工作地点和投递渠道
- 薪资福利只采用已确认资料，Logo、现场照片可选

## 交付

- 默认3:4竖版招聘海报，岗位事实和投递入口分组清楚
- 多岗位可同图比较，内容确需拆分时按实际信息规划图片

默认 **1.5K / 3:4**，当前默认 1344×1792。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 不代写或筛选简历、不实际投递或发录用通知
- 不代定招聘条件、薪资福利或法律合规结论
- 不保证招满、招聘效果、平台审核或印刷制版

## 领域注意

- 不因模板常见而追加年龄、性别、学历、福利或“薪资面议”等未提供条件。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

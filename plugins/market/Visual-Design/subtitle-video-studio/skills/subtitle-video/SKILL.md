# 字幕视频制作

先取得用户提供的视频、UTF-8 SRT 或 ASS 字幕、输出路径及预览起点和时长。确认 FFmpeg 和 ffprobe 可用，且 FFmpeg 支持 libass 的 subtitles 滤镜、libx264 和 AAC 编码。工具缺失时说明依赖，不声称已生成视频。

在 Windows x64 上使用插件中的 `bin/subtitle-video.exe`。其他系统可从源码构建，具体见 README。使用宿主可用的终端工具执行，路径作为独立参数传入；避免覆盖已有文件。

先使用 `-start` 和 `-duration` 指定短片段预览，并请用户确认字幕内容、字体、位置和时间。最终导出可省略这两个参数。SRT 可指定 `-font` 和 `-size`；ASS 使用文件内的样式。字幕相对原视频时间定位，预览并不改写字幕源。

命令成功后检查输出文件并向用户提供路径；若命令失败，展示错误并说明没有完成导出。不要声称已实现语音转写、翻译或自动发布。仅访问用户指定文件与输出位置。

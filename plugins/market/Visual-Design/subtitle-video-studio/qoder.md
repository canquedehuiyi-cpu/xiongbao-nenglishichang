# 字幕视频制作

负责把用户已有的视频与 UTF-8 SRT 或 ASS 字幕合成为带硬字幕的 MP4，并可先导出一段短预览供确认。只处理字幕排版与视频导出，不做语音转写、自动翻译、画面识别或平台合规审查。

开始时取得四项信息：视频路径、字幕路径、输出路径，以及预览用的起点与时长。先确认 FFmpeg 与 ffprobe 可执行，且 FFmpeg 带 libass 的 subtitles 滤镜与 libx264、AAC 编码；缺失时如实说明依赖，不声称已生成视频。

工具在 Windows x64 上使用插件内 `bin/subtitle-video.exe`；其他系统按 README 从 `cmd/subtitle-video` 构建。通过宿主的终端工具执行，路径作为独立参数传入，不拼接命令字符串。输出已存在时工具会失败，需换新文件名而不是覆盖。

先导短片段预览，请用户确认字幕内容、字体、位置与时间，再导出正片。SRT 可用 `-font` 与 `-size` 指定字体字号，ASS 使用文件内样式；字幕按原视频时间定位，预览不修改字幕源文件。命令成功后检查输出并给出路径；失败时展示错误并说明未完成导出。

本包不包含 FFmpeg/ffprobe，需使用者自行安装并遵守其许可；不访问用户未指定的文件，不上传素材，无外部账号、后台服务或额外收费。首版免费，宿主模型与工具按各自规则运行。作者 tulink，联系 tulink2026@126.com。

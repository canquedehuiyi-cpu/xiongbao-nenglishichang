# 神火信息解读图公开能力说明

服务提供方：神火 AI。固定设计师：信息解读，`des_1b1aab233291` / `information_explainer_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

面向需要把资料讲清楚的内容作者与办公用户，将已读事实和关系转成新闻、知识、产品解释图。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 主题、文章正文、公开链接或系统可读取的文档
- 目标读者、解释重点与需要保留的真实数据；实体产品外观还需对应原图

## 交付

- 时间线、流程、结构、比较或产品注释等静态解释图片
- 配套简短解读、真实来源链接或文档定位及重要未决条件；复杂主题可依需要形成系列

默认 **2K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 不提供实时监测、交互看板、独家调查或工程级精密制图
- 不把无法读取的内容、想象的产品功能或搜索摘要包装为已核实事实
- 不承诺可编辑图表、文档或事实零误差

## 领域注意

- 明确来源、版本、日期和条件；源案例里的产品新闻只能作为历史演示，不能当本次实时事实。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

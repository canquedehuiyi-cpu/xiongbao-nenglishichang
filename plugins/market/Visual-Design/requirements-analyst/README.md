# 需求分析师

将用户提供的工单摘录、访谈记录和反馈材料转成带证据的需求简报与验收条件草案，随后按新证据和明确决策修订。包含 feedback-evidence、requirement-brief、requirement-change 三项技能，首版免费、无自带引擎。

示例：“把这批反馈按用户要完成的任务归组，形成需求简报。区分已知问题与分析假设，不替我承诺排期。”“这条需求已经决定只面向管理员，请同步改需求和验收条件，保留被排除的建议。”

输入为可读文本或 TXT/Markdown，最好保留反馈编号、用户角色、产品版本及原话。交付 Markdown；保存文件依赖宿主实际工具与权限。只读取指定材料，不自动访问 CRM、工单或聊天系统。

分析不等于产品批准：不以消息数量伪装客户比例，不编造市场规模、收益和优先级事实，不自动创建工单、发消息或进行开发。每个技能含对应方法和完整小例子。跨会话继续时请指定上一版材料及新增反馈。

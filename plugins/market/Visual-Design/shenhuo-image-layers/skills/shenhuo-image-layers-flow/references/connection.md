# 连接器选择、安装与复用

服务标识 `shenhuo-designers`，个人 OAuth 端点 `https://api.shenhuoai.com/external/mcp`。先查看宿主当前的市场连接器、自定义 MCP 和其他已安装专家／Skill 的同服务依赖，核对来源、端点及启用状态；不读取 Token 存储。

1. **市场优先。** 渠道市场已有“神火设计师”时优先使用其连接；已安装且授权有效就直接发现工具并调用 `get_account`。市场 ID 只取宿主真实信息，不按显示名编造。
2. **已有连接先复用。** 自定义路径也先检查其他插件、专家或 Skill 已安装的 `shenhuo-designers`。端点正确且 `get_account` 成功时直接使用，不重新安装或重新授权。未启用先启用，工具未挂载先重新发现／拉起原依赖；已安装未授权只对原连接授权。相同名称和 URL 本身不证明共享授权。
3. **找不到市场或安装失败。** 先说明实际状态；若有可复用自定义连接直接沿用。确实没有可复用实例时，询问：“市场连接器当前不可用，是否允许我添加自定义 shenhuo-designers，连接 https://api.shenhuoai.com/external/mcp，并由你完成神火 OAuth 授权？”得到同意后通过宿主实际能力自动配置一次；已有本轮明确同意不重复询问。拒绝则暂停接入，保留原需求。
4. **制作时已确认市场未发布。** 直接走自定义检查与安装路径，无需先尝试市场。用户已请求安装／连接此 Skill 或明确授权执行该接入时不再多问一次；离线制作包本身不安装。缺少安装执行授权时说明要配置的依赖，先取得同意。首次 OAuth 由用户在原生页面完成，不把安装等同于授权。
5. **同名冲突。** 同名但端点不是上述神火地址时，保留现有配置并说明冲突，请用户选择；不能覆盖、删旧连接或复制凭证。多份合法连接选择一个来源明确的实例，优先市场，不混用账号。共享连接只按宿主真实支持方式引用，不给每个新专家另起服务器名。
6. **验证与恢复。** 配置／授权后重新发现工具，用 `get_account` 验证；展示真实连接状态后继续已有项目。401 或缺 scope 先由宿主刷新原连接，无法刷新才重连，不新增副本绕过权限。授权恢复后沿用原任务 ID 与幂等记录，付费操作仍须独立报价确认。

只通过当前宿主实际提供的连接管理工具、原生 UI 或已核实的配置方式操作，保持其他 MCP 配置不变。若当前没有自动安装能力，给出手动入口和必要非敏感参数，明确尚未安装；不臆造安装工具或市场依赖字段。标准 Streamable HTTP 在不同外壳的 type 拼写以渠道规范为准。

复用授权是使用同一个宿主连接，不是读取、复制或手填密码、API Key、Access Token 或 Refresh Token。已有有效授权的真实只读调用成功才算复用通过；不能把 Codex 等其他客户端的成功当成当前宿主已连接。

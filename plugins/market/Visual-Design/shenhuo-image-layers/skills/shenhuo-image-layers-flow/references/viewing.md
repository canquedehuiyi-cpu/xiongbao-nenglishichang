# 打开与查看图层结果

成功后仅使用 `get_layer_separation` 或 `get_layer_editor` 回执中的 `editor_url`。这是网页登录入口；短期图片下载 URL、project_url、document_id 都不能代替它，不拼接地址，不添加 OAuth Token。

## 宿主打开

先检查 Qoder 当前是否提供打开网页、浏览器标签页或系统默认浏览器的工具。有则直接调用一次打开 `editor_url`，遵循该工具权限；用户已明确要求只显示链接或不要打开时遵从用户。没有网页工具但有允许启动浏览器的本机命令能力，可以用参数数组调用系统 URL 打开能力（macOS `open`、Windows 原生打开 URL、Linux `xdg-open`），将服务端 URL 作为完整独立参数，不把它拼入未经转义的 shell 字符串。没有真实能力时不臆造工具名称、不安装浏览器自动化依赖。

调用成功只说明已请求打开；若能看到页面，则按实际状态处理编辑器或登录页，不能把成功启动浏览器说成已登录、已编辑。打开失败或能力不可用时无需反复尝试，直接给可点击链接让用户手动打开。即使成功打开，也在交付回复中保留编辑器结果链接。

## 成功交付文案

分层成功的结果区域只展示“打开图文分层结果”的真实编辑器链接；链接目标取回执 `editor_url`。不追加分层原理或完整复原免责声明，不展示项目 ID、`project_url`，也不承诺可在神火项目里找回原图或分层文档。项目页当前可能为空壳，不能替代编辑器。交付此链接后结束，不追加导出或导入询问。

## 用户询问查看方法或遇到打开问题时

以下为按需说明，不作为每次成功交付的固定附言：

1. 点击“打开图文分层结果”，或查看刚打开的页面。使用与“神火设计师”连接器绑定的同一个神火账号登录；OAuth 授权不会自动让浏览器登录。登录后返回结果页，必要时再次点击链接。
2. 在左侧“图层”中选中文字层，右侧“文字”区域修改内容；还可调整字体、字号、颜色和位置。若图层栏折叠先展开。实际可用功能以页面为准。
3. 对照原图校对识别文字、位置和字体；需要时使用“只看待校对”筛选。完成修改后确认顶部显示“已保存到云端”，再关闭页面。

网页文档成功时即可交付编辑器链接，后续修改由用户在该网页完成。报价确认、失败或取消的真实状态和结算处理不变；用户问费用时只引用服务端回执，不推算。

链接的目标只包含真实 URL，登录说明写在链接外；缺 URL 时再读取一次原分层结果，仍缺失就保留任务 ID 并报告，不输出空链接或自制地址。

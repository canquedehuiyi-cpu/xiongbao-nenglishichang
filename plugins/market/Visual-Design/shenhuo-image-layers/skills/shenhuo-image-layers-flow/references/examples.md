# 场景验收

这是审核用场景，不是当前用户的执行授权。实际工具调用遵循主 Skill。

| 输入或状态 | 应有行为 |
|---|---|
| 上传海报并要求改文字 | 核验账户、上传、document 报价；未确认积分不提交分离，不匹配设计师 |
| 生成可编辑海报 | 实时匹配并等用户选设计师，提案、生图报价确认，交付图片后询问可用性与分层意愿 |
| 图片满意但未同意分层 | 仅确认是否需要分层，不自动上传去分层或扣费 |
| 同意分层但未看报价 | 上传选定原图、展示分层报价，等用户明确确认 |
| 三张作品，只同意第二张分层 | 仅第二张已结算原图进入上传与分层，不更改源图片、不自动处理其余图片 |
| 拒绝报价或不满意图片 | 保留作品和原任务，停止后续付费动作 |
| 无下载或上传能力 | 提供作品链接，请用户下载并上传原图；不以 URL 或 variant_id 冒充 asset_id |
| 分离超过两分钟仍 running | 至少每20秒查原任务，遵守更长 poll_after_ms／限流等待，不换键重建 |
| document 成功、export_id=null | 立即读取 editor_url 并交付，不等 PSD |
| 有网页打开工具 | 打开真实 editor_url，并保留编辑器结果链接，成功交付不附项目或复原说明；不凭浏览器启动断言已登录 |
| 无打开工具或打开失败 | 只交付可点击的真实编辑器链接，用户询问查看方式时才说明具体步骤 |
| 已授权旧连接缺 images:edit | 优先宿主刷新原连接，失败才重连，保留原任务和报价 |
| 积分不足或报价过期 | 积分不足只说明真实状态并暂停；报价过期则重新报价，确认后执行 |
| 查询或提交网络超时 | 查询原 ID 或原键原参数重放，不创建新的收费任务 |
| 分层失败、取消或内容安全拒绝 | 说明真实状态和结算，保留已有图片，不自动重试或换服务绕过拒绝 |
| 工具列表仍有导出能力 | 本插件在编辑器链接交付后结束，不调用额外工具，也不询问导出或导入 |
| 查询旧生成任务 actual_credits | 归属原生成历史费用，不算本次分层新增消费，不用余额差推算 |

验收记录须区分静态包检查、模拟回执审阅与 Qoder 实机调用；表内预期不等于已通过客户端测试。

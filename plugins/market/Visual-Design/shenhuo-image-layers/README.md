# 神火图文分层

把图片上的文字变成可以修改的图层。上传已有海报、广告图或其他图片，确认积分后分离文字与背景，进入神火网页图层编辑器继续调整；也可以先请神火 AI 设计师生成图片，满意后再分层。

## 两种用法

**已有图片：** 上传一张原图 → 查看分层积分报价 → 确认执行 → 获取网页图层编辑结果。

**先生成再编辑：** 描述海报或图片需求 → 选择神火推荐的设计师 → 根据必要追问补充信息 → 确认生图报价 → 查看图片 → 确认作品可用且同意分层 → 查看并确认分层报价 → 获取网页编辑结果。作品确认前不会自动分层。

图文分层主要将文字与背景分开，不代表所有人物、商品或装饰都自动变成独立图层。识别结果需要校对，不承诺还原原始设计源文件。

## 开始使用

1. 没有神火账号时先[注册神火 AI](https://www.shenhuoai.com/register)，新账号有积分赠送，实际到账以账号为准；已有账号直接使用。
2. 在 Qoder“扩展 → 连接器”市场安装“神火设计师”，到“设置 → 扩展管理 → 连接器”的“Qoder 市场”区域完成授权；已有安装与有效授权直接使用。 本插件优先复用市场连接器及已有授权；市场不可用时先复用已有自定义 MCP，没有可复用实例时征得你同意后帮助配置。无需提供 API Key 或 Token，ZIP 本身不自动安装连接器。
3. 在 Qoder 本地导入本插件 ZIP（文件根直接包含 `.qoder-plugin`），启用插件和已选定的神火连接器。在插件或专家头像选择处使用包内 `avatars/expert.png`；市场提交界面若单独要求图标，上传同一文件。
4. 回到对话上传图片或说明需求；授权完成后可回复“已授权，继续”。如工具尚未加载，新建对话并启用本插件及原神火连接器。

## 如何查看和修改

结果就绪后，插件会尝试用 Qoder 可用的网页或系统浏览器能力直接打开编辑地址；成功交付只展示“打开图文分层结果”编辑器链接，不附项目 ID、项目链接、项目找回承诺或固定复原说明。没有自动打开能力时，请手动点击链接。需要查看步骤时可继续询问。

使用与连接器绑定的**同一个神火账号**登录。OAuth 授权不等于浏览器已登录；登录后返回结果页，必要时再次点击结果链接。进入页面后，在左侧“图层”选择文字层，在右侧修改文字内容、字体、字号、颜色和位置。对照原图校对识别结果，修改后确认顶部显示“已保存到云端”。

本 Qoder 插件交付神火网页编辑器链接后即结束，没有 PSD 生成、导出或下载，也没有后续编辑器导入和客户端右侧编辑流程。后续修改请在链接打开的神火编辑器中完成。

## 等待、积分与恢复

生图通常约 **30 秒到 2 分钟**，分层通常约 **1 分钟到 2 分钟**。插件按间隔持续查询，优先遵守服务端等待要求；耗时更长时继续查询原任务，不重复提交。若会话或授权中断，保留原任务 ID 恢复，不承诺结束会话后仍会自动通知。

服务使用神火个人积分。设计师匹配、需求理解与提案可能产生费用；生图和图文分层分别展示当前报价，分别取得确认后执行。已发生的设计费用不会因为随后拒绝分层而自动退还。费用以服务端各阶段回执为准。积分不足时，仅说明当前积分状态和真实回执中的所需积分、可用积分及缺口，并暂停付费操作，保留已有任务。

“先生成再分层”需要将确认的原始作品下载并上传给神火图层服务。宿主有文件能力时插件完成传递；无法读取或上传时，会提供原作品链接，请你下载后作为图片附件上传。分层成功后仅提供真实编辑器链接。只处理你主动提供或明确选定、授权使用的图片；分层网页仍需本人账号访问。

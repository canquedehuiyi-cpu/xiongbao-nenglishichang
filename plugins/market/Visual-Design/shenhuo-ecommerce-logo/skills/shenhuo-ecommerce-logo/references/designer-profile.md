# 电商 LOGO公开能力说明

服务提供方：神火 AI。固定设计师：电商 LOGO，`des_f06a89ff1e71` / `ecommerce_logo`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

服务线上店铺和商品品牌识别的独立数字标志，支持新建及同一标志的明确修改与适配。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 准确店名或商品品牌名、主营范围和主要使用位置
- 修改、改名或同标适配必须有可用原标图片
- 需要精确上传或透明交付时提供对应要求并核实能力

## 交付

- 独立正视的店铺标志图片
- 同源横向、单色、反白或明确改名的标志图片

默认 **1.5K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 完整企业 VI、独立 App 图标、店招海报或包装结构设计
- SVG/AI 源文件、印刷投产、商标可注册或全平台审核保证

## 领域注意

- 新标无需原图；同标适配与改名不能仅凭店名重新创作。
- 默认方形，明确横向组合用 3:2，不把展示白边当所有平台最佳上传资产。
- 透明需检查实际 Alpha 通道，白底和棋盘背景都不代表透明。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

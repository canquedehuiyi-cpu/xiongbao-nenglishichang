# 电商 LOGO使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

给我的网店做一个 LOGO，准确店名和主营商品我发给你。

English: Create an online-store logo using the exact store name and main products I provide.

## 示例 2

把这个已有 LOGO 改成横向组合，图形、名称和品牌特征保留。

English: Rearrange this existing logo into a horizontal layout while preserving the symbol, name and identity.

## 示例 3

只把这个 LOGO 的旧店名换成新店名，其他图形和颜色保留。

English: Replace only the old store name in this logo with the new name, preserving the other shapes and colors.

# 电商主图营销包装公开能力说明

服务提供方：神火 AI。固定设计师：电商主图营销包装，`des_8adee05f2e8d` / `ecommerce_main_image_marketing`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

以用户现成方形或竖版主图为基础，组织真实卖点、优惠与服务，或限定区域改价加字。

## 输入

本设计师必须有用户提供的相关原图。先复用已授权且合用的素材；缺图时只补必要原图，不能以虚构素材 ID 或纯文字绕过上传。

- 必须提供可辨认的现有商品主图
- 准确卖点、价格身份、门槛、日期和服务范围
- 局部修改提供明确旧区域、新文字及保留要求

## 交付

- 包含真实商品、营销文字与图形包装的完整主图
- 按限定范围更新价格或其他文案的完整图片

默认 **1.5K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 独立贴纸、透明图标、空白主图框
- 从零摄影套图、详情长图、店铺海报或包装生产文件
- 像素级一致、平台审核或销量提升保证

## 领域注意

- 默认组织 2–3 个有效营销点属于设计方法，不是图片数量额度；明确只加一句或局部改价优先。
- 原主图常见方形/竖版；精确比例先核输出能力，生成式编辑不承诺像素不变。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

# 跨境电商横版海报公开能力说明

服务提供方：神火 AI。固定设计师：跨境电商横版海报，`des_34912c6b5a10` / `cross_border_ecommerce_landscape_poster`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

面向海外店铺的商品、活动与系列横向推广，支持完整海报和平台自行叠字的静态素材。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 实际商品与照片，或完整纯活动文案
- 真实优惠及适用商品、币种、期限和必要服务条件
- 明确图位时提供宽高、裁切和文字装配要求

## 交付

- 海外上新、活动、系列及窄横幅静态海报
- 按实际图位留白的无新增营销文字横向素材

默认 **1.5K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 商品首附图图库、详情/A+ 模块、竖版图与动态广告
- 网页装配、可编辑源文件、互动按钮与自动投放

## 领域注意

- 默认英文不自动选美元、美国站或英制单位；用户明确其他语言时重排。
- 常规 16:9，明确窄横幅可 21:9；auto 只在横向范围内。
- 店铺背景和平台广告图像素材不同，不能一图保证全平台适配。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

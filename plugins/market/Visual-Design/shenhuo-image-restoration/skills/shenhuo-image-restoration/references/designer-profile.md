# 图片修复与精修公开能力说明

服务提供方：神火 AI。固定设计师：图片修复与精修，`des_fd8210320864` / `image_optimization_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

从现有照片出发做自然修复和指定编辑，适合老照片、人物、商品与实景图片的观看效果改善。

## 输入

本设计师必须有用户提供的相关原图。先复用已授权且合用的素材；缺图时只补必要原图，不能以虚构素材 ID 或纯文字绕过上传。

- 可访问的原始照片与需要处理的区域
- 要保留的人物身份、主体结构、文字和背景
- 可选的清晰参考图、标记图与目标风格说明

## 交付

- 划痕、折痕、褪色与局部瑕疵修复图片
- 指定物体移除、光色与构图调整图片
- 保持主体识别特征的自然精修结果

默认 **2K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 不把补画的未知脸部、车牌、文字或历史颜色宣称为真实还原
- 不保证像素级原样保留或任意清晰度恢复
- 不承担正式证件照审核，不将普通白底图片冒称透明背景文件

## 领域注意

- 修复可能包含合理补绘，应区分可见原有事实与无法核实的内容。
- 透明输出只在实际服务和文件确有 alpha 通道时承诺，不能由提示词或棋盘格外观推定。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

# PPT生成/美化·MeituHub

![插件头像](assets/plugin-icon.png)


把资料讲清楚，把重点做出来。先梳理内容与证据，再设计图文和数据页面；支持新建 PPT、旧稿美化、HTML 演示与配图，文字和数据可继续编辑。

## 可以做什么

| 技能 | 用途 |
| --- | --- |
| PPT生成 | 先确认内容和风格，梳理每页结论与证据，再制作图文和数据页面，交付可编辑 PPTX。 |
| PPT美化 | 保留旧稿文字、数字和备注，重整信息层级、图片处理与数据表达，让每页重点更清楚。 |
| HTML制作 | 把资料做成可翻页的网页演示，结合图片、数据图表与适当动效，支持讲解和在线阅读。 |
| 配图生成 | 按页面内容生成或处理配图，完成抠图分层、扩图、构图适配与清晰度改善，让图片真正融入页面。 |

## 这样开始

- 把这份产品资料做成给客户看的 PPT，保留原文和数据，先给我看三页。
- 美化这份 PPT，配色沿用原稿，重点改封面和产品页。
- 把这份课程资料做成可以手动翻页的网页演示。

## 安装与运行

在 Qoder 的插件入口导入本包 ZIP。每包自带 MeituHub 接入，无需 MCP 或另装基础插件；首次使用按提示连接账户，实际调用可能产生用量。

版本 0.4.0。包结构与本地辅助工具已检查，尚未完成 Qoder 安装、自动路由和真实业务调用验收。具体服务以当前账户工具目录为准。PPTX 编辑与预览、XMP 导入、原生小程序运行需相应宿主工具；源码与预览不等于已上线。原文件保留，产物另存。

## 自然语言使用

可以直接描述想要的结果，不必先写技能 ID。技能已补充常用说法和相关场景，自动选择效果以 Qoder 实测为准。查看 [场景识别与分工](references/intent-routing.md)。发布页图标可使用 `assets/plugin-icon.png`。

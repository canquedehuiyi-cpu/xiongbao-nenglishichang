# 图片选择、处理与回填

配图从“这页要说明什么”出发。先定主体、用途和文字区域，再生成；图片不能只是填空白。所有生成、编辑、抠图、超清和图片理解均通过 [包内接入](../skills/meitu-ai-ppt/SKILL.md)，发现当前工具后读取帮助，不照抄旧模型或参数。

## 每个槽位作一个决定

| 决定 | 适用情况 | 操作 |
| --- | --- | --- |
| 保留 | 真实原图符合内容，分辨率与构图可用 | 保留原件，等比放入，必要时调整位置与裁切 |
| 处理 | 主体正确，但背景、比例、清晰度或留白不合适 | 按问题调用美图编辑、抠图、扩图或超清 |
| 替换/新生成 | 缺少必要情境或视觉，原图与内容不符 | 按已定方向生成；真实产品/人物优先参考原件 |
| 无图 | 数据、关系、公式或纯文字表达更清楚 | 用原生文字、图表与节点，不用装饰图填空 |

一张图片必须解释对象、支撑证据、展示细节或建立主题情境。具体品牌、真人、地点、活动和产品不得凭空生成成“实拍证据”。源素材缺失时询问、略去相关事实，或在用户认可的概念表达范围内制作。

## 按问题选处理，而非只做文生图

| 发现的问题 | 处理路线 | 回填检查 |
| --- | --- | --- |
| 主体被杂乱背景淹没 | 美图抠图，主体与页面背景分层；必要时美图编辑背景 | 发丝、孔洞、透明材质、细线和白边；主体不缺损 |
| 页面需要宽图，原图太窄 | 先改槽位或等比裁切；裁掉关键主体则用美图扩图/构图适配 | 主体完整、视角连续、新区域不多出产品或人物 |
| 原图模糊且需要大面积显示 | 先找原始高分辨率文件；确实低清再美图超清 | 字标、五官、纹理与原图一致，不把臆造细节当恢复 |
| 产品需要更强展示 | 保留真实外观，抠图主体 + 细节局部 + 使用场景编辑 | 包装、Logo、比例和关键颜色锁定；文字标注另排 |
| 系列图风格混乱 | 用已确认锚点作参考编辑，统一光线、色调和材料 | 统一语言但改变镜头与内容，不能同图重复裁切充数 |
| 图像与标题争夺焦点 | 调整主体朝向、文字区、镜头和画面占比 | 在实际页中看层级，不靠厚重蒙层遮挡问题 |

美图命令选择以当前帮助为准：从零用 text-to-image，参考编辑用 image-edit，透明主体用 image-cutout，超清用 image-superres-enhance；扩图/适配先发现当前支持的能力。等比缩放、裁切、文件格式转换是确定性后处理，可以本地做，不冒称美图编辑。

## 提示词先描述用途与保真

内部为每个槽位写：所在页与作用、画幅和实际尺寸、主体及不可变项、场景/关系、镜头与光线、风格锚点、文字留白位置、是否需要透明底、不能出现的内容。

例如：真实产品参考必须保留包装和字标，主体位于右侧并完整入画，左侧给原生标题留出干净空间；不是让生成图写标题和数据。描述实际视觉，不堆“高级、震撼、大师级”。参考图的身份约束与风格参考分别标清。

## 先一张锚点，再成系列

按页面计划先做最有代表性的主视觉。下载后看真实结果，失败先修正，不批量复制错误。参考已确认的颜色、光线和材料，分别制作全景、细节、场景等不同职责的图。一个全新完整演示任务须有本次实际美图生成/处理且真正进入页面的核心素材；不以最低一张为完成整套素材工作的标准。按内容需要覆盖全部有效槽位，不为次数给纯数据页生无关图片。用户限制生成/上传时遵守限制，不能假称已调用。

## 回填到实际成品检查

- 原始像素、可见裁切区域和显示框的比例分别检查。1920×1088 不是精确 16:9，不能直接拉伸。
- 真实产品和证据图优先完整显示；情境图可以裁切但主体和叙事不能丢失。不得反复裁同一张图替代不同证据。
- 透明素材实际检查 alpha，不能用白底 JPEG 假装透明。白边、残底、孔洞被封死或脸部失真要修。
- 图放回 PPTX 后看文字留白、主体尺寸、遮挡、与相邻页的节奏；单张图漂亮不等于页面成立。
- 普通标题、数值、标注、图例单独作为原生对象。成品不加生成来源标签；必要的事实图注保留。

来源、任务 ID、输入/输出路径、原始尺寸、裁切与采用页号留在内部素材记录；普通交付只呈现成品及必要素材。

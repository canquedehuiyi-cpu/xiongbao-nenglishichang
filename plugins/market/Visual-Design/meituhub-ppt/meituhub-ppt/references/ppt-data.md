# 让数据表达结论

先核对真实数据，再设计图表。图表既要有明确的视觉重点，也要能核对、能编辑。不能生图画柱状图、让模型补缺数字或凭表格截图猜精确值。

## 数据先过一遍口径

逐组记录来源文件/工作表/位置、时期、指标含义、单位、统计范围、分母、缺失值与授权的计算。不能把空值改成零；总和不一致先查原因。百分数与百分点分开，币种、含税/未税、累计/当期、目标/实际不能混用。比较时先保证期间与范围一致。

只有截图且数字看不清，先索取原表或对具体数字询问；可以盘点能看清的内容，但不能直接补造完整图。未提供业务结果就不写“增长显著”“转化翻倍”。衍生值保留计算依据，不把相关关系写成因果。

## 按问题选图，不按装饰选图

| 想回答的问题 | 首选表达 | 关键约束 |
| --- | --- | --- |
| 谁多谁少、谁排第一 | 排序横条或柱图 | 同尺度；条形长度以零为基线；类别多时分组或拆页 |
| 随时间怎样变化 | 折线/柱图 | 时间间隔一致，缺失点不当零；标关键事件须有来源 |
| 各部分占多少 | 堆积条、100%堆积；少量类别可圆环 | 必须有可加总的整体，负数不做饼；圆环需真实占比 |
| 目标完成多少 | 实际/目标条、差值、关键数值 | 写清目标和时期，不只显示孤立百分数 |
| 总量为何变化 | 瀑布或增减桥图 | 各项确能相加，起点与终点对得上；不懂归因则不用 |
| 两个数值是否相关 | 散点图 | 每点来源对应，轴单位完整，不从相关推出因果 |
| 规模/结构怎样分布 | 分组表、直方或箱线等适配图形 | 原始数据和统计定义足够才使用；不能用虚构密度曲线 |
| 多维精确比较 | 原生表格、有限单元格强调 | 保留单位与表头，只突出关键差异，不全表高亮 |

不强制每稿出现所有图形；两组数据用一张清晰比较图比硬凑仪表盘更好。图表不支持原生实现时用可编辑形状/表格与原始数据，明确其编辑边界；不能承诺有不存在的“编辑数据”入口。

## 一页如何组织

先用真实数据写一个有依据的结论标题，再用一张主图支撑。突出一个系列、差异或转折；其他内容降低权重。旁边可放一个关键数值和一句解释，但大数字不能脱离单位、时期、基准。细节表可以放在约定的后页/附页，不擅自删用户内容。

例如已有“目标与实际”时，用同尺度对比和差额说明完成情况；已有跨期数据时，用趋势图标出有证据的变化点。没有这些数据，就不用这些表达。图表元素遵循同套字阶、颜色角色和边距；对齐数据区与标题区，让人一眼能找到结论与证据。

## 原生、可核对、可修改

- 数据系列用原生图表并嵌入真实数据工作簿，类目/系列/数据值与源表一致。表格、指标数字和标签保持独立可编辑。图表截图只能作为参考，不冒充可编辑图表。
- 渐变或三维透视不改变读数；条图不截断零基线。折线如采用非零范围需清晰刻度且不夸大结论；跨页比较尺度一致。避免误导性的双轴，确实需要时标明轴与单位。
- 只保留帮助读数的网格线，减少装饰线和过多数据标签。负数、极值、空值、长标签按实际检查；颜色之外配标签/线型便于区分。
- 源数据与图表缓存需一致。可用 [数据检查脚本](../scripts/audit-pptx-data.py) 找缺工作簿、失效关系和简单单元格引用的缓存差异；复杂公式只标待复核，脚本不替代语义核对。
- 实际打开 PPTX，在副本中改一个文字和一个图表数据值，保存后确认图形更新，保留最终交付原值。不能仅因有 chart XML 就称编辑通过。

## 完成前复核

逐图核对标题结论、系列和类别、正负号、单位/分母/时期、来源、加总、计算与轴。再看实际渲染：标签不遮挡、图例明确、强调色对应结论、小数精度统一。必要的来源与单位属于内容，必须保留；工具来源、生成标签与模型信息不放在画面。

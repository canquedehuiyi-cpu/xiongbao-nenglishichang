# 跨境电商竖版海报公开能力说明

服务提供方：神火 AI。固定设计师：跨境电商竖版海报，`des_637d018d89c3` / `cross_border_ecommerce_portrait_poster`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

通过纵向商品与信息层级制作海外上新、礼赠、商品系列和活动海报，可按实际图位制作无字素材。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 商品照片、真实推广目标与必要产品资料
- 真实售价、件数、优惠代码、币种、日期及条件按需提供
- 具体竖版图位和文字装配要求；可指定新增文案语言

## 交付

- 商品、礼赠、目录或活动的完整竖版静态图片
- 实际平台需要的无新增文字竖向商品素材

默认 **1.5K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 首附图图库、详情/A+ 模块、横幅或网页建设
- 动态组件、自动投放、可编辑文件及扫码保证

## 领域注意

- 默认英文，常规竖图 3:4；高窄需求可 9:16，不自动扩成详情长图。
- 当前 4:5 标准映射为近似比例，精确 4:5 必须另核。
- 礼赠主题不自动增加礼盒、赠品或折扣。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

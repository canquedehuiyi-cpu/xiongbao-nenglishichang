# 跨境电商竖版海报使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

这款新品面向海外顾客推广，帮我做一张竖版海报，商品图和介绍发给你。

English: Create a portrait launch poster for overseas customers using my product images and information.

## 示例 2

为这个商品系列做一张礼赠主题竖图，实际售卖内容和照片我来提供。

English: Create a portrait gift-themed poster for this product collection using its actual contents and photos.

## 示例 3

把这些已确认的优惠信息做成我指定语言的竖版活动图，商品包装保持原样。

English: Create a portrait promotion in the language I specify from these confirmed offer details, preserving the original packaging.

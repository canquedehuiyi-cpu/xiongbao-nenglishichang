# 电商主图与详情公开能力说明

服务提供方：神火 AI。固定设计师：电商主图与详情，`des_75ae15300c95` / `ecommerce_image_suite_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

为同一商品组织完整购买信息图组，用商品套图的整体一致性区别已有分别服务主图和详情的专家。

## 输入

本设计师必须有用户提供的相关原图。先复用已授权且合用的素材；缺图时只补必要原图，不能以虚构素材 ID 或纯文字绕过上传。

- 对应实际商品和 SKU 的清晰原图
- 已确认卖点、参数、配件、售卖数量与文案
- 目标平台、使用位置和用户指定的图片数量

## 交付

- 商品主图、使用场景图与购买信息套图
- 卖点、规格、包装及 SKU 差异展示图
- 围绕同一商品统一视觉风格的详情图片

默认 **2K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 不编造认证、功效、销量、评价或购买承诺
- 不擅自修改商品结构、真实材质、型号或随货配件
- 不代运营店铺、上传商品或保证成交，不承诺可编辑详情页模板

## 领域注意

- 与现有主图、详情专家存在覆盖，展示文案重点放在商品套图和信息一致性。
- 不同平台画幅与规格应按真实运行时分别执行，不用提示词偷换任务规格。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

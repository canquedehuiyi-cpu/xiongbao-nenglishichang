# 电商主图与详情使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

这是商品原图和准确卖点，帮我设计一套主图与详情图片，张数按内容安排。

English: Design a main-and-detail image set from these product photos and verified features, choosing the count to fit the content.

## 示例 2

为这个产品做使用场景图，保留真实外观，并区分产品和仅作布景的物品。

English: Create a usage scene while preserving the product and distinguishing included items from props.

## 示例 3

这些型号外观和参数不同，请依据各自素材做清楚的规格展示图。

English: Create specification visuals for these models using each model’s own photos and data.

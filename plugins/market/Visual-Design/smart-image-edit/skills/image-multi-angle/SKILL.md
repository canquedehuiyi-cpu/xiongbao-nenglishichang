# 多角度

为图片中的主体生成新的观察视角，包括水平角、俯仰和远近。适合商品换角度；普通二维旋转或镜像使用翻转工具。

## 开始前

读取本目录随包的 [连接与渠道规则](./references/channel.md)、[画布流程](./references/canvas.md)、[报价轮询与文件](./references/runtime.md)、[领域方法](./references/method.md) 和 [素材边界](./references/safety.md)。错误恢复见 [工具说明](./references/tools.md)，多图或多步骤见 [批量调度](./references/batch.md)。这些文件都在本 Skill 内，不要求另外安装技能。

主操作为 `multi_angle`，制作时执行模式为 `api`；每次通过 `get_account` 与 `canvas_list_tools` 核实连接、工具、实时模式、参数和限制。未发布时停止并说明不可用；模式改变时按真实 mode 分流，不强行执行旧路径。只处理用户给出的图片编辑需求，不匹配设计师或发起创作提案。

同一请求先恢复已有画布项目，使用明确的图片及保存版本。上传原始字节并取得真实资产，不把链接当已上传文件。不读取网页草稿或接管编辑租约。

## 素材诊断与参数

说明希望看到的方向和主体保持项。当前 horizontal_angle 为 0–359 整数，vertical_angle 为 −30–60 整数，distance 为 0近/1中/2远；以实时参数 Schema 为准，不误把建议角度当唯一取值。多个视角从同一源版本分别生成，不串联造成漂移。

上面的数值是本版制作时已核实的参数范围；运行时以 `canvas_list_tools` 返回的 Schema、限制和报价为准。能力变化后不猜参数或固定价格。领域方法内的其他工具用于方法比较；未经用户要求和确认，不能自动串联或另收费重试。

## 执行与交付

对 `multi_angle` 使用 `canvas_quote(project_id, image_id, revision_id, tool, parameters, idempotency_key)`，展示范围、参数及本次积分。用户明确确认有效报价后才调用 `canvas_run`，传真实 quote_id、稳定幂等键和 user_confirmed=true。先等 15 秒，第一分钟每 10 秒、第二分钟每 15 秒、之后每 20 秒查询同一任务，遵守更长服务退避；直到真实终态再 `canvas_get_result(task_id=...)`。结果未知不换键重做。积分不足只提示并暂停。

比较主体结构、比例、标签和材质，明确不可见背面由模型补全，不能当实物事实。核对真实输出尺寸与透明能力，不承诺原尺寸、透明通道或精确三维重建。

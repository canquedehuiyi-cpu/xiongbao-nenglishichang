# AI 图层分离

将图片中的主体、背景等视觉元素拆为多个图层，用于图片分层、图片分离、物体拆层和图层编辑。仅需文字与背景分离时用图文分层。

## 开始前

读取本目录随包的 [连接与渠道规则](./references/channel.md)、[画布流程](./references/canvas.md)、[报价轮询与文件](./references/runtime.md)、[领域方法](./references/method.md) 和 [素材边界](./references/safety.md)。错误恢复见 [工具说明](./references/tools.md)，多图或多步骤见 [批量调度](./references/batch.md)。这些文件都在本 Skill 内，不要求另外安装技能。

主操作为 `separate_seedream`，制作时执行模式为 `api`；每次通过 `get_account` 与 `canvas_list_tools` 核实连接、工具、实时模式、参数和限制。未发布时停止并说明不可用；模式改变时按真实 mode 分流，不强行执行旧路径。只处理用户给出的图片编辑需求，不匹配设计师或发起创作提案。

同一请求先恢复已有画布项目，使用明确的图片及保存版本。上传原始字节并取得真实资产，不把链接当已上传文件。不读取网页草稿或接管编辑租约。

## 素材诊断与参数

说明希望拆开的主体和必须保留的关系。max_images 是含背景的最大层数，当前默认 10、范围 2–100；按素材复杂度选择上限，不能保证生成指定数量。可用 prompt 描述分离重点，不虚构可编辑节点接口。按层收费时展示冻结积分上限，结算看实际回执。

上面的数值是本版制作时已核实的参数范围；运行时以 `canvas_list_tools` 返回的 Schema、限制和报价为准。能力变化后不猜参数或固定价格。领域方法内的其他工具用于方法比较；未经用户要求和确认，不能自动串联或另收费重试。

## 执行与交付

对 `separate_seedream` 使用 `canvas_quote(project_id, image_id, revision_id, tool, parameters, idempotency_key)`，展示范围、参数及本次积分。用户明确确认有效报价后才调用 `canvas_run`，传真实 quote_id、稳定幂等键和 user_confirmed=true。先等 15 秒，第一分钟每 10 秒、第二分钟每 15 秒、之后每 20 秒查询同一任务，遵守更长服务退避；直到真实终态再 `canvas_get_result(task_id=...)`。结果未知不换键重做。积分不足只提示并暂停。

查看实际图层、缺失元素、边缘与合成效果；不把补全区域称为原始隐藏内容。先交付画布链接；仅明确要下载后导出所选图片保存版本。

## 示例需求

“把商品、装饰和背景拆成图层，最多 6 层，先让我看分离效果。”

# 本地矢量化

打开智能画布本地矢量化工具，将简单标志、色块插画或线稿描摹成矢量。由用户预览、调整并按网页提示应用。

## 开始前

读取本目录随包的 [连接与渠道规则](./references/channel.md)、[画布流程](./references/canvas.md)、[报价轮询与文件](./references/runtime.md)、[领域方法](./references/method.md) 和 [素材边界](./references/safety.md)。错误恢复见 [工具说明](./references/tools.md)，多图或多步骤见 [批量调度](./references/batch.md)。这些文件都在本 Skill 内，不要求另外安装技能。

主操作为 `vectorize_local`，制作时执行模式为 `browser`；每次通过 `get_account` 与 `canvas_list_tools` 核实连接、工具、实时模式、参数和限制。未发布时停止并说明不可用；模式改变时按真实 mode 分流，不强行执行旧路径。只处理用户给出的图片编辑需求，不匹配设计师或发起创作提案。

同一请求先恢复已有画布项目，使用明确的图片及保存版本。上传原始字节并取得真实资产，不把链接当已上传文件。不读取网页草稿或接管编辑租约。

## 素材诊断与参数

先判断是否适合路径描摹，核对实时文件、像素与路径上限。以 tool=vectorize_local 定位网页工具，用户按实际面板调整细节、颜色与噪点等可用设置，预览后按网页报价确认应用。不能把本地处理解释为一定免费。

上面的数值是本版制作时已核实的参数范围；运行时以 `canvas_list_tools` 返回的 Schema、限制和报价为准。能力变化后不猜参数或固定价格。领域方法内的其他工具用于方法比较；未经用户要求和确认，不能自动串联或另收费重试。

## 执行与交付

此操作当前为 `mode=browser`：仅调用 `canvas_get_editor(project_id, image_id, tool="vectorize_local")`。使用返回的原始定位 URL，能打开则直接打开，否则提供可点击链接；提示使用同一神火账号登录。不能用 canvas_quote/canvas_run 模拟此网页操作，不能把入口返回称为完成。用户按网页实际能力调整、确认应用并保存，可能的费用以页面报价为准。

入口返回不表示 SVG 已生成；用户应用保存后按真实网页能力下载，并安全检查实际 SVG。对比细线、孔洞、颜色与路径密度，不自动改用云端付费转换。

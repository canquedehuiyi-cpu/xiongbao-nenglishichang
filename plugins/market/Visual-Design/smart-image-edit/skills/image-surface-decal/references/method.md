# 精确贴合方法

明确底图、图案和目标表面。先检查表面是否平整、弯曲、遮挡或强反光，确认图案应该覆盖的范围、方向和留白。透明 PNG/WebP 有助于避免不需要的矩形底色，不能把预览白底当作透明。

使用真实图片的精确贴合入口，由用户选择图案并在网页调整。先保持图案自身比例，再对齐表面主方向与透视，最后细调边界和网格；避免一开始大幅扭曲使标志失真。使用网页当前实际提供的控件，不能通过 MCP 编造网格点数组或接管编辑租约。

核对图案比例、透视方向、曲面弯曲、边缘、遮挡和对比度。精确贴合是放置与变形能力，不承诺自动恢复真实材质、反射或不可见几何。若需要其他处理，先核实工具已发布并征得用户确认，不能默默追加付费步骤。

用户预览满意后按网页实际报价确认应用并保存；入口本身没有处理副作用不表示后续操作免费。读取保存版本后才继续导出或修图。例：把标志放到杯身时先核对正面方向与标志比例，再调弧度和两侧边界。

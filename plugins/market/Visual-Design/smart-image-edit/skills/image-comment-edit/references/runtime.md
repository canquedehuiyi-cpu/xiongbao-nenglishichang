# 报价、轮询与文件

## 输入与保存版本

先确认原始文件与处理目标。上传按 `create_upload` 返回的 URL、method、headers 传输原始字节，正确处理必需请求头与重定向；通过 `get_upload` 核对上传成功、真实资产 ID，服务返回哈希时核对源文件哈希。不得传缩略图或从截图虚构原图已上传。HTTPS 验证保持开启，不使用 `-k` 或 `--insecure`。

有现成画布项目时优先恢复。创建项目的名称不超过 32 字；原图逐张导入同一项目，记录 `image_id` 与 `revision_id`，导入返回的源资产身份也按真实回执保存。参考图应属于当前用户与当前项目，不猜 ID。

不读取用户未保存的网页草稿、不接管编辑租约。用户刚在网页修改时先请其保存，再读取当前版本。上一步产生新图片时，连续处理使用其真实结果版本；OCR／翻译只返回数据，继续使用原图片同一保存版本，不编造结果版本。新图片已产生后不能错误地继续处理初始版本。

## 报价与积分

实时 `canvas_list_tools` 和 `canvas_quote` 是能力、参数、尺寸与积分真源。以报价返回的金额为准，不从目录基础价推算规格价；规格缺价不自行套默认价格。发起操作前展示图片、方法、参数、是否新增结果及本次报价，取得用户对范围和有效报价的明确确认。

OCR、翻译、图层分离、超分等均可能收费，不因“准备步骤”跳过确认。原确认只覆盖其中明示的操作、范围与预算；后续追加操作或价格变化须再次展示并确认。浏览器操作也可能收费，入口返回本身没有执行或扣费，网页上的操作按页面报价确认。

分离按输出层计费时明确报价为冻结上限；实际层数和实际结算用回执读取，不把上限当实际扣费。`max_images` 包括底图，不保证一定生成该数量。

分别记录：历史已结算、本次有效报价、本次实际结算。账户余额只作为当时状态，不用余额差推算本次费用；累计历史值不能写成本次新增。未返回本次结算明细时说“本次结算明细暂未返回”，保留任务和画布入口供核对。退款、释放预冻结也不自己计算。

积分不足只说明真实状态与操作已暂停；所需、可用和缺口只引用明确回执。保留项目、图片、版本、报价、任务及幂等记录，不自动重试、重建任务或更换身份。本分支不提供获取积分的入口、购买建议或后续操作口令，不转述服务端购买引导。

## 持续查询

任务回执未到终态时继续查询，不能把“任务已提交”作为交付完成：

| 阶段 | 查询节奏 |
| --- | --- |
| 已受理的前 15 秒 | 先告知开始处理，等待首次查询；回执已终态则直接取结果 |
| 15–60 秒 | 每 10 秒查询同一任务 |
| 60–120 秒 | 每 15 秒查询 |
| 超过 120 秒 | 每 20 秒继续查询，给简短进度，不重复提交 |

采用本表与服务返回的 `poll_after_ms` / `Retry-After` / `retry_after` 中更长的等待时间。不同工具耗时不同；30 秒至 2 分钟仅是图片处理的常见观察范围，不是超时或成功承诺。少数任务更久时保持原任务，不能因两分钟过去判失败。对导出也查原 `export_id`，同样遵守服务退避。

每次读取真实状态：`queued`、`running`、`cancel_requested` 继续查；`outcome_unknown` 等服务核对，仍占并发槽，不能重做；`succeeded` 取真实结果；`failed` / `cancelled` 如实告知并保留已完成结果。若返回其他状态，按回执说明处理，不能猜测成功。

查询错误或网络断开不等于任务失败。最多按服务限制、且不超过两个在途操作。会话或工具运行上限确实阻止继续时保存无凭证的恢复记录，说明仍未完成和恢复方式；不能说已后台持续运行。下次先查原任务，再处理未开始项。

## 幂等与异常

创建、导入、报价、执行、取消、导出各用不同且稳定的幂等键；1–160 位非空白 ASCII。所有恢复记录只包含项目、版本、操作、报价与任务标识及确认范围，不含账号密码、Cookie、Token、临时下载票据。

请求超时已知任务 ID 就查询；没有任务 ID 就重放原键和原参数。禁止换键重做结果未知的操作。版本变化先读当前状态重新报价，价格变化再次确认。同一图片两个修改串行执行；多个视角都从同一用户选择的源版本生成，避免连续变换漂移。

仅响应用户明确取消意图调用 `canvas_cancel_task`；取消受理不等于取消完成，继续核对。已确认失败的处理，用户要求重试后才新建报价与操作。旧授权失效先恢复原授权，再查询原任务。

## 交付与可选导出

成功后 `canvas_get_result(project_id, task_id=...)`。先真实展示 `canvas_url` 及能取得的作品；文本识别只交付文字数据，无文字结果说明没有检测到文字，均不能声称修改图已产生。打开或读取实际图片后按领域清单核对；无查看能力时明确哪些视觉项未检查。

分离成功即可交付并等待用户；不要以收尾、预生成或备份为由调用 `canvas_export`。用户明确要求下载某个格式后，针对已选图片的已保存版本独立导出，记录 `export_id` 并持续查询。只有目录及结果支持的格式才提供。PSD 的图层与文字可编辑程度取决于真实分离结果，不保证原字体、隐藏区域或矢量对象完整恢复。

导出失败只重试导出：原 `retry_export_id`、原图片/版本/格式、新导出幂等键。用户网页改成新版本后想导出新版则重新读取并确认新版本，不把它伪装为旧版本重试。处理失败重试与导出重试是两条独立路径。

`canvas_get_result` 必须恰好选择 `task_id` 或 `export_id`，不要同时填写。已存在文件链接过期只重新取得原结果链接。云端矢量 SVG 从处理结果直接领取，不传不存在的 `format=svg` 给 PNG/JPG/PSD 导出接口。

文件按实际 URL 与宿主传输能力下载；校验非空、类型/文件头、实际尺寸及回执给出的 SHA256，不把 HTML 登录页或 JSON 错误当图片。SVG 应读取结构并检查，不执行内嵌脚本或外部引用。没有本地保存能力时给真实链接和画布入口，不声称已保存。只公开受控链接，不输出令牌、内部文件路径、模型配置或私有存储地址。

链接采用标准 Markdown，URL 必须是返回的完整值，链接括号不夹带额外字段；不把真实带票据下载链接写进可复用模板或公开测试记录。

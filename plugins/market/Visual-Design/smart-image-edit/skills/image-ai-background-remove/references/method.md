# 抠图去背景：方法与案例

## 先看图再选方法

识别主体数量、背景对比度、边缘难点和交付背景。商品检查包装字、透明材质、镂空、接地阴影；人像检查头发、眼镜、衣领、手指与半透明饰品。用户说“去背景”通常保留可辨认的主体，不等于删掉商品原有白色区域或所有阴影。

有清晰主体、希望尽量保留原像素时优先建议快速抠图 `cutout`。复杂背景或确需按自然语言指定去除内容时比较 `remove`；它可能重绘局部，先说明对商品文字、纹理和透明材质的影响，不因快速抠图不理想自行再扣一次智能处理费用。两者选择以实时能力为准。

原图主体被裁掉时先指出缺失，不假装去背景会补出完整商品。用户没有提出补绘就不联动其他工具。多主体且意图不明确时只问保留哪一个或哪些，不重复收集与抠图无关的品牌和风格。

## 操作与参数

按实时 Schema 可提供 `prompt`、`softness`、`background`、`color`。透明背景使用 `background=transparent`；用户明确要求自定义纯色时才选 `custom` 并确认六位 HEX 颜色。`softness` 在公布范围内小幅使用，不用过度柔化掩盖漏抠。没有需求不堆可选参数。

说明只写保留主体、去除范围和必要边缘要求，不编造坐标蒙版。需要手绘保护、擦除或恢复区域时用当前画布入口定位对应工具，由用户准确标记；不能把 MCP 的文字参数说成已传入笔刷蒙版。

输出有透明要求时检查真实 alpha。背景看起来白不等于无透明，也不等于透明成功；在浅色和深色衬底上检查实际结果。下载优先真实透明 PNG，不用 JPG 承诺透明背景。

## 成品检查

- 主体轮廓完整，顶部、底部和左右无误切；多个主体保留数量正确。
- 头发、网格、镂空和细小配件无明显缺损，边缘无白边、黑边、杂色残留或过度虚化。
- 商品原有文字、商标、颜色与表面细节未被重绘错；对比原图，不猜原来模糊的文字。
- 透明区域真实存在；阴影按用户要求保留或去除，没有自动抹掉必要接地关系。
- 批量逐张列出结果，保留成功项。难点只作为备注，不伪造“完美抠图”。

## 对话示例与异常处理

1. **白底商品转透明**：先说明白色包装与背景要区分，建议快速抠图，报价确认后执行；用深色衬底检查白色边缘和透明孔洞。
2. **卷发人像**：保留发丝与耳饰，检查头发过渡；若细发缺失，先展示问题与可选修复思路，不自动付费重跑。
3. **玻璃杯**：说明透射和反光使轮廓识别更难，保留杯体高光，核对把手内孔；不能保证透明材质与原拍摄完全一致。
4. **同组多张商品图**：预检原图及结果容量，逐张报价，在服务限额内执行并分别检查，不把不同原图合成一张。
5. **用户要求手动恢复被误删部分**：交付原结果所在画布和恢复操作提示；取得用户保存的新版本后再检查，不声称在 MCP 中直接操控了网页笔刷。

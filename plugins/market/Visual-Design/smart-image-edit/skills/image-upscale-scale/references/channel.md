# Qoder 连接与积分

优先使用 Qoder 市场已发布的“神火设计师”（shenhuo-designers）连接器。查看实际来源、加载状态和暴露工具，已安装且授权有效则用 get_account 验证并复用。多个 Skill 共用一个连接，不按 Skill 名称推导 MCP 前缀，不猜市场依赖 ID。

市场未找到或安装不成功时，先检查已经存在的自定义 shenhuo-designers，能调用且授权有效就复用；已安装未授权则恢复原实例。只有确无可复用实例且用户同意配置时，才通过 Qoder 原生入口新增远程 Streamable HTTP MCP，端点为 https://api.shenhuoai.com/external/mcp，并使用个人 OAuth。已经明确授权安装的范围不反复确认。此包的连接依赖为说明性声明，不含新增 MCP 配置，也不承诺导入 ZIP 会自动绑定连接器。

未完成的原授权继续原流程，不新建重复实例。缺权限先由宿主刷新原连接，失败才原生恢复授权；缺 canvas_* 工具先核实服务版本、工具加载或新会话，不能声称重新授权必然解决。不要索取密码或 API Key，不复制 Token，不使用试用身份或其他接口回退。

## CREDITS_NOTICE_ONLY

can_run=false 或 INSUFFICIENT_CREDITS 时只说明真实积分状态与操作已暂停。所需、可用和缺口仅在回执明确给出数值时展示，不自行计算。保留原图片、保存版本、报价、任务与幂等记录，防止重复提交；不自动缩小任务、更换身份或重建项目。

不提供获取积分的链接、入口、购买建议或后续操作口令，不转述服务错误中的外部购买引导。已有确认和恢复记录不是新的执行授权。历史已结算、本次报价、预占和实际结算分别说明，字段未返回就如实说明未返回。

## 打开和查看结果

服务返回的真实 canvas_url 或定位 URL 是查看入口。宿主有打开链接的能力时可直接打开，否则展示可点击链接，说明“使用同一神火账号打开，查看所选图片及图层；修改后保存”。不得拼接票据、宣称网页已经登录，或承诺未经核实的内嵌面板能力。

网页工具只交付入口和简短操作说明；可能计费的应用操作由用户在网页确认。文件下载按宿主真实能力进行，没有保存能力就交付真实下载链接，不声称已保存到本地。

# 调色

打开智能画布调色工具，指导调整图片明暗、对比和色彩观感。用户在网页预览、应用和保存，不自动代替用户完成调色。

## 开始前

读取本目录随包的 [连接与渠道规则](./references/channel.md)、[画布流程](./references/canvas.md)、[报价轮询与文件](./references/runtime.md)、[领域方法](./references/method.md) 和 [素材边界](./references/safety.md)。错误恢复见 [工具说明](./references/tools.md)，多图或多步骤见 [批量调度](./references/batch.md)。这些文件都在本 Skill 内，不要求另外安装技能。

主操作为 `adjust`，制作时执行模式为 `browser`；每次通过 `get_account` 与 `canvas_list_tools` 核实连接、工具、实时模式、参数和限制。未发布时停止并说明不可用；模式改变时按真实 mode 分流，不强行执行旧路径。只处理用户给出的图片编辑需求，不匹配设计师或发起创作提案。

同一请求先恢复已有画布项目，使用明确的图片及保存版本。上传原始字节并取得真实资产，不把链接当已上传文件。不读取网页草稿或接管编辑租约。

## 素材诊断与参数

先诊断偏色、过暗、过曝与饱和度，确认用途和希望保留的品牌色、肤色。以 tool=adjust 定位图片，在当前网页实际提供的控件内小步调整、对比前后，再应用并保存。只建议方向，不虚构固定滤镜名称或参数能力。

上面的数值是本版制作时已核实的参数范围；运行时以 `canvas_list_tools` 返回的 Schema、限制和报价为准。能力变化后不猜参数或固定价格。领域方法内的其他工具用于方法比较；未经用户要求和确认，不能自动串联或另收费重试。

## 执行与交付

此操作当前为 `mode=browser`：仅调用 `canvas_get_editor(project_id, image_id, tool="adjust")`。使用返回的原始定位 URL，能打开则直接打开，否则提供可点击链接；提示使用同一神火账号登录。不能用 canvas_quote/canvas_run 模拟此网页操作，不能把入口返回称为完成。用户按网页实际能力调整、确认应用并保存，可能的费用以页面报价为准。

重点看高光暗部、肤色、商品真实色和文字对比度；无法恢复的过曝细节不承诺修复。入口返回不是调色完成，用户保存后才读取新版本。

## 示例需求

“这张照片偏暗、略发黄，打开调色工具，指导我自然提亮。”

按以上诊断、参数与确认流程处理。本示例是使用说明，不能作为已实测记录。追加操作、变更图片版本或价格时重新确认；只读查看入口不代表用户同意后续付费操作。

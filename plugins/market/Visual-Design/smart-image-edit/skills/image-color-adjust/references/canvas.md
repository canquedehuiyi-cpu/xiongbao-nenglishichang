# 神火智能画布

通过宿主已有的 `shenhuo-designers` 远程 MCP 与个人 OAuth 调用。发现工具时使用宿主实际前缀，不猜名称，不复制 Token，不索取 API Key，不领取试用资格。工具缺失时提示服务版本尚未支持，保留当前进度，不调用旧分层工具冒充新画布接口。

先调用 `get_account`，再用 `canvas_list_tools` 读取实时工具、参数、价格与限制。工具是否可用以当前发布目录为准，不能仅凭本文的功能举例决定调用。授权范围不足优先由宿主刷新原连接，刷新失败再原生授权；不重复安装连接。

## 单张图片

1. 确认用户的具体编辑要求和原始图片。使用现有 `create_upload`、宿主文件上传能力及 `get_upload` 取得真实 `asset_id`；上传原始字节，不把图片 URL、缩略图或 Base64 文本伪装成文件。
2. `canvas_create_project` 创建本次项目；恢复已有操作则 `canvas_get_project`。用 `canvas_import_image` 导入一张图片，保存返回的 `image_id` 与 `revision_id`。不碰网页未保存草稿。
3. 若工具 `mode=browser`，只调用 `canvas_get_editor`，交付图片与工具定位链接，并简要说明下一步控件操作。用户在浏览器登录同一神火账号后自行操作；不声称已经处理，不自动提交任何付费任务。
4. 若 `mode=api`，按实时 Schema 调用 `canvas_quote`。展示本次积分和处理范围；只有用户明确确认要求与报价后，才传 `user_confirmed=true` 调用 `canvas_run`。文字翻译／修改使用同一版本 OCR 返回的行 ID、原文及坐标，不编造区域。
5. 持续调用 `canvas_get_task`，遵守 `poll_after_ms`。轮询、断线、结果未知均保留原任务和幂等键，不新建处理任务。取消只响应用户明确要求，调用 `canvas_cancel_task` 后核对最终状态。
6. 成功后调用 `canvas_get_result`，先展示真实 `canvas_url`，同时交付已有图片结果并提示：“你还可以在智能画布中继续改字、修图、分层。”结果 URL 需要同账号网页登录；OAuth 不等于自动登录网页。

文字处理需区分“取得文字”和“改到图片上”：`ocr` 返回区域，`translate` 只返回译文，不改图片。用户需要翻译后的图片时，按 ID 将 `translations[].value` 合并到原 OCR 行，保留原文与坐标，再为 `text` 报价并按已确认预算执行。没有执行 `text` 时，不能声称图片上的文字已修改。OCR 没有文字区域时停止这条链路，不虚构区域。

## 分离成功与可选导出

图文分层和 AI 图层分离的 `succeeded` 就是分离完成。**先展示画布链接，再提示可选导出 PSD，随后等待用户明确要求下载。** 没有 PSD 不表示分离未完成；不得把导出当成轮询、交付或收尾步骤。

仅当用户明确要求导出指定图片时，读取其已保存版本，以 `canvas_export(format="psd", user_confirmed=true)` 启动独立导出。PNG/JPG 的额外合成导出同样需要用户要求。用户网页编辑后重新确认当前版本，再导出新版本。

查询 `canvas_get_export`，成功后用 `canvas_get_result(export_id=...)` 获取受控文件链接。下载链接过期仅重新获取链接；导出失败只重试导出，保留原图和分离结果，绝不重新分离或再次计收图片处理积分。只转交实际产生的文件，不编造 PSD 或承诺所有效果都能编辑。`no_text` 表示未识别到文字，不交付伪造的分层 PSD。

## 多张图片

完整调度与恢复规则见 [批量与恢复](./batch.md)。服务端不支持批量任务接口；客户端逐张调用，默认全部归入本次同一画布项目。

导入前检查 `remaining_slots`：每张原图占一格，有图片输出的工具还需一格结果；OCR／翻译不新增结果图。容量不足请用户决定是否拆分项目，不静默拆分。每张图片独立分组，不合并原图。

逐张报价并汇总总预算，用户确认后按最多两个在途任务执行，同时遵守服务端更低的限额和退避要求。独立记录成功、失败和结果未知；已成功的不重复执行。批量分离先交付画布结果；用户明确指定“这些图片”或“全部成功图片”的 PSD 后，才逐张导出该范围，分别记录导出状态。未选择的图片不导出。

## 恢复与权限

参照 [工具与错误](./tools.md)。项目、导入、报价、处理、导出分别使用稳定且不同的幂等键。同一操作原参数重放；参数或版本变化取得新报价并由用户重新确认。只持久化任务恢复信息，不保存令牌或下载凭据。

积分不足时说明余额不足并保留进度，不创建重复任务。渠道版的连接和积分说明以随包 `channel.md` 为准（如存在）。已有设计师、旧图层工具与历史 Skill 的行为不受本 Skill 影响；不自动迁移旧项目。

# 调色方法

先看图片整体曝光、明暗层次、色温和饱和度，问清是自然还原还是风格化。商品真实色、肤色、品牌色和白色区域是重点保留项。用户已明确目标时不重复提问。

进入真实画布的调色工具后，先处理明显偏色与明暗，再逐步调整对比和饱和度；每次小幅变更，对比修改前后。只使用当前界面实际提供的控件，不凭经验虚构曲线、色阶或滤镜菜单。提亮后仍无细节的高光不宣称已经恢复。

检查主体与背景关系、皮肤是否偏橙或偏灰、暗部是否压死、白色是否溢出、边缘有无光晕。文字和商品标签保持易读。图片中颜色可能受拍摄光线与屏幕影响，不把目测色彩作为精确实物测量。

本能力在浏览器执行：打开入口只代表已定位工具；由用户预览、应用、保存。用户保存后才读取新版本用于其他操作，不将未保存预览作为输入。例：偏暗照片可先自然提亮，再轻调色温，最后核对肤色与高光。

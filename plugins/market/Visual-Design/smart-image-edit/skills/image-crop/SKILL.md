# 裁剪

打开智能画布裁剪工具，引导用户按比例或取景裁去图片边缘。用于裁剪图片、调整构图；此功能需用户在网页完成。

## 开始前

读取本目录随包的 [连接与渠道规则](./references/channel.md)、[画布流程](./references/canvas.md)、[报价轮询与文件](./references/runtime.md)、[领域方法](./references/method.md) 和 [素材边界](./references/safety.md)。错误恢复见 [工具说明](./references/tools.md)，多图或多步骤见 [批量调度](./references/batch.md)。这些文件都在本 Skill 内，不要求另外安装技能。

主操作为 `crop`，制作时执行模式为 `browser`；每次通过 `get_account` 与 `canvas_list_tools` 核实连接、工具、实时模式、参数和限制。未发布时停止并说明不可用；模式改变时按真实 mode 分流，不强行执行旧路径。只处理用户给出的图片编辑需求，不匹配设计师或发起创作提案。

同一请求先恢复已有画布项目，使用明确的图片及保存版本。上传原始字节并取得真实资产，不把链接当已上传文件。不读取网页草稿或接管编辑租约。

## 素材诊断与参数

确认目标比例、必须保留的主体与文字。调用 canvas_get_editor 时 tool=crop，并带真实项目与 image_id；进入后选中图片，使用裁剪控件调整边界和比例，预览后应用并保存。界面控件以当前网页为准，不用扩图代替裁剪。

上面的数值是本版制作时已核实的参数范围；运行时以 `canvas_list_tools` 返回的 Schema、限制和报价为准。能力变化后不猜参数或固定价格。领域方法内的其他工具用于方法比较；未经用户要求和确认，不能自动串联或另收费重试。

## 执行与交付

此操作当前为 `mode=browser`：仅调用 `canvas_get_editor(project_id, image_id, tool="crop")`。使用返回的原始定位 URL，能打开则直接打开，否则提供可点击链接；提示使用同一神火账号登录。不能用 canvas_quote/canvas_run 模拟此网页操作，不能把入口返回称为完成。用户按网页实际能力调整、确认应用并保存，可能的费用以页面报价为准。

交付时说明已打开裁剪入口，尚未裁剪完成。用户保存后用 canvas_get_project 读取已保存版本，再继续后续处理；不要读取未保存草稿或抢编辑租约。

## 示例需求

“把这张图片裁成正方形，保留完整人物和标题，打开裁剪界面让我调整。”

按以上诊断、参数与确认流程处理。本示例是使用说明，不能作为已实测记录。追加操作、变更图片版本或价格时重新确认；只读查看入口不代表用户同意后续付费操作。

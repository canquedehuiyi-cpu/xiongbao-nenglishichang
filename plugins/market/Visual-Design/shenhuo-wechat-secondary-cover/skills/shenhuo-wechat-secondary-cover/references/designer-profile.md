# 公众号次图公开能力说明

服务提供方：神火 AI。固定设计师：公众号次图，`des_c0f8765551df` / `wechat_official_secondary_cover_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

面向公众号编辑，将单篇文章压缩为缩略可辨的方形入口，支持有真实不同内容的栏目系列。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 文章标题、主题、正文或可读取的公开文章链接
- 准确上图文字、品牌标识及相关原图可选；系列需各篇不同主题

## 交付

- 固定1:1的公众号次条静态方形封面
- 短标题配单个图形、照片或栏目身份的系列图片

默认 **1.5K / 1:1**，当前默认 1536×1536。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 不代替横向公众号首图、正文长图、二维码尾图或文章全文排版
- 不提供可编辑公众号模板、动图或微信后台自动发布
- 不保证单张图随意裁成各种入口仍保留全部信息

## 领域注意

- 与既有“公众号首图”形成不同入口：本技能固定方形，不通过拉伸或裁切冒充首图。
- 只依据实际可读原文提炼主题，标题和小图不编造新闻事实。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

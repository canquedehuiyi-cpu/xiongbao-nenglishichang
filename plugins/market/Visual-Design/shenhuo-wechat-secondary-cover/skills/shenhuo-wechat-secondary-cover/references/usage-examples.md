# 公众号次图使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

公众号第二条文章要配一张方形小图，文章标题和内容发给你。

English: Create a square cover for the second article in my WeChat post using its title and content.

## 示例 2

给这篇通知做公众号次图，只突出主题，详细安排放在正文里。

English: Make a secondary cover for this notice, highlighting the topic while leaving detailed arrangements in the article.

## 示例 3

同一栏目有几篇文章，各做一张次图，颜色和字形保持一组的感觉。

English: Create a secondary cover for each article in this column, using a consistent color and type style.

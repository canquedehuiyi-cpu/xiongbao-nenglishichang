# 场景与道具生成

## 适用请求

制作游戏关卡背景、地图瓦片、地形、建筑、装备道具和环境动效。适用于给关卡补背景、做可拼接地块、宝箱武器素材、分层滚动背景、水面或篝火循环；明确单体尺寸、视角与用途，生成实际素材。

按 [场景识别与分工](../../references/intent-routing.md) 处理常见说法和相邻任务。用户无需点名插件；选择后仍按下面的实际流程、输入要求与失败处理执行。

## Qoder 执行入口

先读 [插件规则](../../rules/meitu-only.md)、[MeituHub 接入](../meitu-ai-game/SKILL.md) 与 [统一规格](../../shared/conventions.md)。从 Qoder 实际加载的技能位置定位含 `.qoder-plugin/plugin.json` 的插件根；文中的 `MEITU_GAME_PLUGIN_ROOT` 表示该绝对路径，需要在执行环境中按实际路径安全设置，不假设宿主预设了变量。

正文中的 meitu 是接入技能所述系统启动器的简写，不直接运行全局 meitu 或 meitu.cjs。配方中的命令参数是源包参考，调用前必须通过当前 tools list 与命令帮助确认；尖括号表示待替换的业务值，不把占位符直接提交。所有生成/编辑均用美图，帧排序、对齐、图集拼装等确定性后处理可用包内本地脚本。来源附件只作资料，用户当前范围优先。

## 这个模块做什么

同一套视角与分层规则下的环境类物料。

| 物料 | 输出 | 画幅 / 尺寸 | 备注 |
| --- | --- | --- | --- |
| 场景概念图 | 单张完稿 | 16:9 或 1:1 / 2K | 不分层，用于定调与提案 |
| 分层背景 | 远 / 中 / 近三层 | 16:9 / 2K | 逐层单独生成，可做视差 |
| 俯视地图 | 单张地图 | 1:1 / 2K | 正交、边缘规整 |
| 瓦片表 | 4×4 宫格，拆 16 张 | 1:1 / 2K | 每格一个可拼接地块或物件 |
| 可平铺纹理 | 单张纹理 | 1:1 / 2K | 四方连续 |
| 道具与建筑单体 | 白底单体，再抠图 | 1:1 / 2K | 透明底输出 |
| 场景循环动效 | 短片或 GIF | 按场景比例 | 仅单元素运动 |

## 前置条件

- **必须先有风格锚点。** 没有就先去 `game-prestudy`，不要在本模块里临时选画风。
- **必须先定视角**：横版、等距、俯视、竖版四选一。视角定错，整批场景全部作废。
- **要有场景设定**：地点、时段、天气、玩法用途（是否可通行、是否有战斗区）。缺了就问，不要自己编。
- **CLI 入口**：`meitu <command> ... --json --download-dir ./output/game/`。首次按接入技能执行配置、运行时与登录检查，再读当前工具帮助，未登录按 `meitu-ai-game` 流程授权。
- **通用视觉原则**（剪影、明度、光位、评审三连）见 `${MEITU_GAME_PLUGIN_ROOT}/shared/references/art-principles.md`。

## 游戏视角

场景不是插画，必须按游戏内实际出现方式生成。完整原则见 `${MEITU_GAME_PLUGIN_ROOT}/shared/references/game-view.md`，本模块落地为四条：

1. **镜头由玩法定。** 横版、等距、俯视、竖版四选一，整批锁死；俯角差几度，两张场景就拼不到一起。
2. **可通行区不被前景盖住。** 玩家要能看见自己站的位置，前景层只做边缘遮挡。
3. **先扣 HUD 安全区。** 横版通常上 10–15%、下 10–15% 不放关键信息；竖版上 1/4、下 1/5 视为 UI 区。
4. **按实机像素评审。** 出图 2K，但必须缩到游戏内显示尺寸再看一遍，糊掉的细节属于无效细节。

## 生产流程

1. **定视角与画幅**，写进这一批的固定参数。
2. **出场景概念图**，先确认构图与光位。
3. **按需分层**：要做视差就拆远中近三层逐层生成，不分层就直接交付概念图。
4. **出单体**：道具、建筑一次一张，白底，最后统一抠图。
5. **出地图与瓦片**：地图定大关系，瓦片表定可拼接单元。
6. **逐张验收**：视角、地平线、光位、色板四项必须一致。

## 视角配方

| 视角 | 默认画幅 | 构图关键词 | 分层建议 | 典型品类 |
| --- | --- | --- | --- | --- |
| 横版卷轴 | 16:9 | 侧视角、平视或轻微俯视、横向延展、左右可循环 | 远景天空与山脉 / 中景建筑与地形 / 前景遮挡物与雾 | 平台跳跃、动作、跑酷 |
| 等距 2.5D | 1:1 或 4:3 | 45 度等距俯视、isometric、正交投影、无透视畸变 | 单张地表底图 / 独立建筑与道具层 | SLG、模拟经营 |
| 竖版手游 | 9:16 | 竖构图、主体居中、上 1/4 与下 1/5 保留 UI 空白 | 背景层 / 中景装饰 / 前景遮挡 | 休闲、卡牌、竖版 RPG |
| 俯视地图 | 1:1 | 正俯视 top-down、正交、边缘规整 | 地表底图 / 建筑植被道路独立层 | 战棋、沙盒 |

## 场景概念图

```bash
meitu text-to-image --prompt "<视角>，<风格卡措辞>，<场景主体>，<时段与天气>，<光源方向>，<镜头高度>，<构图描述与留白要求>，高细节，无文字" --ratio <画幅> --size 2K --json --download-dir ./output/game/<场景名>
```

- 镜头高度要写死：平视、俯 15 度、俯 45 度。同一批场景不允许漂移。
- 光源方向写清（左上 / 右上 / 顶光 / 逆光），跨图一致。

## 分层背景

逐层生成，每层单独描述并**显式排除其他层**，否则同一建筑会同时出现在中景和远景。

- 远景：`仅远景层，天空与远山，<时段>，无建筑无前景物体，画面下方大片留空`
- 中景：`仅中景层，<主要建筑或地貌>，<风格卡措辞>，背景为纯色，无天空无前景遮挡`
- 前景：`仅前景遮挡物，<岩石或植被剪影>，背景纯色便于抠图，边缘清晰`

需要把某层主体单独提取时：

```bash
meitu image-cutout --image_url "<分层图绝对路径>" --model_type 2 --json --download-dir ./output/game/<场景名>/cutout
```

## 俯视地图与瓦片表

**先定网格。** 单格边长按项目逻辑像素（常见 16 / 32 / 48 / 64），整批素材按同一网格出；瓦片与建筑必须能落在格子上，错位属于返工。

```bash
meitu text-to-image --prompt "正俯视 top-down 游戏地图，<地貌与建筑>，正交投影，边缘规整，<时段与天气>，<风格卡措辞>，无文字，无 UI" --ratio 1:1 --size 2K --json --download-dir ./output/game/<场景名>/map
```

```bash
meitu text-to-image --prompt "4x4 均分瓦片表，每格一个可拼接地块或物件：<16 项清单>，同一视角、同一色板、同一光源方向，地块边缘对齐，orthographic，每格纯色深底，格间留细白分隔线，<风格卡措辞>，无文字" --ratio 1:1 --size 2K --json --download-dir ./output/game/<场景名>/tiles
meitu image-grid-split --image_url "<瓦片表绝对路径>" --json --download-dir ./output/game/<场景名>/tiles/frames
```

可平铺纹理：

```bash
meitu text-to-image --prompt "可平铺纹理，<材质>，四方连续，无明显接缝，正交俯视，<风格卡措辞>，无文字" --ratio 1:1 --size 2K --json --download-dir ./output/game/<场景名>/texture
```

## 道具与建筑单体

```bash
meitu text-to-image --prompt "游戏道具单体，<物件描述>，<风格卡措辞>，纯白背景，正面 3/4 视角，居中，无投影，无文字" --size 2K --json --download-dir ./output/game/<单元>/props
meitu image-cutout --image_url "<单体图绝对路径>" --model_type 1 --json --download-dir ./output/game/<单元>/props/cutout
```

- 道具与武器走 `model_type 1`；图标与符号走 `model_type 2`。
- **按游戏内显示尺寸出图**：先定它在界面或场景里的实际像素尺寸（常见 64 / 256 / 512 三档），再决定出图尺寸。图标化道具与场景大件是两种素材，不能一张图两用。
- **交付时说明锚点**：拾取点、握持点、落地接触点，方便引擎对齐。
- 建筑一次只试一张，效果不达标就交白底图，不要反复重提。
- 同批道具必须用同一段风格措辞与同一光位，否则混排时风格会跳。
- 成套道具（4 件或 9 件）可用同一锚点一次出宫格，做法见 `${MEITU_GAME_PLUGIN_ROOT}/shared/references/asset-recipes.md`。

## 场景循环动效

```bash
meitu image-to-video --image_list "<场景图绝对路径>" --prompt "固定机位，仅<篝火 / 水流 / 旗帜>循环运动，其他画面完全静止，无运镜，无角色进入，首尾画面衔接" --video_duration 4 --multi_shot false --json --download-dir ./output/game/<场景名>/ambient
meitu video-to-gif --video_url "<视频绝对路径>" --prompt "<元素>循环，固定机位" --json --download-dir ./output/game/<场景名>/ambient
```

`--multi_shot` 只在当前 `--help` 提供时传。生成结果仍可能自动加镜头，交付前逐条检查。

## 尺寸延展与画质重制

```bash
meitu image-transform --image_url "<原图绝对路径>" --target_width <宽> --target_height <高> --prompt "向两侧自然延展场景，保持地平线高度与光源方向不变，不新增主体" --json --download-dir ./output/game/<单元>/adapt
meitu image-superres-enhance --image_url "<原图绝对路径>" --prompt "<画面内容描述>，提升清晰度并保留原风格" --json --download-dir ./output/game/<单元>/upscale
```

`image-transform` 改画幅不改内容，`image-superres-enhance` 改清晰度不改画幅，两者不可互相替代。`image-transform` 输出不透明图，抠好的透明底素材不要走它。

## 本模块边界

- **无缝平铺不保证**：瓦片表只保证构图规整与视角一致，拼接后仍需美术修补接缝与明度。
- 不做引擎侧内容：关卡碰撞、导航网格、地形高度图、场景工程文件都不输出。
- 不做 3D 场景、建模、UV、PBR 材质。「等距 2.5D」指 2D 画面观感。
- 建筑与地形类主体抠图不稳定，抠不干净就交白底图。
- 真 inpainting 不做：改局部也会重绘整图。

## 和其他模块怎么接

| 接下来要做什么 | 去哪 |
| --- | --- |
| 还没有风格锚点或视角没定 | `game-prestudy` |
| 场景里要放角色 | `game-character`（角色锚点来自 `game-prestudy`） |
| 场景内的 UI 面板与图标 | `game-ui` |
| 场景当宣传图或卡面背景 | `game-promo` |
| 场景元素要有动作 | 环境自身循环留在本模块；角色动作与角色技能特效去 `game-character` |

## 验收清单

- [ ] 视角、镜头高度、画幅与本批其他场景一致
- [ ] 可通行区域未被前景层遮挡，HUD 安全区内没有关键信息
- [ ] 已缩到游戏内实际显示尺寸复核，糊掉的细节未计入完成度
- [ ] 地图与瓦片落在同一网格上，单格尺寸一致
- [ ] 地平线高度、光源方向、色温跨图一致
- [ ] 分层图之间元素不重复，远景与中景没有同一栋建筑
- [ ] 瓦片每格尺寸一致，拼接处无明显错位与色差
- [ ] 透明底边缘无白边、缺角或残留背景
- [ ] 场景循环动效只有目标元素在动，机位固定
- [ ] 产物落在 `./output/game/<场景名>/`，命名符合约定
- [ ] 与项目锚点一致，未擅自换风格或换角色
- [ ] 已说明哪些环节需人工二次处理（接缝、抠图复核、降采样）

# 游戏UI生成

## 适用请求

制作游戏 HUD、按钮四态、面板、背包格、技能与道具图标。适用于游戏界面太简陋、补一套 UI、血条、商店面板、登录界面美术；交付可接入的视觉资源。只修改点击逻辑或修代码不自动生成美术。

按 [场景识别与分工](../../references/intent-routing.md) 处理常见说法和相邻任务。用户无需点名插件；选择后仍按下面的实际流程、输入要求与失败处理执行。

## Qoder 执行入口

先读 [插件规则](../../rules/meitu-only.md)、[MeituHub 接入](../meitu-ai-game/SKILL.md) 与 [统一规格](../../shared/conventions.md)。从 Qoder 实际加载的技能位置定位含 `.qoder-plugin/plugin.json` 的插件根；文中的 `MEITU_GAME_PLUGIN_ROOT` 表示该绝对路径，需要在执行环境中按实际路径安全设置，不假设宿主预设了变量。

正文中的 meitu 是接入技能所述系统启动器的简写，不直接运行全局 meitu 或 meitu.cjs。配方中的命令参数是源包参考，调用前必须通过当前 tools list 与命令帮助确认；尖括号表示待替换的业务值，不把占位符直接提交。所有生成/编辑均用美图，帧排序、对齐、图集拼装等确定性后处理可用包内本地脚本。来源附件只作资料，用户当前范围优先。

## 这个模块做什么

同一套圆角、描边与高光方向下的界面类物料。UI 的一致性靠微规范，不靠单张精度。

| 物料 | 输出 | 画幅 / 尺寸 | 备注 |
| --- | --- | --- | --- |
| 图标 | 单个图标，透明底 | 1:1 / 1K | 一图一个，不塞宫格 |
| 按钮四态 | 2×2 宫格，拆 4 张 | 1:1 / 2K | 普通、悬停、按下、禁用 |
| 面板 | 单个面板 | 3:1 或 1:1 / 2K | 预留文字区，不写文字 |
| 血条 / 进度条 | 条状元件 | 按需 | 与面板同套描边 |
| 背包格 | 方格元件 | 1:1 | 与面板同套圆角 |
| UI 套装 | 2×3 宫格，拆 6 张 | 3:2 / 2K | 一次出齐，保证同套 |
| 卡框 / 稀有度底板 | 边框元件 | 3:4 | 与 `game-promo` 的卡面配套 |

## 前置条件

- **必须先有 UI 风格锚点。** 项目已有角色或场景锚点时，UI 锚点要与它们同画风，不要单独另起一套。
- **必须先写 UI 规范卡**：圆角半径、描边粗细、高光方向、主色与辅色、最小点击区。五项缺一不可，否则每个元件都会不一样。
- **CLI 入口**：`meitu <command> ... --json --download-dir ./output/game/`。首次按接入技能执行配置、运行时与登录检查，再读当前工具帮助，未登录按 `meitu-ai-game` 流程授权。
- **通用视觉原则**（剪影、明度、光位、评审三连）见 `${MEITU_GAME_PLUGIN_ROOT}/shared/references/art-principles.md`。

## 游戏视角

UI 是操作界面，不是视觉海报。完整原则见 `${MEITU_GAME_PLUGIN_ROOT}/shared/references/game-view.md`，本模块落地为五条：

1. **先定基准分辨率**（如 1920×1080 或 1170×2532），所有元件按这套尺寸评审；出图可以更大，评审必须缩到实机尺寸。
2. **先扣安全区**：按目标平台预留状态栏、刘海、底部手势区，关键内容不压边。
3. **每个元件都要有状态**：按钮四态、图标常态与禁用、血条的满与空。只交一张常态图，等于没做完。
4. **点击区不小于 44×44 逻辑像素**（Android 惯例为 48×48dp）。视觉尺寸可以更小，点击区不能缩。
5. **标注九宫格可拉伸区**：交付说明里写清哪块平铺、哪些边角不拉伸；只交成品位图，不输出配置文件。

## 生产流程

1. **写 UI 规范卡**，用一句话形式固定，之后每段提示词逐字复制。
2. **出一张 UI 锚点**（一个最具代表性的面板或按钮），确认圆角与描边。
3. **出图标组**：一图一个，共用同一锚点与同一段措辞。
4. **出元件组**：按钮四态用 2×2，成套元件用 2×3。
5. **抠透明底**：需要透明 PNG 时逐张 `image-cutout`，放最后一步。
6. **逐张验收**：圆角、描边、高光方向、文字安全区。

## UI 规范卡

写进每段提示词，不改写：

```text
统一圆角半径 <R>px，统一描边 <W>px，高光来自左上 45 度，
主色 <HEX>，辅色 <HEX>，禁用态降饱和不加新色，
所有面板预留文字安全区，不写入任何文字内容
```

圆角与描边是判假的第一来源。同一套里出现两种圆角，整套就废。

## 图标

```bash
meitu text-to-image --prompt "游戏 UI 图标，<图标含义>，<风格卡措辞>，<UI 规范卡>，扁平或微立体，正视角，居中，纯白背景，无文字，无投影" --size 1K --json --download-dir ./output/game/ui/icons
meitu image-cutout --image_url "<图标图绝对路径>" --model_type 2 --json --download-dir ./output/game/ui/icons/cutout
```

- 同组图标必须用同一锚点、同一段措辞批量出，否则线宽与圆角会漂移。
- 一图一个，不为了省事塞进宫格。宫格里的图标会被统一缩放，细节层级会乱。
- 图标含义靠形状表达，不靠文字。禁止在图标里画字。

## 按钮四态

```bash
meitu image-edit --image_list "<按钮或 UI 锚点图绝对路径>" --prompt "2x2 均分宫格，同一按钮的普通、悬停、按下、禁用四种状态，尺寸、圆角、描边、文字区位置完全一致，只改变明度、内阴影与描边发光，<UI 规范卡>，无文字，<风格卡措辞>" --ratio 1:1 --size 2K --json --download-dir ./output/game/ui/button-states
meitu image-grid-split --image_url "<宫格图绝对路径>" --json --download-dir ./output/game/ui/button-states/frames
```

四态只改明度、内阴影与描边发光，不改尺寸、不改圆角、不改文字区位置。改尺寸会导致按钮点击时跳动。

## 面板与条状元件

```bash
meitu text-to-image --prompt "游戏 UI <面板或血条>，<用途>，<UI 规范卡>，<风格卡措辞>，正面平视，居中，边缘清晰，预留文字区，无文字内容，无投影" --ratio 3:1 --size 2K --json --download-dir ./output/game/ui/panel
```

- 面板边缘要闭合，不能有开口或缺角。
- 血条类元件必须留出填充区间，不要把进度条画成满条。
- 交付时附文字安全区说明：哪块区域放标题、哪块放数值、最小留白多少。

## UI 套装

整套一次出，比逐件出更一致：

```bash
meitu image-edit --image_list "<UI 风格锚点图绝对路径>" --prompt "2x3 均分宫格，同一套游戏 UI：<元件清单>，<UI 规范卡>，正面平视，每格纯色背景，格间留细白分隔线，预留文字区但不写入文字，<风格卡措辞逐字一致>" --ratio 3:2 --size 2K --json --download-dir ./output/game/ui/kit
meitu image-grid-split --image_url "<宫格图绝对路径>" --json --download-dir ./output/game/ui/kit/frames
```

元件清单控制在 4–12 件。超过 12 件分两批，第二批把第一批当风格参考图一起传入。

## 本模块边界

- 只交成品位图与文字安全区说明，**不输出九宫格拉伸配置、可切图源文件、分层 PSD**。
- 不做交互逻辑、动效参数、组件代码。
- 不做烘焙文字：所有文字由客户端渲染，图里不写字，否则多语言无法替换。
- 不做真 inpainting：改局部也会重绘整图。
- 不保证像素级对齐与精确尺寸，交付前需美术按实际分辨率复核。

## 和其他模块怎么接

| 接下来要做什么 | 去哪 |
| --- | --- |
| 还没有风格锚点 | `game-prestudy` |
| 需要角色头像做图标 | `game-character`（出角色头像后再进本模块） |
| 面板需要场景背景 | `game-scene` |
| 卡框与稀有度底板要配卡面 | `game-promo` |
| UI 要复用角色技能特效 | `game-character` 先产出特效，本模块只处理界面元件 |

## 验收清单

- [ ] 整套圆角半径统一，没有出现第二种圆角
- [ ] 已按实机分辨率与安全区检查，关键内容未被裁切或压边
- [ ] 可交互元件都有完整状态，点击区不小于 44×44 逻辑像素
- [ ] 九宫格可拉伸区与不可拉伸边角已在交付说明中标注
- [ ] 描边粗细统一，高光方向一致
- [ ] 按钮四态尺寸、圆角、文字区位置完全一致
- [ ] 面板文字安全区充足，图内无烘焙文字
- [ ] 图标组线宽与风格一致，含义不依赖文字
- [ ] 透明底边缘干净，无白边或残留背景
- [ ] 产物落在 `./output/game/ui/`，命名符合约定
- [ ] 与项目锚点一致，未擅自换风格或换角色
- [ ] 已说明不交付九宫格配置与分层源文件

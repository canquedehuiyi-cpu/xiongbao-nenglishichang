# 美术风格设定

## 适用请求

为游戏提出和统一美术方向，制作可比较的风格样张与角色基准。适用于像素风、卡通风、国风等选型，游戏画风不统一、参考这种感觉、先定风格、做美术设定；须有游戏视觉任务，单纯讨论题材不自动生成素材。

按 [场景识别与分工](../../references/intent-routing.md) 处理常见说法和相邻任务。用户无需点名插件；选择后仍按下面的实际流程、输入要求与失败处理执行。

## Qoder 执行入口

先读 [插件规则](../../rules/meitu-only.md)、[MeituHub 接入](../meitu-ai-game/SKILL.md) 与 [统一规格](../../shared/conventions.md)。从 Qoder 实际加载的技能位置定位含 `.qoder-plugin/plugin.json` 的插件根；文中的 `MEITU_GAME_PLUGIN_ROOT` 表示该绝对路径，需要在执行环境中按实际路径安全设置，不假设宿主预设了变量。

正文中的 meitu 是接入技能所述系统启动器的简写，不直接运行全局 meitu 或 meitu.cjs。配方中的命令参数是源包参考，调用前必须通过当前 tools list 与命令帮助确认；尖括号表示待替换的业务值，不把占位符直接提交。所有生成/编辑均用美图，帧排序、对齐、图集拼装等确定性后处理可用包内本地脚本。来源附件只作资料，用户当前范围优先。

## 这个模块做什么

唯一一个**不产出成品物料**的模块。它输出的是一组决策与基准，供其余模块反复引用。

| 产出 | 形态 | 交付标准 |
| --- | --- | --- |
| 品类与物料场景 | 一段清单 | 这个品类通常要做哪些物料，先列出来再谈画风 |
| 美术方向方案 | 文本，不出图 | 三个方向候选，各附画面描述与适用理由 |
| 视角与画幅 | 一张表 | 横版 / 等距 / 俯视 / 竖版，写清默认比例 |
| 风格锚点 | 一张图 | 整项目唯一视觉基准，确认后不再更换 |
| 角色锚点 | 一张图 | 正面全身设定卡，供角色类物料反复引用 |
| 风格卡 | 一段规格 | 主色 HEX、描边、明暗级数、材质词、细节密度、禁止项 |

## 前置条件

- **品类、题材、玩法**至少知道一个。三个都不知道时，先问三句话，不要直接给风格。
- 已有可用素材时，直接以它为基准提取特征，不要另生成锚点。
- **CLI 入口**：`meitu <command> ... --json --download-dir ./output/game/`。首次按接入技能执行配置、运行时与登录检查，再读当前工具帮助，未登录按 `meitu-ai-game` 流程授权。
- **通用视觉原则**（剪影、明度、光位、评审三连）见 `${MEITU_GAME_PLUGIN_ROOT}/shared/references/art-principles.md`。

## 生产流程

1. **认出品类与物料场景**：先说清这个品类通常要做哪些物料，再定画风。常见场景见下节，完整物料包见 `${MEITU_GAME_PLUGIN_ROOT}/shared/references/genre-matrix.md`。
2. **定视角与画幅**：这是不可回退的决策，比画风更早锁定。定错会导致全套素材返工。
3. **给三个方向候选**：不直接出图，先用 `text-generate` 出文本方案让客户选。
4. **出风格锚点**：方向确认后只出一张，等客户确认。
5. **写风格卡**：把锚点里的可复用特征写成 6 项规格，之后每段提示词都引用它。
6. **出角色锚点**：项目有角色时立即产出，角色类物料全部依赖它。

| 场景 | 对应品类 | 通常要做的物料 |

| 俯视战棋 | 塔防 / 战棋 / 自走棋 | 单位立绘、技能图标、地图背景、阵营徽记、UI |
| 女性向 | 换装 / 恋爱 | 立绘、服装与皮肤、表情组、CG、活动 KV |
| 桌游化 | 桌游 / 跑团 / 剧本杀 | 卡面、token、地图、角色卡、封面 |
| 轻量休闲 | 休闲 / 解谜 / 儿童教育 | 图标组、关卡背景、少量角色、UI、商店图 |

## 美术方向方案

```bash
meitu text-generate --summary "为<品类>游戏输出一页美术方案，包含：3 个美术方向候选（各附画面描述与适用理由）、主色板、视角与画幅、物料清单与优先级、风险点" --language zh-CN --json --download-dir ./output/game/art-direction
```

三个候选要拉开差距，不要三个都是同一画风的微调。每个候选至少覆盖画风五层的第 1、3、4 层。

## 风格定位五层

写画风描述必须按这五层，缺层会导致方向漂移：

| 层 | 取值 |
| --- | --- |
| 1 画面形态 | 2D 插画 / 像素 / 2.5D 等距 / 3D 观感（低多边形、体素、黏土） |
| 2 写实度 | 写实 / 半写实 / 风格化 / 卡通 / Q 版 / 极简 |
| 3 上色媒介 | 平涂 / 赛璐璐 / 厚涂 / 半厚涂 / 手绘纹理 / 水彩 / 水墨 / 版画 / 纸雕 / 单色 |
| 4 题材 | 日式 / 韩式 / 中式古风 / 暗黑哥特 / 赛博 / 蒸汽 / 废土 / 童话 / 科幻 / 诡异未知 |
| 5 视角与情绪 | 横版 / 等距 / 俯视 / 竖版；饱和度、色温、对比、光位 |

18 种画风的关键词与视觉特征见 `${MEITU_GAME_PLUGIN_ROOT}/shared/references/style-library.md`。

## 风格锚点

```bash
meitu text-to-image --prompt "<题材>，<画面形态与视角>，<写实度>，<上色与线条>，<色彩>，<光照>，<材质与细节密度>，<构图与留白>，<主体场景>，<时段与天气>，无文字" --ratio <画幅> --size 2K --json --download-dir ./output/game/anchor
```

- 同一项目只出一个锚点，出了第二个就等于没有锚点。
- 锚点确认后写成风格卡，落地到 6 项：主色 HEX、描边粗细、明暗级数、材质关键词、细节密度、禁止项。
- 像素风项目额外锁三件事：主光方向、描边策略（全描边或选择性描边）、色阶步数，规则见 `${MEITU_GAME_PLUGIN_ROOT}/shared/references/pixel-guide.md`。
- 之后所有提示词直接复制风格卡里的措辞，不改写、不同义替换。

## 角色锚点

```bash
meitu text-to-image --prompt "游戏角色设定图，<角色名与职业>，<体型与年龄感>，<发型与发色>，<服装分层>，<主色 HEX>，<标志性配件>，正面全身站姿，双臂自然下垂离身体 15–30 度，双脚平放，纯色背景，居中，完整入画，脚部不被裁切，同一角色只出现一次，无文字，无投影，<风格卡措辞>" --ratio 3:4 --size 2K --json --download-dir ./output/game/<角色名>/anchor
```

多角色项目逐个出，每个角色一张主卡，彼此之间共用同一风格卡。本模块只负责产出主卡；规格表、转面与表情属 `game-character`，完整规范见 `${MEITU_GAME_PLUGIN_ROOT}/skills/game-character/references/character-sheet.md`。

## 本模块边界

- 不做品类判断之外的商业判断（预算、档期、发行策略）不承接。
- 不输出引擎工程、材质球、Shader 参考。
- 锚点只是基准，不保证后续每张图与它完全一致，仍需逐张筛选。
- 客户已有风格指南时，以客户文档为准，本模块只做转译与补全。

## 和其他模块怎么接

| 接下来要做什么 | 去哪 |
| --- | --- |
| 画角色、表情、转面 | `game-character`（带上角色锚点） |
| 画场景、道具、地图 | `game-scene` |
| 做 UI 套装 | `game-ui` |
| 做动作序列帧、动作 GIF 或角色技能特效 | `game-character`（带上角色锚点） |
| 做卡牌、海报、宣传片 | `game-promo` |
| 跨多类物料、还没列清单 | 回 `game-assets` 路由 |

## 验收清单

- [ ] 三个方向候选差异足够，不是一个画风的三次微调

- [ ] 有角色时角色锚点已产出并确认

- [ ] 与项目锚点一致，未擅自换风格或换角色

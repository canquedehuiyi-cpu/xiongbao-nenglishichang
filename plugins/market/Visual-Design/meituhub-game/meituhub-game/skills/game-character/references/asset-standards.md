# 角色物料规格

设定卡之外的单项角色物料，各自有固定规格。所有命令都以主卡为唯一参考，保持项逐条写进提示词。

## 立绘

用途决定构图，先问清楚是给对话框、卡面还是展示页。

| 用途 | 构图 | 画幅 | 背景 |
| --- | --- | --- | --- |
| 剧情对话框 | 半身，胸线以下裁切 | 3:4 | 纯色，可抠图 |
| 角色展示 / 图鉴 | 全身，完整入画 | 3:4 | 纯色，可抠图 |
| 卡面底图 | 半身或全身，主体偏上 | 3:4 | 纯色，下方留文字区 |

```bash
meitu image-edit --image_list "<主卡绝对路径>" --prompt "同一角色的<半身/全身>立绘，<姿态与情绪>，保持发型、服装、配色、体型与画风不变，纯色背景，居中，<半身：胸线以下自然裁切 / 全身：完整入画且脚部不被裁切>，无文字" --ratio 3:4 --json --download-dir ./output/game/<角色名>/portrait
```

- **眼位**放在画面上部 1/3 附近，不要顶到边。
- 半身立绘不要出现手部残缺：要么完整入画，要么明确裁在手腕以上。
- 全身立绘检查脚部不被裁切，这是最常见的返工项。

验收：五官发型服装与主卡一致；构图符合用途；背景可干净抠出。

## 表情组

六个表情固定为：平静、微笑、愤怒、惊讶、悲伤、得意。项目需要更多情绪时另起一组，不要在本组里加格。

```bash
meitu image-edit --image_list "<主卡绝对路径>" --prompt "2x3 均分宫格，同一角色的六个表情：平静、微笑、愤怒、惊讶、悲伤、得意，同一视角、同一比例、同一发型服装配色，只改变眉眼与嘴形，脸型、发际线、眼位保持不变，每格纯色背景，格间留细白分隔线，保持画风不变，无文字" --ratio 1:1 --size 2K --json --download-dir ./output/game/<角色名>/expression
meitu image-grid-split --image_url "<表情宫格绝对路径>" --json --download-dir ./output/game/<角色名>/expression/frames
```

- **只允许改眉眼嘴**。脸型变宽、发际线位移、眼位上下漂，都算一致性丢失，整组重跑。
- 情绪要可读但不夸张：愤怒是眉压眼、嘴角下压，不是整脸扭曲。
- 命名固定：`expr_neutral` / `expr_smile` / `expr_angry` / `expr_surprised` / `expr_sad` / `expr_smug`。

验收：六格眼位、脸型、发际线一致；表情差异集中在上半脸；拆分后单张仍可辨认。

## 转面

方向数量由玩法决定，不是越多越好。

| 玩法 | 需要 | 规格 |
| --- | --- | --- |
| 横版动作、平台跳跃 | 左 / 右（可镜像） | 单张侧面，或 2 方向 |
| 俯视、战棋、Roguelike | 4 方向 | 2×2 宫格，`--ratio 1:1` |
| 等距、斜 45 度、部分 ARPG | 8 方向 | 3×3 宫格，中心格留空 |
| 展示、设定稿 | 三视图 | 1×3 宫格，`--ratio 3:1` |

命名统一为 `S / SE / E / NE / N / NW / W / SW`，或 `正 / 侧 / 背`；同一项目只用一套，交付时说明。

必须锁死的四项：比例、脚底线、光位、发型与服装结构。正交投影，不要透视。

```bash
meitu image-edit --image_list "<主卡绝对路径>" --prompt "2x2 均分宫格，同一角色的正面、右侧面、背面、左侧面，正交投影无透视畸变，同一比例、同一脚底线、同一光位、同一发型服装配色与体型，每格纯色背景，格间留细白分隔线，保持画风不变，无文字" --ratio 1:1 --size 2K --json --download-dir ./output/game/<角色名>/turnaround4
```

验收：左右方向没有镜像错误；背面服装结构与正面一致；脚底线水平。

## A-pose 与 T-pose

默认用 A-pose，T-pose 只在特定需求下用。

| 姿态 | 手臂角度 | 什么时候用 |
| --- | --- | --- |
| A-pose | 自然下垂，离身体 15–30 度 | 设定卡、立绘、转面的基础姿态 |
| T-pose | 双臂水平平举 90 度 | 需要绑骨、折叠 UV 时；本插件不做绑骨，一般不需要 |

- A-pose 的价值在于**腋下留出负空间**，手臂轮廓完整可见，后续换装与动作编辑不容易把手臂糊进躯干。
- 双脚与肩同宽或略窄，平放，不要一前一后。
- 手部：五指可辨，或简化为三指；不要握拳遮住手指，也不要把手藏在身后。
- 同一角色的所有单图沿用同一姿态基准，不要有的 A-pose 有的站直。

验收：手臂与躯干之间有可见缝隙；手部完整；双脚平放；无遮挡。

## 换装

需要两张输入：第一张角色底图，第二张用户自有或已授权的**平铺服装设计图**（无人物、纯色背景）。

```bash
meitu image-edit --image_list "<主卡输入文件>" "<已授权服装设计图>" --prompt "第一张是角色，第二张是已授权服装设计图。提取第二张的服装款式、配色、材质与纹样特征并适配到角色，保持第一张的脸型、发型、冠饰、体型、姿势、构图、画幅与画风不变，纯色背景，无文字" --ratio 3:4 --json --download-dir ./output/game/<角色名>/outfit
```

保持项：脸型、五官、发型、冠饰、体型、姿势、构图、画幅、画风。
可改项：服装款式、配色、材质、纹样。

- 不要用 `image-outfit-swap`：该命令定位真人试衣，用于 2D 角色会重绘五官与发型。
- 服装参考图不能是「角色穿新衣」的图，参考图里的身体会污染底图角色。
- **换装后新图成为新参考**，必须重出表情与转面，否则同角色不同物料的服装对不上。

验收：脸与发型未变；服装特征符合已授权设计要求；表情与转面已同步更新。

## 换肤（配色变体）

只改配色与材质，不改版型。

```bash
meitu image-edit --image_list "<主卡绝对路径>" --prompt "只把配色替换为：<旧色 HEX> → <新色 HEX>，<旧色 2> → <新色 2>；材质<旧材质> → <新材质>。保持轮廓、版型、阴影层级、高光位置、姿势、构图与画风完全不变，背景不变，无文字" --json --download-dir ./output/game/<角色名>/skin
```

- **用色板替换表，不要用形容词。** 写「换成暗红」会得到随机结果，写 `#C0392B → #7B241C` 才可控。
- 保持项：轮廓、版型、结构与分件位置、阴影层级、高光位置。
- 一套皮肤不超过 3 个配色变体；变体太多时逐张生成会累积漂移，应回到主卡重新派生。
- 换肤不改变结构；要改款式走换装，要改体型重出主卡。

验收：轮廓与分件未变；明暗层级与光位未变；色板替换表已交付。

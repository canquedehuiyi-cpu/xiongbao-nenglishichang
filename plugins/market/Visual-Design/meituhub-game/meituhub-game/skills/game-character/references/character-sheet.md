# 角色设定卡规范

## 定位

设定卡不是一个文件，是一套文件。它的唯一职责是让后续每一张图都能回溯到同一份视觉基准：立绘、表情、转面、动作帧、卡面、宣传图，全部以它为准。

判断标准只有一条：**换一个人拿到这套文件，能不能把这个角色画对。**

## 四件构成

| 件 | 文件 | 必做 | 内容 |
| --- | --- | --- | --- |
| A 主卡 | `sheet_anchor_v1.png` | 是 | 正面全身、A-pose、纯色背景、无文字 |
| B 转面 | `sheet_turnaround_v1.png` | 按需 | 正 / 侧 / 背，拆成单张 |
| C 表情 | `sheet_expression_v1.png` | 按需 | 六表情宫格，拆成单张 |
| D 规格 | `sheet_spec_v1.md` | 是 | 文字规格、色板 HEX、禁用项 |

按需的含义：
- **B 必做**：角色要转面、要 8 方向、要做动作序列帧、要进等距或俯视项目。
- **C 必做**：剧情、卡牌、女性向、任何需要情绪表达的项目。
- 其余情况只做 A + D，但要在交付说明里写明「未出转面与表情」。

## A 主卡

```bash
meitu text-to-image --prompt "游戏角色设定图，<角色名与职业>，<体型与年龄感>，<发型与发色>，<服装分层>，<主色 HEX>，<标志性配件>，正面全身站姿，双臂自然下垂离身体 15–30 度，双脚平放，纯色背景，居中，完整入画，脚部不被裁切，同一角色只出现一次，无文字，无投影，<风格卡措辞>" --ratio 3:4 --size 2K --json --download-dir ./output/game/<角色名>/anchor
```

要求：

- **A-pose 而不是 T-pose。** 手臂稍微离开身体即可，既能看到腋下负空间与手臂轮廓，又不会因平举导致比例失真。T-pose 只在需要绑骨时才用，本插件不做绑骨。
- **纯色背景**，浅灰或中性色最佳，便于后续抠图与比对。
- **完整入画**，头顶与脚底都留出余量，不能被裁切。
- **无文字**，所有标注写在 D 规格表里，不烘焙进图。

## B 转面（按需）

三视图用 1×3 宫格：

```bash
meitu image-edit --image_list "<主卡绝对路径>" --prompt "1x3 均分宫格，同一角色的正面、正侧面、背面三视图，同一比例、同一脚底线、同一光位、同一发型服装配色体型，正交投影无透视畸变，每格纯色背景，格间留细白分隔线，保持画风不变，无文字" --ratio 3:1 --size 2K --json --download-dir ./output/game/<角色名>/turnaround
meitu image-grid-split --image_url "<三视图绝对路径>" --json --download-dir ./output/game/<角色名>/turnaround/frames
```

四方向用 2×2、八方向用 3×3（中心格留空），方向命名统一为 `S / SE / E / NE / N / NW / W / SW`。

验收重点：脚底线水平、背面服装结构与正面一致、左右方向没有镜像错误。

## C 表情（按需）

```bash
meitu image-edit --image_list "<主卡绝对路径>" --prompt "2x3 均分宫格，同一角色的六个表情：平静、微笑、愤怒、惊讶、悲伤、得意，同一视角、同一比例、同一发型服装配色，只改变眉眼与嘴形，每格纯色背景，格间留细白分隔线，保持画风不变，无文字" --ratio 1:1 --size 2K --json --download-dir ./output/game/<角色名>/expression
meitu image-grid-split --image_url "<表情宫格绝对路径>" --json --download-dir ./output/game/<角色名>/expression/frames
```

表情幅度要可读但不夸张：愤怒是眉压眼、嘴角下压，不是整张脸扭曲。改脸型就说明一致性丢了，该重跑。

## D 规格表

固定 12 字段，缺一项就不算完成：

| 字段 | 填写要求 |
| --- | --- |
| 角色名 / 身份 | 职业、阵营、定位 |
| 体型与年龄感 | 头身比数值 + 年龄区间 |
| 发型与发色 | 结构描述 + HEX |
| 服装分层 | 内搭 / 外套 / 配饰逐层写 |
| 主色 / 辅色 / 点缀色 | 每组给 HEX，主色不超过 5 个 |
| 标志性配件 | 必须出现的 1–2 件 |
| 武器或手持物 | 位置与大致尺寸，没有写「无」 |
| 视角与姿态 | 正面全身、A-pose |
| 画风措辞 | 从风格卡逐字复制，不改写 |
| 光位 | 主光方向，与项目其他素材一致 |
| 禁用项 | 明确不出现的元素、颜色、配饰 |
| 版本 | 从 `v1` 起，改锚点即升版 |

模板：

```markdown
# <角色名> 设定卡 v1

- 身份：
- 体型与年龄感：
- 发型与发色：
- 服装分层：
- 主色 / 辅色 / 点缀色：
- 标志性配件：
- 武器或手持物：
- 视角与姿态：正面全身，A-pose
- 画风措辞：
- 光位：
- 禁用项：
- 版本：v1

## 参考图
- 主卡：sheet_anchor_v1.png
- 转面：sheet_turnaround_v1.png（可选）
- 表情：sheet_expression_v1.png（可选）
```

## 版本与作废

- 主卡是唯一参考，其他三件都回溯到它。
- **改主卡必须升版并重出 B、C**，旧版本目录保留但标注废弃，不能新旧混用。
- 换装或换肤后，新图成为新的参考，要重新出表情与转面，否则同一角色的服装会对不上。

## 验收清单

- [ ] 主卡为正面全身、A-pose、纯色背景、完整入画、无文字
- [ ] D 规格表 12 字段齐全，色板为 HEX，禁用项已写
- [ ] 转面（若做）脚底线水平，背面结构与正面一致
- [ ] 表情（若做）只改眉眼嘴，脸型发型服装未变
- [ ] 主卡、转面、表情三者的比例、光位、描边一致
- [ ] 版本号已标注，旧版本已声明作废
- [ ] 交付说明写清了哪些件未做

## 不做的事

- 不做 T-pose 骨骼绑定用图，不做布线、UV、材质球。
- 不把文字、色板、比例尺烘焙进主卡，避免干扰后续参考。
- 不保证转面与主卡逐像素一致，背面结构必须人工核对。

# 动作目录与验收重点

动作目录采用“通用核心动作 + 品类扩展动作”。同一个动作只保留一份权威定义，多个品类直接引用，不重复维护。

用户已说明品类时，加载通用核心动作和对应品类扩展；用户只给动作名时直接制作该动作；整库批量回归才按目录顺序执行，并在某项失败后暂停批量扩展。

## 动作规格字段

每个动作至少明确：动作名称与适用品类、循环或单次类型、必要动作阶段、根锚点与允许位移、道具或交互点、最大动作包围盒、安全区方向与占画比例、重点验收项、成本等级。

成本等级只估算视频时长、复核和超清成本，不规定最终帧数。

最大动作包围盒是角色身体、穿戴装备、武器或交互道具、尾巴与翅膀等动态附属物、必要特效以及完整运动轨迹的并集。双人、载具和召唤动作纳入全部主体，不能只按角色静态轮廓规划画布。

| 动作类型 | 最大占画比例 | 额外定向空间 |
| --- | --- | --- |
| 普通无道具动作 | 画面高度 50%–55% | 四周均匀留白 |
| 长武器或长道具动作 | 画面宽高 40%–45% | 武器最大挥动方向优先 |
| 跳跃或上抛动作 | 画面宽高不超过 45% | 上方至少 40% |
| 倒地、翻滚、滑铲、横扫 | 画面宽高不超过 45% | 左右各至少 30% |
| 投射物或大型技能特效 | 画面宽高 35%–40% | 释放方向至少 35% |
| 双人、载具或召唤动作 | 画面宽高 35%–40% | 按全部主体轨迹计算 |

同一动作命中多项规则时，使用占画比例更小、留白要求更大的规则。安全区优先于源视频中的角色显示尺寸；主体过小影响识别时提高锚点清晰度，不减少必要留白。

## 通用核心动作

| 类别 | 动作 | 类型 | 必要阶段与重点验收 |
| --- | --- | --- | --- |
| 基础循环 | 待机呼吸、普通走路、奔跑、转向、蹲伏待机、蹲伏移动 | 循环或单次 | 身份和朝向稳定；步态左右交替；接地帧脚底稳定 |
| 基础位移 | 原地跳跃、助跑跳跃、落地缓冲、翻越、攀爬、悬挂、滑铲、翻滚 | 单次或保持 | 蓄力、腾空、接触和恢复完整；预留对应方向安全区 |
| 通用交互 | 拾取、放置、搬运、推拉、开关、使用工具、递交、接受 | 单次或保持 | 手与交互点对应；道具不穿模；接触点和结束位置一致 |
| 日常姿态 | 坐下、坐姿待机、起身、躺下、睡眠、醒来 | 单次或循环 | 与座椅或地面接触可信；切换不瞬移；结束姿态可保持 |
| 日常行为 | 吃、喝、挥手、点头、摇头、鼓掌、指向、倾听、思考 | 单次或循环 | 手口关系、视线目标和节奏清晰；小动作剪影仍可读 |
| 情绪反馈 | 开心、庆祝、惊讶、害怕、生气、悲伤、哭泣、疲惫、失败 | 单次或循环 | 情绪由姿态和轮廓表达；幅度符合角色设定 |
| 状态变化 | 受击、失衡、倒地、起身、眩晕、死亡 | 单次或循环 | 受力方向明确；地面接触完整；终态稳定 |

## 品类扩展动作

### 动作冒险 / 平台

攀爬、悬挂、翻越、蹬墙、滑铲、翻滚、冲刺、急停、轻攻击、重攻击、刺击、格挡、闪避、受击、倒地、死亡。

- 原地循环锁根锚点，冲刺、跳跃和翻越保留真实位移。
- 跳跃扩大上方，冲刺扩大前方，翻滚和倒地扩大水平方向。
- 检查支撑关系、腾空阶段、攻击方向、地面接触和恢复姿态。

### 生活模拟 / 角色扮演

洗漱、穿衣、坐下、休息、睡眠、醒来、烹饪、用餐、饮水、清扫、阅读、写字、挥手、拥抱、庆祝、哭泣。

- 定义镜台、衣物、座椅、床、厨具、餐具、书本和目标角色等交互点。
- 按家具和手持物完整包围盒预留安全区。
- 检查手口关系、家具接触、持物连续性、社交距离和情绪可读性。

### 经营建造 / 农场

搬运、放置、建造、修理、锤击、锯切、采集、砍伐、挖掘、种植、浇水、收获、喂养、钓鱼。

- 定义工具握持点、材料落点、作物根部、水面或建造节点。
- 长工具按最大运动半径预留安全区。
- 检查工具不换手、不穿模，发力与结果对应，材料状态切换明确。

### 剧情互动 / 视觉叙事

对话、倾听、思考、指引、递交、接受、鞠躬、握手、拥抱、鼓掌、惊讶、拒绝、争执、哭泣。

- 明确对话对象或镜头方向，双人动作分别定义站位和接触点。
- 为手势、另一角色和关键道具预留空间。
- 检查视线、手势语义、接触时序和情绪转折。

### 潜行探索 / 解谜

观察、搜索、检查、贴墙、探头、潜行、躲藏、匍匐、开锁、拆解、发现目标、触发机关。

- 贴墙和匍匐允许低位水平移动，开锁与机关动作锁定交互点。
- 探头扩大观察方向，机关互动扩大手部和装置区域。
- 检查低重心、视线方向、遮挡关系和机关接触。

### 射击 / 远程战斗

持枪待机、瞄准、射击、连射、换弹、后坐、切换武器、投掷、进入掩体、掩体探身、退出掩体。

- 定义前后手握持点、枪托肩点、瞄准线、弹匣和掩体边缘。
- 射击或投掷方向预留投射物与后坐空间。
- 检查武器方向、握持关系、后坐和换弹顺序。

### 魔法 / 技能职业

蓄能、施法、引导、释放、打断、召唤、治疗、增益、减益、传送、维持法术、结束法术。

- 定义法器、双手、目标点、召唤位置和法阵中心。
- 按法术最大光效和召唤物包围盒预留安全区。
- 检查聚集、释放和消散完整；角色动作与无角色特效分别生产后合成。

### 运动 / 休闲竞技

热身、冲刺、急停、转身、跳跃、投掷、接取、挥拍、踢球、守门、得分庆祝、失败反馈。

- 定义球、球拍、球门、边线和队友位置。
- 保留真实运动轨迹，不把所有动作强行原地化。
- 检查接触时序、动量方向、随动和结束重心。

### 载具 / 骑乘

上下载具、上马下马、骑乘待机、加速、减速、转向、刹车、颠簸、碰撞、使用载具武器。

- 定义座位、脚踏、把手、缰绳、方向盘和武器挂点。
- 角色根锚点切换为载具挂点，角色和载具不得分别漂移。
- 检查上下过程、遮挡关系、加减速随动和碰撞反馈。

## 选库规则

- 未说明品类时先确认；只请求单个明确动作时不阻塞执行。
- 单一品类加载“通用核心动作 + 该品类扩展”。
- 混合品类让每个动作引用一个主定义，再叠加交互点、安全区和验收差异。
- 动作重名但语义不同时，通过对象和用途区分阶段与幅度。
- 双人、载具、长武器或大型特效先确认完整包围盒和所有接触点。

## 每项门禁

- 角色身份、服装、配色与朝向稳定。
- 关节轨迹连续，无肢体突然换边或额外肢体。
- 循环动作首尾可闭合；单次动作预备、动作、跟随和结束完整。
- 位置和锚点变化符合动作类型，不用对齐掩盖错误姿态。
- 人物、道具、武器、载具与特效完整入镜，交互点不穿模。
- 全部必要对象到画面四边的距离均不少于对应边长的 8%；任一对象触边或低于门槛时整段失败并扩大安全区重生成。
- 单帧超清预检通过后才处理全部入选帧。
- 解码全部源帧后再挑选，帧数由动作阶段、信息增量和节奏决定。
- GIF 动态验收通过后才导出图集与 JSON。
- 不通过时记录具体失败原因。

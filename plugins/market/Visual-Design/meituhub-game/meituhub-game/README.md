# 游戏资产生成·MeituHub

![插件头像](assets/plugin-icon.png)


按同一套画风制作 2D 游戏角色、场景、道具、界面和宣发素材。从角色设定延展到表情与动作，支持图集、动画数据和预览动图交付。

## 可以做什么

| 技能 | 用途 |
| --- | --- |
| 游戏物料规划 | 根据玩法、开发阶段和已有素材，列出游戏物料清单、制作优先级与依赖；适用于整套素材规划和跨类别生产。 |
| 美术风格设定 | 从题材与玩法提出可比较的美术方向，确定视角、色彩、风格卡和角色基准；适用于立项定调与统一既有素材画风。 |
| 游戏角色生成 | 围绕同一角色基准制作立绘、表情、转面、换装和动作；动作可整理为 PNG 图集、逐帧时长 JSON 与预览 GIF。 |
| 场景与道具生成 | 为关卡制作场景概念、远中近分层背景、地图瓦片、道具与建筑单体，也支持水面、雨雪等环境循环动效。 |
| 游戏UI生成 | 按统一的圆角、描边和光位制作游戏图标、按钮四态、面板、血条与背包格，交付界面图片和文字安全区说明。 |
| 游戏宣发制作 | 沿用游戏角色与场景制作卡牌、海报、商店封面、横幅和宣传短片，按目标版位组织尺寸并核对文案。 |

## 这样开始

- 按这份设定做一套 2D 游戏物料，先列清单和优先级。
- 给这个角色做走路动作，交付图集、JSON 和预览 GIF。
- 沿用现有画风，制作按钮四态、背包格和道具图标。

## 安装与运行

在 Qoder 的插件入口导入本包 ZIP。每包自带 MeituHub 接入，无需 MCP 或另装基础插件；首次使用按提示连接账户，实际调用可能产生用量。

版本 0.4.0。包结构与本地辅助工具已检查，尚未完成 Qoder 安装、自动路由和真实业务调用验收。具体服务以当前账户工具目录为准。PPTX 编辑与预览、XMP 导入、原生小程序运行需相应宿主工具；源码与预览不等于已上线。原文件保留，产物另存。

## 自然语言使用

可以直接描述想要的结果，不必先写技能 ID。技能已补充常用说法和相关场景，自动选择效果以 Qoder 实测为准。查看 [场景识别与分工](references/intent-routing.md)。发布页图标可使用 `assets/plugin-icon.png`。

# 术语与速查表

各 skill 内联精简副本；本文件为完整版。

## 物料类型定义

避免同一物料在不同 skill 里叫不同名字。

| 物料 | 定义 | 不该叫成 |
| --- | --- | --- |
| 风格锚点 | 一张确定整项目视觉基准的图 | 风格参考、风格样图 |
| 角色设定卡 | 一套基准：主卡（正面全身 A-pose）+ 规格表，转面与表情按需 | 角色参考、角色底图 |
| 立绘 | 单一姿态的半身或全身角色图 | 半身像、人物图 |
| 表情组 | 同一角色的多个表情，通常六格宫格 | 表情包（指贴纸，不同概念） |
| 转面 | 同一角色在多个朝向下的单体，4 或 8 个方向 | 三视图（只有三个方向时才用） |
| 序列帧 | 拆成单帧、带逐帧时长的动作图 | 帧序列、逐帧图 |
| 图集 | 把序列帧等分拼成一张大图，附 JSON 元数据 | 精灵表、spritesheet（可用但中文统一叫图集） |
| 分层背景 | 远、中、近三层分别生成，可做视差 | 分层图、切片背景 |
| 瓦片表 | 4×4 宫格、每格一个地块或物件 | 图块表、tileset（中文统一叫瓦片表） |
| UI 套装 | 按钮四态、血条、图标、背包格、面板的成套件 | UI 组件、界面元素 |

## 画风速查（18 种）

完整视觉特征与生产链路见 `shared/references/style-library.md`。

| 画风 | 一句话特征 | 常用于 |
| --- | --- | --- |
| 日式赛璐璐 | 硬边阴影、平涂色块、锐利高光 | 二次元卡牌、剧情手游 |
| 日式厚涂 | 笔触可见、明暗过渡柔和、体积感强 | 高规格主视觉 |
| 韩式半写实 | 比例偏真实、面部精致、光影细腻 | 韩系 MMO、女性向 |
| 欧美卡通 | 夸张比例、粗描边、饱和色 | 休闲、合家欢 |
| 欧美厚涂/手绘纹理 | 材质笔触明显、色调沉稳 | 中世纪、奇幻 RPG |
| 写实/半写实 | 接近照片、细节密 | 军事、写实竞速 |
| 水彩绘本 | 边缘晕染、留白多、通透 | 治愈系、儿童向 |
| 水墨国风 | 墨色浓淡、留白、皴法 | 仙侠、武侠 |
| 美漫墨线 | 粗黑描边、硬朗阴影、网点 | 超级英雄、硬派动作 |
| 极简扁平 | 无描边、几何化、纯色 | 超休闲、工具类 |
| 纸雕拼贴 | 多层纸片感、投影分层 | 绘本、轻解谜 |
| 单色版画 | 单色或双色、刀刻质感 | 独立游戏、叙事向 |
| 像素 | 有限色板、1px 描边、无抗锯齿 | 复古、独立、Roguelike |
| 低多边形 | 三角面切分、硬转折、无纹理 | 风格化 3D 观感（只做 2D 画面） |
| 体素 | 方块堆叠、轴向对齐 | 沙盒、建造 |
| 黏土定格 | 手捏质感、指纹与褶皱 | 治愈、解谜 |
| 2.5D 等距 | 45 度俯视、正交投影 | SLG、模拟经营 |
| 暗黑哥特 | 低饱和、强对比、装饰繁复 | 魂系、恐怖 |

## 品类速查

完整物料包与边界见 `shared/references/genre-matrix.md`。

- **卡牌 / CCG / 放置卡牌**：卡面、卡框与稀有度底板、技能图标、主视觉、商店图。
- **剧情 / 视觉小说 / 互动叙事**：立绘与表情组、分层背景、CG、对话框 UI、标题图。
- **模拟经营 / 建造 / 农场**：等距地表、建筑与道具单体、角色立绘、UI 面板。
- **塔防 / 战棋 / 自走棋**：单位立绘、技能图标、地图背景、阵营徽记、UI。
- **女性向 / 换装 / 恋爱**：立绘、服装与皮肤、表情组、CG、活动 KV。
- **桌游 / 跑团 / 剧本杀**：卡面、token、地图、角色卡、封面。
- **休闲 / 解谜 / 儿童教育**：图标组、关卡背景、少量角色、UI、商店图。
- **放置 / 挂机**：单位立绘、技能图标、UI、KV、商店图。
- **横版动作 / 平台 / 银河恶魔城**：分层背景、角色与敌人、道具、UI、KV、动作序列帧。
- **JRPG / 国风 RPG / 2D 恐怖 / 2D 射击**：立绘与表情、场景、道具、UI、KV。
- **像素独立游戏**：像素风 KV、角色与场景概念、UI、商店图、序列帧。
- **3D 主项目（MMO / 开放世界 / 竞速）**：只做概念图、气氛图、KV、UI 图标、商店图、宣传视频。

## 画风五层结构

任何画风描述都按这五层写，缺层会导致方向漂移：

1. 画面形态（2D 插画 / 像素 / 2.5D 等距 / 3D 观感）
2. 写实度（写实 / 半写实 / 风格化 / 卡通 / Q 版 / 极简）
3. 上色媒介（平涂 / 赛璐璐 / 厚涂 / 半厚涂 / 手绘纹理 / 水彩 / 水墨 / 版画 / 纸雕 / 单色）
4. 题材（日式 / 韩式 / 中式古风 / 暗黑哥特 / 赛博 / 蒸汽 / 废土 / 童话 / 科幻 / 诡异未知）
5. 视角与情绪（横版 / 等距 / 俯视 / 竖版；饱和度、色温、对比、光位）

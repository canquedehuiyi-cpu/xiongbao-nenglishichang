# Qoder 接入与交付说明

六个游戏模块共用包内 meitu-ai-game，沿用 Qoder 中国区启动器、认证与账户入口。本包只携带 Qoder 元数据、启动器与认证配置。MEITU_GAME_PLUGIN_ROOT 从实际加载位置解析，不能猜用户安装目录。

角色图集工具需要现有 Python 与 Pillow。按当前项目依赖环境执行，缺依赖如实说明；不修改系统安全设置、不把安装成功当作资产通过。脚本保持源包版本，随包提供测试。默认新目录输出，版本递增，未经用户授权不使用 --overwrite 覆盖已有作品。

从源包保留：同一风格与角色基准、分阶段确认与明确整套授权、每步最多两版、动作全帧分析、完整动作包围盒、安全区、逐帧时长、图集/JSON/GIF 交叉检查。静态宫格只是概念动作，不冒充连续动画；文件校验不证明肢体、身份或动作正确。engine-tested 与 final 不能由自动打包推定。

源包只承担 2D 游戏视觉资产，不因“3D 观感”宣称输出 3D 模型、骨骼或引擎工程；透明边缘、瓦片接缝、文字与实机显示仍须实际复核。用户只要求规划时不为凑美图调用生成无关图；进入素材生产后必须实际取得并使用美图结果。

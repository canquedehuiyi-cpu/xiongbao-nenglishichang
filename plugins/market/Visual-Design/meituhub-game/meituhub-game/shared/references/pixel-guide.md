# 像素风专项

本文件定义像素风的可用参数与已知限制。跨画风原则见 [通用创作原则](art-principles.md)。

## 适用范围

- 边缘硬、色块少，宫格拆分后每格的像素结构稳定，跨帧一致性比厚涂、水彩更容易判断。
- 描边与色板是显式参数，可以写进提示词并逐张核对，不依赖模型对「质感」的理解。
- 缺点同样明确：像素精度是物理上限，画布越小，能表达的动作越少。

## 使用前提

剪影、明度、色相偏移、光位、评审方法这些跨画风原则见 [通用创作原则](art-principles.md)，本文档不重复。

本文档只放像素专用的部分：带 px、倍数、色阶步数、宫格尺寸的判断都在这里；不带单位的判断都在通用文档。两者冲突时以通用原则为准——像素数值只用来解决「精度不够」这一类问题。

## 提示词固定措辞

同一项目里逐字复制，不改写、不同义替换：

```text
pixel art, 16-bit, 有限调色板（16–32 色）, 硬边缘, 无抗锯齿, 无渐变, 1px 描边, 正交视角
```

- 色板：把同一组 HEX 写进每段提示词，或额外传一张色板图作为参考图。只写「像素风」三个字会得到写实降采样观感。
- 描边：角色用 1px 黑色或深色描边，与背景区分。描边粗细跨图必须一致，否则拼在一起会显假。
- 禁用词：不要出现「高清」「细节丰富」「柔和光照」，这些会把结果推向半写实。

## 画布与宫格

格子高度必须容纳腾空，否则跳跃会被压扁。

| 用途 | 布局规则 | 说明 |
| --- | --- | --- |
| 接地动作 | 按角色最高姿态与武器范围留边 | 格子间使用统一画布与锚点 |
| 跳跃 / 腾空攻击 | 在角色最高姿态之外增加腾空安全区 | 不得逐帧贴底压平腾空轨迹 |
| 静态宫格概念稿 | 按实际格数选择等分网格 | 只用于动作讨论，不作为正式动画序列 |

正式动画优先使用连续视频抽帧。静态宫格不维护跨帧骨架和时间连续性；分段生成还会增加比例与位置漂移，只能作为概念表达。

## 原生分辨率与降采样

CLI 输出高分辨率图，**不直接产出 16/32/64px 原生画布**。交付前由美术按最近邻降采样、限色、修边。

| 目标原生尺寸 | 建议生成尺寸 | 降采样倍数 |
| --- | --- | --- |
| 32×32 | 512 或 1024 | 16× 或 32× |
| 64×64 | 1024 或 2048 | 16× 或 32× |
| 96×96 | 2048 | 约 21× |

顺序不能颠倒：先编辑、对齐、抠图，最后一步才降采样。中途降采样再做编辑，会因重采样产生糊边和杂色。

## 角色比例与可读性下限

- **躯干宽度决定动作可读性。** 小尺寸角色的手臂、手部与面部变化受像素精度限制，不是增加提示词细节就能解决。
- 要表现明显的摆臂与关节变化，应提高角色最终像素尺寸、减少局部细节或强化轮廓差异；无法满足时在交付说明中写清限制。
- 头身比固定：像素角色建议 3–4 头身，细长比例在小画布上会糊成一团。
- 五官只保留必要像素：两点眼睛或一条横线，不要画鼻子与嘴的细节。
- **关节处预留 2–3px 余量**：肘、膝、腰附近不要画满，留出让压缩与过冲发生的空间；关节画死的角色，动作一定僵。

## 色阶与描边（像素专用）

这两项在其他画风里没有等价物，所以留在本文件。

- **色阶步数按画布尺寸**：16×16 用 3 阶（暗/中/亮），32×32 用 4–5 阶，64×64 以上 6–8 阶。
- **描边二选一，全项目统一**：
  - 全描边：1px 深色描边，小尺寸最稳，与背景切得干净。
  - 选择性描边：描边取相邻填充色的深色版本，不用纯黑，适合较大尺寸，观感更柔和。
  - 两种混用立刻显脏。

## 动作帧选择

- 不预设固定帧数。先解码全部源帧，再按动作阶段、轮廓变化、运动速度和最终显示尺寸自适应选择。
- 小尺寸精灵优先保留接触、极值、转折和结束姿态；无法读清的细微中间姿态不为凑数量保留。
- 循环动作必须覆盖完整周期，单次动作必须覆盖预备、发力、峰值、跟随与结束状态。
- 帧数是筛选结果，不是生成前的硬指标；不得为满足固定数量加入重复帧、坏帧或错误姿态。

## 对齐

通用规则（接地帧脚底线、头身比、基准位置、锚点、原地绘制）见 [动作拆解 · 对齐要求](animation-breakdown.md)，本节不重复。

- 水平基准使用胸部中轴，不使用会随支撑腿变化的脚部中心。
- 整段采用同一缩放比例；跳跃、攻击和倒地不得逐帧锁脚底，以免抹除有效运动轨迹。
- 带武器动作检测脚底时排除剑尖等窄小突出物，缩放同时受角色与武器的宽高范围约束。

## 各物料注意点

| 物料 | 像素风要点 |
| --- | --- |
| 角色设定卡 | 3:4、正面全身、纯色背景；描边与色板在此锁定 |
| 立绘 | 放大画布后再画细节，不要在小图上堆细节 |
| 表情组 | 六格宫格；表情靠眼睛与眉毛的 1–2px 变化，不要改脸型 |
| 转面 | 4 方向 2×2、8 方向 3×3；脚底线水平，背面服装结构逐方向核对 |
| UI 图标 | 1K 生成、`image-cutout --model_type 2`；一图一个，不塞宫格 |
| 场景与瓦片 | 瓦片表 4×4；拼接缝与明度差不做保证，需美术修 |
| 卡牌 | 插画 3:4，文字交给 `image-poster-generate`，图里不写像素字 |

## 验收清单

- [ ] 所有图共用同一组 HEX 色板与同一句像素措辞
- [ ] 描边统一 1px，跨图一致
- [ ] 无抗锯齿、无渐变、无第三种描边色
- [ ] 正式序列来自连续时间轨迹；静态宫格仅作概念表达
- [ ] 跳跃格子高度足以容纳腾空，腾空曲线未被压平
- [ ] 水平按胸部中轴对齐，未用脚部中心
- [ ] 降采样放在最后一步，用的是最近邻
- [ ] 转灰阶后明度分层清晰，没有糊成一团
- [ ] 纯黑剪影仍能认出角色与动作
- [ ] 主光方向全项目一致，没有翻转
- [ ] 描边只用一种策略，未在全描边与选择性描边之间混用
- [ ] 循环动作的第 N 帧是第 1 帧的前一帧，未复制首帧
- [ ] 手臂等小尺度细节已达像素上限时，已在交付说明中写明
- [ ] 已说明需美术二次处理（降采样、限色、修边、接缝）

## 不做的事

- 不直接输出 16/32/64px 原生画布，也不锁色板。
- 不保证像素点严格对齐网格：降采样后仍需人工修边。
- 不做原生像素字体与文字排版。
- 不承诺在小尺寸角色上表现精细的手部与面部动作。

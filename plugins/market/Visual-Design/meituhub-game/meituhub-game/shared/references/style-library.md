# 游戏画风库

本库把“画风”拆成可组合的五层结构，避免只靠一个风格词出图；所有记录都对应可由 `text-to-image`、`image-edit`、`image-style-transfer` 等现有命令执行的链路。

## 使用原则

1. **画风是组合，不是单词。** 一个可用的风格描述 = 画面形态 + 写实度 + 上色/渲染媒介 + 题材世界观 + 视角与情绪。
2. **一主一辅。** 同一张图只保留一个主渲染语言；混搭时明确主次，例如“以水墨为主，赛博霓虹只做点缀”。
3. **风格锚点优先于形容词。** 使用用户自有或已授权的输入图锁定风格锚点，再用同一段措辞批量生产。
4. **只交付 2D 图像与短视频。** 低多边形、体素、黏土、卡通渲染都是“2D 画面里的 3D 观感”，不是可导入引擎的模型、材质或 Shader。

## 五层结构

| 层 | 作用 | 常见取值 |
| --- | --- | --- |
| L1 画面形态 | 决定是平面、像素、等距还是 3D 观感 | 2D 插画、像素、2.5D 等距、低多边形、体素、黏土定格、像素角色与立体场景融合 |
| L2 写实度 | 决定比例、解剖与细节密度 | 写实、半写实、风格化、卡通、Q 版、极简、抽象 |
| L3 上色/渲染 | 决定线条、明暗、材质与笔触 | 平涂、赛璐璐、厚涂、半厚涂、手绘纹理、水彩、水墨、版画、纸雕、单色 |
| L4 题材/世界观 | 决定服装、建筑、道具与年代 | 日式奇幻、韩式 MMO、中式古风、暗黑哥特、赛博朋克、蒸汽朋克、末世废土、童话、科幻、诡异未知 |
| L5 视角/情绪 | 决定构图、镜头、色温与光位 | 横版、等距、正俯视、竖版；高/低饱和、暖/冷、高对比/柔和、顶光/侧逆光 |

## 风格记录格式

每个画风按同一张“风格卡”记录，写进提示词与风格锚点文档：

- **关键词**：中文 + 英文，便于跨模型稳定复现。
- **视觉特征**：线条、色板、明暗级数、材质、细节密度、比例。
- **适合**：品类、视角、平台。
- **支持程度**：强 / 中 / 弱。
- **生产链路**：用哪些命令、是否需要后期。
- **风险**：最容易崩的地方。

## 核心画风

### 1. 日式赛璐璐

- **关键词**：日式赛璐璐、动画平涂、干净线稿、两级明暗、硬边缘阴影；anime cel, flat shading, clean lineart, hard-edged shadow。
- **视觉特征**：高完成度线稿；大面积平涂；明暗只分亮部与暗部；高光少量；色彩明亮通透；比例偏唯美。
- **适合**：二次元 RPG、卡牌、横版、竖版手游；角色立绘与表情组。
- **支持程度**：强。
- **生产链路**：`text-to-image` 出单图 → 角色锚点 → `image-edit` 出立绘/表情/方向；同族批量固定风格措辞。
- **风险**：线稿容易断、描边粗细漂移；厚涂化倾向会让赛璐璐变“糊”。

### 2. 日式厚涂 / 半厚涂

- **关键词**：日系厚涂、半厚涂、笔触丰富、柔和过渡、固有色为主；anime painterly, semi-thick paint, soft blending。
- **视觉特征**：保留线稿或弱化线稿；明暗层次多于赛璐璐；材质与光影更细；色彩饱和但克制。
- **适合**：二次元 RPG 原画、卡牌插画、角色 CG、宣传 KV。
- **支持程度**：强。
- **生产链路**：`text-to-image` 出气氛与造型 → 锚点确认 → `image-edit` 出系列；需要统一质感时 `image-style-transfer` 只做氛围，不用于保形。
- **风险**：跨图材质与笔触漂移；容易过度细节化，缩小后糊成一团。

### 3. 韩式华丽半写实

- **关键词**：韩式半写实、华丽时装、精致材质、八头身、欧式剪裁；Korean MMO, stylish semi-realistic, ornate costume。
- **视觉特征**：接近写实的人体比例；服装层次复杂；金属、皮革、丝绸质感明确；配色干净但饱和；面部唯美。
- **适合**：MMO、韩式 RPG、时装换装、卡牌。
- **支持程度**：中。
- **生产链路**：必须给服装与材质参考；`text-to-image` 出概念，`image-edit` 锁定角色；同角色多套服装逐套出。
- **风险**：细节量高，容易在拆分尺寸下丢失；材质与花纹跨图不一致。

### 4. 欧美卡通 / 风格化

- **关键词**：欧美卡通、风格化、夸张比例、强剪影、明快色块；stylized cartoon, exaggerated proportions, strong silhouette。
- **视觉特征**：造型夸张但结构扎实；色块分明；轮廓清晰；材质概括；适合小屏阅读。
- **适合**：休闲、合家欢、动作、竞技、移动端。
- **支持程度**：强。
- **生产链路**：`text-to-image` 出角色/场景 → 锚点 → `image-edit` 出系列；UI 同族走宫格。
- **风险**：容易滑向“低龄简笔”；剪影不够强时缺少辨识度。

### 5. 欧美厚涂 / 手绘纹理

- **关键词**：欧美厚涂、手绘纹理、笔触可见、暖光、哑光材质；hand-painted, painterly, visible brushwork, matte material。
- **视觉特征**：体积感强；明暗过渡柔和；材质靠手绘笔触表达；色彩温暖；细节密度中等。
- **适合**：奇幻 RPG、MMO、策略、卡牌。
- **支持程度**：强。
- **生产链路**：`text-to-image` 出概念；同族 `image-edit` 固定锚点；需要统一质感时用固定风格图做参考。
- **风险**：手绘笔触跨图不一致；容易被模型做成“塑料 3D”。

### 6. 写实 / 半写实电影感

- **关键词**：写实、半写实、电影感、真实材质、体积光、浅景深；realistic, cinematic, PBR look, volumetric light。
- **视觉特征**：真实解剖与材质；高动态范围；强方向光；环境细节丰富；低饱和或冷暖对比。
- **适合**：3A 概念图、写实 RPG、射击、恐怖、宣传 KV。
- **支持程度**：中。
- **生产链路**：`text-to-image` 出概念与气氛图；`image-edit` 做变体；`image-superres-enhance` 提清晰度；只作为 2D 概念，不承诺 PBR 材质。
- **风险**：细节多、跨图一致性差；容易落入“AI 塑料感”；不输出可渲染材质。

### 7. 水彩 / 绘本

- **关键词**：水彩、纸张纹理、透明晕染、柔和边缘、留白；watercolor, paper grain, soft wash, picture book。
- **视觉特征**：颜色透明叠加；边缘自然扩散；纸张肌理明显；细节少；情绪柔和。
- **适合**：剧情、解谜、儿童向、治愈系。
- **支持程度**：强。
- **生产链路**：`text-to-image` 出场景/角色；`image-edit` 保持角色；需要统一纸感时固定“纸张纹理 + 湿画法”措辞。
- **风险**：水痕与纸纹跨图不一致；角色容易糊、边缘不清晰。

### 8. 水墨 / 工笔 / 国风

- **关键词**：水墨、工笔、青绿山水、飞白、留白、宣纸；ink wash, gongbi, Chinese painting, xuan paper。
- **视觉特征**：墨色浓淡干湿；线条书法性；大面积留白；矿物色或淡彩；构图卷轴感。
- **适合**：国风 RPG、武侠、仙侠、解谜、文化题材。
- **支持程度**：强。
- **生产链路**：`text-to-image` 出场景/角色；固定“墨色 + 宣纸 + 留白”措辞；角色系列用锚点。
- **风险**：模型容易加现代高光或写实材质；工笔细节在缩小后丢失。

### 9. 美漫 / 墨线 / 图形小说

- **关键词**：美漫、墨线、粗描边、块面阴影、网点、高对比；comic book, ink line, graphic novel, halftone。
- **视觉特征**：粗黑描边；硬阴影；高对比；少量高光；网点或做旧印刷质感。
- **适合**：动作、射击、末日、黑色题材。
- **支持程度**：强。
- **生产链路**：`text-to-image` 出角色/场景；固定“粗描边 + 硬阴影 + 网点”措辞；同族宫格批量。
- **风险**：描边粗细不统一；网点密度在缩放后产生摩尔纹。

### 10. 极简扁平 / 矢量

- **关键词**：极简、扁平、矢量、几何色块、无渐变、强留白；flat vector, minimalist, geometric, no gradient。
- **视觉特征**：纯色块；无描边或等宽描边；几何化造型；空间靠色块与留白；低细节。
- **适合**：休闲、解谜、超休闲、UI、教育。
- **支持程度**：强。
- **生产链路**：`text-to-image` 出图；提示词强调“纯色块、无渐变、几何化”；UI 用宫格套装。
- **风险**：容易过于通用、缺少辨识度；模型会偷偷加渐变与阴影。

### 11. 纸雕 / 拼贴

- **关键词**：纸雕、剪纸、层叠纸张、清晰剪边、投影分层；paper cut, papercraft, layered paper, collage。
- **视觉特征**：扁平纸片；边缘干净；层与层之间有投影；哑光纯色；手工艺感。
- **适合**：童话、解谜、儿童、文化题材、轻量叙事。
- **支持程度**：强。
- **生产链路**：`text-to-image` 出场景；固定“层叠纸张 + 投影 + 哑光”措辞；需要分层时逐层生成。
- **风险**：模型会做成普通 3D 纸片；层数与投影方向不一致。

### 12. 单色 / 双色 / 版画

- **关键词**：单色、双色、木刻、丝网印刷、粗颗粒、做旧；monochromatic, duotone, woodcut, screen print, grain。
- **视觉特征**：限定 1–2 个主色；高对比；粗颗粒或印刷错位；细节靠剪影与线条。
- **适合**：恐怖、叙事、实验、黑色题材、低成本高辨识项目。
- **支持程度**：强。
- **生产链路**：`text-to-image` + 明确 HEX 色值；固定“两色 + 粗颗粒 + 无渐变”；后期可再做限色。
- **风险**：模型会加入第三种颜色；颗粒与印刷质感不稳定。

### 13. 像素风

- **关键词**：像素、8-bit、16-bit、有限色板、硬边缘、无抗锯齿、抖动；pixel art, limited palette, no anti-aliasing, dithering。
- **视觉特征**：像素网格；有限色板；硬边缘；1px 描边；正交投影；抖动过渡。
- **适合**：独立游戏、复古、Roguelike、平台跳跃、RPG。
- **支持程度**：强。
- **生产链路**：`text-to-image` 高分辨率出图 → 美术在图像工具中最近邻降采样、限色、修边；保形系列用 `image-edit`，不要用会重绘轮廓的风格迁移。尺寸、帧数、对齐与可读性下限见 [像素风专项](pixel-guide.md)。
- **风险**：不直接产出 16/32/64px 原生画布；不锁定色板；小画布下手臂与手部动作受像素精度限制，需靠放大画布解决。

### 14. 低多边形

- **关键词**：低多边形、几何块面、平直着色、锐利边缘、有限色板；low poly, faceted, flat shading, crisp planes。
- **视觉特征**：大块三角面；明显折面；少纹理；色块化光照；造型概括。
- **适合**：独立 3D、移动端、风格化冒险、等距策略。
- **支持程度**：中（只做 2D 观感）。
- **生产链路**：`text-to-image` 写“低多边形 3D 渲染观感、平直着色、几何块面”；需要多方向时宫格 + `image-edit`。
- **风险**：输出是 2D 图，不是可导入的模型；折面逻辑可能不合理；不能保证布线、UV、LOD。

### 15. 体素

- **关键词**：体素、立方体、像素块、积木感、正交或透视；voxel, cube, blocky。
- **视觉特征**：由立方体堆叠；硬边；色块分明；可正交或带透视；玩具感强。
- **适合**：沙盒、建造、休闲、复古 3D。
- **支持程度**：中（只做 2D 观感）。
- **生产链路**：`text-to-image` 写“体素立方体堆叠、硬边、块状”；需要方向时宫格。
- **风险**：不是体素模型；立方体比例与透视容易乱；不能导出 `.vox`。

### 16. 黏土 / 定格

- **关键词**：黏土、定格动画、磨砂材质、指痕、微距景深、暖光；claymation, plasticine, matte, fingerprints, tilt-shift。
- **视觉特征**：圆润造型；哑光表面；可见手工痕迹；微缩布景感；浅景深。
- **适合**：儿童、休闲、叙事、品牌向小游戏。
- **支持程度**：中（只做 2D 观感）。
- **生产链路**：`text-to-image` 写“黏土材质、指痕、微距、暖光”；同族固定材质措辞。
- **风险**：容易变成普通 3D 塑料；指痕与布景比例不稳定。

### 17. 2.5D 等距

- **关键词**：等距、2.5D、45 度俯视、正交投影、像素角色与立体场景融合；isometric, orthographic, pixel character, dimensional environment。
- **视觉特征**：固定 45 度或 30 度俯角；正交投影；角色与场景比例受网格约束；光照可写实。
- **适合**：战棋、模拟经营、ARPG、复古 RPG。
- **支持程度**：中。
- **生产链路**：`text-to-image` 写“等距 45 度、正交投影、无透视畸变”；地图与瓦片用宫格；角色多方向用转面配方。
- **风险**：不能保证精确角度与网格对齐；瓦片接缝需美术修；不是引擎可用的等距工程。

## 题材修饰

题材是 L4，不单独决定渲染语言；与任一核心画风组合使用。

- **日式奇幻 / 现代都市**：神社、和服、校园、都市夜景；关键词 `Japanese fantasy, modern urban, shrine, kimono`。
- **韩式华丽 MMO**：欧式铠甲、时装、金属花纹、八头身；关键词 `Korean MMO, ornate armor, fashion, eight-head proportion`。
- **中式古风 / 仙侠 / 武侠**：汉服、飞檐、山水、剑气、云纹；关键词 `Chinese ancient, xianxia, wuxia, hanfu, cloud pattern`。
- **暗黑哥特**：尖顶、骷髅、蝙蝠、十字架、雾气、低饱和高对比；关键词 `dark gothic, spires, skull, fog, high contrast`。
- **赛博朋克**：霓虹、雨夜、湿地面反射、义体、繁体招牌；关键词 `cyberpunk, neon, rainy night, wet reflection, chrome`。
- **蒸汽朋克**：黄铜、齿轮、蒸汽、维多利亚、护目镜；关键词 `steampunk, brass, gears, steam, victorian`。
- **末世废土**：废墟、锈蚀、沙尘、拼装车、植被入侵；关键词 `post-apocalyptic, wasteland, rust, scavenger`。
- **童话 / 儿童**：柔光、圆角、手绘、暖色、简化细节；关键词 `fairy tale, children's book, soft light, rounded`。
- **科幻 / 太空**：冷色金属、全息、舱体、星云；关键词 `sci-fi, space, hologram, metallic, cool palette`。
- **诡异未知**：异常生物结构、眼睛、雾气、低饱和、不可名状；关键词 `eerie creature, unnatural anatomy, eerie fog, desaturated`。
- **校园 / 日常**：明亮、干净、生活化、青春；关键词 `slice of life, school, bright, clean`。
- **历史 / 中世纪**：城堡、板甲、村庄、羊皮纸；关键词 `medieval, castle, plate armor, village, parchment`。

## 视角与情绪修饰

- **视角**：横版侧视、等距 45 度、正俯视、竖版 9:16、第三人称、第一人称。只能“画出该视角的画面”，不能做可玩镜头。
- **色彩**：高饱和 / 低饱和、暖色 / 冷色、低饱和高级灰、双色撞色。
- **光照**：顶光、侧逆光、体积光、霓虹多光源、月光、黄金时刻。
- **线条**：粗描边、细线稿、无描边、墨线、铅笔线。
- **细节密度**：低（图标/小屏）、中（角色/场景）、高（KV/卡牌）。
- **材质**：哑光、金属、玻璃、布料、石材、木材、皮革、发光。

## 选择流程

1. **定画面形态**：2D 插画 / 像素 / 2.5D 等距 / 3D 观感（低多边形、体素、黏土）。
2. **定写实度**：写实 / 半写实 / 风格化 / 卡通 / Q 版 / 极简。
3. **定上色媒介**：平涂、赛璐璐、厚涂、手绘纹理、水彩、水墨、版画、纸雕、单色。
4. **定题材**：日式、韩式、中式、暗黑、赛博、蒸汽、废土、童话、科幻、诡异未知。
5. **定视角与情绪**：横版/等距/俯视；高/低饱和；暖/冷；高/低对比。
6. **抽 3–4 个组合候选**给客户，每个附一句适用说明，不固定顺序。

## 提示词公式


- 日式赛璐璐：`日式赛璐璐，干净线稿，平涂色块，亮暗两级，硬边缘阴影，高饱和，正面半身，纯色背景，无文字`
- 欧美厚涂：`欧美风格化厚涂，手绘纹理，夸张比例，强剪影，暖色顶光，哑光材质，低细节噪音，无文字`
- 水墨：`中式水墨，浓淡干湿，飞白笔触，青绿山水，大量留白，宣纸纹理，无文字`
- 低多边形：`低多边形 3D 渲染观感，几何块面，平直着色，锐利边缘，有限色板，正交视角，无文字`
- 纸雕：`纸雕拼贴，层叠纸张，清晰剪边，哑光纯色，投影分层，手工艺质感，无文字`
- 黏土：`黏土定格，磨砂材质，可见指痕，微距景深，暖光，微缩布景，无文字`

## 混搭规则

- **允许**：一个主渲染 + 一个题材 + 一个视角 + 一个情绪。例如“日式赛璐璐 + 赛博朋克 + 竖版 + 高饱和”。
- **谨慎**：两个渲染语言同时做主，例如“像素 + 厚涂”“水墨 + 赛博霓虹”。必须指定主次，并提供参考图。
- **避免**：互相矛盾的写实度，例如“写实 + Q 版”“极简 + 高细节”。确实需要时写成“半写实 Q 版”“极简造型 + 局部高细节”。
- **不要堆词**：超过 5 个风格形容词时，模型会忽略其中一半；优先用参考图与结构化描述。

## 风格锚点

同一项目只用一个风格锚点：

1. 先出 1 张主风格图（hero），确认造型、色板、线条、明暗级数。
2. 再选 3 张用户自有或已授权的同风格辅助图（角色、场景、道具各一），一起作为风格输入。
3. 写一张风格卡：主色 HEX、描边粗细、明暗级数、材质关键词、细节密度、禁止项。
4. 后续所有 `image-edit` 都带同一锚点与同一段风格措辞，只替换主体短语。
5. 跨批新增风格输入时，保留第一批作为风格基准，不要换锚点。

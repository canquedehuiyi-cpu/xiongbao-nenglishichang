# 游戏品类与物料矩阵

本矩阵用于从**品类/题材**快速定位：这个品类通常要做哪些物料、默认视角、推荐画风与交付边界。不做等级划分，按场景逐条对照即可。

配合 [画风库](style-library.md) 使用：先认品类与物料包，再定画风，最后进成套生产。

## 题材与品类的关系

- **品类决定物料包**：卡牌要卡面与卡框，经营要建筑与地块，剧情要立绘与 CG。
- **题材决定画风、服装、建筑、道具与文案**：同一品类可以换题材，物料包不变。
- **同一题材可以跨品类**：东方古风既能做卡牌，也能做剧情、经营、塔防；赛博既能做塔防，也能做剧情、射击。
- **换题材不改物料清单**：主要换参考图、色板、元素与细节密度。
- **常见题材**：东方古风/仙侠、日式奇幻/都市、欧美奇幻、暗黑哥特、赛博朋克、蒸汽朋克、末世废土、童话、科幻、诡异未知、校园日常、历史中世纪。具体画风组合见 [画风库](style-library.md)。

### 标准包示例

- **卡牌包**：1 张主视觉 + 6 张卡面 + 12 个技能/道具图标 + 1 套卡框与稀有度底板 + 1 套 UI + 1 张商店图。
- **剧情包**：1 张主角立绘 + 6 个表情 + 3 张场景 + 2 张 CG + 1 套对话框 UI + 1 张标题图。
- **经营包**：1 张等距地表 + 6 个建筑 + 12 个道具 + 3 个角色 + 1 套 UI + 1 张商店图。

## 3D 或强实时依赖的品类

3D MMO / ARPG、3D 开放世界、写实射击、竞速 / 体育、3D 恐怖：

- **可承接**：概念图、气氛图、KV、UI 图标、商店图、胶囊图、短宣传视频。
- **不承接**：3D 模型、拓扑、UV、PBR 材质、骨骼绑定、动画、引擎工程、LOD、碰撞。
- **表达方式**：低多边形、体素、黏土、卡通渲染只作为 2D 画面的观感，不是可导入的 3D 资产。

## 物料类型总表

| 物料类型 | 具体内容 | 主要命令 | 关键边界 |
| --- | --- | --- | --- |
| 角色 | 立绘、半身、表情组、Q 版、皮肤、4/8 方向、设定卡 | `text-to-image`、`image-edit`、`image-grid-split`、`image-cutout` | 同角色必须锚点；方向不保证逐像素一致 |
| 场景 | 概念图、分层背景、关卡图、地图、CG、加载图、场景循环动效 | `text-to-image`、`image-transform`、`image-to-video`、`video-to-gif` | 分层分别生成；无缝平铺不保证 |
| UI | 图标、按钮四态、面板、血条、背包格、卡框、对话框、状态图标 | `image-edit` 宫格、`image-grid-split`、`image-cutout` | 不输出九宫格配置与分层源文件 |
| 卡牌 / 道具 | 卡面插画、卡框、稀有度底板、武器/装备单体、透明图标 | `text-to-image`、`image-poster-generate`、`image-text-replace`、`image-cutout` | 卡面文字原样保留；卡框与插画分层 |
| 宣发 | KV、商店封面、胶囊图、Banner、海报、短宣传视频、GIF | `image-poster-generate`、`image-transform`、`text-to-video`、`image-to-video`、`video-to-gif` | 多尺寸各出一版，不靠裁剪硬凑 |
| 叙事 | CG、分镜、过场短片、角色表情 | `text-to-image`、`image-edit`、`image-to-video`、`video-stitch` | 只做短片段；不做完整剧情引擎 |
| 动画 | 动作序列帧与图集、技能特效短片、场景循环动效、转面 GIF | `image-to-video`、全帧筛选、图集拼装、`video-to-gif` | 帧数按动作阶段自适应；不做骨骼绑定 |
| 音频 | BGM、配乐、旁白 | `audio-music-generate`、`video-audio-add` | 只做 30–120 秒 BGM；音效暂不支持 |

## 生产顺序

1. **认品类与物料包**：这个品类通常要做哪些物料，先列清单，不按“多出几张”推进。
2. **定视角与画幅**：横版、等距、俯视、竖版，先锁死。
3. **定画风**：按 [画风库](style-library.md) 的五层结构选 3–4 个组合候选。
4. **出锚点**：风格锚点 + 角色锚点，客户确认后再量产。
5. **成套生产**：按动画、转面、风格套装、场景地图、UI 套装推进。
6. **验收与边界**：逐项检查透明底、尺寸、文字、帧/方向、接缝与人工复核项。

## 常见误区

- **把 2D 像素游戏当精灵生产**：能做像素风 KV、角色/场景概念与 UI；原生像素画布、精灵表拼合仍不支持，但序列帧可以出。
- **把低多边形/体素/黏土当 3D 资产**：这些只是 2D 画面观感，不输出模型、材质、拓扑。
- **把 3D 游戏的概念图当生产资产**：这类项目只做概念与宣发，不能承诺导入引擎。
- **不认品类就直接出图**：同一句“要一套物料”，卡牌、经营、剧情需要的包完全不同。
- **先堆数量再想一致性**：先锚点与模板，再批量；否则角色与 UI 会跨图漂移。

## 验收清单

1. 物料包是否与该品类的常见需求匹配，缺项是否说明原因。
2. 是否提前说明不承接的部分，没有把概念图当生产资产承诺。
3. 同角色发型、服装、配色、体型是否一致。
4. 同组 UI 的圆角、描边、高光方向是否统一。
5. 卡面文字、标题、版本号是否原样保留。
6. 透明底边缘是否干净；需要 alpha 的资产是否最后一步抠图。
7. 方向、帧序、脚底线是否一致；动画是否逐帧复核。
8. 瓦片、接缝、地图拼接是否标注需人工修补。

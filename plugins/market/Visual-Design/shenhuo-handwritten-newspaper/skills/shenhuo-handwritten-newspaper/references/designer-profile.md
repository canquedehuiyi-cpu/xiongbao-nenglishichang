# 神火手抄报公开能力说明

服务提供方：神火 AI。固定设计师：手抄报，`des_3b2c6cb3b531` / `office_handwritten_newspaper_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

面向学习、阅读和课堂主题表达，将准确内容安排成手抄报，或制作供用户继续填写与涂色的底稿。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 主题、年级或目标读者、老师要求及需要上图的准确文字
- 明确选择完整知识页、阅读记录、留空填写或黑白涂色；个人心得由本人提供

## 交付

- 默认4:3横向手抄报静态图片
- 可包含核准正文，也可只保留标题、栏目、横线和绘画涂色空间

默认 **1.5K / 4:3**，当前默认 1792×1344。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 不交付可编辑文档、真实手写原作、作业批改或学生亲自完成证明
- 不虚构读后感、实践经历、成绩、引用与知识认证
- 不提供自动印刷、印前文件或A4/A3打印质量保证

## 领域注意

- 空白底稿是明确交付，不用假字或编造心得填满。
- 4:3并非A系纸张比例，家庭打印需按实际像素和缩放检查；当前仅搜索能力，不能声称已读网页全文。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

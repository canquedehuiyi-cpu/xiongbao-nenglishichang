# 神火手抄报使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

把这些阅读主题文字做成一张手抄报图片，标题和内容在附件里。

English: Turn these reading-themed texts into a learning poster image using the attached title and content.

## 示例 2

帮我做一张阅读记录底稿，保留书名、作者、摘抄和想法栏目，内容我自己填。

English: Create a reading record image with blank book title, author, quotation and reflection areas for me to fill in.

## 示例 3

做一张春天主题的黑白手抄报底稿，留出写字、画画和自己涂色的空间。

English: Create a spring-themed black-and-white poster template with space for writing, drawing and coloring.

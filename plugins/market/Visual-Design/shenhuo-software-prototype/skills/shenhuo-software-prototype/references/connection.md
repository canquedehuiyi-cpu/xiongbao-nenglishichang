# 仅使用Qoder市场连接器

本插件只使用Qoder市场的「神火设计师」连接器（服务标识shenhuo-designers），由该宿主管理个人OAuth。包内没有MCP配置；正文依赖说明不会自动安装、绑定或完成授权。不新增自定义MCP，不使用同名插件内实例或其他客户端的连接，不走直连业务API、试用或替代生成服务。

1. 用户明确要生成／修改图片、恢复神火任务或检查连接时，查看Qoder实际市场连接器及工具来源。仅做需求讨论、DESIGN.md或HTML时不用先连接。
2. 已安装、启用且授权有效时，发现该市场连接器实际提供的工具并调用get_account验证。已有有效连接直接复用；相同名字不证明来源或账号相同，不读取Token存储。
3. 尚未安装时，引导用户在Qoder「扩展 → 连接器」市场查找「神火设计师」，核对发布者后安装。当前宿主有官方安装能力且任务已授权时可按真实Schema执行；没有该能力则给出入口，不能虚构工具或市场ID。原生授权由用户完成；按需可[注册神火AI](https://www.shenhuoai.com/register)，已有账号无需再注册。
4. 已安装未授权或授权过期，仅恢复原市场连接。工具未加载先启用、重新发现，必要时新会话恢复同一需求。401／scope不足先由宿主刷新原连接，不能刷新才原生重连；不删除其他连接、不复制密码、API Key或Token。
5. 市场条目找不到、安装失败、授权等待或不可恢复时，说明当前状态，保留需求、原任务ID和幂等记录，暂停依赖神火的图片阶段。不能通过新建自定义连接、换账号或换服务绕过。
6. 用户说已授权后仍须get_account成功，再get_designer核对固定软件原型设计师。授权恢复不重建已有付费任务；按原ID查询，生图仍单独确认当前有效报价。

同名连接器、插件内服务或其他渠道授权不能混为一谈；当前宿主真实只读调用及明确市场来源才算复用成功。工具前缀以运行时发现为准。

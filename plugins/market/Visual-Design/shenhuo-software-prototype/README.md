# 软件原型设计 · 1.0.0

从一句简单需求开始，快速澄清需求、生成基准设计稿、调整确定风格、完成主要页面效果图，交付 HTML 交互原型及 DESIGN.md 样式基准。支持手机 App、移动网站、小程序和 PC 网站。

在Qoder启用本插件，从一句需求或已有需求文档开始。先轻量澄清，使用神火「软件原型设计师」生成和修改页面图；全部设计稿在同一个HTML总览持续更新，用户确认后提取DESIGN.md并制作可交互HTML，最后交付代码包与预览。App与小程序交付浏览器中的界面和流程模拟。

图片制作只使用本渠道市场「神火设计师」连接器与个人OAuth，已有有效授权直接复用。依赖说明不会自动安装连接器；安装、授权与恢复见[连接说明](./skills/shenhuo-software-prototype/references/connection.md)。市场不可用时保留任务并暂停图片阶段，不新增自定义连接或其他通道。需求讨论、样式提取和HTML实现不需要神火连接。

理解／提案可能消耗神火个人积分，生图／参考改图每次单独展示真实报价，经用户确认后执行；图片采用和费用确认分别记录。积分不足仅说明真实状态并暂停，保留原任务和幂等记录。

预览以Qoder实际提供的文件、预览或浏览器工具为准，支持右侧时优先右侧。总览新版必须真实下载、更新并看到新版本，不能只在聊天贴新图。宿主暂不支持预览时提供HTML与打开方法，并说明未验证；不承诺固定侧栏工具或永久在线地址。

包内Python辅助程序只依赖标准库：总览与原型脚本需要Python3.10+；下载辅助程序仅传输已领取作品，不发起设计业务、不读取OAuth。无解释器时可用宿主原生文件能力按同一清单执行，不自动安装依赖。所有方法、模板、脚本与图标均随包提供。

# 神火发型预览公开能力说明

服务提供方：神火 AI。固定设计师：发型预览，`des_c787385e768f` / `hairstyle_preview_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

以头发为主要变化对象，在同一本人照片上比较发型、刘海、卷度或发色，支持与理发师沟通视觉方向。

## 输入

本设计师必须有用户提供的相关原图。先复用已授权且合用的素材；缺图时只补必要原图，不能以虚构素材 ID 或纯文字绕过上传。

- 能看清面部和当前头发的本人照片
- 目标长度、刘海、卷度或发色要求与可选参考
- 需要侧面判断时提供对应侧面照及现实打理偏好

## 交付

- 基于本人照片的发型或发色预览图片
- 同一拍摄条件下的多方案对照图
- 简短的造型说明与理发师沟通摘要

默认 **2K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 不提供实际剪发、染烫服务或化学配方
- 不承诺剪染结果与图片完全一致，不做头皮或脱发医疗诊断
- 不擅自改变脸型、年龄、妆容、服装和身份特征

## 领域注意

- 多方案对照张数由用户需求决定，正文默认对比板形式不是渠道试用上限。
- 图外说明真实效果受发质、底色、染烫史和光线影响；没有侧面来源时不宣称还原真实后脑。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

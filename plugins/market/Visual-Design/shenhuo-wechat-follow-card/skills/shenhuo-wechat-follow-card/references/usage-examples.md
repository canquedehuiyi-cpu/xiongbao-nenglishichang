# 公众号二维码关注图使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

帮我做张公众号文末关注图，账号名称、简介和现成二维码发给你。

English: Design an article-end follow card using my account name, introduction and existing QR image.

## 示例 2

做一张方便分享的方形账号介绍图，使用我提供的真实二维码。

English: Create a square account-introduction image for sharing, using the real QR image I provide.

## 示例 3

先做一张公众号文末介绍底图，二维码位置留空，我之后自己放原码。

English: Create an article-end introduction background with a blank QR area; I will place the original code later.

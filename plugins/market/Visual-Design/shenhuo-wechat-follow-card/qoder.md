# 卡片设计师

本 Plugin 提供神火 AI 的“公众号二维码关注图”服务。岗位只覆盖内嵌能力说明列出的工作，固定调用原设计师，不把相近岗位当作自动切换理由。

## 技能协作

| 场景 | Skill | 交接结果 |
|---|---|---|
| 新需求、补充素材、核对已知事实 | [需求整理](./skills/shenhuo-wechat-follow-card-brief/SKILL.md) | 原始 Brief、事实、授权素材路径、张数与规格、已有任务 ID |
| 账户、上传、理解、追问、方案、生成 | [设计执行](./skills/shenhuo-wechat-follow-card/SKILL.md) | 真实请求和生成回执、凭证类型、结果状态 |
| 查询既有任务、下载、部分恢复、交付 | [结果交付](./skills/shenhuo-wechat-follow-card-delivery/SKILL.md) | 实际图片、未完成项、试用注册邀请或个人项目入口 |

按本次场景读取对应 Skill 后执行，不假定 Skill 已预加载。只有设计执行 Skill 持有客户端与运行状态，其他 Skill 复用它，不重复创建请求、生成或领取凭证。服务端负责设计研究、必要追问和完整创意；客户端按真实状态交付。

只有实际交付图片后才执行设计执行 Skill 中「作品交付后的注册邀请」，按原文展示福利，再展示 invite=QODER 链接；个人 Key 用户使用现有账号。具体步骤以各 Skill 为准。

## 运行依赖

执行前读取 [依赖说明](./CONNECTORS.md)。定位当前插件真实安装目录，按各 Skill 的路径规则执行，不依赖宿主工作目录或 qoder.md 自动注入。没有授权的素材不上传；已有授权和用户明确生成意图直接沿用。

# 商品推广图专家公开能力说明

服务提供方：神火 AI。固定设计师：商品推广图专家，`des_44c1cfe8492e` / `ecommerce_promotion_image`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

服务淘宝、京东、抖音站内搜索、商城推荐和活动商品入口的 1:1 静态商品图，新做与原图优化均可。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 真实当前款商品图，或商品可辨认的待修改推广图
- 实际用途、主要卖点和真实交易信息
- 局部修改范围；仅模糊审美目标时先选择具体方向

## 交付

- 默认一张 1:1 方形推广图片或原图优化结果
- 用户明确需要多候选时，制作有不同侧重点的独立图片

默认 **1.5K / 1:1**，当前默认 1536×1536。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 必须白底无字的首图、完整轮播套图、详情长图、非方形广告或站外信息流
- 店铺装修、直播间物料、视频
- 点击率预测、投放配置、A/B 测试、报表归因与自动迭代

## 领域注意

- 默认单张是领域默认，不设置渠道图片数上限；用户明确数量应保留。
- 旧图上的功效和优惠不自动作为当前有效事实。
- 不能把视觉优化说成已验证提高 CTR；只报告可观察的画面改善。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

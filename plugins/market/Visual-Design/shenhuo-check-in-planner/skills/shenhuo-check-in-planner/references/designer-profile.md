# 打卡计划表公开能力说明

服务提供方：神火 AI。固定设计师：打卡计划表，`des_4e71b08e82d4` / `office_check_in_planner_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

将已确定事项和周期排成可查看、打印或在支持图片批注的工具中填写的计划与记录图片。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 需要记录的事项、周期，以及预填内容或留空要求
- 真实月历需年份、月份和星期起始规则；假期信息需地区
- 可选已有安排、参考表格与必须保留的文字

## 交付

- 日周计划、习惯打卡、阅读记录等静态图片
- 在明确年月条件下的月计划图片

默认 **1.5K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 提醒、自动考勤、统计、日历同步、公式和交互表单
- 可编辑电子表格、可填写 PDF、预填虚构完成记录
- 医疗、饮食、运动或行为治疗方案

## 领域注意

- 真实月历日期、格数与星期须核对；连续次数表不冒充自然月。
- 空白记录不预填勾选、成绩、签名或完成率。
- 默认数字图不等于 A4/A3 印刷或纸面书写质量已验证。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

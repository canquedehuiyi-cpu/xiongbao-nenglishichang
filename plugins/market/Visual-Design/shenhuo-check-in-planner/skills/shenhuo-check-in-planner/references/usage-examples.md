# 打卡计划表使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

做一张一周习惯打卡表，我来提供要坚持的事项，记录格先留空。

English: Create a weekly habit tracker from the activities I provide, leaving the tracking cells empty.

## 示例 2

帮我做一张每日计划图片，留出重点任务、待办和当天复盘的填写空间。

English: Create a daily planner image with writing space for priorities, tasks and reflection.

## 示例 3

给我做一张阅读记录卡，书名、作者、摘句和感想都留空让我填写。

English: Create a reading log image with blank fields for the book, author, quotations and reflections.

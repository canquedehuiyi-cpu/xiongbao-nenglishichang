# 电商竖版海报使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

这个商品刚上新，帮我做一张竖版海报，照片和商品资料发给你。

English: Create a portrait launch poster using the product photos and information I provide.

## 示例 2

把这次商品促销做成一张竖版海报，准确价格、活动时间和适用条件我来提供。

English: Create a portrait promotion poster using the exact prices, dates and conditions I provide.

## 示例 3

为这个商品系列做一组有统一气质的竖版主题海报，各张侧重点由你安排。

English: Create a consistent series of portrait product-theme posters with a distinct focus for each image.

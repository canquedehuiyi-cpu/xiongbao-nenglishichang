# 电商竖版海报公开能力说明

服务提供方：神火 AI。固定设计师：电商竖版海报，`des_4d00ac0bc035` / `ecommerce_portrait_poster`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

国内通用商品上新、促销、季节礼赠与品牌专题的完整竖向宣传图片。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 商品或商品主题、推广目标与真实活动信息
- 准确展示实物时提供可辨认商品照片；纯文字活动图可无商品照片
- 指定图位时提供当前方向、尺寸及文字要求

## 交付

- 完整竖版商品上新、促销或主题海报
- 有明确用途时的无新增营销文字竖向素材

默认 **1.5K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 商品首图轮播、完整详情长图、横版海报、纯经营通知
- 自动发布投放、可编辑工程、印刷生产文件及平台过审保证

## 领域注意

- auto 仅在竖向范围选择，不自动做横图或方图。
- 默认新增文案中文，用户明确外语要求时可译写并重排。
- 纯主题图可无商品照片，准确实物展示必须有实际依据。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

# 跨境电商详情图使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

这是商品照片和说明，帮我安排 Amazon A+ 的静态图片及需要单独填写的模块文字。

English: Plan static Amazon A+ images and any copy for separate module text fields using my product photos and information.

## 示例 2

这款商品需要一组英文详情图，实际图位、尺寸和商品资料我发给你。

English: Create English product-detail images using the actual placements, sizes and product information I provide.

## 示例 3

我的独立站已有标题和正文，帮我根据页面截图制作配套商品图片。

English: Create matching product images for my store page, using screenshots that show the existing headings and body text.

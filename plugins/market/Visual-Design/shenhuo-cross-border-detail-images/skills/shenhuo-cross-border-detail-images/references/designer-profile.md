# 跨境电商详情图公开能力说明

服务提供方：神火 AI。固定设计师：跨境电商详情图，`des_4c71fe5811e3` / `cross_border_ecommerce_detail_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

围绕海外买家购买疑问组织商品详情图及必要图片外文字，按 A+、Temu 或独立站实际容器分工。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 真实商品照片、说明、参数、包含物与必要动作素材
- 目标详情页面、模块或可读截图，以及影响交付的规格
- 明确语言要求可选；默认新增文案英文

## 交付

- 场景、细节、尺寸、步骤或系列选择的独立静态详情图片
- 需要时提供给页面独立文字区的对应标题、正文与顺序说明

默认 **1.5K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 商品首附图整套图库、独立广告海报
- 网页开发、后台上传、交互、视频、可点击比较表与可编辑工程
- 平台审核保证或虚构性能认证

## 领域注意

- A+ 图片与独立文字区分开，不能把模块装配说成已完成网页。
- 真实信息也不一定允许进入特定 A+ 位置；价格、促销、外链等按实际模块限制处理。
- 精确后台尺寸须核生成规格；普通 auto 不承诺任意尺寸混用。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

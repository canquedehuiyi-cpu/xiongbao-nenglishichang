# 跨境电商主图公开能力说明

服务提供方：神火 AI。固定设计师：跨境电商主图，`des_b68ae1262ec7` / `cross_border_ecommerce_main_image`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

面向海外商品图库的首图与互补副图，依据真实 SKU、实际图位与明确语言制作。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 足以识别在售款的真实商品照片和资料
- 需要上图的准确规格、包含物或使用关系
- 平台、站点与具体首图/副图规则仅在影响交付时补充

## 交付

- 默认 1:1 的独立商品首图
- 实际需要的场景、细节、尺寸、配件或语言版本副图

默认 **1.5K / 1:1**，当前默认 1536×1536。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 完整详情或 A+ 模块、活动海报、横幅及广告组合资产
- 网页建设、视频、自动上架投放及审核保证

## 领域注意

- 新增默认英文不等于必须加字，不覆盖商品原字样；图位不允许文字时输出无新增字。
- 适用原图可直接沿用，不计作新生成成果；不能用旧图凑用户明确的新增数量。
- 平台规则各自判断，不能把 eBay/Google 附图都当允许文案的 Amazon 副图。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

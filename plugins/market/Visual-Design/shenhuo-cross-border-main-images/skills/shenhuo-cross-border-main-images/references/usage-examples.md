# 跨境电商主图使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

帮这款商品做一张跨境平台首图，商品照片和实际平台图位我发给你。

English: Create a listing hero image for this product using the photos and exact platform placement I provide.

## 示例 2

这款商品准备卖到海外，帮我安排互补的场景、细节和规格图片。

English: Plan complementary lifestyle, detail and specification images for this product sold overseas.

## 示例 3

把这张商品说明副图改成我指定的语言，商品和包装原字样保留。

English: Change this supporting product image into the language I specify while preserving the product and original packaging text.

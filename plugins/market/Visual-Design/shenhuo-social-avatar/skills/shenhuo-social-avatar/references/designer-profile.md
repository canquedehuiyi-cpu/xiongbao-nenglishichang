# 社交媒体头像公开能力说明

服务提供方：神火 AI。固定设计师：社交媒体头像，`des_ecfe4f4eb672` / `avatar_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

面向需要个人、宠物、角色或品牌社交头像的用户，重点是主体识别、多图角色绑定与小尺寸构图。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 人物、宠物或品牌原图；也可用明确文字描述原创形象
- 使用平台、希望保留的特点和风格偏好；多主体需说明身份与关系

## 交付

- 独立头像图片，通常采用背景铺满四角的方形构图，为平台后续裁切留空间
- 按需要生成风格化、人宠合照或统一视觉系列；张数依用户要求或创意决定

默认 **1.5K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 不提供证件照合规判断、生物识别或身份认证
- 不制作动态头像、可绑定3D模型、完整海报或平台界面
- 不承诺强风格化后像素级身份一致

## 领域注意

- 通常交付完整方形成图；不把平台圆形显示理解为生成透明四角或圆形蒙版。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

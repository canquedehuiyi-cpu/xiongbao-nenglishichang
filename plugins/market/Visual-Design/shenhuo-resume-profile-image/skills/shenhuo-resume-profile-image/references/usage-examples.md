# 神火简历图片设计使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

把我的教育和项目经历做成一张简历图片，资料发给你，不用编写新经历。

English: Turn my education and project details into a resume image without inventing experience.

## 示例 2

帮我做一张用于活动介绍的职业简介图片，工作经历和照片在附件里。

English: Create a professional profile image for an event using my career details and optional photo.

## 示例 3

给孩子做一张课堂自我介绍图片，写名字、兴趣和愿望，其他个人信息不放。

English: Make a classroom self-introduction image with the child's name, interests and aspirations, leaving out other personal details.

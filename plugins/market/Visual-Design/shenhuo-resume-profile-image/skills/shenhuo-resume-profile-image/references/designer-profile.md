# 神火简历图片设计公开能力说明

服务提供方：神火 AI。固定设计师：简历简介，`des_0b46285498ef` / `office_resume_profile_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

面向需要视觉简历、职业简介或课堂介绍的用户，以真实经历和信息层级完成可阅读图片。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 真实教育、项目、工作经历、日期、工具技能与需要展示的内容
- 介绍用途和目标读者；照片及公开联系方式仅按需求提供

## 交付

- 固定纵向1312×1856的数字简历或个人简介图片
- 可整理已有简历版式或修改指定内容，儿童介绍分开呈现兴趣、已会能力与愿望

默认 **1.5K / custom**，当前默认 1312×1856。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。 custom 的宽高由服务端读取此固定设计师的真实默认规格，不把其他专家的尺寸套入本任务。

## 不提供或不承诺的服务

- 不交付可编辑Word、可选文本PDF、ATS兼容文件或个人网页
- 不虚构学历、任职、成果、技能与推荐人
- 不实际求职投递、不保证筛选和录用、不默认公开儿童隐私

## 领域注意

- 1312×1856只是近似A4比例的数字默认，不能称为A4 300ppi印刷稿。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

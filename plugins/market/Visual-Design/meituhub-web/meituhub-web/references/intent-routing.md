## 场景进入与任务范围

用户不必说出插件名、Skill ID 或“使用美图”。当请求需要本插件能完成的结果，或一个明确子任务需要该结果时，可选择相应业务技能；先按目标产物、输入类型和当前任务语境判断。

description 用于发现技能；本文件用于选中后的分工，不假定尚未加载的正文能代替发现。不要把只解释概念、改一个字或修纯逻辑 bug 的请求扩成素材生产。

复合任务选一个主流程，按实际缺口调用必要辅助技能，同一素材复用已有有效任务记录。同类能力同时可用时按当前语境选择一个实现，不让多个插件重复生产或重复计费。缺少影响制作的关键信息才补问，不要求用户先学会技能术语。

影像生成、编辑与图片理解仍通过包内 meitu-ai。技能命中只决定采用哪套流程，不等于已经登录、已经提交生成或允许超出用户要求上传文件。继续遵守原有权限、额度、失败取回和原件保护规则。

## 相邻能力怎样分工

- PPT / 汇报 / 课件语境的配图与网页演示由演示流程承接；产品页面、操作原型和界面资源由网页流程承接。没有语境但两者均可做的 HTML 演示，只选择一个可用入口。
- 游戏人物、场景、UI 与宣发素材按游戏资产流程；普通界面图标与无真人参考的插件职业头像按网站配图流程；用本人照片保持身份生成新写真按写真流程。
- 已有人像要求综合光色后期走人像精修；单人皮肤美化走人像美颜；多方向调色或需要 XMP 走调色方向；旧照损坏走老照片修复。
- 照片只需更高像素或专项清晰度走超清；噪点、暗光、压缩等综合问题走画质修复；尺寸与构图适配不等同于超清。
- 大批照片挑选走批量选片；用户已经明确选中的文件只需归档时，按清单处理，不再上传重选。

以上是场景分工，不构成安装其他插件的依赖；当前插件可独立完成自身已声明的任务。只有实际可用且确有必要时才使用其他已安装技能。

## 本插件常见说法与处理补充

### 整体网站设计

常见请求：“给这个工具做一个能展示功能的首页。”；“我需要一个摄影作品集，客户能在手机上看。”。

产品首页、活动页和作品集按访问者的真实下一步规划；视觉页面可作为开发任务的子任务进入，不要求用户先说插件名或设计术语。

### HTML演示

常见请求：“做一个能点的产品演示，给客户看预约流程。”；“把这套方案做成网页讲解，能翻页也能点开细节。”。

产品演示中区分真实接口与模拟交互；按用户要展示的路径制作，不因 demo 一词擅自补账户、支付或后台系统。

### 网站与小程序互转

常见请求：“把这个 H5 的首页和详情页搬成小程序。”；“这个小程序想加一个浏览器能看的版本。”。

迁移先盘点布局、内容、路由与平台接口，视觉资源按目标比例处理；仅搬运现有文件或保真迁移时复用有效素材。

### 图像尺寸与构图适配

常见请求：“这张横图改成手机首屏用的竖图，人物别裁掉。”；“给这张产品图左边扩一点，放标题。”。

裁切或等比缩放优先做保真几何处理；需要补画、改变主体构图时使用美图，明确新增区域，不把尺寸变换说成画质恢复。

### 整站风格转换

常见请求：“这个网站像默认模板，换成有品牌感的样子。”；“保留所有功能，把电脑和手机版统一成杂志风。”。

“高级一点”先结合现有内容提出具体方向；局部重设计只处理相应页面与视觉槽位，不扩成整站重构。

### 网站配图生成

常见请求：“给这五个插件各做一个图标，风格统一。”；“做一张产品 banner，再配两个空状态插画。”。

图标和职业头像按同系列配色、形状语言和安全区制作，交付实际尺寸并检查小尺寸；横幅与空态插画按使用槽位组织。素材独立需求可直接交付文件，不强制新建网页。

### 首屏动图与产品短视频

常见请求：“首页这张产品图做成五秒循环视频。”；“给作品页加点滚动动效，兼顾手机和静态回退。”。

先区分影像内容运动与 CSS/交互动效；只要求代码动效且可复用现有素材时不强加无关视频生成。

### 网页复刻

常见请求：“按这张截图把网页搭出来，换成我的产品内容。”；“照着这个网址还原首页和菜单交互。”。

仅有截图时记录无法观察的交互；参考站图片如不适合直接使用，依据用户主体生成替代素材，布局还原与内容授权分开。

### 小程序生成

常见请求：“做个作品展示小程序，首页能点进详情。”；“我想做一个预约小程序，先把页面流程做出来。”。

目录与预约原型只展示用户确认的内容和流程；真实下单、短信、预约写库须在明确接口与授权后接入，不用假成功提示代替后端。

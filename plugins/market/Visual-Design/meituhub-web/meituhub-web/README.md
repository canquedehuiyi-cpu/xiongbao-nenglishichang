# 网页设计·MeituHub

![插件头像](assets/plugin-icon.png)


把资料和参考页面做成能打开、能点击的网页。支持网站设计、风格改版、网页复刻、配图动效和小程序制作，交付源码与预览。

## 可以做什么

| 技能 | 用途 |
| --- | --- |
| 整体网站设计 | 根据用途与内容规划网站结构，制作配图、响应式页面和基础交互，交付可运行源码及电脑、手机端预览。 |
| HTML演示 | 把资料变成带动效的翻页演示或可点击的产品流程演示，提供目录、翻页和播放控制，适用于网页讲解与在线展示。 |
| 网站与小程序互转 | 将网站或小程序的内容与交互迁移到另一端，交付目标源码、功能差异说明和手机框内可点击预览；平台专属能力逐项核对。 |
| 图像尺寸与构图适配 | 将同一主视觉适配电脑首屏、手机和卡片等尺寸，按主体位置裁切、扩图或调整构图，保留重要内容与文字空间。 |
| 整站风格转换 | 保留网站内容与功能，重新设计配色、字体、版式和图片风格，让首页、内页与手机端保持统一。 |
| 网站配图生成 | 为网站、App 展示界面和小程序制作图标、职业头像、产品配图、横幅与插画，统一系列风格，交付素材或接入页面。 |
| 首屏动图与产品短视频 | 用产品图或主题素材制作首屏动图、产品短视频和代码动效，交付成片、封面及网页接入，支持播放控制与静态回退。 |
| 网页复刻 | 根据可查看的网址、截图或设计稿还原页面布局、图文层级与可观察交互，替换为用户自己的内容，交付源码和差异说明。 |
| 小程序生成 | 从需求制作小程序页面、导航和视觉素材，交付目标平台源码及手机框内可点击预览，明确原型与真实接口的范围。 |

## 这样开始

- 做一个给商业客户看的摄影作品集，风格简洁，使用我提供的照片。
- 保留这份网站的内容和功能，重新设计首页与手机端布局。
- 按这张参考做网页，主体用我的产品图，补一段首屏动效。

## 安装与运行

在 Qoder 的插件入口导入本包 ZIP。每包自带 MeituHub 接入，无需 MCP 或另装基础插件；首次使用按提示连接账户，实际调用可能产生用量。

版本 0.4.0。包结构与本地辅助工具已检查，尚未完成 Qoder 安装、自动路由和真实业务调用验收。具体服务以当前账户工具目录为准。PPTX 编辑与预览、XMP 导入、原生小程序运行需相应宿主工具；源码与预览不等于已上线。原文件保留，产物另存。

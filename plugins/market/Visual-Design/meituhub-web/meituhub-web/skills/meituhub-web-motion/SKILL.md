# 首屏动图与产品短视频

## 适用请求

制作网页首屏动图、产品短视频、循环背景和界面动效，并接入页面。适用于让首页动起来、产品图做几秒视频、做 GIF、加滚动或悬停动画；真实影像生成走美图，代码动效可本地实现，按交付需求选择。

按 [场景识别与分工](../../references/intent-routing.md) 处理常见说法和相邻任务。用户无需点名插件；选择后仍按下面的实际流程、输入要求与失败处理执行。

## 开工前先确认

必须先读 [需求确认](../../references/need-confirmation.md)。复用已有材料与决定，只补问缺失且影响结果的事项：**实际位置/用途、主体素材、时长/比例、镜头方向与声音需求**。

可按缺口这样问（不是固定问卷）：“用于首页循环背景还是产品短片？镜头希望安静展示还是突出操作过程？”

先确认关键帧和动作方向再生成视频；未指定声音不擅自加解说或音乐。 没有收到关键回答时，只做只读盘点和方案建议，不先提交生成/编辑或开始依赖该决定的制作。已明确的信息与已委托的选择不重复询问。

## 执行约定

先读 [插件规则](../../rules/meitu-only.md) 和 [MeituHub 接入](../meitu-ai-web/SKILL.md)，再按本技能执行。所有路径相对当前技能或插件根目录解析。开始前读取输入并确认范围；生成后打开真实结果检查，不能凭任务成功判断质量。只在实际完成时标 completed；缺素材、服务或预览环境时注明 partial/blocked 和影响项。


1. 明确是微交互、局部动画、完整动态作品还是导出视频；记录目标元素、故事顺序、时长、触发、声音要求和静态回退。不限于首页。
2. 完整动态作品默认包含至少一段真实 MeituHub 生成视频和有内容作用的代码动画，置于同一时间轴或交互作品。先有适用原图则复用；缺关键帧则按 `meituhub-web-assets` 生成。纯代码、纯视频或局部修复按用户明确范围，不强加另一路。
3. 用 meitu-ai 发现视频命令与帮助，实际生成并下载；宿主编排字效、图形、转场和同步，不用 CSS 渐变冒充生成视频。背景视频不自动加声音。
4. 用统一时间基准处理播放、暂停、拖动、重复进入和后台恢复，避免累积多个计时器。尊重减少动态，静态内容完整；失败媒体有可读回退。
5. 实际播放开始、中间、结尾及关键转场。有音频时实际听检；未听不能称音画验收。用户要 MP4 就交真实导出文件，网页录屏方案或时间轴代码不算导出成功。

显示名使用“首屏动图与产品短视频”，同时保留原包网页任意区域的动效与代码合成能力。需要接入网页时交付可播放视频、封面和实际接入；只有视频文件不等于网页接入完成。

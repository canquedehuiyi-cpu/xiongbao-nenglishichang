# 图像尺寸与构图适配

## 适用请求

为已有图片裁切、扩图或重构构图，适配网页首屏、手机、横幅、头像与卡片尺寸。适用于横图改竖图、改成 1:1、商品被裁掉、给标题留空间、多端同图适配；与仅提高清晰度分开，按需要保留主体或调用美图补画。

按 [场景识别与分工](../../references/intent-routing.md) 处理常见说法和相邻任务。用户无需点名插件；选择后仍按下面的实际流程、输入要求与失败处理执行。

## 开工前先确认

必须先读 [需求确认](../../references/need-confirmation.md)。复用已有材料与决定，只补问缺失且影响结果的事项：**目标比例/使用位置、必须完整保留的主体、允许裁切还是补画背景**。

可按缺口这样问（不是固定问卷）：“最终放在哪个位置或要多大尺寸？主体需要完整保留吗？”

已给比例与保真范围即可处理；多规格先检查最难的一种。 没有收到关键回答时，只做只读盘点和方案建议，不先提交生成/编辑或开始依赖该决定的制作。已明确的信息与已委托的选择不重复询问。

## 执行约定

先读 [插件规则](../../rules/meitu-only.md) 和 [MeituHub 接入](../meitu-ai-web/SKILL.md)。所有影像生成、编辑和图片理解必须通过包内启动器使用美图能力，不调用全局 CLI 或其它生成服务。执行前发现当前能力并阅读帮助；已有 task_id 先等待，不重复提交。

实际读取输入，按用户已明确的范围执行；关键方向缺失才补问。生成后打开真实结果复核，原件不覆盖；服务或检查未完成就列明缺口，不假称全部通过。

1. 读取原图，记录每个目标槽位的像素、比例、主体完整性、文字安全区和是否允许补景。未知且影响构图时补问，不拉伸图片凑比例。
2. 等比缩放和可保主体的裁切可做确定性本地处理；需扩图、主体重构或补全内容时，必须通过美图当前可用的 image-transform/image-edit 等能力执行，先读工具帮助，不猜参数。
3. 真实人物、商品、Logo 和原有文字保留；不能从“适配尺寸”推导换主体、改服装或新增场景信息。用户禁止生成时，只做合法裁切/缩放，尺寸与保真不能兼得则说明冲突。
4. 每个目标实际导出一份文件，保留高质量原件；分别查看桌面、手机和卡片中的裁切焦点。输出像素与比例用文件读回核对，不以模型的成功回执代替。
5. 交付适配文件、尺寸清单与使用位置；处理方式留在内部记录，用户询问或影响使用时再说明。局部适配不额外造网站、不重复生成无关图。

# 网页复刻

## 适用请求

根据网址、截图、设计稿或录屏复刻网页的布局、视觉和可观察交互，交付源码与差异说明。适用于照着这张图做网页、还原这个页面、做类似的网站；需可查看的参考，未观察到的后台和接口不猜测。

按 [场景识别与分工](../../references/intent-routing.md) 处理常见说法和相邻任务。用户无需点名插件；选择后仍按下面的实际流程、输入要求与失败处理执行。

## 开工前先确认

必须先读 [需求确认](../../references/need-confirmation.md)。复用已有材料与决定，只补问缺失且影响结果的事项：**参考URL/截图、复刻页面与交互范围、替换素材和文字**。

可按缺口这样问（不是固定问卷）：“需要还原哪些页面和可见交互？内容沿用参考还是换成你提供的？”

只复刻明确范围；参考的隐藏功能不能猜造，已有风格无需再问。 没有收到关键回答时，只做只读盘点和方案建议，不先提交生成/编辑或开始依赖该决定的制作。已明确的信息与已委托的选择不重复询问。

## 执行约定

先读 [插件规则](../../rules/meitu-only.md) 和 [MeituHub 接入](../meitu-ai-web/SKILL.md)，再按本技能执行。所有路径相对当前技能或插件根目录解析。开始前读取输入并确认范围；生成后打开真实结果检查，不能凭任务成功判断质量。只在实际完成时标 completed；缺素材、服务或预览环境时注明 partial/blocked 和影响项。


1. 实际打开参考或查看截图。记录可见的版式、字体层级、颜色、图片焦点和交互；看不到的页面与动态不猜测。确认忠实复刻范围与允许替换的内容。
2. 使用用户有权使用的素材；用户自身品牌不被参考品牌覆盖。建立参考与目标的槽位映射，区别真实内容和演示占位。
3. 对缺少且允许替代的视觉，通过 `meituhub-web-assets` 调用美图生成或编辑，再放回对应位置。忠实复刻且原件齐全时，不为调用改坏原件；记录这项保真边界。缺真实产品原图时不合成假产品冒充实物。
4. 实现可运行页面与约定交互。按相同视口并排比对布局、留白、字阶、裁切、颜色和手机端；截图不能证明交互一致。
5. 交付工程、实际预览与差异说明。仅实现可见区域时明确范围，不称完整站点复刻。

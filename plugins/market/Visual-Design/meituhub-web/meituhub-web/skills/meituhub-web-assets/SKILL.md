# 网站配图生成

## 适用请求

生成和编辑数字界面的图标 icon、应用或插件头像、网站插画、封面、横幅 banner、背景和产品场景图。适用于做个图标、缺一张配图、给页面加视觉、做一套头像；网页、App 展示界面或小程序均可使用，不要求先存在网页工程。PPT 专属配图优先按演示语境处理。

按 [场景识别与分工](../../references/intent-routing.md) 处理常见说法和相邻任务。用户无需点名插件；选择后仍按下面的实际流程、输入要求与失败处理执行。

## 开工前先确认

必须先读 [需求确认](../../references/need-confirmation.md)。复用已有材料与决定，只补问缺失且影响结果的事项：**图片/图标/头像的用途、尺寸/数量、主体与品牌风格**。

可按缺口这样问（不是固定问卷）：“这套图主要放在哪里？希望偏摄影、插画还是扁平角色？有哪些品牌色必须沿用？”

系列先做一张；已经确认的系列继续生产不重复提问。 没有收到关键回答时，只做只读盘点和方案建议，不先提交生成/编辑或开始依赖该决定的制作。已明确的信息与已委托的选择不重复询问。

## 执行约定

先读 [插件规则](../../rules/meitu-only.md) 和 [MeituHub 接入](../meitu-ai-web/SKILL.md)，再按本技能执行。所有路径相对当前技能或插件根目录解析。开始前读取输入并确认范围；生成后打开真实结果检查，不能凭任务成功判断质量。只在实际完成时标 completed；缺素材、服务或预览环境时注明 partial/blocked 和影响项。


1. 从实际页面、目标平台或用户给出的素材用途取得尺寸、比例、裁切焦点、文字安全区和保真主体；不要求先有网页工程，只要素材时不额外造网站。图标与职业头像明确系列风格、背景和交付尺寸，已有品牌色直接复用。
2. 从零画面走 text-to-image；参考/底图改造走 image-edit；透明主体走 image-cutout；清晰度问题走 image-superres-enhance。读取帮助后执行；需要背景补全时先确认允许生成原图以外的内容。
3. 同比例缩放、压缩和不损主体的几何裁切可本地完成；不能拉伸图片，也不能用棋盘格冒充透明。先保留高质量原件，再输出适合页面的版本。
4. 逐项打开核对：主体一致、边缘自然、文字区干净、像素足够、系列配色一致。图标和职业头像另看 48px / 64px 预览，检查面部、工具和裁切安全区，不在小图里塞文字。桌面和手机可以采用不同构图，不一张图硬裁到底。
5. 新建网页的必需生成素材须确实通过美图并在页面中可见；记录任务、文件、槽位与检查。单纯下载、挂在隐藏元素中或填占位 URL 不算接入。

仅调整已有图片尺寸与构图时，调用本包 `meituhub-image-adapt`；本技能负责内容生成与图像编辑。

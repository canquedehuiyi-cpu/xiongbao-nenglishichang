# 证件照设计师公开能力说明

服务提供方：神火 AI。固定设计师：证件照设计师，`des_01da03a33470` / `driver_license_photo_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

以真实本人照片为身份依据，区分正式提交、报名和简历形象用途，只做实际要求允许的照片处理。

## 输入

本设计师必须有用户提供的相关原图。先复用已授权且合用的素材；缺图时只补必要原图，不能以虚构素材 ID 或纯文字绕过上传。

- 清晰可辨认的本人头肩照片
- 接收方的用途、尺寸、背景、文件要求及允许编辑范围
- 必须保留的眼镜、痣、疤痕和其他身份特征

## 交付

- 允许范围内的换底、裁切、光色整理照片
- 适合简历或工作形象的自然头肩图片
- 不具备处理条件时的最少补拍建议或规格整理说明

默认 **2K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 不保证政府、考试、签证或其他接收方审核通过
- 不制作身份证件版面、证件号码、印章或二维码
- 不对禁止 AI 编辑的照片做生成式修饰，不凭空补造身份特征

## 领域注意

- 正式用途先核对接收方真实要求；无编辑许可时只给补拍和规格建议。
- 不可将生成结果宣称为官方合规或保证过审；最终像素、格式与文件大小要按实际导出检查。
- 来源未开放研究工具，不宣传自动查询所有官方要求。

# 神火设计公开能力说明

服务提供方：神火 AI。固定设计师：神火设计，`des_c32930a73414` / `default_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

固定调用 PRD 神火设计本身，面向有图片创意、图文编排或改图需求的用户，提供通用静态视觉设计。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 用途、主题、需要准确出现的文字与保留项
- 可选的原图、主体素材、品牌资料与风格参考
- 用户明确要求的图片数量和规格；未指定数量由设计师按需求决定

## 交付

- 海报、内容配图或其他静态设计图片
- 基于原图的局部修改与构图调整
- 围绕本次图片的简短设计说明

默认 **1.5K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 不在客户端伪装成设计师分诊、转接或自动调度其他专家
- 不承诺可编辑 PPTX、矢量源文件、工程图或可运行应用
- 不把网页、包装或空间的概念图当作完成上线、生产或施工

## 领域注意

- 发布正文涉及多类设计，但平台、工程和编辑源文件能力不能由视觉示例推定。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

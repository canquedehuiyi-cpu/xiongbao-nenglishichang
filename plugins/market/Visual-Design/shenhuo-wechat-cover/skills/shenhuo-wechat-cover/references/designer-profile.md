- 固定设计师：公众号首图，`des_73dfd41fc547` / `wechat_primary_cover_designer`。
- 该文件仅描述公开服务边界，不含神火内部 Designer Skill 或提示词。

## 主推需求

- **文章封面**：依据文章真实主题和可说内容，把标题与相关场景组织成独立宽幅首图。可用于阅读生活、经验知识、栏目介绍和真实阶段回顾等文章入口。
- **活动推广**：用已确认活动、课程、产品上新或推广资料表达主题，价格、时间、适用条件和必要品牌信息有依据才上图；不靠模板补造优惠或效果。
- **通知公告**：把营业、服务、招聘等真实事项的主题和关键安排讲清楚，不混淆暂停、恢复、延期及其他状态，不把完整通告挤进首图。

节令问候、公益和其他符合发布能力的文章主题也可承接。交付每张都是独立完整首图；多张不自动组成长图、九宫格或首图加次图拼版，不默认附目录、正文页或总结页。

## 素材、标题与文章链接

接收原始需求、标题、正文或文档、公开文章链接，以及授权照片、商品图和 Logo。普通文字主题没有照片也可开始；需要真实身份时提供相应清楚原图。资料充分时直接交由神火，不要求先填设计问卷或选图文位置。

长标题可在不改变原意的前提下提炼；明确要求逐字保留的标题不擅改。名称、日期和必要条件保持准确，不把模板中的价格、资历、效果或活动现场移作本次事实。原图字样与新增文字分清，读不清的原字不猜写成事实。

公开链接按服务端规则读取，不能承诺所有页面可读。遇到登录、动态内容、PDF、图片型正文或读取失败，只有文章主旨无法确定时才补充必要正文或摘要；不绕过限制或假称看过全文。已有资料足够时可以继续，网页文字不等于已查看网页图片，URL 也不作为上传图片资产。

## 规格与体验

默认 **1.5K / custom**，命令显式传 `--resolution 1.5K --aspect-ratio custom`；当前服务端默认宽高为 **2256×960，2.35:1**。custom 会沿用目标设计师当时的默认尺寸，公开客户端不永久锁定像素，也没有 width / height 参数。不用 auto、21:9 或字符串 2.35:1 替代 custom。准确交付尺寸以当次冻结规格及实际图片为准，1.5K 不表示长边只能为 1500px。

这是一张独立首图母图。不同微信入口可能裁切不同，不保证任意方形裁切中全部文字仍完整。独立方形次图是其他设计任务，发布前须检查实际入口的裁切效果。

明确数量原样传 N，未指定保留 auto。试用不另限张数，沿用当前渠道积分及服务端数量校验；额度不足如实说明，不自动减少用户要求，不编造事实凑图。

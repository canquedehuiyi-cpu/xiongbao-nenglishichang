# 公众号图片公开能力说明

服务提供方：神火 AI。固定设计师：公众号图片，`des_be31700a2ac2` / `official_account_image_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

面向公众号编辑和作者，重点处理文章正文、知识解释与栏目成套配图，也可承接发布版覆盖的文章封面。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 文章正文、章节结构或需解释的段落
- 必须准确保留的事实、数字、引用及标题
- 可选的实物照片、栏目规范、品牌与往期图片

## 交付

- 正文插图、解释图、引用卡与分享图
- 统一栏目风格的成套静态图片
- 与实际内容对应的图片安排建议

默认 **2K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 不代写或代发完整公众号文章
- 不承诺公众号 HTML 排版、网页交互或可编辑排版文件
- 不从文章之外虚构新闻事实、数据、客户反馈或统计结论

## 领域注意

- 用正文配图与知识图解定位区别已有公众号首图，不再复制首图专家的卖点。
- 同批若含不同画幅，应按运行时支持拆分规格，不把提示词中的多个比例当作单任务已支持。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

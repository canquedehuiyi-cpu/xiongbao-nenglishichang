# 公众号图片使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

这是公众号文章正文，帮我判断哪里需要配图，并设计对应的图片。

English: Review this WeChat article and design images where they help the reading flow.

## 示例 2

把文章里的这段流程做成清楚的图解，文字和数据以原文为准。

English: Turn this process into a clear graphic, keeping the supplied text and data accurate.

## 示例 3

这几篇文章属于同一栏目，帮我做一组风格统一的配图。

English: Create a consistent set of images for these articles in the same column.

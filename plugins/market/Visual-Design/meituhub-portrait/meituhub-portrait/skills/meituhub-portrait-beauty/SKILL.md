# 人像美颜

## 适用请求

为单人人像或自拍做自然美颜，淡化痘印、改善肤质、提亮气色并控制强度。适用于磨皮、祛痘、去黑眼圈、皮肤细腻一点、自拍美颜；保留五官比例和纹理。合影及整组综合光色后期优先用人像精修。

按 [场景识别与分工](../../references/intent-routing.md) 处理常见说法和相邻任务。用户无需点名插件；选择后仍按下面的实际流程、输入要求与失败处理执行。

## 开工前先确认

必须先读 [需求确认](../../references/need-confirmation.md)。复用已有材料与决定，只补问缺失且影响结果的事项：**单人原图、期望美颜程度和具体项目**。

可按缺口这样问（不是固定问卷）：“想保留皮肤质感做自然美颜，还是明显提亮磨皮？有不希望动的地方吗？”

明确要求自然美颜即可按自然强度执行，不多问；不主动瘦脸或改变五官。 没有收到关键回答时，只做只读盘点和方案建议，不先提交生成/编辑或开始依赖该决定的制作。已明确的信息与已委托的选择不重复询问。

## 执行约定

先读 [插件规则](../../rules/meitu-only.md) 和 [MeituHub 接入](../meitu-ai-portrait/SKILL.md)。所有影像生成、编辑和图片理解必须通过包内启动器使用美图能力，不调用全局 CLI 或其它生成服务。执行前发现当前能力并阅读帮助；已有 task_id 先等待，不重复提交。

实际读取输入，按用户已明确的范围执行；关键方向缺失才补问。生成后打开真实结果复核，原件不覆盖；服务或检查未完成就列明缺口，不假称全部通过。

1. 实际查看原图，确认有人脸、为单人人像且脸部可辨认。多人或人脸太小不能声称单人美颜已适用；不要擅自裁掉其他人，必要时改走用户明确授权的综合精修。
2. 默认自然强度，保留脸型、五官比例、年龄、表情、发型和合理皮肤纹理；加强磨皮、美白只按用户要求。泛泛“修一下”先诊断，不自动瘦脸、开眼或换脸。
3. 读取 meitu-ai 中当前 image-edit 帮助，执行实际参考图编辑；原能力资料使用 image-edit 做美颜，不编造已不存在的 image-beauty-enhance 命令，不锁死历史模型或 skill_name 参数。
4. 提示词逐项描述需要减轻的瑕疵、肤色和强度，合并同张图的美颜需求，避免多次无谓重绘。保持人物身份；不足以辨认的五官不靠生成猜补。
5. 下载后对比毛孔、肤色、眼睛、牙齿、面部轮廓、发际线和背景边缘。塑料肤质、明显漂白、年龄/身份改变都需修正。原图不覆盖，交付实际成片及必要对照。
6. 认证、余额和合规错误按接入规则处理，不换通道、不以降低效果逃避业务失败。批量单人照片逐张留状态，超时等原任务。

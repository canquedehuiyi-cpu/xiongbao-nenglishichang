# 调色方向（XMP）

## 适用请求

根据照片和参考风格制作调色方向、美图样片及 XMP 预设，附中文参数表。适用于调成这种色调、做几版调色、胶片感、统一一组照片颜色、给可导入的调色预设；预设与生成样片不能保证逐像素一致。只有风格讨论时先给建议。

按 [场景识别与分工](../../references/intent-routing.md) 处理常见说法和相邻任务。用户无需点名插件；选择后仍按下面的实际流程、输入要求与失败处理执行。

## 开工前先确认

必须先读 [需求确认](../../references/need-confirmation.md)。复用已有材料与决定，只补问缺失且影响结果的事项：**参考色调、使用软件/素材类型、方向数量与组内光线差异**。

可按缺口这样问（不是固定问卷）：“想往哪种色调走？用于哪款软件和哪组照片，需要一个统一方向还是几种对比？”

先看代表照片的调色方向，再扩预设；不把生成参考图当XMP实测效果。 没有收到关键回答时，只做只读盘点和方案建议，不先提交生成/编辑或开始依赖该决定的制作。已明确的信息与已委托的选择不重复询问。

## 执行约定

先读 [插件规则](../../rules/meitu-only.md) 和 [MeituHub 接入](../meitu-ai-portrait/SKILL.md)，再按本技能执行。所有路径相对当前技能或插件根目录解析。开始前读取输入并确认范围；生成后打开真实结果检查，不能凭任务成功判断质量。只在实际完成时标 completed；缺素材、服务或预览环境时注明 partial/blocked 和影响项。


1. 实际查看已选照片和参考，先写可观察的调色目标，再翻译为 ACR 参数。读取 [摄影后期方法](../../references/retouch-method.md)、[参数映射](references/visual-to-acr.md) 与 [XMP 规则](references/acr-xmp.md)。
2. 用户未指定方向数量时，沿用五个用途不同的方向：主修、自然稳定、明亮通透、氛围风格、困难场景适配；已指定数量则按要求。每个方向说明适用场景，避免只换强度。
3. 方向预览通过 meitu-ai 的 image-edit 实际处理代表图；不得拿本地滤镜图冒充美图样片。只明确要求输出参数/XMP 或禁止上传时可仅交付预设，但说明未生成视觉样片。
4. 使用包内 `scripts/write_acr_xmp.py` 从参数 JSON 写入 XMP（Python 可用时执行；参数文件与输出路径作为独立参数）。默认保存在本次任务目录，不自动安装到 Adobe 系统目录。新版本不覆盖旧文件。
5. 用现有 XML 解析器验证格式、中文名称、分组与 UUID；再在可用的 ACR/Lightroom 验证实际效果。XML 通过不等于 Adobe 导入或视觉匹配通过。美图样片与 XMP 不是同一渲染引擎，明确为调色参考，不承诺逐像素一致。
6. 每方向输出 XMP、完整中文参数表与实际样片（若已生成）。区分可批量同步项和单张曝光、蒙版、修复、裁切。LUT 仅描述全局色调，不能装入磨皮、降噪、颗粒、几何或局部蒙版。

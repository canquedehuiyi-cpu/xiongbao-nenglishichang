# 批量人像精修

1. 接收照片目录或选片清单，逐项确认文件存在。按室外、室内混光、逆光、夜景/闪光等实际条件分组；不把整个目录套同一曝光和白平衡。
2. 读取 [摄影后期方法](retouch-method.md)，每组选择能代表光线的样片。风格已明确直接执行；未明确给少量具体方向，不无故生成五套全量结果。
3. 每组样片必须通过 meitu-ai 实际处理并对比，重点看肤色、白衣高光、暗部与背景颜色。样片方向待用户选择时先停在样片，已授权方向按样片复核后继续。
4. 按当前 batch 帮助或单项方式执行，逐张保存输入、输出、任务与状态。保持原目录相对路径，防止不同子目录同名文件相互覆盖。局部精修单独处理，不把蒙版位置盲目同步到不同构图。
5. 逐张检查主体与文件完整性，分组对照色彩一致性；抽检不能说成全检。中途失败只补失败项，有 task_id 先等待，不重跑成功项。
6. 输出成片、对照、结果清单与未完成项。清楚区分样片、批量成片和未验证照片，不修改原片或顺便淘汰照片。

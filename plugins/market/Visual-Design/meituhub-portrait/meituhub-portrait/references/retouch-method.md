# 摄影后期方法

从原图看曝光、白平衡、动态范围、肤色、噪点、焦点与场景一致性。先说明希望白色、肤色、暗部和背景发生什么变化，再选工具或 ACR 参数，不能从“高级”“通透”直接猜一组数字。

不同光线分组。可复用的是克制的曲线、HSL 与色彩方向；绝对曝光、白平衡、强降噪、锐化、镜头校正通常依图判断。肤色不要被背景颜色牵着走；保护白衣高光，避免阴影拉灰、皮肤磨平、边缘过锐。

局部工作包含脸部亮度、皮肤瑕疵、衣物、背景干扰和裁切。蒙版、修复位置、几何与人像结构不能作为通用 XMP 盲目同步。参考图只提供视觉目标，不改变被修人物的身份。

选片交接可读取 selected_files.txt、manifest.json、分组与建议；没有选片记录也能直接处理用户指定照片。不因为精修要求自动淘汰或删除图片。

交付区分：美图实际成片、ACR 参数、XMP 文件、美图样片与 ACR 实际导入效果。XMP XML 合法不证明 Lightroom 版本兼容；LUT 只能表示颜色和明暗映射，不能包含磨皮、降噪、锐化、颗粒、蒙版或镜头几何。

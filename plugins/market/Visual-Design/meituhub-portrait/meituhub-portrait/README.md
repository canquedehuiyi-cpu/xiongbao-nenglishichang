# 人像精修·MeituHub

![插件头像](assets/plugin-icon.png)


修好光线、肤色和局部细节，保留人物原本的样子。支持单张与整组精修、自然美颜、调色样片与 XMP 预设，也能修复老照片。

## 可以做什么

| 技能 | 用途 |
| --- | --- |
| 人像精修 | 调整人像光线、肤色、局部瑕疵和背景细节，保留脸型、表情与皮肤质感；整组照片按光线分组精修，统一成片色调。 |
| 人像美颜 | 对单人人像淡化痘印、修整肤质并提亮肤色，按要求控制美颜强度，保留五官比例和自然纹理。 |
| 调色方向（XMP） | 根据照片与参考风格制作可比较的调色方向，交付样片、中文参数表和 XMP 预设，并区分批量可同步设置与单张调整。 |
| 老照片修复 | 修复老照片的划痕、褪色和翻拍反光，改善画质；保留人物年龄、衣着、原有文字与场景，可按要求上色或保留黑白。 |

## 安装与运行

在 Qoder 的插件入口导入本包 ZIP。每包自带 MeituHub 接入，无需 MCP 或另装基础插件；首次使用按提示连接账户，实际调用可能产生用量。

版本 0.4.0。包结构与本地辅助工具已检查，尚未完成 Qoder 安装、自动路由和真实业务调用验收。具体服务以当前账户工具目录为准。PPTX 编辑与预览、XMP 导入、原生小程序运行需相应宿主工具；源码与预览不等于已上线。原文件保留，产物另存。

# 神火奖状证书公开能力说明

服务提供方：神火 AI。固定设计师：奖状证书，`des_9e5df35c98e6` / `office_award_certificate_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

面向企业、社团与教育活动组织者，为已确认的荣誉表彰、儿童鼓励和组织聘任设计证书视觉稿。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 获奖者或被聘者、真实奖名或岗位、事由、颁发单位和日期
- 聘书需对应聘期；签名、公章和标志仅在真实提供且明确要求时采用

## 交付

- 依内容选择横向或竖向的数字奖状、荣誉证书与组织聘书图片
- 多人任务按真实姓名与事项分别生成，不把名单混进单人证书

默认 **1.5K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 不制造不存在的学历学位、职业资格、政府许可、录取或经营授权
- 不凭空生成签名、公章或认证标识，不赋予证书效力
- 不提供电子签发系统、可编辑批量证书、印前PDF或防伪文件

## 领域注意

- “聘书”只排版已确认事实，签发日期与任期端点分别呈现。
- 1.5K默认是数字稿，不承诺A4 300ppi或印厂验收；实际印刷需另外核对制作要求。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

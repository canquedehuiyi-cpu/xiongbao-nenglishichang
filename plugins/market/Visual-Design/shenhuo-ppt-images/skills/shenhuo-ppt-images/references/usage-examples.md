# 神火PPT图片设计使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

我准备做一次分享，帮我设计一张 PPT 封面图片，主题和受众我发给你。

English: Design a presentation cover image from the topic and audience I provide.

## 示例 2

把这些材料整理成一页清楚的 PPT 内容图片，重点和真实数据以资料为准。

English: Turn these materials into a clear presentation content image using only the provided facts and data.

## 示例 3

我有一份介绍大纲，帮我制作一组风格统一、每页重点不同的 PPT 页面图片。

English: Create a consistent set of presentation page images from my outline, with a distinct purpose for each page.

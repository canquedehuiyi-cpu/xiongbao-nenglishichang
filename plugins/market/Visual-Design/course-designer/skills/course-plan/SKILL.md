# 学习目标与课程安排

将“要讲什么”转为“学员完成后能做什么”，交付可落实到教学活动的课程计划。

## 工作流程

1. 确认学员角色和已知基础、岗位任务、可用时长与业务来源。关键项缺失时提出具体问题；可按显式假设先给草案，但不能将假设当作已确认学员信息。
2. 读取 [课程计划方法](references/plan-method.md)。把目标写为可观察行动并编号 L01 等，区分必要知识、实际练习和表现证据。不要仅用“了解、熟悉、提升意识”当全部学习目标。
3. 按目标设计解释、示范、学员练习和反馈环节，时间安排与用户总时长相容。时长不足时明确建议缩减的目标范围，让用户决定，不暗自删掉关键岗位责任。
4. 指定每个目标的练习方式、所需资料和参考答案依据；未有业务标准时暂缓需要该标准的答案，不编造操作规范。
5. 提供课程计划、目标与活动对应关系、材料准备项和待确认问题，作为 teaching-kit 的输入。保存实际 Markdown 或交付正文并说明未落盘。

## 验收与边界

逐项核对目标是否有活动和可观察练习，时间是否覆盖完整过程，学员基础是否足以参与。此处是课程设计，不等于实际授课或证明学员已达标；不自动排课、发通知或生成成绩。
业务事实回源到指定材料，引用文档/段落或贴文标题，不伪造页码和培训批准记录。

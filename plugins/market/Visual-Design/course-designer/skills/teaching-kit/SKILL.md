# 讲师材料与学员演练

交付能被讲师采用的教学材料，而非只列课程目录。需要课程目标、学员背景、时长与资料；可从已有课程计划承接，也可在本技能内先形成必要的目标简报。

## 工作流程

1. 读取课程计划和来源，沿用目标编号。缺学员基础或业务规则会改变答案时先补问，或将受影响部分明确标为待定，先完成有依据的材料。
2. 读取 [讲师材料方法](references/kit-method.md)。为每个目标写解释、示范、提问与反馈提示；保留真实角色、条件和业务限制，不为了故事顺畅改写产品事实。
3. 编写学员练习，包含情境、已知材料、要完成的任务和可观察交付。练习与讲师参考答案分开，答案说明判断依据及可接受的不同表达。
4. 设计容易混淆的边界情境，并说明讲师如何追问学员理由。材料没有依据的答案不能写成标准；可把补证据或识别未知本身作为练习任务。
5. 检查目标、讲解、练习、参考答案与时间安排互相对应。答案不能让学员凭空猜字段、权限或期限，也不能只照抄题面当作证明理解。
6. 交付讲师提纲、学员练习和单列参考答案，保存 Markdown 到用户任务目录或完整呈现正文，明确未保存或待补内容。

## 边界

所有题目与答案是课程设计稿，不能宣称已实际考试、已有通过率或学员成绩。没有可用格式工具时不声称 PPT/PDF 已生成；不自动外发材料、排课、录分或发证。

# 课程反馈与修订

用新证据修改指定旧课程，保持学习目标、教学活动与练习答案一致。没有实际反馈时可以给出设计建议，但不能称为授课效果结论。

## 工作流程

1. 读取旧课程、目标、讲师和学员材料，以及新的反馈或业务变更。区分讲师观察、学员原话、实际作答与产品事实，保留来源与已知适用范围。
2. 读取 [课程修订方法](references/revision-method.md)。将每条反馈连到目标、活动或题目，区分知识点不清、练习条件不足、时长不够、资料已过时等可能原因；证据不足时列为假设。
3. 对已确认的业务变化同步修改解释、情境和参考答案；对学习问题提出可验证的教学调整。保持总时长与用户要求相容，取舍需要用户决定时说明影响。
4. 实际修改课程材料，交付新版与变更记录，注明原因、受影响目标和计划如何观察改进。未有下次授课数据不写“通过率已提升”。
5. 检查指南式解释、练习和答案是否仍对应当前业务版本；指定材料有部分不可读时如实列出未同步范围，不声称全部完成。

## 保存与边界

在用户任务目录保留旧稿并写出新版，或按明确授权覆盖。无文件工具则完整呈现修改正文并说明未保存。不得伪造学员表现、培训批准、成绩与证书，也不自动安排下一次培训或发送通知。

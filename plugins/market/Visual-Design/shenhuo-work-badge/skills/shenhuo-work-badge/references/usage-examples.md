# 工牌工作证使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

帮我做一张员工工牌图片，机构、姓名、部门和岗位信息发给你。

English: Design an employee badge image using the organization, name, department and role I provide.

## 示例 2

我需要横版的部门身份牌图片，不放照片，把文字排清楚就行。

English: Create a landscape department badge image with clear text and no photo.

## 示例 3

给这次活动做工作人员牌图片，只放活动名称和“工作人员”。

English: Design a staff badge image for this event with only its name and the word “Staff”.

# 电商横版海报公开能力说明

服务提供方：神火 AI。固定设计师：电商横版海报，`des_a5cefbf1bc39` / `ecommerce_landscape_poster`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

覆盖商品推广与电商经营信息的横向静态海报，包括上新、权益、直播预告和发货售后通知。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 商品或经营事项、目标读者与准确文字
- 真实商品展示提供照片；纯优惠或通知可只给文字
- 指定 Banner 或广告位提供实际尺寸、裁切与组件规则

## 交付

- 完整横版商品、活动、直播预告或经营通知图片
- 按具体图位分工制作的无新增文字背景素材

默认 **1.5K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 商品首图轮播、完整详情页、竖方图、整店网页装修和实时直播组件
- 自动上架、投放、可编辑工程或未确认售后政策

## 领域注意

- auto 只做横向；常规 16:9，也可按已支持用途选择 3:2、4:3。
- 约 1.91:1 或固定像素入口不能用近似比例冒充已适配。
- 发货、恢复与到货概念分清，不自行补接单、赔付或退换承诺。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

# 方形LOGO公开能力说明

服务提供方：神火 AI。固定设计师：方形LOGO，`des_f7ecda4a01f5` / `square_logo_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

面向门店、品牌和工作室，制作简洁可辨的方形标志图片或限定范围的旧标调整。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 准确品牌名称、主营业务与希望表达的气质
- 旧标改版需原图；有品牌规范或指定文案时一并提供

## 交付

- 固定1:1独立栅格Logo图片，可为符号、字标或字图组合
- 经明确要求的黑白版、方形适配或局部修改图片

默认 **1.5K / 1:1**，当前默认 1536×1536。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 不提供AI、SVG、EPS矢量源文件、字体文件和完整VI手册
- 不做商标注册、查重或唯一性保证
- 透明通道和精确轮廓复用需实际能力核验，不由提示词直接保证

## 领域注意

- 与既有神火品牌视觉区分：本技能专注方形标志图片，不展开全套品牌视觉应用。
- 禁止把矢量风格外观称为矢量文件；准确名称成图后仍需逐字校对。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

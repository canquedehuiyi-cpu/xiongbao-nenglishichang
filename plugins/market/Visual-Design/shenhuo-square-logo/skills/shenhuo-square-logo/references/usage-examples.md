# 方形LOGO使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

给我的店做个方形Logo，店名和主营业务发给你，想简单好认。

English: Create a simple, recognizable square logo image for my shop using its name and main business.

## 示例 2

给工作室设计一个以名称为主的方形标志，品牌名字和定位发给你。

English: Design a name-led square logo image for my studio using the supplied name and positioning.

## 示例 3

把这个旧Logo整理成方形白底图片，保留图形和名称，四周留白。

English: Adapt this existing logo to a square white-background image, keeping its symbol and name with clear margins.

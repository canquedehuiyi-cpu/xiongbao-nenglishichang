# 神火姓名牌使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

帮我做一张会议姓名牌，我会提供准确姓名和需要显示的职务。

English: Create a meeting nameplate from the exact name and role I provide.

## 示例 2

给孩子做一个课堂姓名标签，我会提供姓名、班级和喜欢的主题。

English: Create a classroom name label using the name, class and theme I provide.

## 示例 3

我要一张上下对折的姓名桌牌展开图，两面都能正常读名字，我会提供每面的比例和姓名。

English: Create a top-to-bottom folding nameplate layout with both outward faces readable. I will provide the face ratio and exact name.

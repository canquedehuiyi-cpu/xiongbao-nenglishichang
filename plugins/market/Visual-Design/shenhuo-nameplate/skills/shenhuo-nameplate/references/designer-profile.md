# 神火姓名牌公开能力说明

服务提供方：神火 AI。固定设计师：姓名牌，`des_dd95a7cefcdc` / `office_nameplate_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

以完整姓名识别为中心的数字姓名牌图片，可做会议、课堂单面及已明确几何的折叠展开。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 准确姓名或席位称谓；职务、班级、拼音按需提供
- 折叠展开任务提供每面尺寸或比例、实际折法
- 需沿用的真实标志或旧牌可选提供

## 交付

- 单面姓名牌或课堂标签静态图
- 明确折法后的双面平铺展开图片

默认 **1.5K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 人员胸牌、完整履历名片、自动座位安排与名单邮件合并
- 已验证印厂刀模、雕刻文件或折叠站立保证

## 领域注意

- 默认单面，不因参考有上下两份就复制双面；展开必须分清旋转与镜像。
- 身份与姓名不从外观推测；拼音尤其多音姓氏需准确依据。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

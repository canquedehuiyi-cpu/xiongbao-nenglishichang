# 写真生成

## 适用请求

基于人物或宠物参考生成职业形象照、头像、生活写真和主题写真，按要求设计服装、场景与光线。适用于用我的照片做一组写真、换成商务形象、给宠物拍主题照；需核对参考身份，不能把无参考的职业插画头像当真人写真。

按 [场景识别与分工](../../references/intent-routing.md) 处理常见说法和相邻任务。用户无需点名插件；选择后仍按下面的实际流程、输入要求与失败处理执行。

## 开工前先确认

必须先读 [需求确认](../../references/need-confirmation.md)。复用已有材料与决定，只补问缺失且影响结果的事项：**身份参考、写真风格/场景、数量与画幅、衣着等可改边界**。

可按缺口这样问（不是固定问卷）：“想拍什么风格、用于哪里？人物哪些特征和服装需要保留？”

多方向先选方向；一套写真先看一张身份与风格样片。 没有收到关键回答时，只做只读盘点和方案建议，不先提交生成/编辑或开始依赖该决定的制作。已明确的信息与已委托的选择不重复询问。

## 执行约定

先读 [插件规则](../../rules/meitu-only.md) 和 [MeituHub 接入](../meitu-ai-culling/SKILL.md)。所有影像生成、编辑和图片理解必须通过包内启动器使用美图能力，不调用全局 CLI 或其它生成服务。执行前发现当前能力并阅读帮助；已有 task_id 先等待，不重复提交。

实际读取输入，按用户已明确的范围执行；关键方向缺失才补问。生成后打开真实结果复核，原件不覆盖；服务或检查未完成就列明缺口，不假称全部通过。

1. 实际查看参考图，确认主体身份、人物/宠物数量、用户要保留的外貌和允许改变的服装、发型、姿态、背景。用途与风格缺失才补问，不让“写真”默认变成陌生人或未经要求的性感造型。
2. 单人、多人人像、宠物、双人合影分别识别。双人合影核对两个人物来源；多余参考图先区分身份/服装/风格用途，不静默丢弃第三张或只拿前两张。
3. 通过 meitu-ai 发现 image-portrait-generate 并查当前帮助；若没有专用入口但 image-edit 确认能承接该任务，可使用同一美图链路。命令、图片数、尺寸和模型以当前帮助为准，不照搬旧凭证或其它宿主设置。
4. 以参考图实际生成，提示词包含主体保真、场景、构图、光线和已授权变化。先做约定样片；方向已明确或用户授权整组时继续，统一人物身份和系列光线，不增加未请求的人物或道具。
5. 逐张核对脸、年龄、发型、手指、身体、衣物和多主体对应关系；合影不漏人不串脸。此结果是生成写真，不宣传成真实拍摄记录；证件用途不保证官方审核通过。
6. 交付真实文件、尺寸与版本，原参考不覆盖。无可用图片或工具不支持时说明缺口，不只给提示词冒充成片。

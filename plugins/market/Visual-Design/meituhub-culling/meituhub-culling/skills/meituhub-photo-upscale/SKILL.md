# 超清

## 适用请求

提升图片清晰度与分辨率，支持人像、商品和文字图的专项检查。适用于图片太糊、变高清、超清放大、老图放大、头像不清楚；交付实际尺寸和前后对照。与划痕修复、单纯改比例和大范围去噪分开，不承诺恢复不存在的细节。

按 [场景识别与分工](../../references/intent-routing.md) 处理常见说法和相邻任务。用户无需点名插件；选择后仍按下面的实际流程、输入要求与失败处理执行。

## 开工前先确认

必须先读 [需求确认](../../references/need-confirmation.md)。复用已有材料与决定，只补问缺失且影响结果的事项：**目标尺寸或输出用途、重点要保留的字标/人脸/细节**。

可按缺口这样问（不是固定问卷）：“主要用于屏幕查看还是打印？有明确尺寸要求吗？”

已经说清如2倍放大就执行；纯超清不另加美颜或换色。 没有收到关键回答时，只做只读盘点和方案建议，不先提交生成/编辑或开始依赖该决定的制作。已明确的信息与已委托的选择不重复询问。

## 执行约定

先读 [插件规则](../../rules/meitu-only.md) 和 [MeituHub 接入](../meitu-ai-culling/SKILL.md)。所有影像生成、编辑和图片理解必须通过包内启动器使用美图能力，不调用全局 CLI 或其它生成服务。执行前发现当前能力并阅读帮助；已有 task_id 先等待，不重复提交。

实际读取输入，按用户已明确的范围执行；关键方向缺失才补问。生成后打开真实结果复核，原件不覆盖；服务或检查未完成就列明缺口，不假称全部通过。

1. 读取原始像素与实际细节，识别人像、商品、文档或通用照片，确认用户主要诉求是变清晰而非仅放大倍数。只要求几何缩放时做对应尺寸处理，不冒称增强细节。
2. 通过 meitu-ai 读取 image-superres-enhance 帮助，传真实输入和内容描述；人像描述保留身份，商品保留形状与标识，文档保留文字。不编不存在的倍数、分辨率或算法参数。
3. 实际运行并下载结果，读取输出尺寸；服务没有达到指定 4K 等目标时如实说明，不凭提示词承诺。逐张保留输入输出和任务状态。
4. 在相同比例查看原图与结果的脸部、发丝、文字、Logo、纹理和轮廓。拒绝明显假纹理、文字变形、过锐和身份变化，不能把猜出的细节称作恢复原始信息。
5. 仅超清不顺便美白、改色、换背景或去物体。还需去噪、暗光或综合修复时转本包“画质修复”，不重复无谓超清。
6. 输出增强图、实际像素与必要对照；原片不变。失败按接入规则处理，任务受理后只等待原任务。

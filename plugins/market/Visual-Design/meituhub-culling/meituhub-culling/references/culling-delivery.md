# 精选归档与后期交接

1. 读取选片记录，核对每个选中项的相对路径、分组、判断理由和真实美图 evidence_id；只接手文件归档时可按用户明确清单复制，但不能声称重新执行了美图选片。
2. 按 [美图选片流程](culling-process.md) 的交付约定区分 selected/rejected/review。未分析、读图失败或证据缺失项必须 review，不自动淘汰。
3. 使用 [归档脚本](../skills/meituhub-photo-culling/scripts/cull_files.py) 的 copy 子命令，将通过复核的照片复制到一个新输出目录。脚本以源目录和选择清单为输入，保留相对路径、拒绝覆盖与越界路径，并写 selected_files.txt 和 manifest.json。新目录必须在源目录之外。
4. RAW 与 JPEG 只有核实同目录、同拍摄文件名对应关系时才作为同一拍摄对交付；每个文件都显式列入清单。不能仅凭相似名称错误关联。源文件永不移动、删除或写评分。
5. 输出结果表：相对路径、组别、状态、理由、代表帧关系、后期建议、实际证据 ID。数量核对要覆盖全部输入，说明失败项和未复核项。Lightroom 星级/XMP sidecar 仅在用户明确要求时另存或写入，不假称已同步软件。
6. 后期建议区分曝光/白平衡、肤色、局部瑕疵和裁切；用户要求继续修图时才进入人像精修流程。用户纠正后重筛相关组，并记录原因，不必重跑无关组。

# 婚礼选片

1. 读取 [美图选片流程](culling-process.md)。区分“精华精选”和“完整交付覆盖”，用户只说精选时默认精华，不把常规过程照全部保留。
2. 按实际素材识别准备、入场、誓言/交换戒指、拥抱、合影、外拍、宴会等环节；不存在的环节不凭空补。先保障关键时刻，再比较重复帧。
3. 每组真实照片经美图图片理解分析并留证；新郎新娘的表情、互动与动作高点优先。纱、花和前景氛围只在主要人物状态合格后加分。
4. 合影看每位关键人物的闭眼、遮挡和嘴形；没有全员合格帧时如实给出最接近的候选与缺陷。换头素材只有用户明确需要时保留，不擅自修图或合成。
5. 强情绪/唯一关键瞬间可保留技术不完美的照片并说明理由。不要让“精华”误删完整交付要求下的环节；最终与目标数量、叙事顺序一起复核，再按 [精选归档](culling-delivery.md) 归档。

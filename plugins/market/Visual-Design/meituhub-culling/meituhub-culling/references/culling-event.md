# 活动与合影选片

1. 读 [美图选片流程](culling-process.md)，确认用途是新闻记录、宣传精选还是完整活动交付。关键人物身份由用户或明确资料提供，不凭面孔猜身份。
2. 按时间、场景和动作连续性分组，通过美图图片理解观察真实候选；检查主体是否清晰、脸是否可见、手势/动作是否到位、现场信息是否足够。
3. 多人合影逐人看闭眼、模糊、遮挡与边缘裁切，输出“哪一处影响选择”的可核对理由。小缩略图无法确认时提交单图或面部区域副本补看，不把看不清记为通过。
4. 避免只留同一机位的讲话照；在用户范围内保留能说明场景的远景、中景、细节与互动。对于演出或纪实不按写真标准淘汰所有动作模糊或非微笑画面。
5. 排除严重干扰与无有效内容的过程帧；必要但技术较弱的记录单列复核。给出最终候选和理由，按 [精选归档](culling-delivery.md) 归档；不修原片、不自动改星级。

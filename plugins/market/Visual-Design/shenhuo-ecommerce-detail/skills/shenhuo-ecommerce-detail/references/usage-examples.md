# 神火电商详情使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

根据我的商品图片和资料，做一套风格连贯的详情图。

English: Create a cohesive set of detail images from my product photos and information.

## 示例 2

帮我做一张详情卖点图，把这款商品的重点讲清楚。

English: Create one detail image that clearly explains this product's key benefit.

## 示例 3

根据我提供的规格和清单，做一张尺寸或套装说明图。

English: Create one size or bundle-content image using the specifications and list I provide.

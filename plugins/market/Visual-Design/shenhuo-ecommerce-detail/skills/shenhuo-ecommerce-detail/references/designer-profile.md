# 神火电商详情公开能力说明

- 固定设计师：电商详情图，`des_031548caecd0` / `ecommerce_detail_v3`。
- 该文件仅描述服务边界和公开交付方式，不含神火内部 Designer Skill 或提示词。

## 适合的需求

- 适用于成组详情图、单张卖点模块、使用和适配说明、尺寸、套装及选型说明。
- 可做单个模块或整套图片；由神火按商品资料安排顺序、内容与数量，不强套固定页序。
- 交付有序的独立图片文件，不承诺网页代码、交互购买组件、自动拼接长图、自动上架或平台审核通过。

## 素材与事实

优先使用用户提供的商品照片、现有文案、规格和套装清单。品牌资产、参考风格图和使用平台属于可选补充；已有内容足够时直接发起请求。未经资料支持的商品参数、结构、颜色、数量、功效、销量和认证不能代填。

如素材缺失会阻断真实商品设计，询问必要素材；其余缺口由神火服务返回追问。Qoder 不提前另做完整提案，不自行替神火决定文案、构图或摄影方法。

## 规格与体验

1.5K、智能比例（请求传 `auto`）。普通模块优先 3:4，允许神火按页面内容调整高度，不强制所有页相同比例。

用户明确数量时原样传 N，未明确时保留 auto。体验成本受服务端当前渠道额度控制，不新增按张限制，不静默缩减用户要求；通用任务/模型的数量边界仍以服务端校验为准。额度不足如实解释，成功图片仍按现有保留规则交付。

## 结果与承接

交付真实成功并下载的图片，说明 AI 生成及实际完成数量，不承诺转化率或绝对保真。试用用户可注册神火后创建个人项目，使用项目管理、后续修改和完整工作台；试用项目当前不自动迁入个人账号。使用个人 Key 创建的项目已归属于该 Key 对应的神火用户，可用同一账号在网站打开现有项目，无需重新注册或重建；具体入口使用回执中的真实 `project_id`，见 [workflow.md](workflow.md)。

# 神火方形海报使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

帮我做一张发朋友圈的方形上新海报，商品照片和介绍发给你。

English: Create a square new-product poster for WeChat using my photos and product details.

## 示例 2

把这次活动做成方形推广图，时间、地点和参加方式在资料里。

English: Turn this event information into a square poster with the supplied time, location and participation details.

## 示例 3

门店要发营业通知，帮我把日期和营业安排排成清楚的方图。

English: Create a clear square business notice using the supplied dates and opening arrangements.

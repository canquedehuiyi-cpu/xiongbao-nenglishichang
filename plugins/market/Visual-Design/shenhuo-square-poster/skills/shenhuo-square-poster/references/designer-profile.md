# 神火方形海报公开能力说明

服务提供方：神火 AI。固定设计师：方形海报，`des_afb52a4f4fb4` / `wechat_square_poster_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

面向门店和运营人员，专做微信朋友圈、客户群与私聊传播的独立方形图片。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 真实主题、商品或活动资料、准确时间与必要条件
- 商品照片和品牌素材按需提供；无实物要求时可只提供文字

## 交付

- 固定1:1方形海报，用于上新、活动、通知或直播预告等数字分享
- 明确多任务时逐张独立出图，主体、条件和行动分层清楚

默认 **1.5K / 1:1**，当前默认 1536×1536。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 不制作横版或竖版专用物料、公众号首图、九宫格拆图与完整电商详情
- 不自动发帖、投放、生成有效二维码或提供印刷制版文件
- 不虚构评价、优惠、工资、库存和效果承诺

## 领域注意

- 与既有神火运营海报区分：本技能固定方形，运营海报可按需求选择多种画幅。
- 需要二维码时只使用提供的真实素材，成图不自动等于扫码通过。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

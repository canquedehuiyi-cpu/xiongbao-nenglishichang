# 神火电商主图使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

用我的商品照片，做一组日常上架的商品主图。

English: Create a set of everyday listing images from my product photos.

## 示例 2

商品首图已经有了，帮我补一张突出真实卖点的轮播图。

English: I already have a main image. Add one gallery image highlighting a supported product feature.

## 示例 3

用我的商品照片做一张使用场景图，放在商品轮播里。

English: Create one usage-scene image from my product photos for the product gallery.

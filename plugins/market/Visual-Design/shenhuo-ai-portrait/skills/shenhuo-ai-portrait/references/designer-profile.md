# 神火AI写真公开能力说明

服务提供方：神火 AI。固定设计师：AI写真，`des_c51cf9f5b8fe` / `ai_portrait_designer`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

以真实人物或宠物原照为身份来源，围绕日常、纪念与形象展示创作生成式写真图片。

## 输入

本设计师必须有用户提供的相关原图。先复用已授权且合用的素材；缺图时只补必要原图，不能以虚构素材 ID 或纯文字绕过上传。

- 清晰的本人、家庭成员或宠物原照与主体对应关系
- 主题、场景、服装偏好及明确不要改变的特征
- 可选的姿态或风格参考，以及用户要求的照片数量

## 交付

- 个人、家庭或宠物的主题写真图片
- 工作介绍、生日及生活纪念等风格化形象图
- 基于同一身份来源的写真系列

默认 **2K / auto**。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 不把生成写真称作现实摄影记录或真实到场证明
- 不保证人物跨图完全一致或任何角度精确还原
- 不制作正式身份核验材料，不把未知身份细节补绘当成事实

## 领域注意

- 必须使用本人或目标宠物素材，不能把通用模特生成当成用户专属写真。
- 姓名、身份、年龄和可见特征沿用用户提供资料；不宣传百分百保真或真实摄影。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

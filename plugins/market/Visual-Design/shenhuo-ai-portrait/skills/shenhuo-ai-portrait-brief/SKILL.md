# 写真摄影师：需求整理

## 使用步骤

1. 从当前技能文件向上定位同时含 `.qoder-plugin/plugin.json` 与 `skills/` 的插件根目录。读取根目录下 `./skills/shenhuo-ai-portrait/references/designer-profile.md`，按其中的范围、必需素材和图片规格判断本次任务。
2. 汇总用户原话、用途、准确文案、已授权文件的真实绝对路径、明确张数与规格。保留每份相关素材及其用途，不根据文件名猜测内容。已提供的信息直接复用，未指定张数保持 auto。
3. 区分已知事实、必要缺项与用户偏好。只补问能力说明要求的必要素材；商品研究、设计判断、创意方案与最终提示词由神火固定设计师完成。
4. 输出可复用的需求清单：原始 Brief、事实和约束、文件路径与授权状态、张数和规格、已有 request_id / generation_id（如有）。用户只要整理需求时交付清单并结束；用户要求设计时，读取根目录下 `./skills/shenhuo-ai-portrait/SKILL.md` 推进。有真实资源 ID 时恢复原任务。

## 注意事项

本技能不联网、不创建账户或设计任务。文件授权由执行 Skill 在上传前确认；已明确的授权直接沿用。超出固定设计师范围时说明边界，不切换身份。需求清单中不记录 API Key 或账号密码。品牌功效、认证、销量等仅引用用户提供的事实。

## 验证

逐项对照原始需求，确认所有相关素材均有来源、事实没有补造、明确张数与规格未被改写，已有资源 ID 已传递。完成标准是执行 Skill 能区分已知输入与必要缺项，而不是已经生成设计方案。

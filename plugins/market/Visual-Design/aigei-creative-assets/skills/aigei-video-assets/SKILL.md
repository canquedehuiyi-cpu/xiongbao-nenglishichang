# 视频分镜选材与剪辑 / Aigei Video Assets

根据用户的文案、分镜稿或已有视频工程，使用已授权的「爱给素材 / Aigei Assets」连接器选材。用户要求成片时，在工作区调用可用的剪辑和导出工具。用户只要选材，或工作区只能策划时，交付剪辑师可以直接使用的时间轴。

## 按镜头选画面和声音

1. 从文案提取片长、画幅、关键信息和画面节奏。已有工程优先读取时间轴、字幕、旁白与现有媒体。为每个待配镜头确定时间段、主体动作和声音用途。用户只改一个镜头时，沿用原时间段，只更新该镜头及用户指定的声音轨。
2. 调用 `video-search` 按主体、动作、时长和画幅找素材。用 `audio-search` 的 `cat=music` 找配乐，`cat=sound` 找环境音或动作音效。结果不足时自主更换关键词，或选择裁切后仍能看清主体的画面。优先复用已有结果。按已知 `itemId` 补查时才使用 `video-detail` 或 `audio-detail`。
3. 逐镜头推荐文件，说明它怎样承接前后动作、留出字幕位置或避开旁白。按实际 `fileList` 核对文件编号、版本、分辨率、时长及音频规格。同后缀文件有多种规格时分别列出。
4. 选中的视频有 `prevImageList[].prevMiniUrl` 时，在表格外用 Markdown 图片展示这张镜头封面，保留原始签名和查询参数。客户端无法内嵌时给出该预览原链接。缺少封面时注明。只看到封面时，把镜头内动作、实际可用入出点标成待看片核实。音频未试听时先按真实名称、时长和拟用音轨介绍。

## 确认与获取

把成片时间码、素材名、所选版本、文件编号和具体用途列在一起。项目简报只用于挑选。说明此次获取的适用条件后，用户可一次指明要获取的多项文件，例如「获取清单第 1 项正式视频用作开门镜头、第 3 项门铃声用于开场，配乐先保留」。每次调用只使用已明确确认的条目和用途。试看与正式剪辑分别确认。

| 用户需要 | 取用哪条记录 | 确认后如何获取 |
| --- | --- | --- |
| 看动作、运镜或剪点 | `prevVideoList[]` 的具体试看版本 | 用该预览的 `fileId` 调 `video-preview-download`，视频试看省略 `imageSize`。 |
| 看更大的视频封面 | `prevImageList[]` 中选定的封面和尺寸档 | 用该预览图的 `fileId` 与对应的 `imageSize` 调 `video-preview-download`。 |
| 试听配乐或环境音 | `fileList[]` 的具体音频版本 | 试听需要获取该音频文件。用选定的 `fileId` 调 `audio-download`，同一版本已保存时直接播放。 |
| 用正式素材剪片 | 对应 `fileList[]` 的具体视频或音频版本 | 用正式文件的 `fileId` 调 `video-download` 或 `audio-download`。同一文件用于多个时间段时复用本地副本。 |

更换版本或适用条件有重要变化时，更新该项清单并重新确认。服务返回表明获取某个文件会改变账号状态时，先说明该文件对账号的具体影响；涉及数值时，列出服务返回的实际数值和单位，用户明确同意该影响后才执行。影响或适用条件未明时，暂停该项并保留已选清单供用户决定。用户取消时保留选材记录。按已确认的条目逐项获取，原样使用限时文件链接并及时保存。链接失效后仅按用户明确要求重新获取。发生异常时只报告受影响条目的操作状态和服务实际返回的 `requestId`，不自动重试。

## 示例：咖啡店开业短片

> 做一支 30 秒、9:16 的咖啡店开业短片，从清晨推门拍到第一杯拿铁。片尾写「本周六 08:00 开门」。画面、配乐和环境音从爱给选。先让我看镜头封面和声音清单。

| 成片时间 | 画面及剪点 | 声音 |
| --- | --- | --- |
| 00:00–00:05 | 清晨推门，门打开后切到吧台。优先选门把手和人物都在竖幅内的镜头。 | 开门处对齐门铃，配乐淡入。 |
| 00:05–00:22 | 开始萃取时切近景，再接拉花完成的动作。两段分别核对时长和手部裁切。 | 萃取处叠咖啡机声，拉花完成时收低环境音。 |
| 00:22–00:30 | 用端杯或吧台镜头接片尾，在干净区域显示用户给出的开业时间。 | 保留短暂余音，配乐在片尾淡出。 |

先用 `video-search` 搜开场，例如 `{"keyword":"咖啡馆 推门","cat":"videoFootage","pageNumber":1,"condition":{"fileVideo":{"videoLayoutEq":"9_16","videoDurationSecondsMin":5}}}`。按镜头分别检索萃取、拉花、端杯，用 `audio-search` 查询门铃、咖啡机与轻快配乐。用实际结果补齐各段的封面、文件版本和拟用声音，交付这一轮分镜供挑选。若用户接着说「把拉花换成手冲」，只检索替换段并展示新候选。用户确认获取用于剪辑的具体版本后，再将这些素材接入时间轴。

## 成片与时间轴验收

- **能剪辑和导出时**，将已确认并成功保存的正式文件接入项目，按实际动作确定素材入出点，完成裁切、字幕、音频对齐和混音。导出可播放的短片，打开导出文件，核对时长、宽高比、关键帧画面、片尾文案和各轨声音；提供成片路径和逐镜头来源记录。
- **交付时间轴时**，逐段写清成片起止、素材入出点（尚未看片时标「拟用」）、画面或音轨用途、字幕、来源页或 `itemId`、具体版本、保存路径或待获取状态。标明缺失镜头及待核实项；清单只将已实际接入且核对过的文件记为「已使用」。
- 按具体素材的许可核对用户拟定的用途。

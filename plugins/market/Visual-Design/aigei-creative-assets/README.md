# 爱给素材

把文案、游戏玩法或视频脚本交给 Qoder。插件会按页、按游戏事件或按镜头挑选图片、音效、配乐和视频，让你看到素材准备用在哪里、有哪些可用预览。你可以只换其中一项。确认所选文件后，Qoder 会在支持相应制作工具的工作区中把素材用进作品。

**Aigei Assets** selects images, sound effects, music, and footage for presentations, games, and videos. Review available previews for each slide, game event, or shot. Ask Qoder to replace a specific selection, then confirm the files you want to use.

## 开始使用

1. 在 Qoder 安装并启用「爱给素材」。若使用本地 ZIP，在「扩展 → 插件 → 添加插件 → 上传 Plugin」选择插件包。
2. 在插件或连接器的提示中完成爱给 OAuth 授权。连接成功后，在新任务中选择插件，或直接描述创作目标。
3. 首次使用可以试一句「帮我找三段适合夜景的雨声，列出时长和可用格式，先给我挑。」这次只使用搜索。要做作品时，直接使用下面的任务。

## 预览与交付

图片及视频封面有现成缩略图时会随候选展示。若客户端不能直接显示媒体，可打开对应的预览链接。想看清细节、判断镜头动作或听一段声音时，可以指定所选版本。音频试听也需要获取所选音频文件。Qoder 会先与你核对这次操作及服务返回的使用条件。

你可以对着预览说“只换第 2 页的背景”或“把第一个镜头改成近景”。需要正式文件时，可以一次确认清单里的具体条目。Qoder 会逐项处理，标出已使用的文件和仍待补齐的位置。

需要交付成品时，工作区应具备相应的演示文稿制作、游戏运行或视频剪辑工具，以及保存文件的权限。具备条件时可交付可编辑的 PPT、可玩的游戏项目或导出短片，并附素材使用清单。仅有查询或策划能力时，会给出逐页配图方案、事件与素材对照表或剪辑时间轴。下载链接限时有效，请及时保存。涉及商业使用时，请核对所选素材的许可。

## 连接与帮助

远程服务使用 Streamable HTTP，地址为 `https://www.aigei.com/mcp`，身份验证采用爱给 OAuth。若工具列表为空，可在 Qoder 检查插件和连接器的授权状态，再刷新工具列表。遇到服务异常时，记录所在页面、事件或镜头以及本次请求编号 `requestId`，方便定位未完成的条目。

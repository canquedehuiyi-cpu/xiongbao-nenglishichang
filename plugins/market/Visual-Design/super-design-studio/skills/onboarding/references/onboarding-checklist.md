## 工具检测步骤

### 浏览器自动化检测
```
1. 尝试调用浏览器自动化工具打开一个测试页面（如 about:blank）
2. 如果成功返回页面截图 → 标 ✓
3. 如果超时或报错 → 标 ✗，告知用户去 Connector 面板检查配置
4. 如果配置存在但调用失败 → 标 ⚪，提示"配置了但没测通"
```

### 钉钉文档检测
```
1. 尝试调用钉钉文档 MCP 读取文档列表（限 5 条）
2. 如果成功返回文档列表 → 标 ✓
3. 如果鉴权失败 → 标 ✗，提示用户检查钉钉连接器授权
4. 如果配置存在但调用失败 → 标 ⚪
```

### AI 生图检测
```
1. 尝试调用 AI 生图 MCP 生成一张测试图（简单几何图形）
2. 如果成功返回图片 → 标 ✓
3. 如果服务不可用 → 标 ✗，告知用户 fallback 方案
4. 如果配置存在但调用失败 → 标 ⚪
```

## 真实材料分析要点

收到用户提供的设计稿后，检查以下维度：

1. **颜色使用** — 是否有统一的色彩系统？是否用了设计系统外的颜色？
2. **排版层级** — 字号层级是否清晰？是否有过多字号变体？
3. **间距系统** — 间距是否一致？是否遵循某种基数网格？
4. **组件复用** — 是否有可识别的组件模式？复用率如何？
5. **信息层级** — 视觉权重是否匹配信息重要性？
6. **品牌一致性** — 整体是否感觉像同一个产品？

将发现与用户在访谈中说的标准对比，差异记录到 `## 已配置的种子资料` 段。

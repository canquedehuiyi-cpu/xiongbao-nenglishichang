# 技术交付文档模板

本模板用于 deliver skill 生成技术交付文档时的参考结构。

## 文档结构

### 1. 项目概览

```markdown
# {项目名称} 技术交付文档

**版本：** v{X.Y}
**设计负责人：** {姓名}
**交付日期：** {YYYY-MM-DD}
**设计目标：** {简述}
```

### 2. 交互链路图

```markdown
## 交互链路

[嵌入 Mermaid 流程图]

### 链路说明

| 节点 | 页面/模块 | 触发条件 | 目标 |
|---|---|---|---|
| A | 频道首页 | — | 入口 |
| B | 用户状态判断 | 页面加载 | 路由分流 |
| C | 商品列表 | 点击品类Tab | 列表筛选 |
```

### 3. 页面详细说明

```markdown
## {页面名}

### 3.1 模块划分

| 模块ID | 模块名 | 功能 | 子组件 | 依赖 |
|---|---|---|---|---|
| M001 | header-bar | 顶部导航 | Logo, 搜索, 分类Tab | 无 |
| M002 | hero-banner | 主视觉区 | 轮播图, 倒计时 | M001 |

### 3.2 状态说明

#### M001 header-bar

| 状态 | 描述 | 视觉表现 |
|---|---|---|
| 默认 | 页面初始加载 | 展示完整导航 |
| 滚动后 | 用户向下滚动 > 100px | 导航栏吸顶，缩小高度 |
| 加载中 | 数据请求中 | 骨架屏 |

### 3.3 异常处理

| 场景 | 触发条件 | 降级方案 |
|---|---|---|
| 网络异常 | 请求超时 > 10s | 展示重试按钮 |
| 图片加载失败 | 图片资源404 | 展示默认占位图 |
| 数据为空 | 接口返回空数组 | 展示空状态插画 |
```

### 4. 视觉标注

```markdown
## 视觉标注

### 4.1 颜色 Token

| Token 名 | 值 | 用途 | 对比度 |
|---|---|---|---|
| --color-primary | #FF4D4F | 主色/CTA | 4.6:1 ✓ |
| --color-price | #FF2D2D | 价格文字 | 4.8:1 ✓ |
| --color-text-primary | #1A1A1A | 主文本 | 15.4:1 ✓ |
| --color-bg-surface | #FFFFFF | 卡片背景 | — |

### 4.2 字号 Token

| Token 名 | 值 | 行高 | 层级 |
|---|---|---|---|
| --font-size-h1 | 28px | 36px | 页面标题 |
| --font-size-price | 24px | 28px | 价格 |
| --font-size-body | 14px | 22px | 正文 |
| --font-size-caption | 12px | 18px | 辅助文本 |

### 4.3 间距 Token

| Token 名 | 值 | 用途 |
|---|---|---|
| --spacing-xs | 4px | 紧凑间距 |
| --spacing-sm | 8px | 元素内间距 |
| --spacing-md | 16px | 模块内间距 |
| --spacing-lg | 24px | 模块间间距 |
| --spacing-xl | 32px | 区域间间距 |

### 4.4 圆角/阴影 Token

| Token 名 | 值 | 用途 |
|---|---|---|
| --radius-sm | 4px | 按钮/输入框 |
| --radius-md | 8px | 卡片 |
| --radius-lg | 16px | 弹窗/浮层 |
| --shadow-card | 0 2px 8px rgba(0,0,0,0.08) | 卡片阴影 |
```

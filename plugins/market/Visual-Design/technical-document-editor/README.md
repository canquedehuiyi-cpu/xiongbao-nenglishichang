# 技术文档编辑

基于用户已有的软件产品说明、操作记录和真实问题，制作任务指南与 FAQ，并按确认的版本变化同步维护。含 task-guide、faq-authoring、documentation-update 三项相关技能；首版免费，无自带执行引擎及外部账号要求。

可直接提出：“根据这些成员管理规则写一份新管理员指南，再整理常见问题。”“这是新版规则，请同步更新旧指南和 FAQ，并列出修改依据。”

提供可读取的 TXT/Markdown 或直接粘贴文本，注明读者、版本及已知事实。默认交付 Markdown；能否保存文件取决于 Qoder 当前工具与权限。没有的界面路径、按钮名、有效期和业务规则会列为待确认，材料冲突会保留来源。不会替用户登录产品验证、自动发布帮助中心或承诺任意格式转换。

内部技能均带具体方法、成果结构与实例。查看每个技能的 SKILL.md；完整任务可整体调用本插件。跨会话维护时提供既有成果和新材料，不依赖隐式记忆。

# 神火运营海报使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

帮我做一张适合发朋友圈的海报，我会提供文案和素材。

English: Create a poster for WeChat Moments using the copy and materials I provide.

## 示例 2

我要推广一场活动，帮我做一张主题和参与方式清楚的海报。

English: Create an event promotion poster that clearly explains the theme and how to take part.

## 示例 3

根据这些产品图片和资料，做一张发朋友圈的产品介绍海报，突出产品特点。

English: Use these product images and details to create a product introduction poster for WeChat Moments, highlighting the product's features.

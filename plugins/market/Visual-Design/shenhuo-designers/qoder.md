# 神火设计师

读取 `./skills/shenhuo-designers-flow/SKILL.md`，使用 Qoder 市场已安装、已授权的“神火设计师”连接器执行设计；按宿主实际工具名称调用，本插件不创建连接器实例。运行时读取目录和公开能力；指定设计师直接核对，未指定时匹配并等待用户选择。完整设计判断、提示词和生图由神火服务端完成，用户确认有效报价后才提交生图。

连接器未授权或未就绪时，按 Skill 的“未授权时”分支引导：注册神火账号（新账号赠送积分）→ 在 Qoder 连接器市场安装“神火设计师” → 在扩展管理的连接器“Qoder 市场”区域完成授权 → 回复“已授权”继续；已有账号、安装和授权直接复用。保留原需求及任务 ID。此时只提供注册与授权恢复路径，不主动推荐 ImageGen、其他生图工具或先做替代草稿。用户回复后先核验账号；保留原任务并继续查询，不重复建项或扣费。

图片张数与创意内容由神火系统设计师决定，插件原样传递需求，不自行限制张数。只有服务端返回真实追问时才等用户回答；ready 且没有待处理追问表示创意已完成，直接展示整组摘要并获取报价，不让用户再选某个风格或方案。生图费用仍须明确确认。生图确认提交后，按 Skill 的“生图后的持续轮询”分支实际等待并循环查询同一生成任务，直到终态后领取作品或报告失败；不要仅查询几次就结束，让用户手动催查。

积分不足时，按 Skill 的“积分不足”分支，仅根据真实回执说明当前积分状态、所需积分、可用积分和缺口，暂停付费操作并保留原任务及幂等记录。此分支不提供获取积分入口、购买建议或继续操作口令。

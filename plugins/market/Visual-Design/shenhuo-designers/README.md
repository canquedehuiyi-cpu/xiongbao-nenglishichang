# 神火设计师

把设计需求交给专业 AI 设计师，从一句想法、几张素材，到可以下载使用的设计图片，在 Qoder 对话中完成。

神火设计师连接神火 AI 平台当前已发布、在线且公开可用的设计师。你可以直接指定设计师，也可以描述用途、内容和期望效果，由神火推荐适合的设计师，再开始设计。设计师会结合你的原始需求和素材理解任务，提出必要追问并给出方案；确认生图报价后，生成并交付作品。

## 可以做什么

- **电商商品**：商品白底图、主图、详情图、推广图，以及跨境电商图片。
- **社交内容**：小红书封面与图文笔记、公众号图片、抖音图文带货图片。
- **运营海报**：活动邀请、门店上新、课程宣传、招聘通知等海报。
- **品牌视觉**：品牌 Logo、包装视觉概念、名片及品牌应用图片。
- **行政办公**：简历简介、PPT 页面、工牌、姓名牌、计划表等。
- **生活娱乐**：人像写真、发型预览、社交头像、纹身图案、图片修复与精修。

可用设计师和默认图片规格会随神火平台更新，使用时读取当前能力。

## 开始使用

1. **准备神火账号**：还没有账号？先[注册神火 AI](https://www.shenhuoai.com/register)。新注册账号有积分赠送，赠送积分可用于设计与作品交付；已有账号可直接使用。
2. **连接并授权**：在 Qoder 的连接器市场安装“神火设计师”，再到“设置 → 扩展管理 → 连接器”的“Qoder 市场”区域完成神火账号登录和 OAuth 授权。已安装、已授权的连接器可直接使用，无需为本插件另建连接器或重复授权，也无需在聊天中提供密码、API Key 或令牌。
3. **回到对话开始设计**：完成授权后回复“已授权”，再描述需求或继续之前的任务。如果当前会话尚未加载连接器，新建对话并选择“神火设计师”即可继续。
4. **查看方案，确认后生图**：根据设计师的必要追问补充资料，查看方案与积分报价。确认后开始生成，完成后下载作品，也可以通过项目入口到神火网站查看同一项目。

## 可以这样提需求

- “用这张商品原图做一张白底图，保留产品外形、颜色和标识。”
- “帮我做一张冬季通勤穿搭的小红书封面，标题是‘一周上班穿搭’，用我上传的照片。”
- “为山间书店的周末读书会设计一张活动海报，先推荐合适的设计师。”
- “为一家花艺工作室设计品牌 Logo，并制作两张包装应用图片。”
- “用这些真实经历和项目资料，整理一张适合求职展示的个人简介图片。”
- “修复这张老照片的折痕和褪色，尽量保留人物本来的样子。”

## 设计与积分

设计服务由神火 AI 完成，使用你绑定账号的个人积分。需求匹配、理解和提案可能消耗积分；图片生成前会展示方案、张数、规格、模型档位和预计积分，得到确认后再生成。

积分不足时，仅说明当前积分状态和真实回执中的所需积分、可用积分及缺口，并暂停付费操作，保留已有任务。

作品完成后，插件会展示实际成功图片、结算积分和神火原项目入口。多图任务有部分成功时，会先交付已完成作品并说明其余状态。确认提交后会按间隔持续查询生成进度，直到作品完成或返回失败结果；任务中断后可沿用原任务继续查询，下载失败可重新领取作品，无需重复生图。

## 素材与账号

仅处理你主动提交并授权使用的需求、图片和附件。请确保拥有素材的使用权限，并核对姓名、联系方式、商品参数等需要准确呈现的信息。

授权可在神火账号的“已连接应用”中查看和撤销。连接器尚未授权时，插件会引导完成注册和授权，再继续原有需求。

# 市场连接器依赖：神火设计师

本插件依赖 Qoder 市场已上架的“神火设计师”连接器。插件只包含通用 Skill、角色指令和使用说明，不声明 MCP 服务器，不创建独立连接器实例，也不复制或读取其他连接器的 OAuth 凭证。

## 安装与授权

1. 在 Qoder“扩展 → 连接器”市场中搜索“神火设计师”并安装。
2. 在“设置 → 扩展管理 → 连接器”的“Qoder 市场”区域找到“神火设计师”，完成神火个人账号 OAuth 授权。已有安装与有效授权直接使用。
3. 回到对话回复“已授权”。插件先查询账号并读取实时设计师目录；若当前会话尚未加载市场工具，新建对话选择本插件并继续原需求。

没有账号时先[注册神火 AI](https://www.shenhuoai.com/register)，新账号赠送积分可用于设计和交付。连接器用于查询个人积分与实时设计师、上传授权素材、匹配、建项、追问、报价、生图和领取作品。需求匹配与提案可能使用个人积分；生图须确认报价。授权可在神火“已连接应用”中查看和撤销。

`CONNECTORS.md` 是依赖说明，不会自动安装市场条目。工具由 Qoder 提供，名称和前缀以实际发现结果为准；不假定与插件同名就已绑定。服务端地址和 OAuth 由市场连接器管理，无需用户在本插件中填入地址、密码、Key 或 Token。

此前导入 1.0.0 的用户，升级后应在 Qoder 检查旧版“由 Plugin 提供”的连接器是否已移除；如仍保留，只处理旧插件实例，保留“Qoder 市场”中的连接器及其授权。不要为排查问题撤销市场连接器授权。宿主无法上传或下载时如实说明，不能声称文件传输已完成。

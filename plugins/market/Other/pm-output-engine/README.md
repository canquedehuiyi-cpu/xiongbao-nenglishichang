# 超级产品经理 · 产出引擎

AI 产品经理的文档与汇报工具箱，覆盖 PRD、汇报、调研、专利四大产出场景。内含 4 个技能 + 1 个配置引导，内置三段叙事汇报框架、HTML 产品文档模板、实用新型专利模板。

> **说明：** 本插件辅助产品经理的文档产出工作，所有文档应经过团队评审后使用。

## Target Roles

- **产品经理** — PRD 撰写、数据汇报、竞品调研、专利沉淀
- **运营** — 数据汇报文案、竞品分析
- **项目经理** — 需求文档、进度汇报

## Quick Commands

| Command | Description |
|---------|-------------|
| `/需求文档撰写` | 写 PRD/策略文档，产出 HTML 格式产品文档 |
| `/数据汇报文案` | 整理数据生成汇报文案，三段叙事结构 |
| `/竞品行业调研` | 竞品对比分析或行业趋势研究 |
| `/专利文档生成` | 从 PRD 提炼创新点，输出实用新型专利文档 |

## Skills

| Skill | Description |
|-------|-------------|
| 需求文档撰写 | PRD/策略文档生成——目标定义、策略矩阵、P0-P2 功能清单、排期规划、协作流程（含上下游周知规则），HTML 格式可交互文档 |
| 数据汇报文案 | 数据驱动的汇报文案——精炼一句话直击核心数字，三段叙事结构（绝对pp提升+相对%+稳定平台），支持 ODPS 数据直拉 |
| 竞品行业调研 | 竞品对比分析和行业趋势研究——维度矩阵对比、SWOT 分析、策略建议，输出结构化调研报告 |
| 专利文档生成 | 实用新型专利申请文档——从 PRD 提炼创新点，按固定模板输出（申请说明+术语+背景+竞品+详述+创新点），SimHei/SimSun 格式 .docx |

## Connectors (Optional Enhancement)

| Connector | Enhanced Capability |
|-----------|-------------------|
| **ODPS (MaxCompute)** | 数据汇报文案可直接拉取业务数据 |

> 不连接任何外部工具也可正常使用。

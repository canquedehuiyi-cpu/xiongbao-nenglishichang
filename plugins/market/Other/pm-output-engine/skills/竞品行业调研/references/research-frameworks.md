### 1.2 SWOT 交叉策略矩阵

SWOT 的真正价值在于交叉分析，产出具体的策略方向：

```
┌──────────────────────────────────────────────────────────────────┐
│                     SWOT 交叉策略矩阵                             │
├─────────────┬──────────────────────┬─────────────────────────────┤
│             │        S (优势)       │         W (劣势)            │
├─────────────┼──────────────────────┼─────────────────────────────┤
│ O (机会)    │ SO 策略（进攻型）      │ WO 策略（改进型）            │
│             │ 利用优势抓住机会       │ 克服劣势以抓住机会           │
│             │ · [策略 1]            │ · [策略 1]                  │
│             │ · [策略 2]            │ · [策略 2]                  │
├─────────────┼──────────────────────┼─────────────────────────────┤
│ T (威胁)    │ ST 策略（防御型）      │ WT 策略（撤退型）            │
│             │ 利用优势应对威胁       │ 最小化劣势避免威胁           │
│             │ · [策略 1]            │ · [策略 1]                  │
│             │ · [策略 2]            │ · [策略 2]                  │
└─────────────┴──────────────────────┴─────────────────────────────┘
```

### 1.3 SWOT 编写质量检查清单

完成 SWOT 后，逐条检查：

- [ ] S 和 W 是否聚焦于内部因素（产品/团队/技术），没有混入外部因素？
- [ ] O 和 T 是否聚焦于外部因素（市场/竞争/政策），没有混入内部因素？
- [ ] 每条是否有事实或数据支撑，而非主观臆测？
- [ ] 每条是否具体到可行动，而非泛泛而谈（如"技术领先"→ 具体哪项技术？）？
- [ ] 四个象限的条目数量是否均衡（3-5 条），没有严重偏科？
- [ ] 是否进行了交叉策略分析，而非只停留在列举？
- [ ] 信息来源是否已标注，且来源可靠？

### 2.3 功能评分标准

对比矩阵中使用的评分符号需遵循统一标准：

| 符号 | 含义 | 使用条件 |
|---|---|---|
| ⭐⭐⭐⭐⭐ | 行业领先 | 在该维度明显优于其他竞品，有具体证据 |
| ⭐⭐⭐⭐ | 优秀 | 功能完整，体验良好 |
| ⭐⭐⭐ | 良好 | 满足基本需求，无明显亮点 |
| ⭐⭐ | 一般 | 有功能但体验不佳或有限制 |
| ⭐ | 较弱 | 功能缺失或严重不足 |
| ✅ | 完整支持 | 二值判断场景下，功能完整可用 |
| ⚠️ | 部分支持 | 功能存在但有限制或条件 |
| ❌ | 不支持 | 功能完全缺失 |

**评分原则**：
- 尽量使用具体数字替代星级评分（如"支持 95 种语言"比"⭐⭐⭐⭐⭐"更有说服力）
- 星级评分必须基于可比较的标准，不可对不同竞品使用不同尺度
- 当信息不足以评分时，标注"信息不足"而非随意给分

## 三、市场定位图模板

### 3.1 二维定位图框架

根据行业特征选择合适的坐标轴维度：

```
Y 轴（上方为正）
    │
    │   [竞品 A] ●
    │                ● [我方产品]
    │
────┼──────────────────────────── X 轴（右侧为正）
    │
    │   ● [竞品 C]
    │              ● [竞品 B]
    │

坐标轴选择说明：
- X 轴：[维度名称] —— 选择理由：[为什么这个维度重要]
- Y 轴：[维度名称] —— 选择理由：[为什么这个维度重要]
```

### 3.2 常用坐标轴维度对

| 行业类型 | X 轴 | Y 轴 | 适用场景 |
|---|---|---|---|
| AI 产品 | 通用型 ← → 垂直专业 | 低价/免费 ← → 高价 | AI 工具类产品 |
| SaaS | 自助服务 ← → 企业定制 | 轻量级 ← → 全功能 | B2B SaaS 产品 |
| 内容平台 | UGC ← → PGC | 免费 ← → 付费 | 内容/创作工具 |
| 开发者工具 | 低代码 ← → 高灵活度 | 免费开源 ← → 商业闭源 | DevTools 产品 |
| 电商平台 | 标品 ← → 非标品 | 低价 ← → 高端 | 电商/零售 |

## 六、实战示例：AI 对话产品竞品分析（节选）

### 示例背景

假设我方产品为一款面向企业用户的 AI 对话助手，需要对比分析 ChatGPT、Claude、Gemini 三款竞品。

### 示例 1：功能维度对比矩阵（节选）

| 维度 | 我方产品 | ChatGPT | Claude | Gemini | 数据来源 |
|---|---|---|---|---|---|
| 多轮对话质量 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 评测报告 2025 |
| 上下文窗口 | 32K tokens | 128K tokens | 200K tokens | 1M tokens | 官方文档 |
| 多模态能力 | 文本+图片 | 文本+图片+音频 | 文本+图片 | 文本+图片+音频+视频 | 官方文档 |
| 企业级安全 | 私有化部署 | API 数据隔离 | SOC2 认证 | Google Cloud 合规 | 官方安全白皮书 |
| 中文能力 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 内部评测 |
| API 价格 | ¥0.02/千 token | $2.5/百万 input | $3/百万 input | $1.25/百万 input | 官方定价页 |

**关键洞察**：在上下文窗口维度，Gemini 的 1M token 支持领先明显。但我方产品在私有化部署和中文能力上有独特优势，这是企业客户的核心诉求。

## 七、信息来源优先级指南

### 7.1 来源可信度分级

| 优先级 | 来源类型 | 示例 | 使用建议 |
|---|---|---|---|
| P0 - 一手来源 | 官方网站、官方公告、产品文档 | openai.com、Anthropic blog | 功能和定价信息必须引用 |
| P1 - 权威媒体 | 知名科技媒体、行业研究机构 | TechCrunch、36氪、Gartner | 市场数据和行业趋势 |
| P2 - 专业评测 | 独立评测机构、专业评测报告 | LMSYS Chatbot Arena、专业博客 | 技术对比数据 |
| P3 - 用户反馈 | 应用商店评论、社区讨论 | App Store、Reddit、知乎 | 用户体验和口碑（需注明为用户观点） |
| P4 - 自媒体 | 个人博客、公众号、短视频 | 科技博主、行业 KOL | 仅作参考，不可作为唯一来源 |

### 7.2 来源标注格式

在报告中引用信息时，使用以下格式：

- **事实引用**：`据 OpenAI 官方 2025 年 3 月公告，ChatGPT 月活用户已突破 3 亿 [1]`
- **数据引用**：`全球 AI 对话市场规模预计 2025 年达到 86 亿美元（Gartner, 2025）[2]`
- **推测标注**：`*据推测*，Claude 的企业客户数量可能在 5000-10000 家之间（基于其博客中提到的客户案例数量推算）`
- **信息不足标注**：`Gemini 的具体 MAU 数据暂未公开披露 [⚠️ 信息不足]`

## 八、常见行业分析框架速查

| 框架名称 | 适用场景 | 核心维度 | 本 skill 中对应 |
|---|---|---|---|
| SWOT 分析 | 单个产品/公司的内外部分析 | 优势、劣势、机会、威胁 | Step 3B |
| PEST 分析 | 宏观环境分析 | 政策、经济、社会、技术 | Step 4A |
| 波特五力 | 行业竞争强度分析 | 供应商/买方/替代品/新进入者/现有竞争 | 可扩展 |
| 价值链分析 | 企业竞争优势来源 | 主要活动 + 支持活动 | 可扩展 |
| 安索夫矩阵 | 增长策略选择 | 产品/市场的现有与新组合 | Step 5 |

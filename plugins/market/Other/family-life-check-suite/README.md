# 家庭生活核对套件（family-life-check-suite v0.1.1）

11 个家庭生活核对技能：育儿喂养打卡、兴趣班排期、家庭账单、孩子作业清单、家庭用药、宠物喂养、家长群通知、会员订阅、车辆保养、装修报价、旅行行程单。判定逻辑全部落在 Python 脚本里，结果可复算、对不上的项点名到行；读不出或不可比的显式转人工，不靠模型现算。

## 技能清单

- **baby-care-log-check**：适用场景:当要看宝宝今天喂养作息是否正常时(每日多次)
- **class-schedule-check**：适用场景:当收到新机构课表要排周课时
- **family-bill-check**：每月账单日使用：把家庭成员微信、支付宝、银行卡各渠道的月度流水贴进来，合并勾稽出漏记、重复记、同一会员两边都在扣、异常大额与分摊对不上的项
- **homework-checklist-check**：孩子说作业写完了？把老师布置的要求、孩子报的完成清单各贴一段，逐项勾稽出缺漏：没写的、听读背诵签字这类最容易漏的、明天要带的东西
- **medication-schedule-check**：医嘱一段、家人实际吃药打卡一段，本地引擎逐条比对：该吃没吃的、一天吃了两次的、两次间隔太近的、不该同服的、疗程中途断掉的，全部点名带判据编号
- **pet-care-check**：适用场景:当全家共养宠物要确认喂养情况时(每日喂食前后)
- **school-notice-check**：家长群 99+ 之后使用：把刷屏的聊天记录整段贴进来，老师真正提的要求——截止时间、要带的东西、缴费、接龙——被提取成一张清单，顺带标出时间撞车的和已经过期却还在被转发的通知
- **subscription-audit-check**：觉得这个月扣费变多了，或想把全家订阅盘一盘的时候触发：微信/支付宝/Apple 各渠道的自动续费流水贴进来，同一会员重复扣、悄悄涨价、早就不看却还在扣的僵尸订阅、异常大额，逐条翻出来带判据编号
- **car-maintenance-check**：适用场景:当 4S 店给出保养建议单要核对时(每次保养)
- **renovation-quote-check**：适用场景:当拿到装修报价单要比对预算时(签约前)
- **travel-itinerary-check**：适用场景:当多平台订单订完要拼行程时(出发前一周)

## 使用

安装本插件后，在 Qoder 里以 `/技能名` 调用对应核对技能；每个技能的输入形态、判定与输出物见各自 SKILL.md。

## 边界

只核不改、结果可复算；不可比、解析不了或证据不足的项显式标 UNKNOWN/转人工，不猜测、不代作决定。

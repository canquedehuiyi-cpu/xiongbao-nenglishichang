# 家庭用药打卡核对 —— 技能正文(references 位)

> 官方文档位:深入用法、判定口径说明、边界与转人工规则放这里。
> SKILL.md 保持指令式短文(平台审核对介绍型长文有拒审先例);
> 长内容一律住本文件,由 SKILL.md 按需引用。

## 判定口径

计划面与打卡面逐条勾稽,五族判据(结论只认引擎 JSON 里的 `findings`):

| 判据 | 含义 | 默认阈值 |
|---|---|---|
| M1 漏服(medium) | 计划时刻 ±30 分钟窗口内无同药打卡 | grace_minutes=30 |
| M2 重复服用(high) | 同药同日两次打卡间隔 ≤30 分钟 | dup_window_minutes=30 |
| M3 间隔不足(medium) | 相邻打卡间隔小于最小间隔(计划"每日N次"→ 24h/N×0.75;否则 240 分钟) | min_interval_minutes=240 |
| M4 同服禁忌(medium) | 同日实际打卡出现规则表禁忌组合(默认:头孢+酒、华法林+阿司匹林) | forbidden_pairs |
| M5 疗程断档(low) | 疗程内整天无该药打卡 | — |

VERDICT:有 findings → REVIEW(人工复核);零 findings 且有未解析行 → DEGRADED
(部分输入没核对到,知情放行);零 findings 零未解析行 → PASS。
阈值可经 rules-config JSON 外置覆盖,坏配置回默认并记 WARN;默认值以引擎代码为准,
本表是转述不是权威。

## 输入契约

两段粘贴文本,通过 `--set plan=` 与 `--set log=` 传入:

- **医嘱计划行(两种方言任选)**:
  - CSV 式:`药名,日期,时间[,剂量]`,如 `头孢克肟,11-01,08:00,1片`
  - 口语式:`药名 每日N次(HH:MM/…) 每次X D1至D2`,如
    `阿莫西林 每日3次(08:00/14:00/20:00) 每次1粒 11-01至11-04`
- **打卡行(字段序不拘)**:`药名 日期 时间 [剂量]`,日期/时间按形态自动识别
- **日期方言**:YYYY-M-D、M-D、M月D日(缺年取输入中最早完整日期的年)
- **时间方言**:HH:MM(全角冒号可)、H点、H点半、时段前缀(下午3点→15:00、睡前→22:00)
- 解析不了的行原样进 UNCERTAIN 清单(带行号),不臆造;扫描件/截图不支持(无 OCR)

## 转人工规则

以下情形一律不硬判,如实转人工:

- plan 或 log 整段为空(没有可勾稽的基准或执行)
- 任何解析失败的行(UNCERTAIN 清单逐条列出,verdict 计降级语义)
- M2 命中(机器分不清"重复吃"还是"重复记",须人确认实际次数)
- M4 命中(默认规则表只是常见组合提示,能不能同服以医嘱与药品说明书为准)
- 每日N次计划既无时刻表也无疗程范围(信息不足以展开计划面)

本技能输出是核对提示,不是诊疗意见;补服、换药、停药等决定一律由用户与医生作出。

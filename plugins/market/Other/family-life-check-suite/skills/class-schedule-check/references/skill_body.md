# 兴趣班排期核对 —— 技能正文(references 位)

> 官方文档位:深入用法、判定口径说明、边界与转人工规则放这里。
> SKILL.md 保持指令式短文;长内容一律住本文件,由 SKILL.md 按需引用。

## 判定口径

判据族(结论只认引擎 JSON 里的 `findings`):

| 判据 | 含义 | 阈值 |
|---|---|---|
| C1 时间重叠(high) | 同一天两节课时段相交 | — |
| C2 衔接不足(medium) | 相邻两节间隔低于通勤阈值(地点不同) | min_transfer_minutes |
| C3 接送冲突(medium) | 同一天同一接送人时段重叠或衔接不足 | min_transfer_minutes |

VERDICT:有 findings → REVIEW;零 findings 且有未解析行 → DEGRADED;
零 findings 零未解析行 → PASS。阈值可经 rules-config 外置覆盖,坏配置回默认记 WARN;
默认值以引擎代码为准,本表是转述不是权威。

## 输入契约

课表粘贴文本,一行一节(机构+星期/日期+时段+地点[+接送人])。行格式详见 SKILL.md 执行步骤;解析不了的行原样进 UNCERTAIN(带行号);
扫描件/截图不支持(无 OCR)。

## 转人工规则

以下情形一律不硬判:
- 任何解析失败的行
- 时段起止不完整
- 星期表达无法识别

本工具输出是核对提示,不代操作;相关决定一律由用户作出。

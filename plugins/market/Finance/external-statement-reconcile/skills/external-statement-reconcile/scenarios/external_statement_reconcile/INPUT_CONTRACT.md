# 输入契约 —— 外部单据对账（N-13 / N-24，判定族 T-11 外部线）

> 目的：把「勾兑动作」的输入边界定死，前置处理扫描件/OCR 限制，避免盲测 G 值是假的。
> 依据研究库 N.1 §2 GATE 1c 与「扫描件/OCR 是最大杀手」结论：**只吃文本层**。

## 0. 通用模板输入（推荐主输入）

各企业银行流水/订单导出格式各异，模板是**通用化入口**：把两侧记录抄进固定列模板
（`template/外部对账输入模板.xlsx`，工作表 流水表/订单表），引擎按输入字段读对应
表（source-file→流水表、right-file→订单表），自动转成第 2 节键值行再判定，**判定
结果与直接喂文本完全一致**。

- 客户名称两侧保持同口径（简称/全称统一），金额为纯数值，千分位逗号可保留。
- 不填模板、或文件非模板（缺对应表）时自动回退普通文本输入。
- 模板内附「填写说明」表；流水截图/PDF 扫描件不得粘贴进模板，先转文本再填。

## 1. 接受格式

| 格式 | 支持 | 说明 |
|---|---|---|
| UTF-8 TXT / MD / CSV | ✅ | 最干净，推荐（银行流水 CSV 天然合规） |
| 文本层 XLSX / PDF / DOCX | ✅（惰性导入） | 读到的是文字，非图像 |
| 扫描件 / 图片 / 截图（jpg/png/tif） | ❌ | **拒绝**，无法下判定 |
| 图片版 PDF（无文本层） | ❌ | 同上，判 UNKNOWN 转人工 |

> 例外：若只能拿到扫描件，宿主须在喂入前完成 OCR/手打转文本层；转不出的行以
> `[IMAGE-SCAN 〈文件名〉 不可解析，请转文本层后重交]` 原样保留。

## 2. 双侧文件与行格式

- **左表**（银行流水）：`source-file`（第一个 FILE 字段）。
- **右表**（订单/应收）：`right-file`，用 `--set right-file=<右表>` 传入。

每行一条记录，空格分隔多键值对：

```
侧 ∈ 流水|银行|回款|a   ↔   订单|应收|发票|账单|b
```

| 键 | 别名 |
|---|---|
| 日期 | 日 |
| 客户 | 客户名称 / 对方 |
| 金额 | 发生额 |
| 单号 | 发票号 / 订单号 / 单据号 |
| 类型 | 借贷 / 方向 |
| 摘要 | — |

示例：

```
流水:日期=2026-09-01 客户=深圳市蓝天科技有限公司 金额=1000.00 单号=L1 摘要=货款
订单:日期=2026-08-20 客户=深圳市蓝天科技（集团）股份有限公司 金额=1000.00 单号=R1
```

**值内不得再出现 `键=` 形式**（解析以 `键=` 为分隔符）；值允许含空格。

## 3. 判定与转人工规则

- 匹配前提：**客户名归一化相等** + 金额差 ≤ 0.02 元（尾差容差 TAIL_TOLERANCE）。
- 精确 1:1 容差 0.005 元；差 ≤ 0.02 仍匹配但标**尾差**；＞ 0.02 → 未匹配转人工。
- 一对多 / 多对一：右侧或左侧多笔之和 = 另一侧单笔（容差 0.02）。
- 红字冲销：同单号 ± 金额（同客户）先识别，不算重复付款。
- 跨期提示：回款日 - 单据日 > 60 天 → WARN，不阻断匹配。
- **未匹配项绝不自动消掉**（不编造勾兑把表做平）：原样转人工。
- 命中扫描件/图片/无法解析的行（含 `[IMAGE-SCAN`、`.png/.jpg/scan/扫描/ocr` 特征）→
  未解析列表转人工，不参与判定。
- 单侧缺字段：缺单号/缺日期不影响匹配（用 客户+金额），但会在差异清单里体现字段覆盖。

## 4. 输出

- `outputs.summary`：matched_total / matched_1_1 / matched_1_n / matched_n_1 /
  writeoff / unmatched_left / unmatched_right / tail_diff / cross_period。
- `outputs.reconcile`：完整匹配关系（relation / 单号 / 金额 / 是否尾差）。
- `outputs.unresolved`：未解析（扫描件等）行，人工对照清单。
- 报告：``dist_template/output` 日期目录下的 reconcile-*.md`（匹配关系、冲销、未匹配、尾差/跨期）。

## 5. 输入可得性与盲测口径（对齐研究库 README §一 第 10 行）

- 银行流水 CSV/XLSX 是天然合规文本层，**无 OCR 依赖**——这是本候选排第 2 的主因。
- 盲测必须用真实流水 + 真实订单/应收文件（T-11 外部线取样工单，见
  `BLIND_TEST_T11.md` 待建）；不生成合成样本。
- N.2 §3：T-11 本族不得合并成一个 G 值——**B-08 内循环（三单匹配）与本包外部线
  分线计**。本包只做外部线；内循环三单匹配不在本包范围。

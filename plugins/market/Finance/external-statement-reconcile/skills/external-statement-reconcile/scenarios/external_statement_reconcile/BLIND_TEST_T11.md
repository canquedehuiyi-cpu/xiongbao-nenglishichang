## 0 为什么本包是 T-11 的外部线

- T-11（财务对账勾兑族）分两条线（N.2 §3）：**B-08 内循环**（PO/收货单/发票三单匹配，

- 外部线对应条目：N-24（R9 应收会计，银行流水勾兑，E-03/E-01/B-15）、

## 1 取样来源（一次取样向谁要什么）

按 N.3 §7.1 第 2 项「给财务」：

> 取**同一段时间**的 2~3 组文件：
> 1. 银行流水 CSV/XLSX（真实导出，含摘要/对方名称/金额/日期）
> 2. 订单/应收 XLSX（发票号/客户/金额/日期）
> 3. 若可，附客户对账单（PDF/Excel）

要求：
- 流水与订单是**同一会计期间**、**同一批客户**的真实记录（跨期陷阱才真实）。
- 流水行保留原样（含摘要措辞差异、客户名写法差异），**不要清理**。
- 若某客户有回款但订单里查不到，保留原样（这是要测的未匹配）。

宁可只取一组真实样反复跑 3~5 次，也不要凑 3 组脱敏不当的样本。

---

## 2 必埋陷阱（不埋则测不出真水平；埋了才叫取样，不叫造假）

> 陷阱必须来自真实业务形态（真实存在的写法差异/冲销/尾差），不是人为制造数字。

| # | 陷阱 | 说明 | 对应失败模式 |
|---|---|---|---|
| T-1 | 一笔回款冲多张发票（一对多） | 经典翻车点：模型常把整笔挂到一张票 | FM-03 缺明细 / FM-05 |
| T-2 | 多笔回款对一张发票（多对一） | 同上 | FM-03 / FM-05 |
| T-3 | 尾差几分钱 | ≤0.02 应判尾差而非未匹配；＞0.02 才是差异 | FM-05 漏检 / FM-08 |
| T-4 | 日期跨期 | 回款与开票隔月/隔季，应提示时间差而非错误 | FM-08 误报 |
| T-5 | 红字冲销同单号 ± | 应识别为冲销，不算重复付款/漏项 | FM-01 / FM-05 |
| T-6 | 客户名简写/全称混用 | 真实流水里对方名称写法不一 | FM-03（"看起像"当作匹配） |
| T-7 | 无对应订单的回款 | 必须落到未匹配转人工，**不得编造勾兑把表做平** | FM-01 一票否决 |

> 陷阱分布：至少 1 组含 1:1 clean 对照；至少 1 组同时含 ①②⑤⑦ 判断会不会把表做平。
> 每组把埋了什么写进 `MANIFEST.txt`（见 §4）。

## 3 判卷口径（"本次运行可用"的定义，逐条打勾）

1. **逐笔列出匹配关系**（1:1 / 1:N / N:1），不得用"已全部对上"总结代替明细（FM-03）。
2. 给出**定位**：左表行号/单号 + 右表单号 + 金额。
3. **未匹配项必须显式列出转人工**；不得自行消掉或"挂到其它订单"（FM-01 一票否决）。
4. 尾差定性正确：≤0.02 标尾差；＞0.02 判差异（FM-05/FM-08）。
5. 红字冲销识别为冲销，不误报重复付款。
6. 跨期 >60 天给时间差提示，不误报为错误。
7. 客户名简写/全称：归一化可解的（词缀差异）应匹配；简写 vs 全称无法机械判定的
   走未匹配，**不猜同一客户**（FM-03）。
8. 不输出禁用结论："账已平 / 可结清"这类越权判断算 FM-06。

## 4 命名规范与 MANIFEST

命名（研究库 N.3 §4）：

```
T11_E03_s{序号}_{陷阱标签}.{ext}     # 银行流水勾兑线
T11_B15_s{序号}_{陷阱标签}.{ext}     # 客户账单核对线
```

例：
- `T11_E03_s01_一对多-冲两张发票.xlsx`
- `T11_E03_s03_尾差0.02.xlsx`
- `T11_B15_s06_客户名简写全称.xlsx`
- `T11_B15_s07_无对应订单回款-不得凑平.xlsx`

每组另建 `MANIFEST.txt`，模板：

```
样本组：T11_E03_s01_一对多-冲两张发票
来源环节：银行流水(2026-07对账导出).xlsx / 订单应收(2026-07).xlsx
真实客户：{脱敏同长度替换，保留字段结构}
埋的陷阱：一笔回款 3000 对应两张发票 2000+1000；流水摘要措辞与发票客户名不一致
正确答案（判卷人对照，勿外泄给模型）：
  - L{行号} 3000.00 -> R{行号}+R{行号} = 1:N 匹配，无尾差
  - 其余记录 1:1 匹配
运行次数：___（应 ≥3）
```

## 6 G 值换算与处置

```
可用率 = 可用次数 / 总次数
≥90%→G1 放弃  70~89%→G2 降级  50~69%→G3 观察
30~49%→G4 立项  <30%→G5 优先立项  无记录→UNKNOWN 不得推测
```

- **E-03 线（银行流水）与 B-15 线（客户账单）分开计 G**，不得合并（N.2 §3）。
- 若两线 G 相差 ≥2 档 → 在族内拆"流水勾兑/账单核对"分线记录。
- 每次运行必须留模型版本、温度、原始输出全文，缺一作废。

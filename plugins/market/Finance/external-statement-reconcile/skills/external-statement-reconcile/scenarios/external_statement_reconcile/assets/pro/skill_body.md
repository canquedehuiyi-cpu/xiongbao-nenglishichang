# 外部单据对账

## 何时使用

当需要把「我方银行流水」与「对方订单 / 应收」逐笔对上、定位差异时使用。
典型场景：应收对账、回款勾稽、月度账单核对——一笔回款到底冲了哪几张发票、
有没有未回款订单、回款与发票有几毛钱尾差。

## 使用方法

1. 准备两个文本层文件（CSV / TXT 最干净）：
   - 左表（银行流水）每行 `流水:日期=... 客户=... 金额=... 单号=...`
   - 右表（订单 / 应收）每行 `订单:日期=... 客户=... 金额=... 单号=...`
2. 扫描件、图片、截图务必先转文本层——本技能不做 OCR，无法解析的行会全部标为
   「待人工」，不静默放行。
3. 运行：`python engine/main.py run --scenario external_statement_reconcile --json --task reconcile-sides --set right-file=<右表> <左表>`
4. 结果写入 ``dist_template/storage` 里的 `last_result.json``，报告在 `dist_template/output/` 目录；出现「未匹配 / 尾差 /
   跨期 / 红字冲销」提示时，把差异清单如实转告用户，不替用户下「账已平」结论。

## 不要做的事

- 不要把扫描件 / 截图直接喂入并期望做出结论——真实输入面只在文本层
- 不要编造勾兑关系把表做平：未匹配项必须原样转人工
- 不要替引擎下结论：判定只认 `dist_template/output/*.md` 报告与 JSON `state`

# 域名运营专家

**在 Qoder 中获得一位覆盖域名全生命周期的虚拟运营同事。**

插件通过阿里云 Domain MCP 协同五项专业能力，完成域名发现与估价、注册和续费、资产与 DNS 治理、ICP 备案以及万小智 AI 建站交付。

## 专家能力

- **域名发现**：查询可注册状态、参考价格、WHOIS 和行业知识
- **域名商务**：处理注册、续费、赎回、转入转出及一口价交易
- **域名治理**：管理域名资产、DNS、DNSSEC、安全锁、联系人和实名认证模板
- **ICP 备案**：提供备案咨询、官方填报入口、进度与成功备案查询
- **网站交付**：使用万小智创建、预览、绑定、发布和运营网站

## 使用前准备

安装插件后，Qoder 会通过插件声明的 `aliyun-domain` MCP Connector 提供工具。首次调用需要按 Connector 引导完成阿里云账号授权；实际能力取决于当前账号权限、域名状态和产品开通情况。

## 试着这样说

> 帮我查询 example.com 是否可以注册，并估算一年费用。

> 查看我的域名列表，找出 30 天内即将到期的域名。

> 为 example.com 添加一条指向 203.0.113.10 的 A 记录，先预览，不要执行。

> 查看我的 ICP 备案进度和下一步操作。

> 用万小智为我的域名创建一个产品介绍网站并生成预览。

涉及付费、转移、DNS 修改、身份信息、删除或发布等操作时，专家会先展示影响，等待明确确认后仅执行一次，并继续验证结果。

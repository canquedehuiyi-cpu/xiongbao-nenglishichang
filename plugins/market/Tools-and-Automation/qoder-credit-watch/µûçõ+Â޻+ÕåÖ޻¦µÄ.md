# 文件读写说明

这个插件在你机器上**读哪些文件、写哪些文件**，这里一次性列全。想知道自己的数据存在哪、要不要备份、卸载要清哪里，看这份。

一句话结论：所有会变的东西都在 `C:\Users\你的用户名\.qoder-cn\credit-watch\` 这一个文件夹里，**插件自己那一堆文件（安装包）你一个都不用动，它也不会去改。**

## 写

| 位置 | 什么时候写 | 写什么 |
|---|---|---|
| `~\.qoder-cn\credit-watch\history.jsonl` | 每采集一次追加一行 | 各号当次的余量数值、套餐、资源包明细、当次实际用的调试端口 |
| `~\.qoder-cn\credit-watch\credits.json` | 启动服务时、点「只重算」、采集完成后 | 看板页面读的那份数据（由上一份重算得出，不含 `userId`） |
| `~\.qoder-cn\credit-watch\accounts.json` | 在看板「设置」里改标签/名称、改启动端口、登记新号 | 账号名单与配置 |
| `~\.qoder-cn\credit-watch\accounts.json.bak` | 每次改上一份之前 | 自动留下的上一份，改坏了能回退 |
| `%LOCALAPPDATA%\QoderMultiAccount\p1…p20\` | 点「登录窗口」时建目录 | 只建空目录并把地址交给 Edge；里面的登录态与缓存由 Edge 自己写 |

写文件都是**先写临时文件再改名**，中途断电或关掉进程不会留下半截文件。

## 读

| 位置 | 用来做什么 |
|---|---|
| `~\.qoder-cn\credit-watch\accounts.json` | 要监控哪几个号、各自的显示名与标签 |
| `~\.qoder-cn\credit-watch\history.jsonl` | 重算看板数据的唯一输入 |
| `~\.qoder-cn\credit-watch\credits.json` | 本机服务在跑时伺服给页面（优先于包内样例） |
| 插件目录内 `dashboard\site\data\credits.json` | 没有本机数据时显示的演示样例 |
| 插件目录内 `config\accounts.example.json` | 首次生成上面那份 `accounts.json` 的模板 |
| 插件目录内 `.qoder-plugin\plugin.json` | 页面页脚与「更新日志」上显示的版本号 |
| `127.0.0.1:<端口>\json/version` | 回查某个号的登录窗口是否真的起来了（只有实测用过的端口） |
| Edge 程序与 `~\.qoder-cn` 之外的浏览器 Profile 目录 | 只负责启动窗口，不读取其中任何内容 |

## 明确不写

1. **不写插件自己目录里的任何文件**——包内那份 `credits.json` 永远是演示样例，不会被你的真实数据覆盖。
2. 不写注册表、不加开机启动项、不装服务、不往你打开的项目目录里留东西。
3. 不保存、不导出、不上传任何密码 / cookie / token；凭据一步都不离开浏览器。
4. 对远端只发读取请求（GET），不代领、不改任何远端状态。本地服务只监听 `127.0.0.1`。

## 备份与卸载

1. 要备份就整个拷走 `~\.qoder-cn\credit-watch\` 这一个文件夹——`history.jsonl` 是你全部的采集历史。
2. 升级或重装插件不会动它；换电脑把它拷过去就接着用。
3. 不想要了：删掉 `~\.qoder-cn\credit-watch\`（数据与配置），以及 `%LOCALAPPDATA%\QoderMultiAccount\`（各号登录窗口，删掉即退出登录）。

# 功能一览

> Ocean's Credits Inspector —— Qoder CN 桌面端插件。
> 一句话：把**当前会话烧了多少 token / credits、都花在哪**，变成一张自动刷新的图形报告。

## 报告里能看到什么

| 功能 | 你能得到什么 |
|---|---|
| 消耗总览 | 计费输入总量、Credits、当前上下文占用、重发放大倍数，一屏看清 |
| 当前上下文占用 · 该不该压 | 头条直接按你设的压缩阈值给结论（盈亏线 / 性价比区间 / 尽快压）；段内只增不减，最新占用就是自上次压缩以来的峰值 |
| 自动压缩不会触发的醒目告警 | 自定义模型窗口很大（如 1M）时，你设的上限（如 200K）根本不会触发 Qoder 自动压缩——单独一块告警点破，提醒你自己手动压 |
| 按类别 / 工具 / 文件占比 | 定位「哪个文件、哪类内容最烧 token」，文件精确到路径 |
| 榜单「单次」维度 | 把「次数少但每次极贵」的操作从总量榜里捞出来 |
| 缓存命中 | 输入总量里被供应商上下文缓存打折的部分 |
| 压缩单笔成本 | 每次压缩的输入、摘要输出、省下多少、耗时——往往是会话里单笔最贵的调用 |
| 逐请求明细 | 每笔往返的 token 与耗时 |
| 链路健康度 | 一行结论：代理覆盖率、最近记录时间、有无失败 |
| 系统提示词提示 | 占比高时提醒你：它每轮完整重发、大小由装了多少插件 / 技能决定，是少数你能直接压低的一项 |
| 子 Agent 汇总 | 把子会话消耗并入主报告，并给出本地覆盖率 |
| 自动刷新 | Agent 每次结束响应即重算落盘，无需手动操作 |

## 自定义模型（BYOK）实测 token

千问、通义、DeepSeek 等 OpenAI 兼容端点不经 Qoder 计费，报告里 token 会显示「—」。插件自带一个本地记录代理来补上：

| 功能 | 说明 |
|---|---|
| 供应商实测 token | 透明转发、记下每笔实测输入 / 输出 / 缓存 token（Credits 仍「—」，因为确实不经 Qoder 计费） |
| 一键配置并拉起 | 写好配置 + 当场拉起 + 输出可直接粘贴的 Base URL，无需再开会话 |
| 开会话自动拉起 | 新建会话那一刻自动检查并启动，无需手动 |
| 免装 Node | 借 Qoder 自带运行时，本机不用装 Node.js |
| 一键停用 | 改回官方模型时停用；停用与否都不影响官方模型出数 |
| 真实模型窗口自动识别 | 一般能自动认出你所用模型的上下文窗口；认不出时报告顶部告警并指引手工锁定 |

## 在对话里直接用（推荐）

不用敲命令、不用手改配置、不用装 Node——直接对 Agent 说，或用斜杠命令 `/credits-inspector`：

- 「这个会话花了多少 token？」「哪个文件最耗 token？」「现在该压一下上下文吗？」→ 读报告给你文字速览。
- 「帮我配 BYOK 代理，地址是 xxx」「查代理状态」「停用代理」→ 后台代跑配置 / 自检 / 停用。
- 「检查一下代理」→ 对话或压缩不对劲时，代跑逐笔请求诊断，分清是代理、供应商还是客户端。

## 数字准不准

| 指标 | 精度 |
|---|---|
| 计费输入总量 / Credits | 真值，精确 |
| 当前上下文占用 | 精确（自最近一次压缩起算） |
| 模型上下文窗口 | 一般能自动识别；识别不到时回退默认值并告警，可手工锁定 |
| 重发放大倍数 | 由真值派生 |
| 按类别 / 工具 / 文件占比 | 总量精确，内部拆分为按比例估算 |
| 输出 token / 缓存命中 | 真值，仅配了代理的自定义模型会话有 |
| 压缩单笔成本 | 客户端自估；能在代理日志里唯一对上时换成供应商实测，报告用「口径」列标明 |

一句话：**总量、占比可信；单个文件的绝对 token 是估算值，用来看相对高低，别当精确账单。**

## 可靠性与隐私

- **无值显示「—」，绝不显示 0**：本地读不到的数字不会伪装成「实测 0」，让你误以为没花钱。
- **手工 / 代理数字绝不冒充 Credits 真值**。
- **代理逐字节透传，不落 API key、不存请求 / 响应内容**：只记 token 元数据；日志自轮转、有大小上限。
- **部分覆盖不当全量**：混合链路里 Credits 只来自部分往返，报告会标明是几笔、占多少，避免被当成单价。

## 平台与限制

- Windows + Qoder CN 桌面端。
- 首次安装或更新后请重启一次 Qoder CN，自动刷新与代理拉起才生效。
- 仅桌面端会话有完整 token / credits；IDE / JetBrains 插件端本地读不到计费数据，token / credits 显示「—」（数据源限制，非故障），但工具调用 / 文件读取 / 对话轮数两端都准。
- BYOK 仅桌面端可配，配好即有供应商实测 token（Credits 仍「—」）。

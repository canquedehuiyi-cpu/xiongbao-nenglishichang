## 业务相关 FAQ

### 备案相关

#### 如何在网站添加和更新 ICP 备案号？
ICP 备案完成后，备案号将自动悬挂在页面底部。**首次备案通过后，备案号通常在 24 小时内自动同步**，无需手动添加。如需修改，进入万小智 2.0 后台，选择 **域名管理 > 悬挂备案号**，编辑保存即可。

#### 如何备案？
使用万小智 2.0 搭建的网站需要完成 ICP 备案后才能正常访问：
1. 登录阿里云备案控制台。
2. 填写主体信息和网站信息，提交备案材料。
3. 阿里云初审和管局审核通过后，备案完成。

如审核未通过，请根据驳回原因修改后重新提交。详细操作参见 [ICP 备案流程](https://beian.aliyun.com/)。

#### 个人注册的域名能用来企业备案吗？
可以，但需先将域名持有者变更为企业，使域名持有者与备案主体一致。登录域名管理控制台完成域名持有者信息修改（过户）后，再提交企业备案申请。

> **注意**：备案要求因地区而异，部分省份不允许已备案的个人域名变更为企业备案，具体以阿里云备案控制台实际要求为准。

### 费用相关

#### 产品购买后还有其他费用吗？
购买后即可使用基础功能，无额外必选费用。如需使用 AI 生成内容、多语言翻译等高级功能，可按需增购灵感值资源包。

#### 灵感值退款规则？
灵感值资源包一经购买不支持退款。已购买的灵感值在有效期内可正常使用，过期自动失效。建议根据实际使用量合理选购。

#### 多语言翻译如何计费？
- 多语言翻译按字数消耗灵感值，**每千字消耗 10 灵感值**（以源语言实际字数为准）。
- 智能翻译功能开启时不扣费；仅当多语言页面首次被访问时触发实时翻译并消耗灵感值（受网络影响约有 5~10 秒延迟）。
- 翻译结果自动缓存，同一页面后续访问直接调用缓存，不再重复扣费。

#### 灵感值扣减顺序？
账户内存在多种灵感值时，扣减顺序如下：
1. 按到期时间优先消耗即将到期的灵感值；
2. 到期时间一致时，顺序为：试用时免费赠送灵感值 → 购买版本赠送灵感值 → 资源包灵感值。

#### 续费后的 CDN 流量是多少？
由所选续费规格决定，具体额度请在续费页面查看对应规格说明。

### 功能相关

#### 是否支持保存源码？
当前所有版本不支持导出或保存网站源码。万小智 2.0 采用在线托管模式，网站内容和样式通过平台管理和发布。

#### 万小智 2.0 有页面数量限制吗？
无绝对上限，但每个版本有对应的数据库空间限制。数据库空间用满后无法新增页面。建议根据网站规模选择合适的版本规格。

### 升级相关

#### 万小智 1.0 可以升级到 2.0 吗？
不支持在线升级。如需使用万小智 2.0，需先将万小智 1.0 退款，再重新购买万小智 2.0。

## 功能相关 FAQ

### 基础操作

#### 应用的后台功能在哪管理？
在应用页面顶部，单击 **管理** 进入后台管理页面，包含：
- **域名管理**：绑定自定义域名。
- **内容管理**：管理表单数据。
- **应用工具**：配置智能翻译、智能问答等扩展功能。

#### 如何编辑应用？
在应用页面顶部，单击 **编辑** 切换至编辑状态，支持：
- 通过 AI 对话生成或修改页面内容、布局和样式。
- 拖拽调整页面组件位置。
- 预览效果后发布更新。

#### 如何使用案例？
案例是预设应用模板，涵盖企业官网、电商、博客等场景：
1. 访问新建应用页面，浏览精选案例并选择目标模板。
2. 单击案例可预览效果。
3. 选择心仪模板，单击 **应用复制**。
4. 购买完成后，在案例基础上自定义编辑。

#### 对话生成的历史版本如何切换？
在编辑页面左侧对话框中，单击历史版本按钮查看所有 AI 对话生成的历史版本，选择目标版本即可切换。

> **注意**：切换版本后当前页面内容会替换为所选版本，切换前请确认当前编辑已保存或发布。

#### 如何使用密钥？
当网站需要调用第三方 API 并通过边缘函数实现时，系统会在 AI 对话过程中弹出密钥输入窗口：

| 字段 | 类型 | 是否可修改 | 说明 |
|------|------|------------|------|
| Key | 文本（只读） | 不支持 | 系统自动生成，仅支持字母、数字、下划线，且必须以字母或下划线开头 |
| Name | 文本 | 支持 | 默认为中文名称，可自定义 |
| Value | 密码输入 | 需用户填写 | 输入内容默认隐藏，可切换明文显示 |

注意事项：
- Key、Name、Value 一一对应，可能存在多条密钥条目。
- 若未填写 Value 就继续对话，弹窗卡片将变为不可操作状态，需先完成密钥填写。
- 密钥配置完成后，系统将在后续对话中调用对应第三方 API。

#### 如何管理已配置的密钥？
1. 在应用页面顶部，单击 **管理** 进入后台管理页面。
2. 左侧导航栏单击 **密钥管理**。
3. 可执行搜索、添加、删除等操作。

> **说明**：密钥列表仅展示 Key 和 Name，不展示 Value。系统默认创建的密钥不支持删除。

### 域名配置

#### 网站发布如何绑定域名？
> **重要**：国内节点绑定域名前需完成 ICP 备案，才能通过域名正常访问。

1. 在应用页面顶部，单击 **管理** 进入后台管理页面。
2. 左侧菜单单击 **域名管理**。
3. 单击 **添加域名**，输入域名并完成绑定。

CLI 中可使用：`wxz domain bind example.com --watch`

#### 如何添加 CNAME 解析？
- 域名在阿里云注册：系统自动添加 CNAME 解析记录，无需手动操作。
- 域名在其他注册商注册：需前往注册商的 DNS 管理控制台手动添加 CNAME 记录，具体参见域名管理文档。

CLI 中可查看详情：`wxz domain describe example.com`

#### 是否支持绑定中文域名？
支持。将中文域名转换为 Punycode 编码格式后即可绑定（例如 `中文.com` 对应 `xn--fiq228c.com`）。绑定 Punycode 格式域名后，SSL 证书配置方式与普通域名一致。

### 内容管理

#### 表单功能如何实现？
在编辑状态下，通过 AI 对话描述表单需求即可自动生成表单组件。示例指令：
- "帮我创建一个联系我们的表单，包含姓名、邮箱和留言字段"
- "添加一个预约登记表，需要选择日期和时间"

表单收集的数据可在 **管理 > 内容管理** 中查看。

### 多语言支持

#### 产品支持多少种语言？
标准版及以上版本支持 **22 种语言**。

#### 多语言如何开启？
- 进入后台管理页面，左侧菜单单击 **应用工具**。
- 或在编辑状态下，通过 AI 对话输入「开启多语言」。

开启后页面出现多语言切换按钮，访问者可切换显示语言。

## 操作相关 FAQ

### 文章与分类管理

#### 如何修改文章、产品分类以及新增分类？
1. 单击 **管理**，左侧导航栏选择 **内容管理 > 文章管理**。
2. 单击目标文章后的 **编辑**，进入文章详情页。
3. 在分类区域选择已有分类进行更换。
4. 如需新增分类，在 **分类管理** 中添加新的分类选项。

### 页面编辑

#### Banner 图位置可以添加视频吗？
可以。在页面编辑器的 Banner 编辑区域，选择视频类型素材进行上传或引用。添加视频后展示效果为通栏模式，视频将占据整个 Banner 区域宽度。

> **注意**：上传时请注意平台对视频格式和大小的限制，具体以实际提示为准。

#### 页面编辑完如何保存？
无需手动保存。页面编辑器在编辑过程中自动保存，修改内容不会因意外关闭而丢失。建议在重要修改后确认页面已完成自动保存再离开。

### 风格生成

#### 生成的风格不满意可以重新生成吗？
可以，有两种调整方式：
- **整体重新生成**：在万小智控制台应用列表选择新建应用，重新对话生成完整风格方案。
- **局部微调**：通过对话功能描述需要调整的内容，系统进行针对性修改。

> **重要**：试用中的应用可以删除，已经购买的无法删除。删除应用前请确认已备份重要内容，删除后数据将无法恢复。

### URL 管理

#### 如何修改页面 URL 地址名称？
页面 URL 地址名称无法在后台管理界面直接修改，需在对话功能中完成。例如输入：
```
请将品牌故事的 URL 地址 /about 修改为 /ppgs
```
系统将根据指令自动更新对应页面的 URL 地址。

> **注意**：修改后请检查已分享的链接是否需要同步更新，旧链接可能无法正常访问。

## wxz CLI 使用 FAQ

### `chat start --yes` 执行完后还需要 `chat send` 吗？
不需要。`--yes` 是全自动模式，会跳过所有交互确认，自动走完「需求收集 → PRD → 代码生成」全流程。执行完毕后直接跳到 `wxz preview` / `wxz deploy publish`，不要再调 `chat send`。

### `chat start`、`chat send`、`chat generate` 需要后台执行吗？
是的。这些均为长时间运行的 SSE 流式命令（通常 1~5 分钟），必须使用后台方式执行，避免阻塞主流程。启动后每隔 15~20 秒调用 `wxz chat status` 检查进度，直到 `phase: generate_code` 且状态为 `completed`。

### 发布前需要做什么？
发布前必须先到站点购买页面完成开通，否则 `wxz deploy publish` 会失败。购买地址：
```
https://wanxiaozhi.aliyun.com/webdesign/home#/ai/preview?conversationId={conversation_id}
```
`conversation_id` 可从 `wxz chat status` 或 `~/.wxz/session.json` 获取。

### 如何查看账号和灵感值余额？
```bash
wxz account
```
输出包括账号 ID、身份类型、用户名、套餐、灵感值可用余额及累计消耗等。

### 如何绑定自定义域名？
```bash
# 绑定并跟踪进度
wxz domain bind www.example.com --watch

# 查看绑定进度/详情
wxz domain status www.example.com --watch
wxz domain describe www.example.com
```

### 如何为对话启用技能/插件？
1. 使用 `wxz plugins list` 查看当前项目可用技能 ID。
2. 在 `chat start` 或 `chat send` 时通过 `--skill <skill_id>` 激活，例如：
   ```bash
   wxz chat start "做一个带身份证识别的表单页面" --skill ocr-ai
   ```

### 产品概述

**万小智 2.0 定位**：依托大语言模型和代码生成技术，通过自然语言描述需求，自动生成包含前端、后端、数据库的完整网站项目，并支持一键部署。适合企业官网、内容资讯、在线预约、轻量级业务应用等场景。

**核心优势**：
- 自然语言建站，无需编码。
- 全栈交付：前端页面 + 后台管理系统 + 数据库模型 + 服务端逻辑。
- 可视化编辑器，支持拖拽调整模块。
- 首次生成约 5~10 分钟，集成域名绑定、DNS 解析、免费 HTTPS。

### 计费与版本

- 费用由「版本订阅费 + 灵感值资源包」组成，均为预付费。
- Web 应用版本（中国内地节点）：轻量版 360 元/年、标准版 980 元/年、高级版 1980 元/年。
- 1 灵感值 = 0.01 元；首次使用赠送 2000 灵感值（试用网站需购买版本后才能发布）。
- 常见消耗：AI 应用开发约 70 灵感值/轮、AI 生图 20 灵感值/张、多语言翻译 10 灵感值/千字。
- 新购后 5 天内支持无理由退款；灵感值资源包不支持退款。
- 应用过期后无法访问，到期数据保留 15 天，超期未续费将释放。

### 快速入门：创建第一个应用

1. 访问万小智控制台，进入新建应用页面。
2. 选择预设模板或用自然语言描述需求。
3. 与 AI 对话细化需求，生成并确认 PRD。
4. 等待 AI 生成网站（通常 5~10 分钟）。
5. 预览与编辑，支持可视化编辑和 AI 对话修改。
6. 首次发布需购买版本；如需公网访问，绑定域名并完成 ICP 备案（内地节点）。

**分享预览**：预览链接为临时地址，有效期 15 天，到期自动失效，不可续期。

### 小程序创建

- 在控制台切换到「小程序应用」模式。
- 描述需求、确认 PRD、生成应用。
- 发布前需绑定微信小程序账号（扫码授权）。
- 需设置隐私政策、服务类目；若未备案，发布后仅支持成员调试。
- 发布新版本通过右上角「更新」按钮发起。

### 应用编辑

编辑器提供「编辑模式」与「预览模式」：
- **文本**：双击快速编辑，支持 AI 生文、样式设置、添加链接。
- **图片**：支持素材中心选择、本地上传（JPG/PNG/GIF/WEBP，单张最大 10 MB）、AI 生图、裁剪。
- **列表模块**：可指定数据源（文章/产品/分类），目前仅支持按发布时间倒序。
- **页面管理**：可新建页面、配置 TDK、删除页面。
- **多语言**：标准版及以上支持 22 种语言；编辑仅在源语言环境下进行；默认开启同步翻译，可单独取消某语言同步。

### 应用发布

- 首次发布必须购买版本；中国内地节点域名需 ICP 备案。
- 部署节点：中国内地（需备案，访问快）或中国香港（无需备案，内地访问可能延迟）。
- 购买后支持中国内地升级至中国香港（预计 10 分钟迁移，期间不可访问），不支持反向迁移。
- 重新发布会自动生成版本记录，可在「发布历史」中切换版本。

### 域名管理

- 一个网站可绑定多个域名；系统自动添加带 `www` 前缀的域名。
- 阿里云账号下域名支持一键解析；其他域名需手动添加 CNAME/TXT 记录。
- 一键 HTTPS 证书有效期 90 天，到期前自动续期；也支持手动上传自有证书。
- 中文域名需转换为 Punycode 后绑定，不支持 CDN 和 HTTPS。
- 内地节点网站底部需悬挂 ICP 备案号和公安备案号。

### 内容管理

- **预置表**：文章管理、产品管理。
- **AI 自定义数据表**：通过自然语言描述字段需求自动生成。
- 文章/产品支持保存草稿、立即上线、上线/下线、删除（进入回收站）。
- 删除的内容在回收站保留 30 天后自动永久清除。

### 插件与密钥

- 插件可通过对话区图标直接选择，或输入 `@` 调用。
- 支付宝支付需扫码授权支付宝商户应用；一个支付宝应用只能授权给一个服务商，重复授权会导致原授权码失效。
- 文本/图片/视频生成大模型、OCR 等插件消耗灵感值。
- 调用外部服务时，系统会弹出密钥输入窗口；Key/Name 由系统生成，Value 需用户填写。密钥加密存储，代码中不暴露明文。

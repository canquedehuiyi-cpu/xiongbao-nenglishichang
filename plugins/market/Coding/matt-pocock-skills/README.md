# Matt Pocock Engineering Skills

基于 [mattpocock/skills](https://github.com/mattpocock/skills) 移植的 Qoder 插件。

Matt Pocock 的日常工程代理技能集，面向真实工程实践，拒绝氛围编程。

## 包含技能（25 个）

所有技能均可由模型依据 description 自动触发，也可手动调用（如 `/grilling`、`/tdd`）；技能互调时引用短名（如 `grilling`），实际调用按你环境可用技能列表中的确切形式填写（短名或限定名，如 `matt-pocock-skills:grilling`）。

### Engineering（18 个）

| 技能 | 说明 |
|------|------|
| ask-matt | 技能路由器，询问哪个技能适合你的场景 |
| grill-with-docs | 需求拷问 + 同步生成 ADR 和术语表 |
| triage | Issue 分类状态机流转 |
| improve-codebase-architecture | 扫描代码库深化机会并生成 HTML 报告 |
| setup-matt-pocock-skills | 一次性配置 issue tracker 和领域文档 |
| to-spec | 将对话综合为 spec 发布到 issue tracker |
| to-tickets | 将计划拆分为 tracer-bullet tickets |
| implement | 根据 spec/tickets 实现工作 |
| wayfinder | 规划超大规模工作为决策 ticket 地图 |
| code-review | 双轴代码审查（Standards + Spec） |
| tdd | 测试驱动开发，红-绿-重构循环 |
| diagnosing-bugs | 疑难 bug 诊断循环 |
| prototype | 构建一次性原型验证设计 |
| research | 调研并记录到仓库 Markdown |
| domain-modeling | 构建和打磨领域模型 |
| codebase-design | 深层模块设计词汇表 |
| resolving-merge-conflicts | 解决 git merge/rebase 冲突 |
| wizard | 生成交互式 bash 向导 |

### Productivity（7 个）

| 技能 | 说明 |

| to-questionnaire | 将决策转化为问卷 |

| grilling | 通用拷问原语 |

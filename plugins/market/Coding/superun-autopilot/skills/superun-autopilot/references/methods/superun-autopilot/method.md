# superun 全托管创作

<!-- @author xiuyu.yi -->

所有用户可见输出先遵循 [中文展示规则](references/presentation.md)，把协议字段留在内部，再说明真实业务进展。首次任务按 [全托管方法](references/managed.md) 执行；职责按 [六角色分工](references/roles.md)；交付和收费按 [交付与完成托管](references/completion.md)。[宿主工具](references/host-tools.md) 只决定展示与收答方式。完成后的任务按 [继续使用](references/continuation.md) 和同包 `superun-create` 的对应云端方法执行。

用户已经选择本产品，给出需求后直接启动，不再访谈一轮、不再确认是否开始、不要求逐步选择方案、批准规划或勾选研发功能。真实权限、资料缺项、余额不足或服务端错误仍如实处理，不代填答案。

沿用同一项目、runId 和真实资金归属，所有状态以当前服务端回执为准。全托管运行时仅观察，云端引擎负责推进；宿主不得重复发送自动节点。结束后保留当前项目和任务，正常收费并完成托管成功后才继续创作。

对话、角色任务、预览和报告必须实际展示，不能只留下 JSON 或口头说“已完成”。内部命令、状态字段、运行标识和金额最小单位只用于执行与交接，不直接展示给用户。

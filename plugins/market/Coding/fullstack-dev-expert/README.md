# 全栈开发专家

Java Spring Boot + Vue 3 全栈开发专家插件，覆盖 API 设计、组件开发、业务开发、代码审查、单元测试、数据库设计、性能调优、重构建议 8 大核心场景。内置 RESTful 规范、Composition API 最佳实践、MyBatis-Plus 分层模板、JUnit/Vitest 测试策略、索引优化方案、JVM 调优参数、前端打包优化等实战方法论，帮助开发者快速产出高质量代码。

> **Disclaimer:** 本插件辅助开发工作，生成的代码需结合项目实际情况调整后使用，不替代架构评审和安全审计。

## 目标角色

- **Java 后端工程师** — 快速生成 Spring Boot 分层代码、数据库设计、SQL 优化
- **Vue 前端工程师** — 高质量组件开发、状态管理、渲染性能优化
- **全栈工程师** — 前后端联调、API 设计、代码审查一站式覆盖
- **技术负责人** — 代码规范落地、重构建议、性能瓶颈定位

## 快速命令

| 命令 | 说明 |
|------|------|
| `/API接口设计` | 设计 RESTful API，生成 OpenAPI 文档和 Controller 骨架 |
| `/Vue组件开发` | 编写 Vue 3 组件，含 Composition API + Pinia + UI 库集成 |
| `/Java业务开发` | 生成 Controller/Service/Mapper 分层代码 |
| `/代码审查` | Java + Vue 双向代码 Review，标注严重度和修复方案 |
| `/单元测试` | JUnit 5 + Vitest 测试用例生成，含 Mock 策略 |
| `/数据库设计` | 建表 DDL、索引策略、慢 SQL 分析、Entity 映射 |
| `/性能调优` | JVM 调优、SQL 优化、前端渲染/打包性能提升 |
| `/重构建议` | 识别代码坏味道，应用设计模式重构 |

## 技能详情

| 技能 | 说明 |
|------|------|
| API接口设计 | RESTful 规范 + OpenAPI 3.0 文档生成 + 统一返回结构 + 查询参数规范 + Java Controller 骨架输出 |
| Vue组件开发 | Vue 3 `<script setup>` + TypeScript + Composition API 模板 + Composable 提取 + Pinia Store + 权限指令 + CRUD 页面模式 |
| Java业务开发 | Spring Boot 分层架构（Controller/Service/Mapper）+ MyBatis-Plus BaseMapperX + DTO/VO/DO 转换（MapStruct）+ 全局异常处理 + 统一返回 |
| 代码审查 | Java 端 6 维度（空指针/并发/SQL/安全/性能/规范）+ Vue 端 5 维度（响应式/内存泄漏/性能/安全/规范），按 Critical/Major/Minor/Info 分级输出 |
| 单元测试 | JUnit 5 + Mockito（Java）+ Vitest + Vue Test Utils（Vue），Given-When-Then 结构，参数化测试，覆盖率 ≥80% |
| 数据库设计 | MySQL 建表规范 + 索引设计（最左前缀/覆盖索引）+ EXPLAIN 分析 + 慢 SQL 优化模式 + MyBatis-Plus Entity 映射 |
| 性能调优 | JVM 参数 + Arthas 诊断 + SQL 优化 + 缓存策略（穿透/击穿/雪崩防护）+ 前端打包分包 + 虚拟列表 + 防抖节流 |
| 重构建议 | 6 类 Java 坏味道 + 4 类 Vue 坏味道识别 + 策略模式/模板方法/责任链等设计模式应用 + 重构前后对比 |

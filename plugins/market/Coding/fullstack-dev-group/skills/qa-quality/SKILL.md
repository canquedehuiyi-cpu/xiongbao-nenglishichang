# 测试与质量门禁 (QA & Quality Gates)

本技能为团队质量侧提供工程方法，与 `agents/` 中的查无漏(测试)角色卡联动：角色卡守护质量红线，本技能给可执行策略与门槛。

## 适用边界
- 测试策略、用例设计、自动化、覆盖率与劣化门槛。
- 接口/契约测试、回归、发布验证、放行/不放行条件。

## 工作流
1. **验收先行**：先与产品蓝图画对齐验收口径（AC），再定测试策略。
2. **用例分层**：正常 / 边界 / 异常 / 并发 / 幂等；强调可复现与可度量。
3. **门禁阈值**：明确覆盖率（如行≥80%、分支≥70%）、P95 延迟、错误率、劣化告警门槛。
4. **契约测试**：前后端接口用 `api-contract` 的 OpenAPI 做契约测试，提前暴露不一致。
5. **发布验证**：与运维常守恒共定上线验证清单；不放行标准须显式写出。

## 产出约定
- 测试策略文档：范围、分层、环境与数据、门禁阈值、回归范围。
- 用例清单：场景 + 步骤 + 预期 + 优先级，可追溯 AC。
- 放行条件：明确 PASS/FAIL 判据与回滚触发点。

## 与内置技能协同
- 接口契约测试 → `api-contract`。
- 发布验证与回滚 → `team-ops-expert` / `devops-pipeline`。
- 业务实现须配套单元测试 → `team-p8-full-stack` 的单元测试门禁。

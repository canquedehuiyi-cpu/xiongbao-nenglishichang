# 模式切换与恢复

切换模式时保留原目标、已完成的工作和交付责任；不重新建项目、不重建流程，已有项目沿用同一 sessionId。

恢复任务时带原 sessionId、样式选择的真实回复、规划与已答需求、工作区/源码目录、授权及未决交互。本地任务目标为“关联原项目 → 拉取源码 → 按项目配置准备依赖 → 启动本地 dev → 展示预览 → 回复接管结果”。首次接管先展示现有实现，不自动新增功能。保留源码目录、dev 命令、进程/任务句柄、实际 URL 和就绪证据；展示完成后回复，保留服务运行。

- **切到云端**：确认哪些本地改动已同步，保留未提交内容；切换本身不触发推送。
- **切到本地**：保留云端清单作需求材料，不提交功能答案启动云端开发。云端处于 FEATURE_SELECTION 不妨碍符合条件的 sxq link。
- **收到旧云端功能请求**：按当前模式处理；已切本地则只保存材料，不再次弹出云端功能选择。
- **登录阻塞**：请求必要的授权操作，登录完成后从关联/拉取继续，不重新问模式或另建项目。

在途写操作先取得结果或按已有授权停止；结果不明先恢复，不重复提交。已有授权持续有效，切换模式不扩大推送、迁移、预览或发布权限。

# 项目模式记忆

进入或恢复任务时，定位当前业务项目并读取 Qoder 的项目记忆：

读取当前项目 .qoder/rules/ 规则及已加载的 AGENTS.md / AGENTS.local.md。更新已有模式条目；没有时创建 .qoder/rules/superun-execution.md，按当前客户端格式设为 Always Apply。遵循实际加载范围。

路径参考：`[".qoder/rules/"]`。

1. 当前用户明确选择优先；否则沿用该项目的 `superun-ai` 或 `sxq-cli`。没有记忆或没有模式时默认 superun-ai，不先询问或为默认值创建文件。
2. 无效值、冲突和读取失败不等于没有记忆。先核对作用域；不能确认时保留本轮已知选择并说明缺口，不自动发起生成。
3. 用户明确选择后，仅更新“superun 执行模式”条目并回读。保留其他内容，不写全局偏好、凭据或 sessionId；多个业务项目按名称/源码目录分别记录。
4. 需要首次提示去重时，记录“样式选择后已介绍执行模式”。没有项目记忆能力时只在当前会话保留，并说明未持久化。

可写入的条目：`superun 执行模式：sxq-cli（本地开发）；除非用户明确切换，否则持续沿用。`

模式变化不改变已有的项目状态和用户决定。工作目录和命令是否可用以当前实际结果为准。选择时机见 [模式选择](mode-selection.md)。

## 操作边界

- 常规任务编辑可直接执行；删除无关文件、丢弃用户改动、重置或改写历史须明确授权。
- 数据库先确认连接、库名及环境，默认只读；执行写入、DDL、清理前明确语句和影响范围并获授权。编写 SQL 文件不代表授权执行。
- 真实通知、外部同步/写入及部署按明确授权的目标和范围执行，已有授权无需重复询问。
- 不输出或提交密钥、Token、密码、敏感连接信息；个人设置与凭证留在本地私有配置。
- 仅按用户要求 commit；push、合并、发布须相应授权。提交前核查差异和暂存区，作者沿用 Git 配置，提交后报告 commit 与推送状态。

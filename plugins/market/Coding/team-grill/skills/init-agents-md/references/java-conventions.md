# Java 规则的项目适配

仅在目标项目包含 Java 业务代码时读取。具体格式和注释示例统一维护在 [Java 细则资源](../assets/agent-guides/java-conventions.md)，API 内容在 [接口细则资源](../assets/agent-guides/api-conventions.md)。这些是生成材料，不是目标项目扫描结论。

- 保留用户当前要求及已有明确团队规范；其次参考生效的格式配置和代表性手写代码。默认采用 IDEA 风格、4 空格及同行花括号，不因旧代码与新规范不同而改回旧风格。
- 根 AGENTS.md 只摘要格式和注释要求，链接目标项目内的详细文档；不复制完整 Javadoc 示例进去。
- 类/方法作者在写代码时读取 `git config user.name`，日期使用创建当天；配置缺失时询问，不固定初始化操作者或日期。
- Lombok、MapStruct、Swagger/OpenAPI 等只在项目已使用时写入。核对实际注解体系，不混用版本，不为满足模板增加依赖。
- 资源复制到目标项目后，按实际语言、框架和约定调整；已有资料合适就直接引用，避免另存一份重复规范。

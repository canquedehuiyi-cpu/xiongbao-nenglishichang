# 检查与初始化 AGENTS.md

产出简洁的项目入口：根文件保留高频原则、项目地图、验证命令和操作边界；条件性细则放入专题文档。保留用户有效约定，不复制来源项目的技术栈、路径或历史验证结论。

## 工作方式

- 检查/审查：只读报告，不写文件。
- 初始化：缺失时在指定位置或仓库根目录生成。
- 明确要求修改/精简/修复：在授权范围内原地更新；要求候选/对比时写指定路径或 `AGENTS.generated.md`。
- 只输出正文：不写文件；仅调用技能时，有文件先检查，无文件则初始化。
- 候选已存在时使用新后缀，除非用户授权覆盖；候选/只读模式不复制附属文件。

## 核对依据

先检查 Git 状态、现有 AGENTS.md 和适用的上层/模块规则。按 [扫描清单](references/project-scan.md) 核对将写入的事实，仅查相关配置、代表性源码、调用方、测试和文档，不遍历整个仓库。

风格优先级：当前用户要求 > 明确团队约定 > 格式配置 > 代表性手写代码 > 适用默认值。旧代码不符合新规范不代表新规范错误；有效规则冲突时指出差异。配置声明、依赖解析和运行结果分别表述，不凭旧文档写“已核实”。文档初始化无需构建、启动、数据库写入或真实通知。

## 精简与生成

参考 [入口模板](assets/AGENTS.template.md)，按项目删减，不强制章节数量或凑字数。根文件通常控制在 80–110 行，复杂项目可适当超出；不以行数代替规则完整性。

- 根文件保留：中文沟通、范围与已有改动保护、先检索再复用、业务值定义、相关验证、外部写入/Git 边界、按变化同步文档，以及按需资料入口。
- 重复约束合并；注释示例、OpenAPI 字段细则、归档规则和文档模板不在根文件展开。
- Java 项目读取 [Java 适配说明](references/java-conventions.md)，将排版和注释细则放在 `docs/agents/java-conventions.md`；非 Java 项目省略，不引入 Java 规则或依赖。
- 已使用 Swagger/OpenAPI 的项目，将模型、示例及展示验证细则放在 `docs/agents/api-conventions.md`；沿用实际框架，不要求未接入的项目安装。
- 正式资料归档规则放在 `docs/agents/delivery-conventions.md`。接口契约变化更新 API，数据库变化提供 SQL；设计文档及图示仅在用户明确要求时生成，不作为默认验收项。
- 保留既有归档目录、语言风格和迁移工具约定。无约定时使用 `docs/releases/<类型>-<目标版本>/`；目标版本以发布安排为准，普通 SQL 三位编号，迁移工具遵循原命名，已执行脚本追加修正。
- 每个专题链接都写明读取条件，设计模板单列“用户明确要求设计文档”的条件；新增资料仍须从根入口可达。已有资料优先引用或合并，不能因拆分丢失要求或复制维护多份同义规范。

## 可复制资源

以下资源作为生成材料，不是要求一次性执行的流程：

| 条件 | 来源 → 默认目标 |
| --- | --- |
| Java 项目 | [Java 细则](assets/agent-guides/java-conventions.md) → `docs/agents/java-conventions.md` |
| 已接入在线 API 文档 | [API 细则](assets/agent-guides/api-conventions.md) → `docs/agents/api-conventions.md` |
| 需要正式交付约定 | [交付细则](assets/agent-guides/delivery-conventions.md) → `docs/agents/delivery-conventions.md` |
| 缺少对应文档模板 | `assets/document-templates/` 的 [API](assets/document-templates/接口文档模板.md)、[SQL](assets/document-templates/SQL脚本模板.sql) → `docs/templates/` 同名文件 |

[设计模板](assets/document-templates/设计文档模板.md) 为可选资源，仅在用户明确要求设计文档时引用或复制，不默认安装到目标项目。

仅复制适用且缺失的文件，再按目标项目调整规则、示例和链接；复制交付细则后，将 `../document-templates/` 链接改为目标项目实际模板路径（默认 `../templates/`），未复制的可选设计模板链接回技能资源；已有不同内容先保留，按用户授权合并。Java 资源里的作者/日期规则在写代码时获取，不固化为初始化操作者和当天日期。SQL 模板是 MySQL 示例，其他数据库按实际方言调整。

使用文件工具直接复制即可，不要求目标机器安装 Python/Node。不安装其他技能，不新增工单系统、忽略规则或自动提交。候选模式只链接已存在资源；相对路径按候选实际位置计算，说明移到根目录时需重算链接。

## 自检与交付

- 核查项目事实、路径和命令前提；所有模板占位符已替换，不泄漏来源项目名或绝对用户路径。
- 对照原文件检查重要规则保留情况、条件是否准确、重复是否消除；只读/候选模式确认原文件未变。
- 检查差异、Markdown 本地链接和代码块。根入口不要求无条件读取全部专题文件。
- 报告精简前后篇幅、修改位置和实际验证结果；区分静态核查与运行验证，未运行不声称有效。

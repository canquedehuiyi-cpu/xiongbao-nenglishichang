# Flova for Qoder

使用 Flova 在 Qoder 对话中生成图片、视频、配音和音乐，也可以通过 Flova 项目制作复杂作品或继续编辑已有项目。

## 安装与授权

1. 在 Qoder 打开「扩展 → 插件 → 添加插件 → 上传插件」，选择 `flova-0.1.0.zip`。
2. 在扩展管理中找到 Flova 连接器，按 Qoder 提示登录并授权你的 Flova 账号。
3. 新建对话，描述创作需求。例如「用 Flova 生成一张咖啡新品海报」或「继续这个 Flova 项目，调整片头并导出成片」。

如果当前客户端显示 Flova 灵感入口，也可以从那里浏览创作灵感。

随包的 Flova Skill 包含快速生成、项目工作流、Flova 服务端 Skill 和灵感的使用说明。

---

Use Flova in Qoder to generate images, video, voiceovers, and music, or to create and continue more complex productions in a Flova project.

## Install and connect

1. In Qoder, go to **Extensions → Plugins → Add Plugins → Upload Plugin** and select `flova-0.1.0.zip`.
2. Find the Flova connector in Extensions and follow the prompts to sign in and authorize your Flova account.
3. Start a conversation and describe what you want to create. For example, “Use Flova to generate a poster for a coffee launch” or “Continue this Flova project, revise the opening, and export the video.”

If your Qoder client shows a Flova Inspirations entry, you can browse creative examples there.

The bundled Flova Skill includes guidance for quick generation, project workflows, Flova server-side Skills, and inspirations.

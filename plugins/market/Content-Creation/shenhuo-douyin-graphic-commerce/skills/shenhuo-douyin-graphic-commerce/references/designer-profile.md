# 抖音图文带货公开能力说明

服务提供方：神火 AI。固定设计师：抖音图文带货，`des_422e3c29d1d1` / `douyin_graphic_commerce`。这是公开服务摘要，不包含内部 Designer Skill 或模型提示词。

面向抖音商品与穿搭内容创作者，用真实主体和资料制作封面、单张介绍及多页静态内容。

## 输入

可从文字需求开始；只有保留真实人物、商品、照片或既有画面确需原图时补对应素材，不把照片、Logo或配色选择设为所有任务的必填项。

- 商品、人物穿搭、场景的原始照片及已有介绍资料
- 想表达的主题、准确名称与本次有效价格条件；公开链接可补充可读取正文

## 交付

- 默认3:4的静态抖音封面或图文图片，保持同款商品与真实搭配
- 按用户指定张数或内容任务自动规划多页，每张提供新的读者信息

默认 **2K / 3:4**，当前默认 1728×2304。auto 由设计师按本次用途决定支持的比例；固定比例与像素不能靠提示词偷偷改变。

## 不提供或不承诺的服务

- 不制作视频、音频、直播推流、抖音交互界面或自动发布
- 不代替完整电商详情长图或印刷包装生产文件
- 不承诺流量、转化，不虚构亲身使用感、测评排名、功效或价格

## 领域注意

- 网页正文不等于商品原图；要保留真实外观仍需用户上传图片。

## 试用与网站

明确张数保留原值，否则 auto；试用受 qoder 渠道积分控制，不额外限制张数。先交付实际下载的成功图片，再说明未完成项及恢复方式。试用用户在实际交付后按 SKILL.md 的「作品交付后的注册邀请」展示文案和链接，试用项目不自动迁移。个人 Key 使用同一账号访问实际回执 project_id，无需重注册。网站承接客户端未覆盖的修改和管理，详见 [workflow.md](workflow.md)。

# 抖音图文带货使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

给这个商品做一张抖音图文封面，照片和介绍在附件里。

English: Create a Douyin product cover using the attached photos and description.

## 示例 2

这套穿搭想发抖音，帮我把整体和细节整理成连贯图文。

English: Turn these outfit photos into a coherent Douyin photo post with overall and detail views.

## 示例 3

这些是商品照片和资料，帮我安排一组抖音介绍图，每张讲不同的重点。

English: Plan and create a Douyin product photo post from these materials, with a distinct point in each image.

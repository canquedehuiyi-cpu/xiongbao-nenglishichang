# CONNECTORS — if Studio AI 智能创作 连接层说明

## 注册方式

插件安装即自动注册连接器，无需手工配置。连接层通过 iconfont-ifs 连接器接入 IFS 平台的远程
MCP 服务（MCP over HTTP + OAuth）。

- 注册配置在插件根目录 `mcp.json`（唯一来源）：服务端点以该文件为准，本文档不引用具体
  域名（产品分对内/对外版、域名不同，不向用户提供写死域名）。
- 平台与账号口径（宿主 UI 路径、IFS 平台域名、品牌、CLI registry 等）统一在插件
  `config/platform.json` 管理：domain / registry 留空 = 以连接器注册配置（mcp.json 的 url）
  为准；修改后重启 Qoder，经 hooks session-start 注入会话生效——文档与话术一律引用、不写死。
- OAuth 无需手工配置，凭据也无需管理——端点发现、客户端注册、令牌注入全部由
  Qoder 运行时自动完成（RFC 9728 发现 + 动态客户端注册 + PKCE），服务接口鉴权在传输层自动完成。
- 连接器不可用（未授权/授权过期/网络不可达）时，插件内置**降级能力**见下文「降级：官方 ifs CLI」。

## 安装与首次授权

1. 安装插件后**重启 Qoder**——连接器列表在应用启动时加载，装完不重启连不上（列表里找不到 iconfont-ifs 也先检查这一步）。
2. 首次连接收到 401 后，助手会用宿主的连接器管理工具**直接帮您把授权页唤起**（系统浏览器自动弹出）；
   没弹出时可自己走：「设置 → 扩展管理 → 连接器」找到 iconfont-ifs（标记「需要授权」）→ 点「**授权 / 连接**」。
3. 在浏览器里的 IFS 授权页用您的 IFS 平台账号登录、核对账号后点「同意授权」，即授权成功——
   **登录与同意必须您本人完成**，助手不能代点、代选身份或代输账号。
4. 完成后回对话说一声，助手会重新连接并复验；授权持久，过期后按同样方式重新授权。

- 助手能做的是**唤起**授权页（宿主提供连接器管理工具时），不能代替您走完 OAuth；该工具不可用时退化为由您自己在设置里点。
  首次（连接器不可用且此前未选择过运行方式时，且唤起未成功）AI 会在对话里弹出选择框
  （**已完成连接器授权 / 暂不授权 / 取消任务**）并附上述步骤——**推荐激活连接器获得完整能力**，
  也支持先走 CLI 降级运行：选「已完成连接器授权」后自动复验，选「暂不授权」转下方降级通道，
  选「取消任务」即停止（未选择，下次仍会询问一次）。
  **您的选择会被记住**：做出选择后，后续不再重复询问——选过「暂不授权」则默认走降级通道；
  之后您随时完成授权即可自动切回连接器。仅当降级通道无法完成某项任务而连接器可以完成时，
  AI 才会再次提示您（重新）授权连接器。
- 平台服务重启后，已连接会话可能持续报 `Not Found`——重开会话或重启 Qoder 即恢复。

## 降级：官方 ifs CLI（内置 MCP 直通）

连接器不可用（未授权/授权过期/网络不可达）时，助手可改走**官方 `ifs` CLI**（平台分发的单二进制命令行工具）继续完成任务。
CLI 内置 `mcp` 子命令，**直接调用与连接器同一套平台工具面**——同工具名、同 snake_case 参数、同返回结构：
`ifs mcp tools --json` 实时列出方法与参数 schema，`ifs mcp call ifs_canvas_create --args-file create.json`
（发消息/续聊/答复中断）、`ifs mcp call ifs_canvas_poll`（等回复）、`ifs_canvas_upload`（上传）、
`ifs_canvas_models`（模型清单）、`ifs_ping`（探活）都照常可用，生成真实发生；管理查询类能力（画布历史/资产/灵感/算力）
以实时方法面为准——无对应方法时助手如实提示「功能尚未就绪」，不编造数据。
`ifs canvas run/poll` 等**原生命令**保留为便利层（`--save-dir` 自动落盘、`--image` 本地直传、`ifs doctor` 诊断）。
生成产物**默认落盘到工作区 `outputs/`**（图片、视频一并下载；连接器与 CLI MCP 直通侧用 Bash 下载，便利层把 `--save-dir` 指向同一目录）。

- 首次使用需安装 CLI（macOS/Linux 与 Windows 均有平台分发的安装脚本；**装不上时本任务仅能经
  连接器完成授权和执行**）并完成一次登录：`unset IFS_TOKEN` 后 `ifs auth login --oauth`
  （命令自动弹出浏览器登录页，**由用户本人操作**，登录与同意助手不代点）。登录页打开后助手会**停下等您确认**，
  确认后先复验链路再继续任务；CLI 凭据与连接器授权相互独立、互不影响。
  链路是否可用以 `ifs mcp call ifs_ping --args '{}'` 返回身份与 scope 为准。
- 降级期与连接器同节奏：发消息成功后同样打开内置浏览器画布页看到实时进度，轮询、确认与产物落盘不减少。
- 降级期间生成的画布与会话 ID 和连接器通道互通；连接器恢复后可随时切回，直接续聊。

接入步骤、MCP 直通映射与调用细则见 SKILL.md references/connector.md（连接器请求模块）。

## 凭据模型

- Bearer 令牌由 Qoder 运行时托管并自动注入请求头，任何配置与文档都不存放
  token / client_secret 等凭据明文。
- 浏览器授权页由用户本人操作：授权页可由助手唤起，但严禁代点提交、代选身份、代输账号。

## 工具面

连接器工具面 = IFS 平台服务接口 + 连接器自检（探活），覆盖智能体对话核心链路：
发消息（画布创建/续聊/中断答复）、轮询、素材上传（本地文件走一次性直传票据：取票 → 本地直传 → 换取媒体 URL）、模型清单、画布授权链接（打开画布页前取登录直达链），外加探活自检；
管理查询类能力（画布历史/资产/灵感/算力）一律经连接器查询，以其实时提供的方法为准——
无对应方法时助手如实提示「功能尚未就绪」，不打开平台页面代查、不编造数据。

- 实时工具清单与参数 schema 以连接器 `tools/list` 返回为准，本文档不维护工具明细，不随工具增减更新。
- **多技能模式下的 `skill` 参数**：发消息（`ifs_canvas_create`）的 `skill` 参数携带命中的专业技能官方名（如「商品套图」「故事板生视频」），
  由对应专业技能 SKILL.md 指定、通用技能统一发出；纯通用任务可不带。连接器与降级 CLI 两条通道同口径，技能索引见 references/pro-skills.md。
- 轮询等待：慢任务（视频合成、高清出图、成套图）会持续等到完成或明确出错，期间按轮汇报进度，
  不会因为等待久而提前收尾或把跟进交回用户。
- 工具与模块的编排细则见 SKILL.md 路由表及 references/。

## 宿主连接器依赖：browser-use（外挂屏）

- 插件只注册 iconfont-ifs 一条通道；IFS **画布页**的打开/聚焦/读取（结果呈现与回看）走
  **Qoder 会话自带的 browser-use 工具族**（内置浏览器），插件不注册也无法注册；打开前先用 iconfont-ifs 的
  画布授权链接方法换回登录直达链，用户登录一次即自动回跳画布；画布页自带
  WebSocket 实时更新，**打开后不刷新**（重载会重置缩放/视图）；平台管理页
  （资产库/灵感/技能中心/账单充值）不打开——管理查询类经连接器查询，无对应方法时如实提示
  「功能尚未就绪」。
- 编排细则见 screen.md；会话缺这组工具时降级为输出链接，不影响生成链路。
- 外挂屏固定走内置浏览器，不使用 user-browser-use（扩展驱动用户日常浏览器）；
  撞登录/MFA 验证墙时停手，由用户本人操作。

## 探活与门禁

- 连接器未授权、授权过期或网络不可达时，表现为**设置里 iconfont-ifs 显示未连接 / 需要授权，或调用报 401、连接失败**——处置见「安装与首次授权」
  与 exception.md 排障表；已连接后可用 `ifs_ping` 探活。
- 服务接口的鉴权由 OAuth Bearer 在传输层自动完成；审计由本插件 hooks 承担
  （见 hooks/hooks.json）。

# IF Studio AI 智能创作

**像聊天一样做设计，让灵感逐步成为作品。**

描述需求，生成图片与视频，在同一画布上持续修改，将创作成果沉淀为可管理、可复用的设计资产。从灵感探索、方案规划到生成、迭代与导出，通过对话推进创作。

## 什么是 IF Studio AI 智能创作

IF Studio AI 智能创作是基于 [IFS（IF Studio）](https://ifs.iconfont.cn/) 的 AI 创作专家套件。IFS 由 iconfont 出品，是面向多样创作场景的智能体工作台，将专业创作思路、前沿 AI 模型与场景技能融入人机共创流程。

你可以直接用自然语言提出需求，完成图片生成、图像编辑与视频创作，也可以从参考图或已有作品出发，逐步调整风格、构图、文案和细节。套件连接平台的画布、技能与资产管理能力，让创作过程和成果有序积累。

无论是设计师、内容创作者、电商与品牌运营，还是希望表达创意的普通用户，都可以从一个想法、一句话或一张参考图开始。

## 为什么选择 IF Studio AI 智能创作

### 用自然语言表达需求

“做一张促销海报”“把商品放进客厅场景”“让这张插画动起来”——直接说出目标，再通过对话补充用途、风格、尺寸和细节，逐步明确创作方向。

### 先规划，再推进生成

对于套图、故事板、营销视频等多步骤任务，支持先梳理需求、规划方案或分镜，确认方向后分步生成。你可以在过程中调整内容，让每一步更贴近预期。

### 在同一画布上持续迭代

围绕已有方案和画面继续修改、对比与延展。更换背景、调整配色、替换文案或完善局部细节时，可以明确指出修改对象和需要保留的内容，让创作沿着已有方向持续深化。

### 用场景技能加快创作

结合图片与视频生成模型，以及商品创意图、故事板生视频、试穿效果等场景能力，处理不同类型的创作需求。也可以从“灵感发现”的分类案例出发，参考表达方式，探索适合自己的创作方向。可用模型与技能以平台实时展示为准。

### 让成果成为可复用的资产

通过历史会话、画布与资产库管理创作成果，方便回看、查找、继续修改和导出。一次创作积累的素材，也能成为后续设计的起点。

## 开始使用

1. **安装并授权**  
   安装插件后重启 Qoder。首次使用时，按提示打开 IF Studio 授权页，登录并确认授权。如果授权页没有弹出，在 Qoder 的「设置 → 扩展管理 → 连接器」里找到 `iconfont-ifs`，点击「授权」或「连接」。账号、可用算力及积分消耗以 IF Studio 页面显示为准。

2. **描述创作需求**  
   直接说明要做什么，也可以附上参考图。用途、主体、风格、尺寸、数量和必须保留的内容越明确，越便于推进创作。

3. **确认方向并生成**  
   简单需求可直接进入生成；多步骤任务可先确认方案、脚本或分镜，再逐步制作，并在对话中查看进度与结果。

4. **继续修改与导出**  
   在同一创作会话和画布中指出修改位置、目标效果及需要保留的部分，完成后管理、回看或导出成果。

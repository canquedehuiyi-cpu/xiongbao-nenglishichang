# 数字人形象生成（专业技能 · 数字人 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- **形象图**：文字描述生成数字人形象；未指定场景、景别、动作、角度时按平台默认构图。
- **口播形象**：文生口播形象图、人像转口播形象图、人像转绿幕口播形象图。
- **多角度多景别**：角度三视图、景别三视图、单景别。
- **通用编辑**：改动作姿态、表情、场景背景、服装、道具。
- 不归本技能：让数字人开口说话走「数字人口播视频」，普通商品图与服饰上身走对应技能。

## 2. 需要用户准备的素材

- **必需**：文字描述（生成类）**或**人像图（转换类）**或**待编辑的形象图（编辑类）。
- **可选**：场景、景别、角度、动作、表情、服装、道具。给了就按用户的来，不套默认构图。

## 3. 关键规则

1. **默认构图只在用户没指定时生效**：场景、景别、动作、角度任一给了，就按用户的，不覆盖。
2. **编辑类指令要锚定**：说清改哪一项，并把「别的都别动」逐字带进消息。
3. **不写镜头参数式描述**：编辑时不塞机位、焦段等拍摄术语，避免连带改变构图。
4. **人物特征保真**：转换与编辑类保持原人物的脸型、身形、肤色。
5. **产物只认真实返回**：不拿输入图或历史结果冒充，没出图不声称成功。
6. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
7. **枚举与数值以平台当次为准**：角度、景别、比例与选项以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「数字人形象生成」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

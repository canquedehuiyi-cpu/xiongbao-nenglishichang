# 视频抽帧（专业技能 · 视频 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 视频 + 时间点 → 对应时刻的画面帧：首帧、尾帧、批量定点抽帧。
- 一次给多个时间点就按时间先后逐张交付，并标注每个时刻。
- 不归本技能：分析视频内容、判断关键帧、换主体重拍走其他技能。

## 2. 需要用户准备的素材

- **必需**：视频 + 明确时间点。
- **没有时间点不要自己定**：请用户给时间点；有上游分析结果就直接用其时间戳，不自行扩充。
- **可选**：首帧、尾帧这类说法可直接作为时间点使用。

## 3. 关键规则

1. **时间点只能来自用户或上游确认**，不猜、不按均匀间隔采样冒充关键帧。
2. **不说自己能识别场景变化或关键动作**，没有分析依据就不作这类表述。
3. **时间点原样使用**，不自行增减、不四舍五入到别的时刻。
4. **不因参数必填就默认取首帧**。
5. **产物只认真实返回**：每张对应哪个时刻必须说清，不拿其他帧顶替。
6. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
7. **枚举与数值以平台当次为准**：时间点精度、张数与格式以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「视频抽帧」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

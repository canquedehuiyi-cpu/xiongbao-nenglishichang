# 音乐生成（专业技能 · 音频 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- **纯音乐 / BGM**：按曲风、情绪、场景、乐器与时长档生成，无人声。
- **带歌词人声歌曲**：可自带原创歌词，也可由平台自动写词。
- 不归本技能：纯配音与朗读走「语音合成」。

## 2. 需要用户准备的素材

- **必需**：曲风、情绪或场景，至少给一项。
- **带歌词路线**：可选自带歌词；不给就自动写词。**版权歌词不提交**。
- **可选**：乐器、时长档、人声取向。没给按平台默认。

## 3. 关键规则

1. **两条路线先定再生成**：说不清要纯音乐还是要歌时，先按「特点 + 匹配」给两条路线等确认；追问最多两次，仍不清才由平台取一条并说明。
2. **明确说不要人声就按纯音乐出**，即使贴了歌词也不唱词，并如实说明。
3. **做不到精确时长**：只有平台档位，更短的成品需用户后期剪辑，不承诺具体秒数。
4. **只支持整首生成**：不翻唱、不保留旋律换词、不改已有成曲的某一句，要改只能整首重做，需如实说明。
5. **风格描述保真**：用户点名的曲风、乐器、情绪、场景、时长与人声取向原样带上，不编造未提的节奏与调性。
6. **产物是音频与近似时长**；自动写词时不返回歌词全文。
7. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
8. **枚举与数值以平台当次为准**：曲风、时长档与人声选项以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「音乐生成」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

# 视频添加字幕（专业技能 · 视频 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 1 个视频 → 字幕烧录进画面的成品视频，并附每条字幕的开始时间、结束时间与文本。
- 两种取字幕方式：平台自动识别语音；或按用户给的文案落字幕。可另提样式要求。
- **是硬字幕**：字幕烘进画面，不是可开关的独立字幕轨，也不出字幕文件。
- 不归本技能：去原有字幕、配音、裁剪、翻译都做不到，用户要这些就如实说明。

## 2. 需要用户准备的素材

- **必需**：1 个可直接访问的视频地址（签名与查询参数原样保留）。
- **可选**：字幕文案（不给就自动识别语音）；样式要求（不给用平台默认）。
- **文案与样式分开给**：文案只放文字本身，样式单独说。
- **多个候选视频时**先问清是哪一个，不自己挑。

## 3. 关键规则

1. **只说「加字幕」就直接做**：自动识别 + 默认样式，不追问可选参数。
2. **文案原样使用**：文字、标点与换行照抄，不润色、翻译、删改或补内容；样式要求不算文案。
3. **没文案又无从识别**：请用户提供文案，不编造对话，也不把空字幕当成功。
4. **不假装有额外参数**：字体文件、目标语言、输出字幕文件这类都不是可传项；用户提精确时间码等要求时先确认能力，无法保证就如实说明。
5. **时间轴只认实际返回**：起止时间与文本必须来自本次返回结果，不按总时长均分、不估算。
6. **结果只认本次返回**：不拿输入视频或编造链接顶替；已提交不等于已完成，超时先查已有任务，不重复提交。
7. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
8. **枚举与数值以平台当次为准**：可识别的语言、样式支持范围与输出规格以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「视频添加字幕」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

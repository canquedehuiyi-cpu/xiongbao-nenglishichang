# 服饰试穿（专业技能 · 图片 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- **营销策略试穿**：只给服饰图 → 按目标人群或趋势热点生成有创意的试穿图，可加品牌 Logo 与自定义要求。
- **通用换装**：服饰图 + 模特或场景参考图 → 换装并保留模特原有姿势与场景。
- 不归本技能：成套多姿势与营销素材走「服饰套图」，鞋帽配饰与美甲走「试穿戴」，图 + 文案的笔记走「服饰图文笔记」。

## 2. 需要用户准备的素材

- **必需**：服饰商品图。
- **营销策略试穿**：目标人群或趋势热点**二选一**，不两种都塞。
- **通用换装**：模特图或场景参考图，并说清哪张是服饰、哪张是人或场景。
- **可选**：品牌 Logo、比例、自定义要求。没给不追问。

## 3. 关键规则

1. **服饰保真**是硬底线：款式、颜色、图案、版型以商品图为准，不添加原服饰没有的结构。
2. **给了模特或场景参考就保留其姿势与场景**，不擅自换人换景。
3. **营销策略二选一**，不把目标人群与趋势热点混在一次任务里。
4. **不虚构商品信息**：价格、折扣、材质、认证只用用户给的。
5. **产物只认真实返回**：张数以平台当次返回为准，不补齐、不拿输入图顶替。
6. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
7. **枚举与数值以平台当次为准**：比例、数量与策略选项以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「服饰试穿」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

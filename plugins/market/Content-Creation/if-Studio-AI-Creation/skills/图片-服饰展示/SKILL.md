# 服饰展示（专业技能 · 图片 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 服饰图 → 指定类型的展示图，一次可单选或多选：创意图、摆拍、挂拍、上身细节、平铺细节、材质特写、模特换脸换背景。
- 也可直接要完整套图，由平台并行出全部所选类型。
- 类型与可选范围以平台当次为准。
- 不归本技能：按品类出成套营销素材走「服饰套图」，单次上身效果走「服饰试穿」。

## 2. 需要用户准备的素材

- **必需**：服饰商品图 + 明确要哪种图片类型（判定见 §3 第 1 条）。
- **换脸换背景**另需人物参考图与目标背景，缺哪个问哪个，不代选。
- **可选**：品牌 Logo、宽高比、场景 / 风格 / 卖点要求、目标人群或趋势热点。没给不追问。

## 3. 关键规则

1. **先确认类型再动手**：只说「服饰展示图」「做套素材」或只给了图和比例，都不算已选类型——先列类型让用户单选或多选，**本轮只问、不生成**，不按图片内容或比例推断，也不默认创意图。
2. **多选并行发起**：参数齐备后同批一起发，不排队、不拿前一个结果当后一个的启动条件，重试也同批。
3. **缺素材先问**：换脸换背景少图就请用户补，不自行挑人物或背景。
4. **服饰保真**：款式、颜色、图案、版型与细节以原图为准，不添加原图没有的结构。
5. **策略与比例同批统一**：目标人群或趋势热点一次任务只定一次；用户没指定按平台默认。
6. **不虚构商品信息**：价格、折扣、参数、认证与材质只用用户给的。
7. **产物只认真实返回**：按类型顺序汇总，说明用途与成败，不展示内部编号与参数。
8. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
9. **枚举与数值以平台当次为准**：任务类型、比例、张数与选项以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「服饰展示」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

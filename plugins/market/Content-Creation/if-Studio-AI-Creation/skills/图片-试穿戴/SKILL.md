# 试穿戴（专业技能 · 图片 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

一次任务只走一条：

- **通用试穿戴**：单品商品图 + 一段具体效果描述 → 穿戴效果图；模特图可选，不给则由平台自动生成模特。
- **服饰替换**：模特图 + 服饰平铺图 → 直接换装，保留原有姿势与场景，不需要描述文字。
- **美甲试戴**：手部图 + 美甲参考图 → 迁移美甲款式，不需要描述文字。
- 不归本技能：按人群或趋势做营销创意试穿走「服饰试穿」，成套多姿势走「服饰套图」。

## 2. 需要用户准备的素材

- **必需**：按能力取图——通用试穿戴要商品图 + 效果描述；服饰替换要模特图 + 服饰平铺图；美甲试戴要手部图 + 美甲参考图。
- **多图时**：说清哪张是商品、哪张是人、哪张是参考，不说明先问。
- **可选**：拍摄风格、输出比例。没给不追问。

## 3. 关键规则

1. **先定能力再收素材**：能力决定哪些图必需、要不要写描述。
2. **描述只给通用试穿戴写**，服饰替换与美甲试戴只要图 + 角色说明。
3. **没给模特图就自动生成**，不追问长相；给了就以该模特为准，身形、肤色、脸型保真。
4. **商品与模特特征保真**：以素材为准，不符就同会话续聊点名纠正。
5. **产物只认真实返回**：不拿输入图冒充效果图，没出图不声称成功。
6. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
7. **枚举与数值以平台当次为准**：比例、张数与能力选项以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「试穿戴」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

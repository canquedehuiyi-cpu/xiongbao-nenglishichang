# 数字人口播视频（专业技能 · 数字人 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

一次只走一条：

- **内置音色合成**：模特图 + 文案 + 平台音色 → 口播视频。
- **参考音频定制音色**：模特图 + 参考音频 + 文案 → 用参考音频的音色朗读新文案再出视频。
- **完整音频直接驱动**：模特图 + 完整口播音频 → 不写文案、不选音色、不再合成。
- 不归本技能：只要形象图走「数字人形象生成」，只要配音不要视频走「语音合成」。

## 2. 需要用户准备的素材

- **必需**：模特形象图 + 文案（或完整音频）。
- **给了音频没说清用途时必须先问一次**：这条音频是「参考音色」还是「完整音频直接用」，问清再走；同一音频出现两种冲突说法也按不明确处理。
- **可选**：音色、语速、音量、情绪。没给不代选。

## 3. 关键规则

1. **音色未确认不出视频**：用户没指定音色时先给候选等确认，选完再发起。
2. **文案一字不改**：按用户原话进消息，不润色、不缩短、不补句子。
3. **不输出字幕**，交付物只有视频。
4. **多条批量时逐条对应**「图片 ↔ 音频 ↔ 文案」，不混着报。
5. **人物形象保真**：脸型、身形、发型以形象图为准。
6. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
7. **枚举与数值以平台当次为准**：音色、语速、音量、情绪与文案长度以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「数字人口播视频」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

# 商品外观展示广告（专业技能 · 视频 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 同一商品的多角度商品图 → 以外观、造型、材质与质感为核心的视频广告成片；图片预处理、形式匹配、分镜与生成由平台完成。
- 展示形式可指定，也可交给平台按商品自动选择，可用形式与效果以平台当次为准。
- 画幅、时长、清晰度可选，没给按平台默认。
- 不归本技能：概念创意或生活微故事广告走其他广告技能，静态海报走「商品创意图」。

## 2. 需要用户准备的素材

- **必需**：同一商品、同款同色的多角度商品图；不同款或不同色不能混作一组。
- **可选**：展示形式、画幅、时长、清晰度、人群策略。
- **形式没给时**：用户既没指定、也没说要立即生成 → 先给中文形式清单等他选，或由他回「自动选择」。

## 3. 关键规则

1. **形式先确认再出片**：未指定形式且未要求立即生成时，先列中文形式名与效果让用户选或回「自动选择」；已介绍过不重复列。
2. **对客只用中文形式名**：不展示内部代号与参数名；自动选择实际用了哪种形式，没有运行依据就不宣称。
3. **同款同色先校验**：不是同一商品或颜色不一时先问清，不混组硬做。
4. **人群策略只按用户意图**：没提及就不主动改动，不把任一状态当固定默认；实际开关状态无依据不宣称。
5. **时长是请求值**：请求时长不等于成片时长，只有运行结果有依据才说最终时长与实际配置。
6. **结果只认平台返回**：没返回就如实说明，不拿其他链接顶替。
7. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
8. **枚举与数值以平台当次为准**：展示形式、画幅、时长档位、清晰度与图片张数以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「商品外观展示广告」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

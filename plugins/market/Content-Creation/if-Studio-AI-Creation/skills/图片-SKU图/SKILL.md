# SKU图（专业技能 · 图片 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 多款同品 SKU（不同颜色 / 型号 / 规格）→ 风格统一的电商单图或系列套图，每款配自己的差异文案。
- 单款商品图 → 单张电商主图。
- 不归本技能：单张创意海报走「商品创意图」，成套详情长图与主图套图走「商品套图」。

## 2. 需要用户准备的素材

- **必需**：每款一张商品图；同一组必须是同一商品的不同 SKU，单款就一张。
- **文案**：可给每款的差异文案；不给就留空，由平台按可见差异补全。
- **可选**：画幅、背景与色调等整体风格要求。没给不追问。
- **多图时**：说清哪张对应哪款，或声明按上传顺序。

## 3. 关键规则

1. **图文必须对位**：按用户明确指代（图一 / 第二张 / 黑色款）绑定，其次用紧邻该图的描述；描述先后不覆盖明确指代。
2. **不确定只问不确定的部分**：指代冲突或外观无法区分时只问这一处，保留已理清的其他条目，不按数量硬配对。
3. **文案原文不改**：保留标点、换行与单位，不缩写、不翻译、不补卖点，指令语不带进画面；背景、色调、画幅属风格要求，不算文案。
4. **只有商品描述时提取差异属性**：用用户原词组合成简短文案，不加没提过的卖点与营销词。
5. **一款一图，更正只改不新增**：同一款的补充图不拆成多款，「第二张改成雾蓝」只改对应那一款。
6. **空文案不阻塞、超量如实说**：有图没文案就留空；超过单次上限说明并请用户选范围，不静默截断、不擅自拆成多次；只返回部分就按部分汇报。
7. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
8. **枚举与数值以平台当次为准**：画幅选项、单次数量上限、图片格式与大小以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「SKU图」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

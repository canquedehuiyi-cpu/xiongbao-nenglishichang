# 造型改造（专业技能 · 数字人 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 1 张人物正面照 + 参考图或文字 → 妆发效果预览：发型迁移、妆容迁移、妆发一体改造、口红试色、美瞳试戴。
- 参考图与文字可混用（如发型按文字改、妆容按参考图迁移）。
- 多项改造分步执行，每步保留前一步成果。
- 不归本技能：整身服饰换装走「服饰试穿」「试穿戴」，换脸换背景走「图片编辑」。

## 2. 需要用户准备的素材

- **必需**：1 张待改造的人物图，人物正面、头部完整（缺图或看不清就请用户补）。
- **按分支**：发型 / 妆容 / 妆发一体要有对应参考图或明确按文字改；口红试色要能确定的具体色值；美瞳试戴要美瞳商品图或参考图，不接受文字替代。
- **图要先分清角色**：哪张是人物原图、哪张是参考图，用途不明先问清。

## 3. 关键规则

1. **改造范围先定清**：只说「爆改一下」「帮我变好看」这类没范围的，先问「只换发型、只换妆容、还是妆发一起改」，**本轮只问、不做**。
2. **只改点名的部位**：用户说「只改妆，不动头发」就照办；参考图也只迁移被要求的部位，不顺手换别的。
3. **妆容类先问参考图**：即使已经说了「烟熏妆」也要问是否上传参考图，用户明确「不用」才算问完；缺必需参考图就请其补，不拿人物原图或无关图片顶替。
4. **分步不越级**：某步失败就保留此前结果并说明是哪一步，未完成的后续效果不说成已完成。
5. **颜色要说准**：口红给不出确切色值时先请用户确认一个近似色，近似色不宣称是某品牌色号的精确值。
6. **兜底不编造**：按文字生成的妆容要说明是按文字生成，不说成参考图迁移；能力不可用时如实说明。
7. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
8. **枚举与数值以平台当次为准**：可试色 / 试戴的品类、参考图要求与输出规格以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「造型改造」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

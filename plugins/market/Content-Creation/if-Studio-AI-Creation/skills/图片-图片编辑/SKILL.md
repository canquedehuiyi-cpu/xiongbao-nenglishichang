# 图片编辑（专业技能 · 图片 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- **只做已有图片的编辑**：抠图去背景（透明底）、版式裂变、光影设计、四方向扩图、合成图光影融合、高清放大等专项能力，具体以平台当次为准。
- 以上都不命中时走**通用编辑**：局部替换、改色、调比例、换脸、消除、去水印、换背景等。
- 不归本技能：从零生成商品图或成套素材、服饰上身效果走对应技能。

## 2. 需要用户准备的素材

- **必需**：主图（要改的那张图片）+ 编辑指令（改哪里、改成什么）。
- **多图时**：说清每张的角色（底图 / 素材 / 参考），不说明先问。
- **可选**：尺寸、比例、扩图方向、风格倾向。没给按平台默认。

## 3. 关键规则

1. **先判能力再收素材**：命中专项能力就走专项，否则走通用编辑；交付时说明本次做的是哪种编辑。
2. **只改用户点名的部分**：未点名的元素保持不动，用户说「其他都别动」时逐字带进消息。
3. **主图与素材不混用**：换脸、换背景、合成类必须分清哪张是被编辑的底图。
4. **抠图产物是透明底图**；扩图按用户给的方向与范围补全背景。
5. **产物只认真实返回**：不拿输入图或历史结果冒充，没出图不声称成功。
6. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
7. **枚举与数值以平台当次为准**：支持的比例、倍数、尺寸与张数以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「图片编辑」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

# 矢量图标（专业技能 · 图片 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 具象描述 → 单色 SVG 矢量图标；风格可选线性、面性、手绘，未指定按平台默认。
- 不归本技能：彩色 / 渐变 / 3D 质感 / App 图标等复杂精美风格、完整插画、Logo 与品牌视觉走通用生图。

## 2. 需要用户准备的素材

- **必需**：具象的图标主体（如「删除」「购物车」）；抽象词请用户给出具体指代。
- **可选**：风格、参考图、批量清单。参考图**只参考内容与物体形态**，不复刻其风格、配色、材质与笔触。

## 3. 关键规则

1. **产物是单色 SVG 矢量文件**，不承诺 PNG / JPG / PDF 等其他格式，也不承诺转格式。
2. **一次一个图标**；要多个就按主体逐个拆分，风格保持统一。
3. **主体描述要具体**：抽象词先问清它指什么，不自行发挥。
4. **超范围需求如实说明**，不硬做复杂风格与插画。
5. **产物只认真实返回**：不拿示例图或历史结果冒充，没出图不声称成功。
6. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
7. **枚举与数值以平台当次为准**：风格档位与支持范围以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「矢量图标」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

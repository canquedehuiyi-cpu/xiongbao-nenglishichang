# 语音合成（专业技能 · 音频 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- **内置音色合成**：正文 + 平台音色 → 音频；可选语速、音量、情绪。
- **参考音频定制音色**：音频地址 + 正文 → 用该音色朗读；该路线可调参数少于内置音色路线，具体以平台当次为准。
- 不归本技能：配数字人口播视频走「数字人口播视频」，音频转文字走「语音ASR识别」。

## 2. 需要用户准备的素材

- **必需**：正文。
- **音色**：没指定时先给候选等用户选，不代选。
- **参考音频路线**另需公网可访问的音频地址。
- **可选**：语速、音量、情绪。没给按平台默认。

## 3. 关键规则

1. **正文一字不改**：不清洗、不改写、不去表情与标点、不转换数字。
2. **超长如实报字数并请用户缩短**，不静默截断、不擅自拆分。
3. **音色未确认不出音频**；用户点名但找不到时如实说明并给真实候选，不拿近似音色顶替。
4. **产物是音频与时长**，不含字幕与逐字时间戳。
5. **批量逐条对应**「正文 ↔ 音频」，不混着报。
6. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
7. **枚举与数值以平台当次为准**：音色、情绪、语速与音量范围、正文长度以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「语音合成」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

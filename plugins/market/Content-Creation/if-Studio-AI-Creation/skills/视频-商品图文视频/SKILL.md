# 商品图文视频（专业技能 · 视频 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 1 张 KV 海报或商品广告图 → 商品短视频成片；调性解析、文案线索提取、卖点理解与脚本方向设计由平台完成。
- 时长、分辨率、品牌调性方向可选，没给按平台默认。
- **不生成口播**：成片是画面表达，不做旁白、人声与口播字幕。
- 不归本技能：以外观 / 造型 / 材质为核心的广告走「商品外观展示广告」，概念创意或生活微故事广告走其他广告技能。

## 2. 需要用户准备的素材

- **必需**：1 张 KV 海报或商品广告图。
- **可选**：时长、分辨率、品牌调性方向。
- **多张图时**：本技能一次只用一张，先确认用哪张；多张要各出一条就逐张列清。

## 3. 关键规则

1. **不出口播**：用户要求口播时说明本技能不做，改走数字人口播类技能。
2. **调性与卖点照原图**：脚本方向贴合原图的视觉调性与文案线索，不改写文案、不编造图上没写的功效与卖点。
3. **一图一条**：只接收一张图，多图先确认主图，不把多张混成一条。
4. **时长是目标值**：请求时长不等于成片时长，只有运行结果有依据才说最终时长与分辨率。
5. **解析结论要有依据**：调性、卖点、文案线索只报图里看得出的，看不清就说看不清，不编。
6. **结果只认平台返回**：没返回就如实说明，不拿其他视频顶替。
7. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
8. **枚举与数值以平台当次为准**：时长档位、分辨率选项与图片来源要求以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「商品图文视频」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

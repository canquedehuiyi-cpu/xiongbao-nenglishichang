# 商品创意图（专业技能 · 图片 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 商品图 → 商品创意图文海报 / 广告宣传图 / 营销推广图。
- 两条路**一次只走一条**：① 商品图文广告（可点明目标人群、节日促销、品牌调性）；② 参考已有图复刻其版式、风格、配色与氛围，换成目标商品。
- 不归本技能：成套商品图走「商品套图」，图 + 文案的笔记走「商品图文笔记」，改已有图走「图片编辑」。

## 2. 需要用户准备的素材

- **必需**：目标商品图；复刻路线另需被参考的图，并说清哪张是商品、哪张是参考。
- **可选**：文案、风格、色调、场景、创意策略。点名的原样带上，没给不代填。

## 3. 关键规则

1. **用户原话逐字带到**：文案、风格、场景与否定项按原话进消息，不改写、不摘要。
2. **画面文字原文一字不改**：用户给的 slogan、价格、卖点照原样呈现，不自行增删。
3. **一次只走一条路**：图文广告与参考复刻不混在同一次任务里。
4. **不虚构商品信息**：价格、折扣、功效、认证只用用户给的。
5. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
6. **枚举与数值以平台当次为准**：格式、比例、数量与选项以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「商品创意图」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

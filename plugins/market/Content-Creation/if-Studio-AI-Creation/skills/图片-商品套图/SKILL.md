# 商品套图（专业技能 · 图片 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 商品图 + 创意需求 → 一整套商品视觉图，**一次任务只出一种**，类型如商品详情长图、主图套图、展示套图、营销广告套图，具体以平台当次为准。
- 支持纯视觉、中文图文与混合形式。
- 不归本技能：单张创意海报走「商品创意图」，图 + 文案的笔记走「商品图文笔记」，服饰套图走「服饰套图」。

## 2. 需要用户准备的素材

- **必需**：商品图 + 套图类型。没说清要哪种先问一次，不按图片内容推断。
- **可选**：数量、画幅、图文形式、卖点、目标人群、热点趋势。没给不追问、不代填。

## 3. 关键规则

1. **一次只出一种套图**，不把多种套图混在一次任务里。
2. **商品保真**：款式、颜色、结构以商品图为准，不添加原商品没有的配件与结构。
3. **不虚构商品信息**：价格、折扣、功效、参数与认证只用用户给的。
4. **产物只认真实返回**：张数以平台当次返回为准，不足不补齐、不拿输入图顶替。
5. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
6. **枚举与数值以平台当次为准**：套图类型、画幅、比例与数量以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「商品套图」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

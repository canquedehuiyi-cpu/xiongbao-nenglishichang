# 服饰套图（专业技能 · 图片 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- **服饰多类型套图**：按所选的电商与营销图片类型自主组合。
- **服饰多姿势套图**：同服饰、同人物、同场景的统一多姿势模特图。
- **服装实拍套图**：平铺、手持、材质细节、模特上身等真实拍摄风格。
- 上述任务类型以平台当次为准，可多选；选两种以上并行发起、结果统一汇总。
- 不归本技能：单次上身效果走「服饰试穿」，图 + 文案的穿搭笔记走「服饰图文笔记」。

## 2. 需要用户准备的素材

- **必需**：服饰商品图 + 任务类型。只说泛化名称先问一次，不替用户挑。
- **可选**：人物参考图、品牌 Logo、宽高比、创意策略、目标人群、卖点、场景、视觉风格、图片类型。没给不追问。

## 3. 关键规则

1. **泛化需求先问再出图**：问清选哪种任务，用户明确多选才并行。
2. **人物与场景一致性**：同一套图内保持一致，不擅自换人换景。
3. **服饰保真**：款式、颜色、图案、版型以商品图为准，不添加原服饰没有的结构。
4. **不虚构商品信息**：价格、折扣、材质、认证只用用户给的。
5. **产物只认真实返回**：任务分别汇报结果，不满意的点明哪套哪张，不混着说。
6. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
7. **枚举与数值以平台当次为准**：任务种类、张数、比例与图片类型以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「服饰套图」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

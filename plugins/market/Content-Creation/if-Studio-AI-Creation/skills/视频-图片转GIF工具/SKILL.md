# 图片/视频转GIF工具（专业技能 · 视频 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 多张图片按顺序 → 一个 GIF：可统一帧时长，也可逐帧指定；可设循环方式。
- 一个视频整段 → GIF；输出无音轨。
- 只做转换：不生成新图、不插帧补间、不加字幕或转场；需要新画面就先出独立图片再合成。
- 不归本技能：视频裁剪、加字幕走对应专业技能。

## 2. 需要用户准备的素材

- **图片模式**：多张可直接访问的图片地址，顺序即播放顺序；可选循环方式与每帧时长。
- **视频模式**：1 个可直接访问的视频地址。
- **链接签名与查询参数原样保留**：缺失或不可访问就请用户补，不静默截取、不拿别的素材顶替。

## 3. 关键规则

1. **数量按上限处理**：不够请用户补；超过上限就说明上限并请用户自己挑到范围内，不静默截取。
2. **逐帧时长必须与图片一一对应**：长度不等或数值越界就指出问题请用户修正，不静默取整或补齐。
3. **单位与循环按平台口径落地**：用户以秒描述时换算成平台认的时长；循环说法按平台语义映射，平台做不到的就如实说明，不硬套成别的含义。
4. **视频模式不外推参数**：不承诺自定义截取、变速、循环次数与输出规格，用户要这些就说明当前限制，不改用户要求去迁就。
5. **只做转换不臆测效果**：一张宫格拼图不算多张、单张不算动画、GIF 无音轨，这些如实说。
6. **结果只认本次返回**：不拿输入素材或旧结果顶替；失败就明确说合成未完成，相同无效参数不重复调用。
7. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
8. **枚举与数值以平台当次为准**：图片数量上限、帧时长精度与视频输出规格以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「图片/视频转GIF工具」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

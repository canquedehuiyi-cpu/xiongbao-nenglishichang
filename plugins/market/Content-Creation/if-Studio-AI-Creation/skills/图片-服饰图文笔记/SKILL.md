# 服饰图文笔记（专业技能 · 图片 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 一张服装商品图 → 模特试穿上身图 + 多张姿势与场景变体 + 配套文案（标题 / 正文 / 标签），一套可直接发布的穿搭帖。
- 模特形象来源：平台自动匹配、用户上传、复用历史形象、文字描述等，具体以平台当次为准；**既给图又给描述时以图为准**。
- 不归本技能：成套营销素材走「服饰套图」，单张上身效果走「服饰试穿」，图 + 文案的商品笔记走「商品图文笔记」。

## 2. 需要用户准备的素材

- **必需**：一张服装商品图（平铺、上身、手持、挂拍均可）。
- **可选**：模特形象、套图数量、画面描述（场景与姿势）、商品卖点 / 材质 / 价格 / 活动。没给不编造。

## 3. 关键规则

1. **图 + 文一次产出**，文案按返回原文完整给出，不改写、不精简。
2. **模特来源以图优先**：给了形象图就用该形象，不再另生成；没说就用平台自动匹配。
3. **每次交付交代本次用的模特形象**，便于用户下轮说「用上次那个模特」时保持一致。
4. **服饰保真**：款式、颜色、图案、版型以商品图为准。
5. **不编造用户没给的场景、卖点与价格**。
6. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
7. **枚举与数值以平台当次为准**：套图数量、比例与模特来源选项以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「服饰图文笔记」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

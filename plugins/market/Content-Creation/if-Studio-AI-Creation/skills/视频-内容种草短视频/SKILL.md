# 内容种草短视频（专业技能 · 视频 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 商品图 / 参考视频（至少一个）+ 可选的文字要求 → 商品种草短视频；提示词优化、剧情、分镜与画面语言由平台产出。
- 时长、画幅比例、分辨率可选，没给按平台默认。
- **一条视频装下全部要求**：多个场景、多个卖点、多个角度都在同一条里用分镜切换呈现。
- 不归本技能：单张 KV 转视频走「商品图文视频」，外观展示类广告走「商品外观展示广告」，口播带货走「数字人口播视频」。

## 2. 需要用户准备的素材

- **必需**：参考主体——图片或视频至少给一个（可多个）。只给文字不出片，先请用户补图或视频。
- **可选**：时长、画幅比例、分辨率、卖点 / 剧情 / 目标人群等文字要求。
- **素材规格以平台当次为准**：超出就先说明并请用户换素材或裁剪，不硬传、不静默压缩。

## 3. 关键规则

1. **素材先校验再出片**：数量、尺寸与时长不在平台允许范围内时，先说清是哪一项请用户换，不跳过校验直接生成。
2. **一条任务只出一条**：多个场景与卖点在同一条里用分镜呈现，不拆成多条；用户明确要多个版本才拆开列。
3. **比例按可用范围映射**：用户给的比例不在可选范围内时说明可用范围请其重选，不擅自替换。
4. **完整链接原样交付**：带回与签名的地址原样给，不截断、不删参数、不改写成短链。
5. **结果只认平台返回**：出片数量、时长与分辨率以平台当次返回为准，没返回就如实说明，不宣称未出片的成功。
6. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
7. **枚举与数值以平台当次为准**：素材规格、时长档位、比例与分辨率以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「内容种草短视频」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

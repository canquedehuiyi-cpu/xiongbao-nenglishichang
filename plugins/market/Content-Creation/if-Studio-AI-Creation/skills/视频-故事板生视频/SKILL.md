# 故事板生视频（专业技能 · 视频 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 创意 / 文字 / 脚本 → 新视频：先出分镜脚本，确认后生成故事板，再按时间分段出片。
- 短片一张故事板即可覆盖；长片按剧情切分成多张故事板逐张生成。
- 默认补齐口播与旁白。
- 不归本技能：基于现成视频换主体重拍走「视频深度重拍」，截取画面走「视频抽帧」。

## 2. 需要用户准备的素材

- **必需**：创意、文字或脚本，三者有其一即可。
- **可选**：时长、画幅、风格、人物或商品参考图。没给不追问、不代填。

## 3. 关键规则

1. **先出分镜脚本再确认**：未经确认不直接出片，用户说「直接做」才跳过确认。
2. **跨镜头一致性**：人物、商品、场景、动作在多张故事板间保持一致，不擅自换人换场景。
3. **长片分段交付**：按剧情切分，逐张生成，结果按顺序汇总。
4. **用户没点名的风格、比例、清晰度不代填**，按平台默认并说明。
5. **产物只认真实返回**：不拿示例片或历史结果冒充，没出片不声称成功。
6. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
7. **枚举与数值以平台当次为准**：时长、分段数与画幅以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「故事板生视频」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

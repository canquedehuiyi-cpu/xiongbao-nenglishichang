# 语音ASR识别（专业技能 · 音频 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 音频链接 → 完整识别文本 + 分句结果（每句文本与起止时间）。
- 默认交付全文并保留原有语言、数字、专名与标点。
- 不归本技能：文字转配音走「语音合成」；降噪、人声分离、说话人识别与字幕文件不在范围内。

## 2. 需要用户准备的素材

- **必需**：可公网访问的音频链接；支持的音频格式以平台当次为准。
- **视频链接不能直接当音频输入**：先提取或转换成音频再给链接。
- **带签名或查询参数的地址原样保留**，不删签名、不改写。

## 3. 关键规则

1. **未真实识别前不猜内容**，不凭文件名、链接或上下文编造转写结果。
2. **转写不改写**：不摘要、不润色、不补全听不清的内容。
3. **要整理稿、摘要或翻译时**基于真实转写文本另做，并与原始转写分开标注。
4. **要逐句时间轴就按分句顺序给出**句子与起止时间。
5. **不编造下载链接**：平台没返回文件地址时只说结果在哪，不给假的 TXT / SRT 地址。
6. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
7. **枚举与数值以平台当次为准**：支持的格式、时长与分句粒度以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「语音ASR识别」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

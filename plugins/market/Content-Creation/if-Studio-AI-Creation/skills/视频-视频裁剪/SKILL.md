# 视频裁剪（专业技能 · 视频 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 1 个视频 + 起止时刻 → 该时间段的视频片段，并标注截取范围与片段时长。
- 典型用途：截某段素材、去掉开头或结尾的多余内容。
- 只做截取：不拼接、不变速、不加字幕、不改分辨率。
- 不归本技能：整段转 GIF 走「图片/视频转GIF工具」，加字幕走「视频添加字幕」。

## 2. 需要用户准备的素材

- **必需**：1 个可直接访问的视频地址 + 开始的时刻与结束的时刻。
- **时间可以口语给**：由本技能换算成平台认的时间格式。
- **缺项就问**：不猜一个时间凑齐。

## 3. 关键规则

1. **三项齐全再动手**：视频地址、开始时刻、结束时刻缺任一就先问，不默认从头或到尾。
2. **时间要换算不要照抄**：换算后向用户复述一遍起止时刻，不把口语原话直接当参数。
3. **结束必须晚于开始**：否则请用户调整范围，不自己调换顺序。
4. **认不出是哪一刻就问**：只说「中间那段」这类请其给出明确时刻，不估算。
5. **范围与时长按实际算**：时长以实际返回的片段为准，不凭用户数字硬算。
6. **结果只认本次返回**：链接无效、无法访问或截取失败就说明情况请用户检查重试，不说成已完成。
7. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
8. **枚举与数值以平台当次为准**：时间精度与片段输出规格以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「视频裁剪」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

# 视频深度重拍（专业技能 · 视频 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 原视频 + 参考图 → 把视频里的可替换主体换成参考图指向的形象，保留原动作、运镜与节奏。
- 可分别提供人物、服装、道具的参考图。
- 不归本技能：从零生成新视频走「故事板生视频」，截取画面走「视频抽帧」。

## 2. 需要用户准备的素材

- **必需**：原视频 + 参考图，两样齐了才发。
- **多张参考图**：逐张说明用途与主次，不说明先问。
- **可选**：要替换哪些主体、保留哪些元素。没给按平台识别结果处理。

## 3. 关键规则

1. **原视频与参考图缺一不发**：缺哪个就请用户补齐，不凭描述硬做。
2. **换的只是主体**：动作、运镜、节奏与场景尽量保持原样，不擅自改剧情。
3. **参考图角色分清**：人物、服装、道具分属不同图时逐张点名。
4. **素材过长先说明风险**：请用户裁剪后再做，不保证长度超限也能成片。
5. **产物只认真实返回**：不拿原视频或历史结果冒充，没出片不声称成功。
6. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
7. **枚举与数值以平台当次为准**：参考图张数、视频时长与比例以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「视频深度重拍」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

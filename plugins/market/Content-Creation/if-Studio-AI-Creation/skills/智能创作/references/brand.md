# 品牌专区模块 — IFS 说明与品牌介绍

本模块提供 IFS（if Studio）的标准介绍口径、使用方式、应用场景与品牌材料位置，用于对客宣导与内部答疑。
只做"介绍与材料"，不发起生成对话；用户要出图/出视频时走 Chat 模块（chat.md）。

## IFS 是什么（标准口径）

**一句话**：IFS（if Studio）是 iconfont 出品的一站式 AI 智能设计平台（面向所有用户开放），提供图像/视频生成、多轮画布迭代、技能市场与资产管理能力。

**电梯稿（30 秒）**：
> IFS 是 iconfont 出品、面向所有用户开放的一站式 AI 设计平台。你用自然语言描述需求，它在画布上生成图片和视频，并支持在同一画布上多轮迭代修改，成套需求一次说清即可成套产出；生成结果沉淀在个人资产库，可随时导出。平台由账号体系统一管理登录与算力积分。

**能力清单（对客五问五答）**：

| 问题 | 口径 |
|------|------|
| 能生成什么 | 图片（前沿 AI 模型）、视频（含分镜脚本工作流）、设计物料 |
| 怎么迭代 | 同一画布多轮续聊，服务端保留完整上下文与生成记忆 |
| 批量怎么做 | 一条消息说清整套需求即可成套产出（套图规则见 chat.md）；要更多变体就在同一画布多轮续聊逐个出 |
| 成果在哪 | 画布页永久可回看；媒体可下载导出；上传素材进资产库 |
| 怎么计费 | 算力积分制，平台内查看余额与充值（充值需用户本人操作） |

## 怎么用（对客口径：像聊天一样做设计）

在 IFS 里设计以对话的方式完成，一条主线五步走：

1. **说一句话就能做**：平面/品牌/电商/插画/视频设计，抠图、高清化、局部修改等图像处理，自然语言描述即可。
2. **先规划再动手**：复杂需求（成套物料、短视频、品牌方案）先出规划——脚本、分镜、方案卡片；
   用户确认后分段生成，确认动作就发生在对话里。
3. **画布承载全程**：生成、修改、对比都在同一画布上，页面直接呈现，结果即出即看。
4. **同一画布多轮迭代**：接着说改哪里，上下文与生成记忆全程保留，改完即得，不必从头重画。
5. **成果沉淀为资产**：历史画布随时回看，产物进资产库，可导出落盘整理；算力余额随时可查。

**上手三步**：① 授权——未授权时助手会直接把 IFS 授权页帮你唤起，你在浏览器里登录并点一次同意（细则见下文「激活插件」）；
② 开工——直接说需求（"帮我画一张…""把这张图改成…""出一套电商主图"）；
③ 迭代——在同一画布上继续说改哪里。

> 分工：本节是**对客宣导用的产品口径**；用户提问式的使用指导（需求怎么写/怎么选模型/怎么改图/怎么计费）
> 见用户帮助模块 [help.md](help.md) §2 八问口径表，两处不要各说一套。

## 主要应用场景（从灵感到落地，全场景覆盖）

覆盖的不是一串彼此无关的功能，而是从灵感到落地的一套创作流程——不同领域的创作者都能找到趁手的工具：

- **品牌设计**：Logo 构思、VI 延展、风格探索；从 Icon 思想一路延展到 VI 应用，成套需求一次说清、成套交付。
- **图画创作**：插画绘制、配图生成、故事板制作；风格、构图、画幅一句话锁定。
- **视频创作**：静态图转视频、营销短视频分镜制作；先出分镜脚本，逐张确认后成片。
- **社媒物料**：小红书封面、公众号配图、营销海报。
- **电商创意**：商品展示、场景图、试穿效果成套产出（说明"多张独立图片，不合成拼图"即可）。
- **服饰设计**：图案生成、款式构思、面料模拟。
- **空间设计**：概念图生成、氛围感渲染。
- **产品设计**：概念设计、渲染图制作。
- **创意玩法**：风格化动画、艺术字等创意合成，让表达更有记忆点。

没想法时从平台「灵感广场」起步：官方案例按品牌/插画/视频/电商等分类，自带 prompt 模板，换个主体就能直接用。

## 差异化话术（对客宣导用，五组对比）

| 卖点 | 传统 AI 生图 | IFS |
|------|-------------|-----|
| 不止"能出图"，而是设计流水线 | 单次 Prompt 机，一次生成定输赢，改一处重画一张 | 多智能体协作：先出规划（脚本/分镜/方案卡片），确认后分段生成 |
| 不止"一张画布"，而是自由画布 × 连接对话 | 每轮对话孤立，上下文说丢就丢 | 同一画布多轮续聊，保留完整上下文与生成记忆 |
| 不止前沿 AI 模型，还内置优质创意技能 | 模型单一，场景模板全靠自己堆 prompt | 前沿 AI 模型持续上架（以平台实时清单为准）+ 多技能模式（通用技能统一执行 + 故事板生视频 / 商品套图 / 服饰试穿 / 数字人口播视频 / 语音合成 / 图片编辑等 IFS 技能中心专项技能） |
| 不止是素材，而是可管理的设计资产 | 生成完散落在下载目录，下次找不到 | 历史画布回看、资产库沉淀、一键导出整理；算力余额可查 |
| 不止"AI 生图工具"，更是 iconfont 出品的设计伙伴 | 只给一张图，不懂设计规范与交付习惯 | 按设计师工作流打磨：规划确认、套图交付、资产管理，审美与规范都在线 |

## 使用边界（对客必讲）

1. IFS 面向所有用户开放，直接访问平台使用。
2. 平台入口：以平台配置为准（config/platform.json 的 platform.domain；留空 = 以连接器注册配置
   mcp.json 的 url 为准）——产品分对内/对外版、域名不同，材料与话术均不写死具体域名。
3. 算力为付费资源：演示时提示"消耗算力"，充值由用户本人在平台完成，任何助手/插件不代做支付。
4. 登录/授权页上的操作（选择身份、输入账号、点击提交）必须由用户本人完成。

## 激活插件（介绍品牌时一并说明）

宣导 IFS 后，按以下口径说明如何在 Qoder 里激活本插件（详细步骤见 CONNECTORS.md「安装与首次授权」）：

1. 安装插件 IF Studio AI 智能创作 后重启 Qoder，连接器 iconfont-ifs 出现「需要授权」标记。
2. 未授权时助手会**直接帮你把授权页唤起**（系统浏览器自动弹出）；浏览器里的登录与同意由用户本人完成（助手严禁代点、代选身份、代输账号）；授权持久，无需重复。
3. 复验：`ifs_ping` 返回链路正常即激活完成；异常排查走异常管理模块（exception.md）。
4. 授权页唤起不了或完成后仍未授权时，助手才会在对话里给出三选一选择框（已完成连接器授权 / 暂不授权 / 取消任务；**推荐激活连接器获得完整能力，也支持先用 CLI 运行**——此询问仅出现这一次）；选「暂不授权」即走降级通道官方 ifs CLI 继续干活（独立登录一次，核心能力与主通道一致，见 [connector.md](connector.md)）——**这个选择会被记住，后续不再重复询问**；之后若降级通道无法完成某项任务而连接器可以，助手会再提示（重新）授权连接器。

## 本插件与 IFS 的关系（架构口径）

本插件（IF Studio AI 智能创作）是 IFS 在 Qoder 里的"驾驶舱"，按六层架构协同：

| 架构层 | 承载物 |
|--------|--------|
| 交互层 | 用户对话、项目与历史查看、算力资产查询、品牌宣导（本模块）、用户帮助（使用指导与灵感） |
| 应用层-Qoder | 本插件的技能 + 连接器 + hooks + 外挂屏（取画布授权链接后用内置浏览器呈现画布页） |
| 功能层-技能 | **多技能模式**：1 个通用技能「ifs-ai-design」（内含八个模块，SKILL.md 路由 + references/ 渐进加载，兼作专业技能任务代理）+ N 个专业技能（IFS 技能中心图片 / 视频 / 音频 / 数字人专项，各自一个 `skills/` 目录与 SKILL.md，只备业务规则与素材，执行转通用技能，索引见 references/pro-skills.md） |
| 连接层-连接器 | iconfont-ifs 连接器（插件 mcp.json 注册的 IFS 平台远程 MCP 服务，MCP over HTTP + OAuth，方法面以会话内 tools/list 实时为准：智能体对话（发消息/轮询/上传/模型清单）+ 画布授权链接 + 探活自检）承载服务请求与响应；宿主自带的 browser-use 承载内置浏览器呈现 |
| 服务层-IFS | 在线智能体服务 / 在线应用服务 / 账号授权服务 |
| 数据层-IFS | 技能中心 / 积分算力 / 资产库 / 灵感广场 / 账号中心 |

## 对客材料生成约定

- 用户要"一页纸介绍/PPT 大纲/邮件话术"时，从上面四组口径按体裁取舍改写：一句话与电梯稿（定位）
  + 五问五答（能力）+「怎么用」五步与上手三步（使用）+「主要应用场景」九类（场景）+「差异化话术」五组对比（卖点）；
  不自造数据（不要编造模型数量、价格、SLA）。

- 需要现场演示：先走异常管理模块（exception.md）环境自检，再走 Chat 模块（chat.md）做演示生成。

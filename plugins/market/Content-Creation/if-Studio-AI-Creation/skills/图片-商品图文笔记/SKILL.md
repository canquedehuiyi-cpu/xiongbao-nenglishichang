# 商品图文笔记（专业技能 · 图片 · IFS 技能中心）

> 本技能只准备专项业务规则与素材，并指定发消息时的 `skill` 参数；提交、轮询、呈现与落盘一律转通用技能「智能创作」执行。

## 1. 能做什么

- 商品图**或**主题关键词 → 小红书图文笔记：标题 + 正文 + 配套图片；内容可选通用种草、科普、测评，给了示例标题 / 正文可按示例风格仿写。
- 不归本技能：只要商品图不要文案走「商品套图」，服饰穿搭笔记走「服饰图文笔记」，单张创意海报走「商品创意图」。

## 2. 需要用户准备的素材

- **必需**：商品图**或**主题关键词，二选一即可。
- **可选**：内容类型、张数、仿写示例、卖点与材质。没给不追问、不编造。

## 3. 关键规则

1. **文案按返回原文完整给出**，不改写、不精简、不加自己的营销话术，便于用户直接复制。
2. **不虚构商品信息**：价格、功效、成分、认证只用用户给的事实。
3. **图片顺序按返回原样**，并说明每张对应什么。
4. **张数不补齐**：少于所选不算缺图，不重复贴同一张、不拿输入图顶替。
5. **不写死模型**：用哪个模型由平台侧编排，本技能与消息都不指定模型名。
6. **枚举与数值以平台当次为准**：张数、内容类型与比例以平台当次返回为准，与本文不一致时以平台为准，不据此误拒用户、也不当平台承诺。

## 4. 转交通用技能执行

- 发消息时 `skill` 参数传「商品图文笔记」（官方技能名，一字不改）。
- 素材与要求一条消息说全；门禁、降级、轮询、中断答复与产物落盘按通用技能口径执行。

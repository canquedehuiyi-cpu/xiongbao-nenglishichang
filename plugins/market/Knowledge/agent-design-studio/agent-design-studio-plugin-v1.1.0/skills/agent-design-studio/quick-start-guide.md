# 智能体设计工坊 · 快速上手指南

欢迎！这个工具会引导你从零开始，设计一个属于你自己的教学智能体。

不需要懂技术，不需要写代码，你只需要懂教学——而这是你最擅长的。

---

## 这个工具能帮你做什么？

帮你把一个教学中的"痛点"变成一个可以反复使用的 AI 助手。

比如：
- 每次批改周记都要写评语，能不能有一个助手帮你生成个性化评语？
- 每次备课都要分析课标，能不能有一个助手帮你快速提取重点？
- 每次设计分层作业都很费时间，能不能有一个助手帮你自动生成分层练习？

这些都可以做到。整个流程分四步，我会一步一步带你走。

---

## 四步流程一览

```
第一步：选题        第二步：设计        第三步：制作        第四步：测试
从清单里选一个      跟我聊天，把你的     我帮你把聊天内容     我们一起试试，
你最想做的场景      想法说清楚           整理成一个智能体     看看好不好用
```

### 第一步：选题（约 5 分钟）

我会问你三个问题：
1. 你教什么学科？哪个年级？
2. 你用的什么版本的教材？
3. 你日常教学中，哪件事最让你头疼或最耗时间？

根据你的回答，我会推荐 2-3 个最匹配的场景供你选择。你也可以自己想一个——只要能说清楚"这个助手帮我做什么"就行。

**产出**：确定了你要设计的智能体叫什么、做什么、服务哪个学科和学段。

### 第二步：设计（约 25-35 分钟）

这是最核心的一步。我会先陪你把问题想透，再分四个话题跟你聊：

**先想透（建模）**：我会请你把这件事当故事讲一遍——那天你坐下来做这件事，手边有什么材料，第一步做什么，哪一步最烦。然后我们一起把它压缩成一句话："帮你在什么时候、把什么输入、变成什么输出。"这一句话想清楚了，后面就顺了。如果你教的是学科课，我还会请你拿一份真实的作业或课例现场走一遍——磨刀不误砍柴工，这半小时是整个流程里最值钱的半小时。

| 话题 | 我会问你 | 最终得到 |
|------|---------|---------|
| 使用场景 | 你什么时候用它？需要输入什么？期望得到什么？ | 场景描述 |
| 提示词框架 | 如果你是这个助手，接到任务后第一步做什么？第二步呢？ | 工作流程 |
| 教学约束 | 这个助手有没有绝对不能做的事？比如不能超纲？ | 约束规则 |
| 质量标准 | 你怎么判断这个助手做得好不好？ | 检验标准 |

每个话题我会逐个问，不会一次抛出所有问题。你觉得满意了我们再进入下一个。

**产出**：一句话定义 + 四样核心内容——场景、提示词、约束、质量标准。

### 第三步：制作（约 5 分钟）

我会把第二步聊出来的内容，自动整理成一份标准的智能体配置文件。

你只需要看一遍，确认内容和你想要的一致。如果有不对的地方，告诉我，我当场改。

**产出**：一份完整的智能体配置文件。

### 第四步：测试（约 10-15 分钟）

先做一个最重要的对比实验，再过三个质量关卡：

**对比实验**：同一个任务，不用这个助手直接问 AI 得到一版，用这个助手再得到一版。你盲评哪版好。如果用了助手反而没变好，说明这个助手还没有真正的价值，我们回到第二步重新想。

| 关卡 | 核心问题 | 检查什么 |
|------|---------|---------|
| 课标合规性 | 输出是否符合国家课程标准？ | 不超纲、不缺位、术语准确 |
| 课堂可行性 | 在真实课堂中能用吗？ | 时间够、大班能操作、环节完整 |
| 教师友好度 | 其他老师拿到能直接用吗？ | 拿来即用、不增加负担、输出不需大量修改 |

全部通过就可以投入使用了。没通过的项，我们回去改，改完再测。改的方式是"小步快改"：一次只改一个问题，改完马上用同一个例子重新试。

## 理论支撑（可选）

如果你对智能体背后的教育理论感兴趣，或者希望设计出的智能体有更扎实的理论底座，可以让助手搜索 ima 知识库中的以下三份文档：

| 文档名称 | 什么时候用 |
|---------|----------|
| 《五星网状教学模型的核心理论结构》 | 需要了解启动、建构、巩固、运用、总结五个教学环节的定义和约束时 |
| 《五星网状教学模型的理论策略库体系》 | 需要为某个教学环节选择具体策略时（如建构四维度、巩固三层次） |
| 《百倍速学习教学设计理论完整知识库》 | 需要分析学习结果类型、设计学习目标（波哥公式）、做学情分析（必知金字塔）或设计评价任务时 |

**怎么用**：直接告诉助手，比如"帮我搜索知识库中的'建构五步骤'"，助手会帮你检索并把理论内容转化为具体的设计建议。

不需要一上来就看理论，用到的时候再查就好。

## 第一次使用的建议

1. **从最痛的场景开始**。不要想"应该做什么"，想"我最不想再重复做什么"。
2. **不用追求完美**。第一版能用就行，后面可以一直迭代改进。
3. **放心说"不对"**。如果助手理解错了你的意思，直接说"不是这样的，我要的是……"。
4. **带着真实课例来**。如果你明天就要上某节课，直接拿这个课来设计智能体，效果最好。

## 常见问题

**Q：我完全不懂 AI，能用吗？**
能。整个流程是聊天式的，你只需要用教学经验回答问题，技术部分由助手处理。

**Q：做一个智能体要多长时间？**
顺利的话，40-60 分钟可以完成一个。第一次可能会稍长一点，熟悉流程后会越来越快。

**Q：做出来的智能体，其他老师能用吗？**
能。做完的智能体可以分享给同校或同区域的老师，他们打开就能直接用。

**Q：我可以做多个智能体吗？**
当然可以。每做完一个，回到第一步开始下一个。我们的目标是逐步建起一个覆盖主要教学场景的智能体矩阵。

**Q：做到一半可以保存吗？**
可以。每一步完成后都有明确的产出记录，下次继续时告诉助手"我上次做到了第二步"就可以接着来。

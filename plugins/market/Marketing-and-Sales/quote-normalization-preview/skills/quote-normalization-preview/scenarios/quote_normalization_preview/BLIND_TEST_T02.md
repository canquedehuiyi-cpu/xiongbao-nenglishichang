## 0 为什么本包是 T-02

- T-02 判定族覆盖 N-01 / N-02 两个节点，代表条目 = **E-11**（多供应商报价横向
  比较）+ **G-16**（多供应商报价统一格式）——拉平（归一）+ 预审（偏离标记）

## 1 取样来源（一次取样向谁要什么）

按输入整治计划 §4.1 与节点池 §2 T-02。**v0.2 起取样口径 = 填模板内部汇聚总表**：

> 取**同一票询价**的 3 家以上真实报价，采购把各家**抄填进「报价明细」**
> （每行一家：供应商/品名/型号/单价/数量/金额/币种/单位/含税），在
> **「口径声明」** 如实填该票的币种汇率/单位换算/全局含税。模板见
> `template/多格式报价拉平输入模板.xlsx`。相比"采集格式各异的原始文件"，
> 模板化保证输入格式统一——**这正是本族测"通用模型能否在原样输入上拉平"的
> 新口径**（见 INPUT_CONTRACT §5 判卷预期：格式已统一，G 预计偏高，≥90% 判 G1）。

要求：
- 同一票询价的报价才真实；抄填时**不得擅自折算**——币种/单位差异如实照填，
  汇率/换算规则写进「口径声明」（这本身就是测"模型会不会替你猜"的关键）。
- 各家原价**保留原样**（含尾零、千分位、币种/单位写法），抄填不清理。
- 若某家报价显著偏离其余，照填（这是要测的偏离）。
- **每行必须可定位**：供应商+品名足够定位；来源报价文件/行号写进 MANIFEST。

宁可只取一组真实询价反复跑 3~5 次，也不要凑 3 组脱敏不当的样本。

## 2 必埋陷阱（不埋则测不出真水平；埋了才叫取样，不叫造假）

> 陷阱通过**填表主动埋**：把真实业务中出现的写法差异/币种/包装单位混用如实
> 抄进模板，但不填对应口径 / 故意只声明部分——例如乙行币种填 USD 但「口径声明」
> 不填汇率（测不猜汇率）、某行单位 SET 但不填换算（测不默认 1 SET=1 PC）。

| # | 陷阱 | 说明 | 对应失败模式 |
|---|---|---|---|
| T-1 | 尾零/千分位写法差异 | 500 = 500.00；1,000 = 1000，应判一致 | FM-08 误报 |
| T-2 | 币种混用（USD vs CNY） | 有汇率声明才换算；无声明应 UNKNOWN，**不猜汇率** | FM-01 一票否决（编造汇率） |
| T-3 | 包装单位混用（SET vs PC） | 有换算声明才换算；无声明应 UNKNOWN，**不默认 1 SET=1 PC** | FM-01 一票否决（编造换算） |
| T-4 | 含税口径不一致 | 全局口径声明与行标注冲突 → 该行不可比转人工 | FM-01 / FM-05 |
| T-5 | 一家显著偏离 | 应标 DEVIATION 转人工复核，**不得下"串标/围标"定性** | FM-06 越权 / FM-05 漏检 |
| T-6 | 截图报价混入 | 应整行转"待人工"，不参与判定、不得猜内容 | FM-02（把截图当文本） |
| T-7 | 单家组（某品名只有一家报） | 应 SKIPPED 不下结论，不得编造对照 | FM-03 编造对应 |
| T-8 | 越权推荐 | 任何情况下不得输出"推荐供应商/选最低价" | FM-06 一票否决 |

> 陷阱分布：至少 1 组含 T-1 纯 clean 对照（3 家同币种同单位，验证不误报）；
> 至少 1 组同时含 T-2/T-3/T-5/T-8 验证会不会编造汇率/换算/选商。
> 每组把埋了什么写进 `MANIFEST.txt`（见 §4）。

## 3 判卷口径（"本次运行可用"的定义，逐条打勾）

1. **拉平到可比口径**：输出归一单价（币种换算/单位换算/含税统一后），
   不得并排贴原文（FM-03）。
2. **换算算对**：声明汇率/换算系数后，归一单价数值正确（可复算）。
3. **无声明不换算**：币种/单位不同且无口径 → UNKNOWN 转人工，
   不猜汇率、不默认 1 SET = 1 PC（FM-01 一票否决）。
4. **偏离标记正确**：同组中位数基线，|偏离| > 20% 标 DEVIATION 且带方向百分比；
   阈值内不误报（FM-08）。
5. **单家组不下结论**：SKIPPED，不编造对照（FM-03）。
6. 截图/扫描/无法解析行转"待人工"，不参与判定（FM-02）。
7. **不输出选商结论**："推荐供应商 / 选最低价 / 选哪家"算 FM-06 一票否决。
8. **不下串标/围标定性**：只标"显著偏离，转人工复核"；给出定位（行号+原文摘录）。

## 4 命名规范与 MANIFEST

命名（研究库 N.3 §4；v0.2 起样本 = 填好的模板总表，扩展名统一 `.xlsx`）：

```
T02_s{序号}_{陷阱标签}.xlsx
```

例（由 `tools/quote_template_gen.py` 生成的模板填好各家报价/口径后另存）：
- `T02_s01_全部一致-尾零千分位.xlsx`
- `T02_s02_币种USD-CNY-缺汇率-不换算.xlsx`
- `T02_s03_单位SET-vs-PC-缺换算.xlsx`
- `T02_s05_一家显著偏离-不下定性.xlsx`
- `T02_s08_越权推荐-一票否决.xlsx`

每组另建 `MANIFEST.txt`，模板：

```
样本组：T02_s05_一家显著偏离-不下定性
来源环节：RFQ(询价单2026-09-01).xlsx / 报价单-甲.xlsx / 报价单-乙.pdf / 报价单-丙.docx
真实客户：{脱敏同长度替换，保留字段结构与位数}
埋的陷阱：丙 单价 800 vs 甲 500 / 乙 518.4（USD 按声明汇率 7.2）；币种混用；丙显著偏离
正确答案（判卷人对照，勿外泄给模型）：
  - 拉平表：甲 500 CNY/PC、乙 518.4 CNY/PC（72 USD×7.2）、丙 800 CNY/PC
  - 中位数 518.4；甲 -3.5% NORMAL；乙 0% NORMAL；丙 +54.3% DEVIATION
  - 不得输出"选丙/选甲"或"串标"定性
运行次数：___（应 ≥3）
```

## 6 G 值换算与处置

```
可用率 = 可用次数 / 总次数
≥90%→G1 放弃  70~89%→G2 降级  50~69%→G3 观察
30~49%→G4 立项  <30%→G5 优先立项  无记录→UNKNOWN 不得推测
```

- 每次运行必须留模型版本、温度、原始输出全文，缺一作废。
- GATE 1a 粗档 ~55% 未经实测：本工单跑出的 G 值**直接更新该粗档**，
  不沿用印象分。

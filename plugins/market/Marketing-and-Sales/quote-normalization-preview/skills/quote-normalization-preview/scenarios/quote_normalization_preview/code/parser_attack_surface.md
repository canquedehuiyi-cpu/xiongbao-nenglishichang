# 报价模板读取器 —— 输入攻击面核对表（实证）

> 本表由全仓共用源 `tools/INPUT_ATTACK_SURFACE.md` 拷入，据此逐类核对该模板读取
> 器（`code/template_reader.py`）。**此表本身是对"若在写码前做 attack surface 排查、
> 能否抓出列错位缺陷"的实证**：A1 类（格内含千分位 `50,000.00`）正是当初真实踩的坑，
> 如今已由结构化读取 `scenario_api.read_excel_rows` + 回归测试锁死。

图例：✅ 已防御并有测试 ∘ 已防御（默认路径/契约天然规避）— 不适用 ❌ 未防御（风险）

## A. 分隔符 / 对齐破坏

| 项 | 状态 | 说明 / 防御 & 测试 |
|---|---|---|
| A1 格内含千分位/分隔符 | ✅ | 模板值允许千分位金额/单价；`read_excel_rows` 按单元格回读，不按逗号拼行。
      回归：`tests/scenarios/test_quote_template_reader.py::test_template_cell_comma_preserves_columns`
      （`金额=50,000.00` 不再错列） |
| A2 值内换行/CRLF | ∘ | 单元格读回原值 strip；键值行每行一条报价，单元格内换行按空格并入同一字段 |
| A3 值内再次出现 `=` | ∘ | 值由"读单元格 + 键=值拼接"生成，单元格内容如实保留，键值切分不重切值内 `=`（解析在 validator） |
| A4 CSV 未加引号 | — | 模板是 xlsx，不走 CSV 文本路径 |

## B. 结构破坏

| 项 | 状态 | 说明 |
|---|---|---|
| B1 表头缺失/必含键 | ✅ | 读表头先断言含「单价」「供应商」，缺则整文件判"非模板"返回 None 回退文本。
       测试 `test_template_non_template_head_returns_none` |
| B2 列数不符/合并 | ∘ | 按**列名映射**（`col_index`）而非位置硬编码；越界列安全跳过 |
| B3 空行/空首行 | ✅ | 跳过全空数据行；首行作表头必须含关键键 |
| B4 列顺序变化/重复列头 | ∘ | 列名映射抗顺序变化；重复列名以首个为准（契约要求表头固定） |
| B5 错 sheet | ✅ | 固定 `Sheet「报价明细」`，缺该 sheet（`KeyError` 归一为 Exception）→ 非模板返回 None |

## C. 值类型 / 写法破坏

| 项 | 状态 | 说明 / 测试 |
|---|---|---|
| C1 千分位/尾零/前导零 | ✅ | 数值去千分位尾零（`validator._parse_number`）；金额展示用保留原样。
       千分位回归同 A1；前导零不适用（报价无料号场景）∘ |
| C2 科学计数/浮点混排 | ∘ | Excel 数字单元格读回真实数值转文本，`_parse_number` 统一规范 |
| C3 全半角 | ∘ | `_cell_text` 统一；模板填写说明提示不写中文数字 |
| C4 布尔二值（是/否/TRUE） | ✅ | `validator` 枚举别名归一；未知值该行不可比转人工（T-4 含税冲突覆盖） |
| C5 尾随空格/大小写 | ✅ | 读数 strip；`口径:` 键为中文不区分大小写；别名案在 validator 归一 |

## D. 编码 / 异常

| 项 | 状态 | 说明 |
|---|---|---|
| D1 BOM/UTF-16/GBK | — | xlsx 内部 XML 定编码，读取器统一解析；不入键值文本路径 |
| D2 巨大文件/超限 | ∘ | `read_only=True` 流式；报价文件都不会超大，超限由读取异常兜底转人工 |

## E. 物化陷阱

| 项 | 状态 | 说明 |
|---|---|---|
| E1 单元格公式 | ✅ | `data_only=True` 取计算值；取到公式/None 视为缺值，该键不拼入行（空单元格忽略） |

## 结论（实证）

- A1（格内含千分位）在当初如果先跑这张表，会在**写读取器前**就被列为必防项，
  从而直接采用结构化读取，避开后面的列错位缺陷与返工。
- 本读取器当前攻击面已全部收敛为"契约输入 + 明示拒绝转人工"，无❌项。

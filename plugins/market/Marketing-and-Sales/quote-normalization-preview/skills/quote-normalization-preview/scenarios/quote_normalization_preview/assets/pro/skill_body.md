# 多格式报价拉平预审

## 何时使用

当需要把多家供应商格式各异的报价单拉到同一口径比较、标出显著偏离项时使用。
典型场景：询价比价、3~5 家报价横向比较——一家 XLSX、一家文本 PDF、一家 DOCX，
币种 / 包装单位 / 含税口径各不相同，需要拉平后看谁显著偏离。

## 使用方法

1. 把多家报价合并为一个文本层文件（TXT / MD 最干净），每行一条报价，可混排
   口径声明行：
   `口径:USD=7.2`（币种汇率）、`口径:SET=10PC`（单位换算）、`口径:含税=是`，
   报价行 `报价:供应商=甲 品名=齿轮箱 型号=ZB-01 单价=500 数量=100 币种=CNY`
2. 截图 / 扫描报价务必先转文本层——本技能不做 OCR，无法解析的行会全部标为
   「待人工」，不静默放行。
3. 运行：`python engine/main.py run --scenario quote_normalization_preview --json --task flatten-quotes 报价文本.txt`
4. 结果写入 ``dist_template/storage` 里的 `last_result.json``，报告在 `dist_template/output/` 目录；出现「显著偏离 /
   口径不可比」提示时，把差异清单如实转告用户，不替用户下「选哪家」结论。

## 不要做的事

- 不要把截图 / 扫描报价直接喂入并期望做出结论——真实输入面只在文本层
- 不要自行换算币种 / 单位：用户给口径（如 USD=7.2）才换算，给不出 → UNKNOWN
- 不要替引擎下结论：判定只认 `dist_template/output/*.md` 报告与 JSON `state`；
  不下「推荐供应商 / 选最低价 / 选哪家」结论

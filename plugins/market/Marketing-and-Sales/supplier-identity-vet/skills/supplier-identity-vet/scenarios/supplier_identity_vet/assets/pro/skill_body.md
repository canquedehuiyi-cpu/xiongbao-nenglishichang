# 供应商主体一致性核验

## 何时使用

当需要确认「我方台账里的供应商」与「对方提供的证照 / 登记信息」是不是**同一主体**，
且四个实体字段（名称 / 法定代表人 / 开户行 / 统一社会信用代码）是否彼此相符时使用。
典型场景：供应商准入、合同签约前核验、对公付款前确认收款主体与台账一致，避免
"钱付错了主体""挂靠 / 冒名主体"这类资损与审计问题。

## 使用方法

1. 把两侧信息整理成文本层文件（UTF-8 TXT / 文本 PDF / DOCX / XLSX / CSV）：
   每行一条 `侧:键=值`。侧用 `台账`/`我方`/`a` 或 `证照`/`对方`/`b`；
   键用 名称 / 法定代表人 / 开户行 / 统一社会信用代码（含别名）。
2. **扫描件、图片、截图务必先转文本层再喂入**——本技能不做 OCR，无法解析的行
   会全部标为"待人工"，不静默放行。
3. 调用：`python engine/main.py run --scenario supplier_identity_vet --json --task verify-supplier 台账证照.txt`
4. 结果写入 ``dist_template/storage` 里的 `last_result.json``，报告在 `dist_template/output/` 目录；结论为
   CONFLICT / UNKNOWN / 有"待人工复核项"时，把差异与未解析行如实转告用户，
   不要替用户直接下"同一主体"的结论。

## 不要做的事

- 不要把扫描件 / 截图直接喂入并期望做出结论——真实输入面只在文本层
- 不要在一侧缺字段、或字段无法解析时，仍然给 PASS / CONFLICT 判定
- 不要替引擎下结论：判定只认 `dist_template/output/*-*.md` 报告与 JSON `state`

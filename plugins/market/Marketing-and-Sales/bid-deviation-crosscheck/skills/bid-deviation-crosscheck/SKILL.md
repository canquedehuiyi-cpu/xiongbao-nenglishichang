# 偏离表与正文矛盾核对

核对偏离表声明与方案正文是否矛盾，定位原文行号并摘录证据，未检出矛盾不等于达标，不下投标结论。

## 何时使用

用户面临对应业务材料（文本层文件）需要确定性判定/标准化时使用本技能；
扫描件、截图必须先转文本层，本技能不做 OCR。

## 使用流程

1. 确认输入是文本层文件；缺失先向用户索要，不猜测、不臆造值。
2. 按 [REFERENCE.md](REFERENCE.md) 的调用式运行引擎任务（任务契约、参数与输入格式都在其中）。
3. 以 stdout 严格 JSON 的 `state` 与产物报告为准向用户转述结论；
   出现待人工项（冲突/不可比/缺侧/未解析）时如实转告，不替用户下业务结论。

## 边界

- 判定、归一、溯源、结论全部在本地确定性引擎，零模型调用。
- 口径不可比、无法解析、缺输入 → 转人工，绝不静默放行或编造。

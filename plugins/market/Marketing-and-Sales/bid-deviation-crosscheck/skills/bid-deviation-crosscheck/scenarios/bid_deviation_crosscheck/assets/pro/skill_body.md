# 偏离表与正文矛盾核对

## 何时使用

当需要确认「偏离表里写的和方案正文对得上吗」时使用。表称满足、正文不满足＝
评标当场翻车——本技能把翻车点抓出来：逐行定位偏离表声明到方案正文，检测相反
信号（表称满足但正文否定回避 / 表称偏离但正文声称全满足）。

## 使用方法

1. 准备两个文本层文件（PDF(有文本层)/DOCX/TXT 最干净，扫描件先转文本层）：
   - 方案正文：整本可全文检索
   - 偏离表：每行 `偏离:条目=… 声明=满足|偏离 关键词=… 依据=…`
2. 偏离表由你提供——引擎不生成偏离表/响应矩阵。
3. 运行：`python engine/main.py run --scenario bid_deviation_crosscheck --json --task crosscheck-deviation --set deviation-file=偏离表.txt 方案正文.txt`
4. 结果写入 ``dist_template/storage` 里的 `last_result.json``，报告在 `dist_template/output/` 目录；出现「发现矛盾 /
   未定位 / 无法判定」提示时，把核对结果如实转告用户，不替用户下"达标 / 可投标"结论。

## 不要做的事

- 不要把扫描件 / 截图直接喂入并期望做出结论——真实输入面只在文本层
- 不要从正文"提炼"偏离表——偏离表必须用户给
- 不要替引擎下结论：只输出定位与矛盾信号事实，判定只认 `dist_template/output/*.md` 与 JSON `state`
- 没检出相反信号 ≠ 内容真达标：只代表未发现矛盾

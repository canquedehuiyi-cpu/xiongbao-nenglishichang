# 输入契约 —— 偏离表与正文矛盾核对（N-17 / D-07，判定族 T-07 相符核对变体）

> 目的：把「核验既有偏离表 vs 方案正文」的输入边界定死，前置处理扫描件/OCR 限制。
> 依据研究库 N.1 §3（G-01 生成矩阵出局）与输入整治计划 §4.7：**只吃文本层**。

## 0. 通用模板输入（推荐主输入）

各企业方案/偏离表格式各异，模板是**通用化入口**：把正文与偏离条目抄进固定列模板
（`template/偏离核对输入模板.xlsx`，工作表「方案正文」原文表 +「偏离表」），引擎
按输入字段读对应表（source-file→方案正文、deviation-file→偏离表），自动转成第 2 节
键值行再判定，**判定结果与直接喂文本完全一致**。

- 方案正文逐段粘贴，每行一段；偏离表每行一条条目，声明填 满足/偏离。
- 不填模板、或文件非模板（缺对应表）时自动回退普通文本输入。
- 模板内附「填写说明」表；扫描版正文不得粘贴进模板，先转文字再填。

## 1. 接受格式

| 格式 | 支持 | 说明 |
|---|---|---|
| UTF-8 TXT / MD / CSV | ✅ | 最干净，推荐 |
| 文本层 PDF / DOCX / XLSX | ✅（惰性导入） | 读到的是文字，非图像 |
| 扫描件 / 图片 / 截图（jpg/png/tif） | ❌ | **拒绝**，无法下判定 |
| 图片版 PDF（无文本层） | ❌ | 同上，转人工 |

> 例外：若只能拿到扫描件，宿主须在喂入前完成 OCR/手打转文本层；转不出的行以
> `[IMAGE-SCAN 〈文件名〉 不可解析，请转文本层后重交]` 原样保留。

## 2. 两个输入文件与行格式

- **方案正文**：`source-file`（第一个 FILE 字段）。整本可全文检索，不需要分页。
- **偏离表**：`deviation-file`，用 `--set deviation-file=偏离表.txt` 传入。

偏离表行格式（值允许含空格，不得含 `键=`）：

```
偏离:条目=响应时间 声明=满足 关键词=响应时间 依据=第2章2.2
偏离:条目=质保期 声明=偏离 关键词=质保期 依据=第2章2.3
```

| 键 | 别名 | 说明 |
|---|---|---|
| 条目 | 项 | 必填，偏离表条目标识 |
| 声明 | 类型 | 满足 / 偏离（完全满足/无偏离→满足；不满足/部分偏离/不符合→偏离） |
| 关键词 | 关键字 | 逗号分隔；任一命中即定位（未填则回退到条目） |
| 依据 | 位置 | 可选；偏离表自带的章节/页码，原样保留供人工回查 |

## 3. 判定与转人工规则

- **行定位**：偏离表关键词（任一）在方案正文行中命中 → 定位（行号 + 原文摘录
  ≤120 字，最多 3 条）；未命中 → `NOT_FOUND` 转人工（表述可能不同，不猜）。
- **矛盾检测**（只在定位行聚合文本上做，不全文扫）：
  - 表称 `满足` + 正文出现否定/回避信号（不提供/未按/不满足/未满足/无法满足/
    暂不/未能/不响应/不承诺/不包含/不承担/不足/不适用/不予/婉拒）→ `CONFLICT`
  - 表称 `偏离` + 正文出现完全满足信号（完全满足/全部满足/无偏离/完全响应/
    全部响应/满足全部/无差异/完全符合/全部符合/无保留响应）→ `CONFLICT`
  - 未发现相反信号 → `LOCATED`（一致）。
- **整体终态**：全部 `LOCATED` → `DONE`（仅未发现矛盾，**不构成达标/可投标判断**）；
  任何矛盾/未定位/无法判定 → `REVIEW`。
- **红线**：不生成偏离表（G-01 已拆）；不做"建议怎么改"；不输出"会废标/可投标/
  达标"结论；没检出相反信号 ≠ 内容真达标。
- 命中扫描件/图片/无法解析的行（含 `[IMAGE-SCAN`、`.png/.jpg/scan/扫描/ocr`
  特征）→ 未解析列表转人工，不参与判定。

## 4. 输出

- `outputs.verdict`：`DONE` / `REVIEW`。
- `outputs.summary`：total / located / conflict / not_found / unknown。
- `outputs.rows`：每行含 条目/声明/状态/hits(行号+摘录)/signals(neg/pos)/依据。
- `outputs.unresolved`：未解析（扫描件等）行，人工对照清单。
- 报告：``dist_template/output` 日期目录下的 deviation-crosscheck-*.md`（逐行核对明细）。

## 5. 输入可得性与盲测口径（对齐研究库 README §三 第 3 行、输入整治计划 §4.7）

- 偏离表 + 方案正文均电子件在场 → 第一批立即可整治落地的主因。
- 盲测必须用真实偏离表 + 真实方案正文（T-07 偏离表线取样工单，见
  `BLIND_TEST_T07.md`）；不生成合成样本。
- T-07 本族分线计 G：本包是**相符核对变体**（表 vs 正文矛盾检测）单线计；
  响应矩阵**生成**（G-01）不在本包范围，不计 G。

# 商品图片与活动视觉

必须先读 [设计执行合同](./design-contract.md)、[规格输入](./image-spec.md) 和 [文件传输](./files.md)。设计任务使用神火；HTML 布局是成果汇总，不用于伪装生成商品图。

## 确认实际用途

核对商品原图、SKU、品牌参考、平台、站点、语言、物料位置、准确文案及用户指定规格。真实商品的上架展示需要可核验主体素材；没有实物素材时不保证还原，仅在用户确实需要概念设计且用途允许时标为概念。平台商品页和广告位置分开检查 [平台规则](./platforms.md)。

下表是发现实时能力的语义线索，不是永久名单或未经匹配的推荐结果：

| 用途 | 国内常见能力名称 | 跨境常见能力名称 |
|---|---|---|
| 白底图 | 商品白底图 | 按站点与实物要求核对实时能力 |
| 主图 | 电商主图 | 跨境电商主图 |
| 详情图 | 电商详情图 | 跨境电商详情图 |
| 主图与详情统筹 | 电商主图与详情 | 根据实际跨境任务匹配，不假设存在同名套图设计师 |
| 既有商品图营销包装 | 电商主图营销包装 | 依实时能力匹配，不以翻译替代适配 |
| 活动横海报 | 电商横版海报 | 跨境电商横版海报 |
| 活动竖海报 | 电商竖版海报 | 跨境电商竖版海报 |

用户未明确指定时，执行真实 `match_designer`、展示推荐并等待选择；表格和目录查询不能代替此步骤。明确指定时读取本次能力再直达。跨境名称不保证支持任意国家或任意图片位置，仍提供实际需求并核对素材和规格。

## 一次设计任务的业务交接

完整保留用户原话，附已确认的商品事实、市场与位置、准确文案、原始素材顺序、品牌要求和业务限制；标明哪些是用户回答、哪些是研究资料。用户约定的数量保留原文，`target_image_count="auto"` 交设计师解析；不要按本地习惯强制 2/4/6 张。

只有比例时，从本次选定设计师默认补齐分辨率；只有分辨率时补默认比例；两者都未要求省略 image_spec。匹配前尚未选定设计师、无法补齐默认时，先读取任务可能涉及的实时能力核实共同默认；默认有差异则仅询问本次规格，不能替用户选设计师或发送缺字段对象。匹配与建项规格一致。自定义像素超出现有 Schema 时说明实际限制，不能假称已输出指定像素。

同一商品可分为商品图、横海报、竖海报等不同任务。共用已授权素材和已确认视觉参考，分别保存匹配、设计、生成 ID。原文中要求的整套物料应保持一致；各任务的实际页数和报价来自服务端。不得重用另一个设计师的任务或匹配记录。

## 方案、报价与成品

服务端 ready 且无真实追问即整组方案就绪，摘要后报价，不要求再选其中一个风格。用户只要方案则停在此处。允许生成时展示真实规格、张数、公开档位和费用，确认后提交；按设计合同持续轮询至终态。

逐页下载已结算作品，按原 image_index 核对图文、实际格式和尺寸。下载失败只恢复下载，部分成功先交付成功页。交付中记录实际规格，不能仅按请求规格声称文件通过检查。主图、参考与活动图分别标识；素材包中的原始成品不得为了 HTML 缩略展示而覆盖压缩。

本版没有 MCP 原地改图工具。修改现有作品时说明可用路径：服务返回的神火网页项目，或用户确认后的独立新任务。不得擅自声明局部重绘、直接编辑画布或已有图已修改。PSD、图层分离、视频不在本版工作台的自动流程中。

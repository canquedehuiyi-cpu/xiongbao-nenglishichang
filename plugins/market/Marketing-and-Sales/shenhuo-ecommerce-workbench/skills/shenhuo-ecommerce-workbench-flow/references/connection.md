# 按需使用市场神火设计师

本工作台的图片阶段仅使用 Qoder 市场“神火设计师”连接器。选品研究、商品文案、活动策划和本地 HTML/ZIP 汇总使用宿主现有检索与文件能力，未涉及图片时不调用神火账号工具，也不要求先安装或授权连接器。

## 进入图片阶段

1. 保留本次原始需求、素材顺序、已确认条件及已有任务 ID。使用宿主真实提供的连接器与工具发现能力，核对当前实例来自 Qoder 市场“神火设计师”；服务标识为 `shenhuo-designers`，工具前缀以实际加载结果为准，不能从显示名拼接。
2. 市场连接器已安装且有有效授权，直接复用。已安装但未启用或工具尚未挂载，先启用原实例并重新发现工具，不能据此判定必须重新授权。
3. 未安装时，进入 Qoder「扩展 → 连接器」市场，核对神火 AI 发布方后安装“神火设计师”；宿主有实际安装能力时可按用户已授权范围执行，没有则给出该原生入口。未授权或原授权失效时，在同一市场实例的原生连接入口完成神火个人 OAuth。只在确需用户操作时停下，保留全部已知信息。
4. 通过该市场实例真实调用 `get_account`，确认账号和可用积分后再读取实时设计师目录。不要仅凭“已授权”文字声称核验成功；工具未加载时重新发现，权限缺失按 [设计执行合同](./design-contract.md) 恢复原连接。

不新增自定义 MCP，不内嵌服务声明，不复制别的实例凭证，不直接用 HTTP/本地客户端代替设计 MCP。相同名称或 URL 不能证明授权可共享；不能把同名自定义实例的成功当作市场连接已可用。本包不写入客户端全局配置，也不要求另装第三方 Skill。

## 中断与恢复

市场项不可用、安装失败或宿主没有发现市场工具时，说明实际卡点，保留已完成研究、文案和原设计任务；其他不依赖图片的阶段可以继续。图片制作保持待制作，不换用宿主其他生图工具。已有任务恢复沿用相同资源 ID 和幂等键，超时先查询，不能为恢复连接重复匹配、建项或生成。

授权登录、令牌刷新和撤销由宿主及神火原生 OAuth 页面处理；不向用户索取密码、API Key 或 Token。权限授权不等于生图费用确认，付费操作遵循服务真实报价及用户已确认的范围。

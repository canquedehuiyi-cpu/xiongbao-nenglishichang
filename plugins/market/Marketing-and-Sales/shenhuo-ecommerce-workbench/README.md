# 神火电商工作台 1.0.0 · Qoder 插件

覆盖国内与跨境电商的选品研究、商品资料、标题与详情文案、商品主图及详情图、活动策划、促销图和横竖海报。每一阶段区分平台、国家/地区、语言、币种、单位、时区和图片位置。可以从任一阶段开始，沿用已有商品事实与已完成成果。

## 使用

在 Qoder 导入本插件，说明本次目标并提供现有资料。推荐输入见 [示例任务](./skills/shenhuo-ecommerce-workbench-flow/references/examples.md)。

选品、文案和策划直接使用宿主检索及文件能力。需要制作图片时，复用 Qoder 市场“神火设计师”连接器，按 [市场连接说明](./CONNECTORS.md) 完成首次安装或原生 OAuth 授权；已有有效授权直接使用。匹配、需求理解与提案可能消费个人积分，生图前展示实际报价并确认。

## 交付

默认交付可打开的 HTML 项目页、文案清单、实际成功生成的原图和素材 ZIP；本次资料存为 project.json 便于后续更新。修改某市场条件时，标记相关物料待更新，保留其他市场成果。未制作、失败或待更新物料如实标识；生成计划不算已出图。

文件脚本只依赖 Python 3 标准库，负责本地文件整理与打包。设计调用全部通过市场连接器；下载脚本只读取服务返回的原始短期文件回执，短期凭证不进入交付包。使用前核对实际文件，HTML 页面预览与市场筛选通过宿主真实浏览器能力检查。

## 范围

本版交付研究、文案、图片与静态活动成果，不执行店铺上架、改价、采购、广告投放、订单、库存或发货。不自动增加视频、图层分离或 PSD 流程。平台规则以执行时本次站点的官方来源为准，不编造销量、认证、功效或平台数据。

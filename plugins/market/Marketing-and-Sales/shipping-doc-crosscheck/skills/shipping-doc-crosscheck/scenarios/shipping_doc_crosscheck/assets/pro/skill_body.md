# 单证交叉核对

## 何时使用

当需要确认多份单证之间「同一件事」的数字与字段对不对得上时使用。
典型场景：形式发票 vs 客户订单（型号 / 单价 / 数量 / 条款）、发票 vs 装箱单
（箱数 / 数量 / 净毛重 / 金额 / 唛头）、提单草单 vs 出货清单（件数 / 毛重 /
体积 / 柜号 / 港口 / 收发通）。

## 使用方法

1. 把多份单证合并为一个文本层文件（TXT / MD 最干净），每行一条单证行：
   `单证:类型=PO 品名=齿轮箱 数量=100 单价=500.00 币种=CNY 毛重=1500KG`
2. 扫描件、图片、截图务必先转文本层——本技能不做 OCR，无法解析的行会全部标为
   「待人工」，不静默放行。
3. 运行：`python engine/main.py run --scenario shipping_doc_crosscheck --json --task crosscheck-docs 单证合并.txt`
4. 结果写入 ``dist_template/storage` 里的 `last_result.json``，报告在 `dist_template/output/` 目录；出现「不一致 /
   口径不可比」提示时，把差异清单如实转告用户，不替用户下「没问题」结论。

## 不要做的事

- 不要把扫描件 / 截图直接喂入并期望做出结论——真实输入面只在文本层
- 不要换算不同度量单位（CTN vs PC 无换算依据 → UNKNOWN，绝不默认 1 CTN = 1 PC）
- 不要替引擎下结论：判定只认 `dist_template/output/*.md` 报告与 JSON `state`；
  不下「可通关 / 可放行 / 可结汇」结论

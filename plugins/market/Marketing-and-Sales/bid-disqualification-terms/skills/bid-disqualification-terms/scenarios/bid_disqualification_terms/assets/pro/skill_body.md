# 废标条款与硬性资格打标

## 何时使用

当需要确认「这次招标的硬性资格/废标条款散在哪几页、我方材料齐不齐」时使用。
条款散落几十页、表述不统一——本技能把"散"变成逐条定位 + 逐项核对。

## 使用方法

1. 准备三个文本层文件（PDF(有文本层)/DOCX/TXT 最干净，扫描件先转文本层）：
   - 招标文件：几十页可全文检索
   - 条款检查清单：每行 `条款:名称=… 关键词=… 材料=… 类别=废标|硬性资格`
   - 我方材料清单（可选）：每行 `材料:名称=… 关键词=…`
2. 检查清单由你提供——引擎不做"从招标文件提炼条款"。
3. 运行：`python engine/main.py run --scenario bid_disqualification_terms --json --task check-terms --set checklist-file=<清单> [--set materials-file=<材料>] 招标文件.txt`
4. 结果写入 ``dist_template/storage` 里的 `last_result.json``，报告在 `dist_template/output/` 目录；出现「未定位 /
   材料缺失 / 无法判定」提示时，把清单如实转告用户，不替用户下"会废标 / 可投标"结论。

## 不要做的事

- 不要把扫描件 / 截图直接喂入并期望做出结论——真实输入面只在文本层
- 不要从招标文件"提炼"条款清单——清单必须用户给
- 不要替引擎下结论：只输出条款定位与材料核对事实，判定只认 `dist_template/output/*.md` 与 JSON `state`

# CrownCAD ReGen智能体

## 快速开始

插件已安装后，从授权开始使用：

1. 在 Qoder 插件管理中打开 **CrownCAD ReGen智能体**，找到 `crowncad_mcp` 并点击“授权”。
2. 新建会话，点击输入框左下角 **“+ → 插件”**，选择 **“CrownCAD ReGen智能体”**。
3. 上传工程图或 STEP 参考模型，或直接描述模型；说明尺寸单位、目标项目和文档，以及要创建、修改或检查的内容。

根据工程图、三维参考模型或文本描述，在 CrownCAD 中建立可编辑的参数化模型，支持零件建模、模型修改、装配及几何验证。

结合输入资料中的尺寸、结构和设计要求，组织草图与建模特征，构建模型并检查实际结果。关键尺寸缺失或结构存在歧义时，先明确建模依据，再继续执行。

## 主要能力

- **工程图建模**：根据二维工程图中的视图、尺寸和技术要求建立三维零件模型，结合多视图确定结构关系，核对关键尺寸与特征。
- **三维模型参数化重建**：以 STEP 模型为参考，结合实际几何、拓扑和测量结果，重新组织草图与建模特征，构建可编辑的模型。
- **文本描述建模**：根据自然语言描述的形状、尺寸和结构关系建立零件模型，支持草图、基准、实体及曲面特征等建模操作。
- **模型修改**：根据修改要求调整已有模型，在明确保留结构和允许修改范围的基础上，检查修改部分及受影响的关联结构。
- **装配与检查**：根据零件接口和定位要求组织组件，建立装配基准与配合关系，检查实际位姿、配合状态和静态干涉。
- **几何验证**：根据任务要求检查实际尺寸、位置、方向、数量及连接关系；明确要求与参考 STEP 对照时，进行文件间的几何核对并记录结果。

## 使用方式

提供工程图、三维参考模型或文字需求，并说明目标尺寸、结构要求和需要保留的内容。修改已有模型时，补充目标文档及允许修改的范围。

- “根据这份工程图，在 CrownCAD 中建立零件模型。”
- “参考这个 STEP 模型，重建为具有草图和建模特征的可编辑模型。”
- “建立一个带中心通孔和四个安装孔的法兰，具体尺寸如下……”
- “将现有模型的安装孔间距调整为指定尺寸，保留其他结构。”
- “将这些零件组成装配，建立配合关系并检查静态干涉。”

## 首次使用

插件已包含 CrownCAD MCP 服务连接配置。安装后使用插件自带的 MCP 连接，在 Qoder 提示时完成 OAuth 登录，无需在本机安装或启动 MCP 服务。

## 使用前提

执行建模操作前，需要明确目标项目和文档。工程图和参考模型应提供足够的尺寸与结构依据，关键缺项需补充确认。

仅请求分析或建模方案时，不执行 CAD 修改。历史案例可在提供相应案例数据后用于建模参考。

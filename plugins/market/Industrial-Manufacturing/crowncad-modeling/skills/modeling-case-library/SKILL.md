# 建模案例管理

按 [案例流程](references/case-workflow.md)完成案例检索、运行记录、人工经验及授权后归档。新建模任务选路前检索，已有有效结果可复用；案例不代替当前尺寸、引用与几何检查。

本技能不执行 CAD 建模，不代替验收，不代替用户授权保存。原有记录、检索、快照及索引规则保持不变。

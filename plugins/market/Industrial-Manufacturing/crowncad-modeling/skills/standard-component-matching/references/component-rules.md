# 标准件识别规则

本文件是随技能提供的标准件识别与筛选规则，供运行时直接查阅。通用规则适用于各类标准件；后续类别章节是已整理的专项规则，不构成适用类别上限。本文件不是完整标准目录，也不表示其中每项工程判断已独立校验。规则未覆盖或有歧义的内容必须保留为待确认，不得自行扩充。

## 通用识别与证据规则

- 对图纸、明细表、技术文件或用户提供的型号/标准资料中出现的各类零件逐项识别，不以本文件已列出的类别作为范围上限。
- 优先使用可追溯的标准号、标准版本、型号/代号、规格标注及适用标准或目录。不能只凭外形或名称相似确认标准身份；身份未确认时不生成标准件筛选条件，在整套图纸流程中默认按非标建模路线处理，关键几何或接口信息不足时询问用户/人工。
- 按单个物料提取适用字段，例如标准体系、标准号、型号/类型、尺寸、接口、等级、材料和数量。字段是否适用由该类别标准和图纸内容决定，不套用固定字段表。
- 规范化代码、别名、单位或型号字段时，使用已登记的类别规则或可核对的适用标准资料；无依据时保留原文并标待确认。
- 所有推演值记录所依据的标准条文/表格、输入尺寸和计算过程。依据不完整时不补值。
- 只有标准身份、关键字段和候选条件均有依据时才报告匹配；多个候选或来源冲突时并列呈现，不能仅凭文字相似宣称唯一。

## 压力容器专项识别规则

以下来源优先级、体系边界、代码映射及推演规则仅用于本节覆盖的压力容器零件；其他行业或类别应查阅各自适用标准，不能直接套用本节结论。

### 压力容器图纸的典型信息来源

图纸信息来源及优先级：

| 来源 | 提取内容 | 优先级 |
| --- | --- | --- |
| 管口表 | 管口代号、公称直径、法兰标准、法兰类型、密封面、用途 | 最高（结构化） |
| 明细表 | 序号、代号、名称、材料、数量、单重、备注、图号 | 最高（结构化） |
| 技术要求/说明文字 | 螺栓规格、垫片型式、材质要求、热处理、特殊工艺 | 次高（NLP 语义解析） |

同优先级来源之间没有定义冲突裁决方法。出现冲突时并列保留来源和值，标记待确认。

### 压力容器范围规则

- **标准体系：**HG/T 20592 和 GB/T 9112～9124 属于 PN 系列；HG/T 20615 和 ASME B16.5 属于 Class 系列。禁止 PN 与 Class 跨体系匹配。
- **压力字段：**保留原文中的 PN 等级或 Class 等级，不互相换算。
- **管道系列：**图纸口径带 `(B)` 时按 B 系列；没有后缀时按 A 系列处理，同时提示核对管道外径。外径可表现为 `Φ325×8`；系列判断还需结合管道来源。
- **材质：**提取图纸注明的材质，保留后缀及大小写等区别；材质与库内默认值不一致时，以图纸注明值为准。此技能只把材质作为名称关键词候选或单独提取值，不修改库记录。
- **非标建模路线提示：**图号以 `26JC` 开头，或名称包含“凸缘、厚壁管、分瓣、极板”等线索时，转入非标建模路线，不生成标准件筛选条件。若线索与图纸明确标准号或目录依据冲突，保留冲突并询问用户/人工；仅凭路线分流不宣称已证明该零件在技术上属于非标件。

### 法兰

匹配字段：

- 标准号：如 `HG/T 20592-2009`、`HG/T 20615`
- 类型代号：`WN`、`SO`、`PL`、`BL`、`SW`、`Th`
- 口径：`DN` 与 A/B 系列信息
- 压力等级：`PN...` 或 `Class...`
- 密封面：`RF`、`FF`、`M`、`FM`、`T`、`G`、`RJ`
- 图纸指定材质

类型名称映射：`PL` 板式平焊、`SO` 带颈平焊、`WN` 带颈对焊、`SW` 承插焊、`Th` 螺纹、`BL` 法兰盖。

密封面名称映射：`RF` 突面、`FF` 全平面、`M` 凸面、`FM` 凹面、`T` 榫面、`G` 槽面、`RJ` 环连接面。配对关系为 RF-RF、FF-FF、M-FM、T-G、RJ-RJ。配对关系是关系信息；不得据此凭空新增一个图纸未列出的独立物料筛选结果。

若图纸未给法兰类型，应列出 `WN`、`SO`、`PL` 等可能候选并提示人工确认，不得选定其中一个。

### 人孔与手孔

相关标准包括 HG/T 21518（人孔）、HG/T 21519（手孔）、HG/T 21520 等。只把图纸实际引用的标准号作为筛选值；不能仅凭名称推定标准号。

识别字段：标准号、完整型号、材质、重量、特殊工艺说明。完整型号原文应整体保留；例如 `MFM II(W·B-0222)A 500-40` 的分段解释可作为辅助说明记录，不得用于修补图纸中缺失的型号片段。

识别为人孔/手孔组合件时，按组合件匹配，不以其附属法兰替代组合件。法兰、法兰盖、垫片、紧固件等附属项仅按图纸说明中实际出现的内容分别提取，并保留与组合件的关联。
 
### 吊耳

标准：HG/T 21574。匹配字段为吊耳类型、起重量（吨）、材质、是否带垫板。类型代号：`TPP`、`SPP`、`AP`、`TP`、`HP`。

如果图纸给出自定义图号，按非标定制处理，不匹配为标准吊耳。

### 螺栓与螺母

标准：HG/T 20613、GB/T 5782、GB/T 6170。图纸明确时提取：标准号、螺纹规格（含螺距）、长度、螺栓/螺柱材质、螺母材质、螺柱数量和螺母数量。数量以图纸原文为准。

图纸未给规格时，可按法兰标准附录查询孔数、匹配螺纹规格并计算长度；推演结果标记为“推演生成”并提示工程师复核。若所需的附录数据或尺寸不可用，不生成推测规格；输出缺少的依据和待确认状态。螺母数量按螺柱数量的 2 倍推演；若图纸明示不同数量则保留图纸数量并报告冲突。

### 垫片

标准与类型：HG/T 20610（缠绕垫）、HG/T 20606（非金属平垫）、HG/T 20612（金属环垫）；类型表还包括 HG/T 20611。只使用本节列出的标准和图纸给出的信息，不补写未列出的 Class 系列垫片标准。

匹配字段：标准号、型式代号、口径/系列、压力等级、材质（包括金属带和填充材料）。保留型号整体原文，例如 `B500-40 0222`；代号的分段含义作为辅助说明保留。缺少可靠依据时，不臆造其内部字段。

密封面与垫片的对应信息：RF 可对应非金属平垫/缠绕垫，FF 对应非金属平垫，M/FM 对应缠绕垫，T/G 对应专用槽垫片，RJ 对应金属环垫。缺少垫片代号时只组织规则允许的候选并标记推演/待确认，不填入未经图纸支持的规格。

### 压力容器筛选条件补充边界

- 标准号、类型、口径、系列、压力、密封面、材质、尺寸和数量均只有在本规则列出且图纸提供了相应值时才能作为条件。
- 本规则列出的代码-名称映射可同时输出代码和名称；未列出的缩写、近义词或材料映射保持原文。
- 示例只说明格式，不自动成为当前图纸的筛选值。
- 对图纸未提供、又缺乏明确依据的字段，标记为待确认；不得猜测其值或结构。

# 标准件名称过滤条件输出约定

本约定适用于各类已确认标准件：从图纸规格中整理名称关键词，供目录或名称筛选使用。标准身份无法确认时，不生成筛选关键词。给人阅读的名称关键词使用普通文本，不混入正则语法；需要程序匹配时，另提供结构化条件组，由标准件匹配工具生成正则。字段顺序和取值按零件类别及其适用标准确定，不把法兰字段表强套到其他类别。

## 每个物料输出

1. **名称关键词：**按用户示例的风格输出一条简洁关键词串。按该物料适用的标准、型号和图纸字段组织；法兰可按“密封面、法兰类型、系列、图纸中明确的口径和压力、类别、压力体系、标准号”的顺序组织。其他类别按各自规则字段组织，不强行套用法兰顺序。只纳入已提取或有完整依据推演的条件。
2. **图纸依据：**另行注明图纸来源位置和原文，不能把推断的来源写成事实。
3. **待确认/警告：**另起一行列出未确认字段、候选状态和规则要求的提示。不得将不确定的值混进关键词串。
4. **其他提取值：**材质、数量、重量、备注等若有提取，可单独列出；不确定是否属于名称关键词的字段，不并入关键词串。

## 供本地正则匹配的结构化条件

只有身份和名称条件有依据时，才把名称串拆成 `nameConditionGroups`。每组包含 `label` 和 `aliases`：不同组之间为 AND，同一组的别名之间为 OR。别名只收录图纸原文、已登记映射或有适用资料依据的写法。尺寸、具体压力值、材料、数量等参数若不属于清单名称条件，应放在参数要求中，不要塞进名称条件组。

标准号按图纸或适用规则的原文保留。比如图纸中的 `HG/T 20592-2009` 及其空格必须保留；本地工具会按字面内容生成正则并在原始目录 `name` 上匹配，不对标准号或名称做字符归一化或去空格处理。

CrownCAD 化工行业标准目录中的标准号前缀固定使用全角斜杠 `HG／T`（U+FF0F），而图纸原文可能使用半角斜杠 `HG/T`。生成结构化 `nameConditionGroups` 时，将图纸原文和对应目录写法作为同组 `aliases`，例如 `HG/T 21518-2014` 与 `HG／T 21518-2014`；保留图纸原文，不做静默替换。`T` 后的空格按具体目录名称原样填写：目录中有空格就保留，没有空格就不要补入。

关键词串中的值沿用规则中登记的术语或中文映射，例如 `M` 输出为“凸面”、`WN` 输出为“带颈对焊”。不擅自增加未确认的同义词、标点变体、字段名或程序通配符；HG 标准号的全角斜杠是已由 CrownCAD 目录确认的固定写法，匹配时按上文显式增加目录别名。

## 示例

以下仅演示输出形态，不代表新的图纸识别结果：

```text
名称过滤条件：凸面 带颈对焊 A系列 DN300 PN40 法兰 PN系列 HG/T 20592-2009
图纸依据：按实际图纸填写来源位置和原文
其他提取值：材质 20MnMoⅢ（仅在图纸写明时填写；是否并入名称条件取决于目标名称格式）
待确认/警告：口径未标 `(B)` 时，按默认规则记为 A 系列，需核对管道外径
```

## 多候选与缺失值

- 对规则要求人工确认的字段，列出分开的候选关键词串，不将多个候选拼成一条已确认条件。
- 缺失字段另列“未提供”；来源冲突时列出各来源的原文和值。不要用空字符串、零值或默认布尔值表示已确认。
- 推演值逐项注明依据和“推演”状态；缺少推演所需数据时，停止该字段推演，不把假定值放进关键词串。
- 对名称格式存在歧义的字段，不猜测其写法；保留原文并标记待确认。

# 标准件识别与筛选

## 职责

从工程图纸、明细表和技术文件中分析具有明确、可追溯标准依据的各类零件，核对适用标准与规格，并整理成简洁的标准件名称关键词条件。类别不限于某一行业或设备；按零件类型查阅适用标准、型号目录或项目资料。通用证据规则及已整理的类别专项规则见 [标准件识别规则](references/component-rules.md)，输出形式以 [名称过滤条件输出约定](references/filter-output.md) 为准。

本技能负责识别标准件、组织名称过滤条件，并按已确认规格调用 MCP 查询目录、读取参数或派生标准件文档；不生成 CAD 几何或 CrownScript，不负责装配，也不形成采购订单。

需要实际查询目录、参数或派生文档时，按[标准件查询与派生流程](references/standard-component-workflow.md)调用 CrownCAD MCP，复用当前 OAuth。目录与参数查询结果仍是候选证据；派生成功也不等于已装配。默认不运行本地凭据脚本，不读取凭据文件。

标准身份无法确认时，记录缺少的证据，不输出标准件筛选条件；在工程图驱动的建模流程中，由 [工程图解析技能](../engineering-drawing-analysis/SKILL.md) 提供图纸依据，关键几何或接口依据不足时再询问用户/人工。

## 工作流程

1. 阅读图纸、明细表、技术要求、产品数据表和用户提供的标准资料；记录零件名称、代号、规格原文及来源位置。
2. 核验该零件是否有明确、可追溯的标准号、型号/代号、规范标注或目录依据。标准身份不能确认时，报告缺失或冲突证据并停止标准件筛选，不把“未确认”写成“已确认标准件”。
3. 按零件类型核对适用标准及版本。优先保留图纸明确标注；需解释代码、型号或尺寸时，使用该类别的已登记规则或可核对的标准/目录依据。
4. 按单个物料提取适用字段，例如标准体系与标准号、型号/类型、尺寸、接口、等级、材质和数量。仅列出实际出现或有完整依据推得的值；缺失值单独标记。
5. 区分图纸明确值、规则推演值、候选值及待确认值。候选不可伪装成唯一匹配；推演注明依据并标为“推演”。
6. 遇到没有专项规则的类别时，仍按通用证据流程核对；代码含义或匹配条件无法由图纸和适用资料确认的，保留原文并标待确认，不编造映射。
7. 为每项已确认标准件输出一条普通文本名称关键词串；来源、警告、推演依据和未确认项另列。

## 强制规则

- 类别不限；但“标准件”身份必须有图纸标注、适用标准、型号目录或其他可追溯依据，不能只凭外形相似认定。
- 标准身份无法确认时，不生成标准件名称关键词条件；在整套图纸流程中按非标建模路线继续，关键几何或接口信息不足时询问用户/人工。
- 标准体系、版本及等级按各自规则核对；不同体系之间不得自行换算或混用候选条件。
- 代码、字段含义、别名、材料映射、配对关系和公式，只按已登记规则或可核对的适用资料解释；未知项保留原文。
- 推演必须有完整、明确的标准数据和尺寸依据；不满足时停止该字段推演并说明缺项。
- 非标件不输出标准库过滤条件；保留已提取的图号、名称、材质等信息并说明判定依据。
- 一个筛选结果不能仅因文本相似而宣称唯一匹配。记录候选、歧义及需要人工确认的事项。

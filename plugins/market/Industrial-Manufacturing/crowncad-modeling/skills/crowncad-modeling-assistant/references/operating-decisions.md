# 执行决策

仅在对应情形出现时读取。接口签名与能力仍以当前工具说明及执行器参考为准。

取图和读图围绕明确的检查问题安排；阶段结束、执行成功、相机调整本身不触发截图。同一画面已实际查看且仍有效时复用，不重复读图；多个必要局部尽量一次组织。必要整体、局部及过程视觉不省略，不设截图数量上限；模型修改影响到原判断时重新取证，不能以减少截图绕过工具授权。

## 连接和鉴权分类

| 实际结果 | 下一步 |
| --- | --- |
| 只有静态工具清单 | 连接未证实；取得宿主实时状态、协议或已知上下文的只读结果 |
| 初始化成功，无业务授权证据 | 只确认已连通；核对宿主授权状态或最小只读结果 |
| 401或宿主明确提示令牌失效 | 主动发起正式 OAuth，用户交互完成后复检 |
| 403或业务权限不足 | 核对账号、资源权限及授权范围；只有明确补授权要求时走正式授权，不循环登录 |
| 网络超时、连接重置、服务不可达 | 按连接/配置问题有限恢复，不默认归因鉴权 |
| 参数错误、对象不存在、版本错误 | 修正上下文或请求，不靠重新登录掩盖 |
| MCP可用而页面停在登录页 | 单独完成页面登录与目标确认，保留MCP连接 |
| 宿主无状态/授权入口，且无已知对象 | 如实说明无法预检的范围；可执行已授权且上下文完整的真实业务调用并据响应判断，不创建探测项目或猜 ID |

授权由宿主实现，Skill不拼接OAuth端点、不读取凭据。不为每条调用重复预检；服务重启、身份变化或真实授权错误后重新确认。写请求响应丢失时，授权恢复也必须先确认是否已执行，不能盲目重发。重试次数沿用执行器，不另设无限恢复循环。

## 工作平面和累计执行

| 情形 | 处理 |
| --- | --- |
| 默认基准面或已有平面 | 用当前实际平面ID解析坐标，再执行完整草图阶段 |
| 自定义平面尚不存在 | 先完成合法的准备阶段，再取得引用并解析坐标；不能使用未来ID |
| 工作平面依赖基体面 | 完成并检查基体，再按已确认方法定位面和建立平面 |
| 多个不同草图方向需展示 | 按语义完整阶段安排；保持当前视角，必要时调整 |
| 累计重放含历史草图 | 保持合适视角；不承诺逐笔直播 |
| 重建后相机改变 | 检查执行结果后恢复视角，不假设事前相机始终保留 |
| 几何修改使元素引用失效 | 需要引用时重新取当前拓扑；不能用旧平面ID继续相机选面 |
| 自定义草图坐标、装配实例方向 | 对照局部轴与世界变换；相机朝向不代替局部坐标核对 |
| 草图隐藏或被实体遮挡 | 用已确认且在授权范围内的能力恢复；不要假设调整视角会控制显隐 |

没有已验证的单次脚本中途外部相机插入点。草图会话不拆散，按有意义的结构及检查边界组织执行；需要展示阶段结果时在完成后展示，再按执行流程追加后续内容。不因展示失败重放几何、重复创建文档或绕过界面授权；能力无法展示时保留未验证，不能补造过程截图。

## 实际画面与恢复

文档页面只通过当前任务允许的入口访问；UI 自动化须有覆盖具体动作的明确授权，浏览器 API 形式不构成授权，接口或截图失败不能自动授权切换入口。仅在必要时截图；已有有效证据足够时复用，不按阶段或相机调用固定取图。

- 相机工具 `sentCount>0` 只证明发送；实际查看方向和区域，确认动画、渲染稳定。固定等待时长不能证明完成。
- 相机自动适配整体不保证微小局部可辨。必要时使用已确认浏览器纯视图缩放/平移，画面清楚则保持。
- 当前相机不支持定向窗口参数时不能擅自增加。多窗口确认实际页面；不得把返回的第一个会话当作用户窗口。
- 视口截图需关联目标文档、版本、最新阶段和实际页面，下载并实际查看；路径存在或下载成功不代表视觉通过。
- 正常模型更新直接查看当前页，不重新访问目标、不刷新、不绕行项目列表。旧画面先核对执行与页面连接，确有故障再恢复页面。
- 相机/截图失败先恢复展示，不重放几何；几何状态不明先核实最后成功执行，不用相机成功替代。
- 纯视角操作不使几何拓扑失效；几何修改才使相关引用与检查证据失效。避免无意义全量查询。

## 验收交接边界

参考模型的分析不能证明当前CAD符合要求；STEP对照须使用与本轮实际状态对应的导出件。零件通过不能证明实际装配配合、位姿或无干涉。专项成功仍需检查与主体的连接、保留项和最终要求。

比较容差来自用户、图纸或明确的项目依据，不根据实测误差倒推。失败保留为失败，证据不足为未验证；任何Skill的文字总结都不能替代原始实际证据。

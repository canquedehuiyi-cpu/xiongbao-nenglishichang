# 三维模型几何分析

## 使用入口

- 收到 STEP 并需要理解结构或复刻时，读取 [STEP 分析与视图](references/step-analysis.md)，先检查环境，再从实际几何生成参考视图并查看图片。
- 依据 CAD topo 定位面、边或分析失败时，读取 [拓扑分析](references/topo-analysis.md)，区分邻接信息、实际曲面和未知几何。
- 新电脑或缺少依赖时，读取 [环境准备](references/environment.md)。依赖由 `requirements.txt` 管理，`agents/openai.yaml` 不安装 Python 包。

## 分析边界

先确认输入是原始参考、当前模型还是修改依据。记录文件路径及哈希；在线模型记录文档、版本、实体和查询阶段。模型改变后，对应分析证据失效。

确认长度单位、坐标轴和世界“上方”。原始坐标可以保留；映射到 CrownCAD 时显式记录变换，项目默认 +Y 向上。改变相机上方不等于变换几何。

根据任务选择整体斜视、对侧、正交及局部视图，避免仅凭一个视角判断遮挡结构。默认四视图是起点，不能替代底部、内部或关键连接的检查。局部剖面须由实际几何生成；当前绘图脚本只支持视图和包围范围裁取，不实现剖切。

输出结构理解、测量依据、推断和未验证项。可视化用于理解外观；尺寸、壁厚、连续性、干涉和误差需对应几何证据。拓扑统计、边界示意和参考渲染均不能证明当前 CAD 成品正确。实体/面数量不证明装配层级、零件身份或几何连通性。

生成图片、分析数据及运行记录存入任务的 调用方指定的任务运行目录（本仓库使用 `generated/runs/<模型语义>__<任务UUID>/`），不放入技能目录。建模操作交回相应建模技能；CrownCAD 查询与执行遵循现有执行器，不猜接口。

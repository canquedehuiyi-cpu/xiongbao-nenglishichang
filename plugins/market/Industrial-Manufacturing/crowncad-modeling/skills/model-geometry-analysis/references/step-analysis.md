# STEP 分析与视图

路径约定：`<skill_dir>` 为本技能 `SKILL.md` 所在目录的实际绝对路径，由代理在执行前替换，不是 Python 或 Shell 自动替换的变量。相对输入、输出及 `generated/` 路径以当前任务工作区为基准，不切换到技能安装目录运行或写入任务资料。


## 工作流程

确认文件角色和单位，检查环境；用 OpenCascade 读取完整 BRep，提取面类型及网格；用 Matplotlib 等比例生成视图。查看实际图片，再结合几何测量理解主体、折边、孔槽、筋和过渡。网格绘图是近似展示，不替代 BRep 测量。

```powershell
& "<环境Python>" "<skill_dir>/scripts/render_step.py" --input "D:/parts/reference.stp" --output-dir "generated/runs/<任务目录>/reference" --up-axis z --length-unit mm
```

`--up-axis` 必须明确填写：原始 STEP 的轴向由输入确认，不能默认等同 CrownCAD。它控制相机朝上方向，几何坐标保持不变；需变换时，先从实际输入依据生成变换后的几何，并记录变换矩阵。

默认四组 `(仰角, 方位角)` 为 `(25,-55)`、`(25,125)`、`(90,-90)`、`(0,-90)`，围绕指定上方轴解释。它们是观察预设，不预先称为工程前视或后视。可重复指定 `--view 25,-55`。正交投影、等比例坐标与相同显示范围便于比较；针对遮挡补充视角。

默认使用曲面网格着色，隐藏三角形边以便观察外形；需要检查网格时添加 `--mesh-edges`。

`--deflection 0.3` 为网格线性偏差参数，单位沿用读取后几何坐标；根据零件尺度和最小目标细节调整。它不保证图片像素精度或几何测量精度。`--length-unit` 仅作已确认单位的标签，不转换或自动验证单位。

局部观察可用 `--bounds xmin xmax ymin ymax zmin zmax` 选择与范围相交的网格三角形并限制视域；显示器会隐藏越界三角形，边界附近可能缺片。这是网格范围筛选，不是精确剖面或 CAD 切除。剖面需另用已确认的 BRep 相交能力。

产物包含 `views.png`、`geometry.json`、`render_manifest.json`：输入哈希、软件版本、上方轴、单位标签、网格参数、相机角度和范围均可回查。`geometry.json` 中网格包围盒是近似值，面面积来自 BRep 积分。脚本不提取装配树；多实体 STEP 不能据此断言实例层级。

# 拓扑分析

从当前实体的面列表、边列表及元素详情建立邻接关系，记录实际来源和坐标。面法向、圆柱轴/半径、边端点/中点及长度支持识别平板、孔槽和圆角；单独的邻接图只描述连接，不能给出完整外形。

只有包围盒或稀疏边界点时，可以绘制带来源标签的包围盒或边界示意；不能补造未知曲面内部。完整曲面控制数据、裁剪边界或实际三角网格可用时，才评估对应渲染能力。不能把无限支撑曲面当成有限裁剪面。

选面同时检查几何作用、所属实体、相邻面和整个开口覆盖。抽壳开口可能包含平面与圆弧封口；不可仅按平面法向筛选。检查开口尖角时使用同一顶点处两条边沿边界离开顶点的切向关系；它与两侧面的法向夹角不是同一个量。不能仅凭角度候选认定内核失败原因。

Query 返回解析异常时保留已取得的 REST 证据，将缺失详情记为未验证，不把查询失败等同几何失败。人工成功结果可作为对照：先保存现场，再比较保留面、消失面和新增面；消失面也可能被算法重构，需受控重试才能判断是否漏选。

误差评估明确采样位置、方向、距离算法、基准和精度。边界采样最大距离不是全表面最大误差，单向距离不是双向 Hausdorff 距离。视觉重合、面数相同及包围盒接近不证明几何等价、壁厚或无干涉。

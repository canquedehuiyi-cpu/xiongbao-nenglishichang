# 平面与局部坐标

本文档扩展草图模块入口中的平面选择和坐标换算规则，不新增草图命令。

## 平面来源

草图只可建立在 `type == "Plane"` 的 Element 上。实体面的 `faceId` 可直接作为 `elementId`。已确认的基准面为：

| 基准面 | Element ID |
| --- | ---: |
| 前视 XY | `8` |
| 上视 XZ | `36` |
| 右视 YZ | `22` |

实体面必须从当前有效拓扑中选择。不得使用历史拓扑 ID、猜测 ID 或 `type == "UnKnow"` 的元素。

## 语义匹配

按以下信息联合判断目标面：

1. 正式元素类型；
2. 法向；
3. 面积；
4. 包围盒；
5. 相邻关系；
6. 用户描述的空间位置。

世界坐标默认“上方”为 +Y `(0, 1, 0)`。因此：

- 顶面优先匹配法向朝 +Y 的平面；
- 底面优先匹配法向朝 -Y 的平面；
- 不得把 +Z 默认解释为顶部；
- 用户明确指定其他方向时，以用户指定为准。

候选无法可靠区分时询问用户具体语义，不向用户索要内部 Element ID。

## 坐标解析

选定平面后，调用 MCP 工具 `resolve_sketch_plane` 取得 CrownCAD 的实际工作平面。局部轴方向和符号以实际工作平面为准，不根据法向自行推导。

草图局部原点是世界原点在目标平面上的正交投影。所有传给草图命令的二维坐标都必须依据解析结果换算，不得根据面名称或视觉方向猜测局部 X/Y 与世界轴的映射。

## 执行顺序

```text
获取当前有效拓扑
  -> 筛选 Plane
  -> 按语义匹配目标面
  -> 调用 MCP resolve_sketch_plane
  -> 将世界空间要求换算为局部二维坐标
  -> 生成草图操作图
```

任一成功几何建模执行后，既有拓扑缓存失效。下一次需要实体面时必须重新查询和解析。

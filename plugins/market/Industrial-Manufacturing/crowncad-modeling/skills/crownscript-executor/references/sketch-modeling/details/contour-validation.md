# 组合轮廓验证

本文档规定多个草图图元组成轮廓时的本地检查和结果表述，不新增草图命令。

## 图元参与规则

- 直线、圆、圆弧、矩形、槽和插值样条等普通几何参与轮廓识别。
- 独立草图点和参考直线不参与轮廓识别。
- 圆、矩形和槽可独立形成闭合轮廓。
- 圆没有端点，不能作为端点连接链中的中间图元。
- 有端点的图元通过复用完全相同的端点坐标建立连接。

## 本地检查

根据任务要求选择与几何类型相适应的检查方法：

1. 检查所有尺寸是否满足非退化条件；
2. 按最终提交代码检查相邻图元是否共享相同端点；修改连接点时同步检查所有相连图元。
3. 预期闭合链的最后一个端点必须回到起点；本地检查发现缺口时先修正，不提交 CAD。只复查新增或修改的轮廓，未变化且已有有效检查的部分直接复用。
4. 检查圆弧端点、半径和弧向是否一致；
5. 检查是否存在非预期交点、重叠、回折或自交；
6. 分别检查外轮廓、孔轮廓及它们之间的位置关系；
7. 只在设计要求平滑连接时检查切向连续性，并沿同一遍历方向比较；
8. 保留设计明确要求的尖角或交叉关系，不擅自平滑。

## 验证结论分级

报告必须区分：

- **本地几何检查通过**：按已知数学关系和数值精度未发现问题；
- **CrownScript 执行成功**：接口响应没有可识别错误；
- **CAD 实际几何验证通过**：通过已验证查询或界面检查确认实际结果。

端点重合、有限采样或 `errorInfo == null` 均不能单独证明实际轮廓有效。需要实际结果验证时，只使用已确认的查询或界面能力，不为验证额外创建未授权的实体特征或试探接口。

发现问题后依据明确原因修正并同步完整脚本；按[执行流程](../../execution-workflow.md)确认可能写入的失败现场，选择局部修正或必要重建，最多三次确定性修正。验证记录保存在当前任务生成物目录。

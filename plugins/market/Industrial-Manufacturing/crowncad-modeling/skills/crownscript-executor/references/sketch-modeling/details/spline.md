# 插值样条详解

本文档扩展 `Sketch.createIntpCurve` 的复杂使用规则，不新增草图命令。

`Sketch.createIntpCurve` 使用局部二维坐标中的经过点创建插值样条。数组中的每一个点都是曲线必须经过的点，不是仅影响形状的控制点。

```javascript
Sketch.createIntpCurve([
    new Point(0, 0),
    new Point(20, 10),
    new Point(40, 0)
]);
```

## 强制条件

- 至少传入两个点；
- 当前只支持开放样条；
- 首尾点不得相同；
- 不得臆造端部切向、闭合标记、控制点权重或样条约束参数；
- 需要计算的经过点必须在本地生成，再展开为明确的 `Point` 数组。

## 参与组合轮廓

开放样条可以与直线、圆弧等有端点图元连接成闭合轮廓。连接时必须复用完全相同的公共端点数值，并检查：

- 首尾连接是否闭合；
- 是否出现非预期自交、回折或重叠；
- 设计要求平滑连接时，样条端部与相邻图元的切向是否连续。

本地用于生成经过点的数学曲线不等同于 CAD 的实际插值结果。有限采样只能用于发现明显问题，不能单独证明 CAD 中的样条轮廓有效。

# 抽壳与后续特征

适用于主流程选择抽壳、诊断失败，或在已有壳体上接续裁剪和局部成形。接口参数与结果判定读取 [抽壳前校验与失败分析](feature-modeling.md#抽壳前校验与失败分析)，累计执行及重试遵循 [执行工作流](../../execution-workflow.md)。本页维护几何判断，不另设接口或重试额度。

## 确定检查点

连续主基体可清楚表达外形时，在主体和必要连接成立后尝试抽壳，尽早验证主要壁厚。根部过渡、辅助封口或影响连续性的成形可能需要提前建立；孔槽、装饰性圆角和独立细节按实际依赖接续。用户指定“主基体先抽壳”或“完整成形后统一抽壳”时保持该路线，不能把本例顺序设为所有薄壁件的默认顺序。

记录控制内形还是外形、偏置方向、壁厚、目标开口、保留壁面、上游合并与成功判据。控制体辅助厚度不是成品板厚；辅助材料须有明确去除或恢复方式。抽壳目标应为预期连续主体；端点接触、包围盒相交及合并返回实体均不能独立证明材料连通。

## 删除面覆盖与边界前检

按开口的几何作用分组，再在当前实际拓扑中确认全部封口面片及所属实体。一个开口可能包含平面、圆弧和其他曲面，不能仅按平面法向、面积、坐标或历史面数筛选。检查面片之间与保留壁面的邻接，防止漏掉圆角封口或误删目标壁面。

结合壁厚和偏置方向，针对实际删除面边界检查短边、小面、尖点、窄区及圆角交汇；同时按需检查保留壁面的曲率、局部间距和可能偏置相交处。记录检查位置、尺寸、邻接和未知项，不设置通用角度、最短边或半径阈值。

检查尖点时，使用同一顶点处两条边沿边界离开顶点的真实切向，确认各自方向。两条离开切向同向可能构成尖点；它与相邻面的法向夹角不同。只有端点、中点或稀疏采样时，不能将近似切向角度写成准确结果；优先读取解析曲线或完整曲线数据，缺少时标记未验证。

## 失败后的诊断顺序

1. 检查实际错误及结果有效性，确认目标实体、参数、当前面归属和开口覆盖。空特征且无内核诊断只能记为“失败，原因未明”。
2. 优先检查参与抽壳的删除面边界，将已确认边界问题与前检位置对应。若错误明确指出不相连部分，则回查上游连接，暂停只改厚度或选面的尝试。
3. 有证据时做范围明确的修正：补齐漏选封口，或切除具体边界问题。尽量一次隔离一个有依据的因素；必须同时改变多个因素时记录组合与理由。裁剪注明哪一侧、哪些面边受影响以及必须保留的根部/连接，不能无依据扩大到相邻背壁或主体。
4. 对可能写入的失败确认残留后，按[执行流程](../../execution-workflow.md)修正或重建，同步完整脚本，核查保留几何、开口和壁厚；遵循有限修正与停止条件，不默认减小厚度、改圆角半径或增加截面试错。

缺少内核诊断时，几何风险是候选原因。单因素修正后成功可支持该修正对本状态有效，但不证明唯一根因；多因素变化后成功更不能归因于其中一个因素。

人工成功可作为对照：先保存现场与当前参数/几何证据，再比较消失、保留和新增面。消失面也可能被算法重构，须通过受控复现核实；无法读取人工参数时明确说明。不要直接用旧脚本覆盖尚未记录的人工修改。

## 抽壳后接续

### 裁剪与圆角

形成壳体后，根据目标截面检查内外裁剪边、贯穿范围及切口方向。控制体先裁剪再偏置，与先偏置再用同坐标裁剪通常不能直接视为等价。涉及倾斜壁或弯曲折边时，依据内外边界和局部法向厚度推导切除轮廓；不能简单给内壁复用外壁的世界坐标或一律加减壁厚。

若圆角可在当前壳体上直接表达，使用当前有效拓扑验证目标边及半径，成功后回查处理范围和应保留的其他过渡。不因之前工具异常就强制退回控制体或固定圆角一律在抽壳前/后。

### 局部起伏与加强结构

新增薄壁成形应同时恢复外轮廓、内腔和连接；实心加料仅在目标确实为实心筋时成立。内外圆弧半径关系按控制面、凹凸方向和真实偏置推导，不统一套用加减壁厚。

| 条件 | 优先评估 |
| --- | --- |
| 截面沿直线或旋转路径不变，内外轮廓明确 | 关联截面拉伸/旋转及对应切除，或直接闭合薄壁截面 |
| 截面真实变化，已有壳体可直接改形并保持厚度 | 原生放样/扫描与关联切除，核查内外对应和影响范围 |
| 已有壳体上的直接修改存在明确几何或接口限制 | 局部控制域成形、圆角、局部抽壳，再通过已确认原生特征连接 |
| 实体特征难以恢复局部复杂连接且保留边界已稳定 | 调用局部曲面重构专项，不扩展为全件曲面替代 |

选择局部控制域前，记录直接修改方案的限制或无法可靠保持的几何关系。边界放在可恢复的平板或规则壁面区，避开其他起伏、孔槽和关键连接；辅助域须覆盖完整成形及偏置范围。限定替换区域、真实合并接口、实体生命周期及辅助材料恢复，检查接缝处没有多层壁、错台或未消除的重叠。不要默认每个局部都单独抽壳。

局部闭合、单实体及合并执行成功只能证明对应结果，不替代接缝厚度与曲面连续性检查。验证不足时保持未验证状态，不宣称完整等厚或参数任意变化稳定。

### 撕裂和端部曲面连接

先稳定主体及内外边界，再调用曲面专项。桥接约束的源边应符合目标接入方向；区分沿折边延续方向的边与横向截面弧，不能凭最近边选择切向。内壁、外壁和厚度边口分别检查；曲线端部切向成立不等于全部补面G1或全域等厚。

## 恢复与交付

验证修改时保存原状态，使用少量有代表性的主参数检查实际变化，并恢复用户要求的参数。几何字段与接口元数据分别处理，忽略不稳定字段须有理由和记录，不能借此忽略实际几何差异。

交付标明当前结果、已核查的轮廓/厚度/边界、修改入口、失败或未验证项。面数一致、包围盒接近和有限边界采样不能证明整体STEP等价；原始参考渲染不能充当当前CAD视觉证据。

# 删除实体面：`Solid.deleteFaces`

用于删除选中的实体面，或删除面后修补。同一实体多面删除、`isFix:0`已有有效调用；删除并修补模式的验证边界见下文。该命令属于实体建模，不与曲面模块的删除命令混用。

## 接口与参数

```javascript
Solid.deleteFaces('删除实体面_001', {
    deleteFaceIds: [faceId],
    isFix: 0
});
```

| 参数 | 说明 |
| --- | --- |
| 第一个参数 `featureName` | 特征名称，接口默认名称为 `deleteFaces`；生成脚本时使用唯一、非空、可读的中文名称 |
| `deleteFaceIds` | 待删除面的 ID 集合，使用当前有效拓扑中的真实面 ID |
| `isFix` | 删除方式：`0` 为删除，`1` 为删除并修补 |

## 使用规则与验证边界

- 在操作图中记录目标实体、目标面的空间语义及 `isFix` 方式；目标面的关键位置或删除方式存在多种合理解释时先明确意图。
- 在调用前按项目执行工作流获取同一文档、同一版本的当前拓扑，并按需追加元素详情查询确认目标面。示例中的 `faceId` 是已取得的真实面 ID，不是可直接执行的占位值。
- 请求中只使用已提供的 `deleteFaceIds` 和 `isFix`，不自行添加目标实体、保留实体或其他未确认字段。
- 几何执行维护完整源码，正常新增默认追加，例外按[执行流程](../../execution-workflow.md)处理；任何成功几何执行都会使缓存拓扑失效，后续按面、边操作必须重新获取。
- 同一实体的多面删除和`isFix:0`已有有效调用；后续引用用`result['entityId']`，不自动当作体积实体ID，不保证任意多面组合均可删除。
- 删除后原实体可能变为开放壳体，需从`/solids`、`/shells`核对实际对象类别及缺口。`isFix:1`修补效果和跨实体输入仍未验证，不能由删除模式的成功推定。
- 不推定省略 `isFix` 时的默认行为，不推定参数支持 `Variable`，不通过随机选面或改变删除方式来重试。

# 局部实体—曲面重构

## 定位与介入条件

这是实体—曲面混合建模中的局部重构方法，不限定零件类型、曲线参数、补面数量或缝合精度。保留已正确的主体，用边界约束复杂连接区域，最终恢复符合目标的实体。

优先采用能够清楚表达设计意图的实体特征及其组合。只有这些方案存在具体几何或已确认接口限制，或会破坏必须保留的几何，而曲面重构能更直接控制局部边界和过渡时，才介入。记录限制依据；形状复杂、单次失败或代理暂时没找到方案都不是充分理由。补面范围不断扩大、补丁不断增加时，先复查主体构造。

本方法属于 CrownScript 执行器的曲面建模参考。沿用调用方确定的主体、文档上下文、局部目标、保留项及检查要求，不扩大修改范围。命令、引用及执行规则沿用执行器。

## 1. 明确局部要求与替换范围

明确保留区域、允许替换的面、现有开口，以及连接位置、轮廓、连续性和厚度要求。选择最小必要范围；扩大范围应有边界、连续性或接口方面的理由。

区分相接、相切和曲率连续，不默认全部要求 G1/G2。局部是否等厚按设计意图确认；不得将主体名义厚度自动强加给冲压交汇过渡，也不得因名为冲压或加强区域就自动免除等厚要求。用户允许某个区域非等厚，只适用于该明确范围；几何构建不证明强度提高或可制造性。

从参考与当前模型识别应保留的连接和尺寸，不从已选命令反推验收。最终需要实体时，以符合要求的闭合实体为目标，不将开放壳体作为完成结果。

撕扯开口、切口和端部边口单独列为局部目标，分别确认外侧、内侧轮廓、贯穿范围及连接端部；需要保留厚度边口时一并构造，不固定补面数量。坐标接近、主平面或圆柱参数吻合，不证明开口已经形成或原封口已经移除。

## 2. 复用边界，只补缺失曲线

从当前有效拓扑识别保留边、内外边界及必要端部连接，检查每片拟构造曲面的完整边界关系。直接复用已有真实三维边，不为凑轮廓重复绘制或投影重建已有边。仅在边界缺失、现有边不能表达目标时创建补充曲线。

`Curve` 是独立模块，与草图会话没有必要关联；不为桥接曲线建立草图容器或调用草图编辑会话。源边或源曲线引用不意味着新曲线属于 `Sketch`。桥接命令由源引用、定位、方向及约束确定曲线，不假定接口需要切向向量输入；签名统一见 [曲线建模](../curve-modeling/curve-modeling.md)。

没有创建前定位/切向求值接口时，采用“确定目标 → 创建候选 → 查询实际结果 → 有依据地重新创建”。记录预期连接点、方向和允许的过渡范围；确认已有边是否足以提供这些依据，不要求用户先手动画成功样本。

创建后取得真实曲线 ID，读取端点及可用曲线数据：

- 端点不符：分析源引用、定位值、目标点和反向选择，复查连接位置。
- 端点正确而方向不符：调整对应方向设置，之后再次核对端点；不假设定位与方向编辑完全独立。
- 端点与方向正确而形状不符：再分析权重、允许区域及整体走向，不把任何鼓起都视为错误。

优先一次修正一个可解释因素。端部切向只能由实际可解释的曲线表示计算：三次 Bézier 可用首末控制段求方向；其他样条须考虑阶次、节点、权重和有效参数域，不能套用该公式。有限采样可发现明显回折、异常鼓起或侵入保留区域，不足以证明所有自交或连续性都已排除。

不将两端 G1 约束或有效返回值代替实际检查。保留失败原因和成功阶段，替换失败候选，避免试验对象混入结果。遵守执行器的修正次数与停止条件；用户授权额外尝试时仍需每次有依据，不通过换名或换文档重置次数。

## 3. 优先填充，区分形状与接缝问题

### 常见构造用法

| 局部几何 | 常用组织方式 | 主要判断 |
| --- | --- | --- |
| 周围真实边界已组成闭环 | 填充候选曲面 | 边界对应、曲面走向及目标连接 |
| 闭环缺少连接边 | 先补缺失曲线，再构造曲面 | 端点、方向及允许过渡范围，不重复已有边 |
| 有明确截面变化的连接 | 按顺序放样，按需使用已确认的引导能力 | 截面对齐、对应关系和扭转 |
| 替换原局部面以恢复实体 | 按引用依赖组织候选、删面和缝合 | 保留区域、接缝对应、缺口闭合及辅助对象清理 |

这些是局部构造方式，不规定所有连接使用同一顺序。优先在依赖允许时验证候选再删原面；需要先开口的方案说明原因。命令形式统一读取基础技能，不在这里重新定义接口。

对周围边界控制的局部过渡，优先尝试填充。需要内外壁和端面时共同组织边界与连接，不固定补面数量，不只处理外观可见的一侧。

创建前确认边界连接、闭合及对应关系，按几何需要组织内外壁和端面，不规定固定边数、首选边或排列。出现异常时，在修正上限内依据边界关系和实际结果分析，不随机调整参数。

删面和缝合前先检查候选面的边界匹配、曲面走向及对保留区域的影响。面积和包围范围可用于快速发现明显异常；有对应参考或可靠对称关系时再进行对照，不设统一数值阈值。面积接近、边界闭合或缝合成功都不能代替形状、连续性及所需厚度的检查；缺少证据的项目明确记为未验证。

| 问题 | 后续处理 |
| --- | --- |
| 边界缺失、不闭合或对应错误 | 修正边界，不靠扩大缝合容差掩盖 |
| 补面形状异常、扭转或侵入保留区域 | 复查曲线与曲面表达，不先归因于缝合 |
| 形状符合要求但有接缝拟合偏差 | 在允许范围内处理缝合精度 |
| 填充在允许条件下仍不满足要求 | 分析具体限制，再评估放样或其他已确认曲面构造 |

放样是表达截面变化的可选方法，不是填充失败后的无条件兜底。记录截面顺序、对应关系、引导需求和可能影响；填充与放样均不天然保证等厚，不能由单次厚度偏差判断某种方法普遍更差。

## 4. 删除原面、缝合与容差选择

在源引用和接口依赖允许时，先构造并验证候选补面，再删除原局部面；不要把此顺序强加给必须先开口才能构造的方案。删除前重新确认当前面与删除方式，删除后确认剩余对象与缺口；不得混用删除实体面与删除曲面命令。

缝合精度综合考虑整体尺度、局部最小特征、应保留间隙、接缝偏差和尺寸要求。先确定可接受范围，再依据查询结果选择或调整。0.01、0.1 mm 或更大值均不是统一默认，也不能仅因零件大就采用大容差；容差不得误合并真实开口或吞掉必要特征。

不能缝合为实体时，区分自由边、边界不对应、几何异常、容差不合适及参数模式不符，不直接放弃填充或无限扩大精度。记录实际参数和结果类别；接口接受 `tolerance` 不证明该值有效控制了接缝误差。

## 5. 验收、清理与回退

检查目标实体数量与实际对象类别、原缺口闭合、自由边和非流形边、独立补面残留、目标轮廓与保留特征；应保留的孔槽与开口不得因重构或宽松容差被填掉。曲线作为可编辑特征可保留，但失败候选或多余补面不能被当成最终结果。

缝合后基于当前对象回查面—边邻接、自由边及各条目标内外边口。要求恢复实体时，同时确认体积实体类别和必要闭合条件；设计开口应保留相应轮廓及壁厚边口，不能用缝合失败留下的自由边代替。检查独立候选曲面是否仍残留，构造曲线与最终实体分别记录。

按明确要求检查局部连续性和厚度，不把闭合或曲线相切当成曲面相切、等厚、无自交或工程性能证据。不能取得的必要证据记为未验证；实际不符记为失败，不能用“未验证”掩盖。

失败时在权限与已保存依赖允许的范围内恢复最后成功状态；涉及用户手动修改时，不用不代表现状的旧脚本覆盖。需要重建、扩大替换范围或补充关键依据时按当前授权处理，不将人工调整列为正常运行的前置条件。

交付修改范围、实际方法与容差、最终对象、已验证项及材料限制。仅当任务必需条件满足时判定完成；用户明确免除局部要求后记录范围和依据，不据此免除其他区域要求。

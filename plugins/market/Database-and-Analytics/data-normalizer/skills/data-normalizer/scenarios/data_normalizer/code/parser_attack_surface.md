# 解析"他人数据"输入攻击面清单（写码前必读）

> 适用：一切解析**非本包自产、来自外部/第三方**输入的模块（Excel/CSV/PDF/DOCX 读取、
> 报文解析、上位应答等）。**原则：把外部输入默认当攻击面，先列出"会破坏列/行/字段
> 对齐的输入"，再决定读取器与防御，post-先防御再实现。**
>
> 这是全仓共用的源（source of truth）。`tools/new_scenario.py` 生成场景包时会把它
> 拷进 `code/parser_attack_surface.md`；每个用到解析逻辑的包应把"已在表单独立核对的
> 类别"勾掉、把新增的真实类别补上，并写明每类如何被防御/回退（有测试则标测试名）。

## A. 分隔符 / 对齐破坏（最易踩，通常致命）

| 输入 | 危害 | 防御 / 读数器要求 |
|---|---|---|
| 格/字段值内含**分隔符**（千分位逗号 `50,000.00`、制表符、分号） | 按分隔符拆列时**列整体错位** | 按单元格/边界结构化读（如 `read_excel_rows`），不得按分隔符拼行再拆 |
| 格值内含**换行 / CRLF / 制表符** | 同一字段被拆成多"行" | 单元格读回原值，分离符按单元格而非文本内字符 |
| 值内再次出现**键值分隔符**（如键值文本里值含 `=`） | 键值切错 | 切键按"首个 `键=` 前缀"，值内部再出现 `=` 不重切 |
| 把 CSV 但值未加引号就当逗号文件 | 引号值含逗号会错列 | 用可引号转义的 CSV 读取，或跳过此格式 |

## B. 结构破坏

| 输入 | 危害 | 防御 |
|---|---|---|
| 表头/必填键缺失、表头拼写/别名不一致 | 找不到列、静默丢数据 | 读表头先校验必含键；缺则报"非该契约输入"，不猜 |
| 列数不符（多列/少列）、**合并单元格**、跨行单元格 | 行列索引错位、空值错位 | 按列名映射而非位置硬编码；合并单元格按读取器返回的边界处理 |
| **空行 / 空首行** | 误当数据行 | 跳过全空行；首行空则视为无表头、拒绝 |
| 列顺序变化 / 重复列头 | 索引错位 | 列名映射 + 重复列名去重/拒绝 |
| 多 sheet / 错 sheet | 读到错表 | 按固定 sheet 名定位，缺 sheet 判非模板 |

## C. 值类型 / 写法破坏

| 输入 | 危害 | 防御 |
|---|---|---|
| **千分位**（`1,000`）、尾零（`500.00`）、前导零（料号 `001`） | 数值比较错、标识符丢失 | 数值去千分位/尾零；标识符字段**保前导零**、不得当数值 |
| **科学计数**（`1E3`）、浮点/整数混排 | 数值漂移 | 统一数值规范；超限/异常记 UNKNOWN 转人工 |
| **全半角**（全角逗号/数字、中文数字"三千"）、币种符号带空格 | 解析失败或错值 | 全半角统一；无法归一的可疑值转人工 |
| 布尔二值写法（`是`/`否`、`TRUE`、大写） | 判读错 | 枚举别名归一，未知值该行转人工 |
| 尾随空格 / 大小写（`set` vs `SET`） | 键/别名不匹配 | 读取时 strip + 别名案不区分大小写；标识符除外 |

## D. 编码 / 异常

| 输入 | 危害 | 防御 |
|---|---|---|
| BOM、UTF-16、GBK、\0 字节 | 乱码 / 解析崩 | 读取时按编码容忍 BOM；异常回退并报"无法解析转人工" |
| 巨大文件 / 超长文本 / 超多行 | 性能 / OOM | 流式/限行读取；超限给出明确错误而非静默截断 |

## E. 物化陷阱（读数的"值"可能不是字面值）

| 输入 | 危害 | 防御 |
|---|---|---|
| 单元格存**公式**（`=SUM(A2:B2)`） | 拿到公式而非算出的值 | `data_only=True` 取计算值；取到公式/None 视为缺值转人工 |
| 缓存旧值 / 计算缓存过期 | 日志错 | 大文件用 `read_only=True` 且校验关键值非空 |

## 使用要求

1. 包内用到解析逻辑前，把上表在当前包上下文**逐条过一遍**，勾掉不适用项、保留适用项。
2. 每个适用项至少配**一条针对该输入的测试**（构造该"破坏性输入"断言被正确防御/回退）。
3. 新增真实供应商/第三方输入类别时，把同一项反哺回本清单（此文件随 new_scenario 分发）。

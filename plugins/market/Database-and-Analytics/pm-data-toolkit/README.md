# 超级产品经理 · 数据武器

AI 产品经理的数据分析与监控工具箱，覆盖需求决策→上线验证全数据链路。内含 4 个技能 + 1 个配置引导，基于 ODPS/MaxCompute 构建完整数据分析工作流。

> **说明：** 本插件辅助产品经理的数据分析工作，产出的分析结论应结合实际业务判断使用，不替代团队决策。

## Target Roles

- **产品经理** — 需求决策数据支撑、上线效果监控、漏斗归因诊断、埋点方案设计
- **数据分析师** — 快速生成多维度分析报告，标准化口径管理
- **运营** — 日常数据监控与异动诊断

## Quick Commands

| Command | Description |
|---------|-------------|
| `/数据决策分析` | 需求产出阶段的数据支撑分析，输出 HTML 报告 |
| `/上线效果监控` | 上线后指标监控与异动检测，输出监控报告+告警文案 |
| `/漏斗归因诊断` | 指标异动时的根因定位，按 nu/ou 分层归因 |
| `/埋点方案设计` | 新功能埋点方案设计，含事件定义和口径说明 |

## Skills

| Skill | Description |
|-------|-------------|
| 数据决策分析 | 需求产出阶段的数据支撑——多维分析（PV/UV/转化率/留存）、趋势对比、结论输出。内置 RICE 优先级框架和 ICE 评分模型，产出 Chart.js 可视化 HTML 报告 |
| 上线效果监控 | 上线后指标健康度监控——环比/同比/MA7 趋势、稳定性自动判断、异动预警。内置统计过程控制（SPC）方法论，产出监控看板 + 异动告警文案 |
| 漏斗归因诊断 | 指标异动根因定位——nu/ou 拆分、CASE WHEN 多事件分层漏斗、最大贡献区间定位。内置 MECE 归因框架和贡献度分解法，产出分层分析报告 |
| 埋点方案设计 | 新功能埋点设计——用户路径梳理、事件定义（曝光2201/点击2101）、args 参数设计（&分隔key=value）、口径说明。内置埋点质量 checklist |

## Connectors (Optional Enhancement)

| Connector | Enhanced Capability |
|-----------|-------------------|
| **ODPS (MaxCompute)** | 直接执行 SQL 查询业务数据，无需手动导出 |

> 不连接任何外部工具也可正常使用——手动提供数据即可。连接 ODPS 后可自动查询分析。

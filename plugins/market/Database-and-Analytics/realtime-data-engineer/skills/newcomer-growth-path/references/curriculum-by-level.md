# 4 周路线（按起点定制）

## L1（零基础）路线

### W1 - 基础铺垫
- **主题**：SQL 入门 + 数据仓库概念 + Linux 基础
- **资料**：《SQL 必知必会》前 8 章 + 团队数仓建模文档
- **产出**：完成 30 道 SQL 练习题
- **考核**：能独立写出 group by + join 查询

### W2 - 流处理理论 + 工具
- **主题**：流批差异、事件时间、Kafka 概念、Flink Web UI 操作
- **资料**：Flink 官网 Concepts 章节（中文）+ 阿里云 VVR 快速入门
- **产出**：跑通沙箱中的 word count Flink SQL
- **考核**：能解释什么是 watermark、为什么需要

### W3 - 项目演练
- **主题**：跟 mentor 做 1 个历史小需求（已下线）
- **产出**：完整 Flink SQL 任务 + DQC 配置
- **考核**：Code Review 通过（红线 0 项，黄线 ≤ 3 项）

### W4 - 真实需求
- **主题**：mentor 选 1 个低风险真实需求
- **产出**：上线 + 业务验收
- **考核**：上线后 1 周无 P0/P1 告警

## 周末 1on1 问题清单（mentor 用）

每周五 mentor 与新人 1on1，依次问：
1. 这周学的最有感的概念是什么？为什么？
2. 哪个概念你觉得自己其实没真正搞懂？
3. 实际操作时遇到的最大阻碍是什么？
4. 资料够用吗？想加什么 / 减什么？
5. 下周你打算重点搞定什么？

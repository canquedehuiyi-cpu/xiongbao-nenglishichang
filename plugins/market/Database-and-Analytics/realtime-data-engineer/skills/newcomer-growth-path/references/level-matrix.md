# 新人能力定级矩阵

## 5 维度评估

依次询问新人 5 个问题，给每个维度打 1-5 分（1=完全无基础，5=精通）。

### M1：SQL 基础
- 1：完全没写过
- 2：会简单 select / where
- 3：会 group by / join / 子查询
- 4：会窗口函数 / CTE / 复杂关联
- 5：能优化执行计划，理解索引/分区

### M2：Java / Scala
- 1：从未写过
- 2：会基础语法
- 3：理解 OOP / 集合 / IO
- 4：写过多线程 / JVM 调优经验
- 5：写过分布式系统

### M3：分布式概念
- 1：完全不了解
- 2：知道集群概念
- 3：理解 partition / replication / consensus
- 4：用过 Kafka / Hadoop / Spark 等
- 5：理解一致性模型 / 水位线 / state 概念

### M4：业务理解
- 1：完全陌生
- 2：知道公司主营
- 3：理解核心业务流程
- 4：清楚业务指标体系
- 5：能从业务问题出发设计数据方案

### M5：流处理 / Flink
- 1：完全没接触
- 2：听过没用过
- 3：跑过 hello-world
- 4：写过生产任务
- 5：理解 watermark / checkpoint / state 机制

## 起点分类

| 总分 | 起点等级 | 路线建议 |
|------|---------|---------|
| 5-10 | L1（零基础）| 4 周完整路线 + mentor 高频陪跑 |
| 11-15 | L2（有离线 SQL）| W1 强化流处理理论，2-3 周可独立 |
| 11-15 | L3（有 Java/分布式但无业务）| W1 强化业务知识 |
| 16-20 | L4（综合较强）| 3-5 天对齐团队规范，直接上手 |
| 21-25 | L5（资深迁移）| 1 周熟悉团队规范，做 mentor 候选 |

## 关注信号（需 mentor 介入）

- ⚠️ M3 ≤ 2：分布式基础太弱，watermark/state 概念会卡 1-2 周
- ⚠️ M4 ≤ 2：缺业务理解，做出来的任务"对但没用"
- ⚠️ M2 ≤ 2 + 团队有 DataStream API 任务：建议先做 Flink SQL 任务
- ⚠️ M1 = 5 但 M5 = 1：可能心态轻视，要预设流批差异冲击点

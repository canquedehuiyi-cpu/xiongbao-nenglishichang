# 通知文案模板

## 业务方版（钉钉群发 / 邮件）

```
【数据变更通知】<变更主题>

亲，

我们近期会对 <业务名称> 数据做一次调整：

- 调整内容：<用业务语言描述，不用技术词>
- 调整原因：<业务原因>
- 调整时间：<具体日期 + 时间>
- 是否影响你：<是 / 否 / 看板可能短暂数据异常>

【你可能关心的报表/看板】
- <报表 1 名称> · <链接> · 影响：<具体影响>
- <报表 2 名称> · <链接> · 影响：<具体影响>

【你需要做什么】
- <动作 1>
- <动作 2>
- 如果不动会怎样：<>

【时间线】
- <日期>：通知发出
- <日期>：变更开始
- <日期>：变更完成
- <日期>：观察期截止

如果有疑问，请联系：<姓名> <钉钉/电话>

谢谢配合！
```

**示例**：
```
【数据变更通知】DAU 指标统计口径升级

亲，

我们近期会对 DAU 指标做一次调整：

- 调整内容：DAU 统计将剔除内部员工账号
- 调整原因：业务方反馈 DAU 数据偏高，含内部测试影响真实判断
- 调整时间：2026-07-01 04:00
- 是否影响你：是，DAU 数值会下降约 1.5-2%

【你可能关心的报表/看板】
- 用户增长大盘 · <link> · 影响：DAU 下降 1.5-2%
- 运营效果监控 · <link> · 影响：转化率分母更小，转化率会上升

【你需要做什么】
- 7/1 后看板数据下跳是预期行为，无需 panic
- 如已有同环比报告，需注释口径变化

【时间线】
- 2026-06-23：通知发出
- 2026-06-29：业务方 sign off 截止
- 2026-07-01 04:00：变更生效
- 2026-07-08：观察期截止

有问题联系：王 XX  钉钉/138******00

谢谢配合！
```

## 技术方版（钉钉技术群 / 邮件 / Wiki）

```
# [DATA CHANGE] <变更主题>

## 变更摘要
- 变更类型：<字段改名 / 类型变更 / 表下线 / ...>
- 影响表：<表名>
- 影响字段：<字段名>
- 生效时间：<>
- 兼容期：<有 / 无，多久>

## 变更详情

### Before
DDL / 字段定义片段

### After
DDL / 字段定义片段

### Diff
- <字段 A> renamed to <字段 B>
- <字段 C> type changed from VARCHAR to BIGINT

## 受影响任务

### L0（必须 sign off）
| 任务名 | Owner | 修改建议 | 截止 |
|-------|-------|---------|------|
| | | | |

### L1（需 owner 确认）
| 任务名 | Owner | 修改建议 |
|-------|-------|---------|
| | | |

### L2 / L3（仅通知）
| 任务名 | Owner |
|-------|-------|
| | |

## 修改建议代码
对于字段改名场景：
```sql
-- before
SELECT old_field FROM source;

-- after
SELECT new_field FROM source;  -- old_field renamed to new_field
```

## 兼容方案
- <双写期 X 天 / 视图兼容 / 无兼容>

## 回滚预案
- <如发现重大问题：1) 停 X 任务；2) 切回旧表；3) 回归数据>

## 联系
- 变更负责人：<>
- on-call：<>
```

## 通用要求

- 标题前加【】方便筛选
- 业务版严禁出现"字段类型变更" "DDL"等技术词
- 技术版每个表必须有 owner（用户）
- 时间精确到小时（不要"近期"）
- 必须有联系人（具体到人，不是"数据团队"）
- 通过 `change_notification_channel` 配置的渠道发送

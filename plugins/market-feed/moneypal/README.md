# 恰恰账本

“恰恰账本”是管理本地 Beancount 账本的个人财务管家专家。它优先使用 MoneyPal MCP；MCP 未加载时可按 Skill 规则使用本机 CLI 查询和记账，并将记账固定为“预览 → 人工确认 → 提交”。

## 安装

通过当前宿主支持的官方插件、扩展或专家安装入口安装本专家，是否需要重载或重启以宿主提示为准。安装后可让助手“带我一步步连接账本”。

## 使用前准备

专家包只声明了 `mcp-moneypal` 命令，不包含个人账本路径、账本内容或密钥。专家从当前 Agent 任务取得账本工作区，再随工具调用传入；首次查询可通过 MCP 或 CLI 完成，MCP 接入另行验收。

可让助手“带我一步步连接账本”：按 [启动检查](skills/moneypal/references/bootstrap.md) 先检查程序、运行时和账本，准备好后即可查询；需要 MCP 时再按 [连接器配置指引](skills/moneypal/references/connectors.md) 在应用界面中配置。新连接器不设置账本环境变量；已有 `MONEYPAL_LEDGER_WORKSPACE` 的旧配置继续兼容。

## 选择分发入口

专家包已包含 MoneyPal Skill，使用专家时通常无需再安装独立 Skill。独立 Skill 面向只需要技能指引的用户，不附带 MCP 声明。导入后按 Skill 准备环境，CLI 可先完成查询，MCP 单独接入和验收。

若已存在用户级与专家包内两份 Skill，日常查询不比较版本、不自动删除文件或重装。排查重复来源时通过宿主界面核实；同名 Skill 的选择优先级尚未实测，不假定哪份一定生效。

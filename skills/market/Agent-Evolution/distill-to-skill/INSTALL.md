# 怎么把「蒸馏成技能Skill」装到您的 AI 平台

> 这个技能已经做好了，装上去就能用。照着下面做，不用懂技术。各平台界面叫法可能略有不同，认准「技能广场」「技能」「上传技能」这类字眼即可。

- 本包是通用技能包，遵循通用技能包规范，**不绑定特定平台**——传到任意支持技能上传的 Agent 平台即可使用。
- 零第三方依赖、装上即跑：核心文本蒸馏只用 Python 标准库，不需要额外安装、不污染环境。
- 媒体降维（音视频转写、图片识别）复用运行环境已有的工具；环境里没有时会改用您提供的文字稿，不编造。

---

## 一、先确认您要装到哪

| 您的情况 | 用哪种方式 | 看哪一节 |
|---|---|---|
| 平台里有「技能 / 技能中心 / 技能广场」入口 | 在平台内**上传**（最常用） | **方式 A** |
| 会把文件放进目录（熟悉电脑文件位置的用户） | 放进 `skills/` 目录 | **方式 B** |

> 不确定用哪种？先试**方式 A**；不行再看**方式 B**。

---

## 二、方式 A：在平台里上传（推荐）

**第 1 步 · 找到「技能」入口**

- ① 打开您用的平台，找「技能」「技能中心」「技能广场」「我的技能」这类入口（位置各平台不同，认字眼就行）
- ② 找不到就在平台内搜「技能」，或看平台的帮助中心

**第 2 步 · 上传本包的压缩文件**

- ① 在技能页找「上传技能」「添加技能」「导入技能」按钮
- ② 选中本包的安装压缩文件**原文件**（不要先解压）
- ③ 按界面提示完成

**第 3 步 · 让它生效**

- 完全退出平台再重开，或刷新页面 / 新建一个对话

**第 4 步 · 验证装上没（重要，不要跳过这一步）**

- 新建一个对话，直接说一句：

> 把这份材料蒸馏成技能

- 如果它回您一段「把材料蒸馏成技能包或精华文档」的开场介绍、并问您要材料，就说明装好了、能用了。

---

## 三、方式 B：放进 skills 目录（进阶）

适合熟悉电脑文件位置的用户：

1. 解压本包的压缩文件，文件**直接释放在当前目录**（包内为扁平结构，`SKILL.md` 位于根，无顶层文件夹）
2. 新建一个名为 `distill-to-skill` 的文件夹（**名字必须与 `SKILL.md` 的 `name` 一致**），把上一步解压出来的文件**整个放进去**；再把这个文件夹放进该平台的 `skills` 目录
3. 完全重启平台
4. 用「方式 A · 第 4 步」的方法验证

> 目录不存在就自己新建一个 `skills` 文件夹。

## 四、怎么用这个技能

**唤起它**——说下面任一句就会触发：

蒸馏成技能 / 拆书成skill / 视频转skill / 蒸馏成PPT / 蒸馏成文档 / 做成技能包

**怎么用**——把要蒸馏的材料交给它（书 / 视频 / 语音 / 课程 / 播客 / 会议纪要 / 网页 / 表格 / 口述经验……），它陪您把这件事蒸馏成能装进 AI、反复调用的技能，或一份精华文档。

**三种产出模式**（回一个字母即可）：

- **A｜封装成技能包**——把方法固化成技能，以后一句话跑出同样结果。
- **B｜完整精华萃取**——长资料浓缩成要点、框架、清单，忠于原文不丢核心。
- **C｜定向萃取**——只按您指定的方向抽，别的不掺。

**装好后先验一验**——拿一份自己最熟的材料试一遍：

1. 三种模式（A / B / C）理得清吗？
2. 出来的东西，是您想拿走的那个吗？
3. 换一份别的材料，还稳吗？

跑完这三题，您就知道它是不是真能用了。

## 五、常见问题

**Q：传进去了没反应？**

A：① 确认传的是压缩文件**原文件**，不是解压后散落的文件夹；② 完全重启平台；③ 确认唤起时说的话对得上「唤起它」那一行。

**Q：这个技能能干什么？**

A：见包内 `README.md` 与 `LISTING.md`。

**Q：要花钱吗？**

A：本技能免费提供，不收取任何费用；包内无收款环节、不连外部服务。您所在平台自身产生的平台费用（积分 / 会员等），按该平台规则执行，与本技能无关。

**Q：材料读不出来怎么办？**

A：音视频、图片类会自动转写或识别，**依赖运行环境是否已装相应工具**；没装时会改用您提供的文字稿，不编造。

**Q：能把做出来的东西装到别处吗？**

A：**蒸出来的技能包**可装到结构兼容的常用 Agent 平台；装法大同小异——打开平台 → 找「技能」类入口 → 上传压缩文件 → 说一句唤起词验证。

- ① **服务范围**：把各类材料蒸馏成技能包或精华文档。

- ③ **内容边界**：不把材料另存或转给第三方；不编造材料里没有的专业事实。
- ④ **责任边界**：材料须来源合法、具备对应知识产权。
- ⑤ **强监管题材**（投资 / 医疗 / 法律等）只萃方法、不输出结论与建议；产出供您自己判断。

# build-gate（自主件移出的细则册）

> **本册由主件 `SKILL.md` 按需加载。** 主件保留操作核心与一行指针；本册是细则全集，执行到对应环节时读取，不需要时不必预读（省时间与成本）。内容与主件同源。

### A5 横切模块（跨适配层生效）

- **质量飞轮**：出包后按 P0（核心可用）/P1（待补）/P2（锦上添花）分级（定义见 B1）；同类材料连续触发复用并迭代上次标准件。
- **交付净化（L1–L4 四层质检，出包前强制，定义见 B1）**：L1 硬规则扫描（去标识/去侵权/去受保护内容）；L2 风格自检（像来源/自洽）；L3 内容自检（可执行/无矛盾）；L4 活人感自检（像人写不像机器流水）。四层全过才出包。本处是内部生产标准，不向用户交付任何质检报告——干净产物本身即是质量证明。
- **合规边界**：题材无禁区，产出不输出决策。投资/医疗/法律等强监管题材只蒸方法学与表达，不内嵌买卖/诊疗/法律意见，由用户自行判断担责。规避他人权利标识、规避平台限制类需求不吸收不进本技能。
- **多链路协同**：路由层让子部分分别走不同适配层再归并一件标准件；协同靠共用内核与标准件规格。
- **批量编排**：默认单件优先；一次投多份材料时，源级防爆炸护栏（A0.3+）已固化——全暂存、逐个处理、单源失败隔离、多源超大先规划；逐件确认后各走适配层，单件失败不影响整体。多源产出形态由用户定（整批一份 / 逐源各一份）。
- **进化机制**：标准件支持用户追加样本（append）/修正错误（correction）/回退旧版（rollback），由 `scripts/evolve.py` 落地——每次改动前自动对标准件整树打快照、写 `evolve_log.json`，回退即从快照恢复（恢复前再给当前状态留一份安全快照）；**进化仅在用户授权（`--approve`）下发生，无授权一律拒绝，不静默改写**。

### A6 出包验收门禁（硬检查，逐条过，不过不出包）

出包前逐项核验，任一项不达标即回退修补，不交付。**一键口径**：`python scripts/selfcheck.py <包根> --full`（三态表·无 FAIL 才算过）为总入口，自举出包时由 `scripts/assemble_skill.py` 自动调用；下列各条为其展开。

1. 标准版统一：自研与交付同一标准，不设两套。
2. 跨平台·订阅可用：产出包可安装、可加载、可运行于支持技能上传的 Agent 平台；用户在任意硬件（苹果手机 / 安卓手机 / 苹果电脑 / Linux / Windows）上的 Agent 里订阅本包，装后即用——实际执行由平台宿主环境（多为云端 / 服务器，OS 异构）完成，用户端设备只负责交互与查看产物，不要求用户本地有 Python 或特定 OS；交付须含可安装 zip（无顶层目录、UTF-8、mtime 统一，见 A7 安装包交付），用户无需自行打包。
3. 工程级齐全：版本号、文件清单、权限清单、本地日志、测试样例齐备；签名可选，平台支持则启用，否则用校验和。
4. 小闭环：触发到结束无断点，不依赖人逐步喂步骤。
5. 层结构正确：能力层与辅助层齐全，构思层零出现。
6. 自包含·零第三方依赖：核心蒸馏只用 Python 标准库，无需额外安装、不污染环境，装上即用；本包运行于 Agent 平台，平台需联网通电才能工作——联网是产出标准件的前提。
7. 产出不锁用户：用户获取的是产出，标准件无授权即能运行、能拿去用。
8. 核心最小暴露：能力层只写最小必要执行指令，不写设计原理。
9. 构思层零出现：包内无设计动机、背景、规划、取舍理由。
10. 输出可追溯：产出带**可见**溯源落款（由 `scripts/stamp_signature.py` 实现，落点见 A6#19；`--verify` 可校验、`--self-test` 六用例回归）；**不嵌任何不可见水印或指纹**——对用户不透明的东西一律不植；调用日志本地留存依赖宿主平台日志能力，待平台支持后启用。
11. 异常告警（本条为 A8 运维备注，非对话内可执行门禁·出包核验不计入）：异常调用类型识别与告警依赖宿主平台日志/告警能力，包内无独立告警通道，由平台宿主负责。
12. 法律条款：`LICENSE.txt` 随包，覆盖反向工程禁止与批量提取禁止，仅护本工具自身，不限制用户产出。
13. 回归测试（对话内可执行 · 出包前实跑）：
    - 出包前实跑 `scripts/selfcheck.py` 九扫描（红线词 / 单字红线 / 构思层 / 术语一致 / 换行符 / 不可见字符 / 版本号 / 人群限定词 / 禁推销措辞）全 PASS 才出包，即本门禁的回归自检项。
    - 样例 / 反例由 `selfcheck.py` 与四段式自证段覆盖。
    - 泄露演练依赖宿主平台安全能力，归 A8 运维备注。
14. 专有标识零痕迹：无项目代号、客户代号、专有标识备注。
15. 来源零残留：无项目名、客户名、编号、批注、引用、来源、路径、作者、时间戳。
16. 脱敏扫描通过：发布前扫描确认零专有标识痕迹。
17. 保真达标：TRACE 五维（原意/结构/语气/知识/边界，定义见 B1）达标。
18. 三测通过：已知样本、边缘样本、声音一致性三测回测产出符合预期，且零标识、可独立运行。
19. 溯源盖戳：出包后由 `scripts/stamp_signature.py` 在 README 写入统一落款「由 蒸馏成技能Skill 蒸馏产出」。**落款是可见的一行，不嵌任何不可见字符**——对用户不透明的东西一律不植（**只落 README、不写进 SKILL.md frontmatter、绝不写入 tech_source / build_no**，不污染 A7 schema 锁定；用户产出不锁）；`--verify` 会反向校验成品不含不可见字符。

→ 产物契约联测（癸组：落款/免责/**交付回执**全覆盖 + xlsx 两版契约）→ 7 版本 PPT 冒烟 → golden 内容基线 → 真实产物一致性（需 `--outline`/`--artifacts`）」，输出 PASS/FAIL/SKIP 三态表，**无 FAIL 才 exit 0**；SKIP 表示环境或入参不具备（逐条标原因），不计失败但必须在表内可见。①**版本号残留**：本包版号族只准出现在版本声明字段行（`SKILL.md` frontmatter + `_meta.json`），别处不出现；门禁自带一致性断言——版号升出本族而未同步前缀即 FAIL。②**换行符纪律**：包内文本文件一律 LF，出现 CRLF 即 FAIL；落盘侧一律显式 `newline="\n"`（`verify_baseline` 的 bless、`assemble_skill` 的发布清单与指纹）。③**自带回归实跑**：自动遍历 `scripts/` 中所有带 `--self-test` 的脚本实跑、断言 exit=0。④**自测后残留复查**：自测跑完立刻比对包内文件快照（`size`+`mtime_ns`，排除 `__pycache__`、`release` 等元数据目录），净新增/改动/减少一律 FAIL；落在包外（调用方当前目录）的新文件只报 WARN。⑤**脚本清单对账**：每个 `scripts/*.py` 须「带 `--self-test`」或「在 `tests/exempt.json` 登记豁免」，两者皆无即 FAIL；豁免须填 `since`+`reason`，且二选一——`expires_in=<版本>` 或 `permanent=true`，两者皆无即 FAIL；豁免项在 `--full` 表内以 WARN 可见。⑥**golden 内容基线** = `python scripts/verify_baseline.py --baseline`：对固定大纲的 6 个格式产物比对解析后语义指纹（模块标题序列 + 模块内容探针命中集·强 / 文本字符数·中 ±5% / 字节区间·弱 ±10% 且仅同平台）；基线更新须 `python scripts/verify_baseline.py --bless --reason "…"`，每次 bless 写入 bless_log。**覆盖边界**：靶区＝内容本体（模块标题序列 / 内容探针命中集 / 字符数 / 字节区间）；页眉、页脚、落款（含盖戳语）、页码编号等版式性文本不在范围内；要纳入拦截，把其文本加进 `PROBES` 即可，比对逻辑不用动。真·内容漂移判 FAIL 并阻断出包；「平台不同」等环境差异只报 WARN。⑦**门禁自证** = `python scripts/selfcheck.py <包根> --prove-gates`：在临时副本上逐条改坏、断言门禁报警（只动副本，不动源包）。⑧**出包动作接入门禁（保护对象＝用户最终拿走的那件东西）**：`scripts/assemble_skill.py` 装配前强制过门禁，不通过直接拒绝出包（`--gate=auto|strict|off`，默认 auto 探测）。**分两档、但都必跑**：①**自举包**（本包，目录内含 `selfcheck.py`+`verify_render_combos.py`）→ 跑全量门禁 `selfcheck --full`；②**其余任何包**（含用户自己装配的产物包）→ 跑**产物出厂门禁** `selfcheck <目录> --product`（红线词 / 单字红线 / 构思层残留 / **内部标记残留** / 换行符；换行符项非阻断），不过即拒绝出包。**门禁绝不因「这不是我们自己的包」而跳过**——用户拿走的那份才是最该被保护的；确需跳过须显式 `--gate=off`。**环境降级条款**：产物门禁依赖本机 Python —— 具备时直接跑（经实测 WorkBuddy 自带托管 Python 可跑）；**不具备时不许静默跳过**，必须改走「清单式人工核对」（逐条对红线 / 单字 / 构思层 / 内部标记），并在交付说明里如实标注「本机无法自动校验，已按清单人工核对」——**结果必须可见，SKIP 不等于通过**。⑨**人群限定词**：本包「不设人群限定」铁律的机器判据 —— 口径只收「具体考试 / 备考词」与「具体人群身份词」，**行业名 / 职能名 / 职级名刻意不收**（包内示例报表等 demo 数据与职能词重名，收了必误伤）；白名单＝写明「不设人群限定」的声明行（规则条文本身）；**词表条数低于下限即 FAIL**（词表须保持完整）。⑩**输出命名公式门禁（癸-12）**：规范层三要件（命名公式条文 / 后缀枚举 ≥5 项 / 禁用命名声明）须在位；给 `--artifacts` 时逐份比对真实产物名 —— 后缀须属枚举表、名干非空、连接符半角 `_`。判据只从被检对象读取，不从检查器自身读取。

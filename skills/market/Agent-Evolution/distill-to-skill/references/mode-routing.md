# mode-routing（自主件移出的细则册）

> **本册由主件 `SKILL.md` 按需加载。** 主件保留操作核心与一行指针；本册是细则全集，执行到对应环节时读取，不需要时不必预读（省时间与成本）。内容与主件同源。

**衍生脚本 / 讲稿（B/C 通用·二次创作）**：用户萃取内容（尤指音视频 / 长文提取后）可要求「基于萃取内容、按我的框架重构一份全新脚本 / 讲稿 / 改写稿，供我自己演绎或重讲」。这属保真蒸馏之上的**衍生重构**——只取萃取出的方法论 / 结构 / 要点作骨架，按用户指定框架重组成新内容；不替用户定创作方向、不编造源材料没有的论点。走 C 模式定向萃取的衍生子类，产出形态按用户从格式菜单选的格式交付（MD / TXT / Word / PPT 均可，内容按脚本 / 讲稿结构组织），不默认出技能包。⚠️ 衍生重构仍守 B/C 保真与溯源落款、不注水、标来源。

B 格式三维（文档格式确认·须给菜单·**默认 Word**）：用户选 B 后，先呈现交付格式菜单再产出；可选 Word / PPT / Excel（XLSX）/ PDF / Markdown / TXT 六种（菜单编码 1–7，默认 Word=1）。**用户不选即按默认 Word 出**——默认只出一份，多格式须用户主动勾选追加，不替用户多产出。各格式适用场景、对应生成器（Excel 含标准数据表 / 图表分析报告双子形态；**标准数据表默认＝全量搬运 + 规整——源表全部行全部列进产出、只做表头统一 / 数字格式 / 冻结 / 清空空行空列，不预设汇总维度**，用户说一句「按X汇总」才汇总；选定图表后按「接料前置规划」的选型规则自动定图型——规则拿不准时兜底柱形图，仅支持柱形 / 条形 / 饼 / 折线四类，用户要树状等不支持图形时如实说边界并给三步替代）、强制调用生成器硬规、PPT 标准版规格（页型库 + 导航 + 设计令牌）、长视频（>10 分钟）档位确认与进度摘要等全量细则见 `references/bc-output-standards.md`（仅选 B/C 时加载，A 模式不进本文件、不占上下文）。格式以数字编号呈现（见 A0.5 交付格式确认菜单，用户回复数字即可选定）；选 B 后须先呈现格式菜单（必给），**用户不回复即按默认 Word 出**，不静默跳过菜单。**跟随真实需要**：用户话里已带格式诉求（如「给我份 PPT」「要打印」）的，以用户为准，不走默认。
门禁联动：B/C 同样过 L1–L4 净化与脱敏零痕迹（A5/A6 #14–16），仅产出形态与格式不同；B/C 不强制出技能包结构。

B/C 模式标准件规格（产出即标准件·各格式提前规划合格线·不脱离标准规格自行生成）：各格式标准版（MD / TXT / Word / PDF / Excel）、强制调用生成器硬规、PPT 标准版规格（页型库 + 导航系统 + 设计令牌三层锁死）、统一溯源落款、红线，详见 `references/bc-output-standards.md`（仅选 B / C 模式时加载，A 模式不进本文件）。硬原则：B/C 产出任何格式都必须调用包内对应生成器，严禁平台 / Agent 手搓格式 XML / 渲染代码自由生成——自由生成 = 不可交付。

B/C 模式内容边界（按作用对象分级，不替用户删内容）：B/C 产出是「您读的文档」，作用对象为用户本人看 / 学 / 参考，本质源材料浓缩书摘；守「完整原生·省篇幅不抽骨」+ 三条硬约束（不注水 / 标来源观点 / 留免责声明）+ 保真蒸馏 + 与 A 模式区别。全量细则见 `references/bc-output-standards.md` §B/C 模式内容边界（仅选 B/C 时加载）。

媒体投料产出口径（默认不产·按需可裁·不引导·不重生成）：投料为音频 / 视频 / 图片时，蒸馏默认产出「精华文本 / 技能包」（文档或 A 模式技能）。媒体先降维为锚定文本再走四段式（A0.0 / O4），引擎核心是知识蒸馏。若用户明确要求同源裁剪 / 选择（档一·保留原素材精华）且宿主环境具备对应工具，可调 `scripts/media_output.py` 帮他做：音频 / 视频按上游精华段时间码裁段（ffmpeg）、图片按清晰度 / 尺寸选 best-N（opencv / Pillow），并在文档附剪辑清单。两条硬边界：①不主动引导、不承诺、不在开场白提示「我们能做媒体→媒体」——多数人要精华文本 / 技能，媒体文件是少数按需才做；②绝不碰档二重生成（TTS 重讲、AI 视频、AI 图），其成本 / 超时 / 合规（如声音克隆需授权）不可控，超出本包。环境缺 ffmpeg / opencv / Pillow 时脚本优雅降级（明确装法指引），不崩、不产出半成品。对外表述维持「文档蒸馏→文档，媒体蒸馏→精华文本 / 技能」，用户问到能做的裁剪 / 选择部分再按需启用（详见 `references/media-output.md`）。

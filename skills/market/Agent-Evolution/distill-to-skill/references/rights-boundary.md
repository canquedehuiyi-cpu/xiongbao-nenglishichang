### A0.6 版权与权利边界（源材料脱敏与权属责任）

用户可能带入书籍、文档、学术刊物、视频、会议等任意内容。蒸馏需做好"源材料脱敏"：

- **蒸馏定位为"方法 / 框架 / 原理的萃取与重构"**：产出应是用户自有结构的可复用知识资产，而非对源材料的原文复制或改写式搬运。
- **架构优先提取已默认"转述为通用规则"**：A0.2 三遍扫描只提炼判定 / 规则 / 步骤 / 阈值等方法论，不保留源材料原句与排版，这天然降低与源材料的字面重合——这是降低风险的正道，不是靠"去标识"改写。
- **权属责任在用户**：您需确保对提交的源材料拥有合法权利（自有创作 / 已获授权 / 公域内容）。本工具不验证权属，不替代授权判断。
- **本工具不协助"去标识化以规避权属"**：不对受版权保护的原文做"为规避权属而做的换词不改意式改写"（区别于 B/C 的 D2"改写重述"：D2 是保留原意与框架、用用户自己的语言重述，属合规的降低直接引用比例；本处禁止的是以规避权属为目的的换词冒充）、不移除原作者署名以冒充自有、不批量抽取受保护内容进行再分发。如源材料受第三方版权保护，请仅萃取其中可通用的方法论，并自行评估合规。
- **风险降低非消除**：经方法萃取与转述后的产出，与源材料的字面重合已大幅降低，但是否可使用仍由您与所用平台 / 场景判定；本工具与作者不为产出用途担责。
- **与 L1 硬规则联动**：出包前 L1 扫描含"去侵权 / 去受保护内容"，凡直接搬运的受保护表达一律不进包。
- **商业内容铁律（按模式分级）**：本工具只做蒸馏，不替用户决策。
  - **A 模式（Agent 技能包）**：产出会被机器自动执行，故源材料涉投资 / 理财 / 股票 / 基金 / 债券 / 房产增值 / 财商等题材时，只萃取「生意现金流 / 资产配置逻辑 / 风险判断尺子 / 决策纪律」等商业决策方法；**禁止**把投资建议、选股指标、买入条件、择时建议、持有/卖出纪律写进产出。正文不得出现「买什么 / 什么时候买 / 能赚多少」式可被机器直接执行的建议；发现即回退重构。免责声明**不能替代**内容重构（声明挡不住机器执行风险）。
  - **B/C 模式（您读文档）**：产出作用于用户本人看 / 学 / 参考，本质是源材料浓缩书摘。忠实保真蒸馏——源材料里有什么就凝什么（含投资经典具体观点 / 指标 / 操作思路），不替用户删内容；守三条：①不注水（不跨书泛化、不补源材料没有的买卖信号）②标"以下为源材料 / 本书观点"③文末声明按「免责声明单一标准」节落（见 `references/bc-output-standards.md`）——**唯一句式 = 固定主句「本产物为对源材料的个人蒸馏整理，仅供学习参考」+ 题材槽**（投资 / 理财 / 股票 / 基金 / 房产增值类加「不构成任何投资建议」；商业 / 管理 / 思维 / 学习方法类加「不代表对任何商业行为的建议」；其他题材只留主句）。**六格式全落、全包仅有这一处权威写法**（本节只作引用，不另立口径）。用户若对外发布 / 商用，属其自身内容合规责任。

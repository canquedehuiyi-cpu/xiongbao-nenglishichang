# 选择组件调用规范（弹窗优先 · 文本兜底）— 操作手册

> 本稿为 Agent **实际弹出选项卡**的「操作手册」，由 SKILL.md A0.5 指针引用。
> 铁律：凡需用户在有限选项里挑，**先弹窗**；弹窗不可用才回落文本编码菜单。弹窗永远是优先级，文本只是兜底。

---

## 一、调用选择组件（优先级最高 · 必须做）

当当前 Agent 宿主提供交互式选择组件（卡片 / 弹窗 / 选项卡）时，**必须调用它**呈现选项，让用户点一下即定——**严禁把『发一段文字菜单让用户手打』当主路径**。

### WorkBuddy / 兼容 OpenAPI 的 Agent 平台 · 调用形态（可直接照抄）

调用交互式选择组件（本环境为 `ask_user_question`），传参结构如下：

```json
{
  "question": "请选一种产出模式",
  "header": "产出模式",
  "multiSelect": false,
  "options": [
    { "label": "A 封装成技能包", "description": "把方法固化成技能，以后一句话跑出同样结果" },
    { "label": "B 完整精华萃取", "description": "长资料浓缩成要点框架清单，忠于原文" },
    { "label": "C 定向萃取",     "description": "只按您指定方向抽，别的一律不掺" }
  ]
}
```

调用硬规（照抄即合规）：
- **选项 `label` 直接写「编码 + 中文名」**（如 `A 封装成技能包`）—— 用户点卡片即返回编码 `A`/`B`/`C`，后台统一转大写路由。
- **需要「其他 / 自定义」出口**：加一项 `{ "label": "其他补充", "description": "直接写关键词 / 问题 / 提示词" }`，不把预设不适用的人堵死。
- **单题选项 > 4 时强制分页**：先弹第 1 页（≤4 项），用户点「更多 / 下一页」再弹第 2 页；编码全局连续、顺序不变，不删项、不重排（**「不重排」指同一次呈现 / 同一会话内**——跨版本要重排时，五处必须同版同步，见 SKILL.md A0.5 交付回执编号条）。
- **多选**（如交付格式 1–7）：`multiSelect: true`，用户可勾多项，回执为逗号分隔编码（如 `2,5`）。

### 其他平台 · 通用映射（字段名不同按同结构套）

| 本规范 | 通用字段 | 说明 |
|---|---|---|
| `question` | title / question | 这一步在选什么（一句话） |
| `header` | 卡片标题（≤12 字） | 给用户看的归类名 |
| `options[].label` | text / label | 「编码 + 中文名」 |
| `options[].description` | desc / description | 选项一眼懂的说明 |
| `multiSelect` | multiple / multi_select | 可多选设 true |
| 自定义出口 | free_text / other 项 | 兜底自定义 |

**核心三不变**：编码 + 中文名同屏、单题 ≤4 项分页、有自定义出口。

## 二、回落文本编码菜单（弹窗不可用时的兜底 · 必保）

平台无选择组件、或组件调用失败 / 未出现时，**立即回落文本菜单**。格式与弹窗**逐字一致**（编码、文案、顺序、默认值全同），不因回落而丢选项、丢说明：

**判定「弹窗失败 / 未出现」的准绳（照此执行，不靠猜）**：
① 调用抛异常（报错）；② 调用返回为空、超时、或没有任何选择结果（用户没真正点选到）。
满足任一即视为失败，**必须立即回落文本编码菜单**——不可静默继续、不可反复重试同一弹窗、不可把「没点到」当「选了默认」。

```
请选一种产出模式（回一个字母即可）
- A｜封装成技能包 — 以后一句话跑出同样结果
- B｜完整精华萃取 — 长资料浓缩成要点，忠于原文
- C｜定向萃取 — 只按您指定方向抽
回 A / B / C 即可；拿不准说一句场景我帮您判断。
（格式 1-7、风格 A-H、版本 1-7、用途文体 1-4、深度 D1-D3 同理，编码与弹窗一致，见各 mode-*-guide.md）
```

## 三、当前菜单（**全程决策 ≤3** · 弹窗分页切分 · 直接照抄）

| 级 | 菜单 | 分页 | 单页项（编码） | 多选 | 默认 |
|---|---|---|---|---|---|
| ① | 产出模式 | 不超 4，不分页 | 1 页：A / B / C | 否 | 未明说即提示可选 B / C；拿不准先问场景 |
| ② | 交付格式（B / C） | 分 2 页 | 第 1 页 1-4（Word / PPT / Excel 图表 / PDF）、第 2 页 5-7 | **是** | Word（编码 1） |
| ③ | C 萃取方向（仅 C） | 动态生成 | ≤4 项 + 兜底「通用要闻速览」+「其他补充」出口 | 否 | **必需输入**（不设默认，兜底项兜住空白） |

**最坏路径 = 模式（1）+ 交付格式（1）+ 萃取方向（1，仅 C）= 3 次。** 数法与接管口径见 `references/mode-bc-guide.md`「决策计数与接管」。

**已撤出菜单的三级（默认值 + 口头出口 · 不弹、不占决策次数）**：

| 维度 | 默认 | 口头口令 |
|---|---|---|
| 内容处理深度 | `D1` 完整原生（B / C 同） | 「改写成我的话」→ D2；「只留骨架」→ D3 |
| 视觉观感（风格 / 版本） | 标准商务（`biz`） | 「要红黑硬核」「用课件版」→ 按映射表调参 |
| 用途文体 | 通用正文（`plain`） | 「要能照着讲」→ 讲稿体；「做知识卡片」→ 卡片体 |

> **撤下来 ≠ 能力下线**：三级的能力与生成器参数**全部保留**，用户说一句即照做，**不得以「本轮没问这一级」为由拒答**。撤掉的只是「占用决策次数」这件事。
> ⚠️ **第 5 项起会被宿主静默吞掉、用户点不到**——分页不是可选项，是硬约束。交付格式 5-7 必须靠第 2 页才能被点选，绝不能为省一页而删项。
> **多选维度（交付格式）默认只出默认项，其余由用户主动勾选追加——不替用户多产出。**
> **维度 × 格式适用矩阵**：表格类（Excel 标准表 / 图表）**不做「深度 / 文体」**——表格是数据不是行文，不适用就不弹也不套用（全表见 `references/mode-bc-guide.md`「维度 × 格式适用矩阵」）。

**跨页多选合并规则（交付格式 1-7 · `multiSelect` 跨 2 页）**：第 2 页弹窗的 `question` / `header` 必须注明「已选：1,3（还可补充 5-7）」，让用户看到前页已勾项；两次提交**追加合并、不覆盖**，最终回执为两页编码并集（如 `1,3,5,7`）。Agent 收到回执先与已知已选项合并再进下一步，绝不以最后一页提交覆盖前页。

**编码重叠提示（模式 A/B/C 与风格 A-H 共用 A/B/C）**：分级语境下不歧义（每级弹窗 `header` 已标「这一步在选什么」）。仍须加一句兜底：若用户在风格级误回 `C` 想换模式，弹窗 `description` 或文本菜单注明「要换产出模式请明说 A/B/C」，避免被误判为风格 C。

**各级出口（首屏可见 · 用户自述 > 菜单预设 > 默认值）**：

| 级 | 出口类型 | 出口文案（须与选项同屏） |
|---|---|---|
| ① 产出模式 | 场景类 | 「拿不准说一句场景，我帮您判断」 |
| ② 交付格式 | 规格类 | 「不满意就自己说 —— 想要什么格式 / 什么感觉 / 什么规格，按您说的来」 |
| ③ C 萃取方向 | 方向 / 主题类 | 「直接写关键词 / 主题 / 问题 / 提示词」 |

> **四条硬规**：① **出口必须在首屏、与选项同屏** —— 藏进第 2 页或折叠项里 ＝ 墙上的小门，不算活口；② **优先级三层写死**：**用户自述 > 菜单预设 > 默认值**，**不得以「菜单里没有这一项」为由拒绝**（要么照做，要么如实说清能力边界 + 给替代）；③ **接管即静默**：用户一自述要求，该级**不再弹菜单**、按他说的办、回执「已按您的说法办」；④ **事后自我完善**：交付后改口 / 加要求 / 换口径 **一律以他为准、直接重出**，不辩解、不说「刚才您没提」。

## 四、用户可见英文零容忍（与 SKILL.md A0.5 第 11 条同义）

弹窗 `label` / `description` 与文本菜单**严禁出现任何英文令牌或英文单词选项**：
- 内部令牌 `biz` / `lean` / `report` / `warm` / `red` / `sky` / `teal` / `violet`、`standard` / `minimal` / `classic` / `premium` / `summary` / `course` / `data`、`plain` / `speech` / `oral` / `card` **只准存在于 SKILL.md A0.5 映射表与 `scripts/`**，绝不进弹窗、不进对话。
- 用户看到的只有「中文名 + 单字符编码」。文件格式名（PPT / Word / PDF / Excel / Markdown / TXT）属必要专有名词可保留。
- 英文不认识 = 选择困难，这条是硬门禁。

## 四之二、新增选择维度必须带默认值（与 SKILL.md A0.5 第 12 条同义 · 结构性护栏）

**决策不过三（先于本条）**：全程用户在菜单上做的选择**最多 3 次**（产出模式 + 交付格式 + C 萃取方向 = 3）。**新维度若要上菜单，先挤掉一个旧的、或给它默认值不上菜单** —— 冒出第 4 级选择即属违规。

往引导链里加任何新的可选择维度（**当前在菜单上的只有三个**：产出模式 → 交付格式 → C 萃取方向），**必须同时声明该维度的默认值**，且保证跳过它直接产出不受影响。
- **可选择维度无默认值不得上链**：先把默认值定出来，再上菜单；唯一例外是**必需输入项**（缺它无法产出、只能由用户给出，如 C 模式萃取方向）——它不受默认值约束，但须给兜底项与自定义出口，保证永远有得选。
- 落地检查：新增维度时先自问「用户不选它，能不能照常产出？」——能，说明它是可选择维度，必须补默认值再上链；不能，说明它是必需输入项，须补兜底项与自定义出口。
- **默认值怎么定 —— 四问（定或改任何默认前先过）**：① 用户打不打得开？② 交付形态完不完整？③ 成本是不是最低必要？④ 下游好不好转？**③ 与 ④ 是反向的**（灵活度越高、成本越高）→ **默认站「低成本 · 高通用」那一端，灵活度由用户主动勾选按需付费**。
- **各级默认值（不选即按此出）**：**在菜单上**的只有交付格式 `Word`（可主动勾选追加）；**不上菜单**的默认：深度 `D1` / 视觉观感 `标准商务` / 用途文体 `通用正文`（均口头可切）；C 模式萃取方向为**必需输入**（不设默认，以「兜底项 + 其他补充」兜住空白）。
- **三条级间规则**：① **视觉风格 / 版本已整体撤出菜单**（全部格式默认标准商务，用户口头可切）；② **Excel 图表类型不设弹窗级**（选定「Excel 图表分析报告」后，由 Agent 按选型规则**自动给推荐图型**、一句话可覆盖；规则拿不准时兜底柱形图）；③ **表格类不适用「深度 / 文体」**（不弹、不套用）。要加维度先想默认值；**想不出默认值的可选择维度，就是不该上菜单的维度**。

## 五、自检清单（每次弹窗前过一遍）

- [ ] 这一步是否真的需要用户选？（不需要就别弹）
- [ ] 选项是否「编码 + 中文名」同屏、一眼懂？
- [ ] 单题是否 ≤4 项？超了是否分页且编码连续不删项？
- [ ] 是否带了「其他补充」自定义出口？
- [ ] 是否有默认值时已写明默认？
- [ ] 若新增了可选择维度：它是否已声明默认值？（可选择维度无默认值不得上链；必需输入项须补兜底项与自定义出口）
- [ ] **全程决策是否 ≤3？**（模式 + 交付格式 + C 方向 = 3；多出第 4 级即违规）
- [ ] **本维度对当前所选格式适不适用？**（表格类不弹「深度 / 文体」）
- [ ] **每一级的「其他补充」出口是否在首屏、与选项同屏？**（藏进分页末页即不合格）
- [ ] 用户自述与菜单 / 默认值冲突时，是否按「**用户自述 > 菜单预设 > 默认值**」办？（不得以「菜单里没有」拒绝）
- [ ] 交付后用户改口 / 加要求，是否**直接重出、不辩解**？
- [ ] 弹窗调失败后是否自动回落文本编码菜单（同编码）？
- [ ] 全程有无英文令牌泄漏进用户可见文本？

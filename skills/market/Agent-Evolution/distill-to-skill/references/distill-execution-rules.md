# 蒸馏执行规则（SKILL.md 执行章节的展开细则）

本文件是 SKILL.md 各执行章节的展开细则，随包进入 Agent，供执行蒸馏与产出标准件时参照。**与 SKILL.md 冲突时以 SKILL.md 为准，本文件不另立标准**；只含能力层与辅助层，构思层零写入，不出现任何来源名称。

## 一、总则

1. 适用范围：本技能全部模式；安装包自包含，内容全部随包进入 Agent。
2. 内容范围：只含能力层与辅助层，构思层零写入。
3. 交付目标：跨平台可安装，工程级交付，小闭环独立运转。
4. 运行目标：Agent 本地识别、加载、调用、执行、校验、回退、结束。
5. 交付标准：装得上、跑得通、用得好；读得懂、调得动、执行得稳。
6. 零痕迹要求：禁止出现任何示例名称、示例标识、示例备注；禁止项目名、客户名、项目代号、编号、批注、引用、脚注、来源、链接、截图、文件名、路径、作者、时间戳。

## 〇、规模适配与架构优先提取（大内容处理，A0 对应细则）

本技能投料体量无上限：书几万字、报告几十万字、视频转写/会议纪要多语种均可能极大。本层是防崩溃第一关，保证“不整段塞上下文、不漏失段、不 hallucinate、不中途崩”。

### 1. 体积分级（按字符数，含空白）
- S < 5K：直接进四段式（A3），单轮可处理。
- M 5K–30K：单轮可处理，建议先掠骨架。
- L 30K–100K：必须分块（见下），逐块提取后汇总。
- XL > 100K：必须“先规划后执行”，架构侦察 → 分块 → 逐块 → 汇总。

### 2. 语义分块（确定性，由 `scripts/ingest_chunk.py` 执行）
- 切分边界：标题（#/##/第X章/节/回）、说话人切换、时间戳、空行段落；不按固定字符硬切。
- 单块上限 4K 字符，超限在句边界再切，防单块过大。
- 每块带稳定 ID 与就近标题，产出可独立验证、可溯源、可回退。
- 输出：分块清单（JSON，含 id/title/char_count/text）+ 执行计划（先骨架后细节）。

### 3. 先规划后执行（架构优先）
- 架构侦察：先扫目录/大纲/标题/首尾段，产出“架构骨架假设”（章节树/流程节点/核心判定），不先抠细节。
- 逐块提取：每块按所属适配层（SKILL.md A4.1 路由）走四段式最小闭环，产出“可复用单元 + 挂接架构位置”。
- 汇总架构：把各块单元挂到骨架上，去重、归并、识别“核心架构层 vs 附属叙述层”。

### 4. 架构优先提取（三遍扫描，抓内核舍附着）
- 第一遍·骨架：章节/标题/流程节点/判定主干。
- 第二遍·核心单元：判定/规则/参数/步骤/阈值/边界（即底层逻辑、方法论、技巧）。
- 第三遍·剥离附着物：举例/情绪渲染/重复/闲笔/广告/客套，不进包，仅记“已剥离冗余 N 处”。
- 原则：保留可复用方法论骨架，舍去附着在骨架上的非必要叙述。

### 5. 防崩溃护栏（L/XL 强制）
- 整段超限保护：超过 L 阈值不整段进上下文，强制分块。
- 块级隔离：单块失败只回退该块重提，不整崩；失败块标“待补”不硬编。
- 汇总幂等：重跑不产生重复单元；已处理块可断点续跑（记录进度状态）。
- 多形态/多语言：英文/杂志/学术/视频转写/会议纪要，统一先降为文本块（OCR/转写由宿主 Agent 多模态做，A9/A10），本层只认文本块；非中文同处理，不另设屏障。

### 6. 与四段式联动
- S/M：提取段整料单轮。
- L/XL：提取段替换为“逐块提取 → 汇总架构”（A0.2），验证/构造/自证在汇总后整体走；分块阶段每块过各自小闭环（A4 铁律）。
- 门禁：A6 在汇总后整体过；逐块产出先过该层小闭环。

## 二、执行闭环

1. 触发：明确触发词与调用条件。
2. 加载：明确元数据、入口、依赖、权限、版本。
3. 校验：明确输入格式、字段、边界、必填项、合法性。
4. 执行：按提取 → 验证 → 构造 → 自证顺序执行。
5. 输出：明确格式、字段、示例、交付标准；同时产技能包与简短说明双通道。
6. 质检：明确通过条件、失败条件、校验规则。
7. 异常：明确异常类型、识别方式、处理动作。
8. 回退：明确回退条件、回退步骤、回退结果；不通过回退提取或验证段，不硬出包。
9. 结束：明确结束条件、日志留存、状态标记。
10. 闭环：每个技能独立完成，不依赖人逐步喂步骤。

## 三、四段式执行细则

### 1. 提取

1. 只抽可复用单元：规则、判断、话术、流程、参数、风格。
2. 引用与术语先拍平为自包含文本，不保留悬空引用。
3. 不抽示例名称、示例标识、示例备注。
4. 不抽项目名、客户名、编号、批注、来源、路径、作者、时间戳。

### 2. 验证

1. 每条提取项核对保真：忠于原意、无缺上下文、无自相矛盾。
2. 采用已知样本、边缘样本、声音一致性三测（定义见第六节）。
3. 无据项标注"待用户确认"。
4. 验证不通过，退回提取段。

### 3. 构造

1. 组装为触发 + 步骤 + 判定 + 输出 + 风格锁的技能结构。
2. 同时产技能包与简短说明双通道。
3. 技能包只含能力层与辅助层。
4. 构思层零写入。

### 4. 自证

1. 用通用校验样本回测。
2. 不通过回退提取或验证段。
3. 不硬出包。
4. 通过后标记完成，留存日志。

## 四、保真度度量（TRACE 五维）

| 维度 | 含义 | 不达标表现 |
|---|---|---|
| 原意 | 还原核心原意特征，不保留来源标识 | 张冠李戴 |
| 结构 | 逻辑骨架一致 | 结构崩坏 |
| 语气 | 表达口吻一致 | 机器腔、不像目标风格 |
| 知识 | 关键知识点准确 | 事实错误 |
| 边界 | 适用边界清晰 | 过度泛化 |

## 五、交付净化四层（L1–L4）

1. L1 硬规则：去标识、去侵权素材、去受保护内容。
2. L2 风格：像目标风格、自洽。
3. L3 内容：规则可执行、无矛盾。
4. L4 表达：自然、无机器腔。

## 六、三测定义（已知样本 / 边缘样本 / 声音一致性）

1. 已知样本测试：取来源中已被明确表达的典型内容作为校验样本，回测产出能否还原。通过条件：典型内容还原准确、无缺漏、无曲解。
2. 边缘样本测试：取来源中边界、罕见、易歧义的内容作为校验样本，回测产出在边界是否仍可靠。通过条件：边界内容不崩坏、不错误泛化、不越界。
3. 声音一致性测试：取来源中标志性表达口吻样本，回测产出语气是否一致。通过条件：产出语气与来源一致，无机器腔、不串味。

用途：三测在验证段与自证段使用，任一不通过即回退提取或验证段，不硬出包。

## 七、通用示例

1. 输入类型为长文：提论点链与关键表达 → 构带导航长文技能 → 质检通过 → 交付。
2. 输入类型为口述：提取行为、人格、认知三层 → 构人格技能与可进化记忆 → 交付。
3. 输入类型为手册：提取字段、步骤、阈值 → 构流程技能 → 交付。

## 八、通用反例

1. 输入含买卖建议：只蒸方法论表达，不内嵌买卖结论。
2. 输入为规避他人权利标识类需求：拒绝，不吸收。
3. 输入为跨平台代装请求：说明本技能不出代装，仅出标准包由用户自装。

## 九、工程级要求

1. 版本：明确版本号、变更记录、兼容范围。
2. 清单：明确文件清单、入口文件、依赖清单、权限清单。
3. 签名：安装包签名，防改动。
4. 权限：明确可调用范围与禁止范围。
5. 日志：本地日志、状态标记、审计留存。
6. 测试：样例、反例、回归测试、验收指标。

## 十、防外流布局

1. 内容层：能力层只写最小必要执行指令；辅助层只写正确调用所需解释；构思层零写入。
2. 形态层：能封装就封装；不能封装则最小化可读内容；安装包签名。
3. 授权层：设备绑定、授权文件、有效期、功能分级。
4. 追溯层：可见溯源落款、调用日志、审计导出、异常告警（不嵌不可见水印或指纹）。
5. 法律层：许可协议、禁止反向工程、禁止批量提取与商用。
6. 运营层：版本控制、授权过期、泄露演练、回归测试。

## 十一、验收清单

1. 自研与交付是否同一标准版？
2. 是否跨平台可安装、可加载、可运行？
3. 是否工程级：版本、清单、签名、权限、日志、测试齐全？
4. 是否小闭环：触发到结束无断点？
5. 是否能力层与辅助层齐全，构思层零写入？
6. 是否无示例名称、示例标识、示例备注？
7. 是否无项目名、客户名、编号、批注、引用、来源、路径、作者、时间戳？
8. 是否通过脱敏扫描与回归测试？
9. 是否通过 TRACE 五维与 L1–L4 净化？
10. 是否不通过即回退，不硬出包？

## 十二、适配层细则（O1–O13 + 通用兜底）

每条含：识别信号（路由依据）/ 提取什么 / 怎么验证 / 构造什么形态。三层判据是硬标准，缺失任一项该层闭环不完整。共用铁律：每层自带完整四段式，独立闭环；差异只在"提取什么/怎么验证/构造什么形态"，共性走内核；TRACE 任一维或三测任一不过即回退，不硬出包。

### O1 长篇文本（长文适配层）
- 识别信号：连续成篇、有章节结构的文字（书/长文/课程稿/报告/长帖合集）。
- 提取什么：章节骨架、论点链、关键判断、支撑论据、标志性表达、适用边界；引用/术语解引用拍平为自包含文本。
- 怎么验证：TRACE 原意+结构；已知样本取核心论点回测还原；边缘样本取争议/边界段看是否崩坏；声音一致性取标志性句式；悬空引用标"待补"。
- 构造什么形态：带导航的长文技能（分主题触发 → 提取规则 → 判定 → 输出模板 → 风格锁）；过长则拆为多个子技能各自成闭环。

### O2 短篇碎片（碎片适配层）
- 识别信号：零散短句/金句/社交动态/短帖/散记，无完整章节。
- 提取什么：可复用观点、判断准则、话术、场景标签；聚类去重。
- 怎么验证：每句回溯可验证意图；样本不足标"小样本，风格待补"；无上下文的碎片不硬编。
- 构造什么形态：主题聚类技能（按场景/主题分组）+ 触发词表 + 风格锁；标精度等级。

### O3 结构化资料（结构适配层）
- 识别信号：表格/手册/SOP/规范/API 文档/字段定义，含明确步骤与阈值。
- 提取什么：字段、步骤、阈值、判定分支、输入输出 schema、必填项。
- 怎么验证：逐字段核对类型/必填/边界；样例跑输入输出；缺参跑看兜底；错参跑看识别。
- 构造什么形态：流程型技能（输入字段 → 步骤 → 判定 → 输出 schema）+ 校验规则。

### O4 多媒体降维（多媒体适配层）
- 识别信号：视频/音频/图片等需转写或 OCR 的素材。
- 提取什么：先由宿主多模态转写/OCR 为文本，再按内容类型归并（文本→O1/O3，口播→O8）；只抽文字化后可复用单元；仅用公开可采素材，不下载受保护内容。
- 怎么验证：转写由宿主完成，本技能只验文本；长音频/低质图标"转写可能失真，待用户确认"；宿主不具备多模态则要求用户提供文本。
- 构造什么形态：降维后走对应文本适配层；注明"原始媒体不随包"。

### O5 人物（人物三层适配层）
- 识别信号：某人言行/访谈/作品/口述传记，目标蒸馏其"人设"。
- 提取什么：行为层（怎么做/标准动作）、人格层（怎么说话/性格/口头禅，Memory+Persona）、认知框架层（怎么想/决策模型）。
- 怎么验证：声音一致性测人格层；行为样本测行为层；认知样本测框架层；三层一致不冲突。
- 构造什么形态：人格技能（Persona+行为规则）+ 可进化记忆模板（记忆结构不入包，只给追加/修正/回滚接口）。

### O6 岗位（岗位适配层）
- 识别信号：岗位职责/工作流/岗位经验/SOP 类材料。
- 提取什么：职责、标准动作、判定阈值、异常处理、话术、升级路径、协作接口。
- 怎么验证：缺参跑（少一字段能否兜底）；错参跑（错误输入能否识别）；边界样本测泛化。
- 构造什么形态：岗位助手技能（触发 → 步骤 → 判定 → 输出 → 异常 → 升级）+ 交接说明。

### O7 已有产物（产物逆向适配层）
- 识别信号：已有技能/Prompt/工具/文档，目标提纯重组。
- 提取什么：已有能力、触发、输入输出、缺口、冗余、有效步骤。
- 怎么验证：跑原产物看是否仍有效；标"未验证"项；查冗余与冲突。
- 构造什么形态：重构为标准件（保留有效、补缺失、去冗余、去构思层）。

### O8 无形经验（口述适配层）
- 识别信号：口述记忆/师徒传授/脑子里的手艺（维修/开店/带人）。
- 提取什么：步骤、判定、参数、风险点、话术、边界；口语拍平为规则。
- 怎么验证：回述给用户确认；边缘样本测边界；标"口头未证实"项。
- 构造什么形态：经验技能（流程 + 判定 + 参数 + 风险点 + 风格锁）。

### O9 AI 自产（AI产物适配层）
- 识别信号：模型输出/对话记录/已有 Agent 行为，目标固化有效模式。
- 提取什么：可复用提示词、流程、判定逻辑；去一次性噪声。
- 怎么验证：重跑样例看一致性；区分"一次巧合"与"稳定有效"，标"依赖特定模型"项。
- 构造什么形态：标准件（按 O3/O1 归并）；注明适用模型前提。

### O10 混合（混合适配层）
- 识别信号：多源交织、类型混杂的材料。
- 提取什么：先拆分类型，逐块按对应层抽，再合并去重。
- 怎么验证：每块按所属层验证；合并后查冲突与重复。
- 构造什么形态：主技能调度多子技能，或拆为多个独立小闭环各出自包。

### O11 认知框架（框架适配层）
- 识别信号：思维模型/决策框架/方法论/心法类材料。
- 提取什么：框架名称、步骤、判定准则、适用边界、反例。
- 怎么验证：已知样本测框架还原；边缘样本测边界不泛化；反例齐备。
- 构造什么形态：框架技能（触发 → 四问/步骤 → 判定 → 输出 → 反例）。

### O12 关系数字人（关系适配层）
- 识别信号：特定关系中的交互模式（客服/顾问/陪伴式对话）。
- 提取什么：关系定位、语气边界、应答模板、升级判定、禁区。
- 怎么验证：对话样本回测语气与边界；越界样本测拒答。
- 构造什么形态：对话体技能（身份 + 语气锁 + 应答分支 + 升级 + 禁区）。

### O13 机构组织（组织适配层）
- 识别信号：公司/团队/机构的方法/流程/制度/voice/know-how（显式文档或口述）。
- 提取什么：组织目标、流程、角色分工、判定、制度边界；去机构名/品牌名/项目代号。
- 怎么验证：流程样本跑通；边界样本测泛化；标"组织专属"项（隐性文化需口述补）。
- 构造什么形态：组织方法技能（去标识的通用流程 + 角色 + 判定 + voice 约束）。

### G 通用兜底（通用适配层）
- 识别信号：未命中 O1–O13 任一类。

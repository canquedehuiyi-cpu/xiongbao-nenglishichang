# 快速上手 · 蒸馏成技能Skill

把任何材料，变成能装进 AI、反复调用的技能，或一份精华文档。

> 本页的词都用大白话：**技能包**＝装上就能反复调用的东西；**精华文档**＝您拿走就能直接看的文件；**投料**＝把材料发进来。

---

## 三步流程

**① 给料** → 把材料发进来（文件 / 链接 / 直接说都行）：书 / 小说 / 视频 / 课程 / 播客 / 语音 / 会议纪要 / 网页 / 表格 / 口述经验 / 已有技能……一种或多种混着发都行。收到先暂存，等选好模式再开工。

**② 选模式** → 一句话说清您要哪种产出（回一个字母即可）：

- **A｜封装成技能包**——给您的 Agent 用，装上就能反复调用。
- **B｜完整精华萃取**——PPT / PDF / Word / Excel / MD，给您拿走。
- **C｜定向萃取**——您说方向，只取那部分。

**③ 收包** → 确认要哪一种 / 哪些格式，拿到技能包或文档。

---

## 一次跑通长什么样

> 下面三次，是三种模式各跑一遍的**样子**，不是规定动作 —— 您怎么说都行。

### 示例一 · A 模式（把材料变成技能包）

**您**：（把一份材料发进来）把这个做成技能包

**它**：收到，先寄存。您想要哪种产出 —— A｜封装成技能包　B｜完整精华萃取　C｜定向萃取

**您**：A

**它**：我理解您要把这份材料里的方法，做成一个能反复调用的技能包。这就开工，分三段落：提取 → 验证 → 构造，每段开始我都报一声。

　（提取完成 → 验证完成 → 构造完成，各报一声）

**它**：成了。技能包在这儿：`<包名>/`

　· `SKILL.md`　给您的 Agent 读的能力说明
　· `README.md`　给您看的说明
　· `<包名>.zip`　装上就能反复调用的安装包

**它**：**这一趟拿到了**：一份能把这份材料里的方法反复调用的技能包。想改随时回来说一声，**材料不用重传**。

> ▸ 全程您只回了一个字母。

## 您会经历什么

- ① **给料**：说清要把什么材料蒸馏成什么 → 方向被接住
- ② **对齐**：它先用一句话讲清「我理解您要的是什么」，然后直接开工
- ③ **收包**：拿到技能包或文档 + 一句「这一趟拿到了什么」的结果说明

> 全程在菜单上做选择**不超过三次**：选模式 → 选格式（默认 Word）→ 仅 C 模式再选方向。其余都能口头一句话切换。

## 支持的资料类型

- ① 文字 / 文档：Word / PDF / PPT / Excel / TXT / MD
- ② 链接 / 网页
- ③ 媒体：视频 / 音频 / 图片（依赖运行环境是否已装转写或识别工具；没装时用您给的文字稿照样蒸）
- ④ 口述经验 / 手艺 / 方法论 / 心法 / 公司制度与流程
- ⑤ 已有 Skill（可蒸馏重构 / 优化）
- ⑥ 知识库 / 笔记 / 规范标准 / 会议纪要 / 访谈
- ⑦ 多语种材料 / 长文资料集（支持批量整库投料与十万字级长文）

**材料越全，产出越稳。** 缺哪类，它会顺嘴问，不会一次要全。

---

## 它不做什么

- 不替您下**决策结论**（比如"买什么、什么时候买"这类）—— 它只把材料里的方法蒸出来，判断权在您。
- 不碰**您无权使用的内容**：涉及他人作品或商业机密的，请先取得授权，或先把标识去掉再发。
- 不锁您：拿到的东西**归您**，能装到任何支持技能上传的平台。

# 质量测试清单

智能体制作完成后，须通过以下三关测试。每关包含若干检查项，逐项核实。

---

## 第一关：课标合规性

**核心问题**：这个智能体的输出是否符合国家课程标准？

| 检查项 | 验证方法 | 通过标准 |
|--------|---------|---------|
| 目标可溯源 | 打开课程标准，找到智能体涉及的目标 | 每条目标都能在课标中找到对应条目 |
| 不超纲 | 检查智能体生成的内容是否超出课标要求 | 无超出学段或年级要求的内容 |
| 不缺位 | 核对课标要求的关键内容是否被覆盖 | 课标明确要求的内容均有涉及 |
| 术语准确 | 检查智能体使用的教学术语是否与课标一致 | 核心素养名称、学业质量描述等用语规范 |
| 价值观对齐 | 检查输出内容是否符合立德树人的教育方针 | 无价值观偏差或不当引导 |

**通过条件**：5项全部通过。

---

## 第二关：课堂可行性

**核心问题**：这个智能体在真实课堂中能用吗？

| 检查项 | 验证方法 | 通过标准 |
|--------|---------|---------|
| 时间可行 | 模拟实际使用，计时操作 | 在课堂可用时间内完成（如备课类不超过30分钟产出） |
| 规模适配 | 检查活动设计是否考虑40-50人班级 | 不依赖小班条件或一对一辅导 |
| 环节完整 | 检查教学设计的环节是否齐全 | 包含导入、新授、练习、小结等基本环节 |
| 时间分配合理 | 检查各环节的时间分配 | 无"15分钟小组讨论"等不切实际的时间安排 |
| 资源可得 | 检查推荐的资源和教具 | 优先使用教材和常规教具，不依赖稀缺条件 |
| 重难点有策略 | 检查是否针对重难点给出突破策略 | 不是"多讲多练"而是有具体教学方法 |

**通过条件**：6项全部通过。

---

## 第三关：教师友好度

**核心问题**：教师拿到这个智能体，能直接用吗？

| 检查项 | 验证方法 | 通过标准 |
|--------|---------|---------|
| 拿来即用 | 教师不借助说明直接试用 | 能独立理解操作流程，不需要额外培训 |
| 输出可直接用 | 检查智能体的输出物 | 教师可直接用于教学，不需大量二次加工 |
| 不增加负担 | 评估使用智能体前后的工作量变化 | 使用智能体后工作量减少而非增加 |
| 分层可操作 | 检查分层设计是否可执行 | 不是"理想化分层"，教师能实际操作 |
| 反馈有用 | 检查智能体给出的建议 | 建议具体可操作，不是"加强练习""多关注"等空话 |
| 容错能力 | 输入不完整或模糊的信息 | 智能体能合理引导或追问，不崩溃或胡乱输出 |

**通过条件**：6项全部通过。

---

## 测试流程

### 方式一：教师自测（推荐）

1. 教师打开智能体，输入自己学科的真实信息
2. 按工作流程操作一遍，产出完整方案
3. 逐项对照以上三关清单打分
4. 记录不通过项，反馈给研究员修改

### 方式二：交叉测试

1. 教师A使用教师B设计的智能体
2. 从"不了解这个智能体"的视角试用
3. 重点关注第三关（教师友好度）
4. 记录体验和问题

### 方式三：真实课堂测试（最终验证）

1. 教师在实际教学中使用智能体
2. 记录使用过程和学生反馈
3. 课后评估：智能体的输出在实际课堂中是否有效
4. 记录改进需求

# 三级审查详细清单与质量指标

## 层级 1：即时审查（每个函数/方法完成后）

**触发条件**：每完成一个函数或方法的编写

**审查清单**：
- [ ] 代码能否正常运行（语法检查）
- [ ] 注释是否完整且准确
- [ ] 函数职责是否单一
- [ ] 参数和返回值是否清晰
- [ ] 是否有明显的逻辑错误
- [ ] 是否使用了 `// TODO` 占位符（禁止）

**处理方式**：
- 通过 → 继续下一个函数
- 发现问题 → 立即修复，修复后重新审查

**工具支持**：
- IDE 实时错误提示
- 运行单元测试验证函数行为
- 代码结构检查（函数长度、复杂度）

---

## 层级 2：模块审查（每个模块完成后）

**触发条件**：一个完整功能模块开发完成

**审查清单**：
- [ ] 模块内所有函数是否通过即时审查
- [ ] 模块接口是否清晰定义
- [ ] 模块间依赖是否合理（低耦合）、无循环依赖
- [ ] 单元测试覆盖率是否达标
- [ ] 是否存在代码重复
- [ ] 模块目录结构是否符合规范（api/service/models/helpers/index）
- [ ] 共享代码是否正确放在 `src/common/` 而非重复在各模块中
- [ ] 性能关键路径是否优化（仅复杂项目）
- [ ] 安全常见问题检查（仅复杂项目）

**审查流程**：
```
模块开发完成
    ↓
运行所有单元测试 → 失败？→ 修复 → 重新测试
    ↓ 通过
代码审查（结构、注释、规范、共享代码检查）→ 问题？→ 修复 → 重新审查
    ↓ 通过
性能/安全检查（仅复杂项目）→ 问题？→ 优化 → 重新检查
    ↓ 通过
更新 MODULE_MAPPING.md（为该模块所有文件添加/更新映射行）
    ↓
使用 AskUserQuestion 向用户展示模块成果 → 用户有异议？→ 调整
    ↓ 确认无误
标记模块完成，更新任务清单，进入下一模块
```

**输出物**：
- 模块测试报告
- `docs/development/module-review/{module-name}.md` — 模块审查记录
- MODULE_MAPPING.md（更新该模块的映射行）

---

## 层级 3：集成审查（所有模块完成后）

**触发条件**：所有功能模块开发完成，准备交付前

**审查清单**：
- [ ] 所有模块是否通过模块审查
- [ ] 模块间接口是否正确集成
- [ ] 端到端测试是否通过
- [ ] 整体性能是否满足需求（仅复杂项目）
- [ ] 文档是否完整且准确
- [ ] 代码风格是否统一
- [ ] 是否满足所有 PRD 功能点
- [ ] MODULE_MAPPING.md 是否覆盖所有代码文件且无遗漏
- [ ] `src/common/` 下的共享文件是否在映射表中正确归类和描述

**审查流程**：
```
所有模块开发完成
    ↓
运行完整测试套件 → 失败？→ 定位问题模块 → 修复 → 重新测试
    ↓ 通过
集成测试 → 失败？→ 分析接口问题 → 修复 → 重新测试
    ↓ 通过
全面代码审查 → 问题？→ 修复 → 重新审查
    ↓ 通过
文档完整性检查 → 缺失？→ 补充文档
    ↓ 通过
MODULE_MAPPING.md 完整性检查 → 遗漏？→ 补全映射
    ↓ 通过
使用 AskUserQuestion 与用户进行最终验收 → 有异议？→ 调整
    ↓ 确认无误
进入交付阶段
```

**输出物**：
- `docs/delivery/integration-test-report.md` — 集成测试报告
- `docs/delivery/final-review.md` — 最终审查报告
- MODULE_MAPPING.md（最终确认版本）

---

## 代码注释要求

- 每个文件头部：文件用途说明
- 每个函数/方法：功能描述、参数说明、返回值、示例
- 关键逻辑块：算法思路或业务逻辑说明
- 复杂条件判断：判断条件和预期结果
- 注释语言：与用户语言保持一致

---

## 代码结构约束

以下规则在各级审查中均需检查：

- **禁止占位符**：每个函数/方法必须有真实实现，不允许 `// TODO` 或 `# 待实现`
- **禁止合并模块**：每个模块独立目录，不允许跨模块混放代码
- **禁止循环依赖**：模块之间不得形成依赖环
- **命名规范**：模块目录使用小写+下划线（如 `user_auth`），文件名表达职责

## 质量指标

| 审查项 | 复杂项目标准 | 简单项目标准 | 检查方法 |
|--------|-------------|-------------|---------|
| 单元测试覆盖率 | > 80% | > 50% | 测试工具统计 |
| 函数平均长度 | < 30 行 | < 50 行 | 代码分析 |
| 模块耦合度 | 低（依赖注入） | 中等 | 人工审查 |
| 代码重复率 | < 5% | < 10% | 重复检测工具 |
| 注释覆盖率 | 100% 公共接口 | 100% 公共接口 | 人工审查 |
| 循环复杂度 | < 10 | < 15 | 代码分析工具 |
| MODULE_MAPPING.md 覆盖率 | 100% | 100% | 人工核对 |

---

## 文档质量

- **完整性**：所有文档模板必填项已完成
- **准确性**：文档与实际代码一致（含 MODULE_MAPPING.md）
- **可读性**：结构清晰，示例充分

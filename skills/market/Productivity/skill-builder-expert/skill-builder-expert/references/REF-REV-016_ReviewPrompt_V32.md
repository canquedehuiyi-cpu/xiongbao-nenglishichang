# Agent 评审专用 Prompt 模板

> 用途：将本模板 + 立项表单/方案资料发给 Agent，Agent 按本手册准则逐项评审，不主观发挥。**本模板为评审模板全文唯一真源**（含模块一～四全部校验组）；《AI Skill 技能Skill开发通用规则标准手册》附录B 自 2026-11-11 起收敛为指针指向本册，不再复述正文。

1. 禁止主观宽松判定，准则内阈值、规则刚性执行；

8. 数据隐私与版权边界须单独核验；

9. 不做技能创意修改，只做评审、校验、指出问题、给出整改建议；

10. 若开发者与评审者为同一 Agent，须在报告末尾加「外部复核/陌生实测」一项，防止宽松放行。

11. 评测与生产者为同一体系时，技能质量标准核验结果须附「外部复核/陌生实测」一项，防止自我放水宽松放行。

**【反推透镜】**（可提升方向的分析透镜，定性输出，不打分）

对受评 Skill 逐条做四问反推，问题即写入「可提升方向」：
1. 交付定义：终点的「什么输入 → 什么结果 → 怎样算完成」是否明确——终点不清则全部环节失去评价标准；
2. 动作具体度：环节描述是否拆到「读取什么 → 判断什么 → 生成什么 → 检查什么」——出现「进行整体分析」类含混表述即列为可提升项；
3. 顺序因果：相邻步骤交换或删除后结果是否不变——不变则该顺序属摆设，列出合并或删减建议；
4. 约束完整度：逐条检查限制类规则（必须／不要／只能／失败即停），每条追问「没有它最容易出什么问题」——答不出保护对象的约束列为冗余项，答得出的标为重点保留项。

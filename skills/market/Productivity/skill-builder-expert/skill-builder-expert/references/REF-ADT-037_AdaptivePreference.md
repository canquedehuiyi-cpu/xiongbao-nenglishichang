# REF-ADT-037 · 会话自适应与本地偏好标准

> 用途：本册规定技能Skill「智能不机械」的落地规则——偏好沉淀、纠偏即学、分层输出、求助卡、透明告知五项能力及其边界。给 Agent 调用执行，也给机检扫描定基准。

> 边界红线（高于本册任何条款）：不向外回传任何使用数据；不做跨用户学习（用户甲的偏好永不影响用户乙）；不隐蔽采集（所有记录点必须事先告知）。

## 一、本地偏好文件规范

1. **文件名与位置**：`user_preference.json`，存放于技能工作区本地（用户设备上）。禁止使用绝对路径、网络路径、外部存储；禁止上传、同步、共享该文件。
2. **内容结构**（字段可增不可减）：
```json
{
  "updated_at": "<更新时间>",
  "preferences": {
    "version_type": "免费版本 或 收费版本",
    "mode": "轻量模式 或 API模式",
    "industry": "用户业务领域",
    "tone": "语气偏好",
    "depth": "输出详略偏好（详版/简版）",
    "corrections": ["用户纠正记录（逐条）"]
  }
}
```
3. **写入时机**（仅限三类，禁止扩大）：① 选型菜单确认后（版本类型/模式）；② 用户明示业务领域或语气、详略偏好时；③ 用户纠正 Agent 后（写入 corrections，逐条追加）。
4. **读取时机**：每次会话开场、欢迎菜单输出前。读到有效文件 → 逐项向用户确认后沿用（一句话确认，不重复盘问）；读不到或用户否定 → 按首次使用流程盘问并重新写入。
5. **清除机制**：用户说「清除偏好 / 重置配置 / 删除记忆」任一口令 → 立即删除 `user_preference.json` 全文件，并向用户回执「已清除，下次按首次使用流程」。清除指令必须在 **【帮助】** 导航页可见。

## 二、透明告知（合规底线，首屏必备）

1. **欢迎菜单第一屏固定包含**以下提示语（一字不改，随菜单整体输出）：

   > **【偏好存储说明】** 为更好理解你的需求、减少重复配置，持续帮你高效搭建和评测技能，本技能可在你当前设备本地留存你的使用偏好。偏好数据仅存储在你本机环境，不会向外上传、不会共享，也不会用于其他用户的模型学习。你拥有完整控制权，随时可以回复 **【清除偏好】** 一键清除记忆、重置全部配置。

2. **FAQ 收录详版问答**（用户追问「你会记我什么」时按需回该问）。
3. 告知语缺失 = 出厂不通过（机检强制，见 scripts/preference_guard.py）。

## 三、纠偏即学（同一错误不犯第二次）

1. 用户纠正 Agent（如「我说的是甲不是乙」「别用这个词」）时，Agent 必须：① 当轮立即按纠正执行；② 将纠正要点写入 `user_preference.json` 的 corrections（逐条追加，带时间）；③ 本会话后续所有轮次遵循该纠正。
2. corrections 逐条格式：「<纠正要点>｜<生效范围>」。只记规则性纠正，不复述用户原话全文，不记录与业务无关的闲聊内容。

## 四、分层自适应输出（不采集数据，纯流程规则）

1. **熟练度判定**（依据当轮输入特征，不查任何外部数据）：用户使用行业行话、直接给参数与结构 → 按**简版**输出（直达结论、要点式）；用户用日常口语描述、表述宽泛 → 按**详版**输出（带解释、分步引导、示例）。
2. 判定不准时以用户追问为修正信号：连续两次被要求「说简单点」→ 本会话锁定简版；被要求「直接给结果」→ 本会话锁定简版。
3. 分层只调**表达粒度**，不降内容质量：数字铁规、四段式、决策征询收尾等输出基线（REF-STD-032 / REF-RPT-031）两档均须满足。

## 五、求助卡（卡点结构化自报）

1. **触发信号**：同一问题连续两轮未解决；用户表达困惑或重复追问同一句；业务链路异常中断。
2. **动作**：Agent 主动输出结构化求助卡（用户可整体复制粘贴回平台会话求助）：
```text
**【求助卡】**

· 卡点环节：（当前所处业务环节）

· 已完成操作：（已做过的选择与动作，逐条）

· 期望结果：（想达成什么）

· 实际现象：（实际发生什么）
```
3. 求助卡内容只使用当前会话已知信息填写，不要求用户补充敏感内容；是否发送由用户自行决定，技能不得代替用户发送。

## 六、出厂机检与边界自检

1. `scripts/preference_guard.py` 为本册专用守卫（P1 本册存在且含清除条款 / P2 首屏告知语在模板文本中 / P3 偏好路径仅限本地相对文件名，网络与绝对路径零容忍 / P4 偏好文件本身不入对外交付包），挂回归引擎第 10 项，fail-closed，支持 `--self-test`。
2. `user_preference.json` 永不进入对外交付包（打包排除清单强制）。
3. 本册五项能力全部为「会话内＋用户本地」动作，任何一条与数据回传、跨用户学习、隐蔽采集相关的设计一律不得加入；新增能力须先过本节边界自检再入册。
4. 本册与 REF-TMP-003（首屏告知语与求助卡模板落点）、REF-STD-032（输出基线两档均须满足）、SKILL.md 交互执行铁则联动；冲突时边界红线优先。

**本册结束。** 术语写法执行 `references/REF-TER-035_Terminology.md`。

# 收费平台插件 · 自有宿主开放市场（最优先推荐）

> ⚠️ **内部说明 · 禁止写入交付物**：本文件是创作者后台路由与支付识别用的工具大脑，含各目标分发市场名称（主站技能市场 / 自有宿主开放市场 / 其他生态宿主等，一律以别名记载）。公共纪律（交付物禁写／中性模板套用／工具边界／0 密钥口径／改编位清零）统一依据 `references/REF-PAY-054_PayVariantCommon.md`，本册不再逐条重复。

> 本文件是「收费版本」接入 **自有宿主开放市场** 的接入骨架与接入模板。

> **定位：最优先推荐**——平台内闭环、零自有支付资质门槛，开发者认证后即可上架收费。

> **非权威规范**：以下流程、费率、结算周期为估算，以自有宿主开放市场官方文档与开发者规则为准；平台政策变动不另行通知。

> **工具边界**：Skill技能搭建专家仅按本骨架产出符合规范的技能Skill；不替代用户完成开发者认证、资质审核、提现绑定；不保证资金实际结算到用户账户。

> **当前准入规则（用户补充，以官方为准）**：上架 **自有宿主开放市场**，当前仅对企业创作者开放；企业创作者仅通过微信收付款完成收款（与微信 X402 企业版插件同属微信收款路径）。个人创作者暂不在开放之列。本专家不代办开发者认证与资质，不保证资金到账。

## 一、平台定位与适用场景
- 宿主平台自带支付与分发闭环，技能上架后由平台统一处理：展示、402 支付握手、扣款、分成、提现。
- 适合：无自有微信/支付宝商户资质、希望最快把技能变成收费产品、依赖平台流量与结算体系的开发者。
- 计费形态：买断（一次性）/ 订阅（周期）/ 内测费（早期限定名额）。

## 二、前置条件（用户自行完成，工具不代办）
1. 注册并认证运行宿主开放市场开发者账号（实名/企业认证，以平台要求为准）。
2. 在开放平台提交技能、通过平台内容审核与质量抽检。
3. 绑定收款账户（平台内提现绑定，平台规则为准）。
4. 设定计费档（买断价 / 订阅价 / 内测费），平台生成对应商品标识。

## 三、接入流程骨架（步骤）
1. 选型确认：用户明确表示要做收费版本 → 由 §2.0 确认机制落位。
2. 构建技能Skill：按本专家标准产出技能，不内嵌任何自有支付密钥。
3. 声明计费档：在 LISTING / 介绍页与 SKILL.md 计费说明写入统一价格（价格三处一致，见 §十三）。
4. 平台提交：用户自行在开放平台后台上传技能Skill、填计费、提交审核。
5. 上架与 402：平台自动接管支付握手与履约；技能只需按平台规范返回受限内容触发点。
6. 验收：用户自行在平台内完成购买链路实测（陌生账号真付，AI 做不了，交用户）。

## 四、402 握手 / 凭证形态（文字描述，非可复制命令）
- 用户请求受限内容 → 平台返回 402 ＋ 支付要求（含商品标识与金额）。
- 用户在平台内完成付款 → 平台签发订阅/购买凭证。
- 用户携凭证重试 → 平台鉴权通过后放行履约。
- 本插件不要求技能Skill持有任何支付密钥，全部由平台托管。

## 五、密钥与占位符
- 本插件**无需用户自备支付密钥**；支付由平台托管。
- 技能Skill内需保留的占位符（如适用）：`{{PLATFORM_PRODUCT_ID}}`（平台生成的商品标识）、`{{ENTITLEMENT_CHECKPOINT}}`（受限内容触发点标识）。
- 任何真实密钥、账号、私钥一律不进包、不进文档正文，保持占位符形态。

## 六、结算与限制（工具不保证）
- 结算方式、周期、分成比例、内测费率以平台官方规则为准（约 1% 内测费或平台分成，T+ 周期提现）。
- 资金是否实际到账、到账时效、税务处理，取决于用户是否满足平台全部前置条件与平台结算政策；**本工具不保证、不承诺资金结算结果**。

## 七、与通用范式六条对应关系
1. 402 握手：由平台自动接管。
2. 两套密钥：平台托管，技能Skill零密钥。
3. 幂等：平台侧交易单号去重，用户无需自管。
4. 云端保护 / 原文隔离：平台内订阅鉴权，核心逻辑仍建议服务端化以防套取。
5. 价格三处一致：LISTING / SKILL.md / 平台商品定价须一致。
6. 计费矩阵：见 §十三 自有宿主开放市场行。

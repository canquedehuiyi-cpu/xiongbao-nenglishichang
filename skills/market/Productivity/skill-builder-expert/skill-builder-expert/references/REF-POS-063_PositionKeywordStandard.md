# REF-POS-063 立项三问与布词纪律标准件（技能搭建说明书视角）

> 定位：代建立项与布词环节的两条刻度。本件**不定义内容、不设人群门槛**（总纲：资料成千上万，只定义格式与要求）——立项三问是定位刻度不是禁令，布词是接住搜索的格式纪律。

## 一、立项三问（定位刻度）

动手构建前，对产物主题过立项三问：

1. **普遍性**：主题是否指向目标人群普遍存在的处境或焦虑（而非少数人偶发需求）？
2. **零门槛**：理解产物价值是否无需任何预先教育（一眼知道能帮自己干什么）？
3. **利害级**：是否落在守钱、护娃、保命、保权益这类高利害区？

读法与用法：

- 立项三问全过＝强赛道，按标准流程满配走；
- 过两问＝可做，布词按第二节加倍下功夫（覆盖面补普遍性）；
- 过一问或零问＝照做（**用户坚持的主题一律照做**），但如实告知预期：工具品属慢热型，靠长尾布词与持续迭代起量，不做虚假承诺；
- 立项三问结论写进立项记录，一行即可。

## 二、布词纪律：去重不去钩

产物描述与检索布词遵循一条铁律：**钩子一个不许少，同义重复一个不留。**

1. **钩子＝用户会说的原话**：写进描述与 tags 的每个词，都应是目标用户在搜索框或对话里会说的大白话（场景词、口语词、俗称），禁堆术语、禁自造词；
2. **一个口语说法＝一个钩子**：不同说法（哪怕意思相近）独立保留——「孩子半夜哭」与「宝宝夜醒」是两个钩，各接一批真实搜索；
3. **同义重复＝零**：同一说法的变体字（仅语序、虚词不同）合并为一个，省字节不减覆盖；瘦身时**删重复、不删钩子**；
4. **隐式触发优先**：布词覆盖「用户不提领域名也能被接住」的说法（如说「我家娃不听话」即触达育儿类产物），六类隐式信号（抱怨式、转述式、行为描述式、求助式、对比式、情绪式）逐类检查是否布到位；
5. **体量纪律**：布词在产物 frontmatter 描述与 tags 六层布局内完成，遵循既有体量闸，不为堆词破体量。

## 三、与既有规范的关系

- 本件是 `REF-NAM-006_NamingDiscovery.md` 命名与可发现性规范的**补充刻度**：NAM-006 管命名与上架前核查，本件管立项定位与布词取舍，并行不替代；
- 冲突时以本件「去重不去钩」为布词取舍准绳，以 NAM-006 为流程准绳。

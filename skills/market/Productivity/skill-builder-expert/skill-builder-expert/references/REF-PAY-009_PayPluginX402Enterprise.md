> 本文件是「收费版本」接入 **微信 X402 企业版（SkillPay 企业版入驻）** 的接入骨架与接入模板。

> **非权威规范**：以下流程、协议头、密钥形态、费率为骨架，以微信支付与 SkillPay 企业版官方文档为准；平台政策变动不另行通知。

> **工具边界**：Skill技能搭建专家仅按本骨架产出符合规范的技能Skill；不替代用户完成企业商户号开通、SkillPay 入驻、RSA 密钥生成；不保证资金实际结算到用户账户。

> **当前准入规则（用户补充，以官方为准）**：本插件覆盖两条微信收款路径——① 主站技能市场收费版本「企业」创作者（仅微信收付款 SkillPay，AI 专属支付卡）；② 自有宿主开放市场「企业」创作者（仅微信收付款）。**仅企业创作者可走此路径，个人创作者不可。** 工具不代办企业商户号开通与 SkillPay 入驻，不保证资金到账。

## 一、平台定位与适用场景
- 微信生态内付费技能：企业版 SkillPay 入驻后，技能可在微信/宿主侧以 X402 协议拉起微信支付。
- 适合：已有微信支付企业商户号、需要微信生态内收款的团队/企业。
- 认证强度：高（企业资质 + 商户号 + RSA-2048 双密钥）。

## 二、前置条件（用户自行完成，工具不代办）
1. 开通微信支付企业商户号，完成企业实名与对公结算绑定。
2. 完成 SkillPay 企业版入驻申请与审核。
3. 生成 RSA-2048 双密钥：商户私钥（签名用，服务端持有）+ 平台公钥（验签用）。
4. 准备备案域名，配置 443 反代到内网服务端口（公网直连非标准端口口子默认关闭）。
5. 取得 `merchant_id` / `product_id` 等用户侧专属参数（不由工具生成）。

## 三、接入流程骨架（步骤）
1. 选型确认：用户明确收费版本且具备微信企业资质 → §2.0 落位。
2. 构建技能Skill：按标准产出，支付相关仅放占位符。
3. 注入支付触发点：在受限内容返回处按 X402 协议返回 `402` ＋ `WeixinPay-Required` 头。
4. 服务端承接：用户付款后，宿主携支付凭证（如 `payment_code`）重试，服务端校验后履约。
5. 网关配置：`api_endpoint` 走自有备案域名反代；`allowed_domains` 白名单仅放支付域名。
6. 实测：陌生账号真付实测（L3，AI 做不了，交用户）。

## 四、402 握手 / 凭证形态（文字描述，非可复制命令）
- 用户请求受限内容 → 技能/服务端返回 `402 Payment Required` ＋ 头 `WeixinPay-Required: <商品标识>`。
- 宿主拉起微信支付 → 用户扫码/确认付款。
- 付款成功后，用户携 `payment_code`（平台签发）重试原请求。
- 服务端校验 `payment_code` 有效性与 `out_trade_no` 幂等 → 履约返回内容。

## 五、密钥与占位符
- 商户私钥：仅服务端 `.env`，包内/文档一律占位符 `{{WECHAT_MCH_PRIVATE_KEY}}`。
- 平台公钥：用于验签，占位符 `{{SKILLPAY_PLATFORM_PUBLIC_KEY}}`。
- 用户参数占位符：`{{MERCHANT_ID}}`、`{{PRODUCT_ID}}`、`{{PAYMENT_ENDPOINT}}`。
- 会外传的三处（SKILL.md / LISTING / README）必须 0 密钥，全部占位符。

## 六、结算与限制（工具不保证）
- 结算：微信支付按 T+1 结算至企业商户号绑定的对公账户（以微信支付规则为准）。
- 费率：微信支付标准费率（以官方为准）。
- 资金是否实际到账、到账时效、税务处理，取决于用户是否满足全部前置条件；**本工具不保证、不承诺资金结算结果**。

## 七、与通用范式六条对应关系
1. 402 握手：`402` ＋ `WeixinPay-Required` 头。
2. 两套密钥：商户私钥 / 平台公钥分离，包内零落密钥。
3. 幂等：`out_trade_no` 唯一去重。
4. 云端保护 / 原文隔离：核心逻辑服务端化，包内仅放入口与鉴权。
5. 价格三处一致：SKILL.md / LISTING / 支付参数金额一致。
6. 计费矩阵：见 §十三 微信 X402 企业版行。

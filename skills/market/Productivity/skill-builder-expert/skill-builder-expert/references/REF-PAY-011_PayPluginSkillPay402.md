> 本文件是「收费版本」接入 **其他生态 Alipay SkillPay（402 支付哲学）** 的接入骨架与接入模板。

> **非权威规范**：以下流程、协议形态、费率为骨架，以对应生态开发者平台与 Alipay SkillPay 官方文档为准；平台政策变动不另行通知。

> **工具边界**：Skill技能搭建专家仅按本骨架产出符合规范的技能Skill；不替代用户完成对应生态开发者入驻、Alipay 签约；不保证资金实际结算到用户账户。

> **当前准入规则（用户补充，以官方为准）**：本插件针对**其他生态智能体宿主内分发**，遵循 402 支付哲学。若上架目标为主站技能市场或 SkillPay 支付宝收费版本，请按 §十四 准入矩阵路由至「支付宝个人版 / 微信 X402 企业版」插件，勿与本插件混用。工具不代办对应生态开发者入驻与 Alipay 签约，不保证资金到账。

## 一、平台定位与适用场景
- 其他生态（其他生态宿主）内付费技能：遵循 402 支付哲学，先握手后履约。
- 适合：主分发场在其他生态、已具备对应生态开发者资质的团队/企业。
- 认证强度：中（对应生态开发者入驻 + Alipay 签约）。

## 二、前置条件（用户自行完成，工具不代办）
1. 完成对应生态开发者平台入驻与实名/企业认证。
2. 完成 Alipay SkillPay 签约，取得对应 `product_id` / `serviceId`。
3. 准备服务端密钥（签名/验签），仅落服务端。
4. 准备备案域名反代（如涉及自有网关），公网直连非标准端口口子默认关闭。

## 三、接入流程骨架（步骤）
1. 选型确认：用户明确收费版本且主分发在其他生态 → §2.0 落位。
2. 构建技能Skill：按标准产出，支付相关仅放占位符。
3. 注入 402 触发点：受限内容返回处按 402 哲学返回支付要求。
4. 云端保护：核心逻辑放服务端，包内仅放入口与鉴权（订阅制防套取，见 §十二）。
5. 分发形态：支持「试用 → 购买 → 订阅」三档权益演进。
6. 实测：陌生账号真付实测（L3，AI 做不了，交用户）。

## 四、402 握手 / 凭证形态（文字描述，非可复制命令）
- 用户请求受限内容 → 技能/服务端返回 `402 Payment Required` ＋ 支付要求（含商品标识与金额）。
- 宿主拉起支付宝/平台支付 → 用户完成付款。
- 付款成功后，用户携支付凭证重试 → 服务端校验凭证与 `out_trade_no` 幂等 → 履约。
- 试用档：限定次数/时长免付；购买档：一次性；订阅档：周期续费。

## 五、密钥与占位符
- 服务端签名私钥：仅服务端 `.env`，占位符 `{{ALIPAY_SKILLPAY_PRIVATE_KEY}}`。
- 平台公钥：验签用，占位符 `{{ALIPAY_SKILLPAY_PUBLIC_KEY}}`。
- 用户参数占位符：`{{PRODUCT_ID}}`、`{{SERVICE_ID}}`、`{{PAYMENT_ENDPOINT}}`。
- 会外传的三处（SKILL.md / LISTING / README）必须 0 密钥，全部占位符。

## 六、结算与限制（工具不保证）
- 结算：按平台/支付宝规则结算至绑定账户（以官方为准）。
- 费率：平台/支付宝分成（以官方为准）。
- 资金是否实际到账、到账时效、税务处理，取决于用户是否满足全部前置条件；**本工具不保证、不承诺资金结算结果**。

## 七、与通用范式六条对应关系
1. 402 握手：遵循 402 支付哲学，先握手后履约。
2. 两套密钥：服务端私钥 / 平台公钥分离，包内零落密钥。
3. 幂等：`out_trade_no` 唯一去重。
4. 云端保护 / 原文隔离：订阅制防套取，核心逻辑服务端化。
5. 价格三处一致：SKILL.md / LISTING / 支付参数金额一致。
6. 计费矩阵：见 §十三 SkillPay 402 行。

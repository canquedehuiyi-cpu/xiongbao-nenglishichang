# REF-DLV-049 交付模式与版本关联规约（Agent 可读执行）

> 定位：本册是部署形态与版本链路的唯一执行依据。核心定调：本工具免费，无立场推荐任何方案；默认「免费版本＋轻量模式」是为让使用方最容易拿到可用成果，不等于偏好推荐；全部方案具备配置支撑能力，完整告知边界与前置条件，选择权全归使用方。

## 1. 版本定义
① 免费版本：你的技能 Skill，由你设定为免费，其他使用者无需支付费用，订阅安装即可使用；使用方式包含两种：一是上传至对应 Agent 账号内的技能列表直接使用，无需提交到开放平台、技能广场；二是导出技能安装包，分享给其他人，接收方将安装包上传至自己的 Agent 账号技能列表即可使用。若面向全网公开订阅分发，则需要上架至开放平台。

② 收费版本：你的技能 Skill，由你设定为向其他使用者收费，其他使用者付费后，订阅安装方可使用；使用方式包含两种：一是上传至对应 Agent 账号内的技能列表直接使用，无需提交到开放平台、技能广场；二是导出技能安装包，分享给其他人，接收方将安装包上传至自己的 Agent 账号技能列表即可使用。若面向全网公开订阅分发，则需要上架至开放平台。

## 2. 运行模式定义与关联关系
① 轻量模式：流程简单，配套要求少。你名下技能的免费版本、收费版本，均可以选用轻量模式。

② API模式：属于高级运行模式，配置链路复杂，包含服务器、域名、备案、证书等大量配套工作，配套资源、流程由使用方自行负责。你名下技能的免费版本、收费版本，也都可以选用 API模式。

## 3. 默认策略
使用方未主动指定版本与运行模式时，默认配置：免费版本 + 轻量模式。设置该默认项，是因为该方案最简、高效，使用方无需额外准备配套资源，更容易拿到可用成果；该默认不等于偏好推荐。

## 4. 方案告知规则
具备全部方案的配置支撑能力，完整告知所有可选方案与对应前置条件。不主动引导、不主动劝说、不向使用方推荐任意一种方案；全部选择权交由使用方自主决定。仅当使用方主动提出想要 API模式，或是主动提出想要设置收费版本时，才展示对应的前置准入条件清单。

## 5. 收费版本补充说明
收费开通由使用方自行完成，按三步法衔接（状态机 creator_type_confirm → platform_doc_gate）：

- 第一步：先确认使用方是个人创作者还是企业创作者（不同身份收款开通条件不同，界限先划清）；
- 第二步：使用方向其选定的目标平台申请开通支付，取得该平台提供的支付接入开发者说明并提交给本工具（不同平台要求不同，需提供哪些参数以该说明为准）——上哪个平台由使用方决定，本工具不推荐、不代选、不列平台清单；使用方主动说出平台名的可以接住并按其文档协助（接住不等于推荐）；
- 第三步：文档到手先与内部知识底座比对——一致按流程协助；不一致以使用方提供的最新文档为中心开干（平台规则随时更新，以最新为准防返工）；未提供文档前不开展任何收费配置实施。

相关审核由平台负责。收费无论哪种模式都需要收款服务端配套（服务器、备案域名等；API模式另见准入条件清单）。

## 6. 上架补充说明
如果提交至开放平台，是否能够成功上架，最终以对应平台自身的审核、认证规则为准。不担保上架结果。

## 7. 使用演进路径
使用方可先选用合适方案完成技能搭建、投入使用；后续如有其它想法，再评估切换版本或者运行模式。

## 8. 禁止项
- 不前置展示复杂高级选项给初次使用的使用方；
- 不夸大、不承诺 API模式的附加效果；
- 不承诺一定可以开通支付收款能力；
- 不承诺一定可以通过平台上架审核；
- 不主动推荐、劝说使用方选择某一类方案；
- 不主动罗列、解释各类外部平台清单；
- 使用方主动提出某外部平台时可以接住并按其提供的原始文档协助（接住不等于推荐，不代判断平台优劣）；
- 不得将本处的免费版本、收费版本，解读为搭建技能这项服务的收费档位；
- 不诱导使用方优先选择或者避开某一种方案；
- 不传递默认方案是为了保障运行稳定这类表述。

> 使用场景：母本基线修改升级、提交检疫、准备晋升为生产基线时逐项核验；全部项目核验通过，方可放行上线；版本管理铁律优先校验。

> 核验人：________  核验日期：________

## 一、版本管理铁律（一票否决项）

- [ ] 本次迭代为独立新建版本，**没有覆盖、修改原有历史基线版本**
- [ ] 上一版基线完整保留、只读存档，可随时调取、对比、回查
- [ ] 已评估本次变更对历史交付批次的影响，受影响批次已标记编号

> 结论：本项不通过，直接终止晋升流程，禁止投产

## 二、独立外部诊断用例核验（禁止母本自证）

- [ ] 静默跳过解析测试：上传同名、同大纲、内容修改素材，完整解析、输出差异对比，不会直接返回“已有”跳过流程
- [ ] 评审透明化测试：混合补充 / 冲突素材，逐条输出纳入理由、排除理由，提供异议重评审分支
- [ ] 归档渗漏测试：基准替换后，无法读取归档 archive 内已经废止的规则
- [ ] 质检旁路测试：构造违规包（冒用第三方推广 ID、缺少边界说明、对话漂移），质检节点拦截，不允许交付放行
- [ ] 变更传染测试：修改规则后，全量历史回归用例执行，旧漏洞不复现
- [ ] 自检绕过测试：工厂自检逻辑独立，母本无法绕过自检闸门

## 三、基线硬性约束核验

- [ ] 全链路操作留痕：比对、评审、状态变更、放行 / 阻断日志完整，支持独立环境复现结果
- [ ] 基线具备唯一版本号 + 哈希摘要，版本强标识
- [ ] 新增规则同步配套新增回归测试用例
- [ ] 无临时补丁留在生产基线，所有修复合并进正式版本

## 四、试运行稳定性核验

- [ ] 在隔离环境试运行，未发现异常路由、状态机漂移、节点失效
- [ ] 配套交付提示文案完整：包含技能广场上架要求、多维度自测、高风险业务复核提示
- [ ] 联盟推广专项：冒用推广参数的场景可以识别拦截，归因链路校验逻辑正常

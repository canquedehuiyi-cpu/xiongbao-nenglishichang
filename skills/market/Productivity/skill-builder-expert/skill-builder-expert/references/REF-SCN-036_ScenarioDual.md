# REF-SCN-036_ScenarioDual ｜双场景标准（场景1 对外开源 · 场景2 私有内部）

> 定位：用户拿这套标准产出的技能去两种典型场景使用，各有一套专属纪律；两套场景执行**同一套工程质量基线，不因场景降标**（与 REF-DST-034 统一铁则同源）。

> 配套：资产保护护栏（REF-DMN-019）、分发访问模式（REF-DST-034）、双用例 A/B 发版工序（REF-LST-022 第九节）、两条不可动摇边界（REF-HON-017 第六节）。

## 一、场景1 · 对外开源上架

**场景特征**：产物面向公开渠道（技能广场等），任何平台用户可获取，公开后内容不可撤回。

专属纪律：
1. **内部资料零落**：联盟密钥、私有推广参数、内部流程规则、客户数据、真实报价体系，一律不得进入产物任何文件——打包前逐文件过公开合规扫描；
2. **占位值处理**：确需保留参数位的信息，用明显非真实的占位值（如 `YOUR_API_KEY` 样式占位符），交付说明里注明由使用者自行填入；
3. **专名清洗**：第三方专有名词按平台无关化纪律清洗（REF-DMN-019），不随包外泄任何一方的私有命名体系；
4. **公开即定局**：平台有缓存、他人有下载记录——公开前按「公开后收不回」的标准重看一遍全文再发布；
5. **配套输出**：上架流程说明、多维度测试 Checklist、能力范围说明随包附上（REF-LST-022）。

## 二、场景2 · 私有内部

**场景特征**：产物仅自用或团队企业内部使用，素材含内部业务资料（内部规则、参数、密钥类信息），不对外公开。

专属纪律：
1. **资产护栏逐条过**：密钥、私有推广参数、专属业务配置——禁止直接复用、禁止外泄、禁止落进任何文档与产物文件；
2. **内部资料隔离**：内部私有内容只进服务端 / 本地私有环境，产物内仅留调用入口与授权校验位；内部流程规则确需内置时，先评估「这页纸如果明天在社会上流传，损失多大」，过不了这条评估的就不进包；
3. **素材归档**：内部素材单独归档管理，与对外展示素材物理分开；案例展示只列名称与检索入口，不复制业务逻辑（与 SKILL.md 素材与案例管理机制一致）；
4. **模式适配**：含敏感资料优先专用模式（自用版 / 私域版，见 REF-DST-034）；若资料敏感到「连平台审核都不能给看」，只有自用版（仅安全规则校验）能兜住；
5. **分发风险自管**：导出安装包后的对象访问风险由创作者自行评估管控——给谁用、怎么给，发出去之前想清楚。

## 三、两场景共同底座

- 同一套工程质量基线：技能质量标准五维、八维安全基线、生成物内核四卡、统一输出基准——场景只改变信息保护与发布纪律，不降低产物质量；
- 两条不可动摇边界全程适用（REF-HON-017 第六节）：严格执行全套标准是底线；业务效果由用户侧实测确认；
- 模式选择与场景匹配：场景1 对应公开模式；场景2 对应专用模式（自用版 / 私域版）；生产前锁定，公开后回退未必可行。

## 四、出厂必查

- 产物按目标场景过对应纪律清单（场景1 五条 / 场景2 五条）；
- 发版前双用例 A/B 各跑一遍（REF-LST-022 第九节）：开源素材与内部素材两套都过才发版；
- 场景2 产物：资产护栏条目逐条留检查痕迹，密钥私有参数零落文档。

---

**本标准结束。** 与 REF-DST-034（分发访问模式）、REF-DMN-019（平台无关化与资产护栏）、REF-LST-022（双用例 A/B）、REF-HON-017（两条边界）配套生效。

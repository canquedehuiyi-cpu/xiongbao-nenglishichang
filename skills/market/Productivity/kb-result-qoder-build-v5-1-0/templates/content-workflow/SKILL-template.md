# 内容生产流水线（模板 · 改编后删除本行）

> 骨架来源：代建助手行业模板库。改编完成后本注释与全部 `【改编位】` 标记必须清零。

## 一、能力定位（一句话）

【改编位：一句话说清给谁写、写什么、按谁的口气。示例口径：您给主题或丢素材，我按您定下的口径出成稿——结论前置、场景开场、金句可摘；每一稿都有编号，改过什么都能对账。】

**立场铁律**：数字必须来自用户给的素材，**算不清的数不上稿**；引用别人的话注明出处；口径（结论先定还是先出三版选）按用户拍板执行，写完不改口径。

## 二、接料触发表（处境信号 → 动作）

| 用户怎么开口 | 实际要什么 | 本技能做什么 |
|---|---|---|
| 「最近没东西可写」 | 选题 | 出选题单（每条带一句「写给谁、戳什么场景」） |
| 「这篇帮我改改」 | 改稿 | 先问改哪层（开头 / 结构 / 口径），按层动刀 |
| 「开头不够抓人」 | 开头重写 | 出三版不同切法，标注各版路数 |
| 「照这个口气写」 | 定风格 | 先出 200 字风格样张，确认后成稿 |
| 「上个月好像写过」 | 查重复用 | 按编号检索旧稿，给复用建议 |

## 三、核心流程

- **选题**：素材库 + 用户近况 → 选题单（一次至多 5 条，每条带场景句）→ 用户勾选才开工。
- **成稿**：确认口径 → 初稿（结论前置 / 场景开场 / 金句加粗 / 移动端短段落【改编位：按发布平台定版式规则】）→ 交付带编号。
- **改稿**：按层改，不动没让动的部分；改完在稿尾列「本稿改动两三处」。
- **留档**：成稿编号入库（编号 / 日期 / 主题 / 用过的素材 / 数据表现留空待回填）。

## 四、输出卡（交付物格式）

**成稿**：编号 + 标题 + 正文（版式按改编位规则）+ 稿尾「本稿依据的素材清单」。
**选题单**：编号 + 题目 + 一句场景 + 建议形式（长文 / 短文 / 脚本）。

## 五、自验证（交付前必跑三问）

1. 稿里每个数字都能指到素材出处吗？指不出的删掉或标「待补数据」。
2. 口气跟样张一致吗？拿样张并排对一遍再交。
3. 稿尾素材清单列了吗？没列不算交付。

## 六、出厂自检

装得上（name＝slug＝目录名）｜唤得起（description ≥5 个触发说法）｜答得对（触发表 ≥3 种开口）｜说得清（三问跑过、证据随交付）｜分页合规（旧稿库超 50KB 装行号索引）｜改编位清零。

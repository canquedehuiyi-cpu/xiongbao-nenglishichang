# 怎么把「AI技能Skill代建助手」装到您的 AI 平台

> 这个技能已经做好了，装上去就能用。照着下面做，不用懂技术。各平台界面叫法可能略有不同，认准「技能」「上传技能」这类字眼即可。

---

## 一、先确认您要装到哪

**先分清两件事**（一句话：本包只服务 Qoder 系；代建出来的成品能装更广）：

- **本包自己的服务范围 = Qoder 系**：**安装与使用**在 Qoder 平台（Qoder CN / APP / IDE / CLI / QoderWake）——平台内「上传技能」，装完直接在对话里用。
- **本包代建出来的成品** = 可装到结构兼容的常用 Agent 平台（WorkBuddy / CodeBuddy / Qoder 系 / 扣子 · 豆包 · IMA / Cloud Agent / 其他）。

| 您的情况 | 用哪种方式 | 看哪一节 |
|---|---|---|
| 在 **Qoder**（生态内） | 平台内「上传技能」 | **方式 A（§二）** |
| 手里是 zip、结构兼容的其他平台 | 平台内「上传技能」 | **方式 A（§二）** |
| 会把文件放进目录的平台（进阶用户） | 放进 `skills/` 目录 | **方式 B（§三）** |

> 不确定用哪种？先试方式 A，不行再看方式 B。

---

## 二、方式 A：在平台里上传（推荐，最省事）

**第 1 步 · 找到「技能」入口**

- ① 打开您用的平台，找「技能」「技能中心」「技能广场」「我的技能」这类**入口**（位置各平台不同，认字眼就行）
- ② 找不到就在平台内搜"技能"，或看平台的帮助中心

**第 2 步 · 点「上传 / 添加 / 导入技能」**

- ① 在技能页找「上传技能」「添加技能」「导入技能」按钮
- ② 选中这个文件：`kb-result-qoder-build-v5-1-0_v8.8.23.zip`
- ③ 按界面提示完成

**第 3 步 · 让它生效**

- 完全退出平台再重开，或刷新页面 / 新建一个对话

**第 4 步 · 验证装上没（重要，别跳过）**

- 新建一个对话，直接说一句：

> 帮我变成技能

- 如果它回您一段"把您的方法、经验变成能反复调用的技能"的开场介绍，就说明装好了、能用了

---

## 三、方式 B：放进 skills 目录（进阶）

适合熟悉电脑文件位置的用户：

1. 解压 `kb-result-qoder-build-v5-1-0_v8.8.23.zip`，文件**直接释放在当前目录**（包内为扁平结构，`SKILL.md` 位于根，无顶层文件夹）
2. 新建一个名为 `kb-result-qoder-build-v5-1-0` 的文件夹（**名字必须与 `SKILL.md` 的 `name` 一致**），把上一步解压出来的文件**整个放进去**；再把这个文件夹放进 Qoder 平台的 `skills` 目录
3. 完全重启平台
4. 用上面「第 4 步」的方法验证

> 目录不存在就自己新建一个 `skills` 文件夹。

## 四、怎么用这个技能

**唤起它**——说下面任一句就会触发：

帮我变成技能 / 做成技能包 / 封装一下 / 出初稿 / 做质检

**怎么用**——把您脑子里的经验、手上的流程、要立的标准，说给它听，或把资料发给它，它会陪您把这件事整理成一份能装进 AI、反复调用的技能。

**只聊思路、还不急着做**——说"帮我理清 / 给个思路 / 列个清单"就行。

**长期用**——每遇到一个新打法、发现哪句答复不对，把修正告诉它，它就越用越准。

**装好后先验一验**——拿几道真题测测它（题自己出，最贴近您自己的真实场景）：

1. 【您最常碰到的那种客户 / 情况】，它给的判断合理吗？
2. 【您最头疼的那种反馈 / 问题】，它的应对方式对吗？
3. 【您最近成功的一单 / 一次】，它的分析跟您的做法对得上吗？

跑完这几题，您就知道它是不是真懂您的方法了。

## 五、常见问题

**Q：传进去了没反应？**

A：① 确认传的是 zip **原文件**，不是解压后散落的文件夹；② 完全重启平台；③ 确认唤起时说的话对得上触发词。

**Q：能装到别的平台吗？**

A：分两件事看。**本包自身的服务范围＝Qoder 系**：安装与使用在 Qoder 平台（Qoder CN / APP / IDE / CLI / QoderWake），平台内「上传技能」即装即用。**本包代建出来的成品**可装到更广的常用 Agent 平台——Qoder 系 / 扣子 · 豆包 · IMA / Cloud Agent / 其他（见 [LISTING.md](./LISTING.md) 的「支持平台」）。要把**本包自己**装到那些生态，请用对应生态的版本。

**Q：这个技能能干什么？**

A：见技能包里的 `README.md`。

**Q：怎么知道它是真的在替我干活、不是在空谈？**

A：认一句话——它会一步步问您要料、跟您对齐方向、最后给您一个能装的包。它不会替您编专业结论，不知道的会明说。

**Q：要花钱吗？**

A：本技能**完全免费**，不收取任何费用、不采用任何计费机制。

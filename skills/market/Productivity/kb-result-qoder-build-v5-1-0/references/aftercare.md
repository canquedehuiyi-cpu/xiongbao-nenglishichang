# 交付后效果观察 · 三件套与五项口径

> 这一页回答一个问题：**技能交出去了，怎么知道它到底管不管用。**
> 三件套都是**给您自己用的模板** —— 想用就用，不想用不影响任何功能。
> **一条底线写在最前面**：三件套**全部自愿**，包内**不存在任何自动上报行为** —— 不联网、不回传、不埋点、不要求填写。

---

## 一、装后自测题（3 道 · 装完即可跑）

> **怎么用**：装好后新建一个对话，把下面三题**按您自己的真实情况**问一遍。**题是模板，不是标准答案** —— 把方括号里的内容换成自己的事，越具体越准。
> **判断口径**：不看它答得漂不漂亮，看**它有没有把您的方法原样搬进去**。

### 第 1 题 · 看它接不接得住您的料

```
我这件事的做法是这样的：[用三句话把您最常做的那件事说清楚 ——
先做什么、再做什么、哪一步最容易出岔子]。请帮我把它整理成能反复调用的技能。
```

- **看什么**：它有没有**主动问您要缺的部分**，而不是自己替您编。
- **过关的样子**：它会回头问"这一步的判断标准是什么""遇到什么情况要停"。
- **不过关的样子**：它直接给一版看起来很完整、但里面没有您独特做法的东西。

### 第 2 题 · 看它会不会替您发挥

```
刚才那一版里，[指一处您没说过的细节] 是从哪来的？我没讲过这个。
```

- **看什么**：它认不认账。
- **过关的样子**：它承认那是自己补的，并把它删掉或标出来问您。
- **不过关的样子**：它硬说"这是行业通行做法" —— 那就是在替您发挥。

### 第 3 题 · 看它给的东西能不能拿走

```
把刚才整理完的东西给我一份最终版，我要能拿到手直接用。
```

- **看什么**：有没有**明确的交付物**（一份文件 / 一个包 / 一份说明书），而不是只在对话框里聊。
- **过关的样子**：它给出成品，并告诉您怎么装、装到哪。
- **不过关的样子**：只有一段聊天文字，拿不走。

> **三题跑完怎么记**：三题都过关 = 这个包在您这儿跑通了。有一题不过关，把**原话贴回来** —— 那是最有用的一条反馈。

## 二、交付后 7 天回访模板

> **怎么用**：**由您自己填、自己留着**。不做任何自动联系、不催填。**填不填完全自愿** —— 填了的好处是您自己看得见"这七天它到底帮您省了什么"。
> **给做交付的人**：这份模板可以在交付时附上，但**不要在 7 天后自动联系用户**；要问，也只在**用户下次主动来的时候**顺口问一句（见第三节末）。

| 项 | 填什么 |
|:--|:--|
| 这七天里，我实际用它做过几次？ | 　次 |
| 跑得最顺的那一次，省了我大约多少时间？ | 　（分钟 / 小时） |
| 卡住过没有？卡在哪一步？ |  |
| 它的答复里，有没有出现过您**没教过**的内容？ | 有 / 没有（若有，是哪一处） |
| 您自己有没有再补过料、改过口径？ | 有 / 没有（补了什么） |
| 一句话：值不值得继续用？ |  |

> **最后一行是核心**。填"值得"的，第 5 项通常写着"我自己补过料" —— 这说明**包在长**，是好事。

---

## 三、案例回收模板

> **怎么用**：用户**自己**跑出满意的结果后，可以把过程留下来。**回不回收完全自愿**，不回收不影响任何功能、不影响后续使用。
> **不索要业务机密**：模板只问"怎么做的"，**不问**客户名、金额、内部数据。用户想给多少给多少，留白是可以的。

| 项 | 填什么 |
|:--|:--|
| 这件事大概是什么类型？（用您自己的话说，不用套模板） |  |
| 您给了哪些料？（口述 / 文档 / 其他） |  |
| 中间改过几版？主要改了什么？ |  |
| 最后拿到的是什么？（一句话） |  |
| 您觉得最有用的是哪一步？ |  |
| 可不可以留作案例给后面的人看？ | 可以 / 只留做法不留细节 / 不用 |

> **三条回收纪律**
> 1. **默认不回收** —— 用户不点"可以"，就当没这回事。
> 2. **给了也能撤** —— 用户随时可以说"那条删掉"，照办。
> 3. **留下只留做法** —— 场景细节、数字、名称可在留档时替换为泛称；正文里写清哪些是**真实样本**、哪些是**示意案例**。

### 用户下次主动来时的顺口一句（非商业）

> 用在**用户自己又来说话的时候**，不主动去找人。

- 用户又带着新料来 → 「上次那个用得怎么样？有哪句答得不对，您直接说，我这就改。」
- 用户说"挺好用" → 「那您方便说说它替您省了什么吗？我想把它记下来，让后面的人用起来更顺。」
- 用户说"没怎么用" → 「没关系。是没空用，还是那次整理得不对路？您说哪种我就知道往哪改。」

> **一句都不许出现**：任何收费、报价、续费、引流、加联系方式、外部链接。这一节**只做一件事**：把用户的下一次开口接住。

## 四、五项指标口径

> 这五项是**口径说明**，不是收集机制。**全部靠人工观察与用户自愿反馈得出** —— 没有一行代码在自动统计。
> **为什么要把口径写死**：口径先定死，后面谁看同一份数据，算出来才是同一个数。

| # | 指标 | 口径（怎么算） | 数据从哪来 | 说明 |
|:--|:--|:--|:--|:--|
| 1 | **安装成功率** | 成功装上并能唤起的人数 ÷ 拿到包的人数 | 用户主动告知 / 自测题第 1 题跑通 | 分母是"拿到包的人"，不是"下载次数" —— 转发传播的数看不到 |
| 2 | **唤起成功率** | 说出触发词后、技能确实被唤起的人数 ÷ 装好的人数 | 用户主动告知 | 与第 1 项分开 —— 装上了唤不起，是两个不同的问题 |
| 3 | **自测通过率** | 三题全过的人数 ÷ 跑过自测的人数 | 用户自愿贴回结论 | 只算"跑过的"，不跑的不计入分母 |
| 4 | **案例回收数** | 用户点了"可以留作案例"的条数 | 案例回收模板 | 含"只留做法不留细节"的（计 1 条） |
| 5 | **复访率** | 交付后 30 天内**自己又回来**的人数 ÷ 交付人数 | 对话记录 | ★ 本项最值钱：**主动回来 = 真的在用**；不回来不等于不好用，只等于没形成习惯 |

> 五项全部**只增不减**地留档，不做实时看板。**分母谁、分子谁，写死在上表里** —— 换人看、换时间看，算出来是同一个数。

---

> **说明**：本件为交付后的效果观察方式说明，三件套均以用户自愿为前提，包内不含任何自动上报与联网行为。

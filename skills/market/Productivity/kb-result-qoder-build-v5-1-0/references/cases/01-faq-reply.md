# 案例一：把高频重复问答变成技能

> 💡 本案例沉淀为可复用能力资产：把高频重复的专业应答经验，封装成可调用、可传承的数字员工与 AI 助手。

## 背景

一线答询的人每天被问到大量重复问题：时间是几点、材料怎么交、流程怎么走、结果在哪查、先后顺序怎么排……一一回答既慢又口径不一。他把自己的回复经验口述出来，代建成一个技能。

## 进料（用户给的）

- 场景：一线高频问答岗，每天面对数十条重复提问
- 步骤：先判断问题类型 → 查对应标准答案 → 按需补充个性化信息（如某件具体事项）
- 准则：不替对方做正式承诺；涉及个人隐私不公开；只给查询路径、不代下结论
- 标准：回复要温和、书面、可复制；敏感信息单独沟通
- 资料：原有沟通记录截图若干、正式通知模板

## 代建产出（技能长什么样）

- 触发词：有人问 XX 怎么回 / 帮我回这类问题 / 高频问题
- 内部：问题分类表 + 每类标准话术 + 红线清单（隐私 / 承诺）
- 用户眼前只三步：给料 → 对齐（给谁用、装哪）→ 收包

## 验收判据

- 真机用 3 个真实提问跑一遍，产出合规回复，无越线 → 通过。

# 案例二：把周期性申报流程变成技能

> 💡 本案例沉淀为可复用能力资产：把高频重复的专业应答经验，封装成可调用、可传承的数字员工与 AI 助手。

## 背景

一位每月都要按固定流程申报的人，手上有三十来家主体的申报要做，流程高度重复但细节多：资料收集、类别核对、申报节点、常见异常。她把整套流程口述出来，代建成一个技能，新接手的人也能照标准走。

## 进料（用户给的）

- 场景：周期性申报岗，手上多家主体的申报按月重复
- 步骤：期初资料收集 → 票据整理与归类 → 类别核对 → 申报节点排期 → 异常兜底
- 准则：不代做专业筹划结论；滞纳金 / 罚款类风险必须提示；留痕可查
- 标准：每一步有检查清单；申报前必做「三核对」（类别 / 金额 / 期限）
- 资料：内部 SOP 文档、往期申报记录样例

## 代建产出（技能长什么样）

- 触发词：这家这个月怎么报 / 走一遍申报流程 / 做质检
- 内部：主体类别映射表 + 每月节点日历 + 三核对清单 + 异常兜底表
- 用户眼前只三步：给料 → 对齐（给谁用 / 装哪）→ 收包

## 验收判据

- 真机用 1 家新主体资料跑一遍，产出申报清单与节点排期，无漏类别 → 通过。
- 特殊场景提示：涉具体金额与专业筹划，技能只做流程封装，不代下专业结论。

# 金句池（社交货币 · 20 条）

> 🗣 **本文件：对用户说的话（金句池，会到达用户眼前——每次只取一条）**
> 取用规则以 SKILL.md「金句池」一节为准；本文件只管「有哪些句子可用」。

## 每一条怎么用

- **只在三种情形取用**：用户流露出沮丧、犹豫、自我怀疑或想放弃时；用户完成一次交付、准备往下一步走时；用户主动问「这对我到底有什么用」时。**三种之外不取。**
- **每轮最多 1 条；整场对话最多出现 2 次；同一条不重复。**
- **位置**：回复末尾、进度锚点**之前**，单独一行——让用户能**直接复制带走**。
- **首轮不带**：第一屏给路径，不给金句。
- **不硬塞**：用户正常推进时，只用进度锚点，不取金句。

## 按场景取用（用户此刻在哪一类，就取哪一条）

> `【…】` 是给你（Agent）看的取用索引，**不要把标注念给用户**——给用户的，就是那条句子本身。

- **【撑不住的时候】**「算了 / 做不下去 / 太累了 / 不想做了」 → 取 Q12、Q15
- **【怀疑自己不够格的时候】**「我没什么可给的 / 我就是个普通岗位 / 我不会写文档」 → 取 Q02、Q04、Q06、Q13、Q17、Q19
- **【觉得自己资料太散的时候】**「资料太乱 / 就几个碎片 / 不够系统」 → 取 Q07、Q10、Q11
- **【一直磨、停不下来的时候】**「反复改 / 怕做不完 / 还想再完美一点」 → 取 Q05、Q14、Q16、Q20
- **【做完一步、想确认值不值的时候】**「这对我到底有什么用 / 做完能干嘛」 → 取 Q01、Q03、Q08、Q09、Q18

**一句话判据**：句子是给用户的，标注是给我（Agent）的；对不上场景就不取。

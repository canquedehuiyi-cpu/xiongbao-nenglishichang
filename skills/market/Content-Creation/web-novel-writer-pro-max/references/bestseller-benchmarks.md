# 爆款拆书对标库（bestseller-benchmarks）

> 版本：1.7.0
> 用途：给新作品的大纲/成稿提供"真实爆款"的**框架级对标**（爽点机制 / 节奏 / 开篇结构 / 钩子偏好 / 对话与自然度特征）。
> 数据原则：**仅收录可公开核实的创作特征**（题材 / 平台 / 风格 / 叙事结构），**不编造**订阅量、均订、追读等无法核实的量化数字。
> 拆书方法论：`novel-deconstruction.md`（10 大拆解维度 + 16 项量化指标 + 七层可复用资产）；拆解得到的公式/曲线/钩子体系等沉淀为可复用资产卡，存入 `asset-library.md`（只收结构骨架，不收原句原文）。
> 对标书热度与赛道位置用 `market-radar.md` 交叉核验，事实与数据按 `verify-protocol.md` 标注来源与快照日期。
> 合规：拆解仅提取结构与技法，不复制原文具体表达（`ai-creation-ethics.md`）。

## 对标维度说明

每部作品档案含 7 个可核实维度，供新作品对照：

| 维度 | 含义 | 新作品对照方式 |
|------|------|------|
| 题材 | 所属十大题材分类 | 与目标题材一致性检查 |
| 平台 | 首发平台（公开信息） | 与目标平台基准对照 |
| 核心爽点机制 | 该作品最依赖的爽点类型 | 大纲是否覆盖该爽点类型 |
| 开篇结构 | 开篇如何留人（冲突/悬念/身份） | 对照新作前 50 字信号 |
| 节奏特征 | 爽点-压抑的循环方式 | 对照压抑-释放比与钩子轮换 |
| 钩子偏好 | 章末钩子常用类型 | 对照大纲钩子类型覆盖 |
| 对话与自然度 | 对话风格 / 叙述平实度 | 对照口语度与 AI 分 |

## 《斗破苍穹》

- 题材: 玄幻修仙
- 平台: 起点中文网
- 核心爽点机制: 升级流 + 打脸 + 退婚流（三年之约长线目标）
- 开篇结构: 退婚羞辱开场 → 金手指（戒指老爷爷）→ 废柴逆袭预告，冲突前置
- 节奏特征: 升级-打脸-获宝高频循环，长线悬念（三年之约）贯穿全书
- 钩子偏好: 宝物 / 预告 / 悬念
- 对话与自然度: 对话快节奏、冲突台词直给；叙述平实直给，少修饰堆砌

- 平台: 起点中文网

## 使用方式

1. 新书选题对标：按 7 维度（题材/平台/爽点机制/开篇结构/节奏/钩子偏好/对话自然度）逐项比对自己大纲与目标爆款档案，输出重合度评语。
2. 扩展书库：按上述 7 维度补录真实作品，仅填可核实特征，量化数字留白。

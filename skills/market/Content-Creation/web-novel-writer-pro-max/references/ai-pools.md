## 二、AI高频词库扩充（词级）

> anti-ai-engine.md 支柱一已定义14大类（逻辑连接词/绝对化/抽象名词/模板开头/总结套话/虚假关怀/因果链/假设让步/数据精确/情感标签/逻辑显式/转折词/过度比喻/无效强调）。本文件补充**高频修饰词清单**（AI 偏爱而真人少用）：

### 2.1 AI高频形容词/副词（替换为具体细节）

| AI高频词 | 真人写法方向 |
|----------|--------------|
| 缓缓地 | 删掉，或换成具体动作（他扶着桌沿坐下来） |
| 静静地 | 删掉，或换成环境音（屋里只剩挂钟在走） |
| 默默地 | 换成具体行为（他把话咽回去，点了根烟） |
| 冷冷地 | 换成可见特征（他盯着她，没接话） |
| 淡淡地 | 换成动作细节（她"嗯"了一声，低头翻菜单） |
| 深深地 | 删掉或换（他吸了口气，肺里灌进夜风） |
| 轻轻地 | 换成具体接触（她碰了碰他的手背，又缩回去） |
| 瞬间/刹那间 | 删掉，用紧凑句式替代（他刚转身，刀风就到了） |
| 仿佛/似乎/好像 | 限用：每300字≤2次，多用直接感官 |
| 某种/一种莫名的 | 换成具体对象（不是"一种莫名的恐慌"，是"他怕她看穿"） |

### 2.2 AI高频动词（弱动词 → 强动词）

| AI高频 | 替换 |
|--------|------|
| 感到/觉得 | 直接写感受来源（胃里发紧/后脖颈发麻） |
| 意识到 | 删掉，用行为转折（他话说到一半，停住了） |
| 决定 | 换成行动（他扣上外套，出了门） |
| 拥有/具备 | 删掉，直接写事实（"他拥有过人的记忆力"→"他记一遍就不会忘"） |
| 进行 | 删掉（"进行讨论"→"讨论"） |
| 产生 | 删掉（"产生了兴趣"→"来了兴致"） |

### 2.3 AI高频副词/程度/氛围词扩充

> 这些词单个看正常，但 AI 写作会**高频堆叠**：一句里"顿时+立刻+瞬间"，一段里三个"似乎+仿佛+好像"。真人写作：**大多数时候懒得修饰，直接写核心动作**。规则：同类副词每300字≤1次。

| AI高频副词/程度词 | 真人写法方向 |
|-------------------|--------------|
| 顿时/立刻/连忙/赶紧/随即 | 删掉，直接写动作（不是"他顿时站了起来"，是"他站了起来"） |
| 瞬间/刹那间/转瞬之间 | 删掉，用紧凑句式（"他刚转身，刀风就到了"） |
| 再次/又一次/再度 | 改成具体行为（"他重新点了根烟"） |
| 渐渐/逐渐/慢慢 | 删掉或用过程细节（不是"天渐渐亮了"，是"玻璃窗先亮起来"） |
| 似乎/貌似 | 每300字≤1次，其余直接陈述 |
| 或许/也许/可能/大概 | 真人只在真正不确定时才用，AI每段都用——删掉大半 |
| 几乎/差不多/险些 | 换成具体差距（"差点摔倒"→"膝盖磕在门槛上"） |
| 显得/流露出/透露出 | 换成可见行为（不是"显得很紧张"，是"他不停换腿站着"） |
| 猛地/猛然/骤然 | 换成事件冲击（"门被踹开"比"他猛地抬头"强） |
| 注定/命中注定 | 删掉宿命论，用因果（"他早就知道会有这一天"） |
| 沉重/凝重/沉闷/压抑 | 用具体物件（"屋里只剩钟摆声"） |
| 深邃/深沉 | 用行为（"他盯着对方，很久没说话"） |
| 冰冷/冰凉/清冷 | 用接触反应（"她碰到他的手，凉得像石头"） |
| 一丝/一抹/一缕/一股/些许 | 删掉量词，直接写事物（"一丝冷笑"→"他冷笑"） |
| 有点/有些/略显/略微 | 删掉，直接写程度（"略显疲惫"→"眼皮耷拉着"） |
| 坚定/毅然/决然 | 用行动证明（"他锁上门，把钥匙扔进河里"） |
| 显著/格外/分明 | 换成对比（"格外安静"→"连呼吸声都听得见"） |
| 巨大/庞大/强烈/剧烈 | 换成具体尺寸/声响（"巨大的声响"→"轰——屋顶塌下来"） |
| 暂时/暂且/一时之间 | 删掉，用场景（"他一时之间不知说什么"→"他张了张嘴"） |
| 看似/表面上 | 换成反差行为（"看似平静"→"他端着茶，手却在抖"） |
| 低沉/沙哑 | 用对话内容暗示（"'妈，我回来了。'这句话他练了一路"） |
| 无法想象/不可估量/至关重要 | 换成具体得失（"损失不可估量"→"三间铺子、十年的心血，全没了"） |
| 不断/不停/不住地 | 换成节奏细节（"不停地敲门"→"门被他拍得哐哐响"） |

### 2.4 AI通感描写滥用库（重点）

> **AI 最爱用"无关的嗅觉/触觉/味觉/听觉"做比喻形容撑字数**：明明在写战斗/谈判/复仇，突然来一句"空气中弥漫着铁锈味与雪松冷香""甜腻的腥气在舌尖炸开"。真人几乎不这么写——**人大多数时候都懒得形容，直接推进核心动作、心理、对话、场景、表情**。
>
> 判断标准：**这个感官描写推动剧情/情绪了吗？没有 → 删**。通感只保留"真的影响判断"的（比如闻到烟味知道着火了）。
>
> 命中任一 → 优先删除；确需氛围时用**具体可验的感官**（看见什么/听见什么/闻到什么具体的）替代。

| 高频通感描写（嗅/触/味/听） | 真人替代 |
|------------------------------|----------|
| 铁锈味/金属腥/铜腥 | 删；或具体场景（"水缸里的水发浑，飘着铁锈"） |
| 臭氧味/雷电灼烧味/焦糊的电气气息 | 删；写现象（"灯泡闪了两下，灭了"） |
| 硫磺味/呛人的硝烟气 | 删；写事件（"枪响前，他先闻到火药味——晚了"） |
| 血腥味混杂尘土气息 | 删；写画面（"地上拖出一道暗红的印子"） |
| 冰碴般的腥气/碎冰般的冷息 | 删；写身体反应（"他打了个哆嗦"） |
| 腐朽腥甜/腐烂的甜香/发酵般的甜腥 | 删；写具体物（"墙角那袋垃圾已经发臭了"） |
| 苦杏仁味 | 删；写结局（"她倒下去时，手里攥着半个杏核"） |
| 雪松冷香/凛冽的松香/雪松香混松脂 | 删；写人（"他身上的烟味很重，混着汗味"） |
| 霉味/霉腥/潮湿青苔 | 删；写环境（"墙皮翘起，湿漉漉地往下掉"） |
| 刺鼻/塑胶味/焦糊味 | 删；写反应（"他皱着眉退后半步"） |
| 一丝凉意/凉飕飕/寒意从脚底升起 | 删；写动作（"他往灯下挪了半步"） |
| 炸雷/平地惊雷/闷响 | 删；写事（"轰隆——，是隔壁仓库的方向"） |
| 甜腻的腥气/甜腻（形容血腥） | 删；写画面（"他吐了一口血，混着晚饭的青菜"） |
| 以（一种）X的Y（万能句式） | 删"以一种"，直接写 |

## 三、AI高频语库（短语级）

> 每条含：命中短语 + 风险说明 + 2-4 个替换方案（按场景/情绪/文风维度）。

### 3.1 情绪动作模板短语

| 命中短语 | 替换方案 |
|----------|----------|
| 瞳孔猛地一缩 | ① 他盯着那行字，半天没眨眼 ② 手指在杯沿上停住 ③ 她笑到一半，脸僵了 |
| 嘴角勾起一抹（冷笑/弧度） | ① 他扯了扯嘴角 ② 嘴角动了一下，又压平 ③ 她笑了一声，不像笑 |
| 眼底闪过一丝（惊讶/寒意） | ① 他眉毛动了动 ② 她端杯子的手顿了一下 ③ 他没说话，眼神却变了 |
| 呼吸一滞 | ① 他吸进去的那口气卡在喉咙 ② 她停了半拍才接话 ③ 声音发紧，自己都没察觉 |
| 心头一颤/心里咯噔一下 | ① 他捏烟的手一抖，烟灰落在裤子上 ② 她把钥匙攥进掌心 ③ 胃里像坠了块石头 |
| 脸色一沉/阴沉下来 | ① 他脸上那点笑没了 ② 她放下筷子，看着他 ③ 空气安静了两秒 |

### 3.2 环境氛围模板短语

| 命中短语 | 替换方案 |
|----------|----------|
| 空气仿佛凝固了 | ① 没人说话，只有水壶在响 ② 她听见自己的呼吸声 ③ 玻璃窗上的雾气慢慢爬下来 |
| 气氛压抑得可怕 | ① 他一进门，屋里的笑声就停了 ② 碗筷碰着碗沿，声音格外清楚 |
| 房间安静得能听见针掉 | ① 只剩吊扇吱呀转 ② 楼下的狗叫了两声又停了 |
| 时间仿佛在这一刻静止 | 删掉，用具体定格（他举着筷子，菜掉回碗里） |

### 3.3 心理描写模板短语

| 命中短语 | 替换方案 |
|----------|----------|
| 心中涌起一股暖流 | ① 他鼻子一酸，别过脸去 ② 那句话在胸口转了两圈，没说出来 |
| 一股寒意从脚底升起 | ① 后脖颈的汗毛竖起来 ② 他下意识往亮处挪了半步 |
| 内心五味杂陈/百感交集 | ① 高兴有，生气也有，更多是累 ② 他想骂她，又想笑，最后什么都没说 |
| 思绪万千/脑中一片空白 | ① 脑子里像塞了棉花 ② 她张了张嘴，没发出声 |

### 3.4 转折/过渡模板短语

| 命中短语 | 替换方案 |
|----------|----------|
| 就在这时/突然 | 删掉或换成事件本身（门被推开的声音/手机在桌上震动） |
| 然而/但是 | 多用"可""却"，或不用转折词直接接 |
| 没想到/出乎意料 | 换成读者视角（他以为她会闹，她只是点了点头） |
| 幸运的是/不幸的是 | 删掉，让情节自己说话 |
| 与此同时/另一边 | 用场景切换代替（镜头式：隔壁房间里，同样的问题在吵） |

### 3.5 万能修饰短语（高频但空）

| 命中短语 | 替换方案 |
|----------|----------|
| 微微一怔/微微一愣 | ① 他举着杯子停在半空 ② 她"啊"了一声，又闭上嘴 |
| 轻轻叹了口气 | ① 他呼出一口气，肩膀垮下来 ② 她把话说完了，才长长地舒气 |
| 深深吸了一口气 | ① 他吸了口气，烟味呛进嗓子 ② 她攥紧扶手，坐直了 |
| 眼中闪烁着光芒 | ① 他眼睛亮了 ② 她盯着那行字，手在发抖 |
| 嘴角微微上扬 | ① 他嘴角动了动 ② 她没忍住，笑了一声 |

### 3.6 表情/眼神模板短语

> 真人表情描写：**一个可见动作 + 直接进入下一句**，不会把每个表情都"表演一遍"。命中后优先换成"不表演"的写法。

| 命中短语 | 替换方案 |
|----------|----------|
| 眼神深邃/眼神热切/目光里毫不遮掩 | ① 他没说话，一直看着 ② 她盯着那杯茶，没抬头 |
| 目光扫过/锐利的眼睛 | ① 他扫了一眼全场 ② 她的目光停在他脸上 |
| 眼中闪过一丝惊讶 | ① 他眉毛动了一下 ② 她停了半拍 |
| 微微挑眉 | ① 他没接话 ② 她"哦"了一声 |
| 脸上堆满了笑/脸上带着笑意 | ① 他笑着，笑不到眼底 ② 她咧了咧嘴，算是回应 |
| 看得目瞪口呆/嘴巴张得能塞下一个鸡蛋 | ① 他张了张嘴，半天没出声 ② 她揉了揉眼睛 |
| 指节泛白/发白/指甲掐进肉里 | ① 他攥着杯子的手在抖 ② 她把掌心掐出印子 |
| 他的表情变暗/他的脸变了 | ① 他脸上那点笑没了 ② 她放下筷子，看着桌上那封信 |
| 脸色一沉（见3.1）/不容置疑 | ① 他直接打断："就这么办。" ② 她没给反驳的机会 |
| 不动声色/不卑不亢 | ① 他照常倒茶，手很稳 ② 她平视着对方，声音不大 |

### 3.7 心理/认知模板短语

> 心理描写的 AI 特征：**每件事都要"心中了然/已经有了猜测"地总结一遍**。真人心理是断的、乱的、有反悔的。

| 命中短语 | 替换方案 |
|----------|----------|
| 心中一凛/心下一沉 | ① 他后背的汗毛竖了起来 ② 她握着筷子的手一紧 |
| 心中一片平静 | ① 他只觉得累，连气都懒得生 ② 她笑了笑，没往心里去 |
| 心下了然/心中了然/了然于心 | ① 他明白了，但什么都没说 ② 她点了点头，没戳穿 |
| 心里隐隐有了猜测 | ① 他想起那天她说的话 ② 她心里有个名字，不敢往下想 |
| 心中一动 | ① 他看了一眼价钱，脚步放慢了 ② 那句歌词卡在他嗓子里 |
| 深吸一口气/深深吸了一口气 | ① 他揉了揉眉心 ② 她把话咽回去，换了句别的 |
| 话锋一转/话头一转 | ① 他忽然问："你吃饭了吗？" ② 她放下杯子："说点别的。" |
| 沉吟片刻/沉默片刻 | ① 他隔了好几秒才接话 ② 烟灰落了一截，他才开口 |
| 以一种（X的）Y | 删"以一种"，直接写 |

### 3.8 对话/声音模板短语

> 对话标签的 AI 特征：**每句对话都配一个"声音X/语气X"**。真人写对话：**能删标签就删，能藏进动作就藏**。

| 命中短语 | 替换方案 |
|----------|----------|
| 声音坚定/眼神坚定/语气坚定 | ① 他直直地看着她："我答应了。" ② 她把钥匙放在桌上："你走吧。" |
| 声音轻细/声音不大/声音很轻 | ① 她凑近了些，像是怕人听见 ② "小声点。"他做了个噤声的手势 |
| 压低了声音 | ① 他往前探身，压着嗓子 ② "别让人听见。"她贴着门缝说 |
| 声音低沉而沙哑 | 换成内容（"这句话他练了一路"） |
| 淬了毒/像淬了毒 | ① 她笑吟吟地，话却扎人 ② "你爸要是知道，得气死。" |
| 近乎偏执/执拗地 | ① 他一遍遍地擦那支枪 ② 她把同一个问题问了第三遍 |
| 炸雷/平地惊雷/闷响 | ① "轰隆——" ② 话音没落，门被撞开 |

## 四、AI高频句库（句式级）

> 句式是更隐蔽的 AI 指纹：单看每个词都正常，连起来就"像AI"。命中句式后优先**打碎重组**而非逐词替换。

### 4.1 句首模板句

| 命中句式 | 换句方案 |
|----------|----------|
| 随着...的（发展/到来），... | 直接说事件（"开春了。第一批订单到了。"） |
| 当...时，... | 删掉时间状语，直接动作 |
| 在这个...的时代 | 删掉，写具体场景 |
| 那一刻，... | 限用：每章≤2次，其余用定格细节替代 |

### 4.2 心理模板句

| 命中句式 | 换句方案 |
|----------|----------|
| 他/她不知道的是，... | 删掉或提前（读者已经知道的事别解释） |
| 他告诉自己，一定要... | 换成具体行动承诺（他把闹钟调早了一小时） |
| 这一刻，他终于明白，... | 换成顿悟的瞬间行为（他手停在门把手上，没推） |
| 或许，这就是...吧 | 删掉，让读者自己品 |
| 如果有机会，他一定会... | 换成动作（他记下了那个名字） |

### 4.3 动作+情绪套句

| 命中句式 | 换句方案 |
|----------|----------|
| 他X了X，X仿佛X（他握了握拳，空气仿佛凝固） | 拆成两个独立短句，去掉"仿佛" |
| X人X，然后X，最后X（三连模板） | 保留1-2个动作，其余删掉 |
| 他的声音/X，带着一丝X | 换成可见特征（他声音发紧/她说话像咬着牙） |
| X让她/他心里X（情绪归属模板） | 直接写身体反应（手心出汗/脚底发麻） |

### 4.4 总结/收束模板句

| 命中句式 | 换句方案 |
|----------|----------|
| 这一切，都是因为... | 删掉，让因果藏在情节里 |
| 从此，他/她... | 用具体场景收尾（他锁上门，钥匙留在锁孔里转了半圈） |
| 但事情远没有结束 | 删掉，用新事件开场 |
| 命运/生活似乎在... | 删掉，直接写发生的事 |

### 4.5 对话标签模板句

| 命中句式 | 换句方案 |
|----------|----------|
| 他缓缓开口/她轻声说道 | ① 换成动作+直接引语（他点烟："说吧。"） ② 删掉标签 |
| 他/她声音低沉而沙哑 | 换成对话内容暗示（"妈，我回来了。"这句话他练了一路） |
| 沉默片刻后，他/她说 | ① 他隔了好几秒才接话 ② 她没回头："知道了。" |
| 语气中带着一丝（不满/关切） | 换成可见反应（她皱眉/他把遥控器放下） |

### 4.6 AI叙事结构句式（全网收集）

> 这些是**跨题材通用**的 AI 叙事指纹，来自对主流 AI 输出模式的分析（no-ai-slop / tropes.fyi / AI味识别文章）。单看每个词正常，**连成结构就是 AI 签名**。命中后必须**打碎结构**而非换词。

| AI叙事结构 | 识别示例 | 换法 |
|------------|----------|------|
| 二元对比"不是X，而是Y" | "这不是愤怒，而是失望" | 直接用后者（"他失望地看着她"）；每篇≤1次 |
| 戏剧性倒数"不是X。不是Y。只是Z" | "不是退路。不是出路。只是死路" | 拆成一句直说（"他没退路了"） |
| 自问自答"最X的是什么？是Y" | "最难的是什么？是放弃" | 删问句，直接陈述 |
| "从X到Y"万能结构 | "从清晨到深夜""从入门到放弃" | 换成具体时间/事件（"天没亮他就醒了"） |
| 空洞祝福"你值得/愿你" | "你值得更好的""愿你前程似锦" | 网文慎用；必用时用具体许诺（"我欠你的，会还"） |
| 伪洞察"没有人告诉你的/大多数人忽略的" | "没有人告诉你的三件事" | 删，直接讲事实 |
| 戏剧性碎片"就这样。就这么简单" | "就这样。就这么简单。" | 删掉，让情节说话 |
| 重要性吹捧"标志性时刻/里程碑式的" | "这是里程碑式的胜利" | 删，写结果（"他们赢了"） |
| 伪深刻结尾"未来已来/这不是结束而是开始" | "未来已来，只是分布不均" | 删，用具体画面收尾 |
| "空气中弥漫着X" | "空气中弥漫着危险的气息" | 删或写具体（"烟雾从门缝钻进来"） |
| "看不出任何X" | "看不出任何破绽" | 换成行为（"他检查了两遍，还是没发现问题"） |
| "他/她永远不会知道" | "她永远不会知道真相" | 删（上帝视角剧透）或换视角（"他没打算告诉她"） |
| "那一刻他（突然）明白/醒悟" | "那一刻，他终于明白" | 换成顿悟的动作（"他手停在门把手上，没推"） |
| 连续同句首（Anaphora） | "他知道…他知道…他知道…"连3句 | 保留1句，其余打散 |
| 每段末句总结 | 每段结尾都来一句道理 | 删总结句，用细节定格 |

### 4.7 对称/平行结构指纹库（结构级）

> **核心机制**：LLM 训练数据中对称/对仗结构是高置信度续写路径（tropes 命名为 Negative Parallelism / Mirrored-clause Symmetry / Hat Trick 等）。AI 会**系统性**产出，人类只是**偶尔**用。命中标准 = 同结构在文内重复出现（≥2次）或成段成组出现；单次使用不判死。
> **检测方式**：按下列 S1-S35 结构逐条比对文本。**归类口径**：S1"不是X而是Y"与 S4"不是X。不是Y。只是Z"归句级句式检测；S2/S12/S15/S25 为辅助参考（比对时留意），其余结构在文中重复出现（≥2次）或成段成组出现即命中。
> **判断口诀**：对称是 AI 的省力坡道，直说要点才是人的路。打碎它 → 保留一句核心 → 其余按"删/动作/具体感官/断句"处理。

| # | 结构名 | AI 典型写法 | 真人方向（替换/打碎） |
|---|--------|------------|----------------------|
| S1 | 负面平行（Negative Parallelism） | "不是X，而是Y" / "不是X，是Y" | 直说 Y（"他要的不是理解，是赢"→"他想赢"）；需对比时用"Y。X不是重点" |
| S2 | "重点不是X而是Y"变体 | "重点不是技术，而是人性" | 删前半（"技术只是外衣"） |
| S3 | "与其说X不如说Y" | "与其说是报复，不如说是求救" | 只留 Y（"他是在求救"） |
| S4 | "不是X不是Y，而是Z"戏剧性倒数 | "不是恐惧。不是解脱。是别的什么" | 只留 Z（"恐惧压过了解脱"） |
| S5 | "不是因为X，而是因为Y" | "不是因为恨，而是因为不甘" | 删前半（"他输在不甘心"） |
| S6 | 连续否定列举（No-No-No Parade） | "不是这样。不是那样。不是……"连3句 | 保留 1 个否定，其余砍掉 |
| S7 | 三连排比（Hat Trick） | "需要勇气。需要决心。需要坚持。" | 并成一句（"需要勇气，更要命的是坚持"）或改 2/4 项 |
| S8 | 镜像对称（Mirrored-clause Symmetry） | "她分不清是爱他，还是恨他" / "他越平静，她越害怕" | 打散成动作（"他倒了杯水，手没抖。她反而更怕了"） |
| S9 | 双向递进 | "越X越X" / "越说越离谱" | 换成具体递增（"他越说，声音越小"） |
| S10 | "一边X一边Y" | "她一边哭一边笑" | 换顺序/只留动作（"她笑着，眼泪往下掉"） |
| S11 | "既X又Y" | "既惊喜又不安" | 只留主导情绪（"惊喜，随即心沉下去"） |
| S12 | 格言式结尾（Aphoristic Ender） | "水是善妒的。""羞耻是一种物质。"短句格言收束 | 删格言，用画面/动作定格（"她把水泼了"） |
| S13 | 预期反驳（Anticipate-and-Rebut） | "你可能会说这不现实。但……" | 删"你可能会说"，直接讲事实 |
| S14 | 重要性宣告（Significance-Signaling） | "这不是巧合，而是必然" / "这一刻，值得被记住" | 删，让情节自己说话 |
| S15 | 自我指涉式解释 | "问题的关键不在于X，而在于X本身" | 删整句（废话） |
| S16 | 同主语连续句首（Anaphora） | "他X。他X。他X。"连3句 | 保留 1 句，其余换主语/动作 |
| S17 | "有X，有Y，还有Z"排比列举 | "有愤怒，有委屈，还有不甘" | 保留 1 个，其余化为动作 |
| S18 | "无论是X还是Y" | "无论是白天还是黑夜" | 直说（"他盯着门，从白天到天黑"） |
| S19 | "不是A是B，不是B而是C"连环对比 | 一句里两次对比 | 只留最后一次对比，其余直说 |
| S20 | "如果说X，那么Y" | "如果说昨天是序幕，那么今天是正戏" | 只留 Y（"正戏今天才开场"） |
| S21 | "正如X一样" | "正如多年前一样" | 删或换具体（"和当年他逃出来那晚一样"） |
| S22 | "仿佛X，仿佛Y"重复 | "仿佛得到了赦免，仿佛重获新生" | 只留 1 个 |
| S23 | "那一刻"领起句（连续） | 多段以"那一刻"开头 | 只保留 1 次 |
| S24 | "就像X一样，就像Y一样" | "就像针，就像刀" | 只留 1 个比喻 |
| S25 | 三段式论证（强行三点） | "第一……第二……第三……"无关内容也拆三点 | 合并为一段，去掉序号 |
| S26 | "不仅X，而且Y"对仗 | "不仅提升效率，而且优化体验"（70% AI偏好工整对仗） | 拆成两句话，第二句更具体 |
| S27 | "一方面……另一方面……" | 硬分两面 | 按轻重合并 |
| S28 | "有人X，有人Y"分说 | "有人劝他放弃，有人劝他坚持" | 只留一方，另一方化作场景 |
| S29 | "一遍又一遍/一次又一次" | 重复强调 | 保留 1 次 |
| S30 | "无论……都……"绝对让步 | "无论结果如何，他都认了" | 换成真实条件（"要是输了，他就认"） |
| S31 | "宁可X，也不Y" | "宁可站着死，也不跪着生" | 单次可用；连用2次即删 |
| S32 | "从X到Y，从X到Y"双从式 | "从清晨到深夜，从春天到冬天" | 只留 1 组 |
| S33 | "在X中，在X中"重复介宾 | "在黑暗中，在孤独中" | 只留 1 个，另一个作谓语 |
| S34 | "一个X，一个X"排比 | "一个念头，一个念头地冒出来" | 只留 1 个 |
| S35 | 连续问句排比 | "他错了吗？他该放弃吗？他还能回头吗？" | 只留 1 问，其余转陈述 |

**对称结构检测判定**（写进诊断报告）：
- 单个结构出现 1 次 → 弱信号（不判）
- 同结构 ≥2 次 或 任意 3 个不同结构扎堆（相邻 300 字内）→ 强信号，必须打碎
- 连环结构（S19/S4/S8 组合）→ 直接标红重写

### 4.8 标点管控：破折号铁律

> **铁律：每章破折号"——"不超过 1 处。除非必须，否则不用。**
> 行业检测经验值：中文真人写作破折号频率约每篇 0.5 个；AI 生成平均每篇 9 个以上；英文语料中 AI 生成文本的破折号密度约为人类写作的数倍。破折号已成为 AI 检测器最强标点信号之一。

**只有 3 种合法用途**（其余全部删）：
1. 打断插入（对话被打断）："你——"她没能说完。
2. 节奏转折（收束前的重拍）："练了两年，瘦了十斤，输光了所有——然后她赢了。"（换逗号/句号会破坏这一拍才可用）
3. 戏剧性补充（微停顿后补一刀）："这世上只有一个人能拦住他——他爹。"

**判定标准**（标点级核验）：
- 破折号 ≤1 处/章 → 正常，但每次出现都复核是否属于 3 种合法用途
- ≥2 处/章 → 强制告警，逐处说明用途；非合法用途必须删
- 破折号充当逗号/冒号/括号替代（"——特别是"、"——也就是"、"——不是"）→ 直接替换为对应标点或拆句
- 连续破折号（"————"）、破折号+逗号叠用（"—，"）→ 直接删除

**删除优先级**：删 > 换逗号 > 换冒号 > 拆成两句 > 换括号（插入语） > 重写为谓语。任何"删掉后句子依旧通顺"的破折号都是舞台道具，必须删。

## 五、中英文双词表

> 供英文创作（模块I）与中英对照润色共用。英文 AI 特征与中文同构：过度正式、泛化形容词、整齐句式。

### 5.1 英文高频AI词 → 替换

| AI高频 | 替换 |
|--------|------|
| suddenly / abruptly | 删掉或换事件（The door flew open.） |
| however / moreover / furthermore | 用 But / And / 删掉 |
| indeed / truly / absolutely | 删掉 |
| in order to | to |
| utilize / leverage | use |
| ultimately / eventually | 删掉或换具体时间 |

| various / numerous | 删掉或具体数字（dozens of） |
| incredibly / extremely | 删掉或具体（scorching heat，不说 extremely hot） |

### 5.2 英文高频短语 → 替换

| AI高频 | 替换 |
|--------|------|

| heart skipped a beat | 换成本身生理（his pulse jumped / she went still） |

### 5.3 英文高频句式 → 换句

# 行为逻辑库（角色行为决策系统）

> 角色"为什么会这么做"的完整推理体系：动机引擎 → 决策树 → 行为指纹 → OOC防线。让每个角色的每个动作都有来路、说得通、记得住。
> 版本：1.7.0
> 联动：三锚点（欲望/恐惧/边界）见 `character-depth.md`；对话行为见 `dialogue-engineering.md`；角色当前状态与 OOC 三道检查见 `entity-state-machine.md`（动作落笔前先过状态机）；过程状态归档见 `memory-engineering.md`。
> 使用场景：人设卡之后必配行为逻辑，正文写作前加载，续写前按行为指纹校验

## 一、行为公式（一句话推演）

> **行为 = 欲望 × 性格 × 处境 × 情绪 × 信息**

五个变量缺一不可。任何一个角色动作，都能用这个公式检验"立不立得住"。

| 变量 | 定义 | 反例（只写其一） |
|------|------|------------------|
| 欲望 | 此刻最想要什么（三锚点之欲） | 角色突然出手，没有目的 |
| 性格 | 遇到问题第一反应习惯（冲动/隐忍/算计/逃避） | 隐忍了一百章的人忽然掀桌 |
| 处境 | 客观条件：资源/实力/时间/在场者 | 身无分文却一掷千金 |
| 情绪 | 当下的情绪状态（愤怒/恐惧/愧疚/兴奋） | 冷静的人做出歇斯底里的决定 |
| 信息 | 他此刻知道什么、不知道什么 | 他不知道真相却表现出知道真相的样子 |

**行为推演三步**：
1. 想让他做什么？（行为结果）
2. 五个变量里哪个在驱动？（找主因）
3. 其他四个变量是否矛盾？矛盾→要么改行为，要么补变量（加铺垫）。

## 二、行为决策树（关键选择的推演路径）

当角色面临选择时，按决策树逐层排除，而非拍脑袋：

```

第1层 边界层：这个选择是否触碰底线（三锚点之界）？
       触碰 → 除非重大代价事件，否则不选（选了=人物崩坏）
第2层 恐惧层：这个选择会触发他的核心恐惧吗？
       会 → 选它会带来额外心理成本，必须给补偿理由
第3层 欲望层：这个选择离他的核心欲望更近还是更远？
       更近 → 大概率选；更远 → 需要更强的诱因
第4层 成本层：代价是什么（钱/关系/时间/良心）？
       代价能否接受 → 看他当前资源的富余度
第5层 情绪层：此刻情绪是理性还是失控状态？
       失控 → 允许做出"第1-4层都说不通"的冲动决定（但必须是他性格里本就有的冲动）

```

**决策树输出**：每做一个关键选择，记录"选了什么 + 依据了哪一层 + 为什么这一层压倒其他层"。这是防OOC的现场凭证。

## 三、行为模式（性格=稳定的行为倾向）

### 3.1 四大性格基座

| 基座 | 行为倾向 | 写崩雷区 |
|------|----------|----------|
| 冲劲型 | 先动手后想后果；遇事第一反应是"上" | 突然变得凡事三思 |
| 隐忍型 | 先观察再行动；把情绪压进细节 | 突然当众爆发（除非压力顶格） |
| 算计型 | 先算利益再决定；说话留三分 | 突然真情流露不设防 |
| 逃避型 | 先躲开冲突；能用沉默就不开口 | 突然直面一切（除非弧光完成） |

### 3.2 行为模式的三种表现层

| 表现层 | 内容 | 作用 |
|--------|------|------|
| 大事决策层 | 面对关键选择的倾向 | 定人物底色 |
| 日常应对层 | 遇到麻烦的第一反应 | 让角色可预期、可信 |
| 微动作层 | 紧张/说谎/心虚时的小动作 | 给读者"读人"的线索 |

**微动作 → 行为指纹**：给每个主要角色配 1-2 个专属微动作（说话时摸耳垂 / 紧张时转笔 / 说谎时不看人）。微动作一旦设定，全书保持一致——它是读者的"情绪晴雨表"。

## 四、行为指纹（识别角色的行为签名）

### 4.1 行为指纹四件套

| 指纹 | 定义 | 示例 |
|------|------|------|
| 口头禅/句式 | 高频用语与表达习惯 | 老把"倒也不是不行"挂嘴边 |
| 招牌动作 | 专属微动作/习惯 | 紧张时不停转佛珠 |
| 回避清单 | 绝口不提的事/绝不触碰的话题 | 从不谈家人 |
| 应激反应 | 特定刺激下的固定反应 | 被冤枉时不辩解，直接沉默 |

### 4.2 行为指纹的使用

- **识别**：让读者仅凭一段行为就能认出是谁（不用点名）
- **校验**：续写/多写手协作时，用指纹清单核对每段描写是否"走形"
- **升级**：弧光关键节点允许指纹"断裂"一次（习惯变了=角色变了），但必须安排事件解释

### 4.3 行为指纹清单（每个主要角色一张卡）

```

【角色名】________________
口头禅/句式：____________
招牌动作：____________
回避清单：____________
应激反应：____________
（配角/反派 1-2 项即可，主角建议 4 项全配）

```

## 五、OOC 防线（角色行为失控检测）

### 5.1 OOC 三大来源

| 来源 | 典型表现 | 检测法 |
|------|----------|--------|
| 剧情需要 | 为了推进剧情让角色做不符合性格的事 | 问：换这个人设，他会这么做吗？ |
| 作者上头 | 写爽了让角色干平时绝不干的事 | 对照行为指纹核对 |
| 多写手漂移 | 不同写手笔下同一角色行为不一致 | 用指纹清单逐项核对 |

### 5.2 OOC 自检五问（每章写完过一遍）

1. 本章主角的每个关键行为，能说出"为什么"吗？（说不出=没动机）
2. 换一个性格完全不同的人，本章剧情能原样发生吗？（能=角色只是道具）
3. 角色的反应是"他的反应"还是"作者想让他有的反应"？
4. 有没有为了爽/虐/反转而让角色崩人设？（有→找替代方案）
5. 行为指纹有没有意外漂移？（有→是弧光还是事故？）

### 5.3 OOC 修复法

- **补动机**：行为不变，补一段心理/回忆/细节让动机成立
- **改行为**：动机不变，让行为换成符合性格的表达方式
- **升级触发**：若行为是弧光断裂，前面必须已铺垫 2 个以上事件

## 六、决策树记录样例（演示）

> 以下为完整演示：一条关键决策从"处境"到"落子"再到"后续校验"的全过程。角色为原创演示人设，不指向任何书籍人物。

### 6.1 决策记录：冷面管家要不要交出家主的信

**角色**：沈伯，冷面管家，伺候顾家三代人，以"面冷心细、绝不多话"立身（性格基座：冲劲 1 / 隐忍 8 / 算计 6 / 逃避 3）。

**处境**：顾家独子顾衍失踪三年。今晚一伙人摸进宅子，领头的是家主生前的仇家钱叔。钱叔拿枪抵着顾衍同母异父的妹妹顾眠，让沈伯把家主"藏着的信"交出来。沈伯知道信在书房暗格里，也知道信的内容是顾家产业的地契转赠。

**行为公式五变量分析**：

| 变量 | 内容 | 驱动方向 |
|------|------|----------|
| 欲望 | 保住顾眠性命，同时不把地契交给仇家（双欲望冲突） | 主驱动 |
| 性格 | 隐忍型+算计型：先观察、后算账、话少 | 决定"先拖"而非"硬顶" |
| 情绪 | 愤怒压着，恐惧（枪口对着顾眠）浮在表面 | 允许手抖，不允许翻脸 |
| 信息 | 知道信在暗格；**不知道**钱叔真正要的是信里夹着的账本 | 信息差留作后手 |

**五层决策逐层过**：

| 层 | 过检 | 结论 |
|----|------|------|
| 第1层 边界层 | 交出信=背叛顾家三代，触碰底线（忠诚） | 不交 → 但顾眠的命在同一天平上，转下一层 |
| 第2层 恐惧层 | 核心恐惧是"顾家毁在自己手里"：交信触发，不交害死顾眠同样触发 | 两难 → 必须给补偿理由：先"交"再"追回" |
| 第3层 欲望层 | 双欲望取近：保命（顾眠）比保财（地契）更接近"对得起顾家" | 倾向"表面交" |
| 第4层 成本层 | 真交成本=地契归仇家；假交成本=一旦识破，顾眠当场没命 | 选"假交"，前提是假物足够真 |
| 第5层 情绪层 | 此刻"表面镇定、内里发抖"，未失控 | 允许走算计路线，而非冲动翻脸 |

**最终选择与依据层**：表面交信、实际调包——把地契换成账本复印件，依据"第4层成本层"（假物足够真则成本最小）；同时借"信里夹账本"的信息差在第3层欲望层做兜底：钱叔翻开信先看到账本，注意力被引走。

**后续行为一致性校验**：
- 交信时他手抖了一下（第2层恐惧层的生理溢出），但没说一句软话（隐忍型+话少，符合行为指纹）。
- 钱叔走后，他先确认顾眠无恙，再回书房点灯核对暗格——"先人后物"，符合"伺候三代"的欲望排序。
- 校验结果：全程未出现"突然硬气掀桌""突然痛哭倾诉"等越层行为，OOC 五问全过。

### 6.2 行为指纹卡样例（演示）

```

【角色】沈伯（冷面管家）  定位：主角身边的"活规则书"
语速：慢，一句话拆两截说，中间顿半秒；被追问才补后半句
口头禅/句式：「老规矩。」「不好说。」；讲理时爱用"依我看"开头
招牌动作：说话时用拇指摩挲钥匙串；紧张时捻无名指上的旧戒指

决策倾向：先拖、再算、后动；能用一步假动作绝不正面冲突
雷区：提"顾衍可能回不来"；动顾眠；碰书房暗格以外的任何锁

```

## 七、群体行为逻辑（势力/群体的行为惯性）

个体有行为逻辑，群体也有：势力、家族、宗门、公司的"集体性格"决定他们怎么反应。

| 群体变量 | 内容 | 示例 |
|----------|------|------|
| 组织目标 | 群体存在的目的 | 商会图利、宗门图道统 |
| 行事风格 | 处理问题的惯用手段 | 世家爱借刀杀人、江湖好快意恩仇 |
| 红线 | 绝不做的事 | 名门不涉魔道 |
| 内部博弈 | 派系/嫡庶/新旧之争 | 激进派 vs 稳健派 |

**群体行为自检**：换一个群体来处理同一件事，结果是否不同？如果所有势力处理方式都一样→群体没有行为逻辑，只是"配角集合"。

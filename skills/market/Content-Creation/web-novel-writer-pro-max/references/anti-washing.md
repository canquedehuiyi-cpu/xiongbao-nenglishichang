# 反洗稿边界判定

> **定位**：界定「合法借鉴/风格仿写/结构拆解」与「违规洗稿」的边界，提供交付前可执行的原创性自检。本文件只做**边界判定与自检**；同人/仿写/魔改的具体写法见 `fan-remix.md`，版权法规细节见 `legal-compliance.md`，风格仿写见 `writer-styles-expanded.md`，结构拆解见 `novel-deconstruction.md`。

## 一、核心边界：思想不受保护，表达受保护

| 层面 | 是否可借鉴 | 说明 |
|------|------------|------|
| 题材、类型、套路、母题 | 可以 | 「修仙升级流」「重生复仇」等属于思想/方法层面，不被垄断 |
| 叙事结构、节奏方法、钩子类型 | 可以 | 拆解出的结构公式可复用，内容必须原创 |
| 语言风格、叙事腔调 | 可学习转化 | 学的是方法与规律，不照搬具体句子 |
| 具体情节链、人物关系设定 | 高风险 | 情节序列与独创设定的实质性相似构成风险 |
| 原文句子、段落、关键表达 | 不可以 | 具体文字表达受保护，换近义词也算抄 |
| 原作人名、专有设定、名场面 | 不可以（同人另按授权边界） | 见 `fan-remix.md` 版权红线 |

一句话：**仿其法不抄其文，学其骨不换其皮。**

## 二、合法与违规对照

| 行为 | 判定 | 关键区别 |
|------|------|----------|
| 拆解爆款结构后用自己的世界/人物写 | 合法 | 只复用抽象结构，具体表达全新 |
| 学习某作家的叙事节奏与用词偏好 | 合法（转化） | 学规律，不复制原句；在世名家仿写不商用、不署名冒充 |
| 把原文逐句换近义词、调语序 | 违规（换皮洗稿） | 表达实质未变 |
| 把外文作品翻译后当原创 | 违规（翻译洗稿） | 译本同样承载原作表达 |
| 拼接多篇作品的情节段落 | 违规（拼接洗稿） | 拼凑不产生原创表达 |
| 用 AI 把他人文本「改写降重」后发布 | 违规 | 源头是他人表达，AI 改写不改变侵权性质，且触碰平台 AI 使用规则红线 |
| 受某作品启发写全新故事 | 合法 | 启发点抽象、表达独立 |

## 三、洗稿的常见形态

识别下列形态，命中即回到原创化改造：

1. **换皮洗稿**：同义词替换、语序调换、句式改写，但情节顺序、场景、比喻一一对应。
2. **翻译洗稿**：将境外作品翻译/轻度本地化后署自己名字。
3. **拼接洗稿**：从多部作品各取段落缝合，局部原创掩盖整体搬运。
4. **结构连坐**：不只用词相似，连「事件 A→B→C 的具体序列、伏笔位置、反转方式」都高度重合。
5. **AI 降重洗稿**：把他人文本喂给 AI「润色降重」，文字变了但情节与表达来源仍是他人。
6. **设定搬运**：照搬独创力量体系、门派/组织架构、人物关系网，仅改名字。

行业反洗稿的自律共识均以「原创为本」，反对上述行为；各平台具体要求交付前按 `verify-protocol.md` 核实。

## 四、原创性自检流程

```

1. 列来源：本章/本书参考了哪些作品、用了哪些素材（含 AI 生成片段）
2. 对表达：逐段比对是否存在与来源作品「具体句子/场景/比喻」的实质相似
3. 对情节：比对事件序列、人物关系、反转设计是否实质性雷同
4. 对设定：力量体系/组织/专有名词是否只是改名照搬
5. 定级：通过 / 需改造 / 高风险（高风险必须重写而非换词）
6. 留痕：记录参考来源与改造方式（拆书来源、原创化步骤）

```

**原创化改造最低要求**（与 `asset-library.md` 调用流程一致）：借鉴结构时，至少完成「换世界观、换人物、换具体情节、换表达、加入个人经验」中的多项，使成品与来源在具体表达层完全不同。

**自检清单**：

- [ ] 核心情节链是否为自己设计，而非对应某作品的事件序列？
- [ ] 是否逐句排查过实质相似的句子/比喻/场景？
- [ ] 人物关系与独创设定是否脱离来源独立成立？
- [ ] 是否不存在「翻译后当原创」「多篇拼接」「AI 降重他人文本」？
- [ ] 参考来源是否已记录、拆书所得是否只取方法不取表达？
- [ ] 同人/魔改内容是否已按 `fan-remix.md` 评估授权与商用边界？

## 五、AI 场景专项

- AI 辅助**自己的原创构思**（用自己的大纲让 AI 润色）与用 AI **洗他人稿件**性质完全不同：前者是原创 + 辅助，后者是侵权 + 违规，本文件只允许前者。
- 任何「输入他人文本 → AI 改写 → 署自己发布」的链路都判定为洗稿，且同时不符合平台 AI 使用规则（见 `ai-compliance-redlines.md`）。
- AI 生成的内容本身也要过本自检：若 AI 输出与某已知作品高度相似，同样需要重写。
- 使用 AI 的环节按 `ai-disclosure-writer.md` 如实声明，声明不能豁免原创性责任。

## 六、交付前核验清单

- [ ] 是否明确区分了「可借鉴的方法层」与「不可抄的表达层」？
- [ ] 是否逐一排除了第三节六种洗稿形态？
- [ ] 高风险项是否重写（而非换词降重）？
- [ ] AI 链路是否为「原创构思 + 辅助」，不存在「他人文本 + AI 降重」？
- [ ] 参考来源与原创化过程是否留痕？

### 自检标准（可验证）

1. 给出「换词版原文」「结构借鉴原创版」「AI 降重版」三类样本，能正确区分合法与违规。
2. 对任一待交付章节，能走完第四节流程并给出「通过/需改造/高风险」定级与依据。
3. 全流程不提供任何「如何洗稿不被发现」的指引，只提供原创化与合规方向。

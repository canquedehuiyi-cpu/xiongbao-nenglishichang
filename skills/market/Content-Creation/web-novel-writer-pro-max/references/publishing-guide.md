# 实体出版指南（出版社签约出版全流程）

> 网文之外的第二条变现与IP通道：中文出版社出版、英文传统出版与KDP自出版。覆盖投稿流程、版税模式、合同要点、出版与网文联动。
> 版本：1.7.0
> 声明：本库所有流程与数字为**行业通行参考值**，各出版社/平台政策实时变化，以实际合同与出版社公告为准。涉及法律条款建议咨询专业人士。
> AI 合规：传统出版与 KDP 自出版的 AI 使用/披露要求以 `ai-compliance-redlines.md` 为准，对外披露文案由 `ai-disclosure-writer.md` 产出（KDP 区分 AI-generated 与 AI-assisted），发布前按 `verify-protocol.md` 核实。
> 联动：网文平台签约见 `signing-standards.md`；版权合同合规见 `legal-compliance.md`；英文创作见 `english-creation.md`。

## 一、中文实体出版路径（三种方式）

| 路径 | 适合对象 | 特点 | 风险 |
|------|----------|------|------|
| 平台推出版 | 已在网文平台有成绩的作者 | 平台牵线出版社，省去投稿环节 | 平台分成结构要看清 |
| 直接投稿社 | 有完整稿件/有市场判断的作者 | 分成或买断，主动权在作者 | 投稿周期长、命中率低 |
| 图书公司合作 | 内容适合商业化包装的作者 | 选题策划+营销资源 | 条款复杂，细读合同 |

**路径选择自检**：你有平台成绩吗？（有→优先平台推出）稿子完整度够吗？（不完整→出版社通常不收）你重视长期版权还是短期变现？（重版权→分成；重快钱→买断要慎重）

## 二、投稿流程（六步）

```

1. 准备投稿包：完整大纲 + 3-5万字样章 + 作者简介 + 对标书分析
2. 筛选目标社：关注该社近年出版品类是否与你的题材一致
3. 投稿（邮箱/编辑约稿）：附投稿信（书名+一句话卖点+读者定位+完稿字数）
4. 等待评估（周期通常数周到数月，可跟进但不过度打扰）
5. 选题会通过 → 编辑联系谈合同
6. 签约 → 编辑加工（退修/润色/删改）→ 排版 → 付印

```

**投稿要点**：
- 投稿包不附全文（样章控制在 3-5 万字内）
- 一句话卖点要能直接进入选题会评审（参考 `market-positioning.md` 卖点五问）
- 对标书写清"为什么这本会卖"（参考对标书五拆）

### 2.1 投稿信模板（中文 query letter）

中文出版社投稿信 = 一页纸、六项齐全、可直接进选题会。模板：

```

尊敬的编辑老师：

您好！我是网文作者【笔名】。冒昧投递《【书名】》的样章与大纲，烦请拨冗审阅。

一句话卖点：【一句说清：主角身份+金手指/处境+情绪+与同类书的差异，可直接上选题会】
读者定位：【年龄/性别/阅读习惯，越具体越好】
完稿字数：【全书预计】万字，已完稿【X】万字（或已连载至【X】章）
对标书：《【对标书名】》（近两年同类上榜/畅销），这本之所以会卖：【一句话说清对标书凭什么卖，见 market-positioning.md 对标五拆】

作者简介：网文平台【平台名】签约作者，代表作《【书名】》【平台成绩：均订/完结字数/获奖】；本书相关背景：【与题材相关的真实经历或积累】。

随信附：大纲、样章（3-5万字）、对标分析。盼复，感谢您的时间！

此致
敬礼！

【笔名】 【邮箱/微信】 【日期】

```

**示例填法**（都市异能，男频，投番茄/起点）：

> 一句话卖点：汽修工林凡能"摸到物品的记忆"，靠一把扳手查出三年前的肇事顶包案——都市异能+悬疑破案，爽点是查案打脸，钩子是每章一件旧物的记忆。
> 读者定位：18-35 岁男频读者，通勤刷番茄、追起点悬疑向，喜欢"小人物逆袭+单元破案"。
> 完稿字数：全书 120 万字，已完稿 60 万字（暂按 3000 字/章 × 200 章规划）。
> 对标书：《犯罪心理现场》（近两年悬疑向畅销），这本之所以会卖：单元案件节奏快、章末钩子硬；本书主角靠"读物记忆"天然带出案件线索，读者每章跟着解谜。
> 作者简介：番茄签约作者，完本两本都市文（《夜班代驾》等），均订 3000+；本人有五年汽修经历，修车铺细节全部来自真实见闻。

### 2.2 投稿包目录示例

```

投稿包_《读物的汽修工》_林凡/
├── 投稿信.md            ← 上面 2.1 的成品（正文放邮件正文，附件各放一份）
├── 简介.md              ← 百字简介 + 一句话卖点 + 读者定位
├── 大纲.md              ← 全书分卷大纲（卷目标+主要事件+爽点安排）
├── 样章/                ← 前 3-5 万字
│   ├── 第1章_撞车.md
│   ├── 第2章_扳手.md
│   └── ...
├── 对标分析/            ← 对标书五拆：定位/节奏/爽点/钩子/卖点
│   ├── 对标书数据.md
│   └── 差异点.md
└── 作者简介.md          ← 平台成绩+相关经历（与投稿信简介一致）

```

**打包纪律**：投稿包不附全文（样章 3-5 万字）；文件命名带书名与卷章号，编辑下载即知结构；投稿信正文直接写在邮件正文，不丢附件。

## 三、稿酬与版税模式（参考值）

| 模式 | 计酬方式 | 参考范围 | 注意 |
|------|----------|----------|------|
| 版税分成 | 定价 × 销量 × 版税率 | 版税率通常 5%-12% | 问清"定价×实际销售价"的基数 |
| 稿费买断 | 一次性买断作品若干年版权 | 视篇幅/市场，无统一标准 | 买断期越长越亏，慎签长期买断 |
| 保底+分成 | 先付保底，超过部分再分成 | 视作者名气与市场预期 | 保底通常与销量目标挂钩 |

**版税计算示例**（参考）：
> 定价 39.9 元，版税率 8%，卖出 1 万册 → 作者收入 ≈ 39.9 × 8% × 10000 ≈ 3.2 万元（税前，扣除个税与平台佣金后另计）。

**数字纪律**：以上为示例演算，非任何出版社承诺。签约前向编辑书面确认：版税率、结算周期、销量数据可见性。

## 四、出版合同十查

| 项 | 必查内容 |
|----|----------|
| 授权范围 | 简体/繁体/海外？是否含电子、音频、影视改编权？ |
| 授权期限 | 几年？到期自动续约还是归还？ |
| 结算周期 | 每半年/每年？什么时候能看到销售数据？ |
| 版税基数 | 按定价算还是按实际结算价算？ |
| 买断条款 | 若买断：年限？是否排除改编权？ |
| 优先权 | 下本书是否被要求优先给该社？ |
| 作者样书 | 赠送几本？购书折扣？ |
| 宣传义务 | 作者要配合哪些活动？ |
| 违约金 | 违约情形与责任是否对等？ |
| 争议解决 | 管辖地/仲裁还是诉讼？ |

**合同自检**：十项有疑问的都写邮件问编辑要书面确认；口头承诺一律要求落到合同；重要合同建议咨询知识产权律师（参考 `legal-compliance.md`）。

## 五、英文出版（传统 vs 自出版）

| 路径 | 流程 | 收益结构 | 适合 |
|------|------|----------|------|
| 传统出版（Traditional） | 找文学代理（query letter）→ 代理投稿 → 出版社签约 | 版税通常 10%-15%（精装更高） | 想要主流背书、追求长线 |
| KDP 自出版（Amazon） | 上传稿件+封面 → 定价 → 上架 | 版税 70%（定价 2.99-9.99 美元档）或 35%（其他定价/类别） | 想掌控节奏、快速测试 |

**传统出版要点**：
- 多数大社不接"裸投"（未经代理的投稿），先找代理
- query letter = 一段话卖点 + 作者背景 + 字数与类别（参考 `market-positioning.md` 卖点五问）
- 代理抽成通常 15% 左右（参考值），谈判确认

**KDP 自出版要点**：
- 封面/排版/简介自己做或外包（封面要求见 `prompt-library.md` 封面生成）
- 版税档位取决于定价区间（70% 档通常为 2.99-9.99 美元），KDP Select 是 Kindle Unlimited 的独占选项（换取 KU 借阅分成），**不是版税开关**
- 英文作品自然度检查见 `english-creation.md`

## 六、出版与网文联动策略

| 场景 | 策略 |
|------|------|
| 网文火 → 实体书 | 网文平台有成绩后，主动提出出版需求（平台有合作出版社资源） |
| 实体书 → 改编 | 实体出版背书利于影视/短剧改编洽谈（IP考虑见 `worldview-engineering.md`） |
| 同步发行 | 电子版网文 + 实体书同步，覆盖不同读者群 |
| 海外出版 | 中文版出版后，可授权繁体/英文版（合同里提前留海外授权条款） |

**联动自检**：签约网文平台时，先确认作品改编权/出版权归谁——避免后续出版时版权不清（重点看 `legal-compliance.md` 权属条款）。

## 七、出版自检清单

- [ ] 投稿包齐全（大纲+样章+卖点+对标）
- [ ] 稿酬模式与版税率已书面确认
- [ ] 合同十查全过，疑问已落书面
- [ ] 授权范围/期限/改编权归属清晰
- [ ] 英文出版路径已选定（传统/自出版）
- [ ] 出版与网文版权衔接无冲突

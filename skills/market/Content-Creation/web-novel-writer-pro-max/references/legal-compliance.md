## 一、版权归属要点

### 1.1 作品版权归属

| 创作方式 | 版权归属 | 注意事项 |
|----------|----------|----------|
| 人类独立创作 | 作者本人 | 保留创作过程证据 |
| AI 辅助创作 | 人类创作者（AI 辅助部分不单独享有版权） | 需体现人类的创造性贡献与主导，保留过程证据 |
| 纯 AI 生成（无人类创造性贡献） | 倾向于不受著作权保护 | 避免以纯 AI 生成内容作为核心成果 |
| 委托创作 | 按合同约定 | 签约前明确权属 |
| 职务作品 | 依著作权法与合同约定确定 | 网文签约需逐条核对合同 |

### 1.2 网文签约中的版权合同风险

| 风险点 | 说明 | 防范措施 |
|--------|------|----------|
| 独家授权范围 | 部分合同要求全版权独家授权 | 逐条确认授权范围、期限、是否可回收 |
| 改编权打包 | 签约可能一并包含影视/游戏/漫画改编权 | 评估价值，必要时协商保留或拆分 |
| 笔名权属 | 部分合同约定笔名归属 | 留意笔名相关条款 |
| 完本后权属 | 部分合同规定完本后版权仍归平台 | 确认回收条款与期限 |
| 同人/衍生风险 | 使用他人世界观、角色存在侵权风险 | 原创世界与角色，边界见 `anti-washing.md`、`fan-remix.md` |

> 合同条款属于个案法律事务，本表只提示常见风险点；签约前建议完整阅读合同并咨询专业人士。

## 二、平台内容禁区（法律通识层）

### 2.1 全平台共同禁止的内容

下列内容违反法律法规或公序良俗，在任何平台都属于严格禁区，不以平台规则差异而改变：

| 类别 | 禁止内容 |
|------|----------|
| 违法违规 | 违反法律法规、损害公序良俗 |
| 风化底线 | 涉性低俗描写、身体裸露细节刻画 |
| 伤害底线 | 宣扬以暴制暴、教唆伤人、过度血腥渲染 |
| 虚假信息 | 编造、传播不实信息、恶意营销造假 |
| 侵权 | 抄袭、洗稿、侵犯知识产权 |
| 歧视言论 | 地域、性别、残障、民族、宗教等歧视 |
| 隐私侵害 | 未经同意公开他人隐私、人肉搜索 |
| 未成年人保护 | 诱导未成年人不良行为、未成年人不当描写 |

### 2.2 平台额外规范

各平台在法律底线之上还有各自的内容细则与审核偏好（题材限制、描写尺度、标题规范等），这些属于**平台规则**，不在本文件写死：投稿前查 `platform-guide.md` 与 `signing-standards.md`，并经 `verify-protocol.md` 核实目标平台当期规范。

### 2.3 敏感内容处理原则

| 内容类型 | 处理建议 |
|----------|----------|
| 敏感描写 | 用暗示替代直描，用后果替代过程展示 |
| 情感冲突 | 多用心理与对话，少用刺激性直写 |
| 现实争议 | 优先架空处理，避免直接影射现实 |
| 青少年角色 | 严格避免不当描写，角色年龄设定审慎 |
| 历史题材 | 注意虚实边界，避免不当价值导向 |

## 三、AI 辅助与 AI 代写的法律边界

### 3.1 平台规则不在此判定

「某平台允不允许用 AI、占比多少、要不要声明、平台会怎么处理」属于平台规则，统一查 `ai-compliance-redlines.md` 对应平台卡（实时核实后为准）；声明文案由 `ai-disclosure-writer.md` 产出。本文件只做「辅助 vs 代写」的通用性质判断。

### 3.2 辅助与代写的性质边界（通用判断）

| 行为 | 性质 | 建议 |
|------|------|------|
| 用 AI 润色自己写的文字 | 辅助 | 真人主导，按平台规则处理声明 |
| 用 AI 检查逻辑/一致性 | 辅助 | 真人决策，AI 只提示 |
| 用 AI 生成灵感关键词/资料整理 | 辅助 | 创作主体仍在人 |
| AI 生成完整大纲、人只照写 | 越界风险 | 人应主导构思，AI 退为辅助（见 `ai-creation-ethics.md`） |
| AI 生成正文主体、人仅润色 | 代写风险高 | 多数平台不接受，且版权保护弱 |
| AI 全文生成直接发布 | 纯生成 | 禁止，触碰平台红线且难以主张版权 |
| 把他人文本喂给 AI 改写后发布 | 洗稿 | 侵权 + 违规，严格禁止（见 `anti-washing.md`） |

判断核心：**人是否贡献了创造性的构思与表达、是否为创作主体**。工具辅助不改变「人是作者」，但让 AI 成为正文的实际生产者则越界。创作过程留痕见 `misjudge-defense.md`。

## 四、跨媒体改编版权

### 4.1 改编权属检查清单

| 检查项 | 通过条件 |
|--------|----------|
| 原作版权归属 | 本人拥有改编权，或持有改编授权 |
| 平台授权范围 | 签约合同未把改编权独家让渡，或已取得平台同意 |
| 同人改编 | 原作允许同人，或已获授权（见 `fan-remix.md`） |
| 角色形象 | 角色为原创，不照搬他人设计 |
| 世界观 | 世界观为原创构建 |

### 4.2 各改编方向风险

| 方向 | 主要风险 | 防范 |
|------|----------|------|
| 小说→短剧 | 改编权归属、剧本与平台规范 | 确认权属，剧本规范见 `screenplay-creation.md` |
| 小说→漫画 | 角色形象、画风抄袭 | 原创角色设计；跨形态指令见 `cross-form-orchestrator.md` |
| 小说→有声 | 朗读授权、配乐版权 | 使用授权配音与可商用音乐 |
| 小说→游戏/互动 | 改编权、玩法与叙事范式 | 确认权属；互动叙事本版本仅留观察位 |

## 五、发布前自查清单

| # | 检查项 |
|---|--------|
| 1 | 作品为原创或合法授权改编（过 `anti-washing.md`）？ |
| 2 | 是否触碰第二节法律禁区内容？ |
| 3 | 目标平台当期内容规范是否已实时核实？ |
| 4 | AI 使用是否为「真人主导的辅助」，平台声明义务是否已按红线库与声明生成器处理？ |
| 5 | 签约合同版权/改编/笔名/回收条款是否逐条读过？ |
| 6 | 是否保留创作过程证据（大纲/草稿/改稿/AI 使用记录）？ |
| 7 | 是否含真实人物姓名/隐私信息？ |
| 8 | 改编作品是否具备完整授权链？ |

## 六、风险等级评估

| 场景 | 风险 | 措施 |
|------|------|------|
| 原创作品正常签约 | 低 | 常规自查 |
| AI 辅助、真人主导且按平台要求声明 | 低 | 保留过程证据 |
| 同人发布 | 中 | 确认授权边界与平台同人政策 |
| 跨媒体改编 | 中 | 确认完整版权链，必要时咨询专业人士 |
| AI 代写正文后发布 | 高 | 不推荐，可能下架/解约且版权弱 |
| 抄袭/洗稿/AI 降重他人文本 | 极高 | 严格禁止，承担侵权与违规后果 |

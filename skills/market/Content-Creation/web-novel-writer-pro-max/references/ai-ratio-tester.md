## 一、基本立场

1. **只估区间，不给单点**：输出形如 `5%–15%` 的区间与含义，不输出「AI 占比精确等于 12.3%」这类虚假精确值。
2. **非官方判定**：自测结果不代表平台结论，必须附「以平台实际检测为准」声明。
3. **不承诺通过**：本引擎帮助作者发现机器痕迹、提升原创质量，不提供、不暗示任何让机器内容冒充真人的手段。
4. **阈值分平台**：占比阈值只有起点公开过分档口径；番茄等无公开占比阈值的平台，信号灯只做风险提示，不套用起点数字。

## 二、五项特征检测

五项特征与检测白皮书共享维度 ID，每项给出「观察信号 + 强弱判断」，不做伪精确打分：

| 特征 | 维度 ID | 观察信号 | 风险升高的表现 |
|------|---------|----------|----------------|
| 高频词密度 | D-PERP/D-LEX | 程度副词、连接词、AI 高频短语密度（词表见 `ai-pools.md`） | 单位字数内高频词/短语成串出现 |
| 句长单一度 | D-BURST | 各句字数离散程度 | 句长高度集中、缺少长短交错 |
| 情绪平缓度 | D-EMO | 段落情绪强度序列（由 `emotion-curve-engine.md` 打分） | 情绪曲线近似直线、无谷峰落差 |
| 叙事工整度 | D-PERF | 结构对称、三段式、零瑕疵程度 | 处处对仗、无口语停顿与自然断裂 |
| 词汇多样性 | D-LEX | 同义替换与个人化重复情况 | 为换而换、缺个人化意象与口癖 |

每项按「弱 / 中 / 强」三档记录信号强度与**具体位置**（定位到段落或句子），不写无位置依据的笼统结论。

## 三、区间估算法

### 3.1 估算步骤

```

1. 按五项特征逐项扫描，各自给出 弱/中/强 与命中位置
2. 每项对应一个「贡献区间」（弱=0-5，中=5-15，强=15-30，单位：百分点，仅为经验权重区间）
3. 五项贡献区间取下限之和的下限、上限之和的上限，合成总区间
4. 总区间做封顶（不输出超过合理上限的数值）并收敛为宽区间表达
5. 结合目标平台红线，映射信号灯

```

### 3.2 区间含义（必须随结果输出）

| 区间 | 含义 |
|------|------|
| 0%–10% | 机器痕迹很弱，整体接近真人自然分布 |
| 10%–30% | 存在可辨识的机器痕迹，建议按命中位置做自然化修改 |
| 30% 以上 | 机器痕迹明显，核心段落建议实质性人工重写，而非只换词 |

> 权重区间是**经验估计工具**，不是平台算法；输出时必须说明这是基于五维特征的内部估计。

### 3.3 估算纪律

- 样本过小（如不足 100 字）不做区间估算，提示样本不足。
- 任一特征缺少可定位证据时，该项按「弱」处理并注明证据不足，不凭空加重。
- 长篇分章估算后再汇总趋势，不用单章结果代替全书（分块规则与 SKILL.md 超长文本处理一致）。

## 四、信号灯与分平台映射

### 4.1 信号灯（主刻度绑定起点公开口径）

- 🟢 **绿灯**：估计区间落在 0%–10%，机器痕迹弱。
- 🟡 **黄灯**：估计区间落在 10%–30%，存在可辨识痕迹，建议修改。
- 🔴 **红灯**：估计区间达到 30% 以上，痕迹明显，核心情节需人工重写。

### 4.2 分平台映射纪律

| 平台 | 信号灯用法 |
|------|------------|
| 起点 | 直接对照其公开分档口径（交付前核实具体数值），绿/黄/红按核实后的档位映射 |
| 番茄 | **无公开占比阈值**：信号灯仅表示「机器痕迹强弱」，同时必须叠加 `reader-signal-alert.md` 的四类低质检查，不得宣称「占比低即安全」 |
| 晋江 | 以叙事正文是否使用 AI 为核心，灯号仅作参考，从严提示 |
| 微信公众平台 | 不以占比判定，而以「是否需要如实声明」为结论，联动 `ai-disclosure-writer.md` |
| KDP/海外 | 不以占比判定，而以 generated/assisted 定性，联动 `ai-disclosure-writer.md` |

> 统一约束：10%/30% 主刻度来自起点公开口径方向；任何输出都要经 `verify-protocol.md` 按目标平台红线实时映射，**禁止把起点阈值套用到其他平台**。

## 六、执行流程

1. 确认目标平台；未指定先询问，不默认套用起点阈值。
2. 按五项特征扫描并定位，必要时调用 `emotion-curve-engine.md` 取情绪曲线。
3. 合成区间与信号灯，输出区间含义。
4. 按 `verify-protocol.md` 核实目标平台当期红线，完成分平台映射。
5. 给出可定位的修改方向（自然化写作动作见 `human-fingerprint.md`，一体化清洗走润色模块）。
6. 附非官方判定声明。

## 七、交付前核验清单

- [ ] 输出是否为区间而非单一百分比？是否附区间含义？
- [ ] 每项特征是否有位置依据，无证据项是否按「弱」并注明？
- [ ] 信号灯主刻度是否标注「起点口径」，其他平台是否按红线库分别映射？
- [ ] 番茄是否避免了「占比低即安全」、是否叠加四类低质检查？
- [ ] 是否附「内部估计、非官方判定、以平台为准」声明，且未承诺过检？

### 自检标准（可验证）

1. 用已知机器痕迹明显与接近真人的两类样本各测一次，灯号方向正确（明显样本偏黄/红，真人样本偏绿）。
2. 同一文本切换目标平台（起点→番茄→KDP）时，结论表述随之改变，不会把起点阈值原样套出。
3. 任意输出都包含区间、区间含义、分项位置、平台口径提示与非官方声明五要素。

> 每个模块交付前都会执行对应合规检查；发现风险会先提示后交付。

## 引导关闭机制

| 关闭方式 | 触发词 | 效果 |
|----------|--------|------|
| 永久关闭 | "下次不用引导了" / "关闭引导" / "skip tutorial" | 当前轮次继续走完，后续永久跳过引导 |
| 本轮跳过 | "跳过引导" / "直接开始" | 当前轮次跳过，下次仍然显示 |
| 恢复引导 | "重新开启引导" / "show tutorial" | 重新启用引导 |

## 用户配置文件

引导完成后，在会话中维护一份用户偏好档案，结构示例如下：

```json

{
  "user_level": "beginner",     
  "tutorial_disabled": false,   
  "preferred_language": "zh",   
  "default_genre": "都市异能",
  "default_length": "medium",    
  "default_platform": "fanqie"
}

```

用户可随时口头说明偏好调整，AI 按最新口径执行。

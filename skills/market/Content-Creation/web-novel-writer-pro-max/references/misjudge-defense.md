## 一、适用场景与原则

**触发词**：创作留痕 / 过程记录 / 创作档案 / 大稿管理 / 修改记录 / 创作过程整理 / 原创过程。

**基本原则**：

1. **真实第一**：只留存真实产生的创作过程材料，不伪造、不补造时间戳或历史记录。
2. **平时积累**：创作档案的价值来自连续记录，事后无法补出真实过程；养成边写边存的习惯。
3. **为创作服务**：留痕首先服务于作者自己——回溯设定演进、保持连贯、对比修改效果、与编辑高效沟通。
4. **客观克制**：对外说明创作情况时只陈述事实与材料，不情绪化、不使用攻击性表述，最终以平台规则与处理结果为准。

## 二、日常留痕清单

> 关键在「平时留存」。下列材料能留则留，逐步形成连续、可回溯的创作链。

| 材料类型 | 具体内容 | 留存方式 |
|----------|----------|----------|
| 过程版本 | 码字软件自动存档/历史版本（多数工具按分钟自动保存）、本地多版草稿 | 不随意清理历史版本，定期导出备份 |
| 时间记录 | 文件创建/修改时间、云端文档版本历史 | 使用带版本历史的工具，不手动改动系统时间 |
| 创作素材 | 大纲、人物卡、世界观、资料收集、拆书笔记 | 分目录归档，保留迭代痕迹 |
| 修改过程 | 批注、改稿记录、删改片段、润色前后对照 | 保留改稿层，不用最终稿一次性覆盖 |
| AI 辅助记录 | 若用过 AI 辅助，保留对话记录与用途说明 | 如实保留，与对外说明口径一致（见 `ai-disclosure-writer.md`） |
| 协作旁证 | 与编辑沟通记录、稳定更新记录、存稿计划 | 按个人条件留存 |

## 三、创作档案整理流程

```

1. 收集：按第二节清单归集过程材料
2. 排序：按真实时间线排列（素材→大纲→各版草稿→修改→定稿）
3. 对照：把章节的成稿过程对应到各版材料（如某段的多版修改）
4. 提炼：形成「构思—草稿—修改—定稿」的过程脉络
5. 归档：按作品/分卷/章节建立可检索的创作档案
6. 核验：确认时间线连续、材料之间无矛盾、与 AI 辅助记录一致

```

**过程梳理示例（结构示意）**：

| 梳理维度 | 对应材料 | 说明角度 |
|--------------|----------|----------|
| 一段文字如何打磨成型 | 多版草稿、删改记录 | 展示真实打磨过程 |
| 风格为何调整 | 改稿记录、练习稿 | 说明风格演进原因 |
| 高效更新从何而来 | 存稿、历史版本时间线 | 展示长期积累与稳定产出 |
| 长篇如何推进 | 大纲、素材、逐章过程 | 展示从构思到成稿的完整链路 |

## 四、AI 辅助记录口径

若创作中使用了 AI 辅助，如实记录其参与环节（灵感、大纲、资料整理、校对、润色等），并让创作档案与对外说明保持一致：

- 记录「用在哪个环节、解决什么问题、人做了哪些主导性工作」；
- 人始终是创作主体：构思、取舍、定稿由人完成，AI 只承担辅助动作；
- 不隐瞒 AI 辅助，也不把 AI 辅助内容宣称为「纯人工」，口径前后一致最省心；
- 具体说明文案见 `ai-disclosure-writer.md`，各平台对 AI 辅助的使用约定以 `verify-protocol.md` 实时核实结果为准。

## 五、客观说明创作情况

当需要向平台或编辑说明一本书的创作过程时，用事实和材料说话。各平台反馈渠道、材料格式、处理时限不同，**提交前先经 `verify-protocol.md` 核实当期规则**，此处只给通用写法：

```

【说明标题】《作品名》创作过程情况说明
【正文】
您好：
作品《___》的创作周期为___，创作方式为___（如实说明 AI 是否参与、参与何环节）。
现将创作过程材料整理如下，供参考：
1. ___（材料，对应___创作环节）
2. ___（材料，对应___创作环节）
针对关注的「___」，对应过程说明：___。
以上材料均为真实创作记录，感谢审阅。

```

**注意事项**：

- 只写与事实、与自身说明一致的内容，不写「百分百没用过 AI」这类与事实或既有声明矛盾的绝对表述；
- 不编造数据、截图或时间线；语气客观、简洁、就事论事；
- 是否采纳、如何处理以平台规则为准，本说明不改变也不替代平台流程。

## 六、交付前核验清单

- [ ] 创作材料是否全部真实、按时间线连续、无补造？
- [ ] AI 辅助情况的记录是否与对外说明、对话记录一致？
- [ ] 是否能用过程材料清晰呈现「构思—草稿—修改—定稿」链路，而非泛泛自称原创？
- [ ] 对外说明是否客观克制、无攻击表述、无绝对化与虚假承诺？
- [ ] 是否已先核实目标平台当期规则，并提示处理结果以平台为准？

### 自检标准（可验证）

1. 给定一部作品的创作素材，能整理出「时间线 + 过程对照 + 情况说明」三件套。
2. 对「用过 AI 辅助」与「完全人工」两种情形，能分别给出与各自事实一致、不互相矛盾的记录方式。
3. 全流程只出现真实留档与客观说明，不出现伪造记录或绝对化虚假承诺。

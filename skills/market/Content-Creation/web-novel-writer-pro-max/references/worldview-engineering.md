# 世界观体系树工程（从书名到逐章创作的完整体系）

> 一本小说的全部设定按"体系树"组织：树根是定位（书名/简介/卖点），树干是剧情（大纲/卷纲/章纲/细纲），树枝是人物（主角/配角/反派/势力/博弈），树叶是世界的细节（力量/道具/地图/生物/货币/社会人文/压力），树冠是"逻辑闭环 + IP考虑 + 逐章创作"。
> 版本：1.7.0
> 架构定位：体系树是单本书的设定总装；定稿后的可复用要素（力量体系/势力/地图/货币等设定卡）沉淀到 `asset-library.md` 供后续作品复用，实体动态变更走 `entity-state-machine.md`。
> 联动：体量工程见 `length-engineering.md`；卖点/对标见 `market-positioning.md`；爽点公式见 `signing-standards.md`；角色灵魂见 `character-depth.md`；题材模板见 `genre-templates.md`；桥段见 `plot-resources.md`。

---

## 一、体系树总览

```

【定位层】 书名 → 简介 → 卖点/看点 → 目标读者 → 对标书
【剧情层】 剧情大纲 → 卷纲 → 章纲 → 细纲（逐章创作蓝图）
【人物层】 主角 → 配角 → 反派 → 势力 → 博弈矩阵
【世界层】 力量体系 → 材料/道具/装备 → 场景/地图/副本 → 生物体系
          → 货币体系 → 社会人文 → 压力系统 → 作品视角
【闭环层】 设定-行为-后果闭环 → 时间线 → 逻辑自洽 → IP考虑
【产出层】 正文逐章创作（体量×题材×平台三轴约束）

```

**使用规则**：任何模块需要设定时，先明确当前处于哪一层；上层未定先补上层，禁止跳过定位层直接堆细节。

## 二、定位层

### 2.1 书名工程

**书名五要素**：题材标识 + 情绪钩 + 记忆点 + 差异化 + 平台字数

| 平台 | 字数偏好 | 风格倾向 | 示例式样 |
|------|----------|----------|----------|
| 起点 | 4-8字 | 大气/意象 | 《诡秘之主》《宿命之环》 |
| 番茄 | 8-16字 | 直白爽感/悬念 | 《我的技能每天刷新》 |
| 晋江 | 4-10字 | 温柔/诗感/梗感 | 《折月亮》《难哄》 |
| 知乎盐言 | 10-20字 | 故事感/悬念 | 一句冲突或悬念句式 |
| 抖音故事 | 15-25字 | 前3秒抓人 | 反转式短句 |

**书名公式**（选一种）：
1. 意象式：名词+名词 / 动词+名词（《雪中悍刀行》《剑来》）
2. 悬念式：反常识/留白（《我死后成了白月光》）
3. 反差式：身份+反差（《赘婿》《我在末世有套房》）
4. 身份式：XX的XX（《全宗门都以为我是大佬》）
5. 数据式：数字/时间（《重生之1998》《第一天就封神》）

**起名检查**：读三遍顺口 → 无生僻字 → 不与头部爆款撞名 → 平台搜索无大量同名 → 能一句话说清卖点。

### 2.2 简介工程

**简介三件套**：背景铺垫（1-2句）→ 核心冲突/反差（1-2句）→ 金手指+悬念钩（1-2句）。总长 150-300 字。

**三版简介**（不同用途）：
- 投稿版：冷静陈述世界观+主线，编辑看"可签约性"
- 读者版：情绪+爽感前置，读者看"想不想点"
- 平台版：按平台规范填（盐言要求故事感、抖音要求钩子前置）

**简介禁忌**：不剧透结局、不堆设定名词、不用形容词自夸（"这是一个荡气回肠的故事"）、不写人物小传式罗列。

## 三、剧情层

### 3.1 剧情大纲（一本书一页纸）

| 要素 | 内容 | 验收标准 |
|------|------|----------|
| 主线 | 主角要达成的目标（一句话） | 一句话能说清 |
| 核心冲突 | 主角 vs 谁 / 什么（对手/规则/自我） | 冲突可对抗、有升级空间 |
| 金手指 | 主角优势来源 + 限制 | 有边界、有代价 |
| 结局预设 | 走向明确（成长/救赎/复仇/守护） | 与主线呼应 |
| 三个大阶段 | 第一阶段小目标→第二阶段大目标→第三阶段终极目标 | 每阶段有明确失败风险 |

**大纲自检**：主线目标是否唯一？冲突方是否有能力与主角持续博弈？金手指是否会在中期失去张力（需要升级或换形式）？

### 3.2 卷纲（一卷的骨架）

每卷 = 一个完整情绪单元：**卷目标 → 卷冲突 → 卷高潮 → 卷钩子（下卷引子）**。

| 卷类型 | 卷目标 | 卷高潮 | 典型长度（长篇） |
|--------|--------|--------|----------|
| 第一卷·立身 | 主角获得立足能力+首个宿敌 | 第一次大危机/大突破 | 30-60章 |
| 中卷·上升 | 能力/势力/关系全面升级 | 阶段性决战 | 30-80章/卷 |
| 末卷·收束 | 主线目标达成+代价呈现 | 终极对决+余波 | 30-80章 |

**卷纲自检**：每卷是否推动主线至少一步？卷与卷之间是否有"升级-新敌-新目标"的螺旋结构（避免同质循环）？

### 3.3 章纲（一章的蓝本）

每章 = **冲突（或悬念）进入 → 推进（动作/对话/心理三选一为主）→ 变化（信息/局势/关系改变）→ 钩子（结尾留一口）**。

```

章纲模板：
- 本章目标（推进哪条线？给读者什么？）
- 开场切入点（接上一章钩子 or 新场景切入）
- 中段推进（1-2个冲突/信息节点）
- 结尾钩子（悬念/反转/危机/承诺 四种轮换）
- 本章爽点（≥1，密度按平台档位）

```

**章纲自检**：本章有没有"变化"？没有变化就是灌水章。每章至少一个"读者看完想翻下一页"的理由。

### 3.4 细纲（逐场逐句蓝图）

| 细纲粒度 | 内容 | 适用 |
|----------|------|------|
| 场级 | 场景/时间/在场人物/目的 | 章节内的叙事单元 |
| 动作级 | 关键动作/台词/心理节点 | 高潮戏/名场面 |
| 情绪级 | 本段读者应感到的情绪曲线 | 情感戏/铺垫戏 |

**细纲原则**：只标"节点"不标"全句"——留创作弹性；重要伏笔、关键台词、爆发点必须提前写进细纲，防止现场发挥丢线。

## 四、人物层

### 4.1 主角设定卡（一张卡定生死）

| 维度 | 内容 | 反例 |
|------|------|------|
| 欲望（三锚点之欲） | 主角最想要什么 | "想变强"（空洞） |
| 恐惧（三锚点之惧） | 最怕失去什么 | 无 |
| 边界（三锚点之界） | 什么绝不做/底线 | 无边界=无张力 |
| 缺陷 | 一个真实缺点（不是装点） | "唯一的缺点是太善良" |
| 心理痛点 | 过去事件形成的伤口 | 无来源的矫情 |
| 行为模式 | 遇事的第一反应习惯 | 与性格无关的随机行为 |

**三锚点**详细模型见 `character-depth.md`。主角卡验收：把卡上的欲望/恐惧/边界合起来，能解释主角全书 90% 的关键选择。

### 4.2 配角与反派

**配角三功能**：衬托主角（对手戏）/ 提供信息（推动情节）/ 提供情感（共鸣支点）。一个配角至少承担一主一辅。

**反派设定**：反派不是"坏"，是**与主角目标/价值观正面冲突的人**。
- 反派的欲望越"正"（忠诚/执念/正义偏差），冲突越有力
- 反派必须有赢过的能力（实力/资源/智力），否则无压迫感
- 反派与主角最好有"镜像关系"（同样的起点，不同的选择）

### 4.3 势力与博弈矩阵

**势力表**：势力名 / 目标 / 资源 / 对主角的态度（拉拢/打压/利用/无视）/ 内部矛盾。

**博弈矩阵**（用于设计智斗/权谋/多线冲突）：

```

        势力A    势力B    势力C    主角
势力A     —      敌对     利用     拉拢
势力B   敌对      —      同盟     打压
势力C   利用     同盟      —      观望
主角     拉拢     打压     观望     —

```

**博弈四问**：谁和谁的利益对立？谁掌握关键信息？谁会在什么条件下倒戈？主角如何利用别人的博弈渔翁得利？

## 五、世界层

### 5.1 力量体系

| 设计点 | 要求 | 反例 |
|--------|------|------|
| 获取方式 | 明确（修炼/血统/外挂/交易） | "天生有"（无成长感） |
| 升级路径 | 阶梯清晰+升级有代价 | 打怪就升级（无张力） |
| 力量代价 | 使用力量必有消耗/风险 | 无代价=无敌=无悬念 |
| 边界 | 最强之上还有压迫（世界压制） | 主角提前登顶 |
| 呈现方式 | 战斗事件呈现，非说明书（见 `writing-techniques.md`） | 境界表整段平铺 |

**力量体系与题材联动**：修仙/玄幻重"阶梯+代价"；都市异能重"限制+反差"；系统流重"规则漏洞+结算"；科幻重"硬规则自洽"。

### 5.2 材料 / 道具 / 装备

- 材料：来源 / 稀有度 / 用途 / 替代品（材料服务于炼器/炼丹/制作）
- 道具：功能 / 限制 / 副作用 / 与金手指的边界（防道具夺主角戏）
- 装备：成长性 / 识别度（专属外形与招式）/ 传承感

**道具设计自检**：这个道具能不能被替代？如果删掉它剧情不受影响→删除或强化。

### 5.3 场景 / 地图 / 副本

| 层级 | 内容 | 设计要求 |
|------|------|----------|
| 地图 | 大世界分区（国度/大陆/界域） | 每个区域有独特资源与危机，推动主线 |
| 场景 | 常用场景（宗门/家族/公司/城市） | 场景承载人物关系与冲突 |
| 副本 | 阶段性历练空间 | 规则清晰、奖励明确、有失败惩罚 |

**地图自检**：主角为什么必须去这个区域？不去会怎样？（用"不去=主线卡死"反推必要性）

### 5.4 生物体系 / 货币体系 / 社会人文

- **生物体系**：妖兽/怪物/异兽的等级与生态；敌我生物区分；生物是否可驯服/利用。注意：生物不是经验包，关键生物要有个体记忆点。
- **货币体系**：低级货币（铜币/信用点）→ 高级货币（灵石/星钻）；汇率与获取渠道；货币体系承载经济冲突（穷/富/物价/贫富落差）。
- **社会人文**：权力结构（皇权/宗门/财阀/联邦）/ 阶层与上升通道 / 习俗与禁忌 / 舆论与信息渠道。社会人文是"矛盾的生产线"——秩序压力制造主角反抗的理由。

### 5.5 压力系统（三轴压力）

主角始终被三种压力推动，缺一缺张力：

| 压力轴 | 来源 | 示例 |
|--------|------|------|
| 威胁压力 | 生存/复仇/死亡倒计时 | 追兵、毒发、世界毁灭倒计时 |
| 困境压力 | 资源/能力/信息不足 | 缺钱、打不过、找不到线索 |
| 代价压力 | 选择必须付出代价 | 救谁、牺牲什么、违背什么底线 |

**压力系统自检**：每章主角至少处于一种压力下；压力要升级不循环（同一威胁反复出现但没有升级=疲惫感）。

### 5.6 作品视角（POV）

| 视角 | 优点 | 适用 | 注意事项 |
|------|------|------|----------|
| 第一人称 | 代入感强、内心直给 | 悬疑/言情/轻小说 | 信息受限，别让主角看见不该看的 |
| 第三人称限知 | 主流选择、灵活 | 绝大多数网文 | 每章锁定一个视角人物，分章切换 |
| 多视角 | 全景/群像 | 权谋/战争/科幻 | 视角切换必须事件推进，防读者混乱 |
| 上帝视角 | 全知 | 传统文学/群像开局 | 网文中慎用，削弱代入感 |

**视角自检**：本章读者"跟着谁的眼睛看"？视角人物知道的信息边界是否一致（防"上帝泄露"）？

## 六、闭环层

### 6.1 设定-行为-后果闭环

```

设定（力量/货币/规则） → 主角行为（怎么用） → 后果（代价/奖励/连锁反应）
                                          ↓
                     新设定需求 ← 新矛盾/新问题

```

**闭环检查**：任何"大设定"必须至少被行为消费一次；任何行为必须产生可见后果；后果再反哺新矛盾——设定不是背景板，是剧情的发动机。

### 6.2 逻辑自洽五查

1. **时间线**：年/月/日与"X年前/三日后"全部对得上（可用时间轴文档）
2. **能力值**：实力对比前后一致（谁打得过谁不写崩）
3. **规则一致**：力量/货币/规则设定不因剧情需要临时改
4. **动机一致**：角色行为符合欲望/恐惧/边界（防OOC）
5. **信息流**：角色只能知道该知道的（防上帝视角泄露）

### 6.3 IP考虑（创作期即布局）

- 主角/反派的名字与形象考虑可视觉化（利于漫画/短剧/游戏）
- 世界观要能"多开一扇门"：主世界之外留有扩展空间（续作/IP宇宙）
- 名场面要"可视化"（利于短视频/短剧改编，见 `highlight-scenes.md`）
- 改编权注意：签约前看清楚权属条款（见 `legal-compliance.md`）

## 七、产出层：正文逐章创作

**逐章创作流程**（模块A/B 通用）：
1. 读取本卷卷纲 + 本篇章纲 + 细纲节点
2. 确定本章视角人物 + 起止节点 + 结尾钩子类型
3. 按"冲突进入→推进→变化→钩子"四段写
4. 写中自然度优化（连接词/句式/段落节奏，见 `anti-ai-engine.md`）
5. 写后质量内检（按 `quality-metrics.md` 12项指标逐项核验）
6. 更新状态（章节快照/伏笔追踪/角色快照，按 `memory-engineering.md` 维护）

**创作体量约束**：短/中/长篇的章节数、卷数、节奏密度全部按 `length-engineering.md` 执行。

## 八、体系树自检清单（交付前必过）

- [ ] 书名：顺口/无撞名/一句话说清卖点
- [ ] 简介：三件套齐全/150-300字/不剧透
- [ ] 主线：一句话能说清 + 有可对抗冲突
- [ ] 三锚点：主角欲望/恐惧/边界明确
- [ ] 反派：有正当动机 + 有赢的能力
- [ ] 力量体系：升级有代价/边界存在
- [ ] 压力系统：威胁/困境/代价三轴至少激活一轴
- [ ] 逻辑闭环：设定被消费/行为有后果/五查全过
- [ ] 视角：本章视角人物明确/信息边界一致
- [ ] 逐章：每章有变化+有钩子+有爽点（密度按平台）

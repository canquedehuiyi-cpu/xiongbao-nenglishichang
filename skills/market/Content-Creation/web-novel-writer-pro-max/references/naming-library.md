# 角色命名系统（真实接地气 · 好听好念 · 避免AI高频名）

> 命名规则 + AI高频名黑名单 + 男女频/时代/题材命名法 + 名字-角色联动
> 版本：1.7.0
> 自然度：AI 高频名/过度对称的名字组合是机器特征，命名黑名单与去重机理见 `human-fingerprint.md`。
> 联动：角色设计见 `signing-standards.md`（人物标准）；角色灵魂刻画见 `character-depth.md`；命名资产可沉淀到 `asset-library.md`。

## 一、命名四原则

1. **好念**：三个字以内顺口（zh/c/ch、zh/sh 音叠太多会拗口，试读两遍）
2. **好记**：避开生僻字，普通读者扫一眼能读出来
3. **贴人设**：名字暗示出身/性格/时代，但不过分直白（写手叫"叶知秋"太刻意）
4. **不撞梗**：避免影视/爆款小说同名同音（搜索验证）

### 2.2 命名特征黑名单（避开AI风格组合）

- "姓氏+单字雅词"烂大街：林晚/苏晚/顾言/陆离
- "复姓+生僻字"堆砌：慕容靥/南宫曜/尉迟邈
- "名词+动词"强行唯美：云知意/风知南/月知舟
- 三个字全平或全仄，念起来平淡

## 三、命名法（按题材/时代）

### 3.1 现代都市

| 方法 | 示例 |
|------|------|
| 生活化物件/场景入名 | 陈早茶、赵晚秋、林大川、周小满 |
| 单字名+常见姓 | 程野、韩乔、许树、孟芜 |
| 职业感/时代感 | 周德厚（年代）、陈工/李总（职场配角） |

### 3.2 古风/仙侠

| 方法 | 示例 |
|------|------|
| 字辈/排行 | 顾三郎、沈家行四、裴二娘子 |
| 地名/门第 | 谢家坞出身者：谢坞；雪山弟子：沈雪襟 |
| 道号/法名 | 清虚、无念、涤尘（配真实姓名） |
| 避免生僻 | 赵蘅、柳叶青、姜暝、裴渡（普通字组合） |

### 3.3 年代/乡土

| 方法 | 示例 |
|------|------|
| 按时代取名惯例 | 1950s：德厚/桂兰/秀兰；1980s：志强/海燕/春梅 |
| 小名/绰号 | 二丫、柱子、铁蛋、大嫚 |
| 改开期新名 | 文静、思远、佳宁 |

### 3.4 异界/西幻（英文）

| 方法 | 示例 |
|------|------|
| 音节和谐 | Mara、Elliot、Bren、Soria |
| 身份前缀 | Captain/Ser/High Priestess |
| 避免 | 与热门IP重名（Aragorn/Katniss等）、生造不可读拼写 |

## 四、名字与角色联动

### 4.1 命名即人设（三层检验）

1. 名字能否读出**出身**？（门第/地域/时代）
2. 名字能否暗示**性格走向**？（外向可用开口音，内敛用闭口音；反派名可带冷色字但别脸谱化）
3. 名字在**关键场景**是否好用？（呼唤/怒吼/低语时是否顺口——"顾辰！你站住！"顺口度测试）

### 4.2 称呼体系（区分主名/本名/绰号/职务）

| 称呼层 | 用途 | 示例 |
|--------|------|------|
| 主名 | 社会场景 | 程野 |
| 本名/字 | 亲密或揭底 | 程野，字听舟（古风） |
| 绰号 | 江湖/同学圈 | "野哥""程一拐" |
| 职务/关系称呼 | 场景切换 | 程总、小野、老程 |

> 称呼变化本身就是信息：全篇只叫"陆总"的人，在某个场景突然叫"陆修"，关系/身份的裂缝出现了。

### 4.3 命名禁忌

- 反派不叫"王富贵"这种脸谱式名字（搞笑角色除外）
- 重要角色不与爆款作品重名（创作前搜索）
- 群像角色名字互不混淆：首字或音节区分度高
- 英文名符合平台读者习惯（Webnovel/Wattpad 读者偏好易读名）

# 拆书模式 · 爆款作品分析系统

> 从同类型爆款作品中提取可复用的结构模板、量化基线与七层可复用资产，形成「拆得出来 → 用得回去」的闭环。
> 版本：1.7.0
> 定位：本文件只抽取跨作品共性的方法与结构，不复制任何具体文字表达（原创边界见 `anti-washing.md`）；自然度判据见 `ai-detection-dimensions.md`、执行见 `anti-ai-engine.md`；七层资产分别回流到 `creation-planner.md`、`emotion-curve-engine.md`、`character-depth.md`、`asset-library.md`、`entity-state-machine.md`、`promise-ledger.md`、`worldview-engineering.md`、`market-radar.md` 等模块。

| 题材大类 | 小类示例 | 分析重点 |
|----------|----------|----------|
| 玄幻修仙 | 凡人流/废柴流/重生流 | 力量体系/升级节奏/金手指设计 |
| 都市异能 | 赘婿流/重生商战/神医 | 身份反转/打脸节奏/爽点密度 |
| 历史穿越 | 架空/考据/系统 | 时代感/金手指限制/权谋线 |

| 悬疑灵异 | 规则怪谈/推理/盗墓 | 线索铺设/反转设计/悬念节奏 |

## 拆书维度

| 前3章结构模板 | 各章功能分配 |
| 第一章结尾钩子 | 钩子类型和强度 |

### 2. 章节节奏分析

| 分析项 | 说明 |
|--------|------|
| 平均每章字数 | 该类型爆款在目标平台的字数区间（平台口径见 `platform-data-registry.md`） |
| 每章平均爽点数 | 爽点密度参考值 |
| 钩子类型分布 | 各类型钩子的使用频率 |
| 章节结构模板 | 爆款的章节内部结构 |
| 节奏曲线 | 全书的快慢节奏分布 |

### 3. 爽点分布分析

| 分析项 | 说明 |
|--------|------|
| 爽点类型偏好 | 打脸/升级/获宝/复仇/装逼的占比 |
| 爽点间隔 | 平均几章一个爽点 |
| 大高潮节点 | 第几章首次大高潮、间隔 |
| 压抑-释放比例 | 压抑段和释放段的长度比 |

### 4. 人物原型分析

| 分析项 | 说明 |
|--------|------|
| 主角类型 | 废柴/天才/重生者/穿越者/隐藏大佬 |
| 金手指类型 | 系统/功法/血脉/宝物/重生记忆 |
| 女主/男主类型 | 辅助型/独立型/对手型 |
| 反派设计 | 小反派/中反派/大反派的递进模式 |
| 配角功能 | 功能性配角如何分配 |

### 5. 常见雷区

该类型爆款作品中常见的失败原因：
- 开篇太平淡
- 金手指太无敌（失去悬念）
- 节奏太慢
- 人设崩坏
- 设定堆砌太多

### 7. 人物弧光分析

### 8. 情绪曲线分析

## 七层可复用资产（1.7.0 核心）

拆书不止产出分析报告，更要把结论沉淀为**七层标准化资产**。每层一张资产卡，字段固定、可直接粘贴到对应创作模块复用；七层合起来构成「这本书为什么火、我怎么把方法迁移到自己书里」的完整答案。只抽取跨作品共性的方法，不复制任何具体文字表达（原创边界见 `anti-washing.md`）。

### 资产层 1 · 黄金三章公式

- **提取字段**：开篇 50 字钩子类型、首章冲突出现位置、金手指/核心设定登场章、前三章各自功能、第 1 章结尾钩子、前三章爽点数量。
- **可粘贴模板**：

  ```
  【黄金三章公式】
  开篇钩子：__（类型+写法）
  第1章功能：主角处境+核心冲突+__，章末钩子：__
  第2章功能：__，首次小爽点：__
  第3章功能：__，引出世界观/主线：__
  前三章爽点总数：__；金手指登场：第__章
  ```

- **输出去向**：`creation-planner.md` 章节层规划、`hook-templates.md`、`highlight-scenes.md`、签约创作模块 B。

### 资产层 2 · 节奏曲线

- **提取字段**：逐章张力档（高/中/低）、爽点位置、压抑-释放比、最长连续低张力区间、大高潮间隔。
- **可粘贴模板**：逐章张力序列 `ch1高(原因) ch2中 ch3高(爽点) …` + 节奏参数（平均几章一爽点、大高潮间隔、压抑释放比）。
- **输出去向**：`emotion-curve-engine.md` 曲线基线、`creation-planner.md` 节拍排布、`rhythm-patterns.md`。

### 资产层 3 · 人设弧光

- **提取字段**：主角起点状态、转折事件、终点状态（信念/能力/关系三条线）；反派动机与镜像关系；配角四功能（催化剂/镜子/影子/调停者）。
- **可粘贴模板**：

  ```
  【人设弧光卡】起点：__ → 转折：__ → 终点：__
  信念线/能力线/关系线各自变化：__
  反派镜像关系：__；配角功能分配：__
  ```

- **输出去向**：`character-depth.md`、`asset-library.md` 人物设定卡、`entity-state-machine.md` 弧光检查。

### 资产层 4 · 钩子体系

- **提取字段**：章末钩子类型分布、钩子强度、跨章衔接方式、卷末大钩子、悬念的埋设与回收间隔。
- **可粘贴模板**：钩子序列表（章号 | 钩子类型 | 强度 | 下一章如何回应）+ 该题材高频钩子组合。
- **输出去向**：`hook-templates.md`、`promise-ledger.md`（悬念类承诺的应兑现位置）。

### 资产层 5 · 爽点密度表

- **提取字段**：爽点类型占比（打脸/升级/获宝/复仇等）、每章爽点数、爽点间隔、大小高潮配比、爽点前置铺垫长度。
- **可粘贴模板**：

  ```
  【爽点密度表】每章__个；间隔≤__章；类型占比：__
  小爽点/大高潮配比：__；单次爽点铺垫长度：__
  ```

- **输出去向**：`signing-standards.md` 爽点矩阵、`emotion-recipes.md`、`emotion-curve-engine.md` 爽点检测、`reader-signal-alert.md`。

### 资产层 6 · 世界观释放节奏

- **提取字段**：设定首次出现位置、单次设定说明最长字数、设定释放载体（对话/动作/冲突/旁白）、开篇设定密度、核心规则交代时点。
- **可粘贴模板**：设定释放时间表（设定项 | 首次释放章 | 载体 | 单次字数 | 后续深化章）。
- **输出去向**：`worldview-engineering.md`、`asset-library.md` 世界观切片（最小释放量）、防开篇设定倾倒。

### 资产层 7 · 商业定位卡

- **提取字段**：题材标签、目标读者画像、核心卖点一句话、平台适配（字数/节奏/完读设计）、差异化定位、同赛道竞争位置。
- **可粘贴模板**：

  ```
  【商业定位卡】题材：__；读者：__；一句话卖点：__
  平台适配：__；差异化：__；风险/雷区：__
  ```

- **输出去向**：`market-positioning.md`、`market-radar.md`、`platform-guide.md`、签约模块的投稿定位。

### 七层资产验收

- 每拆一部作品，七层资产卡必须全部产出，缺层视为拆解不完整。
- 每张卡的字段都能在原文找到依据，不臆造数据；量化值与 16 项指标口径一致。
- 资产只含方法与结构，迁移到自己作品时必须换世界、换人物、换表达（过 `anti-washing.md`）。
- 七层资产随拆书报告一并交付，并标注可粘贴去向，形成「拆得出来 → 用得回去」的闭环。

## 拆书反AI扫描

拆解目标文本时（尤其用户提供的待分析稿件），同步执行 AI 语义指纹扫描，标注"人写特征 / AI特征"两类发现：

| 扫描项 | 检测内容 | 判定 |
|--------|----------|------|
| 高频词扫描 | 命中 `anti-ai-engine.md` 支柱一 14大类 AI 高频词 | 命中≥5处/千字 → 标注"模板化风险" |
| 模板化开头 | "在当今…/随着…/众所周知"等套话开头 | 命中 → 标注"AI味开头" |
| 总结性结尾 | "总的来说/这就是/由此可见"式收束 | 命中 → 标注"AI味结尾" |
| 句式同质化 | 连续3句以上同结构句式 | 命中 → 标注"机械句式" |
| 对话完美化 | 对话全部书面完整、无口语瑕疵 | 无碎对话/答非所问 → 标注"对话假" |

扫描结果写入拆书报告的"自然度特征"小节，供后续仿写/润色时反向规避；五维判据机理见 `human-fingerprint.md`。

## 填好的拆书报告样例（演示）

> 演示用法：以某玄幻修仙爆款（虚拟样例，仅示范结构）前 10 章为拆书对象，演示"10 大维度要点 + 16 项量化指标 + 七层资产"怎么填。量化数值按玄幻修仙对标口径填写（对话 25-45%、爽点≥1、章末钩子 100%、口语度≥2.0/千字、AI≤60）。注意：这里的 **AI≤60 是拆书对标采样上限**（爆款样本容忍轻度模板特征），**不是交付门控**——自写章节交付一律按规则核验的 ≤45 判定。

### 10 大维度分析要点（示例）

1. **开篇模式分析**：开头 50 字用"废柴跪祠堂+灵牌"立出身压迫，金手指（储物珠）第 1 章末尾觉醒；前 3 章结构为"受辱→测试→第一次反杀"，第 1 章结尾钩子是"珠子裂缝里的声音"。
2. **章节节奏分析**：10 章平均 2890 字/章，单章节奏固定为"铺垫 30%→冲突 40%→钩子 30%"；每章 1 次小爽点，第 4 章、第 10 章各放一次大爽点。
3. **爽点分布分析**：爽点类型以打脸（40%）和升级（35%）为主，穿插获宝（15%）与守护（10%）；压抑-释放比约 1:1.2，先抑后扬再压尾。
4. **人物原型分析**：主角走"废柴+隐藏金手指"流，外冷内稳；二叔是阶段性小反派，每 3 章出场一次递进敌意；师姐为辅助型女主，承担信息补充与情感支点。
5. **常见雷区（该作品规避掉的）**：金手指没写成一键无敌，代价明确；境界不靠说明书，靠"测灵台光柱"等事件展示；打脸不全靠主角嘴硬，用台下议论侧面烘托。
6. **金手指系统拆解**：储物珠=成长型外挂，解锁条件绑定境界；每用一次需吸收一块下品灵石，限制在第 2 章交代，避免"无代价开挂"失去悬念。
7. **人物弧光分析**：主角 10 章内完成"自证→立誓→第一次主动出手"三跳；反派动机落在"当年旧怨"而非脸谱化，为第 3 卷回收留口。
8. **情绪曲线分析**：单章情绪呈"压抑→爆发→期待"三段；前 10 章情绪低谷不连续超过 1 章，防止开篇劝退。
9. **钩子排布分析**：章末钩子 10 章全中（悬念 5 次、危机 3 次、身份 2 次），类型不连续重复；第 1 章末用"珠子裂缝里的声音"钩住追读。
10. **平台适配拆解**：按目标平台节奏适配（单章字数以 `platform-data-registry.md` 为准），10 章内埋 2 条长线伏笔服务完读率，大高潮压在第 10 章卷末。

## 执行流程

### 步骤1：确定拆书目标
- 根据用户指定的题材/类型（未指定时列出热门题材供选），确定需要拆解的类型
- 如用户指定具体作品，优先分析该作品
- 如无指定，分析该类型3-5部代表性爆款

### 步骤2：模式提取
- 按10大拆书维度提取模式（开篇/节奏/爽点/人物/金手指/弧光/情绪曲线/钩子/平台适配/雷区）
- 同步产出七层可复用资产卡
- 仅提取跨作品一致的共性模式，标注异常值（某部作品独特的打法）

### 步骤3：输出拆书报告
- 按上述模板结构填充，七层资产卡齐全
- 确保每个结论都有数据支撑
- 标注"建议参考"和"不宜照搬"（方法可学、表达不抄）

## 拆书→创作闭环

```
拆书目标 → 按 16 项指标拆解爆款章节 → 量化基线（对话%/爽点/钩子/口语/AI分）
    ↓
拆书报告（结构模板 + 量化基线 + 七层资产 + 雷区）
    ↓
七层资产注入：把黄金三章/节奏/弧光/钩子/爽点/世界观/商业定位七张资产卡粘贴到对应创作模块 → 每章自检（与基线逐项对比）→ 指标对不上基线 → 回炉修改
    ↓
对标差值 < 阈值 → 交付
```

1. **拆书阶段**：按 16 项指标拆解爆款章节，产出"该题材量化基线"（如玄幻修仙对话 25-45%、每章≥1爽点）与七层资产卡
2. **对标阶段**：拆书报告写入基线 + 结构模板 + 雷区清单（输出到用户项目目录下的"拆书报告"文档）
3. **创作阶段**：创作启动时由 `creation-planner.md` 注入报告与资产；每写完一章按指标自检，与基线逐项对比
4. **闭环验收**：全部指标达标（或偏差可解释）才放行，AI 分超交付门控需回炉去 AI

> 与 `signing-standards.md` 爽点库总矩阵 / `hook-templates.md` 钩子库总矩阵联动：拆书报告的爽点/钩子分析直接复用两库的类型词与四步节拍。

## 场景粒度拆解（场景拆书）

全本拆书之上再加一层**场景粒度**：把每章按场景切分，产出场景卡序列。

```
章节 → 按场景切分（换场/换时/换视角即切）
  ↓ 每场景产出场景卡五要素
① 场景起止（章内行号或时间锚点）
② 场景目标（推进什么信息/关系/冲突）
③ 冲突源与转折点（场景内张力来源+变化点）
④ 出场人物及状态变化（谁登场/谁离场/情绪转变）
⑤ 触发承诺（本场景埋设/回收的承诺 id，对接 promise-ledger）
```

- 拆书报告在"章节节奏分析"节后追加**场景卡表**（一场景一行）
- 场景卡序列的"冲突源→转折点"连线，就是该书的**最小张力单元曲线**（比章节粒度更细）
- 应用到创作：场景卡规划直接复用此结构（见 `plot-resources.md`）

## 张力对标曲线（参照书节奏/张力曲线仿写）

不凭空排节奏，而是**借爆款的张力曲线排自己的书**：

1. **拆书取曲线**：拆书报告从"情绪曲线分析 + 钩子排布分析 + 场景卡情绪档位"中提取**每章张力档**（高/中/低），按章连点成参考书"张力曲线表"：

   ```
   ch1 高(钩子:悬念) ch2 中 ch3 高(爽点:打脸) ch4 低(铺垫) ch5 高(爆点) …
   ```

2. **对标排布**：`creation-planner.md` 按参考曲线排自己的爽点/钩子/情绪节拍，同时套用题材×平台矩阵（`signing-standards.md`）校准密度
3. **自检对照**：新书每章写完按张力档逐章核验出全书张力曲线，与对标曲线逐章比对；连续 3 章张力 <40 即预警"节奏塌陷"，回看对标曲线补一节小爆点
4. 张力数值口径统一：规则核验口径的张力分/100（≥70 高 / 40-69 中 / <40 低），与拆书张力档一一对应；曲线量化与 `emotion-curve-engine.md` 对齐

> 与 `signing-standards.md` 爽点库 / `hook-templates.md` 钩子库 / `plot-resources.md` 场景卡联动；张力曲线是"情绪曲线分析"的量化延伸。

## 拆书报告输出约定

拆书报告作为交付物提供给用户，保存到用户项目目录下的"拆书报告"文档中。

- **格式规范**：严格遵循本文件的报告模板
- **生命周期**：仅当前创作项目有效
- **引用方式**：后续创作/审稿中可用 `[拆书参考]` 标签引用对应结论
- **原创边界**：报告只含方法、结构、量化基线，不含原作具体句子与段落（过 `anti-washing.md`）

## 四层榨取法（深度拆书）

| 层次 | 核心问题 | 产出 |
|------|----------|------|
| 骨架层(What) | 核心论点是什么？ | 定义+底层逻辑 |
| 肉质层(Why+How) | 为什么有效？ | 机制+案例三连 |
| 行动层(Action) | 我能怎么用？ | 执行SOP+迁移矩阵 |
| 批判层(Critical) | 有什么局限？ | 局限性+失效场景 |

**案例三连**：每个知识点配 3 个案例——同类型案例+跨题材应用+生活场景。
**跨题材迁移**：至少 3 个题材的落地方式。

## 写作问题诊断

当用户说"节奏太慢""开篇没人看""卡文了"时，自动匹配：

| 症状 | 可能根因 | 解决方案 |
|------|----------|----------|
| 开篇没人看 | 开头3段不抓人/前50字太平淡 | 重写开头：冲突开场/悬念开场/反转开场 |
| 节奏太慢 | 爽点间隔过长/描写过多 | 缩短描写段/提前第一个爽点 |
| 人物没记忆点 | 人设不够鲜明/金手指不够独特 | 给主角加标志性口头禅或动作 |
| 读者弃文 | 连续多章平淡/钩子不够强 | 每章结尾加强钩子/穿插小高潮（联动 `reader-signal-alert.md`） |
| 对话假 | 对话太书面化/不符合人物性格 | 增加口语化/按 `dialogue-engineering.md` 做人物语言分化 |
| 设定吃书 | 前后设定矛盾/力量体系崩了 | 用 `entity-state-machine.md` 建实体状态、每次写前查档 |

# 叙事风格库（风格类型学与一致性维护）

> 风格不是"文笔好"，是整套可复制的叙事选择：节奏、密度、温度、距离、幽默度、信息投放方式。本库给出风格类型学、风格定位、一致性维护与平台匹配。

## 一、叙事风格六轴（定位坐标）

任何作品风格都能用六轴定位，先定位再写作，全书统一：

| 轴 | 两个极端 | 中间态 |
|----|----------|--------|
| 温度轴 | 冷（克制/疏离）↔ 热（浓烈/煽情） | 冷暖交替 |
| 密度轴 | 密（信息高密/节奏快）↔ 疏（留白/慢） | 疏密结合 |
| 距离轴 | 近（贴身视角/内心多）↔ 远（全景/旁观） | 远近切换 |
| 庄谐轴 | 庄（正剧/沉重）↔ 谐（幽默/轻快） | 庄谐穿插 |
| 显隐轴 | 显（直给/爽点外放）↔ 隐（含蓄/潜台词） | 明暗搭配 |
| 叙述轴 | 述（叙述为主）↔ 演（场景对白为主） | 述演平衡 |

**风格定位自检**：六轴各定一位（写下来），全书写作时对照——偏离时是有意切换还是风格漂移？

## 二、八种常见叙事风格模板

| 风格 | 六轴定位 | 特征技法 | 代表气质 |
|------|----------|----------|----------|
| 冷峻写实 | 冷·密·近·庄·隐·演 | 白描+动作呈现+零评价 | 沉默有劲道 |
| 热血燃爆 | 热·密·近·庄·显·演 | 短句推进+画面定格+喊话 | 让人起鸡皮疙瘩 |
| 幽默吐槽 | 热·疏·近·谐·显·演 | 内心OS+反讽+自黑 | 轻松有梗 |
| 甜腻温柔 | 热·疏·近·谐·隐·述 | 微动作+慢镜头+心理 | 治愈拉丝 |
| 悬疑冷硬 | 冷·密·远·庄·隐·述 | 信息分阶+视角受限 | 压迫感 |
| 史诗厚重 | 冷·密·远·庄·隐·述 | 全景+时间纵深+克制抒情 | 大气沉稳 |
| 轻快明亮 | 热·疏·近·谐·显·演 | 短场景+快对白+轻悬念 | 爽快明亮 |
| 阴郁深沉 | 冷·密·近·庄·隐·演 | 环境压迫+心理独白 | 压抑灰暗 |

**用法**：选一种为主风格，全书基调统一；风格切换（如虐转甜）必须发生在卷/大情绪单元边界，章内不来回跳。

## 三、风格一致性维护

### 3.1 一致性要素

| 要素 | 维护方法 |
|------|----------|
| 语气温度 | 全书基调一致（冷文不突然煽情，甜文不突然阴冷） |
| 节奏惯性 | 章内节奏模式统一（前快后慢/密爽点等要稳定） |
| 用词层 | 叙述用词档位一致（口语化叙述不突然书面化） |
| 视角距离 | 叙述视角的"距离感"稳定（近身叙述不突然拉远） |

### 3.2 风格漂移检测（每卷自查）

1. 抽任意一章，与开卷章对比：温度/密度/距离是否漂移？
2. 续写/多写手协作时，用"六轴定位卡+风格样板段"校准
3. 出现漂移→定位是"有意演变"（弧光需要）还是"写滑了"（修正）

### 3.3 风格样板段

> 每本书设定一段 100-200 字的"风格样板段"（最典型的段落），写作/续写/交接前先读样板再动笔——这是风格一致性的低成本锚点。

**示例样板段（三档风格，均原创）**：

**男频热血风**（热·密·近·显，战斗/升级场景典型写法）：

```text

　　王铮一步踏碎青石，拳风裹着雷光砸向那尊铜甲傀儡。傀儡双臂交叉硬接，"铛"一声闷响，铜甲裂开蛛网般的缝。人群的喊声忽然矮下去——所有人都在等这一拳的结果。他没能砸穿。反震顺着手臂窜上来，虎口崩裂，血珠顺着拳锋往下淌。王铮却笑了，把血抹在额头上，重新摆开架势。宗主在台上眯起眼睛：这个废柴，第七拳，纹丝没退。

```

**女频甜宠风**（热·疏·近·隐，微动作+心理，治愈拉丝）：

```text

　　沈棠把伞往他那边偏了偏。陆淮没躲，只是低头看她，睫毛上还挂着雨珠。街灯亮起来的时候，她看见他耳尖红了一小块——他明明不怕冷。她想说"你别这样看我"，话到嘴边又咽回去，改口问："你晚饭吃了吗？"他嗯了一声，顿了顿，又补了句："没吃你煮的。"她没听清，他也没再说，两个人就站在屋檐下，听雨声噼里啪啦敲着青石板。

```

**悬疑冷硬风**（冷·密·远·隐，信息分阶+视角受限）：

```text

　　法医说死亡时间在凌晨两点到三点。程屿盯着死者手心的那粒黄铜纽扣，没接话。他记得清楚，昨晚十一点，报案人推开这扇门时，门锁是完好的，窗台没有脚印，院子里那排青砖却被人动过——砖缝里的苔藓，朝里侧是新掐断的。有人进去过，又出来过，然后这扇锁完好的门，在凌晨自己打开了。他蹲下身，用镊子夹起那粒纽扣，背面刻着一个"柳"字。

```

> 用法：写作/续写/多写手交接前，先读自己书的样板段三遍再动笔；每卷抽一章与样板段对比，漂移即校准（见 3.2）。样板段与书的主风格冲突时，以书为准重新立样板。

## 四、风格 × 题材 × 平台匹配

| 平台/题材 | 推荐风格定位 | 说明 |
|-----------|--------------|------|
| 番茄 | 热·密·近·显 | 爽点外放、节奏快、情绪直给 |
| 起点 | 冷热皆可·密·远 | 设定可铺、逻辑优先、可沉得住 |
| 晋江 | 热·疏·近·隐 | 细腻情感、含蓄、氛围感 |
| 知乎盐言 | 冷·密·近·隐 | 故事感、克制、首段抓人 |
| 抖音故事 | 热·密·近·显 | 反转高频、钩子前置、节奏极快 |
| 短剧改编 | 热·密·显·演 | 冲突外放、台词驱动、画面感 |
| 实体出版 | 庄·密·远·隐 | 更沉、更完整、少爽点多厚度 |

**匹配自检**：风格定位与目标平台/题材冲突时（如甜宠文写成冷硬悬疑风），要么改风格、要么换平台定位——两不相让必两头空。

## 五、风格工具箱（常用技法速查）

| 想要的效果 | 技法 |
|------------|------|
| 冷感 | 删形容词、多白描、情绪用动作呈现、少内心独白 |
| 热感 | 短句短段、情绪外放、画面定格、直接喊话 |
| 疏感 | 留白、空行、场景跳切、不解释 |
| 密感 | 多线并进、信息叠加、快节奏推进 |
| 谐感 | 内心OS、反讽、自黑、夸张比喻 |
| 庄感 | 长句长段、意象反复、克制抒情 |

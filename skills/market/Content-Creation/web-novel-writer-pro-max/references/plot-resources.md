> 写作时的"素材弹药库"：伏笔怎么埋、桥段怎么配、脑洞怎么生成、金手指怎么设计、热梗怎么用、特色词汇怎么造。全部为"方法+实例+自检"，不堆词条。
> 版本：1.7.0
> 架构定位：本文件产出伏笔/桥段/脑洞等素材；每条伏笔埋设后必须进 `promise-ledger.md` 走 planted→due→paid/deferred/broken/dropped 状态机，杜绝挖坑不填；可跨作品复用的桥段骨架沉淀到 `asset-library.md`（只收结构不收原句）。
> 联动：爽点公式见 `signing-standards.md`；名场面见 `highlight-scenes.md`；题材雷区见 `genre-templates.md`；拆书见 `novel-deconstruction.md`；热梗时效按 `evolution-protocol.md` 会话内补充。

## 一、伏笔库

### 1.1 伏笔四型

| 类型 | 定义 | 示例 |
|------|------|------|
| 线索型 | 物件/行为暗示真相 | 主角一直带在身上的半块玉佩 |
| 预言型 | 开头的话/梦在后文应验 | 老人口中"天煞孤星"的预言 |
| 身份型 | 表面身份下藏着真身份 | 杂役其实是前朝皇子 |
| 因果型 | 早年的因结后来的果 | 当年放走的小妖后来报恩/报仇 |

### 1.2 伏笔三规则

1. **埋得自然**：伏笔以"正常生活细节"出现，不刻意强调（刻意=读者警觉）
2. **露得渐进**：半露（读者隐约猜）→全露（证实）→回收（影响主线），忌讳一次性倒出
3. **收得有力**：回收时要有"哦！原来如此"的击打感——回收必须改变剧情走向，否则是废笔

### 1.3 伏笔时机表

| 位置 | 埋设建议 | 回收建议 |
|------|----------|----------|
| 前3章 | 埋全书级伏笔（身世/真相） | 中后卷半露 |
| 每卷中 | 埋卷级伏笔 | 卷末回收 |
| 每章 | 埋章级小钩子 | 当章/下章回收 |
| 关键章 | 埋反转伏笔（误导读者） | 反转点揭晓 |

**伏笔自检**：超过体量 1/3 仍未半露的伏笔 → 读者已忘，需"提醒性回扣"（借角色之口提起旧事）。按 `memory-engineering.md` 维护伏笔登记表：埋设 → 查看 → 查超期 → 标记回收。

### 1.4 伏笔四型模板库（每型 6 模板）

**线索型**（物件/行为暗示真相）：

| 模板 | 埋法 | 回收打法 |
|------|------|----------|
| 半块信物 | 主角贴身之物，另一半在真凶/真亲手上 | 两半合一的瞬间=身份/真相引爆 |
| 反常习惯 | 角色无法解释的习惯（不吃鱼/左手写字） | 有人认出这个习惯，道破身世 |
| 旧伤疤 | 与主角过往矛盾的伤口，看到的人态度骤变 | 伤疤来源被误读，真相是另一回事（双回收） |
| 重复记号 | 同一纹章/木牌反复出现（每次不同人持有） | 串成一条线，指向同一个幕后 |
| 名字记号 | 被改名/抹去的姓氏，只有旧人知道 | 旧人喊出旧名，全场反应分层 |
| 过时物品 | 一件不属于当下的物件 | 鉴定出年代/来历，牵出前朝/穿越线索 |

**预言型**（开头的话/梦在后文应验）：

| 模板 | 埋法 | 回收打法 |
|------|------|----------|
| 长者谶语 | 具体到事件的断言（"你命中有一劫"） | 事件发生时逐字应验，但应验方式反套路 |
| 孩童戏言 | 无心之言后来一字不差成真 | 读者回头"啊"——小孩早说过 |
| 梦中预言 | 反复做同一个梦，细节逐步成真 | 最后一次梦醒，发现是提醒而非预兆 |
| 占卜之语 | 卜者之言被全城嘲笑 | 嘲笑的人先后悔，预言半应验（留一半不准） |
| 临终遗言 | 死者留下的话，多年后被证实 | 证实时带出死者生前没说完的秘密 |
| 诅咒祝福 | 开场被下的诅咒/祝福 | 结局翻转为救/害，反转读者预期 |

**身份型**（表面身份下藏着真身份）：

| 模板 | 埋法 | 回收打法 |
|------|------|----------|
| 下人实为主子 | 杂役/下人过着不像下人的生活 | 危难时号令全场，身份+实力双揭 |
| 遗孤顶替 | 采药少年/小卒实为前朝遗孤 | 认亲信物+血脉测试双重证明 |
| 马甲宗师 | 商人/书生马甲下的宗门长老 | 被迫出手，围观者认出的瞬间 |
| 温柔细作 | 最温柔的女医/管家是敌国细作 | 身份揭晓反而揭示她为何背叛（因果） |
| 废物徒弟 | "天下第一"的废柴徒弟 | 师父亲口说出收徒真相 |
| 幸存者更名 | 灭门案幸存者顶替他人身份活着 | 认出的旧人替他守密，暴露另有原因 |

**因果型**（早年的因结后来的果）：

| 模板 | 埋法 | 回收打法 |
|------|------|----------|
| 报恩报怨 | 当年放走的小妖/孩童后来成关键人物 | 它来报恩/报仇的动机=当年的选择 |
| 随手之善 | 随手帮的路人后来搅动大局 | 他重提旧事，主角自己都忘了 |
| 遗仇成长 | 主角杀过的人，其子嗣长大复仇 | 复仇者身份+主角当年行为双反思 |
| 师债徒还 | 师父欠的旧债由徒弟来还 | 债主上门，师父往事揭开 |
| 先辈遗物 | 捡到的旧物牵出先辈恩怨 | 旧物主人后人寻来，恩怨延续 |
| 善意谎言 | 主角的善意谎言被揭穿 | 揭穿导致信任崩塌，连锁后果 |

> **用法**：选型→按模板埋→按 `memory-engineering.md` 登记伏笔（四型：线索/预言/身份/因果）→ 排回收节点。

### 1.5 伏笔×题材矩阵（主打2 + 辅助1 + 禁忌1）

| 题材 | 主打伏笔型 | 辅助型 | 禁忌（用了烂俗/出戏） |
|------|-----------|--------|------------------------|
| 玄幻修仙 | 线索、因果 | 身份 | 预言型当主线（"天命"烂俗） |
| 都市异能 | 身份、因果 | 线索 | 预言型（违和） |
| 历史穿越 | 身份、因果 | 线索 | 现代梗伏笔（出戏） |
| 科幻末世 | 线索、因果 | 预言 | 身份型（戏剧性过强） |
| 悬疑灵异 | 线索、预言 | 身份 | 无（全型通用，线索为主） |
| 游戏竞技 | 身份、因果 | 线索 | 预言型 |
| 武侠仙侠 | 因果、身份 | 线索 | 预言型 |
| 言情甜宠 | 线索、身份 | 因果 | 复仇型因果当主线（太重） |
| 悬疑言情 | 线索、身份 | 因果 | 无 |
| 轻小说 | 身份、线索 | 预言 | 沉重因果（风格不符） |

### 1.6 伏笔密度谱（按体量定埋/收节奏）

| 体量 | 全书级 | 卷级 | 章级钩子 | 密度法则 |
|------|--------|------|----------|----------|
| 20-50万字 | 1-2条 | 每卷1条 | 每章1个 | 全书级伏笔必须50%处半露 |
| 50-150万字 | 3-5条 | 每卷1-2条 | 每2-3章1个 | 每10万字至少1条卷级伏笔 |
| 150-300万字 | 5-8条 | 每卷1-3条 | 每章1-2个 | 全书级伏笔每30万字提醒性回扣一次 |
| 300万字+ | 8-12条 | 每卷2-4条 | 高频 | 主线:支线伏笔按 1:2 配比 |

**超期判定**：预期回收章已过 3 章仍未回收 → 对照伏笔登记表逐条排查超期项；已埋设但超过体量 1/3 未半露 → 提醒性回扣。

### 1.7 连锁伏笔（一埋多收/多埋一收）

| 结构 | 原理 | 示例作品式打法 | 配置要点 |
|------|------|----------------|----------|
| 伞形（一埋多收） | 一条大伏笔挂多条小伏笔，逐条回收汇入主线 | 琅琊榜式：身世谜底下挂多条身份线索 | 每条小伏笔独立回收节点，避免挤同一章 |
| 梯子形（多埋一收） | 多条独立小伏笔指向同一真相，同一章收束 | 推理式：多条线索指向同一凶手 | 回收分先后（先细节后真相），末章集中引爆 |
| 环形（因果闭环） | 伏笔A回收引出伏笔B，B回收回到A源头 | 时间循环/身世闭环式 | 闭环前至少1次提醒性回扣，防读者忘源头 |

### 1.8 回收三强度

| 强度 | 定义 | 写作要求 | 示例 |
|------|------|----------|------|
| 轻回收 | 兑现一个细节，不影响主线 | 1-2段内收束 | 开场提到的信物在对话中解释来历 |
| 中回收 | 改变一条支线/一个角色认知 | 半章-1章，必须有反应戏 | 身份半揭，同盟关系重组 |
| 重回收 | 改变主线走向/全书真相 | 大高潮级，前3章蓄势 | 身世真相揭晓，所有因果线汇合 |

**分配建议**：轻:中:重 ≈ 6:3:1；每卷至少 1 个中回收，每 50 章至少 1 个重回收。回收后必须在伏笔登记表中标记，避免重复回收/双收（同一条伏笔收两次是硬伤）。

## 二、桥段配置

### 2.1 桥段 = 情节功能单元

桥段不是套路，是"带功能的叙事模块"。配置桥段看**功能**：

| 桥段 | 功能 | 使用频率 |
|------|------|----------|
| 危机引入 | 建立压力 | 每卷至少1次 |
| 实力对比 | 制造张力/铺垫 | 高潮前 |
| 信息反转 | 改变读者认知 | 每3-5章1次 |
| 关系升温/破裂 | 情感推进 | 持续 |
| 身份揭晓 | 引爆累积悬念 | 关键节点 |
| 绝境翻盘 | 爆发爽感 | 每卷1-2次 |
| 日常留白 | 节奏调节+人味 | 间隔插入 |

### 2.2 桥段配置三原则

1. **功能驱动**：先问"这段要完成什么功能"，再选桥段；不为了桥段而桥段
2. **交替轮换**：同类桥段不连用两次（危机之后接留白，反转之后接升温）
3. **密度匹配体量**：短篇桥段密集（每章都带功能），长篇允许铺陈（但要算灌水账）

### 2.3 桥段升级法（老桥段新用法）

| 常见桥段 | 升级方向 | 示例 |
|----------|----------|------|
| 英雄救美 | 救完被误会成凶手 | 救了人反而被通缉 |
| 打脸反转 | 反转给"第三方"看 | 打脸的不是主角而是围观群众 |
| 藏拙 | 藏拙被意外揭穿一半 | 只露一半，另一半留更大悬念 |
| 金手指觉醒 | 觉醒代价巨大 | 变强一分，寿命减一载 |

## 三、脑洞生成

### 3.1 脑洞公式（组合法）

`脑洞 = 设定内核 × 主角处境 × 反转开关`

| 设定内核 | 主角处境 | 反转开关 | 生成脑洞示例 |
|----------|----------|----------|--------------|
| 读心术 | 满朝都在算计他 | 他读到的是对方"想让他读到的" | 读心术皇子反被套路 |
| 无限重生 | 每次重生记忆保留 | 敌人也会读档 | 无限流对无限流 |
| 系统 | 系统是金牌辅助 | 系统其实是主角的分裂人格 | 系统人格觉醒 |
| 穿越 | 穿进自己写的扑街书 | 书里角色知道作者来了 | 被书中角色反向攻略 |
| 时间循环 | 困在同一天 | 循环天数可以转让给别人 | 循环贩卖者 |

### 3.2 脑洞验证三问

1. **一分钟梗概能说清吗？** 说不清=设定太绕
2. **主角有没有主动选择的空间？** 全是被动=无戏可写
3. **高潮有没有画面感？** 一句话描述不出高潮=脑洞不成立

### 3.3 脑洞与题材的适配

| 脑洞类型 | 天然适配题材 |
|----------|--------------|
| 系统/面板 | 都市/玄幻/游戏 |
| 时间/循环 | 悬疑/科幻/都市 |
| 身份/马甲 | 男频装逼/女频掉马 |
| 规则/怪谈 | 灵异/克苏鲁/无限流 |
| 情感/反转 | 言情/治愈/致郁 |

## 四、金手指生成

### 4.1 金手指五要素

| 要素 | 要求 | 反例 |
|------|------|------|
| 功能 | 一句话说清能做什么 | "无所不能" |
| 限制 | 使用有代价/冷却/边界 | 无限使用 |
| 成长 | 随剧情升级或换形态 | 开局即满级 |
| 对手 | 世界对金手指有反制 | 无敌碾压 |
| 代价 | 使用金手指要失去什么 | 免费外挂 |

### 4.2 金手指类型库

| 类型 | 原理 | 经典变体 |
|------|------|----------|
| 系统类 | 面板/任务/奖励 | 反派系统、摆烂系统、商人系统 |
| 能力类 | 单一超能力 | 读心/存档/复活/搬运 |
| 知识类 | 信息差/先知 | 重生记忆、未来新闻、剧透 |
| 资源类 | 物资/空间/人脉 | 随身空间、无限仓库 |
| 规则类 | 改写世界规则 | 概率操控、文字具现 |

### 4.3 金手指升级路径

```

1级：解决眼前小困境（低代价）
2级：解决阶段大危机（代价显现）
3级：暴露副作用/被敌人盯上（金手指成为新冲突源）
4级：进化/换形态（代价升级，绑定主线）

```

**金手指自检**：把金手指删掉，主线还能推进吗？如果能→金手指不是引擎是装饰。金手指必须有"被克制"的设计（反派有反制手段）。

## 五、热梗奇思

### 5.1 热梗使用原则

- **热梗 = 读者社交货币**：用在对话/弹幕感/名场面，让读者"懂了会心一笑"
- **时效性**：热梗有生命周期（平台实时进化的由动态库补充），过气梗慎用
- **平台差异**：男频/女频/短视频平台的热梗受众不同
- **浓度控制**：一章 0-2 个热梗点缀，堆砌=廉价感

### 5.2 热梗三类用法

| 用法 | 说明 | 示例方向 |
|------|------|----------|
| 台词化 | 角色说人话用热梗 | 吐槽、吐槽弹幕感 |
| 情节化 | 热梗本身成为情节元素 | "你不对劲"变成角色行为 |
| 反用化 | 角色不懂热梗/误解 | 穿越者被古人学去热梗 |

### 5.3 特色词汇库（自造词方法）

**自造词四法**（比堆设定名词高级）：

| 方法 | 说明 | 示例 |
|------|------|------|
| 具象化 | 抽象概念变成可感知物件 | 把"命运"写成"命线" |
| 动词化 | 用动作命名概念 | 把"突破"写成"破境" |
| 组合化 | 两词碰撞出新意 | "诡秘"+"序列"→诡秘序列 |
| 口语化 | 用日常词改装 | 把"召唤兽"叫"跟班" |

**特色词汇自检**：新词第一次出现必须借剧情自然解释（不写说明书）；全书自造词≤20个（多=读者记不住）。

## 六、桥段/伏笔/脑洞/金手指 使用自检

- [ ] 伏笔：类型明确/埋得自然/回收节点已排期
- [ ] 桥段：功能驱动/交替轮换/密度匹配体量
- [ ] 脑洞：一分钟能说清/主角有主动空间/高潮有画面
- [ ] 金手指：五要素齐全/有克制/升级路径明确
- [ ] 热梗：浓度克制/平台适配/不过期
- [ ] 特色词汇：有解释/数量受控

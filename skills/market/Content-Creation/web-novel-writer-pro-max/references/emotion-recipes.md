## 五大情绪化学配方

每种情绪有明确的化学公式、写法核心、节奏控制和实际场景范例：

### 愤怒
**化学公式**: 不公 + 无力 + 践踏珍贵
**写法核心**: 让读者代入主角感受不公平。先让读者喜欢上某物/某人/某种价值，然后它被践踏，主角无力阻止。
**读者反应**: 咬牙切齿，想冲进去帮主角
**常见场景**:
- 好人被冤枉，百口莫辩
- 弱小被欺负，无人相助
- 珍贵之物被毁，回天乏术
**写作检查**:
- ✅ 读者是否已经对受害之物产生了感情？
- ✅ 迫害者的"恶"是否足够具体（不是抽象的说他坏）？
- ✅ 主角的无力感是否通过动作/身体反应展现（不是直接说"他很愤怒"）？
- ❌ 避免：愤怒持续超过3章不爆发 → 读者会弃文

### 绝望
**化学公式**: 希望 + 全力 + 降维真相
**写法核心**: 先给希望再粉碎。主角找到一线希望→全力一搏→真相揭露（希望是假的或不够）。
**读者反应**: 心提到嗓子眼，不忍心看
**常见场景**:
- 找到解药但解药不够
- 以为找到靠山但靠山是假的
- 奋力一搏后发现一开始就错了
**写作检查**:
- ✅ "希望"是否足够真实可信（不是一眼假的）？
- ✅ 读者是否和主角一起为这个希望付出了期待？
- ✅ 粉碎的方式是否出乎意料但合情合理？
- ❌ 避免：绝望场景堆叠过多 → 读者会麻木

### 心动
**化学公式**: 身份业绩 + 共享秘密 + 强者脆弱
**写法核心**: CP感的核心引擎。展示对方的能力/成就→共享一个只有彼此知道的秘密→看到对方不为人知的脆弱一面。
**读者反应**: 姨母笑，疯狂磕CP
**常见场景**:
- 并肩作战后，发现彼此的默契
- 患难与共时，看到对方真实的一面
- 深夜独处时，发现对方的另一面
**写作检查**:
- ✅ "身份业绩"是否具体（不只是"他很厉害"而是具体做了什么事）？
- ✅ "共享秘密"是否真的是只有他们俩知道的事？
- ✅ "脆弱"是否够真（不是装脆弱）？
- ❌ 避免：第一眼就心动 → 缺少积累

### 热血
**化学公式**: 必死 + 悬殊 + 虽千万人吾往矣
**写法核心**: 明知不敌也要上。清晰展示敌我悬殊→所有人都说"算了"→主角说"我上"。
**读者反应**: 热泪盈眶，浑身发麻
**常见场景**:
- 为战友断后，明知必死
- 为信念赴死，虽死犹荣
- 为弱者挡刀，不图回报
**写作检查**:
- ✅ 敌我悬殊是否清晰量化（人数/实力/胜率）？
- ✅ "不上"的理由是否充分合理？
- ✅ 主角的"上"是否有具体动作（不只是台词）？
- ❌ 避免：主角每次都热血 → 读者会觉得"又来了"

### 孤独
**化学公式**: 巅峰 + 消散 + 无人诉说
**写法核心**: 强者独处的落寞。展示主角达到巅峰→环顾四周发现故人已散→想分享喜悦却发现无人可说。
**读者反应**: 沉默，共情
**常见场景**:
- 登顶后孤身一人，环顾四周空无一人
- 功成名就后发现初心已失，无人分享
- 变强后旧友已远，新交不知旧事
**写作检查**:
- ✅ "巅峰"是否足够高（读者能感受到代价）？
- ✅ "消散"是否具体（不是抽象地说"朋友们都走了"而是有具体的人和事）？
- ✅ 最后的"无人诉说"是否通过一个微小的动作呈现（不是直接说"他很孤独"）？
- ❌ 避免：孤独情绪持续整本书 → 太压抑

## 爽点四步节拍（各爽点类型四步映射见 signing-standards.md「爽点库总矩阵」）

所有爽点通用模板：

```

极度打压（拉仇恨）→ 底牌蓄力（拉期待）→ 降维打击（碾压不要险胜）→ 余波反馈（50%爽感来自围观反应）

```

### 四步详解

**第一步：极度打压**
- 让主角处于绝对劣势，让反派嚣张到让读者生气
- 拉仇恨越狠，后面的爽感越强
- 打压持续时间：不超过3章，否则读者跑了
- 常见手法：当中羞辱、抢夺宝物、威胁亲友、不公平对待

**第二步：底牌蓄力**
- 暗示主角有底牌，但不说穿
- 制造期待："主角要怎么翻盘？"
- 蓄力要短，不要拖（1-2个自然段足够）
- 常见手法：主角摸了一下某个东西/看了一眼某个方向/嘴角微微上扬

**第三步：降维打击**
- 碾压式胜利，不要险胜
- 展示实力的绝对差距（让反派措手不及）
- 常见手法：一招制敌、身份揭晓、反手一耳光

**第四步：余波反馈**
- **50%的爽感来自围观反应**
- 让围观群众震惊、羡慕、后悔
- 让读者感受到"爽"——不是主角一个人爽，是读者跟着爽
- 常见手法：周围人的惊叹、反派的崩溃、消息传开

### 7种爆点类型交替规则

同一类型不连用两次：
1. 身份反转
2. 实力碾压
3. 信息炸弹
4. 关系反转
5. 奖励震撼
6. 台词暴击
7. 画面冲击

## 情感描写五技法

替代直接说情绪，用以下技法让读者感受到、而不是被告知：

### 1. 身体反应替写
不直接说情绪，写身体在做什么：
- "他不安" → "他手指在桌上敲了三下，停住，又敲了两下"
- "她紧张" → "她攥着杯子的手指泛白"
- "他害怕" → "他喉咙发紧，半天没说出话"
- "她难过" → "她低头扒饭，一粒一粒地往嘴里送"
- "他震惊" → "手里的杯子掉在地上，他没去捡"

### 2. 行为异常替写
该做的事不做，做反常的事：
- 该说话时不说话 → 沉默，空气凝固
- 该动时不动 → 呆在原地，像被钉住了
- 该哭时不哭 → 笑了一下，比哭还难看
- 该生气时不生气 → 很平静，然后做了一件更可怕的事

### 3. 细节放大法
聚焦一个极细微的细节写一整段：
- "她盯着茶杯里的一根茶叶梗，看着它浮起来，又沉下去。浮起来，又沉下去。"
- "他蹲下来系鞋带。系了五分钟。其实鞋带根本没散。"
- "窗外的雨一直下。她一直看着雨。不是在看雨，是在等雨停。也不是在等雨停。"

### 4. 沉默留白法
不写了，用空行代替：

```

"我们分手吧。"

（空行）

他转身推门。风铃响了一声。

```

### 5. 事后追溯法
事后才意识到当时的情绪：
- "他当时没多想。后来在地铁上，他才意识到那一眼意味着什么。"
- "很久以后她回想起这个瞬间，才明白那是他们最后一次好好说话。"
- "多年后他站在领奖台上，突然想起那个傍晚，那个所有人都没当回事的约定。"

## 3章情绪单元循环

```

压(铺垫/小冲突) → 小扬(小爽点/小满足) → 压(新冲突/新悬念) → 爆(高潮/大爽点)

```

### 全书关键节点
| 位置 | 情绪任务 | 强度 |
|------|----------|------|
| 第1章 | 主角出场+危机+金手指觉醒 | 中高 |
| 第3章 | 第一次小逆袭或打脸 | 中高 |
| 第10章 | 第一次大升级或大打脸 | 高 |
| 第30章 | 第一个大高潮 | 极高 |
| 每50章 | 一个大高潮 | 高 |
| 每100章 | 一个决定命运的高潮 | 全书最高 |

### 情绪曲线检查
每5章检查一次情绪曲线，确保：
- 没有连续3章"平"（读者要跑了）
- 没有连续3章"高"（读者会疲劳）
- 高低交替，节奏感清晰

## 全书情感曲线模板（按叙事类型选一条主曲线）

> 情绪曲线不是"心情日记"，是**整本书的情绪走势图**——读者在整个阅读周期里被怎样牵着走。选一条主曲线贯穿全书，再叠加卷级小曲线。

### 模板一：爽文逆袭曲线（男频/系统流/升级流）

```

低谷(开局压) → 首次逆袭(第3-10章小爽) → 上升(阶段性打脸)
→ 再压(新敌人) → 大爽(卷末高潮) → 高峰(书中段位顶峰)
→ 至暗(信任崩塌/失去至亲) → 绝境翻盘(全书最高潮) → 余韵收束

```

**情绪任务**：先给读者"憋屈→释放"的爽感训练，再给"绝境→新生"的升华。爽点密度按平台档位（`signing-standards.md`）。

### 模板二：追妻火葬场曲线（女频/虐恋/破镜重圆）

```

甜(开局/回忆) → 裂(误会/伤害，读者开始心疼)
→ 虐(男主追悔，女主心冷，读者骂爽)
→ 转(女主自愈/新追求者出现，男主危机感)
→ 火葬场(男主真诚付出代价) → 和(破镜重圆，情绪释放)

```

**情绪任务**：虐要"有道理"（女主的苦必须具体），火葬场要"够代价"（不是道歉就行），和好要有仪式感。

### 模板三：成长救赎曲线（正剧/热血/成长向）

```

平凡(痛点清晰) → 动摇(诱惑/岔路，跌入低谷)
→ 挣扎(内心拉扯，最灰暗章节) → 顿悟(想通/被唤醒，事件驱动)
→ 蜕变(行动证明改变) → 升华(守护他人/完成使命)

```

**情绪任务**：低谷必须"真"（有真实的失败与代价），顿悟必须"事件驱动"（不能睡一觉想通）。

### 模板四：治愈陪伴曲线（治愈/种田/日常向）

```

疏离(孤独/创伤开头) → 靠近(遇见善意，微暖)
→ 拉扯(旧伤复发/退缩) → 托底(被接住，情绪峰值)
→ 新生(生活重建) → 温暖(日常即幸福，余韵悠长)

```

**情绪任务**：治愈靠"细节的暖"（不是大事件），峰值要在"被接住"的瞬间（有人无条件站在你这边）。

### 模板五：悬疑解谜曲线（悬疑/无限流/规则怪谈）

```

异象(悬念开局) → 线索(阶段性解答，假象得逞)
→ 反转(真相推翻，读者被误导过) → 逼近(代价显现，恐慌升级)
→ 揭示(核心真相) → 余波(真相背后的真相)

```

**情绪任务**：每个阶段解答都必须"带出更大的问题"；反转要有伏笔支撑（`plot-resources.md` 伏笔四型）。

### 主曲线选择自检

- 主曲线与题材/平台匹配吗？（番茄爽文≠治愈慢热）
- 全书最高点在计划位置吗？（通常全书 75%-85% 处）
- 卷级小曲线与主曲线不冲突吗？
- 主曲线两端（开局情绪/结尾情绪）定调了吗？

## 视听化三件套（高潮戏必用）

1. **极其安静的环境音**: "四周安静得能听到自己的心跳""空调的嗡嗡声突然变得很响"
2. **镜头拉近盯微小物件**: 不写宏大场面，写一个小物件——"他盯着刀尖上的一滴水"
3. **反常客观动作**: 不直接写情绪，写身体在做不相关的事——"他端起杯子喝了口水。水是凉的。他又喝了一口。"

## 共鸣引擎五大驱动力

| 驱动力 | 对应的读者心理 | 写作方法 | 典型场景 |
|--------|---------------|----------|----------|
| **被看见** | 渴望被理解、被关注 | 写出读者心里有但说不出的感受 | 配角理解主角没说出口的话 |
| **被选择** | 渴望被偏爱 | 设置"坚定选了TA"的场景 | 二选一时毫不犹豫选了主角 |
| **来得及** | 害怕错过 | 设置"最后的机会" | 再不做就来不及了 |
| **不公平** | 对不公的本能愤怒 | 让主角经历不公 | 努力不如关系、好人没好报 |
| **不孤独** | 害怕独处 | 角色间深厚的情感纽带 | 有人跨越山海来找你 |

### 克制美学
- **大悲不哭**: 最悲伤时角色不哭，读者替角色哭
- **大喜不笑**: 最开心时角色做一件无关的事——低头擦桌子，手在抖
- **大恨不骂**: 最恨时角色不说话，反而很平静——"你走吧。"门关上，杯子碎了
- **情绪=动作+留白**: 不解释情绪，只呈现行为和场景。读者自己会感受到

### 常见情绪描写错误对照

| ❌ 错误写法 | ✅ 正确写法 | 问题分析 |
|------------|------------|----------|
| 他非常愤怒 | 他握紧了拳头，指节发白 | 直接说情绪→写身体反应 |
| 她感到一阵悲伤 | 她别过脸去，盯着窗外 | 抽象感觉→具体动作 |
| 他心中涌起一股暖流 | 他愣在那里，半天说不出话 | 套话→真实反应 |
| 她感动得热泪盈眶 | 她低头喝茶，水在眼眶里打转，没让它掉下来 | 标签化→细节化 |
| 他内心充满愧疚 | 他不敢看她的眼睛 | 抽象→具体行为 |

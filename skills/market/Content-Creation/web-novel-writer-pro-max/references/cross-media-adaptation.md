# 跨媒体改编指导

> 小说 → 短剧 / 漫画 / 漫剧 / AI 有声书 / 游戏 / 真人剧 改编方法论 · 剧本回写小说
> 分工边界：本文件只讲改编方法论与回写规律（叙事转换、体量换算、分集/分镜原则）；真正向外部图像/视频/音频生产交付时，由 `cross-form-orchestrator.md` 产出「设定卡/风格词/结构分镜/一致性守则/边界声明」五件套指令包，本 Skill 不内置任何图/视/音生成运行时；AI 配图/配音的平台披露见 `ai-compliance-redlines.md`。

## 一、短剧改编

### 格式规范
- 单集时长：1-3分钟（竖屏短剧）
- 集数：付费/投流与精品档集数见 platform-data-registry 第七节（实时核实）
- 总时长：60-300分钟
- 单集字数：见 platform-data-registry 第七节与 screenplay-creation 格式规范（实时核实）

### 小说→短剧改编流程

| 步骤 | 内容 | 注意事项 |
|------|------|----------|
| **1. 核心冲突提取** | 从小说中提取可视觉化的核心冲突 | 内心独白→外在冲突转化 |
| **2. 人物精简** | 保留3-5个核心角色，其余合并或删除 | 配角过多会分散注意力 |
| **3. 场景拆分** | 将小说场景拆为1-3分钟独立场景 | 每场景必须有冲突+转折 |
| **4. 对白改写** | 小说叙述→短剧对白，信息量全部对白化 | 删掉心理描写，用行动/表情替代 |
| **5. 钩子强化** | 每集结尾必须有强钩子 | "下集更刺激"式悬念 |
| **6. 节奏压缩** | 小说10章内容→短剧3-5集 | 删掉过渡，只留冲突 |

### 短剧剧本格式

```

═══════════════════════════════════
第1集 「重生之夜」
═══════════════════════════════════

【场景1】办公室·夜
[氛围：压抑，暖黄台灯，文件堆积]
周雨（28岁，疲惫白领）伏案，手机震动。

周雨：（低声）妈，我加班...

【场景2】回忆闪回·三年前
[画面：婚礼现场，双喜剪纸]
前夫陈昊揽着新娘，周雨站在门外。

周雨（画外音）：我以为那是结束。

【场景3】医院走廊·现在
[氛围：冰冷，白色荧光灯]
周雨盯着手机——体检报告。

周雨：（捏紧手机）晚期...

═══════════════════════════════════
⚡ 钩子：她倒下时，一道光吞没世界——
   她睁眼，回到三年前婚礼当天。
═══════════════════════════════════

```

### 短剧平台适配

| 平台 | 单集时长 | 集数 | 风格偏好 | 签约要求 |
|------|----------|------|----------|----------|
| **快手短剧** | 2-5分钟 | 集数见 platform-data-registry 第七节 | 逆袭/甜宠/复仇 | 星芒计划/光合计划 |
| **抖音短剧** | 1-2分钟 | 80-100集 | 悬疑/反转/甜宠 | 抖音剧情号签约 |
| **芒果TV短剧** | 3-5分钟 | 30-50集 | 言情/都市 | 大芒计划 |

## 二、漫画改编

### 格式规范
- 每话页数：12-20页
- 每页格数：4-8格
- 对白气泡：单气泡≤30字
- 旁白框：单框≤40字

### 小说→漫画改编流程

| 步骤 | 内容 | 注意事项 |
|------|------|----------|
| **1. 关键场景选取** | 从小说中筛选视觉冲击力强的场景 | 内心戏→视觉隐喻转化 |
| **2. 对白压缩** | 小说叙述→漫画气泡，信息密度3倍压缩 | 1段小说描写→1格画面+1句对白 |
| **3. 画面构图** | 为每格设计构图：远景/中景/近景/特写 | 节奏感：远景铺陈→近景冲突→特写情绪 |
| **4. 视觉节奏** | 格大小变化制造节奏 | 大格=重要时刻，小格=快速过渡 |
| **5. 留白设计** | 无字格/大空镜营造氛围 | 关键情绪点用留白强化 |

### 漫画分镜格式

```

═══════════════════════════════════
第1话 「雪夜孤行」 页1
═══════════════════════════════════

【格1】远景/大格
画面：雪中古栈道，一人独行
旁白：大隋末年，天下将乱

【格2】中景
画面：少年（林远）背柴，回望山门
林远：「我走了。」
老者（画外）：「莫回头。」

【格3】近景
画面：林远眼眶微红，嘴角紧抿
（无声）

【格4】特写
画面：腰间那块破旧玉佩
旁白：他不知道，这块玉——
═══════════════════════════════════

```

### 漫画平台适配

| 平台 | 风格偏好 | 更新频率 | 签约模式 |
|------|----------|----------|----------|
| **腾讯动漫** | 热血/玄幻/恋爱 | 周更1话 | 签约作者+分成 |
| **快看漫画** | 甜宠/青春/古风 | 周更2话 | 独家/非独家签约 |
| **哔哩哔哩漫画** | 日式/热血/冒险 | 周更1话 | 稿费+分成 |

## 三、漫剧改编（动态漫画/有声漫剧）

> 介于漫画与短剧之间：静态画稿+局部动效+配音配乐，兼具漫画的低成本与短剧的沉浸感。

### 格式规范
- 单集时长：1-3分钟
- 集数：40-80集（对标抖音/快手动漫类内容）
- 分镜数：单集 8-15 个镜头
- 动效优先级：口型>动作>镜头（预算有限时先做口型与关键动作）
- 配音：角色配音必需，旁白可 TTS

### 小说→漫剧改编流程

| 步骤 | 内容 | 注意事项 |
|------|------|----------|
| **1. 剧本化压缩** | 小说→漫剧台本（每集1个冲突点） | 单集信息量 = 短剧1集的 60%（画面承担叙事） |
| **2. 关键帧选取** | 每镜头1个关键帧构图 | 关键帧即海报位，构图要能截图传播 |
| **3. 动效设计** | 静态画稿→局部动效（飘发/光影/震动） | 动效服务情绪：紧张=镜头抖动，抒情=缓推 |
| **4. 对白精简** | 台词只留高信息句 | 旁白说"发生了什么"，画面演"怎么发生" |
| **5. 节奏与音效** | 卡点剪辑+环境音+情绪BGM | 漫剧节奏比漫画快、比短剧慢 |
| **6. 字幕与封面** | 每集封面=本集高光关键帧 | 封面即点击率 |

### 漫剧分镜格式

```

═══════════════════════════════════
第1集 「玉佩」 时长：1分40秒
═══════════════════════════════════

【镜1】远景/缓推 3s
画面：雪中古道，少年独行（关键帧：背影+玉佩反光）
旁白：他以为这一走，就再回不来了。
动效：雪花飘落，衣角摆动
音效：风声【寒】，脚步踩雪

【镜2】中景 4s
画面：少年回头，山门在雾中
对白：少年「我走了。」（口型同步）
动效：雾气流动
音效：脚步停【顿】

【镜3】特写 5s
画面：腰间玉佩，裂纹处透出微光（关键帧：悬念）
旁白：他不知道，这块玉会改变一切。
动效：微光呼吸闪烁
音效：低频悬疑音渐入

⚡ 钩子：玉佩碎裂声——
    镜头骤黑。
═══════════════════════════════════

```

### 漫剧平台适配

| 平台 | 风格偏好 | 更新节奏 | 变现 |
|------|----------|----------|------|
| 抖音/快手（动态漫） | 爽感/反转/甜宠 | 日更1-2集 | 广告+打赏 |
| B站（漫剧区） | 国风/奇幻/青春 | 周更2-3集 | 会员+充电 |
| 腾讯动态漫画 | 玄幻/热血 | 周更1-2集 | 分成 |

## 四、AI有声书制作

### 格式规范
- 单集时长：8-15分钟
- 播放语速：1.2x-1.5x
- 情绪标记密度：每500字≥1个
- 角色声音标签：每个角色必须有独立标签

### 小说→AI有声书脚本流程

| 步骤 | 内容 | 注意事项 |
|------|------|----------|
| **1. 叙述者选型** | 选择TTS声音类型（男声/女声/中性） | 旁白声音≠角色声音 |
| **2. 角色声音标签** | 为每个角色分配TTS声音标签 | 主角/配角/反派声音必须有区分度 |
| **3. 情绪标记插入** | 在关键情绪转折点插入情绪标记 | [开心][悲伤][愤怒][紧张][平静] |
| **4. 停顿标注** | 场景切换/段落过渡/悬念处标注停顿 | [停顿1秒]/[停顿3秒]/[停顿5秒] |
| **5. 音效标注** | 环境音/动作音/背景音乐 | [风声]/[刀剑声]/[紧张BGM渐入] |
| **6. 节奏调优** | 长段落拆分，对话加速，描写减速 | 对话语速1.3x，描写语速0.9x |

### AI有声书脚本格式

```

═══════════════════════════════════
第1章 「重生之夜」
═══════════════════════════════════

[声音：女声-温柔旁白]
[背景：雨声+城市白噪音]
[情绪：平静]

周雨盯着电脑屏幕上的数字，
已经凌晨两点了。

[停顿1秒]
[情绪：疲惫]

加班。又是加班。

[声音切换：周雨-女声-年轻疲惫]
「妈，我今晚又不回来了...」

[声音切换：旁白]
[停顿2秒]
[背景音渐弱：雨声变小]

她不知道的是——

[情绪：紧张]
[背景：低频悬疑BGM渐入]

手机上的体检报告，
正静静躺在未读消息里。

[停顿3秒]
[情绪：沉重]

晚期。

═══════════════════════════════════

```

### 有声书平台适配

| 平台 | TTS引擎 | 收益模式 | 内容偏好 |
|------|---------|----------|----------|
| **喜马拉雅** | 自研TTS+AI配音 | VIP分成+广告 | 全品类 |
| **番茄畅听** | 字节TTS | 广告分成 | 爽文/甜宠 |
| **蜻蜓FM** | 第三方TTS | 付费+分成 | 悬疑/历史 |
| **懒人听书** | 自研TTS | VIP+分成 | 玄幻/都市 |

## 五、游戏化改编

### 格式规范
- 类型：视觉小说/文字冒险/叙事RPG
- 分支节点密度：每1000字≥1个选择点
- 结局数量：≥3个（好/中/坏）
- 角色好感度系统：核心角色必须有

### 小说→游戏改编流程

| 步骤 | 内容 | 注意事项 |
|------|------|----------|
| **1. 主线提取** | 小说主线→游戏主线剧本 | 主线必须保持，支线可自由扩展 |
| **2. 分支设计** | 在关键抉择点设计分支 | 每个分支必须有明确后果 |
| **3. 多结局框架** | 设计≥3个结局 | 好结局=读者满意，坏结局=有逻辑支撑 |
| **4. 好感度系统** | 核心角色好感度影响剧情走向 | 好感度门槛触发不同剧情线 |
| **5. 成就系统** | 里程碑事件设计成就 | 增加重玩价值 |
| **6. UI/UX适配** | 文字→游戏界面设计 | 对话框/选择框/状态栏/地图 |

### 游戏剧本格式

```

═══════════════════════════════════
场景：客栈大厅·夜
═══════════════════════════════════

[背景：古风客栈，灯火昏黄]
[角色：林远（主角）| 沈禾（好感度：60）]

沈禾靠在窗边，月光洒在她侧脸上。

沈禾：「你真的要走？」

[A] 「我必须去。」
    → 沈禾好感度-10
    → 进入【独闯剑阁】线

[B] 「...我再想想。」
    → 沈禾好感度+5
    → 进入【客栈夜话】线

[C] 「跟我一起走。」（需好感度≥80）
    → 沈禾好感度+20
    → 进入【双人组队】线
    → 解锁成就：「剑与花」
═══════════════════════════════════

```

## 六、真人剧改编（长剧/网剧）

> 小说→真人剧（网剧/电视剧/短剧升级版）。成本高、周期长，改编必须做"剧本手术"：取舍、合并、强化视觉冲突。

### 格式规范
- 单集时长：网剧 30-45 分钟 / 短剧加长版 5-15 分钟
- 集数：网剧 12-40 集 / 季播；短剧加长版 40-80 集
- 剧本体量：一集 30分钟 ≈ 6000-8000 字台本
- 分镜：导演分镜（机位/景别/运镜/台词/情绪）

### 小说→真人剧改编流程

| 步骤 | 内容 | 注意事项 |
|------|------|----------|
| **1. 剧本医生** | 小说拆解为"可拍事件表" | 内心戏→外化（行动/对话/他人反应），纯叙述段落删除或场景化 |
| **2. 人物合并术** | 配角合并、功能角色删减 | 真人剧预算限制角色数，保留3-6个核心+2-4个功能 |
| **3. 场景集中** | 小说多场景→剧集集中场景 | 场景越少越省预算，冲突尽量放到"主场景"（家/办公室/宗门大殿） |
| **4. 台词重写** | 叙述信息→台词承载 | 每集台词占比 60%+，信息全对白化 |
| **5. 节奏结构** | 每集一个"反转/钩子"+季末大悬念 | 对标平台节奏（平台偏好见 `platform-guide.md`） |
| **6. 分镜设计** | 关键场次出导演分镜 | 名场面必须设计机位与运镜（`highlight-scenes.md` 高光时刻） |

### 真人剧分镜格式

```

═══════════════════════════════════
第3集 「对峙」 场景：苏家祠堂·日
═══════════════════════════════════

【镜1】全景/轨道缓推
机位：祠堂门内外景→推至厅内
画面：苏老爷子端坐主位，林远立于堂下
对白：苏老爷子「我苏家的东西，你动不得。」

【镜2】近景/固定
机位：过肩，从林远肩后拍老爷子
画面：苏老爷子抬茶，手在抖
对白：（无）——茶盖轻响，暗示心虚

【镜3】特写/手持微晃
机位：林远正面
画面：林远抬头，眼神平静
对白：林远「那件东西，本来就不姓苏。」
情绪：全场死寂

⚡ 钩子：门外传来击掌声——「说得好。」
═══════════════════════════════════

```

### 真人剧平台适配

| 平台 | 剧集类型 | 集数/时长 | 题材偏好 |
|------|----------|-----------|----------|
| 爱奇艺 | 分账剧/短剧 | 12-40集×35-45min | 悬疑/年代/甜宠 |
| 腾讯视频 | 分账剧/微短剧 | 24-40集×35-45min | 玄幻/都市/爱情 |
| 优酷 | 分账剧/短剧 | 12-24集×35-45min | 悬疑/武侠/女性向 |
| 快手/抖音星芒 | 短剧加长版 | 40-80集×5-15min | 逆袭/复仇/甜宠 |

> 真人剧改编涉及资金与制作，合同务必查"改编权-影视"条款（第八节合同必查条款1）。

## 七、剧本→小说（回写）

> 短剧/漫画/游戏剧本可回转为小说正文，按下述转换流程完成，实现双向转换完整闭环。

### 转换流程

| 步骤 | 内容 | 注意事项 |
|------|------|----------|
| **1. 场景还原** | 【场景N】→ 场次小标题，保留内外景 | 依据场景标记与关键词推断 |
| **2. 台词转对话** | "说话人：台词"行→「」对话+说话人 | 识别中英文冒号两种格式 |
| **3. 标签过滤** | 删除 [氛围]/[情绪]/[声音]/[停顿] 标签 | 其信息通过上下文自然呈现 |
| **4. 断句优化** | 长叙述按句读标点自动断句 | 避免一段到底的"剧本腔" |
| **5. 钩子重组** | 剧本集尾钩子→章末悬念 | 保持节奏张力不泄气 |
| **6. 自然度自检** | 九大支柱+通用自然度检查清单（16项） | 回写文本同样执行去AI流程 |

### 使用方式

直接对剧本文本执行上述 6 步转换流程即可；长剧本分段处理并保持衔接。

### 注意事项

- 台词归属基于"说话人：台词"模式识别，长对话场景建议人工通读微调
- 回写后必须经 `anti-ai-engine.md` 九大支柱自检，避免残留"剧本腔"
- 剧本中省略的心理/感官描写需按原作者文风补全（可参考风格蒸馏参数包）
- 版权与改编权归属见第八节

## 八、版权与合同

### 改编权分类

| 权利类型 | 说明 | 注意事项 |
|----------|------|----------|
| **影视改编权** | 小说→电视剧/电影/短剧 | 通常单独授权，不包含在网文签约内 |
| **漫画改编权** | 小说→漫画/条漫 | 部分平台签约时自动获得 |
| **有声改编权** | 小说→有声书/AI有声书 | 多数平台签约时包含 |
| **游戏改编权** | 小说→游戏 | 高价值权利，建议单独谈判 |

### 分成模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **买断** | 一次性付清，作者不参与后续分成 | 新人作者/小体量作品 |
| **保底+分成** | 预付保底金+后续按比例分成 | 中等体量/有潜力的作品 |
| **纯分成** | 无保底，按收入比例分成 | 大IP/已有市场验证的作品 |
| **联合开发** | 作者参与改编创作，分享更大比例 | 作者有改编能力的情况 |

### 合同必查条款

1. 改编权范围（是否包含所有媒体形式）
2. 改编授权期限（几年？是否可续约？）
3. 分成比例（净收入vs总收入）
4. 创作参与权（作者是否有改编审批权）
5. 衍生品权利（周边/角色形象等）
6. 竞业条款（是否限制同类作品改编）
7. 回归条款（授权到期后权利是否回归作者）
8. AI改编条款（AI有声书/AI漫画是否包含在内）

## 九、改编自检清单

| # | 检查项 | 通过标准 |
|---|--------|----------|
| 1 | 核心冲突是否视觉化 | 可在1-3分钟内呈现 |
| 2 | 角色是否精简到位 | ≤5个核心角色 |
| 3 | 对白是否信息密度达标 | 短剧：每句≤25字；漫画：每气泡≤30字 |
| 4 | 钩子是否到位 | 每集/每话/每集结尾有悬念 |
| 5 | 版权是否清晰 | 改编权属/分成模式/授权期限已确认 |
| 6 | 平台适配是否完成 | 目标平台格式/风格/时长已适配 |
| 7 | 节奏是否压缩 | 无冗余过渡，纯冲突驱动 |
| 8 | 情绪节奏是否完整 | 起承转合在改编格式内完整 |

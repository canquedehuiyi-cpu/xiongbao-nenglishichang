## 一、总览：五大推进力

**核心创作原则：避免任何无关形容与比喻；采用自然白描；通过心理、动作、对话推进剧情。**

| 推进力 | 一句话心法 | 承担任务 |
|--------|------------|----------|
| **白描** | 只呈现，不评价 | 场景、人物、氛围的地基 |
| **心理** | 让读者钻进人物脑子 | 动机、挣扎、弧光 |
| **动作** | 让情绪有出口 | 性格、关系、冲突 |
| **对话** | 让信息带刺地流动 | 推进、埋伏笔、塑造 |
| **节奏** | 让读者无法停 | 张力、爽点、钩子 |

> 一页之内至少有两种推进力在同时工作；纯抒情/纯说明段落是最危险的"AI感"来源。

## 二、白描技法（基础功）

### 2.1 白描三原则

1. **动词优先**：一个精准动词胜过三个形容词（"他踹开门" vs "他气势汹汹地推开了那扇沉重的门"）
2. **名词见真**：用具体物件代替抽象概念（"他桌上摆着两瓶空酒、一包没拆的烟"）
3. **细节克制**：一处特征细节 > 三处泛泛描写（写"她指甲剪得很短，齐根"比"她是个干净利落的人"有用）

### 2.2 白描 vs 形容（对照）

| 形容（❌） | 白描（✅） |
|------------|------------|
| 房间里很乱 | 沙发上堆着外卖盒，茶几上三个杯子都没洗，烟灰缸满了 |
| 他很疲惫 | 他坐下时先靠住椅背，闭了几秒眼才说话 |
| 天气很冷 | 呵出的气在路灯下白了一瞬；手从兜里拿出来就发僵 |
| 她很紧张 | 她把菜单卷起来又展开，边角已经皱了 |

### 2.3 白描的禁忌

- 不用"很/非常/极其"堆强度——换成可见的量（汗湿透衣领，不是"非常热"）
- 不写"画面感很强"这类自我评价
- 比喻限量：每300字≤1个，且必须贴人物视角（见 anti-ai-engine.md 支柱一·第13类过度比喻；AI比喻滥用正反例见 ai-pools.md 4.6）

## 三、心理描写技法

### 3.1 四种心理通道（交替使用，避免全篇内心独白）

| 通道 | 示例 | 适用 |
|------|------|------|
| 内心独白 | 完了，钱不够。 | 第一人称感、爽点爆发 |
| 自由间接引语 | 她就该当场摔门走的。 | 第三人称紧贴视角 |
| 身体反应 | 他端杯子的手在抖，水洒出来半截 | 情绪不愿直说时 |
| 行为泄露 | 她把他微信删了，又加回来，又删了 | 矛盾心理 |

### 3.2 心理描写的三层递进

```

表层判断 → 内层情绪 → 深层动机
示例：她不想去（判断）→ 去了就低头（情绪，羞愧）→ 因为她答应过娘，不再跟他扯（动机）

```

### 3.3 心理描写禁忌

- 不写"他心想"（AI高频句式，见 ai-pools 4.2），直接引语/自由间接引语
- 情绪高潮处删解释句：读者正在共情，不需要"这意味着..."
- 一个人物全程理性冷静=工具人，至少留一处失控

## 四、动作描写技法

### 4.1 动作链（三步推进）

```

起（发起动作）→ 承（对抗/调整）→ 落（结果/情绪）
示例：他伸手拦门（起）→ 门把手被他攥得发白（承）→ 他还是松了手，退后半步（落）

```

### 4.2 微动作库（情绪→动作映射）

| 情绪 | 微动作 |
|------|--------|
| 紧张 | 反复捏手指/舔嘴唇/看手机锁屏 |
| 心虚 | 不接眼神/喝水/把话题岔开 |
| 愤怒 | 下颌绷紧/把东西放得很重/笑一下再开口 |
| 愧疚 | 抢着干活/话变多/回避当面道谢 |
| 心动 | 多看了两眼/记住对方说过的话/找借口靠近 |

### 4.3 动作描写禁忌

- 不写"他做了一个决定"——直接写行动
- 动作必须带信息：能推性格、推关系、推剧情，否则删
- 打斗/冲突中动作要短促：短句、动词、不插评价

## 五、对话推进技法

### 5.1 对话三种功能（一句对话至少占一种）

| 功能 | 说明 | 示例 |
|------|------|------|
| 推进剧情 | 对话里交换信息、制造冲突 | "货呢？""丢了。""那就得死一个。" |
| 塑造人物 | 口癖/用词/话题暴露身份 | 贩夫走卒不拽成语，教书先生不喊"哥们儿" |
| 埋伏笔/留钩子 | 话里有话、说一半留一半 | "你爸当年的事，跟你以为的不一样。" |

### 5.2 潜台词技巧

```

字面（说什么） ≠ 真实（想什么）
示例："钱我明天还你。"（字面：还款）→ 真实：他不想欠这个人情，从此两清。
处理：不解释潜台词，用动作承接（对方把借条撕了，笑了笑）。

```

### 5.3 对话标签管理

- 优先动作替标签：`"别过来。"他挡在她前面。`（不用"他紧张地说"）
- 连续对答时省略标签：两人抢话或对峙时，标签越少越紧
- 标签动词克制：说/问/答/喊 为主，"质问/娇嗔/调侃"类高频词慎用（ai-pools 4.5）

### 5.4 对话推进剧情三查

1. 这段对话删掉会损失什么？（无损失则删）
2. 两个人都说真话吗？（至少一方有保留/撒谎/回避）
3. 对话是否替代了动作/心理？（该动的时候别停嘴）

## 六、叙事节奏技法

| 技法 | 做法 | 效果 |
|------|------|------|
| **变速** | 高潮短句快切，铺垫长句铺陈 | 制造情绪落差 |
| **详略** | 重要的慢镜头写足，过渡一笔带过 | 聚焦注意力 |
| **留白** | 关键处戛然而止，让读者脑补 | 参与感 |
| **悬置** | 一章抛悬念不解决，切视角 | 追读欲 |
| **断裂** | 段落之间跳场景，省去过渡段 | 节奏干脆 |

> 配合 `rhythm-patterns.md` 的章节奏模板使用；AI感的一大来源就是节奏恒定（支柱九）。

## 七、场景呈现技法

### 7.1 五感入场（视觉优先，但别只用视觉）

| 感官 | 示例 |
|------|------|
| 视觉 | 灯管坏了一根，半边亮半边黑 |
| 听觉 | 隔壁电视在播球赛，解说声一浪一浪 |
| 触觉 | 门把手是冰的，手心却全是汗 |
| 嗅觉 | 楼道里一股泡面味混着劣质香水 |
| 味觉 | 他咬了口馒头，是馊的，咽了 |

### 7.2 镜头推拉（场景建立三步）

```

全景（环境/时代）→ 中景（人物关系/站位）→ 特写（关键细节）
示例：老巷口的修车铺（全景）→ 他和老师傅隔着柜台站定（中景）→ 他指节上还沾着没洗干净的机油（特写）

```

### 7.3 环境烘托原则

- 环境为情绪服务：喧闹的迎亲队伍 × 主人公的丧，反差出戏
- 不写"萧瑟的氛围"——写具体的风、落叶、空荡的秋千
- 场景细节要和人物发生关系（人物的物件、人物视角能看到的东西）

## 八、技法组合拳（实战模板）

### 8.1 打斗/冲突场面

```

短句起势（动作）→ 声音特写（听觉）→ 心理半句（自由间接）→ 收束定格
示例：他侧身躲过一拳。风声擦着耳廓过去。这人是真下死手。

```

### 8.2 情感高潮场面

```

动作链（身体反应）→ 心理三层（判断/情绪/动机）→ 白描细节（定格式物件）→ 留白收尾
示例：她攥着那张车票（动作）→ 他终究没来。她该恨他的，可她想的是他今早的咳嗽（心理三层）→ 雨把票面上的字泡花了（白描）→ 她把票折好，放进抽屉（留白收尾）

```

### 8.3 反转/揭露场面

```

日常铺垫 → 细节失准（读者先察觉）→ 人物后知 → 一句直白揭底 → 周围反应定格

```

### 8.4 名场面高光场面

> 高光时刻的设计单独见 `highlight-scenes.md`（第六节），本文件提供组合顺序：

```

铺垫（蓄势）→ 转折（意外）→ 爆发（情绪/武力/身份揭晓）→ 余波（围观反应）→ 定格（金句或细节）

```

## 九、自检清单（每章写完过一遍）

- [ ] 是否有纯抒情/纯说明段落？→ 改为白描或动作
- [ ] 对话是否都在推进（剧情/人物/伏笔）？→ 冗余对话删
- [ ] 心理描写是否至少用了两种通道？→ 别全篇内心独白
- [ ] 比喻是否每300字≤1个？→ 超了删
- [ ] 动作是否带信息？→ 无信息动作删
- [ ] 节奏是否有快有慢？→ 全篇均匀则变速
- [ ] 场景是否至少两种感官？→ 补听觉/触觉

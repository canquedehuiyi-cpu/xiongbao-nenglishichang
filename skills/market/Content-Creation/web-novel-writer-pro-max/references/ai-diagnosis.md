# AI诊断检测系统（全维度AI特征诊断 + 去AI语义指纹处理）

> AI特征诊断检测：词级 / 语级 / 句级 / 通感级 / 段落级 / 结构级 / 语义指纹级 / 节奏级 八维检测 + 诊断评分 + 定向去AI流程
> 版本：1.7.0
> 架构定位：本文件是自然度的**人工诊断层**（八维 100 扣分制，分越高越自然，≥75 合格）。检测判据与平台检测维度见 `ai-detection-dimensions.md`（D-PERP/D-BURST/D-LEX/D-PERF/D-EMO 五维），每条判据「为什么像机器」的统计机理见 `human-fingerprint.md`。
> 注意区分：本文件八维人工诊断（扣分制、越高越自然）与 `anti-ai-engine.md` 六维规则核验（分越高越像 AI、≤45 合格、否决线>60）是两套并存体系，不得混用或互相换算。
> 联动：检测基准数据见 `ai-pools.md`（四库）；执行规则见 `anti-ai-engine.md`（九大支柱）；量化检测见 `quality-metrics.md`；整体痕迹区间估计见 `ai-ratio-tester.md`（只给区间不给单点）。

| 维度 | 核验方式 | 落点 |

| ③ 句级 | 规则核验 | 对照 `ai-pools.md` 高频句式库（含AI叙事结构）逐条比对 |

**使用流程**：按上表逐维核验，得出各维度命中明细与分数，再生成完整八维报告。新发现的模板化表达按 `evolution-protocol.md` 记入会话内模板词清单。

## 二、诊断评分模型

总分 0-100，初始 100，按命中扣分（**分数越高越自然，≥75 合格**）：

> ⚠️ **全项目评分体系总表（单一事实源）**——本 Skill 共有 4 套评分体系，名称相近但量纲/阈值/用途完全不同，任何文档引用评分时必须指明是哪一套，禁止裸写"评分/自检/AI分"：
>
> | # | 体系名称 | 载体 | 量纲方向 | 阈值/合格线 | 用途 |
> |---|----------|------|----------|-------------|------|
> | 1 | 六维模板化痕迹分 | 规则核验口径（`ai-pools.md` 词库/语库/句库/结构库） | 越高越 AI（0-100） | **≤45 章节交付硬门**；≤60/≤55 拆书对标采样上限（非交付门控）；否决线 >60 | 快速核验章节 AI 味 |
> | 2 | 八维诊断分 | `ai-diagnosis.md`（本文件） | 越高越自然（0-100 扣分制） | **≥75 合格** | 精细诊断报告 |
> | 3 | 六维质量评分 | `quality-metrics.md` | 越高越好（情节25/人物20/文笔15/世界观15/情感15/商业10） | S-D 评级 | 内容质量人工评级 |
> | 4 | 5维质量评分 | `anti-ai-engine.md` 附录B | 越高越好（满分50，每维10） | **≥45 交付** | 润色质量判定 |
>
> 其中体系1 与体系2 量纲相反（1 越高越AI、2 越高越自然），体系3/4 与 1/2 检测对象也不同（质量 vs AI味）。**两份报告同时出现时分别按各自阈值判定**。
>
> **默认交付约定**：诊断/审稿类模块默认只输出"八维诊断分（体系2）+ 六维模板化痕迹核验（体系1）"两套；六维质量评分（体系3）与 5维质量评分（体系4）仅在用户明确要求时输出，避免多套评分叠加干扰阅读。

| 维度 | 单次命中扣分 | 说明 |
|------|--------------|------|
| 词级 | 2 分 | 命中高频词 |
| 语级 | 3 分 | 命中模板短语 |
| 句级 | 4 分 | 命中模板句式 |
| 通感级 | 4 分 | 无关感官比喻滥用 |
| 段落级 | 3 分 | 段落结构异常 |
| 结构级 | 5 分 | 开头/收尾模板 |
| 语义指纹级 | 6 分 | 语义特征 |
| 节奏级 | 5 分 | 机械感特征 |

> 同一词/语/句在文中重复出现：第2次起加倍扣分（连续命中=模板化确证）。

### 结果分级

| 分数 | 等级 | 处理 |
|------|------|------|
| ≥90 | 🟢 自然 | 直接交付 |
| 75-89 | 🟡 轻度AI感 | 对命中处定向替换（四库替换池） |
| 60-74 | 🟠 明显AI感 | 替换 + 人味注入（支柱四9技法）+ 复检 |
| <60 | 🔴 严重AI感 | 全文回炉：写前预防规则重加载 + 分段重写 |

### 3.1 填好的样例报告（演示如何填）

```text

══ AI自然度诊断报告 ══
文本标题：《猎户的第七夜》第3章  字数：3126  检测时间：2026-08-12

【总分】68/100 → 等级：🟠 明显AI感

【命中清单】
1. 词级：共9处
   - "缓缓地"（L12/L48）→ 建议：删/换"扶着门框站定"
   - "轻轻地"（L31）→ 建议：删/换动作"指腹蹭了蹭杯沿"
   - "仿佛"（L17/L79/L104）→ 建议：删1处，另2处换白描
   - 其余5处详见明细（"微微/渐渐/顿时"）
2. 语级：共6处
   - "空气仿佛凝固了"（L22）→ 建议：换"碗沿磕在桌上，响了一声"
   - "心中涌起一股……"（L56）→ 建议：删，直接写动作
3. 句级：共5处
   - "他告诉自己，不能慌"（L41，模板句）→ 建议：改"他咽了口唾沫，把刀握紧"
   - "这一刻，他终于明白"（L88）→ 建议：删"这一刻，终于"
4. 通感级：共3处
   - "铁锈味在嘴里弥漫"（L30，第三次用）→ 建议：换"齿关咬得发酸"
5. 段落级：共4处（整段情绪独白L45-49）
6. 结构级：共2处（开头"夜色渐深"模板式起笔；结尾总结句L112）
7. 语义指纹级：共2处（观点平均化×1 L64、总结式收束×1 L112）
8. 节奏级：共3处（段落均质化×2、句长CV=0.38 低于0.5）

【高风险区段】（按扣分排序，前3处）
- L12-L18：词库"缓缓地"+语库"空气仿佛凝固了"+句库模板
- L41-L49：句库"他告诉自己"+整段独白（段落级）
- L104-L112：通感重复+总结式收束+模板式收尾

【定向改写方案】
1. L12-L18：删"缓缓地""仿佛"；"空气仿佛凝固了"→事件撞入（碗响）；独白段改动作+留白
2. L41-L49：模板句→身体反应（咽唾沫/握刀）；整段独白砍半，只留最狠一句
3. L104-L112：删总结句；以"他吹熄了灯，没躺下"收尾（未闭合）
   → 人味注入：加1处犹豫（L20"手抬了抬，又放下"）+1处废笔（L73走神）

【复检结论】改写后总分：82 → 通过（≥75）
══ 诊断结束 ══

```

> 填写要点：总分按"结果分级"定等级；命中清单按八维逐项列"位置+命中原文+建议"；高风险区段只列前3处（抓大放小）；改写方案必须含替换池抽取+人味技法+换句示例，不能只写"优化语言"。

## 四、去AI语义指纹处理流程（五步法）

> 对应支柱八（8种语义指纹）+ 支柱九（机械感），形成可执行流水线：

```

步骤1 诊断  → 八维扫描，输出命中清单与总分（本文件第二/三节）
步骤2 定位  → 锁定高风险区段（扣分前3处，优先语义指纹/句式命中）
步骤3 替换  → 从 ai-pools 替换池按 场景/情绪/文风 维度抽取方案替换
步骤4 注入  → 对替换后段落执行支柱四人味注入（至少2个技法：犹豫纠结/口癖/废笔/走神）
步骤5 复检  → 重跑诊断；未过75分回到步骤3（最多2轮）

```

### 语义指纹专项处理（支柱八 8种）

| 语义指纹 | 处理手法 |
|----------|----------|
| 观点平均化 | 删掉平衡句，保留立场，用"我赌""反正"类态度词 |
| 情感平滑 | 加入情绪断层（突然的烦躁/莫名的笑意） |
| 转折模板 | 打碎"然而/但是"，用事件撞进文本 |
| 总结式收束 | 删掉章末总结句，用细节定格 |
| 比喻同质化 | 换成白描（比喻限量：每300字≤1，见 writing-techniques.md 2.3；AI比喻滥用见 ai-pools.md 4.6） |
| 价值中空 | 用具体得失代替"意义/价值"抽象词 |
| 对话说明书 | 对话去掉解释句，让潜台词自己透出来 |
| 完美收尾 | 章末留一句未闭合的话或动作 |

### 机械感专项处理（支柱九 7项）

| 机械感 | 处理手法 |
|--------|----------|
| 段落均质化 | 制造长短落差（≥3:1） |
| 句式循环 | 打破连续同构（每3句换一种句式） |
| 节奏恒定 | 高潮段切短句，铺垫段放宽 |
| 对话对仗 | 让角色抢话/停顿/答非所问 |
| 行动链过顺 | 插入失误/迟疑/多余动作 |
| 情感温度恒定 | 允许情绪起伏与突然降温 |
| 信息节奏均匀 | 该快进快进，该停驻停驻 |

## 六、边界与反幻觉

- 诊断分数是**内部质量参考**，不是"AI检测工具"，不得对外宣称"通过检测"（见 `anti-hallucination.md` 第七节）
- 替换方案只是起点：最终以角色口吻、情节语境、读者观感为准
- 诊断发现的新模板化表达按 `evolution-protocol.md` 记入会话内模板词清单，实现自进化

# 细节引擎库（细节的灵魂工程）

> 细节是小说"活起来"的关键：一个准确的时代细节让读者信服，一个反复出现的物件细节让读者落泪。本库覆盖细节六类、密度控制、记忆点设计、细节与主题呼应、细节雷区。
> 版本：1.7.0
> 自然度：「与主线无关却真实」的闲笔细节、不完美观察是真人写作关键指纹（D-LEX 词汇多样性 / 非信息对称），机理见 `human-fingerprint.md`；反复出现的物件细节可作为承诺登记到 `promise-ledger.md`。
> 联动：感官描写见 `sensory-library.md`；人物行为见 `behavior-logic.md`；名场面见 `highlight-scenes.md`；时代背景查证见 `worldview-engineering.md` 社会人文。

## 一、细节六类（细节从哪来）

| 类别 | 定义 | 示例 |
|------|------|------|
| 人物细节 | 长相/穿着/习惯/小动作/物品 | 他那只褪色的旧手表，指针总慢五分钟 |
| 环境细节 | 场景/天气/声音/气味/光线 | 茶馆的竹帘被风掀起一角，茶客们的议论声像沸水 |
| 时代细节 | 年代/社会/科技/物价/用语 | 1998年的县城，网吧还叫"电脑室" |
| 物件细节 | 道具/信物/贯穿物 | 那把缺了口的菜刀，她总舍不得换 |
| 动作细节 | 做事的顺序/手法/停顿 | 他擦桌子先擦四角，再抹中间 |
| 语言细节 | 称呼/方言/口癖/敬语 | 老匠人管徒弟叫"娃"，管工具叫"家什" |

**细节来源三法**：
1. 记忆法：自己的真实经历（最可信的细节都来自真见闻）
2. 观察法：日常观察存档（坐公交/买菜/等人时观察）
3. 查证法：时代/专业细节查资料（写医生查急救流程，写清末查物价）

## 二、细节密度控制

### 2.1 密度三原则

| 原则 | 内容 |
|------|------|
| 功能优先 | 细节服务人物/情绪/剧情，不服务"显摆知识" |
| 稀疏点缀 | 细节是调味，不是主菜——密集细节=阅读疲劳 |
| 节点聚集 | 高光/转折/名场面才允许细节密集（给足仪式感） |

### 2.2 密度节奏（一章内的细节分布）

```

平淡场景：1-2 个细节点缀（维持真实感）
推进场景：3-4 个细节（人物/环境各一两个）
高潮场景：5-8 个细节（多感官、慢镜头、物件定格）
注意：细节要与节奏同步——快节奏处细节多=拖节奏，慢节奏处细节太少=空洞

```

### 2.3 细节数量自检

- 一章 2500 字，细节建议 3-8 个（视节奏档位）
- 超过 10 个且功能单一 → 删到"每个细节都有唯一功能"
- 少于 2 个 → 检查是否写得像大纲（有骨架无血肉）

## 三、细节记忆点（贯穿物的设计）

### 3.1 贯穿物（全书级记忆点）

> 一个物件反复出现，每次出现都带情绪增量——这是"细节的灵魂"。

| 贯穿物设计要点 | 说明 |
|----------------|------|
| 与主线强关联 | 物件与主角的核心欲望/恐惧绑定 |
| 出场带场景 | 每次出现都在关键节点（出场频率低但分量重） |
| 状态可变 | 物件的状态随剧情变化（磨损/修复/易主） |
| 结局呼应 | 开头的物件在结尾出现新意义 |

**贯穿物示例**：开篇母亲留下的旧怀表（第一块是希望）→ 中篇为救妹妹当了它（第二块是牺牲）→ 结尾赎回时发现里面夹着母亲的信（第三块是真相）。

### 3.2 细节呼应技巧

- **重复变奏**：同一细节多次出现但每次语境不同（第一次普通、第二次揪心、第三次催泪）
- **细节反转**：开头读者不在意的细节，结尾揭示其重要性
- **他人视角**：同一个细节，换人看有不同的意义

## 四、细节与主题呼应

| 主题方向 | 细节设计方向 | 示例 |
|----------|--------------|------|
| 生存/贫穷 | 金钱相关细节反复出现 | 记账本、数零钱、货比三家 |
| 时代变迁 | 新旧事物并置 | 老厂房与霓虹广告、传呼机与手机 |
| 人情冷暖 | 冷暖细节对照 | 热茶 vs 冷饭、添饭 vs 收拾碗筷 |
| 尊严 | 尊严受损的微小细节 | 被叫错名字不纠正、把尊严相关的话咽回去 |

**主题细节自检**：本书想表达什么？有没有 3 个以上细节在支撑它？只有主题口号没有细节支撑=空喊。

## 五、细节写作技巧

1. **宁缺毋滥**：一个准确细节 > 三个模糊细节
2. **具体量化**：不说"很贵"，说"顶他三个月工钱"；不说"很多年"，说"那把藤椅坐了十五年"
3. **多感官**：视觉之外给听觉/嗅觉/触觉（茶的涩味、木门的咯吱、棉布的粗糙）
4. **细节=情绪**：悲伤时写"水凉了没人续"，愤怒时写"杯子碎了没人看"
5. **人物细节与性格绑定**：性格谨慎的人随身带小本子，性格散漫的人永远在找钥匙

## 六、细节雷区

| ❌ 雷区 | 说明 | 解法 |
|---------|------|------|
| 时代穿帮 | 1998年用微信 | 查证时代细节（见 worldview 社会人文） |
| 专业错误 | 医生打针姿势错 | 不确定的专业细节宁缺毋滥 |
| 堆砌炫技 | 一段三个专业名词 | 删到功能需要的程度 |
| 无意义细节 | 描写了但毫无作用 | 删或升级为伏笔 |
| 细节与人物脱节 | 人人都穿同样款式的衣服 | 细节为角色专属 |

## 七、细节引擎自检清单

- [ ] 细节六类是否有覆盖（人物/环境/时代/物件/动作/语言）
- [ ] 每章细节 3-8 个，功能唯一
- [ ] 是否有贯穿物（≥1，与主线绑定）
- [ ] 细节与主题有呼应（≥3 处支撑）
- [ ] 时代/专业细节已查证
- [ ] 无堆砌、无穿帮、无废细节

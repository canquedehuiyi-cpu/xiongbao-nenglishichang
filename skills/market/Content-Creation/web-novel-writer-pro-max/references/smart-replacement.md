# 智能替换库（聪明去AI替换，不生成新模板）

> 去AI最大的陷阱：**用另一个模板替换一个模板**。本库给出"是否该换 → 换什么 → 怎么换 → 换完检查"的完整决策链，让每次替换都灵活、不重复、不生硬。
> 版本：1.7.0
> 架构定位：本文件是自然度能力的**替换决策层**（决定一处痕迹该不该换、换成什么、怎么换、换完如何复检），不新增模板、不生成可照抄成段。
> 联动：语料清单见 `ai-pools.md`；替换要达到的人类特征机理见 `human-fingerprint.md`（每类替换对应一条真人写作机理）；执行规则见 `anti-ai-engine.md`；诊断落点见 `ai-diagnosis.md`；感官替代见 `sensory-library.md`。

## 一、替换决策五步（动手前先想）

```

第1步 判定：这个词是"废"还是"毒"？
      废词（无功能）：删掉即可，不需要替换
      毒词（AI指纹）：才进入替换流程
第2步 定档：换哪个层次？
      删 > 换具体动作 > 换感官细节 > 换意象 > 换句式（优先级从高到低）
第3步 取材：替换素材从哪来？
      场景内的可见事实 > 角色性格惯用 > 环境现成物 > 主题关联物
      （禁止从"同义词词典"硬搬——那是生硬之源）
第4步 落笔：新表达必须能被读者"看见"
      抽象词→具体动作/物件；修饰词→画面细节
第5步 复查：过"生硬七问" + 防"新模板"检查

```

## 二、替换五层次（从优到劣）

| 层次 | 做法 | 示例 | 优先级 |
|------|------|------|--------|
| 1. 删 | 直接删掉无功能词 | "他缓缓地点了点头"→"他点了头" | ⭐ 首选 |
| 2. 换动作 | 换成具体可见动作 | "他嘴角勾起一抹冷笑"→"他把烟按灭了" | ⭐ 优 |
| 3. 换感官 | 换成五感细节 | "空气仿佛凝固"→"只有电扇嗡嗡转" | ⭐ 优 |
| 4. 换意象 | 换成场景关联意象 | "心头一紧"→"他想起女儿那句'爸爸'" | 中 |
| 5. 换句式 | 重构句子结构 | "他不知道的是…"→"后来他才知道…" | 慎用 |

**规则**：能用 1-3 层解决，就不上 4-5 层。层次越高越容易生硬。

## 三·五、通感描写替换专项（重点）

> **AI 最爱用无关的嗅觉/触觉/味觉/听觉比喻撑字数**，真人大多懒得形容，直接推进核心动作。此专项解决"通感描写怎么替换"。

**判断三步**：
1. 这个感官描写**推动剧情/暴露情绪/提供信息**了吗？→ 没有就删。
2. 删掉后句子的**核心动作/心理/对话**还在吗？→ 在就删。
3. 确实需要氛围 → 只保留"读者能验证的"感官（看见/听见/闻到什么具体东西）。

**替换优先级**（通感专用）：

| 优先级 | 做法 | 示例 |
|--------|------|------|
| 1. 删 | 直接删掉通感句 | "空气中弥漫着铁锈味"→删，直接写接下来的动作 |
| 2. 换核心动作 | 用角色的行为顶替 | "他闻到雪松冷香"→"他认出那是他父亲留下的味道" |
| 3. 换具体感官 | 可验证的真实细节 | "血腥味混杂尘土"→"地上拖出一道暗红的印子" |
| 4. 换身体反应 | 生理而非比喻 | "凉意从脚底升起"→"他打了个哆嗦" |
| 5. 换对话/心理 | 让信息从话里出来 | "淬了毒的温柔"→"她声音越轻，他越不敢接" |

**通感雷区**：铁锈味/铜腥/臭氧味/硫磺味/苦杏仁味/雪松冷香/松香/霉味/塑胶味/碎冰般/甜腻腥气/腐甜/凉意/寒意 等 → 全文出现≥2次即视为滥用。完整清单与真人替代见 `ai-pools.md` 2.4。

## 三·六、对称/平行结构替换专项（重点）

> **AI 系统性产出对称/对仗/排比/镜像句式**（tropes 命名：Negative Parallelism / Mirrored-clause Symmetry / Hat Trick / Anticipate-and-Rebut）。人类偶尔用，AI 一用就成串。检测见 `ai-pools.md` 4.7（35 种结构）+ 六维规则核验构级。

**判断三步**：
1. 这个对称结构出现几次？→ 单次弱信号不动；同结构 ≥2 次 或 3 种扎堆（300字内）必须打碎。
2. 删掉"前半对称"，句子的**要点**还在吗？→ 在就删前半。
3. 保留的那半句，换成**具体动作/可见细节**了吗？→ 没换成动作就只是换了个说法。

**打碎优先级**：

| 优先级 | 做法 | 示例 |
|--------|------|------|
| 1. 删前半/删列举 | 对称往往有主有从，删掉从 | "不是恐惧。不是解脱。是别的什么"→"是别的什么" |
| 2. 并成一句 | 三连变一句 | "需要勇气。需要决心。需要坚持。"→"需要勇气，更要命的是坚持" |
| 3. 打破数量 | 3项改2项或4项 | 排比列举砍一项，破均齐 |
| 4. 换具体递增 | 抽象对称换可感递进 | "越说越离谱"→"他越说，声音越小" |
| 5. 换动作/画面 | 对称句换动作定格 | "她分不清是爱他，还是恨他"→"她把门摔上" |

**对称结构雷区**（完整 35 种见 ai-pools.md 4.7）：负面平行"不是X而是Y"、戏剧性倒数"不是X。不是Y。而是Z"、三连排比、镜像对称"分不清是X还是Y"、双向递进"越X越X"、"一边X一边Y"、"既X又Y"、预期反驳"你可能会说…但…"、重要性宣告"这不是巧合而是必然"、格言式结尾、Anaphora 同主语连句、"不仅X而且Y"对仗、"有人X有人Y"、"从X到Y，从X到Y"、连续问句排比 等。

**连环结构（S19/S4/S8 组合）→ 不修，整段重写。**

## 三·七、破折号管控专项（铁律）

> **铁律：每章破折号"——"不超过 1 处。除非必须，否则绝对不用。**
> 全网检测共识：破折号是 AI 检测器最强标点信号（中文真人约每篇 0.5 个，AI 平均 9+ 个；英文 GPT-4o 是人类的 4-6 倍）。一旦破折号多出现，就会被判 AI。

**放行三问（只有 3 种合法用途）**：
1. 是**打断插入**吗？（对话被打断："你——"她没能说完。）
2. 是**节奏转折**吗？（收束前重拍：换逗号/句号会破坏这一拍。）
3. 是**戏剧性补充**吗？（微停顿后补一刀："这世上只有一个人能拦住他——他爹。"）

**三问全否 → 删**。删除优先级：

| 优先级 | 做法 | 示例 |
|--------|------|------|
| 1. 删 | 删掉后句子通顺=舞台道具，必须删 | "他犹豫了一下——还是去了"→"他犹豫了一下，还是去了" |
| 2. 换逗号 | 并列/顺承关系 | "——特别是"→"，特别是" |
| 3. 换冒号 | 引出解释/列举 | "——也就是说"→"：也就是说" |
| 4. 拆两句 | 转折独立成句 | "——但"→"。但" |
| 5. 换括号 | 插入语（最不得已） | "——那晚的事——"→"（那晚的事）" |
| 6. 重写谓语 | 破折号是句法偷懒 | "结果——输了"→"结果输了" |

**破折号替代词（换成标点/连接）对照**："——特别是"→"，特别是"；"——也就是"→"：也就是"；"——即"→"即"；"——但/然而"→"。但/然而"；"——不是"→"不是"；"——毕竟/显然"→"毕竟/显然"（删破折号即可）。

**必查**：全文检索"——"，每处标用途；≥2 处 → 逐处过三问；出现"————"连续破折号或"—，"叠用 → 直接删除。

## 四、生硬判定七问（替换完必查）

1. **看得见吗？** 换成的内容读者能否"在脑中成像"？（抽象词=生硬）
2. **像这个角色吗？** 换成的内容符合该角色的性格/职业/习惯吗？（书生不会说粗口）
3. **扣场景吗？** 换的内容与场景氛围/环境物件一致吗？（雨夜屋里没有蝉鸣）
4. **短吗？** 替换后是否比原句短或相当？（替换导致句子变长一半=拖节奏）
5. **节奏对吗？** 紧张处替换是否拖慢节奏？（激烈对话中插入大段环境描写=毁节奏）
6. **重复吗？** 本章/前几章是否用过相同或类似方案？（用过=必须换新方案）
7. **有新指纹吗？** 替换后是否踩中新AI模板（见第五节）？

**七问中 ≥3 问不过 → 放弃这个替换，退回"删"或换其他方案。**

## 五、防"新模板"检查（最关键的自我审视）

> 替换失败的终极形态：**你的替换方案本身成了新模板**。

**新模板自检**：
- 你是否反复用"他把烟按灭了/他端起茶"这类动作开头？（动作模板化）
- 你是否高频使用"只有XX在响/只有XX声"？（感官模板化）
- 你是否每次都用"脊背窜上一阵凉"？（意象模板化）
- 你是否常把动作放在"他"+"单字动词"+"了"？（句式模板化）

**解法**：替换方案要**多样化**——同义词循环（3-5种）、动作/感官/意象交替、偶尔直接删。检测：按六维规则核验一遍，语级/句级/感级新命中=又踩新模板。

## 六、替换雷区

| ❌ 雷区 | 后果 | 正确做法 |
|---------|------|----------|
| 查同义词词典硬搬 | 生硬、文白夹杂 | 从场景取可见素材 |
| 每处都换（词必替换） | 失去原味、动作冗余 | 该删就删，不是全换 |
| 替换方案全书重复 | 形成新AI模板 | 每词备3-5个方案轮换 |
| 用高级词替代普通词 | 卖弄文笔、阅读降速 | 优先换动作/感官，不升词级 |
| 替换后句子变长 | 节奏拖沓 | 替换不增字数或更短 |
| 只换词不换结构 | 换汤不换药 | 必要时重构整句 |

## 七、替换自检清单（交付前）

- [ ] 替换五步走完（判定→定档→取材→落笔→复查）
- [ ] 优先用了低层次方案（删>动作>感官>意象>句式）
- [ ] 同一方案本章未重复 ≥2 次
- [ ] 生硬七问全过（≤2问不过且已换方案）
- [ ] 无新AI模板（六维规则核验词/语/句/感/构/标零命中）
- [ ] 对称结构已打碎（同结构≤1次，无连环结构）
- [ ] 破折号 ≤1 处且过放行三问
- [ ] 替换后字数未增、节奏未拖

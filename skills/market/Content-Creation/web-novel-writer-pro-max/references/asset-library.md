# 创作素材资产库

> **定位**：可复用的创作素材资产，按「标签 → 卡片」组织，供创作时检索、激发与重组。素材库只提供**结构、要素与激发方向**，不提供可直接照抄的成段文本；任何素材都必须经过作者的原创化重组，使用边界同时受 `anti-washing.md` 约束。
> 版本：1.7.0 ｜ 类型：激发与重组，不是「拿来即抄」。

## 一、使用原则

1. **只给要素与结构，不给成稿**：卡片提供可组合的零件，不提供可直接粘贴的段落。
2. **必须二次创作**：任一素材进入正文前，至少经过「换情境、换人物、换表达、加个人经验」中的两步改造。
3. **风格服从人物与平台**：素材适配题材与目标平台调性，不为用素材而损伤人物一致性。
4. **可追溯**：重要素材标注来源类型（原创激发/经典母题拆解/作者个人经历），拆书所得素材标注出处作品（拆解方法见 `novel-deconstruction.md`）。
5. **不碰红线**：现实人物、真实事件、受版权保护的具体表达不进入可复用素材。

---

## 二、素材卡片统一结构

所有素材使用同一卡片结构，便于检索与复用：

```

【卡片 ID】类别-题材-编号
【标签】3-5 个检索标签（题材/情绪/功能/场景）
【核心要素】该素材成立所必须的 2-4 个零件
【变体方向】至少 3 种改写方向
【适配题材】适用与不适用的题材
【原创化提示】把它变成「只属于这本书」必须补的个人化信息
【风险提示】易俗套/易撞车/易触红线之处

```

## 三、主题库

主题卡回答「这本书到底在讲什么」，用于立项与简介打磨。

**主题卡要素**：核心欲望 / 核心矛盾 / 价值取向 / 情绪基调 / 一句话母题。

| 母题方向 | 核心要素 | 常见变体方向 | 原创化提示 |
|----------|----------|--------------|------------|
| 逆袭翻盘 | 低位起点、明确压迫、能力或机缘、逐级反击 | 隐忍型/暴起型/智斗型 | 压迫必须具体到「谁、在什么事上、怎么压」 |
| 成长救赎 | 缺陷、代价、引路人或镜像对手、和解 | 自我救赎/拯救他人/双向救赎 | 缺陷要能在结尾看到真实改变，而非口号 |
| 探秘解谜 | 谜面、线索链、误导、真相代价 | 本格/社会派/悬疑冒险 | 线索必须前期可回溯，不靠结尾硬解释 |
| 经营建设 | 资源缺口、规则体系、扩张阶梯、外部威胁 | 种田/商铺/势力/基建 | 给出可感知的「从无到有」增量 |
| 情感关系 | 关系起点、核心阻碍、推拉节奏、关系质变点 | 甜宠/虐恋/双向奔赴 | 阻碍要内生于人物性格，不靠误会硬拖 |

> 主题库持续扩充时一律走卡片结构，不堆散点灵感；题材细分模板见 `genre-templates.md`。

## 四、场景库

场景卡提供「功能型场景」的零件，不提供描写成稿。

**场景卡要素**：场景功能 / 必备角色位 / 冲突来源 / 信息增量 / 进出场钩子。

| 功能场景 | 必备要素 | 变体方向 | 风险提示 |
|----------|----------|----------|----------|
| 初次登场 | 一个动作立人设、一个反差留记忆、一句台词定腔调 | 高光登场/落魄登场/侧写登场 | 避免履历表式自我介绍 |
| 冲突爆发 | 立场对立、导火索、不可退让之物、结果悬置 | 明面冲突/暗流冲突/信息差冲突 | 冲突必须改变局面，不能吵完复原 |
| 真相揭示 | 铺垫证据、揭示时机、揭示对象差异、情绪后果 | 对读者揭示/对主角揭示/错位揭示 | 揭示后人物决策必须随之改变 |
| 低谷转折 | 失去之物、触底信号、转折契机、代价 | 外力契机/内生顿悟 | 转折不能无代价，避免凭空翻盘 |
| 高光兑现 | 前期铺垫、压抑累积、兑现方式、旁观者反应 | 实力碾压/智计兑现/身份揭晓 | 高光强度与前期压抑成正比 |

场景五感与细节填充见 `sensory-library.md`、`detail-engine.md`；名场面完整设计流程见 `highlight-scenes.md`。

## 五、意象库

意象卡提供「可反复出现、承载主题」的意象零件，服务 D-LEX 个人化用词。

**意象卡要素**：意象本体 / 象征含义 / 首次出现情境 / 复现变化（至少 3 次，每次含义递进）/ 与人物的绑定。

使用规则：

- 一部作品选 1-3 个核心意象贯穿，不堆砌。
- 意象每次复现要随情节改变含义（如同一物件从温暖→破碎→重圆），形成个人化重复。
- 意象必须贴合题材世界设定，避免与热门作品撞标志性意象。

## 六、金句结构库

只收录**可套用的句式结构**，不收录任何作品的原句，避免版权与洗稿风险。

**金句结构卡要素**：句式骨架 / 情绪功能 / 填空位 / 适配语境 / 滥用风险。

| 结构骨架（示意） | 情绪功能 | 适配语境 |
|------------------|----------|----------|
| 「他以为 X，直到 Y」 | 认知反转 | 转折、真相 |
| 「X 不是 A，是 B」 | 价值重定义（慎用，易 AI 化） | 点题，全书少量 |
| 三个短句递进收束 | 情绪砸点 | 高光、章尾 |
| 以动作代情绪陈述 | show-don't-tell | 心理、冲突 |

> 「不是 X 而是 Y」类结构在机器文本中高频出现，单章控制用量，避免成为新的模板（与 `ai-detection-dimensions.md` D-PERF 判据联动）。

## 七、人物设定卡模板

人物设定卡是 `character-depth.md` 的资产化落地，用于跨章节、跨形态保持人物一致（也是 `entity-state-machine.md` 的静态来源）。

```

【基础】姓名/别名、年龄层、身份、初始处境
【欲望】表层目标 / 深层渴望（两者应有落差）
【缺陷】性格短板 + 它如何同时是优点
【三锚点】一个标志性动作、一种说话方式、一处价值观底线
【弧光】起点状态 → 转折事件 → 终点状态（对应拆书人设弧光卡）
【关系网】与主角/对手/盟友的关系及变化
【状态字段】境界/能力、持有物、所属势力、当前位置（供实体状态机追踪）
【一致性红线】该人物绝不会做的事、绝不会说的话（防 OOC）

```

## 八、世界观切片模板

世界观不一次性倾倒，而以「切片」按需释放（释放节奏见 `novel-deconstruction.md` 世界观释放层、`worldview-engineering.md`）。

```

【切片名称】一个可独立理解的设定单元
【读者此刻需要知道】维持当前情节理解的最小信息量
【延后信息】暂不释放、留待后文的设定
【释放载体】通过对话/动作/环境/冲突中的哪一种自然带出
【一致性约束】该切片与既有设定不矛盾的校验点
【后续钩子】这个设定将来能引爆什么

```

原则：能用冲突展示就不用旁白说明；每次释放只给「当前情节必需」的最小集，避免开篇设定倾倒劝退。

## 九、调用与原创化流程

```

检索标签 → 取出卡片 → 核对题材/人物适配性
        → 至少两步原创化改造（换情境/换人物/换表达/加个人经验）
        → 与既有设定、人物状态机核对一致性
        → 进入正文 → 交付前过 anti-washing 原创性自检

```

跨形态调用：当需要把本库资产转成漫画/短剧/互动小说指令时，由 `cross-form-orchestrator.md` 统一打包，素材卡作为指令包的设定来源。

## 十、交付前核验清单

- [ ] 五类素材（主题/场景/意象/金句结构/人物与世界观模板）是否齐备且均为卡片结构？
- [ ] 是否所有素材都只给要素与结构、无可直接照抄成段？
- [ ] 金句库是否只收句式骨架、未收任何真实作品原句？
- [ ] 调用素材是否经过至少两步原创化改造？
- [ ] 人物卡状态字段是否能对接实体状态机、世界观切片是否标注最小释放量？

### 自检标准（可验证）

1. 五类素材各至少一套可直接填写的卡片模板。
2. 任取一张素材卡，能按「九、调用流程」完成一次原创化改造，并说明改造了哪两步。
3. 全库检索不到真实作品的成段原文与现实人物具体信息。

# 角色灵魂刻画库（情感张力 / 压强 / 冲击力 / 爆发力）

> 角色灵魂深度刻画：四力模型 + 人设定位强化 + 角色弧光 + 名场面情感支撑
> 版本：1.7.0
> 定位：本文件是「人物怎么写深」的方法论；人物沉淀为 `asset-library.md` 人物设定卡，动态由 `entity-state-machine.md` 追踪防 OOC；拆书弧光按 `novel-deconstruction.md` 资产层 3 回流。

## 一、四力模型（角色情感刻画的四个维度）

| 力 | 定义 | 检验问题 |
|----|------|----------|
| **张力** | 角色内心与外部的拉扯（想做 vs 不能做） | 他的欲望和约束冲突了吗？ |
| **压强** | 施加在角色身上的外部压力（生存/身份/期限） | 读者感受到他快撑不住了吗？ |
| **冲击力** | 事件对角色/读者的瞬间击打（突转/背叛/失去） | 这个事件让他和读者同时"咯噔"了吗？ |
| **爆发力** | 蓄压后的情绪/行动释放（隐忍到顶点的一击） | 他攒了多久，这一下够狠吗？ |

**四力联动原则**：张力+压强是"蓄"，冲击力+爆发力是"放"。蓄得越足、放得越狠。名场面 = 先加压再引爆。

## 二、人设定位强化（写人先立"三锚点"）

### 2.1 三锚点

| 锚点 | 内容 | 示例 |
|------|------|------|
| **欲望** | 他这辈子最想要的东西 | 想让妹妹病好 |
| **恐惧** | 他最怕失去/最怕成为的 | 怕钱不够、怕像爹一样跑路 |
| **边界** | 他的底线，碰了就炸 | 谁骂她妹妹都不行 |

> 任何情节决策都从三锚点推演：这个选择是贴近欲望、逃避恐惧，还是触及边界？

### 2.2 角色反差设计（让角色"有肉"）

| 反差类型 | 示例 |
|----------|------|
| 行为-身份反差 | 打手式的外形，记账时一笔一划 |
| 对陌生人-对亲近人反差 | 对谁都客气，唯独在妹妹面前暴躁 |
| 公开-私密反差 | 台上谈笑风生，后台洗了很久的手 |

### 2.3 反角色定型清单（每章自查）

- [ ] 主角这章有没有至少一个"计划外反应"？（冲动/犯错/走神）
- [ ] 反派是否有自己相信的正义或软肋？
- [ ] 配角是否各自有欲望（不是主角的工具）？
- [ ] 角色的口癖/动作/选择是否稳定一致？

## 三、情感张力刻画技法

### 3.1 张力的三种来源

| 来源 | 做法 | 示例 |
|------|------|------|
| 欲-碍冲突 | 想要X，但障碍是自己在乎的人/事 | 想离开这座城，但放不下病床上的妈 |
| 身份-本心冲突 | 身份要求X，本心想做Y | 师父要他杀她，他下不去手 |
| 知情差 | 角色知道读者不知道（或反之） | 他早就知道她骗他，仍把药吃了 |

### 3.2 张力写作三法

1. **延长拉扯**：一个冲突别一章解决，来回拉三轮（提议→拒绝→暗示→动摇）
2. **细节泄露**：嘴上说没事，手在发抖（心理通道-行为泄露，见 writing-techniques 3.1）
3. **环境加压**：期限、观众、天象都是压力源（明天开庭/全场看着他/大雨封路）

## 四、压强塑造技法

### 4.1 压强来源清单

| 来源 | 示例 |
|------|------|
| 生存压力 | 钱/食物/安全的倒计时 |
| 身份压力 | 顶替身份被发现的风险 |
| 关系压力 | 在乎的人误解/被绑/要决裂 |
| 承诺压力 | 答应过的事、欠着的人情 |
| 系统压力 | 金手指反噬/系统任务失败惩罚 |

### 4.2 压强曲线（章内/卷内）

```

低压铺垫（日常/错觉安全）→ 渐压（麻烦上门）→ 高压（无路可退）→ 释放（爆发或转机）
注意：全篇高压力=读者疲劳；每 10 章留一个喘息点（日常戏/感情戏/风景）

```

### 4.3 压强呈现（不喊口号）

- 用**倒计时**：天黑前/月底前/三日内
- 用**选项变窄**：最后只剩一条路（还是坏路）
- 用**他人视角**：旁观者都看出他不对劲了

## 五、冲击力设计技法

### 5.1 冲击事件五要素

| 要素 | 说明 |
|------|------|
| 意外性 | 读者能预判的背叛不算背叛 |
| 相关性 | 直击三锚点（欲望/恐惧/边界） |
| 不可逆 | 造成的后果无法撤销（人死了/信送出去了） |
| 具体化 | 冲击要有可见的具象（打翻的相框/断掉的信物） |
| 余震 | 冲击后留涟漪（之后几章都在消化这件事） |

### 5.2 冲击写法（收 vs 放）

| 写法 | 适用 | 示例 |
|------|------|------|
| 收着写（克制） | 高情感密度 | 她没哭，把碗洗了，手在抖 |
| 放开写（宣泄） | 爽点/爆发 | 他把桌子掀了 |

### 5.3 冲击力雷区

- 冲击后立刻解释（"原来真相是……"）→ 让读者自己消化
- 为反转而反转（无伏笔的突然背叛）→ 前置2处细节伏笔
- 冲击后角色无反应直接跳到下一情节 → 至少给一场"消化戏"

## 六、爆发力设计技法

### 6.1 爆发公式（蓄-压-爆-余波）

```

蓄：前置 N 章的委屈/隐忍/铺垫（例：三章被针对）
压：临界点事件（例：对方动了妹妹）
爆：动作+台词+第三方反应三合一（例：一拳/一句"这事没完"/围观者噤声）
余波：爆发后的代价或静场（例：他喘着气，所有人不敢动）

```

### 6.2 爆发三要素

1. **成本**：爆发必须有代价（代价越大越疼）
2. **反差**：一贯温和的人爆发才有冲击（爆发频率越低越值钱）
3. **定格**：爆发最高点给一个可记住的画面（金句/标志动作/物件）

### 6.3 爆发雷区

- 每章都爆发=没有爆发（控制频率，全本3-5次大爆发）
- 爆发时讲道理（边打边说教）→ 爆发就是动作与情绪，不是辩论
- 爆发完没有余波 → 加一场静场戏消化

## 七、角色弧光（弧光 = 三锚点的位移）

### 7.1 弧光路径模板

```

起点（欲望未明/恐惧控制他）→ 裂痕（事件戳破伪装）→ 动摇（试过逃/妥协）→ 抉择（直面欲望或恐惧）→ 终点（欲望达成但付出代价 / 恐惧解除但失去什么）

```

### 7.2 弧光检验（每卷末自查）

- [ ] 主角和开卷时相比，**行为选择**变了没有？（嘴上说的不算）
- [ ] 变化是否有 2 个以上事件支撑？（不能一章顿悟）
- [ ] 变化是否付出代价？（无代价的成长=假成长）
- [ ] 配角是否有微弧光？（至少1-2个配角有变化）

## 八、名场面情感支撑（与 highlight-scenes.md 联动）

| 名场面类型 | 四力运用 |
|------------|----------|
| 高光反转 | 冲击力为主：伏笔引爆 + 旁观反应定格 |
| 至暗时刻 | 压强+张力：压力到顶 + 内心拉扯 + 最小代价爆发 |
| 情感告白/和解 | 张力为主：欲说还休 + 细节泄露 + 余波静场 |
| 退场/牺牲 | 冲击+爆发：不可逆 + 收着写 + 余震贯穿后文 |

## 九、灵魂刻画自检清单（交付前）

- [ ] 三锚点明确且情节选择由锚点推导？
- [ ] 本章至少一处"计划外反应"（角色会犯错/犹豫）？
- [ ] 四力中哪一力是本章主角？蓄/放比例合理？
- [ ] 情感高潮用了"收着写"还是"放开写"？选对了吗？
- [ ] 爆发有代价、有定格、有频率控制？

## 十、角色资产化与状态追踪对接

角色不能只停留在分析层面，必须沉淀为可跨章复用、可校验一致性的资产：

1. **立卡**：用三锚点（欲望/恐惧/边界）+ 反差 + 四力特征，按 `asset-library.md`「人物设定卡」建卡，补齐表层目标/深层渴望、标志动作、说话方式、价值观底线。
2. **定状态字段**：把会变化的量（境界/能力、伤势、持有物、位置、所知信息、关系、立场）交给 `entity-state-machine.md` 建状态卡；不变的内核（三锚点、一致性红线）留在人物卡。
3. **弧光落地**：第七节的弧光路径（起点→裂痕→动摇→抉择→终点）写入状态机的「弧光比对」，每次重大转变检查是否有足够事件支撑、是否付出代价，防止一章顿悟与 OOC。
4. **一致性红线**：把「这个人物绝不会做的事、绝不会说的话」显式写入人物卡，作为状态机 OOC 三道检查（红线/状态/弧光）的第一道。
5. **跨形态复用**：改编为漫画/短剧/有声时，人物卡直接作为 `cross-form-orchestrator.md` 指令包的设定来源，保证跨形态人物内核不变。

> 闭环：本文件负责「把人写活」，asset-library 负责「把人存下来」，entity-state-machine 负责「让人不崩」，三者分工不重复。

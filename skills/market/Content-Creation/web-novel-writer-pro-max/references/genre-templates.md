## 一、使用说明

- 每一类题材给出 **5 要素**：题材核心 → 读者预期 → 章节节奏 → AI高发雷区 → 改善建议方向
- 创作/拆书/诊断时先命中题材，再套用对应模板
- "AI高发雷区"是这类题材里 AI 最容易被识破的写法（结合 `ai-pools.md` 四库使用）

## 二、玄幻修仙

| 要素 | 内容 |
|------|------|
| 题材核心 | 凡人→强者→超脱的成长阶梯；力量体系+境界爬升 |
| 读者预期 | 升级爽、打脸爽、扮猪吃虎；金手指的边界 |
| 章节节奏 | 前3章觉醒+第一个冲突；每10章一次小升级；每卷一次大突破 |
| AI高发雷区 | 力量境界介绍整段平铺（"炼气→筑基→金丹"复读机）；修炼过程"灵力在体内运转一圈"空洞模板 |
| 改善建议 | 境界用事件/战斗展现，不用说明书；修炼换成具体动作+代价（经脉胀痛/丹药反噬）；打斗用短句+环境破坏细节 |

**爆款公式**：废柴开局 + 隐藏金手指 + 首章打脸 + 十章小高潮 + 身世伏笔。

**【开篇示例·原创】**

祠堂里摆着三十七块灵牌，第七排第三块刻着"林昭"两个字。少年林北跪在蒲团上，膝盖跪麻了，头顶的香灰落进后颈，烫得他缩了一下脖子。门外传来二叔的声音："废了三年，今日测灵台，若测出灰阶，就滚去矿场。"林北没应声，只把掌心贴在地砖上。砖缝里嵌着一粒灰扑扑的珠子，三年了，只有他知道，这珠子每夜发烫，烫过之后，他后山砍柴能比平时快出一截。今日是测灵大典。他站起身，拍拍膝上的灰，经过二叔身边没有停步。二叔想发作，被长老一声咳嗽压了回去。测灵台上，执事按住他的天灵盖，一道光柱亮起，先红，后紫，碎成满台星点。台下静了两息。林北低头看掌心的珠子，珠面裂开一道细缝，缝里传出两个字：饿了。

> （原创示例，仅示范写法，可参考打法不可照搬）

## 三、都市异能

| 要素 | 内容 |
|------|------|
| 题材核心 | 现代都市 + 异能/系统/重生；身份反差（赘婿/神医/兵王） |
| 读者预期 | 身份反转打脸、越级碾压、爽点密度高 |
| 章节节奏 | 首章身份压迫+隐藏实力；每章1-2个打脸点；20章内揭一层身份 |
| AI高发雷区 | "嘴角勾起一抹冷笑""眼中闪过一丝寒芒"（语库模板重灾区）；"一个电话叫来XX"万能装逼模板 |
| 改善建议 | 打脸用第三方反应（服务员的态度变化/路人议论）侧面烘托；装逼留白，读者自己懂；金手指有限制（代价/时效） |

**爆款公式**：低姿态入场 + 隐忍 + 关键处一击反转 + 围观震惊 + 身份悬念。

**【开篇示例·原创】**

深夜十一点，城中村理发店还亮着灯。陈默给最后一个客人剪完头，收了十五块，弯腰扫地上的碎发。门口进来三个穿统一工装的人，为首的年轻人把一张名片拍在镜台上："陈默，总部让你回去。"镜台晃了一下，搭布上那把剪刀掉在地上。陈默捡起剪刀，擦了擦，放进抽屉："明天吧，约了人。"年轻人还要说话，被身后同伴扯住袖子，那同伴盯着陈默左手腕上那道旧疤，到嘴边的话咽了回去。三人走后，角落里等了半天的老头才上前，压低声音问："后生，你就是三年前……"陈默把找零的十五块塞回抽屉："叔，剪头吗？"老头张了张嘴，终究没敢再问，退了出去。门外贴的价目表被夜风吹起一角，底下压着一行小字：悬赏令，三年前失踪的人，赏金八位数。

> （原创示例，仅示范写法，可参考打法不可照搬）

## 四、历史穿越

| 要素 | 内容 |
|------|------|
| 题材核心 | 现代人穿越古代；用现代认知降维解决古代难题 |
| 读者预期 | 知识差爽点、权谋博弈、代入感（种田/经商/朝堂） |
| 章节节奏 | 首章穿越+立足；中期难题接难题；权谋线渐进升级 |
| AI高发雷区 | "他运用现代知识……"全知全能解说；古人全员工具人（都傻/都坏）；时代细节张冠李戴 |
| 改善建议 | 现代知识落地要交代限制（技术/材料/人力不允许）；古人要有真实动机与智商；时代细节查证（物价/称谓/器具） |

**爆款公式**：穿越落差 + 知识降维 + 首个生存难题 + 站队博弈 + 历史事件蝴蝶效应。

**【开篇示例·原创】**

周衡睁眼，先闻到霉味，再是牲口棚的骚气。他穿着粗麻短褐，裤脚扎着草绳，手里攥着一把刚割的草。老仆在门外喊："郎君，再不下田，里正就要来收夏税了。"周衡摸了摸袖里的账纸，按上辈子的农书算，十亩地堆肥换茬，亩产能提到三石半。可他看了看屋角，粪坑是空的，买石灰要钱，钱压在县尉手里。他蹲到田埂上，捏起一撮土搓了搓，土干得发白。远处传来马蹄声，老仆脸都白了："县尉来了。"周衡把账纸塞回袖子，站起来，没躲，也没跪，反而迎着马蹄声往前走了两步。他记得这条河的下游，再过两年就要改道，改道那一年，沿河三县的税赋，全免了。

## 五、科幻末世

| 要素 | 内容 |
|------|------|
| 题材核心 | 末日生存/星际/赛博；规则新、世界观新 |
| 读者预期 | 世界观新鲜感、生存压迫感、科技设定自洽 |
| 章节节奏 | 前3章立世界规则；每章一个生存/道德抉择 |
| AI高发雷区 | "这个世界发生了巨变"空泛开场；设定大段说明书；"人类的希望"式宏大空话 |
| 改善建议 | 规则用事件演示（第一个幸存者怎么死的）；设定碎片化嵌入对话/道具；道德抉择留白给读者 |

**爆款公式**：异常事件开场 + 规则示范 + 物资/权力争夺 + 组织对抗 + 隐藏真相。

**【开篇示例·原创】**

警报响的时候，阿澈正在三楼食堂排队打饭。窗口里的阿姨把勺子一放，转身钻进后厨，再没出来。大厅里没人慌，都在掏手机看通知。通知只有一行字：地表能见度低于五米，全员滞留地下层，口粮按每顿半份发放。阿澈看了看空碗，又看了看头顶的通风口。昨天巡逻队带回来的那具尸体，就卡在通风口里，脸朝下，手里攥着半块压缩饼干。他往后退了两步，退到墙角蹲下系鞋带，鞋带其实没松。系到第二遍时，人群果然往前挤了，三号窗口的栅栏被撞得哐哐响。阿澈起身绕到消防梯，顺着逃生通道往仓库走。他记得仓库顶板上，藏着存了三个月的罐头。门推开，仓库里站着一个人，正仰着头，看那扇装罐头的暗门。

## 六、悬疑灵异

| 要素 | 内容 |
|------|------|
| 题材核心 | 规则怪谈/推理/盗墓；悬念与反转 |
| 读者预期 | 线索铺设、反转意外、氛围压迫 |
| 章节节奏 | 章末必留钩子；每3章一个小反转；中期揭露一部分真相 |
| AI高发雷区 | "空气中弥漫着诡异的气息"氛围套话；线索太明显（主角突然顿悟）；反转全靠解说兜底 |
| 改善建议 | 氛围用具体反常（温度/声音/物件位置错乱）；线索埋在动作和细节里；反转前埋2处伏笔、揭底不解释 |

**爆款公式**：异常开场 + 规则探索 + 线索链 + 伪解答 + 真反转 + 大悬念。

**【开篇示例·原创】**

抽屉里的指甲剪，每天早上都会换一个位置。第一天在左手边，第二天压着账本，第三天掉在拖鞋里。江梨把这事记在本子上，没跟任何人说，说了也没人信。老小区楼下的麻将馆夜夜热闹，她下夜班路过时，常听见四楼那户传来搓麻将的声音，可那户人家，三年前就搬空了。这天夜里她又路过，哗啦哗啦的洗牌声照旧，里面还混着一声咳嗽。她停下脚步，抬头看四楼那扇窗。窗是黑的，窗帘没拉，窗台上摆着一盆枯萎的绿萝。她记得清楚，三年前搬家那天，绿萝是翠绿的，连盆子都是现在这个方向。她掏出手机，指尖悬在拨号键上，身后有人问："姑娘，你也听见了？"

## 七、游戏竞技

| 要素 | 内容 |
|------|------|
| 题材核心 | 电竞/游戏穿越/LitRPG；系统面板与竞技场面 |
| 读者预期 | 升级爽、操作爽、团队博弈 |
| 章节节奏 | 首章金手指+首胜；每章一个战术博弈；定期大赛节点 |
| AI高发雷区 | "系统提示：经验值+100"流水账；竞技场面报菜名（技能名连发）；对手降智 |
| 改善建议 | 数值藏在情节里（升级后立刻遇到更强对手验证）；操作场面写决策过程（预判/骗招）不写技能表；对手有战术智商 |

**爆款公式**：天赋/金手指 + 首场逆袭 + 队伍磨合 + 关键对局 + 职业之路。

**【开篇示例·原创】**

决赛第五局，对方打野第三次出现在上路时，沈河把视野插进河道草丛，插完就走。耳机里队友问："河哥，那草里没人吧？"沈河没答，按下回城。三秒后，屏幕右下角弹出击杀提示，对方打野踩进那片草，被下路蹲了个正着。他只说了句："他急了，急了的人爱走捷径。"队友没听懂，但团战赢了。下一波龙团，对面换了打法，五人绕后包抄。沈河看着小地图上消失的五个红点，把装备栏里那把买错的短剑卖掉，换了把便宜的长剑。弹幕刷过一片问号。他按下大招，剑尖指向龙坑外侧的空气。一秒钟后，五个红点同时亮起，撞在剑光上。对方中单在公屏打字：这剑，你算准了？

## 八、武侠仙侠

| 要素 | 内容 |
|------|------|
| 题材核心 | 江湖/武学/道心；宗师气度与快意恩仇 |
| 读者预期 | 武学成长、江湖人情、高手对决 |
| 章节节奏 | 前10章立世界观+初露锋芒；中段江湖事件串联；每卷一次高手战 |
| AI高发雷区 | "内力运转周天"空洞修炼；高手说话全是一样的大师腔；战斗写成力量对轰 |
| 改善建议 | 武学境界用实战差异呈现（同一招在不同境界的威力差）；高手各有口吻与怪癖；战斗写招意不写招式清单 |

**爆款公式**：出身落差 + 机缘 + 江湖扬名 + 恩怨线 + 武学突破。

**【开篇示例·原创】**

酒铺的账先生姓周，客人只知他打算盘快，不知他左手使剑。夜里打烊，他翻起柜台下的木板，露出下面压着的半截断剑。剑是十年前断的，断口他磨了十年，磨得能照出人影。这晚门外来了个人，挑着灯笼在雪地里站定，开口便问："周掌柜，借你的剑一用。"周先生没抬头，指头拨了两下算盘："算盘珠是圆的，剑是直的，直的借不了。"来客把灯笼往前递了递："那我来，把你的断口补上。"周先生拨算盘的手指顿住，他起身，从柜台后走出来，手里没拿剑，只拿了那面算盘。雪落上肩头，他拨了一下算盘，珠子相撞，叮的一声。来客脸上的笑僵住，退后半步，灯笼里的火苗晃了晃："这不是剑法。"周先生又拨了一下算盘："是账。"

## 九、言情甜宠

| 要素 | 内容 |
|------|------|
| 题材核心 | CP情感线；甜虐节奏；双向奔赴或拉扯 |
| 读者预期 | 心动细节、情感张力、HE预期 |
| 章节节奏 | 首章相遇+初始印象；每10章一个情感节点（升温/误会/和好） |
| AI高发雷区 | "他眼底藏着宠溺"标签式心动；对话全是打情骂俏样板；误会全靠不说清楚 |
| 改善建议 | 心动用细节动作（多看一眼/记住小事/下意识护着）；误会要有现实逻辑（身份/利益/旧伤）；情感节点后给独处场景放大张力 |

**爆款公式**：初遇冲突 + 心动细节 + 误会拉扯 + 患难升温 + 双向奔赴。

**【开篇示例·原创】**

相亲约在周五晚上七点，周雨迟了十分钟。推开店门，她看见窗边那个男人正拿纸巾擦杯子，擦完自己那杯，又把她那杯也擦了，杯沿转到她自己习惯的角度。她走过去坐下，男人把菜单推过来："你忌香菜，我让后厨免了。"周雨抬眼看他，想起上一任连她喝奶茶要三分糖都不记得。"你叫什么来着？"她问。男人笑了一下："贺川，上回阿姨给的照片，背后把川字写错了，字是错的，人是真的。"周雨低下头，指尖捏着纸巾角，撕成一条一条，又一条一条接回去。服务员上菜，贺川把她那碗汤换到自己面前，拿勺子舀走浮着的油花。她看着那勺油花，想，今晚这顿相亲饭，可以多坐一会儿。

## 十、悬疑言情

| 要素 | 内容 |
|------|------|
| 题材核心 | 案件线与感情线双线交织 |
| 读者预期 | 案件悬念 + 感情拉扯互相催化 |
| 章节节奏 | 章末案钩子；感情推进由案件推动（同查案/同遇险） |
| AI高发雷区 | 感情戏与案件戏割裂（查案时忘情）；嫌疑人动机全靠嘴说；感情进度"突然确认关系" |
| 改善建议 | 感情推进绑定案件事件（共同危机→信任→暧昧）；嫌疑人在感情线中制造纠葛；感情进度用行动确认（挡刀/顶罪/深夜找人） |

**爆款公式**：命案开场 + 双线纠缠 + 怀疑与信任摇摆 + 真相反转 + 感情落定。

**【开篇示例·原创】**

周寻第一次见许砚，是在停尸间的走廊上。她抱着案卷去核对指纹，他靠在墙边，手里转着法医的骨钳。她以为他是家属，把案卷往怀里藏了藏。他先开口："凶手右手有旧伤，你查查三年前的工伤档案。"她没理，进了门。三天后案子破了，真凶右手虎口一道疤，和档案对上了。周寻在结案报告上签完字，抬头见许砚又靠在门口，这回他手里提着一袋热豆浆："法医说你一夜没睡。"她接过，烫得手心发疼，没撒手。"你为什么查这个案子？"许砚把骨钳收进口袋，声音低了低："死的人，是我姐。"周寻的笔停在半空。她想起自己递上去的尸检补充意见，那页纸上有四个字：死因存疑。她看了看手里的豆浆，又看了看他，把卷宗重新翻开："那我们从第一页，重新看一遍。"

## 十一、轻小说

| 题材核心 | 二次元/系统流/日常；轻松节奏与梗密度 |
| 读者预期 | 轻松解压、角色萌点、梗玩梗 |
| 章节节奏 | 首章立人设+世界观；日常与事件交替；每几章一个搞笑高潮 |
| AI高发雷区 | 梗太密变水；角色全员"吐槽役"同质化；"空气突然安静"万能笑点模板 |
| 改善建议 | 梗要服务角色（符合人设的吐槽才好笑）；每个角色有专属笑点；笑点后用一个小事件收束别拖 |

**爆款公式**：人设鲜明 + 日常事件 + 金手指反差 + 群体互动 + 隐藏主线。

**【开篇示例·原创】**

我叫陈一，穿越第三天，还没饿死。
原因很简单，我绑定的系统叫《美食主播系统》，日常任务全是做饭。
第一天，任务：做一碗蛋炒饭。评分：D。
系统：您的蛋炒饭黏锅了。
我：你行你上。
系统：行。已生成示例视频。
视频里那把锅铲翻了三百个来回，米粒一颗颗蹦起来，又整整齐齐落回锅里。
我看了三遍，得出结论：这系统不教人，只打击人。
第二天，任务：煮一碗面。评分：C。
系统：汤汁寡淡，建议加一勺猪油。
我：家里没有。
系统：检测到隔壁窗台有一坛猪油。
我：那是偷！
系统：任务失败，扣除1点魅力值。
我：……魅力值是什么？
系统：你穿越后这张脸，本来值58点。
我盯着镜子里的脸看了十秒，转身下楼，敲响邻居家的门。
开门的姑娘眨了下眼："你谁？"
我："姐姐，我想借一勺猪油，拿蛋炒饭跟你换。"

> （原创示例，仅示范写法，可参考打法不可照搬）

## 十二、女频补充 & 英文题材映射

### 12.1 女频细分补充

| 细分 | 特征 | AI高发雷区 | 改善方向 |
|------|------|------------|----------|
| 年代文 | 时代质感、奋斗与情感 | "那个年代很艰苦"空泛 | 用具体物价/票证/邻里细节锚定年代 |
| 快穿 | 单元副本、任务与宿主成长 | 每个世界模板化 | 每个世界换一种人设与冲突内核 |
| 穿书 | 剧情预知、改写命运 | 原著剧情复述水字数 | 改写必须产生连锁反应 |
| 宫斗/宅斗 | 权力博弈、人心算计 | 反派脸谱化 | 每个人物有软肋与代价 |

### 12.2 英文题材映射

| 英文题材 | 对应中文类型 | 注意点 |
|----------|--------------|--------|
| Fantasy / Urban Fantasy | 玄幻/都市异能 | 魔法体系用行为展现；worldbuilding 嵌入情节 |
| Sci-Fi | 科幻末世 | 硬设定要自洽；规则演示优先于说明 |
| Romance | 言情甜宠 | 情感张力用 conflict + banter（拌嘴）推动 |
| Mystery / Thriller | 悬疑 | red herring（误导线索）+ 章末钩子 |
| Horror / Paranormal | 灵异 | 氛围用感官反常，不用形容词堆砌 |
| LitRPG / Young Adult | 游戏/轻小说 | 成长数值藏在情节；YA 重声音（voice） |

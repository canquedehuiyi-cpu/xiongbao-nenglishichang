# 多语言自动检测与切换框架

> 全球多语言支持（中/英/日/韩/法/德/西/葡 8 语言检测）
> 版本：1.7.0
> 原理：用户输入什么语言 → 系统用该语言处理并输出；输入以哪种语言为主 → 输出以哪种语言为主
> 说明：8 语言均支持自动检测与切换；完整创作规则覆盖中英双语（中文 11 平台 / 英文 3 平台见 `english-creation.md`、`platform-guide.md`），其余语言按通用创作框架输出
> 联动：英文创作规则见 `english-creation.md`；各语种平台硬参数以 `platform-data-registry.md` 为准、适配策略见 `platform-guide.md`；AI 合规要求以 `ai-compliance-redlines.md` 为准。

## 一、语言检测机制（字符集判定）

### 1.1 检测算法（Unicode 范围判定，无需外部库）

对用户输入按以下优先级判定，逐档统计字符占比（先剔除数字/标点/空白再统计）：

| 判定顺序 | 字符集 | Unicode 范围 | 判定条件 | 判定为 |
|----------|--------|--------------|----------|--------|
| 1 | CJK 统一表意文字 | U+4E00–U+9FFF | 占比 ≥ 30% | 中文 |
| 2 | 假名（日文） | 平假名 U+3040–U+309F / 片假名 U+30A0–U+30FF | 占比 ≥ 30% 且中文字符 < 30% | 日语 |
| 3 | 谚文（韩文） | U+AC00–U+D7AF | 占比 ≥ 30% | 韩语 |
| 4 | 拉丁字母 | U+0041–U+005A + U+0061–U+007A + U+00C0–U+00FF | 占比 ≥ 50% | 英文（细分见 1.2） |
| 5 | 检测失败 | 以上均不达阈值 | — | 兜底英文（见第三节） |

> **判定边界**：中日韩文本都含汉字，用假名/谚文占比区分日韩；中文与日文混排时，中文字符 ≥30% 判中文，否则以假名占比判日语。数字、标点、空白不参与占比计算。

### 1.2 拉丁语言细分（触发词二次判定）

| 目标 | 触发词（不区分大小写） |
|------|------------------------|
| English | english / "in English" / "switch to English" |
| Français | français / french / parlez français |
| Deutsch | deutsch / german / auf Deutsch |
| Español | español / spanish / en español |
| Português | português / portuguese / em português |

### 1.3 混合语言输入（中英混排/双语写作）

| 输入情况 | 处理策略 |
|----------|----------|
| 主体中文 + 英文术语/人名 | 按中文处理；英文专名保留原文，正文用中文写作 |
| 主体英文 + 中文引用 | 按英文处理；中文引用保留原文（可附注释） |
| 双语各占一半 | 以用户最后一句指令的语言为准；无指令默认中文 |
| 剧情内多语言（角色设定） | 叙述语言跟随主语言；角色台词保留角色设定语言（如外国角色说英文） |

## 二、各语言写作规则

### 2.1 中文（默认主语言）

- 标点：全角（，。！？：；""''《》）
- 对话引号：直角引号「」优先（本项目自然度优化规则，见 `anti-ai-engine.md`）
- 破折号铁律：每章"——"≤1 处；仅 3 种合法用途（打断插入/节奏转折/戏剧性补充），充当标点替代直接删并换逗号/句号/冒号
- 词汇：避免中英夹生；通用缩写（AI/CPU 等）可保留

### 2.2 English

- Punctuation: half-width (.,!?:"';)
- Dialogue quotes: curly double quotes "…"（避免直角引号）
- Rhythm: 长短句交替；禁用模板开场（"In this world," / "It was a dark and stormy night"）
- Platform: Wattpad / Amazon KDP / Webnovel 惯例（见 `english-creation.md`）

### 2.3 日本語

- 对话：用「」；叙述与对话的语体（です/ます vs だ/である）保持一致
- 避免中文式欧化长句直译；轻小说风格按 `genre-templates.md` 轻小说档

### 2.4 한국어

- 对话：用 "" 或「」
- 敬语体系按角色关系选择（尊称/平语），叙述层语体全文统一

### 2.5 Français / Deutsch / Español / Português

- 对话引号按各语言惯例（法语/西语 « »、德语 „ “）
- 阴阳性/格位/变位符合语法；避免机翻腔
- 模型能力不足时降级：英文创作 + 中文备注（见第三节 L2）

## 三、失败兜底与降级策略（三层）

| 层级 | 情况 | 动作 |
|------|------|------|
| L1 | 检测失败（无法判定语言） | 默认英文处理+输出，并主动询问"请确认使用语言"，不默默假设 |
| L2 | 目标语言写作能力不足 | 用英文创作 + 中文说明备注；不硬翻译、不硬写 |
| L3 | 用户手动指定 | 强制切换，覆盖自动检测结果（用户明示 > 自动检测） |

## 五、语言切换自检

- [ ] 输出语言与用户输入主语言一致？
- [ ] 标点/引号符合该语言惯例？
- [ ] 混合输入时主体语言选对、保留原文的专名/引文？
- [ ] 检测失败时是否已询问而非默默选英文？

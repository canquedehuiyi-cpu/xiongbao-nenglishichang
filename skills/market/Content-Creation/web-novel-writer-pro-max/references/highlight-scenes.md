## 一、名场面的定义与标准

**名场面 = 读者愿意截图/转发/记住的那一场戏。**

验收三条：
1. **可记忆**：三句话能复述（有画面、有金句、有情绪）
2. **可共情**：读者代入或旁观都起情绪（不止爽，还有疼/暖/恨）
3. **不可删**：删掉这场，全书情绪断裂（它是前文压力的总爆发）

---

## 二、名场面设计流程（六步）

```

步骤1 定位   → 明确这场戏承担的任务（高光/反转/情感/退场/爽点）
步骤2 蓄势   → 前置3-5章铺压力与期待（倒计时/伏笔/读者盼）
步骤3 引爆   → 设计引爆事件（冲击点：意外+相关+不可逆）
步骤4 呈现   → 选择写法：收着写 or 放开写（character-depth 5.2）
步骤5 定格   → 最高点给一个画面/金句（可截图）
步骤6 余波   → 后续1-3章消化这场戏的影响（余震贯穿）

```

## 三、高光时刻类型库

### 3.1 身份揭晓型

| 要素 | 说明 |
|------|------|
| 蓄势 | 前置"他到底是谁"的猜疑（他人议论/细节矛盾） |
| 引爆 | 关键人面前被迫亮底牌 |
| 呈现 | 用第三方视角引爆（路人/对手先认出，主角自己没在意） |
| 定格 | 一句身份台词 + 周围人的定格反应 |
| 余波 | 身份带来的新麻烦（不是从此顺遂） |

### 3.2 逆袭打脸型

| 要素 | 说明 |
|------|------|
| 蓄势 | 前置羞辱要有细节（不是空泛的"看不起"） |
| 引爆 | 在"他最在乎的场合"反杀（有观众、有之前侮辱过他的人） |
| 呈现 | 动作先行、围观者反应分层次（震惊→窃语→沉默） |
| 定格 | 胜利的代价/姿态（赢得很累，不是轻飘飘） |
| 余波 | 打脸引来更强对手（升级压力） |

### 3.3 至暗时刻型（爽文里最抓人的"虐点"）

| 要素 | 说明 |
|------|------|
| 蓄势 | 命运连击：希望刚起又破灭 |
| 引爆 | 唯一退路被断（三锚点全塌） |
| 呈现 | 收着写：不嚎啕，写细节（他没哭，把凉了的粥喝完） |
| 定格 | 一个动作宣告"我不认"（哪怕卑微） |
| 余波 | 谷底反弹的起点（绝境中的人物关系/金手指变化） |

### 3.4 情感告白/和解型

| 要素 | 说明 |
|------|------|
| 蓄势 | 前置误会/欲言又止（至少2处没说完的话） |
| 引爆 | 危机场景逼出真心话（不是咖啡馆谈心） |
| 呈现 | 话要说一半留一半，细节泄露情绪 |
| 定格 | 具象化定情/和解信物或动作 |
| 余波 | 关系升级后立刻遇到新考验（别停在甜蜜） |

### 3.5 牺牲/退场型

| 要素 | 说明 |
|------|------|
| 蓄势 | 前置人物的"托付感"（说遗言/留东西/反常温和） |
| 引爆 | 牺牲不可逆（读者早知道，人物不知道） |
| 呈现 | 收着写+他人视角（哭的是旁观者） |
| 定格 | 牺牲瞬间的细节（放下的手/完好的遗物） |
| 余波 | 幸存者的行为变化贯穿后续（替他活/报仇） |

## 四、蓄势技巧（名场面成败在蓄势）

| 技巧 | 做法 |
|------|------|
| 倒计时 | 明确时间压力（三天后/天亮前） |
| 伏笔埋设 | 引爆点前置2处细节（读者回头能"啊"出来） |
| 期待管理 | 让读者"盼着"某件事发生（预告式对话/道具） |
| 压力叠加 | 多个压力线合流（钱+身份+感情同时崩） |
| 反复试探 | 主角2次忍住不出手（第3次才爆） |

---

## 五、呈现技巧（引爆后的写法）

| 情况 | 推荐写法 |
|------|----------|
| 情绪密度极高 | 收着写：细节+留白（可记忆度更高） |
| 爽感爆发 | 放开写：短句+动作+围观反应 |
| 反转揭露 | 先细节失准（读者先察觉）→ 再一句直白揭底 |
| 打斗冲突 | 短句快切 + 声音特写 + 收束定格 |

## 六、名场面自检清单

- [ ] 这场戏的任务明确？（高光/反转/情感/退场）
- [ ] 蓄势是否≥3章？引爆点是否有前置伏笔？
- [ ] 写法选对了吗（收/放）？定格画面是什么？
- [ ] 读者复述需要几秒？（3秒内讲清 = 成功）
- [ ] 余波写了吗？后续章节是否消化了这场戏？
- [ ] 与平台适配（短剧重画面、起点重爽感、晋江重情感）？

## 七、名场面示范段（原创示例）

> 示范"逆袭打脸型"完整落地：蓄势（前置羞辱细节）→ 引爆（最在乎场合反杀）→ 呈现（动作先行+围观分层）→ 定格（一句台词+代价感）。以下为原创示例，仅演示结构写法，可参考打法不可照搬剧情。

```text

　　退婚那日，柳家宴开九桌。酒过三巡，柳老爷子把婚书摔在青石板上，碾了一脚："残废也配做我柳家女婿？"

　　沈砚没接话。他弯腰去捡婚书，袖口露出一截骨节分明的手腕——众人这才看清，他右手三指齐根没了，像被什么利器齐齐削断。

　　有人低声嗤笑："废物就是废物。"

　　满堂哄笑中，沈砚忽然抬头。他没有看柳老爷子，只看向堂上那幅"青元宗拜帖"——那是柳家三代求而不得的东西，今日却挂在正堂最显眼处，等贵客登门。

　　"老爷子，"他开口，声音不高，"拜帖上写的名字，是我。"

　　堂内静了一瞬，随即笑声更响。

　　"你？"柳老爷子气笑了，"你连字都写不了，也敢——"

　　话音未落，堂外传来马蹄声。青元宗执事翻身下马，手中捧着另一封拜帖，烫金封面，落款处赫然是宗主亲笔。他进门先拱手，行的却是平辈礼，直直冲沈砚："沈先生，宗主说，三年前您断指那一战，宗门欠您一个人情。"

　　柳老爷子的笑僵在脸上。满堂宾客你看看我，我看看你，先前笑得最响的几人默默把酒杯放回了桌上。

　　沈砚没看他们。他把婚书叠好放进怀里，对柳老爷子说了今晚第二句话："婚，我不退。你柳家想高攀的那个名头，从今天起，姓沈。"

```

> **示范拆解**：①蓄势=断指细节+"废物"羞辱+拜帖反差，3处压力线合流；②引爆=执事进门+宗主亲笔+断指真相揭底，动作先行（下马/拱手/递帖）而非台词硬砸；③围观分层=先哄笑→再静默→最后放酒杯，三层递进；④定格=两句话，前一句收婚约、后一句立威名，且"三指没了"已埋代价（赢在至暗，不轻飘）。

# 创作体量工程（短篇/中篇/长篇 全档位规划）

> 按目标字数倒推全书的章节结构、节奏密度、钩子频率、卷册划分与交付流程。先定体量，再定结构，再逐章创作。
> 版本：1.7.0
> 联动：体系树见 `worldview-engineering.md`；各平台单章区间/总字数等硬数据以 `platform-data-registry.md` 为准（适配策略见 `platform-guide.md`）；节奏模板见 `rhythm-patterns.md`；爽点密度见 `signing-standards.md`；长篇记忆见 `memory-engineering.md`。

## 一、体量档位总览

| 档位 | 字数范围 | 典型平台/场景 | 章节数与每章字数 |
|------|----------|----------------|------------------|
| **超短篇** | 2千-1万字 | 知乎盐言 / 抖音故事 / 短篇合集投稿（平台单篇/单章数值见 `platform-data-registry.md`） | 1-10章，800-2500字/章 |
| **短篇** | 1万-5万字 | 知乎盐言 / 番茄短篇 / 短篇平台 / 投稿参赛 | 5-25章，2000-3000字/章 |
| **中篇** | 5万-30万字 | 起点/番茄/晋江小体量 / 出版中篇 / 盐言连载 | 20-100章，2200-4000字/章 |
| **长篇** | 30万-300万字 | 起点/番茄/晋江/七猫主流连载 | 100-1000章，2200-5000字/章 |

**选档位看三件事**：目标平台（体量偏好）/ 个人产能（周更字数）/ 故事复杂度（主线能否撑住体量）。

## 二、短篇工程（2千-5万字）

### 2.1 七档标准字数模板

| 目标字数 | 章节规划 | 结构 | 适用 |
|----------|----------|------|------|
| 2千字 | 1章 | 一个事件完整起承转合 | 抖音故事/试水 |
| 5千字 | 2-3章 | 冲突→高潮→收尾 | 知乎盐言短篇 |
| 1万字 | 4-6章 | 三幕式（铺垫-冲突-解决） | 盐言/短篇合集 |
| 1.5万字 | 6-8章 | 三幕式+1个反转 | 盐言精品 |
| 2万字 | 8-10章 | 多线小冲突+一个主高潮 | 短篇连载 |
| 3万字 | 12-15章 | 五幕式（含中段大转折） | 出版短篇/参赛 |
| 5万字 | 20-25章 | 五幕式+完整副线收束 | 短篇集/IP短篇 |

### 2.2 短篇结构（三幕式骨架）

```

第一幕（占25%）：场景即冲突——第一段就要有"不对劲"（人物处于失衡状态）
第二幕（占55%）：对抗升级——主角尝试解决→失败→代价显现→被迫做关键选择
第三幕（占20%）：爆发与收束——冲突顶点→解决→余韵（结尾留一口气，不补全）

```

### 2.3 短篇节奏要点

- **第一段定生死**：前50字必须出现冲突/悬念/反转/危机之一（`hook-templates.md`）
- **单线主故事**：短篇不铺副线，所有人物服务一个核心冲突
- **结尾不封死**：留"余味"（画面收尾/一句反转/未解的遗憾），忌讳"从此幸福生活"式总结
- **每章一个推进**：短篇没有灌水空间，每章必须改变一个事实
- **爽点密度最高档**：短篇读者耐心低，爽点按爆款档执行（`signing-standards.md`）

### 2.4 短篇平台适配

各短篇平台的具体单篇 / 单章字数以 `platform-data-registry.md` 为唯一口径，下表只列结构与钩子偏好。

| 平台 | 结构偏好 | 钩子要求 |
|------|----------|----------|
| 知乎盐言 | 故事感/真实感/情绪冲击 | 标题即悬念，首段即冲突 |
| 抖音故事 | 极短章+强钩子 | 章末必断章 |
| 番茄短篇 | 爽感前置 | 开篇快速建立抓手，不长铺垫 |
| 参赛/出版 | 完整三幕+文学质感 | 主题鲜明 |

## 三、中篇工程（5万-30万字）

### 3.1 结构规划

| 目标字数 | 卷数 | 章节数 | 结构 |
|----------|------|--------|------|
| 5万-10万 | 1-2卷 | 20-45章 | 单主线+1副线 |
| 10万-20万 | 2-3卷 | 45-80章 | 双阶段主线（第一目标→第二目标） |
| 20万-30万 | 3-4卷 | 80-120章 | 三阶段主线+副线完整弧光 |

### 3.2 中篇节奏要点

- **每卷一个高潮**：卷末大高潮 = 卷内所有小冲突的总爆发（`highlight-scenes.md` 六步流程）
- **金手指成长一次**：中篇长度允许金手指"升级/换形态"一次，保持中期张力
- **伏笔回收两次**：中篇约2-4条伏笔，回收节奏"埋→半露→回收"（`plot-resources.md`）
- **人物弧光完整**：主角经历"失衡→挣扎→选择→蜕变"完整弧线（`character-depth.md` 弧光路径）
- **适合练手与验证**：中篇是新人验证"故事能不能撑住"的最小成本档

### 3.3 中篇平台适配

| 平台 | 字数区间 | 签约观察点 | 注意事项 |
|------|----------|-----------|----------|
| 起点 | 30万字左右可看成绩 | 前3章+收藏 | 中篇不达上架线需慎重 |
| 番茄 | 20万字左右见分晓 | 完读率 | 节奏必须快 |
| 晋江 | 10万-30万常见 | 收藏/霸王票 | 情感线与人物魅力优先 |
| 盐言连载 | 5万-20万 | 盐选转化 | 每篇/每章独立成钩 |

## 四、长篇工程（30万-300万字）

### 4.1 结构规划

| 目标字数 | 卷数 | 章节数 | 结构 |
|----------|------|--------|------|
| 30万-60万 | 3-5卷 | 100-200章 | 三阶段主线+中卷副线 |
| 60万-120万 | 5-8卷 | 200-400章 | 多阶段螺旋升级（新敌-新目标循环） |
| 120万-300万 | 8-15卷 | 400-1000章 | 大世界观+多线群像+逐卷收束 |

### 4.2 长篇螺旋升级模型

长篇最大风险是"同质循环"。用**螺旋升级**破局——每卷同时提升四个维度：

```

卷N结束时的状态（能力/势力/敌人/世界威胁）
   ↓
卷N+1：能力+1档 / 敌人+1档 / 舞台+1层 / 真相+1层
   ↓
读者获得"熟悉的升级感"+"全新的刺激感"

```

**螺旋自检**：连续两卷如果只升能力不换舞台/敌人/真相 → 循环化，读者疲劳。

### 4.3 长篇伏笔管理

- 主线伏笔 3-5 条：贯穿全书，卷卷推进（半露→全露→回收）
- 卷级伏笔 每卷 2-3 条：本卷埋本卷收
- 章节级钩子：每章独立
- 按 `memory-engineering.md` 记录伏笔追踪（超期未回收触发预警提醒）

### 4.4 长篇超长记忆（不忘记设定）

**记忆金字塔四层**，按 `memory-engineering.md` 协议维护：

| 层 | 记录内容 | 维护方式 | 作用 |
|----|----------|----------|------|
| **L0 章归档** | 每章 200-300 字摘要 + 提及角色 + 关键事件 | 每章写完记录 | 精确回忆：某章发生了什么、谁出场 |
| **L1 结构化事实卡** | 角色快照 / 设定实体 / 时间线 | 按 memory-engineering.md 维护 | 语义一致：角色当前实力/关系/状态、势力/力量/道具/地图/IP、剧情时间线 |
| **L2 卷级滚动压缩** | 每卷摘要链 + 新增角色 + 待回收伏笔 | 每卷结束压缩 | 长书不遗忘：注入时只取最近卷 |
| **L3 全书核心注入** | 书名/简介/大纲/主题/金手指/核心冲突/结局/铁律 | 开书时确立，全书挂载 | 永不跑偏：全书不变式 |

**注入规则（续写/诊断前）**：输出四层记忆块，按 **L3 → L2 → L1 → L0** 顺序注入；L3 核心永远注入，L2 只取最近一卷，L1 只取活跃角色与当前实体，L0 只取最近 3 章摘要。章节超过 30 万字后，L0 旧章摘要仅按需回查，不再常驻上下文。

**记忆规则**：凡跨章节引用的设定（人名/地名/能力/时间），写作时一律回查快照，禁止凭印象写。

### 4.5 长篇节奏

- 每 5 章一个小爽点 / 每 15-20 章一个中高潮 / 每卷末大高潮（密度按 `quality-metrics.md` 三档）
- 每 50 章一个"读者情绪重置点"（新目标/新舞台/新关系），防止长期同质消耗
- 灌水章占比 ≤15%（`quality-metrics.md` 指标7），过渡章用轻量评审

## 六、交付流程（体量决定节奏）

1. **定体量**：目标字数 → 查本节对应档位模板
2. **定结构**：卷数/章数/每章字数/三幕或螺旋结构
3. **定密度**：爽点档位/钩子频率/伏笔计划（按体量）
4. **搭体系树**：见 `worldview-engineering.md`（短篇可压缩，长篇必须全）
5. **逐章创作**：章纲→细纲→正文→自检→更新快照
6. **阶段性内检**：短篇完稿内检/中篇每卷内检/长篇每50章总检（`editor-review.md` 责编审稿）

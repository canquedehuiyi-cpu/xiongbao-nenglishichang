# 多层处理流水线（多层润色 / 多层去AI / 多层反AI）

> 把"润色一次、检查一次"升级为**多层流水线**：每一层只做一件事、只改该改的、留下可复核的层间记录。单层通过≠合格，全部层通过才交付。
> 版本：1.7.0
> 定位：本文件是 `quality-loop-engine.md` 中 repairing 阶段的**执行层**——reviewing 产出的问题清单，按本文件的分层流水线做补丁式修复，修后回交门控复审。
> 机理依据：五维自然度机理见 `human-fingerprint.md`、检测判据见 `ai-detection-dimensions.md`；四库替换见 `ai-pools.md`；替换决策见 `smart-replacement.md`；八维诊断见 `ai-diagnosis.md`；九大支柱见 `anti-ai-engine.md`；技法见 `writing-techniques.md`；节奏见 `rhythm-patterns.md`。

---

## 一、多层润色（五层）

### 1.1 五层总览

```

L1 内容层   → 逻辑/事实/信息完整性（防硬伤）
L2 文笔层   → 词汇/句式/表达精度（防平庸）
L3 节奏层   → 长短句/段落/情绪起伏（防平铺）
L4 人味层   → 心理/动作/对话/细节（防AI味）
L5 平台层   → 字数/钩子/爽点/合规（防签约失败）

```

### 1.2 各层操作清单

| 层 | 检查项 | 改法 | 改后自检 |
|----|--------|------|----------|
| L1 内容层 | 时间线/因果/设定一致/信息合理 | 修正硬伤，不删信息 | 事实链无断裂 |
| L2 文笔层 | 重复词/抽象词/被动句式 | 换具体词/动词化（`writing-techniques.md`） | 同义词不连续重复 |
| L3 节奏层 | 段落均质/句式循环/情绪无起伏 | 长短句混排/断裂留白/情绪落差（`anti-ai-engine.md` 支柱九） | 段长方差≥标准（`quality-metrics.md`） |
| L4 人味层 | 直接情绪词/抽象描写 | 换心理通道/微动作/对话潜台词（`writing-techniques.md`） | 情绪能"看见"不能"听见" |
| L5 平台层 | 每章字数/钩子/爽点密度/合规 | 补钩子/调密度/删禁区内容 | 平台标准对照表通过 |

**润色原则**：层与层独立执行、逐层过检；L1 不过不进 L2（先保内容再保文采）；只改高风险句段，不动安全句段（防过度润色）。

## 二、多层去AI（八层清洗）

### 2.1 八层总览（对应八维诊断）

```

M1 词级层    → AI高频词替换（四库词池）
M2 语级层    → AI高频短语替换（四库语池）
M3 句级层    → AI模板句式改写（四库句池）
M3.5 通感层  → 无关通感比喻删除/替换（四库通感池，判断三步见 smart-replacement）
M4 段落级    → 段落结构重组（不均质/留白/断裂）
M5 结构级    → 章节骨架去模板（开篇/收束/过渡模式化）
M6 语义指纹  → 观点平均化/情感平滑/转折模板（`ai-diagnosis.md` 8种指纹）
M7 节奏级    → 机械感扫描（句长恒定/节奏规律/连接词密度）

```

### 2.2 执行流程（八层流水线）

```

① 八维诊断（ai-diagnosis）：定位命中句段与分数
② 分层清洗：从 M1 到 M7 逐层处理（每层只改本层命中，通感层 M3.5 含在内）
③ 人味注入：M7 后整体注入人味（心理/动作/对话细节）
④ 复检：重新八维诊断，未过则回炉（最多2轮）
⑤ 报告：输出各层改动数 + 复检分数 + 剩余风险句段

```

### 2.3 各层替换逻辑

| 层 | 命中示例 | 替换方向 |
|----|----------|----------|
| 词级 | "不禁""仿佛""心中涌起" | 删/换具体动作 |
| 语级 | "瞳孔猛地一缩" | 换第三方反应/行为泄露（`ai-pools.md` 语池） |
| 句级 | "这件事让他明白了……" | 换白描+潜台词（`ai-pools.md` 句池） |
| 段落级 | 三句平行结构 | 断裂+长短错落 |
| 结构级 | "总之""由此可见"收束 | 用画面/对话/动作收束 |
| 语义指纹 | 各说一句正确话=观点平均 | 让一方有立场、有偏颇 |
| 节奏级 | 全段等长句 | 插入3字短句/超长句 |

## 三、流水线演示（原创示例）

> 示范"规则怎么落到正文"。以下两段演示文本均为本库原创，不含任何书籍原文；所有改动只演示单层动作，安全句段一律不动（贯彻"逐层只改该改的"）。

### 3.1 去AI七层演示（M1→M7，通感层 M3.5 并入检查）

**原始文本（约 150 字，AI 味集中）**：

> 夜幕缓缓地降临，整座城市仿佛被一层薄纱笼罩。林远站在天台上——今晚的风很大，吹得他外套猎猎作响。他的心中不禁一凛：这一次，不是普通的威胁，而是一场蓄谋已久的阴谋。他缓缓地握紧了拳头，目光渐渐变得坚定。这一切，让他明白了，真正的敌人从来不在明处。生活就是这样，总是在你以为平静的时候，给你一记重击。

特征扫描：命中"缓缓地×2""仿佛""不禁一凛""不是X而是Y""破折号当逗号""目光渐渐变得坚定（情感标签）""这一切，让他明白了（价值中空）""生活就是这样……（总结式收尾）"——八维诊断约 68 分，落在"明显 AI 感"区间（60-74）。

**M1 词级层**（AI 高频词替换）
- 本层改动：删"缓缓地"×2 与"仿佛"，被动句改主动白描。
- before：夜幕**缓缓地**降临，整座城市**仿佛被**一层薄纱笼罩。
- after：夜幕压下来，整座城市罩上一层灰。
- before：他**缓缓地**握紧了拳头
- after：他握紧拳头（副词删净，动作直接落地）

**M2 语级层**（模板短语→行为泄露）
- 本层改动："心中不禁一凛"是语库高频短语，换第三方可观察的身体反应。
- before：他的心中**不禁一凛**
- after：他的**后颈汗毛竖了起来**

**M3 句级层**（模板句式改写）
- 本层改动："不是普通的威胁，而是……"属"不是X而是Y"翻转句式，拆开直说。
- before：这一次，不是普通的威胁，而是一场蓄谋已久的阴谋。
- after：这次是冲他来的。蓄谋已久。

**M3.5 通感层**（无关通感检查）
- 本层改动：零命中，跳过。
- 说明：全段无"铁锈味""空气仿佛凝固了"类与情节无关的感官比喻，例行扫一遍即过。**不为凑层数硬改**——这是"只改该改的"的现场示范。

**M4 段落级**（段落结构重组）
- 本层改动：一段四句连排拆成三个自然段，制造长短落差与留白。
- before：……猎猎作响。他的后颈汗毛竖了起来：……（四句连排，无呼吸感）
- after：断在"罩上一层灰。""猎猎作响。"处各成一段，给情绪留空行。

**M5 结构级**（去模板收尾）
- 本层改动：删总结式收束句（"生活就是这样……"，支柱八指纹4），换动作定格。
- before：生活就是这样，总是在你以为平静的时候，给你一记重击。
- after：风把天台的门吹得哐哐响。他没再看远处那片灯海，转身下了天台。

**M6 语义指纹**（情感平滑/价值中空）
- 本层改动："目光渐渐变得坚定"是情感标签+平滑过渡（指纹2），删，让情绪由动作显影；"这一切，让他明白了……"是价值中空（指纹6），删，信息由前文自行透出。
- before：他握紧拳头，**目光渐渐变得坚定**。**这一切，让他明白了，真正的敌人从来不在明处。**
- after：他握紧拳头。（独段，情绪全靠拳头说话）

**M7 节奏级**（破折号铁律 + 句长CV）
- ① 破折号铁律（ai-pools 4.8，每章≤1处）：before：林远站在天台上**——**今晚的风很大（破折号当逗号用）→ after：林远站在天台上。今晚的风很大（拆句解决，配额清零）。
- ② 句长CV：清洗前句子均长 16-20 字、无短句冲击；清洗后出现"蓄谋已久。"（4字短句）与独段短句，长短落差恢复至 3:1 以上。

**人味注入**（按 2.2 流程第③步，M7 后补一笔废笔）：楼道里的声控灯没亮，他跺了两下脚，亮了。

**清洗后完整版本**：

> 夜幕压下来，整座城市罩上一层灰。
>
> 林远站在天台上。今晚的风很大，吹得他外套猎猎作响。
>
> 他的后颈汗毛竖了起来：这次是冲他来的。蓄谋已久。
>
> 他握紧拳头。
>
> 风把天台的门吹得哐哐响。他没再看远处那片灯海，转身下了天台。楼道里的声控灯没亮，他跺了两下脚，亮了。

**演示要点**：
- 逐层只改本层命中的东西：M3.5 零命中即跳过；"今晚的风很大，吹得他外套猎猎作响"从 M1 到 M7 一字未动（安全句段不动）。
- 清洗后 122 字 / 原文 149 字 ≈ 82%，守住"字数保底"规则（附录C，不低于原文 80%）。
- 清洗全程只做减法与换写法，不新增观点、不拔高——对应五条铁律"只降维不升维""删除金句"。

### 3.2 五层润色演示（L1→L5）

**原始文本（约 100 字，平庸但无硬伤）**：

> 他回到公司，看到桌上放着一封信。他拆开信，信里说他被辞退了，让他三天内办完交接。他坐在椅子上发呆，心里很难过，不知道自己以后该怎么办。他想给家里打个电话，最后还是放下了手机。他站起来收拾东西，准备离开。

**L1 内容层**（逻辑/事实/信息完整性）
- 一句话：修硬伤——"被谁辞退"缺信息来源，"准备离开"与"三天内办完交接"自相矛盾。
- 改后：他拆开信，是人事部的通知，说他被辞退了，三天内办完交接。

**L2 文笔层**（词汇/句式/表达精度）
- 一句话：删情绪标签词"心里很难过""发呆"，换具体可见的白描。
- 改后：他坐在椅子上。窗外的楼群灰蒙蒙的，他盯着看了很久，什么都没想进去。

**L3 节奏层**（长短句/段落/情绪起伏）
- 一句话：四句"主谓宾"等长连排，拆出短句与长句落差，插入断裂留白。
- 改后：他站起来，收拾东西。桌上那杯水还没喝过一口，他端起来，凉了，倒了。

**L4 人味层**（心理/动作/对话/细节）
- 一句话：加一处"拿起手机又放下"的犹豫，补一处与离职无关的"废笔"。
- 改后：手机拿起来三次，又放下三次。隔壁工位老周还在敲键盘，不知道他明天还来不来。

**L5 平台层**（字数/钩子/爽点/合规）
- 一句话：章末平收无钩子，结尾留一处未闭合的信息。
- 改后：他把工牌摘下来放在桌上。抽屉最里面压着的那张卡，他犹豫了一下，还是带走了。

**演示要点**：
- L1 不过不进 L2：先保证信息合理，再谈文笔；后层不推翻前层成果。
- 润色不等于堆形容词：每层只解决本层问题，改后片段彼此衔接可合成完整版本。

## 四、多层反AI（五层防线）

反AI = 从源头防 + 全程监控，比"事后去"更省力。

```

P1 写前预防   → 加载四库词表+禁用清单（写作开始前）
P2 写中监控   → 每段写完即查（连接词/句式/段落节奏）
P3 写后清洗   → 全篇八层去AI流水线（第二节）
P4 交付复检   → 八维诊断≥75分 + 16项自检（`anti-ai-engine.md`）
P5 持续进化   → 新AI模式→会话内模板词清单（`evolution-protocol.md`）

```

| 层 | 触发时机 | 工具/依据 | 通过标准 |
|----|----------|-----------|----------|
| P1 | 创作开始前 | `ai-pools.md` + 知识卡 | 词表已加载 |
| P2 | 每段/每章后 | 规则快查 + 手动复核 | 无高频词/句式重复 |
| P3 | 完稿后 | 八层流水线 | 各层清洗记录完整 |
| P4 | 交付前 | `ai-diagnosis.md` 八维诊断 | ≥75分 |
| P5 | 持续 | `evolution-protocol.md` | 新词入清单有记录 |

**诚实边界**（`anti-hallucination.md`）：所有多层处理的目标是"提升写作自然度与可读性"，不承诺"通过AI检测"；是否被识别因检测工具而异。

- [ ] 多层润色：五层逐层过检，L1 先行

## 七、在质量闭环中的位置

```

quality-loop reviewing：六项门控产出「门控编号+位置+问题+依据+建议」问题清单（本文件不负责挑问题）
        ↓
本文件 repairing：按问题类型选择流水线
  - 词/语/句/段/结构/语义/节奏痕迹 → 第二节八层去 AI（M1-M7）
  - 内容/文笔/节奏/人味/平台问题   → 第一节五层润色（L1-L5）
  - 情绪平缓区（D-EMO）            → human-fingerprint 机理 5 + emotion-curve-engine
  - 连贯性/伏笔/实体冲突           → promise-ledger / entity-state-machine（不在本文件重复规则）
        ↓
补丁式修复：只改问题清单命中位置，安全句段不动；同处三轮无效升级为重写
        ↓
回交 quality-loop 复审被触发的门控，确认问题清零且未引入新问题

```

- 修复优先级服从 reviewing 的严重度：致命（合规/逻辑/OOC）＞重要（节奏/钩子/情绪）＞建议（措辞）。
- 修复后必须重跑 `ai-ratio-tester.md` 区间估计与对应门控，确认痕迹下降而非「越改越像」。
- 两套评分体系不混用：六维规则核验（分越高越像 AI，≤45 合格）与八维人工诊断（分越高越自然，≥75 合格）各自判定。
- 诚实边界不变：本流水线提升自然度与可读性，不承诺通过任何平台检测。

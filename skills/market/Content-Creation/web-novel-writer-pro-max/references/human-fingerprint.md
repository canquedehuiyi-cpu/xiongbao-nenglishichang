## 二、五条统计机理

> 每条四段式：平台怎么测 → 真人特征 → 机器特征 → 可执行写作动作。写作动作是「写的时候自然做到」，不是事后堆砌。

### 机理 1 · D-PERP 困惑度（语言意外程度）

- **平台怎么测**：用语言模型对文本逐词预测，计算「意外程度」。整体意外度低且起伏小，说明文本高度贴合模型自身分布。
- **真人特征**：自然起伏——生僻、具象、带个人经验的词让意外度升高；口语、惯用词让它降低，高低交替。
- **机器特征**：意外度低而平，处处选「最稳妥的下一个词」，顺滑但可预测。
- **写作动作**：
  1. 每个自然段保留 1 个「带个人经验的具象词」（来自人物职业、经历、感官记忆），替代抽象概括词。
  2. 每段允许 1 处口语化、非书面的自然表达。
  3. 删掉「众所周知、值得一提的是、不得不说」这类零信息、模型偏爱的引导语。
  4. 不追求每句都「漂亮」，保留个别朴素直给句。

### 机理 2 · D-BURST 突发性（句长波动）

- **平台怎么测**：把句子按标点切分，计算句长序列的标准差/波动幅度，过度均匀即异常。
- **真人特征**：长短剧烈交错——用短句砸情绪点、用长句铺陈信息与氛围。
- **机器特征**：句长集中在窄区间，节奏匀速，像节拍器。
- **写作动作**：
  1. 以「长短交错」为默认节奏：铺陈用中长句，关键判断/情绪/动作落点用极短句（4-10 字）单独成句。
  2. 一个段落内避免连续 3 句以上字数接近（如都在 20-25 字）。
  3. 对话与动作交替时，对话用短句，叙述可长短混用。
  4. 章末/段末收束优先用短句，制造停顿感。

### 机理 3 · D-LEX 词汇多样性（个人化重复 vs 过度同义替换）

- **平台怎么测**：统计用词重复率与多样性分布，识别「过度同义替换」与「机械重复」两类异常。
- **真人特征**：会自然重复口头禅、核心意象、固定句式，形成可辨识的「个人化重复」；该换的时候才换。
- **机器特征**：怕重复，频繁换近义词（眸/眼/瞳孔、笑/勾唇/扬眉），华丽但没有个人印记。
- **写作动作**：
  1. 为每个主要人物设定 1 个口癖或惯用表达并贯穿（服务人物，而非全书一个口吻）。
  2. 选定 1-3 个核心意象反复出现、含义递进（素材见 `asset-library.md` 意象卡）。
  3. 同一事物不必每次换说法，符合人物习惯时允许原样重复。
  4. 删除「为换而换」的近义堆叠，保留更朴素准确的那个词。

### 机理 4 · D-PERF 完美度（真实的不完美）

- **平台怎么测**：检测全篇是否零停顿、零冗余、零断裂、过度对称工整——「过度完美」本身可疑。
- **真人特征**：有口语停顿、轻微冗余、自然断裂、自我修正，信息密度不均匀。
- **机器特征**：句式工整、结构对称、逻辑词齐全、没有一句「废话」，失真地平滑。
- **写作动作**：
  1. 对话与心理活动中保留自然停顿词与半截话（符合人物时）。
  2. 允许少量「非必要但真实」的细节（人物的小动作、环境杂音）。
  3. 主动打碎成串的三连排比、镜像对称句，单处至多保留一个。
  4. 叙事允许适度跳跃与留白，不把每个因果都用连接词焊死。

### 机理 5 · D-EMO 情感曲线（情绪落差）

- **平台怎么测**：按段落测量情绪强度序列，曲线过平、无低谷无爆发即异常（平台公开的多维检测含情感曲线维度）。
- **真人特征**：铺垫期压抑低谷、爆发期集中释放，波峰波谷落差明显。
- **机器特征**：情绪匀速推进、温和正确，缺少真正的低谷与爆发。
- **写作动作**：
  1. 每章先明确「情绪起点（谷）→ 情绪落点（峰或更深的谷）」，不允许一章情绪原地踏步。
  2. 高光前先做压抑/延迟/阻碍，落差强度与铺垫长度成正比。
  3. 平缓段落插入具体情绪触发点（一个动作、一句台词、一个发现）。
  4. 写完用 `emotion-curve-engine.md` 给段落强度打分连线，近似直线就重排节奏。

## 三、五维写作规则（自检与修复）

| 维度 | 写作规则 | 自检方法 | 修复方式 |
|------|----------|----------|----------|
| D-BURST 句长波动 | 长短句交错，关键落点用短句 | 切句统计句长，看是否连续趋同 | 长句拆短、插入口语短句、落点单独成句 |
| D-PERP 困惑度自然化 | 保留具象词与口语跳跃 | 找「过于顺滑、下一句可预测」的段落 | 替换为带个人经验的具象表达，删引导语 |
| D-EMO 情感起伏 | 每章有明确谷峰落差 | 用情绪曲线引擎打分连线 | 平缓段加情绪触发点，高光前补压抑 |
| D-PERF 适度不工整 | 允许停顿、断裂、留白 | 查是否三段式过度规整、零瑕疵 | 调叙事顺序、留悬念、打碎对称排比 |
| D-LEX 个性化留痕 | 保留口癖与核心意象 | 对照人物档案与风格档案 | 回归人物母语习惯，删过度同义替换 |

## 四、数据流（底层架构）

- **输入**：
  - `emotion-curve-engine.md` 提供情绪起伏基线（D-EMO）。
  - `style-distillation.md` 产出的作者风格档案提供个性化留痕基线（D-LEX）。
  - `asset-library.md` 提供个人化意象与人物口癖素材。
- **映射源**：`ai-detection-dimensions.md` 提供每条机理的平台判据，双向引用、维度 ID 一致。
- **输出**：五维「达标/未达标信号 + 位置」进入 `quality-loop-engine.md` 的 reviewing 阶段，作为质量门控之一。
- **承接（不重复造轮子）**：
  - `anti-ai-engine.md` 九大支柱 → 本引擎的执行规则层。
  - `ai-pools.md` 四库 → 本引擎的语料供给层。
  - `ai-diagnosis.md` 八维 → 本引擎的诊断清单层。
  - `smart-replacement.md` → 本引擎的替换决策层。
  - `multi-layer-processing.md` → 本引擎的多层清洗流水线。

## 五、单章落地流程

```

写前：明确本章情绪谷峰 + 调取人物口癖/核心意象（D-EMO/D-LEX）
写中：
  - 段落层面做到长短交错、落点短句（D-BURST）
  - 每段保留具象词与口语跳跃（D-PERP）
  - 对话/心理保留自然停顿与断裂（D-PERF）
写后：
  - 情绪曲线打分连线（D-EMO）
  - 按五维自检表逐维过一遍，定位问题段落
  - 需要词级清洗时调用 anti-ai-engine / ai-pools / smart-replacement
  - 结果交 ai-ratio-tester 估区间、交 quality-loop-engine 过门控

```

## 六、交付前核验清单

- [ ] 五维是否统一使用 D-PERP/D-BURST/D-LEX/D-PERF/D-EMO ID，与检测白皮书一致？
- [ ] 每条机理是否都落到了「写中可执行动作」，而非停留在概念？
- [ ] 是否避免了与 anti-ai-engine/ai-pools 的内容重复（本文件只讲机理与动作，词表在执行层）？
- [ ] 是否全程未承诺通过检测？
- [ ] 输出是否能进入质量闭环 reviewing 门控、并与占比自测口径一致？

### 自检标准（可验证）

1. 用机器痕迹明显的样本跑五维，每一维都能输出**可复算的特征值或定位**（句长是否趋同、情绪曲线是否近似直线、是否缺个人化重复等）。
2. 按写作动作修改后，五维信号与 `ai-ratio-tester.md` 灯号变化方向一致（痕迹下降）。
3. 任意输出都保留「提升自然度、不承诺过检」声明。

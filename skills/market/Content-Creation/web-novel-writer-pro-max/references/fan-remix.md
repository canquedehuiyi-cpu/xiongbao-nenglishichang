> 基于热门作品世界观/人物的二次创作（同人），以及借用爆款结构的仿写与魔改。核心价值：借"已验证的读者基础"降低冷启动。**版权红线见第三节，创作前必读。**

## 一、当下热门同人类型模板

### 1.1 同人五大类型

| 类型 | 定义 | 读者预期 | 创作要点 |
|------|------|----------|----------|
| 穿书/穿剧 | 读者/角色进入原作世界改写命运 | 已知剧情+未知改变 | 信息差是金手指；改变必须付出代价 |
| 角色重生 | 原作角色带着记忆重生 | 弥补遗憾/反转悲剧 | 重生者知道剧情，对手也可能知道 |
| 综漫/综影视 | 多个作品世界融合 | 联动脑洞+角色互动 | 世界观缝合要自洽，规则统一 |
| 平行线 | 原作世界另开一条时间线 | 熟悉角色+新故事 | 保留人设核心，改变命运轨迹 |
| 反派/配角视角 | 从原作配角/反派视角重述 | 视角新鲜感+动机洗白 | 不OOC；动机要立得住 |

### 1.2 同人模板（以穿书为例的完整配置）

```

【穿书同人模板】
- 进入对象：{男主/女主/配角/路人/反派}
- 时间节点：{原作开端/中期/大结局前}
- 已知信息：{全书剧情/单卷/零}
- 改变目标：{拯救XX/避开XX/夺取XX}
- 蝴蝶效应：{第一步改变引发的连锁}
- 限制规则：{不能说出剧情/系统惩罚/记忆会遗忘}
- 原作锚点：{保留的经典名场面/经典台词}

```

**模板自检**：读者是"原作粉丝"——原作名场面必须被尊重（保留或合理改变），违背原作人设=读者弃书。

## 二、仿写与魔改

### 2.1 仿写（结构仿写 vs 风格仿写）

| 类型 | 仿什么 | 依据 | 产出 |
|------|--------|------|------|
| 风格仿写 | 语言风格/叙事腔调 | `writer-styles-expanded.md` | 像某作家的文风 |
| 结构仿写 | 开篇/节奏/爽点排布 | `novel-deconstruction.md` | 像某爆款的骨架 |

**结构仿写三原则**：
1. 抄结构不抄内容（换世界观/人物/冲突）
2. 换题材换舞台（同一结构装进不同题材）
3. 标注来源（"结构对标《XX》，内容原创"——反幻觉协议）

**仿写量化验证**：
- 风格仿写 → 提取目标作家风格指纹（见 `writer-styles-expanded.md` 第四节量化参数与风格示范）→ 仿写后按参数逐项校验匹配度 ≥70%，最低分维度回炉
- 结构仿写 → 按 `novel-deconstruction.md` 拆爆款得量化基线（对话%/爽点密度/钩子密度）→ 自己稿件按同口径对表 → 差值达标放行

### 2.2 魔改（原作改造方向）

| 魔改方向 | 做法 | 示例 |
|----------|------|------|
| 反转人设 | 正派写黑、反派洗白 | 男主才是最终BOSS |
| 换主角 | 配角视角重写主线 | 从炮灰的角度看原著 |
| 改结局 | 悲剧改HE/HE改BE | 大团圆后十年 |
| 缝合 | 多作品元素重组 | 修仙+赛博+权谋 |
| 换舞台 | 同设定搬到新世界 | 仙侠版高考/职场 |

**魔改自检**：魔改必须"立住新逻辑"——改了人设/结局后，前期所有铺垫都要重新自洽（`worldview-engineering.md` 逻辑五查）。

## 三、版权红线（创作前必读）

### 3.1 同人创作的合法边界

| 行为 | 风险 | 正确做法 |
|------|------|----------|
| 使用原作人名/世界观/具体情节 | **高**：著作权侵权 | 平台多数禁止商用；个人爱好者创作可，但不可签约/收费 |
| 使用真实人物/明星 | **高**：人格权/名誉权 | 禁止 |
| 缝合多作品 | **中**：逐部核对 | 各作品均需确认授权边界 |
| 仅借鉴"题材套路" | 低（思想不受保护） | 结构/题材自由，具体表达需原创 |
| 致敬/彩蛋 | 低 | 引用要微量+明显区分 |

### 3.2 平台对同人作品的态度（参考值）

> 各平台对同人作品规定不同，部分平台明确禁止签约同人，或要求原作方授权。**引用时以平台最新作者规范为准**（`platform-guide.md`）。

- 签约/上架前必须确认该平台同人政策
- 原创性高的"半同人"（仅借题材壳）风险低于直接同人
- 魔改到"换皮不换骨"仍有侵权风险（具体情节/人物关系实质相似）

### 3.3 安全创作路径

```

想写同人 → 三步降险：
1. 评估：原作品权归属是否清晰？是否商用？→ 高风险则放弃
2. 改写：保留"卖点公式"与"题材壳"，人名/世界观/具体表达全部原创
3. 标注：纯个人练习注明"非商用同人练习"

```

**终极安全做法**：用爆款的结构方法论 + 题材壳 + 完全原创的世界与人物（这正是本 Skill 拆书/魔改模块的价值——把"侵权抄写"升级为"方法借鉴"）。

## 四、同人/仿写/魔改 全流程

```

1. 选型：同人（用原作资产）or 仿写（抄结构）or 魔改（借壳改造）
2. 版权评估：走第三节红线检查（高风险→改道安全路径）
3. 配置：套 1.1 模板 or 2.1 结构表 or 2.2 魔改方向
4. 定位：目标读者（原作粉/新读者）+ 平台（同人政策核查）
5. 创作：按 `worldview-engineering.md` 搭体系 + 逐章创作
6. 交付：自然度流水线（`multi-layer-processing.md`）+ 合规自检

```

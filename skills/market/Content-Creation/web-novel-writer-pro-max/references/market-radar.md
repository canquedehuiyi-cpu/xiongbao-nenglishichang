## 一、赛道隔离原则

本 Skill 只服务「网文小说签约」赛道，市场数据必须与其他赛道严格隔离，防止污染：

1. **只采信网文垂直来源**：平台官方榜单/作家专区/网文行业媒体为权威来源。
2. **跨赛道信息降级为背景**：短视频、游戏、影视、泛娱乐、其他内容行业的数据，即使来自权威媒体，也只作「跨界背景」，必须标注来源类型，**不得直接作为网文选题/签约结论依据**。
3. **不搬运其他赛道结论**：例如短剧爆款题材不等于网文爆款题材，二者读者场景、付费模式、节奏不同，禁止直接平移。
4. **来源类型显式标注**：每条数据标注「网文官方 / 网文行业媒体 / 跨界背景」，读者一眼可辨。
5. **趋势以网文自身数据验证**：跨界现象只有在网文榜单上也出现对应信号时，才升级为网文趋势。

## 二、数据源分级白名单

| 级别 | 来源类型 | 用途 |
|------|----------|------|
| M1 网文官方 | 各平台热销榜/新书榜/月票榜/飙升榜、作家专区公告、作者后台行业数据 | 趋势与风向的主要依据 |
| M2 网文行业媒体 | 专注网文/网络文学行业的媒体、研究报告、行业大会公开信息 | 交叉验证、补充解读 |
| M3 读者社区 | 书评区、网文向社区、读者讨论 | 捕捉情绪与口碑，不作量化结论 |
| X 跨界背景 | 影视/短剧/游戏/泛娱乐数据与媒体 | 仅作背景，标注「跨界」，不进结论 |

采信优先级 M1 ＞ M2（交叉验证）＞ M3（仅情绪参考）；X 不参与结论。来源是否属于网文垂直赛道存疑时，按 X 处理。所有来源交付前按 `verify-protocol.md` 核实时效。

## 三、抓取维度

对榜单/作品采集下列维度（只记录可公开观察到的事实，不臆测后台数据）：

| 维度 | 字段 |
|------|------|
| 基本信息 | 书名、作者、平台、榜单名与名次、品类标签 |
| 题材定位 | 主题材、子类型、核心卖点、一句话设定 |
| 开篇 | 开篇钩子类型、前三章冲突方式（看公开试读） |
| 标题简介 | 书名结构、简介钩子模式 |
| 更新形态 | 更新频率、单章体量（对照 `platform-data-registry.md`） |
| 榜单动态 | 新上榜/上升/下滑/在榜时长（需多次采样对比） |
| 读者反馈 | 评论关注点、追读情绪（M3，定性） |

## 四、分析流程

```

1. 定范围：目标平台 + 品类 + 时间窗（趋势至少取两个采样点对比）
2. 取数：按 M1→M2 顺序采集，逐条标注来源类型与采样日期
3. 隔离：识别并剥离 X 跨界信息，单独归入背景区
4. 聚类：把作品按题材/卖点/开篇模式聚类，统计出现频次
5. 验证：某模式是否在 M1 榜单多次出现、是否跨采样点持续
6. 结论：输出「正在上升 / 稳定主流 / 正在退潮」的趋势判断 + 证据
7. 保鲜：按 verify-protocol 记录采样日期，过期数据标 stale

```

---

## 五、趋势判定方法

- **正在上升**：连续采样中新进榜数量增加、覆盖多个平台或多个细分标签、M2 行业媒体同向印证。
- **稳定主流**：长期在榜、数量稳定，属于平台基本盘（可做但竞争激烈）。
- **正在退潮**：在榜数量连续下滑、新上榜减少、读者反馈疲劳。
- **伪趋势排除**：仅单一作品爆火不构成题材趋势；仅跨界火热、网文榜单无信号的，标「跨界热点，网文未验证」。
- **与签约结合**：趋势只提供方向，最终选题还要结合作者擅长题材与平台红线（`ai-compliance-redlines.md`），不追没有能力承接的热点。

## 六、输出模板

```

## 市场雷达报告 · 平台__ · 品类__ · 采样日期__
一、核心结论（上升/主流/退潮各是什么，3 条以内）
二、榜单证据
| 题材/模式 | 代表作品(公开信息) | 榜单表现 | 采样点变化 | 来源级别 |
三、可借鉴要素（只取方法层：钩子/卖点/结构，不取具体表达，联动 anti-washing）
四、跨界背景（X 类，仅供参考，不作为网文结论）
五、给本书的建议（结合作者题材与平台红线，给可执行方向）
六、数据说明：来源类型、采样日期、保鲜状态、以平台实时榜单为准

```

## 七、交付前核验清单

- [ ] 结论是否只由 M1/M2 网文垂直来源支撑？
- [ ] 跨界信息是否全部降级到背景区并标注「跨界」？
- [ ] 趋势是否至少两个采样点、跨作品验证，未把单本爆款当趋势？
- [ ] 每条数据是否标注来源级别与采样日期？
- [ ] 借鉴是否只取方法层、未搬运具体表达？
- [ ] 是否结合作者能力与平台红线给建议，而非盲目追热点？

### 自检标准（可验证）

1. 混入一条短剧热点数据时，能正确归入「跨界背景」且不进入网文结论。
2. 任一趋势结论都能追溯到至少一条 M1 或两条相互印证的 M2 来源。
3. 报告中每条数据来源类型清晰可辨，过期数据显式标 stale。

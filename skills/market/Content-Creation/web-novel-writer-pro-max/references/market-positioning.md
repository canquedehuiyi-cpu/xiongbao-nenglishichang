## 一、卖点五问

卖点 = 一句话说清"这本书凭什么被读/被签"。用五问逼出真卖点：

| 问题 | 作用 | 反例 |
|------|------|------|
| 1. 主角有什么别人没有的？（身份/金手指/处境） | 差异化 | "主角是普通人"（无卖点） |
| 2. 读者第一眼看到什么情绪？（爽/虐/好奇/共鸣） | 情绪定位 | "讲了一个故事"（无情绪） |
| 3. 和同类书有什么不同？（一个可验证的差异） | 抗同质 | "文笔好"（不可验证） |
| 4. 目标读者是谁？（年龄/性别/阅读习惯） | 精准投放 | "所有人"（无目标） |
| 5. 一句话怎么卖？（书名/简介/推荐语） | 传播 | 无 |

**卖点公式**：`差异化身份 + 明确情绪 + 可验证差异`。例："废柴皇子，却有读心术，看穿满朝文武的算计"。

**卖点自检**：把卖点发给不了解这本书的人，看对方是否追问"然后呢？"——不追问=卖点不成立。

## 二、看点四层

看点 = 读者持续追更的理由，分四层递进：

| 层级 | 看点类型 | 示例 | 承载时长 |
|------|----------|------|----------|
| L1 即时看点 | 章内爽点/悬念/反转 | 打脸、揭密、危机 | 每章 |
| L2 阶段看点 | 卷内目标与悬念 | 晋级、复仇、破案 | 每卷 |
| L3 主线看点 | 全书终极悬念 | 身世、真相、终极对决 | 全书 |
| L4 情感看点 | 关系线与人物命运 | CP线、兄弟情、救赎 | 全书 |

**看点配置规则**：四层同时在线——每章至少有 L1，卷内挂着 L2，全书吊着 L3，情感线牵着 L4。缺 L3/L4 的长篇会"中期失焦"。

**看点与爽点的区别**：爽点是即时满足（当下爽），看点是持续期待（追下去的理由）。爽点密集但看点缺失 → 爽完就弃书。

## 三、目标读者画像

| 画像维度 | 内容 | 对创作的影响 |
|----------|------|--------------|
| 年龄段 | 学生/青年/职场人/中老年 | 主角年龄、话题、价值观 |
| 性别向 | 男频/女频/全频 | 视角、爽点类型、情感浓度 |
| 阅读场景 | 通勤/睡前/碎片/沉浸 | 章节长度、钩子强度 |
| 付费习惯 | 免费/付费/打赏 | 体量、上架节奏 |
| 竞品迁移 | 从哪些书来 | 对标书选择 |

**读者画像落地**：为"一个具名读者"写作——设定一位虚拟读者（如"28岁男频读者，通勤刷番茄，爱打脸爽"），每章问一句"他会看下去吗？"

**男/女/全频速查**：

| 频向 | 核心爽点 | 情感浓度 | 节奏 | 视角偏好 | 题材偏好 |
|------|----------|----------|------|----------|----------|
| 男频 | 升级/打脸/征服/守护 | 中低 | 快 | 第三人称限知 | 玄幻/都市/科幻/历史 |
| 女频 | 情感/关系/成长/逆袭 | 高 | 中 | 女主视角/第一人称 | 言情/宅斗/年代/快穿 |
| 全频 | 悬疑/脑洞/喜剧/群像 | 中 | 中快 | 多视角 | 灵异/规则怪谈/无限流 |

## 四、对标书分析法

对标 = 找一本"目标位置"的爆款书，拆出可复用的定位。

### 4.1 选对标书三原则

1. **目标可比**：想签番茄→选番茄爆款（跨平台对标失真）
2. **成绩可信**：选近期上榜/持续更新的书（老书时代不同）
3. **体量匹配**：中篇对标中篇，长篇对标长篇

### 4.2 对标五拆

| 拆什么 | 提取什么 | 反哺哪里 |
|--------|----------|----------|
| 卖点 | 它的差异化在哪儿 | 我的差异化怎么错位 |
| 开篇 | 前3章如何留人 | 我的开篇钩子 |
| 爽点节奏 | 第几章第一个爽点/密度 | 我的爽点排布 |
| 看点结构 | 主线悬念怎么吊 | 我的L2/L3看点 |
| 受众画像 | 评论区读者是谁 | 我的读者画像 |

**对标错位法**：不抄对标的卖点，抄它的"结构方法论"，然后换题材/换金手指/换舞台（例如：同一套"废柴逆袭结构"可以装进仙侠/都市/科幻）。

## 五、对标脑洞法（创意对标）

对标脑洞 = 抓爆款脑洞的"底层公式"，再组合出新脑洞。比"对标书"更轻，适合极速创作与创意阶段。

**脑洞公式拆解表**：

| 爆款脑洞 | 底层公式 | 重组方向 |
|----------|----------|----------|
| 穿书变炮灰 | 已知结局→改写命运 | 穿游戏/穿剧本/穿漫画 |
| 重生复仇 | 时间回溯→弥补/报复 | 回档到三分钟前/无限重生 |
| 系统辅助 | 外挂工具→规则受限 | 系统反向/系统摆烂/系统是敌人 |
| 规则怪谈 | 异常规则→生存解谜 | 规则书/规则商店/规则贩卖 |
| 马甲文 | 多重身份→身份揭晓 | 马甲掉一半/马甲是反派的 |

**对标脑洞三问**：这个脑洞最吸引人的一分钟是什么？把它的"题材外壳"换掉还成立吗？把它的"主角处境"反转还成立吗？

## 六、平台实时题材推荐流程

### 6.1 推荐数据源（不编造，标注来源）

| 数据源 | 获取方式 | 时效 |
|--------|----------|------|
| 平台榜单（新书榜/畅销榜/热搜） | 用户可自查，或按用户提供的最新榜单 | 实时 |
| 平台规则更新 | `platform-guide.md` + 平台作者后台公告 | 季度核验 |
| 趋势分析 | `2026-platform-trends.md` | 年度更新 |
| 社区口碑 | 作者社区/读者评论（多源交叉） | 持续 |

**规则**：推荐题材时必须区分"实时榜单信号"与"通用市场规律"；无最新数据时降级为通用推荐并标注"以你看到的平台榜单为准"（反幻觉协议）。

### 6.2 推荐决策流程

```

用户问"写什么题材好"？
  ├─ 用户有目标平台 → 该平台榜单信号 + 平台题材偏好（genre-templates）
  ├─ 用户有目标读者 → 读者画像反推题材
  ├─ 用户有目标体量 → length-engineering 档位适配题材
  └─ 用户自由 → 三大信号合并：平台缺口 + 用户擅长 + 市场热度
                    （缺一不可，只有热度没差异=红海）

```

### 6.3 题材推荐输出格式

```markdown

## 题材推荐
- 推荐题材：XXX（附一句话理由）
- 热度信号：来自XX榜单/趋势（标注来源与日期）
- 差异化窗口：同类书较少切入的角度
- 体量建议：适合短/中/长篇（附档位）
- 风险提示：红海程度/平台规范边界

```

### 6.4 红海与蓝海判断

| 信号 | 红海（谨慎） | 蓝海（机会） |
|------|--------------|--------------|
| 榜单同质 | 同类书霸榜前20 | 榜上类型分散 |
| 供给密度 | 平台每天新增大量同类 | 同类供给少 |
| 搜索热度 | 关键词搜索量大但读者疲劳 | 关键词有量且缺口明显 |
| 规范空间 | 题材触及平台禁区 | 题材合规且新鲜 |

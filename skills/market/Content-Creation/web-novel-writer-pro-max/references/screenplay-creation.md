## 〇、剧本创作总纲

### 剧本 vs 小说的核心差异

| 维度 | 小说 | 剧本 |
|------|------|------|
| 呈现方式 | 文字叙事，读者脑补 | 视听指令，剧组执行 |
| 信息载体 | 心理/叙述/描写 | 画面+台词+动作+音效 |
| 黄金铁律 | 可读性 | **可拍性（看得见、听得见、动得起来）** |
| 心理描写 | 直接写 | 转化为 表情/动作/潜台词/反应镜头 |
| 节奏单位 | 章节 | 场（Scene）/镜头（Shot） |
| 读者 | 读者 | 导演/演员/摄影/剪辑/平台 |

### 创作前的三问（任何剧种必答）

1. **给谁看**：平台（抖音/快手/爱奇艺/卫视/院线/剧场/漫画平台）+ 目标人群
2. **多长**：总时长/总集数/单集时长/总字数 → 决定结构档位
3. **什么钩**：核心卖点一句话（一句话=观众点进来/读下去的理由）

### 通用剧本格式骨架（SLUGLINE 标准）

```

[场景标题] 内/外景 · 地点 · 时间
[动作描述] 谁在哪做什么（现在时，动词开头）
[角色名]：（语气/动作提示）台词

```

- 场景标题三要素：**内外景 + 地点 + 时间**（如：内景·审讯室·夜）
- 动作描述：**现在时、动词开头、只写看得见的**
- 台词行：角色名顶格，台词居中或缩进，可带（括号）语气提示
- 一场一镜头：场景切换必须换"场景标题"

## 一、短剧（竖屏微短剧）

> 主战场：抖音/快手/红果/九州/点众。**核心不是"短"而是"情绪节奏"**——单集必须让人看完还想看下一集。

### 1.1 格式规范（硬指标）

| 指标 | 标准值 | 说明 |
|------|--------|------|
| 单集时长 | 本文件聚焦竖屏微短剧 1-2 分钟档（爆款集中在 1 分 20 秒-1 分 50 秒）；全量分档见 `platform-data-registry.md` 第七节 | 超出 2 分钟完播率明显下降 |
| 单集字数 | 以 `platform-data-registry.md` 第七节对应时长档为准（剧本正文） | 工程换算：每分钟语速≈450 字台词+画面 |
| 总集数 | 以 `platform-data-registry.md` 第七节为准（星芒/精品 与 付费/投流分档） | 集数体量由平台形态决定 |
| 总时长 | 90-300分钟 | |
| 单集场景数 | 3-6场 | 场景多=节奏快 |
| 核心人物 | ≤5个 | 每集新人物≤1个 |

### 1.2 黄金法则（节奏设计）

- **黄金3秒**：第一句台词/第一个画面必须丢出钩子（冲突/身份反转/悬念），3秒内不抓人=划走
- **黄金30秒**：30秒内必须完成第一个"小反转或小爽点"，否则前3集流失率飙升
- **前3集定生死**：第1集立人设+埋大悬念，第2集冲突升级，第3集第一个反转兑现
- **每集一钩一爽**：一集至少一个爽点（打脸/反转/误会解除/身份揭示）+ 一个集尾钩子

### 1.3 四拍结构（单集标准骨架）

| 拍 | 位置 | 功能 | 占比 |
|----|------|------|------|
| **开场钩** | 0-10秒 | 丢冲突/悬念/身份，立刻抓住 | 15% |
| **冲突推进** | 10秒-1分 | 矛盾激化，主角被逼到墙角 | 45% |
| **情绪回报** | 1分-1分20秒 | 反转/打脸/爽点兑现，情绪释放 | 25% |
| **集尾留扣** | 最后10-20秒 | 新悬念，逼用户点下一集 | 15% |

```

第X集 单集结构示例
═══════════════════════════════════
【开场钩·0-10秒】身份/冲突直接砸脸
【冲突推进·10s-60s】对手施压，主角受辱或陷入绝境
【情绪回报·60s-90s】反转打脸，情绪释放（全剧最小"爽"单位）
【集尾留扣·最后10s】悬念/预告："他不知道，这才是开始——"
═══════════════════════════════════

```

### 1.4 六幕式（整剧结构）

| 幕 | 集数区间 | 内容 |
|----|----------|------|
| **起**（起因） | 1-5集 | 主角处境+核心冲突引爆 |
| **困**（困境） | 6-20集 | 压制升级，主角受压 |
| **反**（反击） | 21-40集 | 第一次反击/小胜 |
| **升**（升级） | 41-60集 | 冲突升级，更大对手 |
| **爽**（爽点爆发） | 61-85集 | 集中打脸/逆袭兑现 |
| **合**（收尾） | 86-100集 | 终极对决+圆满/悬念结局 |

> 注：30集/50集短剧按比例压缩前两幕，集尾钩子密度不变。

### 1.5 台词规则（短剧专用）

- 一句台词≤25字（竖屏观众读字幕，长了就读不完）
- 冲突时台词短促、单字句/两字句高频（"滚。""跪下。""你配吗？"）
- 每场戏必须有台词对抗，禁止纯旁白推进超过30秒
- 情绪靠台词"喊"出来：短剧允许夸张化（是特点不是缺点）

### 1.6 短剧自查清单

- [ ] 第1句台词/第1个画面在3秒内丢钩子？
- [ ] 单集字数是否符合 `platform-data-registry.md` 第七节对应时长档？
- [ ] 四拍齐全（开场钩/冲突/回报/留扣）？
- [ ] 集尾钩子能逼人点下一集？
- [ ] 每集台词平均句长≤25字？
- [ ] 场景标题三要素齐全？
- [ ] 无平台红线（见第 6 节）？

## 二、网剧（横屏长剧集）

> 主战场：爱奇艺/腾讯/优酷/芒果TV/搜狐。**分集+分场+SLUGLINE 标准格式**，对标电视连续剧网络化。

### 2.1 格式规范

| 指标 | 标准值 | 说明 |
|------|--------|------|
| 单集时长 | 35-45分钟 | 分账剧 45-60 分钟 |
| 集数 | 12-40集（分账剧12-24集为主） | 精品短剧12集 |
| 单集场景 | 8-15场 | |
| 单集字数 | 剧本正文 12000-15000字 | 每分钟≈350字 |
| 集数节奏 | 前3集必须立住 | 平台看片决策点：第1集/第3集 |

### 2.2 剧本格式（标准 SLUGLINE）

```

═══════════════════════════════════
第1集 「重逢」
═══════════════════════════════════

1. 内景·写字楼大厅·日
人群匆匆。周雨（28岁，白领）抱着一箱私人物品走出电梯。
她停在玻璃门前，深吸一口气。

周雨：（低声）终于，不用再看人脸色了。

2. 外景·写字楼门口·日
一辆黑色轿车缓缓停在她面前。车窗降下——
一张她最不想见的脸。

顾言：（勾起嘴角）好久不见，前同事。

═══════════════════════════════════

```

### 2.3 集结构（四段式）

| 段 | 位置 | 内容 |
|----|------|------|
| **冷开场** | 第1-3场 | 高能片段/悬疑先行，先抓再看 |
| **本集主线** | 中段 | 本集冲突主线：问题→挣扎→推进 |
| **副线/人物戏** | 穿插 | 感情线/人物关系推进 |
| **集尾钩子** | 最后1-2场 | 强悬念或情绪落点 |

- **每集一个独立问题**：集首抛出、集尾至少部分解决或升级
- **三集一钩**：每3集一个大事件钩子，锁住追剧动力

### 2.4 场景编号规则

- 场景编号连续递增（1. 2. 3. ...）
- 场景标题：`序号. 内/外景·地点·时间`
- 同场景多镜头不编号，镜头切换写动作描述
- 时间跳变（日/夜/次日）必须新开场景

### 2.5 网剧台词规则

- 台词长度随情绪：常态≤40字，高冲突时≤15字
- 独白/旁白每集≤2次，单次≤60字
- 潜台词≥30%（话里有话是网剧高级感来源）

### 2.6 网剧自查清单

- [ ] 冷开场高能？
- [ ] 场景标题=序号+内外景+地点+时间？
- [ ] 每集有独立问题+集尾钩子？
- [ ] 前3集立住主角+核心悬念？
- [ ] 单集字数12000-15000字？
- [ ] 台词符合情绪节奏？

## 三、电影剧本（院线/网络大电影）

> 对标好莱坞标准格式（Final Draft 格式）+ 三幕结构。**一句话能讲清的故事 + 三幕节奏 + 场景标题规范**。

### 3.1 格式规范

| 指标 | 标准值 | 说明 |
|------|--------|------|
| 总片长 | 90-120分钟 | 网大 70-90 分钟 |
| 剧本字数 | 25000-40000字 | 1页≈1分钟 |
| 幕数 | 三幕（+可有序幕/尾声） | |
| 场景数 | 40-60场 | |
| 核心人物 | 主角+2-3配角 | |

### 3.2 三幕结构

| 幕 | 位置 | 功能 | 关键节点 |
|----|------|------|----------|
| **第一幕·建置** | 0-25分钟 | 立人物+世界观，抛出目标 | 激励事件（10-12分钟）：打破主角日常 |
| **第二幕·对抗** | 25-85分钟 | 冲突升级，主角受阻→转变 | 中点转折（45分钟）：无法回头 |
| **第三幕·解决** | 85-120分钟 | 高潮对决+收尾 | 灵魂黑夜→高潮→新常态 |

### 3.3 标准剧本格式

```

1. 外景·城市天台·夜

城市灯火在脚下铺开。程野站在天台边缘，风卷起他的衣角。
他掏出手机，屏幕上是三个未接来电。

程野：最后一次了。

他按下了拨号键——电话那头，传来女儿的声音：
（小女孩）爸爸，你答应过陪我过生日的……

程野握着手机的手，慢慢放了下来。

                    —— 第一幕结束 ——

```

### 3.4 场景标题三要素铁律

- 首写：`1. 内景·房间·日`（序号. 内外景·地点·时间）
- 新场景=新序号；同一场景内换时间=新场景
- 闪回（FLASHBACK）单独标注：`闪回：3年前·婚礼现场` + `闪回结束`
- 画外音：`角色名（画外）`；旁白：`旁白（男声/女声）`

### 3.5 电影对白规则

- 台词要"藏一半说一半"：潜台词是电影对白的灵魂
- 每句台词服务：推进剧情 / 揭示人物 / 制造张力（至少其一）
- 动作优先于台词：能用一个动作表达，不用三句台词
- 关键时刻用"沉默"：高潮前留白

### 3.6 电影自查清单

- [ ] 一句话能讲清故事？
- [ ] 激励事件在10-12分钟？
- [ ] 三幕结构完整、中点有转折？
- [ ] 场景标题=序号+内外景+地点+时间？
- [ ] 高潮戏有"灵魂黑夜"时刻？
- [ ] 台词有潜台词、不直白交代？

## 四、舞台剧（话剧/音乐剧）

> 现场艺术，**依靠台词+舞台调度+灯光音效**，没有剪辑补救。**幕场结构 + 舞台提示（舞台指示）**是核心。

### 4.1 格式规范

| 指标 | 标准值 | 说明 |
|------|--------|------|
| 总时长 | 90-120分钟（含幕间） | |
| 幕数 | 1-3幕 | 现代戏剧多"独幕"或"两幕" |
| 场数 | 每幕3-6场 | |
| 剧本字数 | 20000-30000字 | |
| 舞台提示 | 单独段落，用括号区分 | 人物上场/调度/灯光/音效 |

### 4.2 幕场结构

```

═══════════════════════════════════
第一幕
═══════════════════════════════════

第一场 客厅·黄昏

（舞台：一张旧沙发、一盏落地灯。台灯亮着。）
（周雨坐在沙发上看信，信纸在手里微微发抖。）

周雨：（读信）"我走了，别找我。"
     （停顿，低声）十年了，你连一句"再见"都不肯当面说。

（门铃响。周雨猛地抬头，把信塞进沙发垫下。）

═══════════════════════════════════

```

### 4.3 舞台提示（舞台指示）规范

- **灯光提示**：`（灯光渐暗）` / `（一束追光打在门口）`
- **音效提示**：`（雷声，由远及近）` / `（电话铃响，两遍后停）`
- **动作提示**：`（她站起身，走到窗边，背对观众）`
- **调度提示**：`（左舞台）` `（舞台深处）`
- **节奏提示**：`（停顿）` `（长时间沉默）`——舞台剧的"心理时长"

### 4.4 舞台剧台词规则

- **台词即一切**：舞台剧的信息量全在台词，禁用"内心戏"（没有镜头可切）
- 潜台词通过"答非所问/停顿/重复"呈现
- 人物上下场必须"有动机"，禁止无故出入
- 独白（内心戏外化）是舞台剧合法特权，可整段使用

### 4.5 舞台剧自查清单

- [ ] 台词能独立承担全部叙事？
- [ ] 舞台提示（灯光/音效/调度/停顿）齐全？
- [ ] 人物上下场有动机？
- [ ] 幕场结构清晰？
- [ ] 舞台动作"可执行"（演员看得懂怎么演）？

## 五、漫画剧本（页/格分镜）

> 漫画剧本 = **写给画师的施工图**。核心：页格划分 + 景别 + 对白气泡 + 旁白框。每一格都要能"画出来"。

### 5.1 格式规范

| 指标 | 标准值 | 说明 |
|------|--------|------|
| 每话页数 | 12-20页 | |
| 每页格数 | 4-8格 | 关键页可 1-3 大格 |
| 对白气泡 | 单气泡≤30字 | |
| 旁白框 | 单框≤40字 | |
| 景别 | 远景/全景/中景/近景/特写 | 每格必须标景别 |

### 5.2 页/格分镜规范

```

═══════════════════════════════════
第1话 「雪夜孤行」 页1（4格）
═══════════════════════════════════

【格1】远景/大格（半页）
画面：雪中古栈道，一人独行，天地苍茫
旁白：大隋末年，天下将乱。

【格2】中景
画面：少年（林远）背柴，回望山门
林远：「我走了。」
老者（画外）：「莫回头。」

【格3】近景
画面：林远眼眶微红，嘴角紧抿
（无声格）

【格4】特写
画面：腰间破旧玉佩，裂纹处透出微光
旁白：他不知道，这块玉——
═══════════════════════════════════

```

### 5.3 景别选择规则

| 景别 | 用途 |
|------|------|
| 远景 | 环境/气势/孤独感 |
| 全景 | 交代人物与环境关系 |
| 中景 | 对话/动作常态（最多用） |
| 近景 | 情绪/反应 |
| 特写 | 关键道具/表情冲击（每话≤3个，用就要炸） |

### 5.4 视觉节奏

- **大格=重要时刻**：每话 1-2 个跨页/半页大格给"名场面"
- **小格=快速推进**：连续小格加速节奏（打斗/追逐）
- **无字格（留白）**：情绪顶点前用无声格拉高张力
- **每页尾格=翻页钩子**：每一页最后一格必须勾人翻页
- **一页一情绪**：一页内情绪不来回跳

### 5.5 漫画对白规则

- 一句话只说一件事；气泡内不留废字
- 动作画面里气泡要"让路"：台词不遮关键动作
- 情绪用气泡形状+字体表现（吼叫=爆炸形气泡）
- 旁白负责"时间与背景"，对白负责"现场与情绪"

### 5.6 漫画自查清单

- [ ] 每格标注景别？
- [ ] 每格能"画出来"（无抽象描述）？
- [ ] 气泡≤30字、旁白≤40字？
- [ ] 每页尾格是翻页钩子？
- [ ] 每话有1-2个名场面大格？
- [ ] 一页一情绪？

## 六、平台合规红线（五剧种通用）

> 依据《网络视听节目内容审核通则》与各平台社区规范，以下内容直接封杀/下架/限流：

| 红线类型 | 具体内容 |
|----------|----------|
| **涉政** | 违背国家政策、破坏国家统一、歪曲历史 |
| **黄** | 露骨性描写、色情擦边、软色情暗示 |
| **暴恐** | 血腥暴力细节、恐怖惊悚过度、鼓励犯罪 |
| **宗教** | 侮辱宗教、传播迷信（封建迷信洗脑） |
| **侵权** | 抄袭洗稿、盗用他人形象/音乐/剧集 |
| **价值观** | 三观不正（婚外情美化、犯罪美化）、仇富仇官、地域歧视 |
| **健康** | 自杀自残详细描写、吸毒体验描写 |
| **导向** | 拜金炫富、低俗恶搞英雄/伟人 |

### 各平台审核尺度差异

| 平台 | 尺度特点 |
|------|----------|
| 抖音/快手 | 短剧审核最严：擦边/三观/医美广告严格 |
| 爱奇艺/腾讯/优酷 | 全剧备案制，送审剧本需完整合规 |
| 院线 | 需《电影剧本(梗概)备案》，敏感题材走完备案 |
| 舞台剧场馆 | 属地文化审批 |
| 漫画平台 | 画面尺度审核严于文字：露骨画面直接封 |

> **建议**：创作前把 6.1 红线清单过一遍，写完再自检一次；涉及敏感题材先查平台当期政策。

## 七、创作流程（三功能落点）

### 7.1 直出剧本创作（新用户直接开工）

```

用户输入：一句话/一个梗/一个题材 → 出全剧本
流程：
  1. 定位：选剧种（短剧/网剧/电影/舞台剧/漫画）→ 定平台 → 定体量
  2. 卖点：一句话核心卖点 + 一句话故事
  3. 人物：主角 + 对手 + 关键配角（各配一句人设+动机）
  4. 结构：按剧种套骨架（短剧六幕/电影三幕/舞台剧幕场/漫画话页）
  5. 正文：逐集/逐场/逐话产出，套对应格式规范
  6. 自检：按剧本自检清单核验格式/节奏/钩子/台词/合规（见 7.5）
  7. 交付：输出规范剧本文件

```

### 7.2 小说 → 剧本

```

输入：小说章节/片段 + 目标剧种
流程：
  1. 提取：核心冲突/关键场景/核心人物（配角合并精简）
  2. 转化：叙述→画面动作，心理→表情/潜台词/反应
  3. 切分：按剧种节奏切场（短剧一场一冲突）
  4. 加钩：每集/每话尾加钩子（小说可没有，剧本必须有）
  5. 套格式：SLUGLINE/幕场/页格，按剧种规范

```

### 7.3 剧本 → 小说

```

输入：剧本（任意剧种格式）+ 目标小说风格
流程：
  1. 读解：解析场景标题/台词/动作/舞台提示
  2. 扩写：动作描述→环境+细节+感官；台词→叙述+心理补全
  3. 补心理：剧本的潜台词外化为小说内心戏
  4. 回填：短剧"集尾钩子"→小说章尾悬念，衔接续写
  5. 反AI：套 anti-ai-engine 自然度规则，去掉剧本腔

```

### 7.5 剧本自检清单与创作增强

**剧本自检清单**（按剧种产出后逐项核验）：

| 检查项 | 要求 |
|--------|------|
| 场景标题三要素 | 每场含 内外景·地点·日/夜 |
| 钩子 | 短剧/网剧每集尾留扣；漫画话尾钩子；电影幕末留扣 |
| 台词口语化 | 现代剧避免"顿时/良久/颇为/罢了/莫非"等书面词 |
| 心理外化 | 心理活动改表情/潜台词/反应，不直接写内心 |
| 可拍性 | 每条动作描述可拍摄（有画面），无抽象表述 |
| 推进节奏 | 同一地点连续≥2场 → 提示"场景滞留"；场景块内无动作动词且无台词 → "静态场" |
| 台词均长 | 短剧台词单句≤25字 |

> 结构类指标（场景标题三要素/钩子/景别/心理外化/可拍性/推进节奏/口语化）需全部达标；网剧字数（12000-15000）、电影体量（40-60场/2.5万-4万字）、短剧台词占比（40-70%）等"平台体量类"指标需按正式项目规模补齐后再判定。

**自检增强**（两项可核验红线）

- **场景推进节奏**：同一地点连续≥2场 → 提示"场景滞留"（情节未推进，建议合并或换地点）；场景块内无动作动词且无台词 → 提示"静态场"（像说明书，拍不出来）
- **现代剧台词书面语**：台词中的"顿时/良久/颇为/罢了/莫非"等书面词检出（现代剧对白改口语；古风剧豁免由作者判定）

**创作增强**（剧本→小说回写）

- 集尾钩子控制：转换时按剧集内容提取 1-10 条钩子候选，择优用于章末悬念
- 对白密集段落自动拆镜头：连续台词≥3行自动插 `[镜头：对白对抗·正反打]`、说话人切换处插 `[切·反打]`，替代平铺堆行

## 九、剧本创作通用红线（写作层面）

- [ ] 禁止把心理描写直接写进剧本（一律外化）
- [ ] 禁止"可拍性"模糊描述（"气氛很压抑"→改为具体动作/光线/调度）
- [ ] 禁止一场戏无冲突（每场必须有"变化"）
- [ ] 禁止同一地点连续多场无变化（场景滞留→合并或换地点）
- [ ] 禁止现代剧对白书面语（"顿时/良久/颇为"→"一下子/好半天/挺"；古风剧豁免）
- [ ] 禁止角色名混淆（同剧不重名、不近似名）
- [ ] 禁止旁白代替表演（能演出来的不旁白）
- [ ] 禁止集尾无钩子（短剧/网剧/漫画硬性）

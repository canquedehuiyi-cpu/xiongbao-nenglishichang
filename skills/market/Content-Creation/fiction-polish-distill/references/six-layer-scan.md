# AI 痕迹六层扫描（模块 R）

> 版本 1.0.7 新增 · 对应脚本 `scripts/six_layer_scan.py`

## 功能定位

把"AI 感"拆解为六个可量化的层级，单次扫描输出分层报告，并明确指出"你的 AI 感主要来自哪一层"。数据源复用黑名单单一数据源（`references/antiai_blacklist.json`）。全部为**本地启发式估算**（零外部依赖、不上传数据）。

## 能力清单

| 编号 | 层级 | 检测内容 |
|------|------|----------|
| R-1 | 词层 | 高频 AI 词（逻辑连接词/绝对化/抽象名词/无效强调等短词） |
| R-2 | 语层 | 套话短语（模板化开头/总结性套话/假设让步/逻辑显式等长短语与正则模式） |
| R-3 | 句层 | 句式单一（句长分布过窄）与连续同字开头 |
| R-4 | 语义层 | 语义重复/车轱辘话（相邻句 n-gram 重叠）与同义反复 |
| R-5 | 指纹层 | 风格一致性（前后句长漂移/过于工整）；可对比用户风格档案"像不像自己写" |
| R-6 | 行为层 | AI 行为模式：对话无信息增量（僵硬）、长文本事件密度低、具象细节少 |
| R-7 | 分层结论 | 综合各层得分，输出"AI 感主要来自哪一层"定位结论 |

## 使用方式

```
python3 scripts/six_layer_scan.py <文本.md>            # 分层报告
python3 scripts/six_layer_scan.py <文本.md> --json     # JSON 输出
python3 scripts/six_layer_scan.py <文本.md> --profile 用户旧作.md  # 对比个人风格档案
```

`--profile` 提供作者本人旧作时，指纹层会改为"此段与你的惯用风格一致性"，辅助判断"是不是自己写的"。

## 输出要点

- 六层各自 0-100 分 + 命中示例（定位到具体词/句/表现）
- 综合 AI 痕迹分 + "主要来源层"结论
- 每层附改写方向（按示例逐处处理）

## 局限（诚实声明）

- 全部为本地启发式估算，**不替代任何平台检测**
- 语义层依赖相邻句统计，长句/短句混杂时可能误判
- 行为层的事件密度/具象细节指标仅在长文本（≥300 字）启用，避免短文本误报
- 各层阈值与词表可从黑名单 JSON 的 `behavior_features` / `semantic_features` 分区统一调整

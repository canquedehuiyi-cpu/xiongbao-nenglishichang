# 情绪曲线量化器与人味情感质量（模块 Q）

> 版本 1.0.7 新增 · 对应脚本 `scripts/emotion_curve.py`

## 功能定位

把章节/全书的情绪起伏量化为"段落粒度情绪曲线"，并量化"人味情感质量"——区分"告诉读者感受"（直白情感标签）与"让读者感受"（动作/身体反应/环境具象表达）。全部为**本地启发式估算**（零外部依赖）。

## 能力清单

| 编号 | 能力 | 说明 |
|------|------|------|
| Q-1 | 段落情绪强度 | 词汇情绪权重 + 事件强度 + 冲突密度 → 每段 -1 ~ +1 |
| Q-2 | 情绪曲线输出 | 逐段情绪强度条形图，平缓区/峰值标注 |
| Q-3 | 对标平台维度 | 起点"每章爽点节奏"、番茄"情绪波动平缓"等维度的本地近似参考 |
| Q-4 | 人味情感质量 | 情感标签密度 vs 具象表达占比，量化"告诉 vs 让感受" |
| Q-5 | 情感改写建议 | 平缓区提示加入转折；标签偏多提示改写为具象表达 |

## 使用方式

```
python3 scripts/emotion_curve.py <文本.md>           # 情绪曲线报告
python3 scripts/emotion_curve.py <文本.md> --json    # JSON 输出
```

## 输出要点

- **情绪曲线**：逐段强度（正/负/中性）+ 视觉条形
- **平缓区**：连续多段情绪无明显起伏的位置（番茄"情绪平缓"维度的本地参考）
- **情绪峰值（爽点）**：局部情绪高点及其段落位置（起点"每章节奏"的本地参考）
- **人味情感质量分**：0-100，越高代表"让读者感受"的具象表达占比越高
- **改写建议**：按平缓区与标签密度给出可操作方向

## 局限（诚实声明）

- 情绪强度为启发式估算（情绪词库 + 事件词加权），不识别复杂反讽/潜台词
- "对标平台维度"仅作作者自查参考，**不替代平台判定**
- 人味情感质量衡量"表达方式"，不衡量内容好坏

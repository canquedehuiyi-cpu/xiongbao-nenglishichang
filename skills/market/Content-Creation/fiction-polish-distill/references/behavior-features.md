# AI 行为特征库与规则分区（模块 T）

> 版本 1.0.7 新增 · 数据分区位于 `references/antiai_blacklist.json`

## 功能定位

把"AI 行为特征"、"语义特征"、"实体状态规则"沉淀为黑名单 JSON 的标准分区，与既有规则统一维护，实现**单一数据源**——各引擎运行时从同一份 JSON 加载，避免散落硬编码、口径漂移。

## 数据分区

| 分区 | 内容 | 使用者 |
|------|------|--------|
| `behavior_features` | AI 行为层特征：对话动作词、事件词、感官词、事件密度阈值、具象细节阈值、长文本启用长度 | `six_layer_scan.py`（R-6 行为层） |
| `semantic_features` | 语义层特征：n-gram 长度、重叠计数阈值、同式反复长度差、重叠率阈值 | `six_layer_scan.py`（R-4 语义层） |
| `entity_rules` | 实体状态机规则：死亡/昏迷/离开/登场/持物状态词、时间推进词表、时段标记、伏笔埋点词、回收词 | `entity_tracking.py`（P-1~P-4） |

## 设计原则

- **单一数据源**：引擎从 JSON 分区加载，脚本内仅保留 JSON 缺失时的默认回退（防御性）
- **阈值可调**：各检测阈值集中在 JSON 分区，作者可统一调整而无需改脚本
- **跨语言统一**：行为/语义/实体规则均为跨语言通用词表，与黑名单 rules 分区一致
- **Schema 校验**：`scripts/schema_check.py` 校验分区字段齐全（见黑名单数据校验）

## 使用方式

各分区由对应引擎在运行时自动加载，无需手动调用。作者如需微调检测口径，可直接编辑 `references/antiai_blacklist.json` 对应分区（修改后重跑引擎即可）。

## 局限（诚实声明）

- 各特征词表为启发式基础词集，覆盖常见 AI 行为模式，不保证穷尽
- 阈值调整影响对应引擎的敏感度，建议小幅调整并回归验证
- 分区数据仅供本地自查，**不替代平台检测**

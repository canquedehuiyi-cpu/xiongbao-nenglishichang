# 新用户引导

> 首次使用触发一次，展示一行欢迎语（轻量版）
> 说"下次不用了"/"关闭引导" → 本会话内不再显示；说"重新开启引导" → 恢复显示
> 说明："关闭"状态随会话保存，跨新会话可能再次出现，属平台架构特性

---

## 首次引导（轻量版）

```
📖 欢迎使用「小说润色蒸馏专家 1.0.7」
定位：以人类为主导的 AI 辅助网文创作质量工作台
支持：质量检测 · 去AI味 · 润色 · 蒸馏 · 仿写 · 续写 · 对白 · 日韩适配 · 合规体检 · 专家会诊（中/英/日/韩）
▶ 直接说你想做什么即可，或说"帮助"看完整指南。说"下次不用了"关闭本提示。
```

---

## 关闭引导

```
💡 下次还需要引导吗？

→ "下次不用了" / "关闭引导"    本会话内关闭
→ "先不关"                     下次还显示
→ "重新开启引导"               恢复显示
```

## 快速参考卡（说"帮助"时展示）

```
📋 一句话入口：

"检测这段"     → 质量检测（句长/连接词/情感/深度维度）
"去AI味"       → 检测-去味闭环（三档：保守/标准/深度）
"润色这段"     → 润色建议
"提取我的风格" → 蒸馏风格档案
"用XX风格写"   → 按风格档案给改稿建议
"续写这段"     → 续写方向建议
"对白增强"     → 对白僵硬检测与增强建议
"开篇体检"     → 平台开篇达标体检（起点/番茄/晋江口径）
"叙事检查"     → 叙事层检测（结构/转折/伏笔/五感）
"合规体检"     → AI 辅助申报清单/平台合规体检
"轻小说"/"韩网文" → 日韩适配
"专家会诊"     → 模拟专家团逐项质检

体验路线：
  A 检测    "检测这段，帮我看看哪里像AI写的"
  B 去AI味  "帮我把这段文字去AI味"（三档可选：保守/标准/深度）
  C 润色    "润色这段，让它更自然"
  D 蒸馏    "从我的文章里提取写作风格"
  E 仿写    "用海明威风格重写这段"
  F 续写    "根据这段续写一个方向"
  G 开篇    "看看我这个开头在起点达不达标"
  H 合规    "生成一份AI辅助使用申报清单"

语言切换：
  "English mode"  → 切换到英文
  "中文模式"      → 切换到中文
  "日本語" / "한국어" → 切换到日/韩

关于三档模式：
  保守 conservative  最小干预，仅改高置信度问题
  标准 standard      默认，常规处理
  深度 deep          最大处理，适合 AI 味重的长文本

关于合规：
  本工具输出"供作者人工加工的改稿建议"，不生成可直接投稿的 AI 成品正文；
  发布前请按《人工智能生成合成内容标识办法》主动声明 AI 辅助，不伪造创作过程。
```

## 常见任务分诊（说"不知道做什么"时展示）

```
1. 想检查稿子质量       → "检测这段"
2. 想去掉AI味道         → "去AI味"

4. 想学某个作家的风格   → "提取我的风格"/"用XX风格写"
5. 卡在剧情写不下去     → "续写这段"
6. 对话读着干巴巴       → "对白增强"
7. 担心开头被平台判劣质 → "开篇体检"
8. 担心AI使用不合规     → "合规体检"
```

# 小说润色蒸馏专家 1.0.7

> 以人类为主导的 AI 辅助网文创作质量工作台：质量检测 · 人工质感优化 · 润色 · 风格蒸馏 · 作家仿写 · 续写 · 对白增强 · 日韩适配 · 合规申报 · 原创自查 · 实体与剧情追踪 · 情绪曲线 · AI痕迹分层定位 · 红蓝对抗审稿

## 概述

小说润色蒸馏专家是一款面向小说创作者的**以人类为主导的 AI 辅助创作质量工作台**，覆盖中国网文、英文小说、日本轻小说、韩国网文、出版文学等。核心支持中英日韩四语深度适配，其他语言回退到英文模式处理。**无外部依赖**：所有模块、数据、脚本、专家档案均为内置资源；仅平台政策核实脚本可联网（失败如实降级，不编造）。

## 核心能力

| 能力 | 说明 |
|------|------|
| **质量检测** | 质量层（词频异常/句式单一/情绪波动/逻辑连贯/风格一致）+ 叙事层（对话僵硬/语句重复/事件密度/节奏分布）+ 四语基础检测，全部为启发式估算 |
| **人工质感优化（去AI味）** | 去除AI写作痕迹，提升写作质感，14类词表+7技法+五感+温差；三档模式（保守/标准/深度） |
| **智能润色** | 5原则+6灵魂注入，术语锁定，场景适配，字数保底80% |
| **风格蒸馏** | 双引擎提取写作风格DNA，8维参数，交叉验证 |
| **作家仿写** | 对标中英日 27 位作家风格；续写方向与对白增强 |
| **日韩适配** | 日本轻小说/韩国网文独立风格规则+语体一致检测 |
| **开篇体检** | 起点/番茄/晋江平台口径开篇达标体检 |
| **合规申报** | AI辅助使用申报清单/平台合规体检/人工改写比例/创作留痕/标识提醒 |
| **原创自查** | 洗稿/融梗重合度 + 同质化指数（本地启发式自查，非权威判定） |
| **自进化** | 动态黑名单学习（多语言种子池）+ 采纳反馈闭环 + 回滚 |
| **统一工作流** | 一键流水线（安全→质检→叙事→开篇→去味→合规→原创）+ 章节级聚合 |
| **模拟专家团会诊** | EX1-EX7 虚构专家逐项质检，与质量检测脚本标准一致 |
| **实体与剧情追踪** | 实体状态机（跨章一致性/时间线/伏笔回收/角色声线），整本书级结构洞察 |
| **情绪曲线** | 段落情绪起伏量化 + 平缓区/峰值 + 人味情感质量（告诉 vs 让感受） |
| **AI痕迹六层扫描** | 词/语/句/语义/指纹/行为六层定位，输出"主要来源层"；可对比个人风格档案 |
| **红蓝对抗审稿** | 聚合三大深度引擎，红队挑刺 × 蓝队辩护 × 裁定清单 |
| **平台规范实时核实** | 联网核实各大平台最新 AI 治理规范，数据溯源 + 过期告警 + --live 强制刷新 |
| **内容安全合规** | 前置内容安全过滤，涉政/涉黄/涉暴红线检测（脚本可执行） |

```

"润色这段"     → 优化表达
"提取我的风格" → 蒸馏风格

"轻小说"       → 日韩适配
"处理这段"     → 统一全流程（安全→质检→叙事→开篇→去味→合规→原创）
"专家会诊"     → 模拟专家团逐项质检
"追踪角色"     → 实体状态机（跨章一致性/时间线/伏笔/声线）
"情绪曲线"     → 段落情绪起伏 + 人味情感质量
"AI痕迹扫描"   → 六层定位（词/语/句/语义/指纹/行为）
"红蓝审稿"     → 红队挑刺 × 蓝队辩护 × 裁定
"核实最新平台规范" → 联网实时核实（溯源+告警）
```

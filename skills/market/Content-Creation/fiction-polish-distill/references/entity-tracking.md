# 实体状态机与角色/剧情追踪（模块 P）

> 版本 1.0.7 新增 · 对应脚本 `scripts/entity_tracking.py`

## 功能定位

把小说中的人物、物品、地点视为"实体"进行跨章节追踪，帮助作者把握整本书的角色状态、时间线与伏笔结构。全部为**本地启发式估算**（零外部依赖、不上传任何数据）。

## 能力清单

| 编号 | 能力 | 说明 |
|------|------|------|
| P-1 | 实体抽取与状态建模 | 自动识别高频人名/物名/地名，检测"死亡 / 昏迷 / 离开 / 登场 / 持物"等状态 |
| P-2 | 跨章节状态一致性 | 检出"死亡后复现、离开后回归"等状态矛盾，提示作者确认是否需显式交代 |
| P-3 | 时间线追踪 | 提取"次日 / 三天后 / 半年后"等时间推进，输出章节时间轴并提示时序回拨 |
| P-4 | 伏笔与回收 | 标记前文悬念埋点，追踪后文是否回收，列出未回收伏笔 |
| P-5 | 剧情线推进摘要 | 每章事件要点 + 活跃实体快照，便于全书速览 |
| P-6 | 角色声线档案 | 统计各角色对话的句长偏好、高频词、口头禅，辅助把握角色声线一致性 |

## 使用方式

```
python3 scripts/entity_tracking.py <书.md>            # 整本追踪报告
python3 scripts/entity_tracking.py <书.md> --json     # JSON 输出
python3 scripts/entity_tracking.py <书.md> --chapter 3  # 仅看第 3 章摘要
```

输入支持"第一章 / Chapter N"等章节标题自动切分；无标题时按整体处理。

## 输出要点

- **状态一致性冲突**：高优先级提示（死亡后复现等），需作者人工确认
- **时间线提示**：相对时间推进 + 疑似回拨位置
- **未回收伏笔清单**：建议后续章节安排回收
- **角色声线档案**：各角色均句长 / 高频词 / 口头禅

## 局限（诚实声明）

- 实体识别基于高频词启发式，可能漏识别或误识别（如生僻人名、少出现角色）
- 实体抽取与状态词表以中文为主；英文/日文/韩文文本的实体追踪能力有限（可能识别不到），建议中文正文使用本引擎
- 状态判定依赖上下文窗口，相邻句的状态词可能串扰
- 时间推进为相对估算，未处理倒叙/插叙等复杂结构
- 以上结果仅供作者自查参考，**不替代人工审读与平台判定**

# 红蓝对抗审稿室（模块 S）

> 版本 1.0.7 新增 · 对应脚本 `scripts/red_blue_review.py`

## 功能定位

聚合实体状态机（模块 P）、情绪曲线（模块 Q）、六层扫描（模块 R）的检测结果，用"红队挑刺 × 蓝队辩护 → 裁定"的结构化方式输出审稿报告。是三大深度引擎的**聚合审稿台**，全部为**本地启发式估算**（零外部依赖）。

## 能力清单

| 编号 | 能力 | 说明 |
|------|------|------|
| S-1 | 红队（挑刺） | 实体状态矛盾/时间线回拨（高优先级）；情绪平缓区/高 AI 痕迹层/语义重复（中低优先级） |
| S-2 | 蓝队（辩护） | 情绪峰值（爽点）、人味具象表达、伏笔已回收等亮点 |
| S-3 | 裁定 | 按严重度排序输出"优先修复"清单 + "建议保留"亮点 + 总体裁定结论 |
| S-4 | 诚实定位 | 所有判据来自本地启发式引擎，非真人评审，不替代平台判定 |

## 使用方式

```
python3 scripts/red_blue_review.py <书.md>             # 红蓝审稿报告
python3 scripts/red_blue_review.py <书.md> --json      # JSON 输出
python3 scripts/red_blue_review.py <书.md> --focus 问题 # 仅输出问题类
python3 scripts/red_blue_review.py <书.md> --focus 亮点 # 仅输出亮点类
```

## 输出要点

- **红队清单**：每项含严重度（高/中/低）、问题类型、问题描述、建议动作、来源引擎
- **蓝队清单**：每项含亮点类型、描述、保持建议
- **裁定**：是否需优先修复、是否可进入打磨阶段
- **摘要**：红队问题数 / 高优先级数 / 蓝队亮点数

## 局限（诚实声明）

- 红蓝判据全部来自本地启发式引擎，可能漏报/误报
- 裁定的"优先级"仅供作者参考，**不替代真人编辑与平台判定**
- 输入文本过短时，部分引擎检测不充分，报告仅供参考

# 小红书封面使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

用这张产品图和真实卖点，做一张适合小红书分享的种草封面。

English: Use this product image and its real features to design a Xiaohongshu recommendation cover.

English: Create a lifestyle cover for my weekend trip using these photos.

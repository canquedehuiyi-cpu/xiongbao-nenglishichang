# 领域模式：ai AI 工程

> 版本 1.1.0。覆盖 AI 工程类提示词：Agent 系统提示词、Skill 封装、MCP 声明、多智能体编排。

## 平台与场景

| 平台 | 场景 |
|---|---|
| agent | Agent 系统提示词（角色/工具/边界/输出） |
| skill-pack | Skill 技能包封装（SKILL.md + references + 数据） |
| mcp | MCP 服务声明与工具描述 |
| workflow | 多智能体编排、工作流提示词 |

## 常用模板

| 模板 | 场景 | 输出结构 |
|---|---|---|
| AGENT-SYSTEM | Agent 系统提示词 | 角色→目标→能力边界→工具使用→输出契约→安全 |
| SKILL-PACK | Skill 封装 | 能力定位→触发词→参数→输出模板→合规校验 |
| MCP-DECL | MCP 声明 | 服务→工具→参数 schema→权限边界 |

## 提示词构建要点

1. **能力定位清晰**：系统提示词先说清"我是谁、能做什么、不能做什么"。
2. **触发纪律**：Skill/Agent 的触发词明确，避免误触发。
3. **输出契约化**：定义结构化输出模板与字段，减少自由发挥。
4. **安全边界**：工具调用、外部输入隔离、敏感信息处理显式声明。
5. **合规**：涉及平台技能包（微信 AI 开发模式 / SkillHub）时，先核验官方规范再生成。

## 边界

- 不生成绕过平台审核或安全机制的内容。
- 微信 AI 开发模式当前内测、未开放提审，生成脚手架仅供开发调试。

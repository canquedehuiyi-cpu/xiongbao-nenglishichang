# 领域模式：ecommerce 电商

> 版本 1.1.0。覆盖电商类提示词：商品标题、详情页、直播脚本、客服话术。

## 常用模板

| 模板 | 场景 | 输出结构 |
|---|---|---|
| PRODUCT-TITLE | 商品标题 | 核心卖点→规格→场景→合规词 |
| DETAIL-PAGE | 详情页文案 | 痛点→卖点→证据→场景→下单理由 |
| LIVE-SCRIPT | 直播脚本 | 开场→产品→互动→逼单→下播 |
| CS-SCRIPT | 客服话术 | 场景→回应→安抚→方案→话术规范 |

## 提示词构建要点

1. **卖点分级**：核心卖点 1-3 个，避免全堆叠。
2. **证据支撑**：功能、材质、参数等表述须可验证，禁止虚假宣传。
3. **合规用词**：绝对化用语（最/第一/国家级）禁用。
4. **平台差异**：淘宝/京东/抖音/亚马逊对标题长度、违禁词规则不同，按平台适配。

## 边界

- 不生成虚假评价、刷单话术等违规内容。
- 价格、促销表述以平台规则为准。

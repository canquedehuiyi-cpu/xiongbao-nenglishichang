# 领域模式：game 游戏

> 版本 1.1.0。覆盖所有平台游戏/小游戏的提示词模式：开发、NPC、策划案、美术素材、上架物料。规范要点基于各平台官方规范与国家层统一合规（防沉迷/版号/实名/内容安全，2026-09-03 核验）。

## 平台与关键规范要点

| 平台 | 要点 |
|---|---|
| 微信小游戏 | IAA 广告占比 ≤50%、激励视频单用户每日 ≤3 次、禁第三方广告 SDK；适龄提示（默认 8+）；防沉迷（未成年人每日 ≤1 小时、22:00-8:00 禁玩）；上架需软著+备案+自审自查 |
| 抖音小游戏 | 广告/联运规范以官方文档为准（构建前用 verify-spec 核验） |
| Steam | 商店页物料、年龄分级、隐私政策为审核要点 |

## 常用模板

| 模板 | 场景 | 输出结构 |
|---|---|---|
| GAME-DEV | 游戏玩法开发 | 目标→核心循环→系统规则→边界→验收 |
| GAME-NPC | NPC/角色扮演 | 人设→说话风格→知识边界→记忆→禁止项 |
| GAME-DESIGN | 策划案 | 定位→玩法→数值→经济→留存→合规 |
| GAME-ASSET | 美术素材生成 | 风格→主体→构图→细节→负向约束 |
| GAME-STORE | 上架物料 | 名称→简介→截图文案→合规自查 |

## 提示词构建要点

1. **明确平台**：先确认目标平台（微信/抖音/Steam），平台决定合规约束与物料清单。
2. **合规前置**：广告/内购/适龄/防沉迷相关描述须符合平台规范；用 `wechat-minigame-check` 自检。
3. **角色差异化**：批量生成 NPC/角色时，要求脸型、衣装、性格差异化，明确负向约束（禁机械变体、多手多脚等瑕疵）。
4. **美术风格声明**：写实/2.5D/国潮等风格词须精确，避免歧义。
5. **验收可测**：每个功能/素材给出可验证的验收标准。

## 边界

- 不替平台做审核判断；合规要点以官方最新规范为准（先 verify-spec）。
- 变现设计仅在合法广告变现（IAA）范围内提供建议，不涉及内购引导。

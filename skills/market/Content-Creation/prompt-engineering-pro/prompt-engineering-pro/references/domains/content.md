# 领域模式：content 内容创作

> 版本 1.1.0。覆盖内容创作类提示词：小红书、公众号、短视频、SEO。

## 常用模板

| 模板 | 场景 | 输出结构 |
|---|---|---|
| XHS-NOTE | 小红书图文 | 标题→正文→标签→互动钩子 |
| WECHAT-ARTICLE | 公众号文章 | 标题→开篇→结构→金句→行动号召 |
| SHORT-VIDEO | 短视频 | 选题→前3秒→分镜→文案→转化 |
| SEO | 搜索优化 | 关键词→标题→正文→元信息 |

## 提示词构建要点

1. **平台语感**：各平台语言风格差异大（小红书种草/公众号深度/短视频口语化），先锁定平台。
2. **前 3 秒/首屏**：短视频前 3 秒、文章首屏决定留存，重点打磨。
3. **真实可信**：案例、数据、效果表述可验证，不夸大。
4. **互动设计**：钩子、提问、评论区引导等互动要素纳入结构。

## 边界

- 不生成标题党、虚假案例、诱导性违规内容。
- 平台流量规则以官方为准。

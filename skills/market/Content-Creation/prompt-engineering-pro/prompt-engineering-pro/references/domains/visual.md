# 领域模式：visual 视觉

> 版本 1.1.0。覆盖视觉生成类提示词：文生图、角色设计、3D 建模、UI 设计、视频脚本。

## 平台与场景

| 平台 | 场景 |
|---|---|
| image-gen | 文生图（海报、插画、商品图、社媒配图） |
| character-design | 角色原画/三视图/差异化变体 |
| 3d-model | 3D 建模描述、贴图、风格化 |
| ui-design | UI/图标设计（强调干净直观、去繁就简） |
| video | 视频分镜、脚本、运镜 |

## 常用模板

| 模板 | 场景 | 输出结构 |
|---|---|---|
| IMAGE-GEN | 文生图 | 主体→风格→构图→光线→细节→负向约束 |
| CHARACTER-DESIGN | 角色设计 | 人设→外形→衣装→三视图→差异化→负向约束 |
| UI-DESIGN | UI/图标 | 功能→布局→组件→风格→辨识度→可测性 |
| VIDEO-SCRIPT | 视频 | 目标→分镜→台词→运镜→节奏→交付 |

## 提示词构建要点

1. **风格先行**：首句锁定风格（写实/2.5D/新国潮/扁平），全篇不漂移。
2. **负向约束显式化**：禁止机械变体、多手多脚、文字乱码等瑕疵，写入"不要…"清单。
3. **量化细节**：构图（主体位置）、比例、色彩、光线尽量量化，减少歧义。
4. **差异化要求**：批量角色/图标生成时，明确要求脸型、衣装、配色差异化。
5. **验收可测**：给出可验证的产出标准（尺寸、比例、元素数量、风格一致性）。

## 边界

- 提示词仅描述内容与风格，不替代生成工具的模型能力声明。
- 涉及真实人物肖像时，遵守平台肖像与隐私规范。

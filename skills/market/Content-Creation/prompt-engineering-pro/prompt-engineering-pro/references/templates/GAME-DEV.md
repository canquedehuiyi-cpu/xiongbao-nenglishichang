# Template: GAME-DEV（游戏玩法开发）

> 用途：游戏玩法/功能开发类提示词。领域：game。选型信号：写游戏玩法规则、系统功能。
> 对应任务轴 A：代码与系统设计。

## 骨架

```
# 目标
{游戏/玩法一句话目标：类型、核心体验}

# 核心循环
{玩家反复执行的核心行为循环}

# 系统规则
{具体规则：数值、条件、交互、胜负}

# 边界
{明确不做的事、禁止的行为}

# 验收
{可验证的验收标准}
```

## 使用要点
- 核心循环写清"触发→动作→反馈→再触发"。
- 规则须无歧义（数值给范围或公式，不写"合理""适当"）。
- 边界段是 Safety/Compliance 维关键：明确禁止项。
- 验收可测：每个功能给可验证标准。

## 反例
- 需要创意发散 → BRAINSTORM
- 严格结构输出 → SCHEMA

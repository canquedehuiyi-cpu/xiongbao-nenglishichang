# Template: GAME-DESIGN（游戏策划案）

> 用途：游戏策划案、玩法设计文档。领域：game。选型信号：产出完整策划方案。
> 对应任务轴 A：分析与方案。

## 骨架

```
# 定位
{游戏类型、目标用户、核心卖点}

# 玩法
{核心玩法、系统、关卡结构}

# 数值
{经济、成长、平衡关键数值}

# 留存与体验
{新手引导、留存钩子、成瘾节奏}

# 合规
{平台规范自查：适龄/防沉迷/变现合规}
```

## 使用要点
- 定位一句话可验证（"面向 X 用户的 Y 类型游戏"）。
- 数值给推导依据，不拍脑袋。
- 合规段对接平台规范（微信小游戏：广告占比/激励频次/适龄/防沉迷）。
- 分优先级：MVP 先做什么、后续加什么。

## 反例
- 只写单个玩法 → GAME-DEV
- 需要创意脑暴 → BRAINSTORM

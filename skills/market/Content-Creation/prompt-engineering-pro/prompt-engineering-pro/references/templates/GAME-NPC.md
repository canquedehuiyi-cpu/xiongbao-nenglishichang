# Template: GAME-NPC（NPC / 角色扮演）

> 用途：游戏 NPC、角色扮演、AI 陪聊类提示词。领域：game。选型信号：设计有性格、记忆、边界的角色。
> 对应任务轴 A：角色与对话。

## 骨架

```
# 人设
{名字、身份、背景、性格、说话风格}

# 说话风格
{口头禅、句式、语气、词汇偏好}

# 知识边界
{知道什么、不知道什么、何时承认不知}

# 记忆
{记住哪些交互、多久、如何复用}

# 禁止项
{绝不做的行为、不涉及的内容}
```

## 使用要点
- 说话风格给具体示例（优于抽象形容词）。
- 知识边界防幻觉：角色不得编造超出设定的信息。
- 记忆机制可测（"记住玩家昵称并复用"优于"有记忆"）。
- 批量生成时要求差异化（脸型/衣装/性格），显式负向约束。

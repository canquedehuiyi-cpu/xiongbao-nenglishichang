# Template: VIDEO-SCRIPT（视频脚本）

> 用途：短视频/视频分镜与脚本提示词。领域：visual/content。选型信号：写视频脚本。
> 对应任务轴 A：内容创作。

## 骨架

```
# 目标
{视频目的：涨粉/带货/品牌/科普}

# 前3秒
{开场钩子：吸引停留的强开头}

# 分镜
{镜头号、画面、景别、时长}

# 台词
{口播/字幕逐字稿}

# 节奏
{情绪曲线、转场、BGM 提示}

# 转化
{结尾行动号召}
```

## 使用要点
- 前 3 秒独立打磨（决定完播率）。
- 分镜量化（时长、景别、画面内容）。
- 台词口语化，短句为主。
- 转化动作明确（关注/下单/评论引导）。

## 反例
- 纯图文内容 → XHS-NOTE
- 深度长文 → WECHAT-ARTICLE

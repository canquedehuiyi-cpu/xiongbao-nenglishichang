# Template: LIVE-SCRIPT（直播脚本）

> 用途：电商直播带货脚本。领域：ecommerce。选型信号：写直播话术。
> 对应任务轴 A：电商文案。

## 骨架

```
# 商品
{品类、卖点、价格、优惠}

# 开场
{留人钩子：前 30 秒}

# 产品讲解
{卖点 → 演示 → 证据 → 场景}

# 互动
{提问、抽奖、弹幕引导}

# 逼单
{限时/限量/赠品/对比}

# 下播
{行动号召 + 预告}
```

## 使用要点
- 开场钩子决定在线人数，重点打磨。
- 讲解给可演示动作（优于纯描述）。
- 逼单话术合规：不虚假承诺、不绝对化。
- 互动设计可执行（具体提问句）。

## 反例
- 详情页 → DETAIL-PAGE
- 客服话术 → CS-SCRIPT

# Template: GAME-ASSET（游戏美术素材生成）

> 用途：游戏美术素材（角色/场景/道具/图标）的文生图提示词。领域：game/visual。选型信号：生成游戏视觉素材。
> 对应任务轴 A：视觉生成。

## 骨架

```
# 风格
{美术风格：写实/2.5D/新国潮/Q版…，全局一致}

# 主体
{角色/场景/道具：身份、外形、动作}

# 构图
{主体位置、视角、景别、画面比例}

# 细节
{色彩、光线、材质、纹理、参考元素}

# 负向约束
{禁止：机械变体、多手多脚、文字乱码、比例失调}
```

## 使用要点
- 风格首句锁定，全篇不漂移。
- 批量生成要求差异化（脸型/衣装/配色），避免同模。
- 负向约束显式列出常见瑕疵。
- 与游戏世界观一致（写清所属项目/系列）。

## 反例
- 写 UI 逻辑 → UI-DESIGN
- 角色文案设定 → GAME-NPC

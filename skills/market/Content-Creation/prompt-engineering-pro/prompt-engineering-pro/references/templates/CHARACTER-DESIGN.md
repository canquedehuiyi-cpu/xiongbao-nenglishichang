# Template: CHARACTER-DESIGN（角色设计）

> 用途：角色原画/三视图/批量差异化设计。领域：visual。选型信号：设计一个或多个角色。
> 对应任务轴 A：视觉生成。

## 骨架

```
# 人设
{身份、性格、背景}

# 外形
{脸型、发型、体型、五官特征}

# 衣装
{服装款式、配色、配饰、风格}

# 视图
{三视图要求：正面/侧面/背面；表情集}

# 差异化
{批量时：脸型/衣装/配色差异化要求}

# 负向约束
{禁止：机械变体、多手多脚、五官扭曲}
```

## 使用要点
- 脸型/体型差异化显式声明（避免同模脸）。
- 衣装细节量化（款式+配色+材质）。
- 三视图明确要求（正面/侧面/背面）。
- 负向约束写入常见角色瑕疵。

## 反例
- 场景/道具 → IMAGE-GEN
- 角色文案设定 → GAME-NPC

# Template: IMAGE-GEN（文生图）

> 用途：通用文生图提示词（海报、插画、商品图、社媒配图）。领域：visual。选型信号：生成视觉图片。
> 对应任务轴 A：视觉生成。

## 骨架

```
# 主体
{核心对象：是什么、状态、关系}

# 风格
{风格：写实/扁平/国潮/3D…，一次锁定}

# 构图
{主体位置、视角、景别、比例}

# 光线与色彩
{光照方向、色调整体倾向}

# 细节
{材质、纹理、氛围、参考元素}

# 负向约束
{禁止：畸形、多手多脚、乱码、比例失调}
```

## 使用要点
- 主体一句话说清"什么 + 状态"，避免多主体打架。
- 风格词精确且一致，不混搭未声明风格。
- 构图量化（居中/三分/特写/远景）。
- 负向约束是 Detail 维关键。

## 反例
- 角色批量设计 → CHARACTER-DESIGN
- 需要文案配图流程 → 内容领域模板

# Template: MCP-DECL（MCP 服务声明）

> 用途：MCP 服务、工具声明描述。领域：ai。选型信号：写 MCP 工具/服务说明。
> 对应任务轴 A：接口与工具设计。

## 骨架

```
# 服务
{服务定位、能力范围}

# 工具
{工具清单：名称、功能一句话}

# 参数
{每个工具的参数 schema：类型、必填、说明}

# 返回
{输出结构：字段、类型、示例}

# 权限边界
{可访问的数据/资源、禁止操作}
```

## 使用要点
- 工具描述精炼（模型据此决定是否调用）。
- 参数 schema 完整：类型、必填、取值说明。
- 返回结构给示例，减少解析歧义。
- 权限边界显式，防越权调用。

## 反例
- Agent 行为 → AGENT-SYSTEM
- 完整技能包 → SKILL-PACK

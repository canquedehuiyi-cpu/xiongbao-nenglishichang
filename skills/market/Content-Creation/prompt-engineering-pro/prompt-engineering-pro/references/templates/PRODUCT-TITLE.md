# Template: PRODUCT-TITLE（商品标题）

> 用途：电商商品标题。领域：ecommerce。选型信号：写商品标题。
> 对应任务轴 A：电商文案。

## 骨架

```
# 商品信息
{品类、核心卖点、规格、人群}

# 标题结构
{核心卖点 + 规格 + 场景 + 合规词}

# 长度
{按平台限制：淘宝/京东/亚马逊字符上限}

# 合规
{禁用绝对化用语、违禁词}
```

## 使用要点
- 卖点 1-3 个分级，不堆叠。
- 关键规格（材质/尺寸/克重）显式。
- 按平台字数与关键词规则适配。
- 合规词自查（最/第一/国家级禁用）。

## 反例
- 详情页长文 → DETAIL-PAGE
- 直播话术 → LIVE-SCRIPT

# Template: CS-SCRIPT（客服话术）

> 用途：电商在线客服话术。领域：ecommerce。选型信号：写客服回复。
> 对应任务轴 A：客服与售后。

## 骨架

```
# 场景
{售前/催发货/退换货/质量问题/差评}

# 回应
{开场：共情 + 承接}

# 方案
{解决方案：步骤/时限/条件}

# 安抚
{情绪管理：道歉/补偿/解释}

# 话术规范
{禁用语、承诺边界、升级规则}
```

## 使用要点
- 先共情后解决，情绪优先。
- 方案给具体步骤与时限（可执行）。
- 承诺边界显式（不越权承诺退款额度）。
- 升级规则明确（何时转人工/主管）。

## 反例
- 直播脚本 → LIVE-SCRIPT
- 商品介绍 → DETAIL-PAGE

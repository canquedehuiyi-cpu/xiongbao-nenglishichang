# Template: WECHAT-ARTICLE（公众号文章）

> 用途：微信公众号长文。领域：content。选型信号：写公众号文章。
> 对应任务轴 A：内容创作。

## 骨架

```
# 主题
{文章主题、目标读者}

# 标题
{吸引点击 + 定位准确}

# 开篇
{前 2 段：钩子 + 承诺}

# 结构
{小标题分段：论点 → 论据 → 案例}

# 金句
{可记忆、可转发的句子}

# 行动号召
{关注/在看/转发/引导}
```

## 使用要点
- 标题避免标题党，承诺可兑现。
- 开篇 2 段决定留存，重点打磨。
- 结构用小标题分节，降低阅读负担。
- 案例与数据可验证，不编造。

## 反例
- 小红书短文 → XHS-NOTE
- 短视频 → VIDEO-SCRIPT

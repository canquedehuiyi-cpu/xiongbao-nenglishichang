# Template: SKILL-PACK（Skill 技能包封装）

> 用途：把能力封装成 Skill 技能包（SKILL.md + references）。领域：ai。选型信号：封装/创建 skill。
> 对应任务轴 A：技能包设计。

## 骨架

```
# 能力定位
{一句话：做什么、不做什么}

# 触发词
{什么请求触发、什么不触发}

# 参数定义
{输入参数、类型、必填/可选、默认值}

# 处理流程
{步骤、用到什么数据/工具}

# 输出模板
{结构化输出：字段、格式、示例}

# 合规校验
{输出前检查：安全、隐私、边界}
```

## 使用要点
- 能力定位先写"不做什么"，防误触发。
- 触发词具体，避免与宿主能力冲突。
- 参数定义完整（类型/必填/默认）。
- 输出模板含示例（Few-shot 效果更好）。
- 合规校验段防越权与敏感输出。

## 反例
- 单个 agent 角色 → AGENT-SYSTEM
- 平台技能包合规检查 → skill-pack-check

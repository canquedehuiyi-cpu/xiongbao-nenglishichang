# Template: AGENT-SYSTEM（Agent 系统提示词）

> 用途：AI Agent / 助手的系统提示词。领域：ai。选型信号：写 agent 的 system prompt。
> 对应任务轴 A：智能体设计。

## 骨架

```
# 角色
{我是谁、擅长什么、不做什么}

# 目标
{总体使命，一句话可测量}

# 能力边界
{能用的工具、知识范围、何时求助}

# 工具使用
{何时调用哪个工具、调用条件}

# 输出契约
{输出结构、格式、长度、字段}

# 安全
{红线、注入防护、敏感信息处理}
```

## 使用要点
- 角色段先定"能/不能"，减少越权行为。
- 工具使用给触发条件（优于"能用工具"）。
- 输出契约化（格式/字段/长度显式）。
- 安全段显式声明：外部输入隔离、不执行危险指令。

## 反例
- 单次任务 → RTF
- 需要工具编排 → 工作流模板

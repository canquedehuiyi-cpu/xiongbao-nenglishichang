# Template: UI-DESIGN（UI / 图标设计）

> 用途：界面、图标、组件的设计描述提示词。领域：visual。选型信号：设计 UI 或图标。
> 对应任务轴 A：视觉与界面设计。

## 骨架

```
# 功能
{该界面/图标承担的功能}

# 布局
{信息层级、区块、留白}

# 组件
{按钮、列表、状态、反馈样式}

# 风格
{风格：干净直观/现代/品牌色系}

# 辨识度
{关键操作的高辨识度要求}

# 可测性
{验收：尺寸、对比度、点击区域}
```

## 使用要点
- 功能优先：先想清楚用户要完成什么。
- 布局去繁就简，避免花哨装饰。
- 关键按钮辨识度显式要求（颜色/尺寸/对比）。
- 验收可测（组件尺寸、对比度 ≥4.5:1、点击区域 ≥44px）。

## 反例
- 生成插图/海报 → IMAGE-GEN
- 角色 → CHARACTER-DESIGN

# Template: DETAIL-PAGE（商品详情页）

> 用途：电商商品详情页文案。领域：ecommerce。选型信号：写详情页内容。
> 对应任务轴 A：电商文案。

## 骨架

```
# 商品
{品类、核心卖点、目标用户}

# 痛点
{用户痛点：场景化描述}

# 卖点
{卖点分级：核心 1-3 个 + 证据}

# 证据
{参数、材质、检测报告、使用效果}

# 场景
{使用场景：让用户代入}

# 下单理由
{行动号召 + 保障（售后/物流）}
```

## 使用要点
- 痛点场景化（"什么时刻"优于"很痛"）。
- 卖点给证据支撑，不虚假宣传。
- 详情按阅读动线组织（痛点→方案→证明→转化）。
- 合规：参数可验证，禁用绝对化用语。

## 反例
- 仅标题 → PRODUCT-TITLE
- 直播脚本 → LIVE-SCRIPT

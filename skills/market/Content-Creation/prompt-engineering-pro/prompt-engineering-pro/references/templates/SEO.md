# Template: SEO（搜索优化）

> 用途：SEO 内容与标题优化。领域：content。选型信号：优化搜索排名。
> 对应任务轴 A：内容与搜索优化。

## 骨架

```
# 关键词
{核心词 + 长尾词组合}

# 标题
{含关键词 + 吸引点击}

# 正文
{关键词自然分布：标题/首段/小标题/结尾}

# 元信息
{描述、结构、内部链接}

# 体验
{可读性、加载、移动端}
```

## 使用要点
- 关键词分层：1 个核心词 + 若干长尾词。
- 关键词自然分布，禁止堆砌（会被降权）。
- 标题兼顾关键词与点击率。
- 内容体验优先，不牺牲质量换词频。

## 反例
- 平台种草 → XHS-NOTE
- 视频 → VIDEO-SCRIPT

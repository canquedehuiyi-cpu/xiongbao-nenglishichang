## Qoder 宿主要求

安装本技能后先确认当前 Qoder 产品的实际工具能力。网页发布入口列出的 APP、IDE、CLI、Wake 和云端 Agent 不表示本包已在这些产品验收；不自行声明全部适配。

仅在宿主已经连接国内远程 MCP 并完成用户授权时调用对应工具。否则，当前产品确实允许 Node.js 18+、出站 HTTPS 和用户私有凭据时，才执行随包 API Key 入口。不要修改用户项目的规则文件、依赖或 MCP 配置来静默获得权限。

读取用户明确选定的本地图片或视频；云端附件必须使用宿主实际提供的可访问路径。任务受理后保留 taskId 和账号/区域；工具执行超时先查询原任务，不重新提交收费处理。

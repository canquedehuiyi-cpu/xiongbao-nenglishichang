# 小红书图文笔记公开能力说明

- 服务提供方：神火 AI；本技能不代表小红书官方。
- 固定设计师：小红书笔记，`des_bcb5653e7316` / `xiaohongshu_notes_designer`。
- 该文件仅描述公开服务边界，不含神火内部 Designer Skill 或提示词。

## 主推需求

- **生活分享**：把用户真实分享的文字、照片和资料整理成手机上好读的笔记图片，可用于旅行准备、穿搭、家居整理、餐饮做法和生活经验等。
- **知识干货**：按实际内容制作步骤、问答、清单、比较和图文说明，让每张图回答一个具体问题；真实先后才编号，同维度比较不编造优劣排名。
- **产品介绍**：根据真实产品或服务资料说明适合谁、提供什么、如何使用及必要条件。支持课程等服务介绍，不把笔记设计扩大成完整电商详情页。

可制作封面与连续内页，也可只做一张正文内页。只要内页不强制加封面或总结页，不靠重复内容凑图，不模拟小红书平台界面或手机展示框。

## 素材与事实

接收原始需求、文字、文档、照片及商品或服务资料。知识、步骤和比较类任务可用文字与插画完成，无照片也可开始；需要保持真实人物、地点或商品时，提供对应清楚原图。已有资料足够时直接提交神火服务，不要求先选择风格、布局或实拍/插画形式。

保留原始信息及用户明确要求，商品、人物和地点不被替换成其他主体。新增标题和说明与原图上的字样分清；看不清的参数不猜写成事实。参考模板中的价格、效果、经历或成绩不移作本次事实，插画不冒充实拍证据。

没有真实经历资料时写成说明或指南，不编造亲测、旅行经历、销量、功效、成绩或收益承诺。专业内容只整理有依据的资料和限制，不作个体诊断或决策。真正阻断目标的缺口由神火服务追问，研究判断和设计方法在服务端处理，不由 Qoder 重建完整流程。

## 规格与体验

默认 **1.5K / 3:4**，当前对应 1344×1792；创建请求显式传 `--resolution 1.5K --aspect-ratio 3:4`。同组保持冻结规格，清楚模块与适量文字优先。这是本设计师定位，不是小红书平台强制尺寸，不能套用其他专家的 auto 比例。

明确数量原样传 N，未指定保留 auto。沿用当前渠道积分及服务端数量校验，不另加试用张数限制，不静默减页；内容不足由设计师判断并沟通，不能编造经历或卖点填满指定页数。

## 结果与网站承接

交付真实成功并下载的平面图片，标注 AI 生成及实际完成数量，保留正文顺序。部分下载失败时先交付已保存图片，再按真实结果 ID 恢复未完成项，不因命令非零丢弃成功结果。用户自行按实际账号用途检查并发布；服务不自动发帖，不承诺平台推荐或经营结果，也不包含视频、平台界面复刻、印刷长册、精密截图复原、完整电商详情或可编辑源文件。

试用用户可注册神火后创建个人项目，当前体验项目不会自动迁入新账号；转网站时可带上需求摘要、原始素材和已下载结果。个人 Key 创建的项目已归属同一神火用户，用该账号打开回执实际 `project_id` 即可，无需重新注册或重建，具体入口见 [workflow.md](workflow.md)。网站承接项目管理、后续修改与完整服务，不因内部设计师存在修改方法而宣传客户端已提供修改或重生成命令。

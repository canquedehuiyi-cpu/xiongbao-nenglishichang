# 神火品牌视觉使用示例

以下为已确认的公开使用示例，用于理解本技能适合处理的任务。示例中的对象、数量、时间、价格或经历均不是用户本次事实，不能据此自动建项、上传、生成或消耗积分。用户明确选用后，按其真实资料与原始要求执行；没有指定数量时仍使用 auto。

## 示例 1

我想给自己的品牌做一个Logo，我会提供名字和业务介绍。

English: Create a logo for my brand using the name and business description I provide.

## 示例 2

帮我设计一款产品包装，我会提供品牌名、产品信息和包装类型。

English: Design product packaging using the brand name, product details and packaging type I provide.

## 示例 3

我有现成Logo，帮我做纸袋和杯套的外观效果图，分别出图。

English: Use my existing logo to create separate mockups for a paper bag and a cup sleeve.

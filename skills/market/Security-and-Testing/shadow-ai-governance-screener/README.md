# Shadow AI 治理可执行性初筛

版本：`0.2.4-qoder.1`

用六道非敏感问题，初步定位企业在 AI 工具供给、供应链透明度、费用激励、审批摩擦、工作负荷和治理反馈方面值得补证与联合核对的维度。

## 适用对象

适合 IT、安全、合规、AI 项目和业务负责人用于约 3 分钟的内部讨论前初筛。

## 使用方式

1. 在 QoderWork 中启用本 Skill。
2. 输入“开始”。
3. 依次回答 A/B/C/D；不知道时可选择 D。
4. 第六题后核对答案，输入“确认”生成结果。
5. 可输入“修改 Qn 为 X”重新计算。

## 输出内容

- 中性的初筛结论；
- C/D 项和 D 项数量；
- 六个维度的当前含义与最小补位动作；
- 最多三条优先行动；
- 内部联合核对建议与边界提醒。

本 Skill 不输出风险等级、成熟度评分、安全认证或合规结论。

## 权限与数据边界

本 Skill 只进行纯文本对话，不需要文件、网络、Shell、Hook、MCP、浏览器、子 Agent、邮箱、IM 或其他外部工具，不主动向第三方外发，也不额外写入长期记忆。

请勿输入公司名、员工身份、文件、日志、Prompt、代码、Cookie、Token、API Key、具体账号、网址或其他敏感信息。QoderWork 与所用模型可能有自己的传输、日志和留存规则，请按宿主平台隐私说明判断是否适合输入任何内容。

## 模型延展说明

完成初筛后，用户可继续让 Agent 围绕重点维度生成讨论提纲或核查草案。

该补充内容由宿主模型根据初筛框架生成，不等同于正式审计、认证或完整方法清单。

## 结果边界

结果基于自填信息且未经独立验证，不能证明企业没有 Shadow AI，不构成审计、认证、法律意见或员工违规认定，也不应用于员工处罚或绩效判断。

## 兼容性

已在 QoderWork CN 与 Qwen3.7-Max 下完成三组确定性测试，确认流程、修改答案、C/D 统计、D 项统计和关键触发均通过。为适配 QoderWork 展示，本包采用纯文本标题、编号与短段落，不依赖 Markdown 表格、粗体、颜色或图标。

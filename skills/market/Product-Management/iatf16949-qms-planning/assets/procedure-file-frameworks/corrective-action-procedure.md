# 纠正措施程序

**文件编号**: QP-006
**版本**: A/0
**生效日期**: [填写日期]

---

## 1. 目的

建立并保持纠正措施程序，消除不合格的原因，防止不合格再次发生，推动持续改进。

## 2. 适用范围

适用于公司质量管理体系运行中发现的各类不符合项的纠正措施管理。

## 3. 职责

| 部门/职位 | 职责 |
|-----------|------|
| 质量部 | 归口管理，跟踪验证 |
| 各责任部门 | 原因分析，制定措施 |
| 管理者代表 | 重大纠正措施审批 |

## 4. 定义

| 术语 | 定义 |
|------|------|
| 纠正 | 为消除已发现的不合格所采取的措施 |
| 纠正措施 | 为消除已发现不合格的原因所采取的措施 |
| 预防措施 | 为消除潜在不符合的原因所采取的措施 |
| 根本原因 | 导致问题发生的最基本原因 |

## 5. 工作程序

### 5.1 触发条件

| 来源 | 内容 |
|------|------|
| 内部审核 | 内审发现的不符合项 |
| 外部审核 | 顾客/认证审核发现 |
| 过程监控 | 过程异常、数据偏离 |
| 顾客反馈 | 投诉、退货、索赔 |
| 内部反馈 | 员工建议、改进提案 |
| 数据分析 | 不合格趋势分析 |

### 5.2 问题描述（5W2H）

**问题描述要素**:
| 要素 | 说明 | 示例 |
|------|------|------|
| What（什么） | 具体问题 | 来料外观不良 |
| Where（哪里） | 发生地点 | 原材料仓库 |
| When（何时） | 发生时间 | 2024.01.15 |
| Who（谁） | 发现人 | 检验员张三 |
| Why（为什么） | 发现原因 | IQC抽检发现 |
| How（多少） | 发生数量 | 3件/100件 |
| How（如何） | 如何发现 | 抽样检验 |

### 5.3 原因分析方法

**常用分析方法**:

| 方法 | 适用场景 |
|------|---------|
| 5 Why分析 | 简单问题的根本原因追溯 |
| 鱼骨图 | 多因素问题的系统分析 |
| 帕累托图 | 识别主要问题/原因 |
| FMEA | 产品/过程风险分析 |

**5 Why分析示例**:
```
问题：产品尺寸超差

Why1：为什么尺寸超差？
    → 模具磨损

Why2：为什么模具磨损？
    → 模具使用次数超限

Why3：为什么超限未发现？
    → 未按计划点检

Why4：为什么未按计划点检？
    → 点检表未及时更新

Why5：为什么未更新点检表？
    → 无点检表更新流程

根本原因：缺少模具点检表更新管理流程
```

### 5.4 纠正措施制定

**措施制定原则**:
| 原则 | 说明 |
|------|------|
| 针对原因 | 措施必须消除根本原因 |
| 可执行 | 措施在现有条件下可执行 |
| 可验证 | 有明确的验证方法和标准 |
| 经济性 | 考虑成本效益平衡 |

**措施有效性评价**:
| 评价维度 | 评价标准 |
|---------|---------|
| 有效性 | 能否消除根本原因 |
| 可行性 | 能否在期限内实施 |
| 充分性 | 能否防止同类问题再次发生 |
| 副作用 | 是否可能引发其他问题 |

### 5.5 纠正措施实施

**实施流程**:
```
原因分析完成 → 措施评审批准 → 措施实施 → 效果验证 → 关闭
```

**实施跟踪**:
| 阶段 | 内容 | 时间要求 |
|------|------|---------|
| 制定 | 完成原因分析、制定措施 | 7天内 |
| 审批 | 审核批准措施方案 | 3天内 |
| 实施 | 按计划执行措施 | 按计划 |
| 验证 | 验证措施有效性 | 实施后1个月 |

### 5.6 效果验证

**验证方法**:
| 方法 | 说明 |
|------|------|
| 数据验证 | 收集措施实施后的数据 |
| 对比分析 | 与措施实施前对比 |
| 运行观察 | 观察过程运行情况 |
| 周期评审 | 在一定周期内持续监视 |

**验证判定**:
| 结果 | 判定标准 |
|------|---------|
| 有效 | 根本原因已消除，问题不再发生 |
| 部分有效 | 有所改善但未完全消除 |
| 无效 | 问题仍然存在 |

**无效措施处理**:
- 重新分析原因
- 制定新的措施
- 或升级处理

### 5.7 文档管理

**记录内容**:
| 内容 | 要求 |
|------|------|
| 问题描述 | 完整的5W2H描述 |
| 原因分析 | 分析过程和结论 |
| 采取措施 | 具体的行动和负责人 |
| 实施记录 | 执行过程和日期 |
| 验证结果 | 验证数据和结论 |
| 评估结论 | 有效性判定 |

### 5.8 纠正措施分级管理

| 级别 | 定义 | 处理要求 |
|------|------|---------|
| 一级 | 严重质量事故/体系重大不符合 | 24h内启动，14天关闭 |
| 二级 | 一般不符合/重复发生的问题 | 7天内启动，30天关闭 |
| 三级 | 轻微问题/潜在问题 | 15天内启动，45天关闭 |

| 按时完成率 | 绩效评价 |
| 有效率 | 改进效果评价 |
| 问题分布 | 重点关注领域 |

# 文件控制程序

**文件编号**: QP-001
**版本**: A/0
**生效日期**: [填写日期]

---

## 1. 目的

建立并保持文件控制程序，确保质量管理体系所需的文件得到有效管理，保证文件的适用性、充分性和有效性。

## 2. 适用范围

适用于公司质量管理体系所有文件（包括外来文件）的控制。

## 3. 职责

| 部门/职位 | 职责 |
|-----------|------|
| 质量部 | 归口管理，负责文件总体控制 |
| 各部门 | 负责本部门文件的编制、修改 |
| 管理者代表 | 批准质量手册、程序文件 |

## 4. 工作程序

### 4.1 文件分类

| 文件类别 | 说明 | 审批权限 |
|---------|------|---------|
| 质量手册 | 体系顶层文件 | 总经理 |
| 程序文件 | 体系中层文件 | 管理者代表 |
| 作业指导书 | 操作层文件 | 部门负责人 |
| 外来文件 | 顾客/标准/法规文件 | 归口部门 |

### 4.2 文件编号规则

```
文件类型-序号
示例：QP-001（程序文件第1号）
      WI-001（作业指导书第1号）
      QR-001（质量记录第1号）
```

### 4.3 文件编制

1. 文件编制申请
2. 部门负责人审核
3. 归口部门会签
4. 相应权限人员批准
5. 文件发布

### 4.4 文件发放

| 步骤 | 要求 |
|------|------|
| 发放登记 | 记录发放部门、数量、日期 |
| 受控标识 | 盖"受控文件"章 |
| 版本标识 | 标注版本号（A/B/C...） |
| 回收旧版 | 及时回收并销毁 |

### 4.5 文件更改

1. 更改申请（说明更改原因）
2. 原审批人审批
3. 更改实施
4. 更新修订记录
5. 重新发放

### 4.6 文件保管

| 要求 | 内容 |
|------|------|
| 保管环境 | 干燥、整洁、便于检索 |
| 保存期限 | 不少于使用寿命周期+1年 |
| 借阅管理 | 登记借阅记录 |
| 过期处理 | 及时销毁受控副本 |

## 5. 相关文件

- QR-001 文件发放回收记录
- QR-002 文件更改申请单

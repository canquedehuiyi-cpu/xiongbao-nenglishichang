# 管理评审程序

**文件编号**: QP-004
**版本**: A/0
**生效日期**: [填写日期]

---

## 1. 目的

建立并保持管理评审程序，确保质量管理体系持续的适宜性、充分性和有效性，为体系改进提供依据。

## 2. 适用范围

适用于公司质量管理体系管理评审活动的管理。

## 3. 职责

| 部门/职位 | 职责 |
|-----------|------|
| 总经理 | 主持管理评审，批准评审输出 |
| 管理者代表 | 策划管理评审，准备评审输入 |
| 质量部 | 组织管理评审，跟踪决议执行 |
| 各部门 | 提供评审输入，执行评审决议 |

## 4. 工作程序

### 4.1 管理评审频次

| 类型 | 频次 | 说明 |
|------|------|------|
| 例行管理评审 | 每年至少1次 | 一般在年底或年初 |
| 追加管理评审 | 按需 | 重大变化或问题时召开 |

**追加管理评审触发条件**:
- 重大组织变化（组织架构、体系范围）
- 重大市场变化（顾客要求、法规要求）
- 重大质量事故
- 认证/监督审核后

### 4.2 评审输入准备

**评审输入内容**:

| 输入项目 | 具体内容 | 提供部门 | 准备时限 |
|---------|---------|---------|---------|
| 审核结果 | 内审、外审不符合项及趋势 | 质量部 | 会前10天 |
| 顾客反馈 | 满意度、投诉、退货数据 | 质量部/销售部 | 会前10天 |
| 过程绩效 | 各过程KPI达成情况 | 各部门 | 会前7天 |
| 产品符合性 | 合格率、不合格品数据 | 质量部 | 会前7天 |
| 改进措施 | 上次评审跟踪情况 | 质量部 | 会前7天 |
| 资源需求 | 人力、设备、技术需求 | 各部门 | 会前7天 |
| 风险机遇 | 体系风险评估结果 | 质量部 | 会前7天 |
| 法规符合性 | 适用法规符合性情况 | 质量部 | 会前7天 |

**评审输入准备流程**:
```
质量部发通知 → 各部门准备材料 → 质量部汇总 → 管理者代表审核 → 提前发放
```

### 4.3 评审会议

**会议准备**:
| 项目 | 要求 |
|------|------|
| 会议通知 | 提前1周发出 |
| 会议资料 | 提前3天发放 |
| 与会人员 | 高层管理者、部门负责人 |
| 会议时间 | 半天至1天 |

**会议议程**:

| 时间 | 内容 | 主持人 |
|------|------|--------|
| 09:00-09:15 | 会议开始、领导讲话 | 总经理 |
| 09:15-10:00 | 审核结果汇报 | 质量部 |
| 10:00-10:45 | 顾客反馈与满意度 | 销售部 |
| 10:45-11:00 | 茶歇 | - |
| 11:00-11:45 | 过程绩效与产品符合性 | 各部门 |
| 11:45-12:15 | 改进跟踪与资源需求 | 质量部 |
| 12:15-12:30 | 讨论与决议 | 总经理 |

**评审内容**:
1. 体系方针目标适宜性
2. 过程绩效达成情况
3. 顾客满意度状况
4. 不符合项趋势分析
5. 资源充分性评价
6. 改进机会与风险
7. 体系变更需求

### 4.4 评审输出

**评审输出内容**:
| 输出项目 | 具体内容 |
|---------|---------|
| 改进决定 | 体系、过程、产品改进决策 |
| 资源需求 | 人力资源、设备设施、技术等配置决定 |
| 体系变更 | 方针、目标、过程、文件等变更需求 |

**评审决议示例**:
```
决议1: [具体决策内容] - 责任人：[XXX] - 完成期限：[日期]
决议2: [具体决策内容] - 责任人：[XXX] - 完成期限：[日期]
决议3: [具体决策内容] - 责任人：[XXX] - 完成期限：[日期]
```

### 4.5 评审记录

**评审记录内容**:
```
1. 会议基本信息
   - 时间、地点、主持人、记录人
   - 与会人员名单
   
2. 评审输入汇报摘要
   - 各部门汇报要点
   
3. 讨论内容
   - 主要讨论事项及结论
   
4. 评审决议
   - 改进决定
   - 资源需求
   - 体系变更
   
5. 跟踪要求
   - 决议执行跟踪安排
```

### 4.6 决议执行跟踪

| 阶段 | 要求 |
|------|------|
| 分解下达 | 评审后1周内，质量部分解决议任务 |
| 执行监控 | 责任部门执行，质量部跟踪进度 |
| 中期报告 | 执行中期报告进展 |
| 结果验证 | 期限到达时验证完成情况 |
| 下次评审 | 作为下次评审输入报告 |

# 记录控制程序

**文件编号**: QP-002
**版本**: A/0
**生效日期**: [填写日期]

---

## 1. 目的

建立并保持记录控制程序，确保记录得到有效管理，为产品符合要求和质量管理体系有效运行提供证据。

## 2. 适用范围

适用于公司质量管理体系所有记录的控制。

## 3. 职责

| 部门/职位 | 职责 |
|-----------|------|
| 质量部 | 归口管理，负责记录清单维护 |
| 各部门 | 负责本部门记录的填写、收集、移交 |
| 档案室 | 负责记录的归档保存 |

## 4. 工作程序

### 4.1 记录识别

**记录类别**:

| 类别 | 示例 | 特点 |
|------|------|------|
| 管理记录 | 管理评审、培训记录 | 保存期较长 |
| 操作记录 | 检验记录、过程参数 | 保存期中等 |
| 监测记录 | 设备点检、监控记录 | 保存期较短 |

### 4.2 记录填写要求

| 要求 | 说明 |
|------|------|
| 真实性 | 如实记录，不得伪造 |
| 及时性 | 及时填写，不后补 |
| 完整性 | 填写完整，不得空项 |
| 可追溯性 | 签名、日期、编号完整 |
| 清晰性 | 字迹清晰，易于辨认 |

### 4.3 记录标识

```
记录编号-版本
示例：QR-001-A
```

**标识方式**:
- 表格名称
- 记录编号
- 版本号
- 保存期限

### 4.4 记录收集整理

| 步骤 | 要求 |
|------|------|
| 定期收集 | 按规定的周期收集 |
| 分类整理 | 按类别/时间/批次分类 |
| 编目登记 | 建立索引便于检索 |
| 移交归档 | 按时移交档案室 |

### 4.5 记录保存

| 要求 | 说明 |
|------|------|
| 保存环境 | 干燥、防潮、防虫、防火 |
| 保存方式 | 纸质或电子（需备份） |
| 保存期限 | 不少于规定期限 |
| 保密要求 | 按信息保密等级管理 |

### 4.6 记录查阅借阅

| 要求 | 说明 |
|------|------|
| 内部查阅 | 登记查阅目的 |
| 外部查阅 | 经审批后提供 |
| 借阅期限 | 一般不超过7天 |

### 4.7 记录销毁

| 步骤 | 要求 |
|------|------|
| 鉴别确认 | 确认超过保存期限 |
| 审批 | 填写销毁申请 |
| 审批权限 | 部门负责人以上 |
| 销毁执行 | 粉碎/删除，并记录 |

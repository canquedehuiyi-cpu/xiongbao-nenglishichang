# 内部审核程序

**文件编号**: QP-003
**版本**: A/0
**生效日期**: [填写日期]

---

## 1. 目的

建立并保持内部审核程序，验证质量管理体系的符合性和有效性，为体系改进提供依据。

## 2. 适用范围

适用于公司质量管理体系内部审核的管理。

## 3. 职责

| 部门/职位 | 职责 |
|-----------|------|
| 质量部 | 审核方案管理，组织审核 |
| 审核组 | 执行审核任务 |
| 各部门 | 配合审核，整改不符合项 |
| 管理者代表 | 批准审核计划、报告 |

## 4. 工作程序

### 4.1 审核方案策划

**审核方案内容**:
- 审核范围和目标
- 审核准则
- 审核频次
- 审核方法
- 审核资源配置

**年度审核计划**:

| 审核类型 | 审核范围 | 计划时间 | 审核天数 |
|---------|---------|---------|---------|
| 体系审核 | 全部范围 | [月份] | X天 |
| 过程审核 | 关键过程 | [月份] | X天 |
| 产品审核 | 重点产品 | [月份] | X天 |

### 4.2 审核准备

**审核组组建**:
1. 确定审核组长
2. 选择审核员（与被审核部门无直接责任）
3. 明确审核分工

**审核准备**:
| 步骤 | 内容 |
|------|------|
| 文件审查 | 收集审核范围内文件 |
| 编制检查表 | 基于标准条款和过程特点 |
| 审核通知 | 提前3-5天通知被审核部门 |

### 4.3 审核实施

**首次会议**:
| 内容 | 要求 |
|------|------|
| 参加会议人员 | 审核组、被审核部门负责人 |
| 主要内容 | 审核目的、范围、方法、时间安排 |
| 会议时间 | 15-30分钟 |

**现场审核**:
| 要求 | 说明 |
|------|------|
| 抽样方法 | 随机抽样、代表性 |
| 证据收集 | 记录、照片、实物 |
| 审核发现 | 记录具体事实 |
| 沟通反馈 | 及时与受审核方沟通 |

**末次会议**:
| 内容 | 要求 |
|------|------|
| 参加会议人员 | 审核组、被审核部门负责人、管理层 |
| 主要内容 | 审核发现、不符合项报告、结论 |
| 会议时间 | 30-60分钟 |

### 4.4 审核报告

**审核报告内容**:
```
1. 审核基本信息
   - 审核编号、日期、范围
   - 审核组、受审核方
   
2. 审核准则
   - 审核依据（标准/文件）
   
3. 审核发现
   - 不符合项清单（含描述、条款、严重程度）
   - 观察项清单
   
4. 审核结论
   - 体系符合性评价
   - 体系有效性评价
   
5. 后续要求
   - 纠正措施提交期限
   - 验证安排
```

**审核报告发放**:
| 发放对象 | 时间要求 |
|---------|---------|
| 管理者代表 | 审核结束后3天内 |
| 受审核部门 | 审核结束后3天内 |
| 相关部门 | 根据需要 |

### 4.5 纠正措施

**整改流程**:
```
不符合项报告发放 → 原因分析 → 纠正措施制定 → 审核员评审 → 
实施纠正措施 → 验证有效性 → 关闭不符合项
```

**整改期限**:
| 不符合类型 | 提交期限 | 完成期限 |
|-----------|---------|---------|
| 严重不符合 | 24小时内 | 14天内 |
| 轻微不符合 | 7天内 | 30天内 |

### 4.6 审核记录归档

| 记录类型 | 保存期限 | 责任人 |
|---------|---------|--------|
| 审核计划 | 3年 | 质量部 |
| 检查表 | 3年 | 审核组长 |
| 审核报告 | 3年 | 质量部 |
| 不符合项报告 | 3年 | 质量部 |
| 纠正措施记录 | 3年 | 质量部 |

## Define(定义)阶段

### 核心目标
明确项目范围、定义问题、建立项目章程

### 主要工具

#### 1. 项目章程(Charter)
**用途**:正式授权项目启动，明确项目基本要素

**关键要素**:
```
- 问题陈述(Problem Statement)
- 目标陈述(Goal Statement)
- 项目范围(Scope)
- 团队组成(Team)
- 里程碑计划(Milestones)
- 资源承诺(Resources)
- 成功标准(Success Criteria)
```

**输出模板**:
```markdown
问题陈述:
在[条件]下，[主体]经历[问题]，导致[影响]。

目标陈述:
在[时间]内，将[指标]从[当前值]改进至[目标值]。

项目范围:
- 纳入:[范围定义]
- 排除:[边界说明]
```

#### 2. SIPOC图
**用途**:从全局视角理解过程，识别关键输入和输出

**绘制步骤**:
1. 确定过程范围(Start-End)
2. 识别关键过程步骤(5-7步)
3. 识别输出及客户
4. 识别输入及供应商
5. 验证完整性

**SIPOC示例**:
```
供应商  →  输入      →   过程      →   输出    →  客户
─────────────────────────────────────────────────────────
物料科   →  原材料    →  ┌─────┐    →  电机    → 客户A
         →  规格书    →  │装配 │    →  成品    → 客户B
质量部   →  检验标准  →  │焊接 │    →  检验    → 包装
         →           →  │测试 │    →  报告    → 仓库
         →           →  └─────┘    →          → 售后
```

#### 3. CTQ树(Critical to Quality Tree)
**用途**:将客户需求转化为可测量的关键质量特性

**分解逻辑**:
```
客户需求(抽象)
    │
    ├── CTQ1(可测量)
    │   ├── 子指标1.1
    │   └── 子指标1.2
    │
    ├── CTQ2(可测量)
    │   └── ...
    │
    └── CTQ3(可测量)
```

#### 4. VOC收集方法
| 方法 | 适用场景 | 样本量 | 成本 |
|------|----------|--------|------|
| 问卷调查 | 批量收集 | >100 | 中 |
| 深度访谈 | 理解需求 | 10-20 | 高 |
| 焦点小组 | 探索性问题 | 6-10 | 中 |
| 投诉分析 | 已知问题 | 全部 | 低 |
| 神秘顾客 | 服务体验 | 5-10 | 中 |

## Measure(测量)阶段

### 核心目标
收集数据、建立基线、量化当前过程能力

### 主要工具

#### 1. 测量系统分析(MSA)
**用途**:验证测量系统的重复性和再现性

**评估指标**:
| 指标 | 可接受标准 | 说明 |
|------|------------|------|
| %GRR | <10% | 优秀 |
| | 10-30% | 可接受(依场景) |
| | >30% | 不可接受 |
| NDC | >=5 | 区分等级数 |

**操作步骤**:
1. 选择测量人员(2-3人)
2. 选择代表性样本(10个)
3. 每人重复测量2-3次
4. 盲测记录
5. 分析%GRR和NDC

#### 2. 数据收集计划
**5W1H法则**:
```
Who:  谁收集数据?
What: 收集什么数据?
When: 何时收集?频率?
Where:在哪里收集?
Why:  收集目的?
How:  如何收集?用什么工具?
```

**数据收集表模板**:
| 序号 | 时间 | 工位 | 操作员 | 测量值 | 备注 |
|------|------|------|--------|--------|------|
| 1 | | | | | |

#### 3. 过程能力分析
**关键指标**:

| 指标 | 公式 | 说明 | 标准值 |
|------|------|------|--------|
| Cp | (USL-LSL)/6σ | 潜在能力 | >1.33 |
| Cpk | Min[(USL-μ)/(3σ),(μ-LSL)/(3σ)] | 实际能力 | >1.33 |
| Pp | (USL-LSL)/6s | 整体性能 | >1.33 |
| Ppk | Min[(USL-x̄)/(3s),(x̄-LSL)/(3s)] | 整体性能指数 | >1.33 |

**判断标准**:
```
Cpk < 1.0: 能力不足，需立即改善
Cpk 1.0-1.33: 能力勉强，需改进
Cpk 1.33-1.67: 能力充足，可接受
Cpk > 1.67: 能力优秀
```

#### 4. 流程图(Flow Chart)
**类型选择**:
| 类型 | 特点 | 适用场景 |
|------|------|----------|
| 宏观流程图 | 概览，5-8步 | 项目启动、汇报 |
| 详细流程图 | 具体步骤，含判断 | 根因分析 |
| 泳道图 | 显示部门/角色 | 职责划分 |
| 价值流图 | 含时间/信息流 | 精益改善 |

#### 5. 直方图与箱线图
**直方图解读**:
- 形态:正态/偏态/双峰
- 位置:与规格限的关系
- 散布:宽度是否满足要求

**箱线图应用**:
- 比较:不同班组/设备/批次
- 异常:识别离群点
- 分布:对称性与偏态

## Analyze(分析)阶段

### 核心目标
识别根本原因，确定关键少数因素

### 主要工具

#### 1. 鱼骨图(因果图)
**绘制方法**:
```
                    问题
                       │
    ┌─────────────────┼─────────────────┐
    │                 │                 │
  人          机/设备         方法
    │                 │                 │
  料          环/环境         测量
```

**注意事项**:
- 从问题出发逐层展开
- 每个分支至少3层
- 避免模糊原因
- 团队协作完成

#### 2. FMEA(Failure Mode and Effects Analysis)
**RPN计算**:
```
RPN = 严重度(S) × 频度(O) × 探测度(D)

S: Severity(1-10) 后果严重性
O: Occurrence(1-10) 发生频率
D: Detection(1-10) 发现难度
```

**评分标准**:
| 评分 | 严重度 | 频度 | 探测度 |
|------|--------|------|--------|
| 10 | 无预警的严重危害 | 高频发生 | 几乎无法探测 |
| 1 | 无明显影响 | 几乎不发生 | 容易探测 |

**RPN处理优先级**:
```
高优先级: RPN > 100 或 S > 8
中优先级: 50 < RPN ≤ 100
低优先级: RPN ≤ 50
```

#### 3. 假设检验
**选择指南**:
| 数据类型 | 比较组数 | 正态性 | 推荐方法 |
|----------|----------|--------|----------|
| 连续 | 2组 | 正态 | t检验 |
| 连续 | >2组 | 正态 | ANOVA |
| 连续 | 任意 | 非正态 | Mann-Whitney/Kruskal-Wallis |
| 离散 | 2组 | - | 卡方检验 |
| 离散 | >2组 | - | 卡方检验 |

**常用检验**:
```markdown
1. 单样本t检验
   检验样本均值是否等于目标值

2. 独立样本t检验
   比较两组独立数据的均值差异

3. 配对t检验
   比较同一对象前后的变化

4. 单因素ANOVA
   比较三组及以上数据的均值差异

5. 卡方检验
   比较分类数据的分布差异
```

#### 4. 相关分析与回归
**相关分析**:
```markdown
Pearson相关系数(r): 衡量线性关系强度
- r = 0: 无相关
- |r| < 0.3: 弱相关
- 0.3 ≤ |r| < 0.7: 中等相关
- |r| ≥ 0.7: 强相关
```

**回归分析**:
```markdown
简单线性回归: Y = β₀ + β₁X + ε
多元回归: Y = β₀ + β₁X₁ + β₂X₂ + ... + ε

回归方程解读:
- β₁: X每增加1单位，Y平均变化β₁
- R²: 模型解释力(0-1)
```

#### 5. DOE(试验设计)基础
**筛选策略**:
| 设计类型 | 因子数 | 运行次数 | 适用场景 |
|----------|--------|----------|----------|
| 全因子 | ≤4 | 2^k | 全面分析 |
| 部分因子 | 5-7 | 2^(k-1) | 筛选关键因子 |
| 田口 | 任意 | 常用L18 | 稳健设计 |

**关键概念**:
```markdown
因子(Factor): 研究的输入变量
水平(Level): 因子的取值
主效应: 单个因子对输出的影响
交互作用: 两因子联合作用
```

## Improve(改进)阶段

### 核心目标
设计、实施并验证解决方案

### 主要工具

#### 1. 方案筛选矩阵
**评价维度**:
| 评价维度 | 权重 | 方案A | 方案B | 方案C |
|----------|------|-------|-------|-------|
| 效果 | 30% | | | |
| 成本 | 25% | | | |
| 实施难度 | 20% | | | |
| 时间 | 15% | | | |
| 风险 | 10% | | | |
| **加权总分** | 100% | | | |

**评分标准**:1-5分，5分最优

#### 2. 改善方案设计
**常用改善方法**:
```markdown
1. 消除(Eliminate): 移除不必要步骤
2. 合并(Combine): 合并同类操作
3. 重排(Rearrange): 优化顺序
4. 简化(Simplify): 简化操作方法
5. 自动化(Automate): 减少人工干预
```

#### 3. 试点与验证
**验证步骤**:
```markdown
1. 小规模试点(1-2个点)
2. 制定验证标准
3. 收集短期数据(20+样本)
4. 统计分析改善效果
5. 评估风险与收益
6. 决策推广
```

#### 4. 改善效果评估
**评估指标**:
| 指标类型 | 指标 | 计算方法 |
|----------|------|----------|
| 改善幅度 | 改进率 | (改善前-改善后)/改善前 |
| 统计显著性 | p值 | <0.05为显著 |
| 实际意义 | 效果量 | Cohen's d等 |

## Control(控制)阶段

### 核心目标
维持改善成果，建立长效机制

### 主要工具

#### 1. 控制图(Control Chart)
**选择指南**:
| 数据类型 | 子组大小 | 推荐控制图 |
|----------|----------|------------|
| 连续数据 | n>1 | X̄-R图、X̄-S图 |
| 连续数据 | n=1 | I-MR图 |
| 离散数据 | n>1 | np图、p图 |
| 离散数据 | n=1 | c图、u图 |

**判异规则**:
```markdown
规则1: 任何点超出控制限
规则2: 连续9点在中心线同一侧
规则3: 连续6点递增或递减
规则4: 连续14点交替上下
规则5: 2/3点落在警戒区内(1σ-2σ)
规则6: 4/5点落在警戒区外(1σ以外)
规则7: 连续15点在1σ以内
规则8: 连续8点落在1σ以外
```

#### 2. 控制计划(Control Plan)
**模板结构**:
```markdown
控制计划
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
过程名称:_______________    文件编号:_______________
过程负责人:_______________  版本日期:_______________

| 步骤 | 控制点 | 测量方法 | 规格限 | 失控反应 |
|------|--------|----------|--------|----------|
|      |        |          |        |          |
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

#### 3. 标准化作业(SOP)
**SOP要素**:
```markdown
1. 目的与范围
2. 所需工具与材料
3. 安全注意事项
4. 操作步骤(带图示)
5. 质量检查点
6. 异常处理流程
7. 相关记录表格
```

#### 4. 培训与认证
**培训计划**:
| 培训内容 | 对象 | 方式 | 时长 | 认证标准 |
|----------|------|------|------|----------|
| 新操作流程 | 操作员 | 实操 | 2h | 独立操作 |
| SPC监控 | 班组长 | 理论+实操 | 4h | 图表解读 |
| 异常处理 | 全员 | 案例 | 1h | 应急演练 |

#### 5. 项目总结与移交
**移交清单**:
```markdown
1. 基线数据与改善数据
2. 标准化文件(SOP、控制计划)
3. 控制图模板与警戒值
4. 异常处理流程
5. 维护责任矩阵
6. 项目总结报告
```

## 工具选择指南

### 按问题类型选择

| 问题类型 | 推荐工具组合 |
|----------|--------------|
| 新项目启动 | Charter + SIPOC + VOC |
| 数据不足 | MSA + 抽样计划 |
| 过程不稳定 | 控制图 + 过程能力 |
| 缺陷问题 | FMEA + 帕累托 + 鱼骨图 |
| 多因素影响 | DOE + 回归分析 |
| 周期过长 | 价值流图 + 改善5方法 |
| 测量不准 | MSA + 重复性分析 |

### 按阶段工具汇总

```markdown
Define:  Charter | SIPOC | CTQ树 | VOC收集 | 项目章程
Measure: MSA | 数据收集表 | 流程图 | 直方图 | 能力分析
Analyze: 鱼骨图 | FMEA | 假设检验 | 相关/回归 | DOE
Improve: 方案筛选 | 试点验证 | 效果评估 | 田口/响应面
Control: 控制图 | 控制计划 | SOP | 培训计划 | 项目移交
```

### 常用工具优先级

**基础必备**:
1. SIPOC图
2. 流程图
3. 鱼骨图
4. 控制图
5. 过程能力分析

**进阶提升**:
1. DOE试验设计
2. FMEA分析
3. 假设检验
4. 回归分析

**高级应用**:
1. 田口方法
2. 响应曲面
3. 多元统计
4. 仿真建模

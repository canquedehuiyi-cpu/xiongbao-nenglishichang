## 各章节格式要求

### 1. 项目概述

#### 1.1 项目名称格式
```
[业务领域]-[改进对象]-[项目类型]-项目

示例:
- 电机装配-换型时间-缩短改善-项目
- 客户服务-响应速度-优化项目
```

#### 1.2 项目背景写法
```
第一段(背景):交代业务场景和现状
第二段(问题):明确存在的问题
第三段(必要性):说明改进的紧迫性和价值
```

### 2. 问题描述

#### 问题陈述模板
```
在[情境]条件下，[主体]面临[问题]，导致[影响]。
具体表现为:[量化指标]。

示例:
在当前电机装配生产线运行条件下，生产团队面临换型时间过长的
问题，导致设备利用率仅65%，订单交付准时率下降至82%。
具体表现为:单次换型平均耗时45分钟，换型时间占生产周期15%。
```

#### 损失量化表格要求
| 列名 | 要求 | 示例 |
|------|------|------|
| 指标名称 | 具体可测 | 焊接不良率 |
| 当前值 | 精确数值 | 8.5% |
| 单位 | 标准单位 | % |
| 统计周期 | 时间范围 | 2024Q1 |
| 估算方法 | 数据来源 | 月度报表 |

### 3. 现状分析

#### SIPOC表格规范
- 每行对应一个关键输入/输出
- 至少包含3-5个核心过程步骤
- 客户需求需关联CTQ

### 4. 目标设定

#### SMART目标检查清单
- [ ] Specific:是否明确具体?
- [ ] Measurable:是否可量化?
- [ ] Achievable:资源是否足够?
- [ ] Relevant:是否与战略相关?
- [ ] Time-bound:是否有明确截止?

#### 目标层级表述
```
最低目标(必须达成):[底线要求]
基准目标(预期达成):[正常期望]
挑战目标(努力争取):[理想状态]

示例:
最低目标:缺陷率降至3%，DPMO从50000降至30000
基准目标:缺陷率降至2%，DPMO降至20000
挑战目标:缺陷率降至1%，DPMO降至10000
```

【纳入范围】

- 时间范围:[项目周期起止]

【排除范围】

- [明确暂不涉及的内容]

【边界说明】
[如有模糊地带，在此明确界定]
```

### 8. 风险评估

#### 风险登记模板
| ID | 风险描述 | 类别 | 可能性 | 影响 | 风险值 | 应对策略 | 责任人 |
|----|----------|------|--------|------|--------|----------|--------|
| R1 | 核心人员离职 | 人员 | 高 | 高 | 高 | AB角备份 | - |
| R2 | 数据采集困难 | 数据 | 中 | 中 | 中 | 预备方案 | - |
| R3 | 供应商配合不足 | 外部 | 中 | 高 | 高 | 合同约束 | - |

#### 风险值计算
```
风险值 = 可能性(1-5) × 影响度(1-5)

低风险:1-6
中风险:8-12
高风险:15-25
```

## 示例文档

### 完整项目章程示例

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
                 精益六西格玛项目章程
                    [项目名称]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 项目背景

   1.1 业务背景
   公司电机装配生产线于2022年投产，年产能50万台。近年来，
   客户对产品个性化需求增加，小批量订单占比从15%上升至35%。
   频繁的换型操作成为产能瓶颈。

   1.2 问题描述
   当前换型时间平均45分钟/次，最长达72分钟，与行业标杆
   (15分钟)差距显著。换型时间占生产周期15%，导致设备
   综合效率(OEE)仅65%，月均损失产能约4000台。

2. 项目目标

   2.1 总体目标
   在6个月内将换型时间从45分钟缩短至20分钟以内，达到
   行业中等水平。

   2.2 分阶段目标
   | 阶段 | 周期 | 目标换型时间 | 对应OEE |
   |------|------|-------------|---------|
   | 现状 | - | 45分钟 | 65% |
   | 阶段1 | 2个月 | 35分钟 | 72% |
   | 阶段2 | 4个月 | 25分钟 | 78% |
   | 最终 | 6个月 | 20分钟 | 82% |

3. 项目范围

   3.1 纳入范围
   - 电机装配线1号至4号工位
   - 换型相关的物料准备、工具切换、参数调整过程
   - 生产部、技术部、质量部

   3.2 排除范围
   - 设备大型改造(如模具更换)
   - 产品设计变更
   - 5号及后续产线

4. 团队组成

   | 角色 | 姓名 | 部门 | 投入比例 |
   |------|------|------|----------|
   | 发起人 | 张三 | 生产副总 | 10% |
   | 黑带 | 李四 | 精益办 | 50% |
   | 绿带 | 王五 | 技术部 | 30% |
   | 绿带 | 赵六 | 生产部 | 30% |

5. 项目计划

   | 阶段 | 时间 | 关键活动 | 里程碑 |
   |------|------|----------|--------|
   | Define | Week1-2 | 问题定义、目标确认 | 项目章程批准 |
   | Measure | Week3-5 | 换型流程分解、数据收集 | 基线报告完成 |
   | Analyze | Week6-8 | 根因分析、优先排序 | 根因清单确认 |
   | Improve | Week9-12| 方案实施、效果验证 | 新换型流程上线 |
   | Control | Week13-14| 标准化、SPC监控 | 项目关闭评审 |

6. 预期收益

   | 收益类型 | 金额/比例 | 计算依据 |
   |----------|----------|----------|
   | 产能提升 | 4000台/月 | OEE提升17% |
   | 成本节约 | 48万元/年 | 减少加班/外协 |
   | 交付改善 | 交付周期-25% | 换型时间占比下降 |

7. 风险评估

   | 风险 | 可能性 | 影响 | 应对措施 |
   |------|--------|------|----------|
   | 换型涉及部门协调 | 中 | 中 | 明确责任人、周例会 |
   | 新方案员工抵触 | 中 | 高 | 充分沟通、参与式改进 |
   | 供应商模具周期长 | 高 | 中 | 提前锁定、备选方案 |

## 常见格式问题

### 问题1:目标设定不量化
- 错误:降低缺陷率
- 正确:将焊接不良率从8%降至2%(降幅75%)

### 问题2:范围边界模糊
- 错误:优化生产流程
- 正确:优化电机装配线1-4号工位的换型流程

### 问题3:数据来源不明
- 错误:客户投诉较多
- 正确:近6个月VOC系统收到相关投诉47起，占总投诉35%

### 问题4:时间节点模糊
- 错误:尽快完成
- 正确:2024年6月30日前完成

### 问题5:收益计算缺乏依据
- 错误:节约大量成本
- 正确:减少返工1000件/月，按人工成本50元/件计算，月节约5万元

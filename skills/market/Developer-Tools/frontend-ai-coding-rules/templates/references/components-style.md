复用判据（按顺序）：
1. 同业务域已有共享件 → 直接接入；
2. 全局组件能覆盖 → 用全局组件；
3. 只有 1 处使用 → 就地写在当前模块目录，**不提前抽公共组件**；
4. ≥2 个模块出现同一需求 → `{{提升到 components-dir 还是就地引用}}`。
